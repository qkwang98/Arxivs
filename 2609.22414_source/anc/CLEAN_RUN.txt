Scope
The four public verification scripts in anc/ were run in recorded local container environments.
This archive does not contain the container recipes, so it does not by itself reconstruct those environments; the run assumes executables of the recorded versions on PATH.
The computations for the family of lattice rank 2 cover only q = 1, 2, 3, and 4, and they compute local codimensions, not the codimension in the solution space.
The lower bound of the manuscript for every integer q >= 1 is proved there, not by these finite computations.
