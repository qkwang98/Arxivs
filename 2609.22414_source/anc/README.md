# Verification supplement

This archive contains exact computational certificates for *A codimension formula for intrinsic perturbation of \(A\)-hypergeometric series*.
The companion paper *The obstruction to intrinsic perturbation for \(A\)-hypergeometric series* carries its own supplement, which covers the obstruction module and the examples.
The file `CLEAN_RUN.txt` records the software versions, the scope of the finite computations, and the results of a clean run.
The file `MANIFEST.sha256` records the SHA-256 digest of every other file in this directory.

## Requirements and complete run

The recorded environment uses SageMath 10.9 with Z3 4.15.3 and Macaulay2 1.26.06.
With `sage` and `M2` on `PATH`, run all four certificates from this directory as follows.

```sh
sh run_all.sh
```

The scripts can also be run separately.

```sh
sage verify_rank_two_solution_codimension.sage
M2 --script verify_rank_two_solution_codimension.m2
```

On a system with `sha256sum`, verify the distributed files as follows.

```sh
sha256sum -c MANIFEST.sha256
```

## Five-column rank 2 solution space

The certificates `verify_rank_two_solution_codimension.sage` and `verify_rank_two_solution_codimension.m2` check the five-column rank 2 example independently.
They compute twelve standard pairs, eleven distinct fake exponents, fake-indicial length 12, target local length 2, and intrinsic formal-solution codimension 1 after all fake exponents and both target ordered negative support families are included.

## Fixed-rank family

The SageMath certificate `verify_fixed_rank_boundary.sage` treats, for \(q=1,2,3,4\), the family of lattice rank 2 obtained by taking \(q\) copies of the rows of the Gale dual in the five-column example.
It checks the all-family local codimensions \(1,3,7,12\), which agree with \(\lceil3q^2/4\rceil\), and solves the same-coset fake-exponent equations without imposing a finite search bound.
The same certificate also checks lattice rank 2, normality of the affine semigroup generated by the reduced Gröbner basis vectors, connectedness of the column matroid, the realized negative supports and the distinguished collection, the two ideals \(J_{\mathcal N}^{\mathrm{amb}}\) and \(J_{\mathcal N}^{\mathrm{intr}}\), and the Hilbert series of the obstruction module
\[
u^q(1+u+\cdots+u^{q-1})^2,
\]
which belong to the companion paper.
It computes the full toric ideal directly for \(q\leq3\).
The independent Macaulay2 certificate `verify_fixed_rank_boundary.m2` checks that the all-family local codimensions are \(3,7\) for \(q=2,3\) and that the obstruction module has dimensions \(4,9\).

These finite calculations check the local codimensions for four values of \(q\).
**They do not compute the codimension in the solution space.**
The lower bound \(\lceil3q^2/4\rceil\) for every integer \(q\geq1\) is proved in the manuscript from these local quotients together with the ordering along each \(L\)-coset.

All computations use exact arithmetic.
No finite computation in this supplement replaces an argument in the manuscript that is stated for arbitrary input or arbitrary \(q\).
