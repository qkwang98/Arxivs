We proceed as follows:
\begin{itemize}
%% \item \appref{poc implementation} evaluates a proof-of-concept
%%   implementation of dependently-typed symmetric programming. The main
%%   goal is to determine whether the performance engineering techniques
%%   of \subsecref{partial evaluation} can eliminate the asymptotically
%%   significant overhead that symmetric programming incurs.
\item \appref{indexed adts} presents the theory of symmetric indexed
  data types, as it follows almost identical structure to its
  simply-typed counterpart.
\item \appref{simply-typed wlog details} contains further details
  about the simply-typed \WLOG{} construction (\secref{wlog construction}).
\item \appref{dependent types} contains further details
  about the dependently-typed \WLOG{} construction (\secref{dependent
    types}).
\item \appref{algebraic data types} contains further details and
  proofs about symmetric simply typed data types (\subsecref{initial
    algebras}--\subsecref{partial evaluation}).  This material is a
  special case of its dependently-typed counterparts. Much of it can
  also be done more abstractly and categorically. Here we prove much
  of it more concretely and with fewer abstractions to help make the
  material more accessible.
\item \appref{indexed data types} contains further details and proofs
  about symmetric dependently typed data types (\subsecref{indexed
    data types} and \appref{indexed adts}). Here we give concrete
  descriptions of additional auxiliary results, and omitted details
  from concrete examples.
\item \appref{cat dev} contains a more abstract category theoretic
  development that unifies parts of both theories of data types
  (cf.~summary figure in \subsecref{indexed data types}).
\end{itemize}
