# Uniform bounds on the Dunkl kernel

keywords: [Dunkl kernel, Dunkl 算子, 根系统, 绝对连续, 表示测度, 第一类 ODE 系统]
related_paper: "2609.26394"
one_liner_summary: 对任意约化根系统，给出 Dunkl 核及其任意导数在空间变量上一致的显式上界，并由此证明对重数 $k>1/2$ 与一般谱参数，Dunkl 交错算子表示测度关于 Lebesgue 测度绝对连续，解决了 Rösler–de Jeu 猜想在 $k>1/2$ 情形的肯定解答。

## 1.  核心定位

- **解决的问题**：一般约化根系统上 Dunkl 核 $\Exp_{k}(\lambda,\cdot)$ 的增长估计——现有结果仅在开 Weyl 房内的锥形区域一致（\cite{roslerDeJeu, amriGasmi}），本文给出固定谱参数下对空间变量的全局一致上界，即使空间参数奇异。
- **大图景位置**：Dunkl 核是 Dunkl 变换（推广 Fourier 变换与 Cartan 运动群球变换）的积分核，其增长估计是建立反转与 Plancherel 定理等调和分析的基础；几何情形（Cartan 运动群球函数）的尖锐上界由 Clerc 得到，本文将其推广到一般 Dunkl 设置。
- **主要贡献**：
  - 对 $\lambda\in\a+i\areg$ 与 $\Re\,k\geq 0$，给出 $\Exp_{k}(\lambda,\cdot)$ 对空间参数（含奇异参数）的一致上界；对 $k\geq 0$ 与 $\lambda\in\areg$ 亦成立。
  - 对任意导数 $p(\partial)\Exp_{k}(\lambda,\cdot)$ 给出一致上界（此前仅在几何情形与秩一 $A_1$ 情形已知）。
  - 覆盖复值重数 $\Re\,k\geq 0$（此前尖锐结果要求 $k\geq 0$）。
  - 应用：证明 $k>1/2$ 与一般谱参数下表示测度 $\mu^k_\lambda$ 关于 Lebesgue 测度绝对连续，并给出密度可微性结果；肯定 Rösler–de Jeu 猜想在 $k>1/2$ 的成立。
- **关键先驱工作**：Dunkl 算子与 Dunkl 核（Dunkl, Opdam, de Jeu）；Clerc 的球函数一致上界归纳法；Rösler 的 Dunkl 核积分表示；Rösler–de Jeu 的锥形区域一致界与绝对连续性猜想；Anker–Trojan 二面体群与 Graczyk–Sawyer 对称群的尖锐渐近。
- **结果边界**：上界对固定谱参数一致，而非对谱参数一致（后者仅在复几何情形由 Etingof–Rains 给出，但未利用根系统结构、非尖锐）；绝对连续仅对 $k>1/2$（$0<k\leq 1/2$ 情形仍开放）；未给出 Dunkl 核的完整渐近展开（Bessel 系统具不规则奇点，与超几何系统不同）。
- **开放问题**：$0<k\leq 1/2$ 时表示测度的绝对连续性；一般根系统 Dunkl 核的尖锐渐近展开；谱参数与空间参数同时一致的尖锐界。
- **应用与推广**：Dunkl 变换调和分析（反转、Plancherel）；Dunkl 热核估计（\cite{dziubanskiHejna} 的改进）；随机过程与马尔可夫过程理论（结合 Dunkl 卷积代数，见 [[arxiv_read/2609.26394]]）。

- 技术迁移：本文构造的与抛物子群相伴的一阶系统（修改后便于渐近分析）可迁移到 Heckman–Opdam 超几何系统与对称空间非紧型情形的类似估计。

### 2.3.  批判性思考

- 归纳法（正则参数过渡到奇异参数）需要系统的渐近可研究性，本文为此大幅修改了 Dunkl 核特征值性质导出的一阶系统；修改过程中的控制常数是否随秩增长而劣化需要审视。
- 复值重数 $\Re\,k\geq 0$ 情形的上界虽成立，但最优性（与尖锐界的一致性）仅在若干特例中被验证。
