# Rzk: a Proof Assistant for Synthetic ∞-Categories

keywords: [proof assistant, synthetic ∞-category theory, simplicial type theory, Riehl-Shulman, Rzk, Rezk types, directed type theory]
related_paper: "Riehl-Shulman — A type theory for synthetic ∞-categories"
one_liner_summary: "Presents Rzk, a proof assistant implementing a refinement of Riehl-Shulman's simplicial type theory for synthetic (∞,1)-category theory, with faithfulness and conservativity results, bidirectional type checking, and an automated tope solver."

## 1.  🎯 核心定位

- **解决的问题**：将 Riehl-Shulman 的 simplicial type theory (RSTT)——一种支持合成 (∞,1)-范畴推理的依赖类型论——实现为一个可用的证明助手 Rzk，并提供严格的理论基础（声明式精化、翻译忠实性/保守性、算法化类型检查）。

- **大图景位置**：在 HoTT（合成 (∞,0)-范畴）之后，RSTT 将合成方法推进到高一维——(∞,1)-范畴。Rzk 使这种推理从纸面走向计算机，并已支撑 25,000+ 行的标准库 sHoTT 和 Yoneda 引理的首次形式化。

- **主要贡献**：
  1. **声明式精化（dRzk）**：在 RSTT 基础上增加了 split extension types（外延类型的 shape-indexed Π-type + 类型限制分解）和无强转子类型化（coercion-free subtyping），使 RSTT 的"隐式重塑"(silent reshaping)规范化
  2. **翻译忠实性与保守性**：从 RSTT 到 dRzk 的翻译是忠实的（Thm: faithfulness）且在一个自然推导片段上是保守的（Thm: conservativity），猜测量在全片段上保守
  3. **算法化实现（aRzk）**：双向类型检查算法 + 自动化 tope solver（处理 cube 层上的直觉主义命题逻辑，含等式和 directed interval 𝕀₂）

- **关键先驱工作**：Riehl-Shulman 2017 的 RSTT（原论文的定理是 schematically 陈述的）、Martin-Löf 依赖类型论、Hofmann-Streicher 的 groupoid 解释、Voevodsky 的 univalence、cubical type theories (CCHM)

- **结果边界**：
  - 保守性目前仅在"无 extension type 引入规则"的推导片段上证明（全保守性为猜想）
  - Tope solver 不完备——基于启发式搜索，不是决策过程
  - 缺少隐式参数、用户自定义（高阶）归纳类型——限制了对具体 ∞-范畴的形式化

- **开放问题**：
  1. RSTT 的正规化是否终止？（Weinberger-Ahrens-Buchholtz-North 2022 指出未知）
  2. tope 片段可判定性（作者猜想可判定，但未证明）
  3. Split constructs（特别是 free-standing restriction）的直接语义
  4. 全保守性猜想：dRzk 是否对 RSTT 完全保守？

- **应用与推广**：已用于形式化 Rezk 类型、共变族、伴随、cocartesian 纤维化、(共)极限、Yoneda 引理。未来用于教学（ICERM 2026 工作坊）和游戏化证明引擎。

## 2.  📐 主要定理

> **Theorem (Faithfulness)**. Every derivation in RSTT translates to a derivation in dRzk. — The proof reduces to showing that RSTT's extension type rules are admissible in dRzk.

> **Theorem (Conservativity)**. On a natural fragment of derivations (those that do not introduce extension types), dRzk proves nothing new about RSTT types: if Γ ⊢_{dRzk} a : A and Γ, A are in the image of the translation, then Γ ⊢_{RSTT} σ(a) : σ(A) for a back-translation σ. — *[全片段保守性为猜想]*

> **Proposition (Algorithmic Soundness)**. The bidirectional type-checking algorithm of aRzk is sound relative to dRzk: if the checker accepts a judgment, then it is derivable in dRzk.

## 3.  🔑 关键组件

### 3.1.  声明式精化的三个增量

> **Split Extension Types**: 将 RSTT 的 ext 类型分解为两步——shape-indexed Π-type（t : (⟨Δ⟩ → A)）后接类型限制 ⟨t |_Φ ≡ a⟩。这使得外延类型的形式化不再需要"融合"的元操作。

> **Coercion-Free Subtyping**: 内化 RSTT 中的隐式重塑（silent reshaping）为显式子类型关系 A ≤ B，无强转（coercion）——子类型判断直接"类型检查通过"而不是插入类型转换项。

> **First-Class Parameters**: 将 RSTT 中的 cube/tope 作为定义的一级参数（schematic parameters），使单个 Rzk 定义对所有 cube 实例普遍适用。

### 3.2.  Tope Solver

> 自动化推理 cube 层上的直觉主义命题逻辑，包含：
> - cube 变量和点之间的等式（如 ⟨0⟩ ≡ ⟨1⟩ → 矛盾）
> - directed interval 𝕀₂ 的特殊推理（0, 1 端点，无对合）
> - 基于 Voronkov 证明搜索风格的启发式求解器

## 4.  💡 理解辅助

- **贯穿例子（"是 Segal 类型"的判断）**：在 Rzk 中检查一个类型是否为 Segal 类型，tope solver 需要判断某些 cube 上下文中的 tope 保蕴涵关系。例如，在 𝕀₂ × 𝕀₂ 上定义复合律时，solver 需验证"中间点匹配"的 tope 条件保证 extension type 的非空性。

- **类型检查的实际流程**：用户代码 → 解析为抽象语法（自由作用域单子 Free Scoped Monad）→ 双向类型检查（检查模式 check / 推断模式 infer / 子类型模式 subtype）→ tope solver 调用。类型引导的外延类型计算（type-directed restriction）是 RSTT 特有的挑战：外延类型边界条件的计算方向由目标类型驱动。

### 5.3.  批判性思考

- 保守性证明依赖于 back-translation σ 的 coercion coherence 和 term-level subtyping 到 definitional equality 的坍缩——两者均声明但未机械化。这是理论中的实质性缺口。
- Rzk 当前缺少（高阶）归纳类型意味着 concrete ∞-范畴（如单纯形范畴 Δ、quiver 范畴）只能通过公设引入，附带命题计算规则——这对于实际可用性是一个重大限制，但也如实反映了"有向/单纯形的高阶归纳类型"这一开放理论问题。
- 与 Cubical Agda 的对比：Rzk 的对象层次是 (∞,1)-范畴（有向），而 cubical type theories 的对象层次是 ∞-groupoid（无向）。两者在"形状层"上的技术（cube、tope、interval）高度相似但目标不同——这种分歧是否会收敛？
