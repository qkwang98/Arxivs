# Stable Limit DAHA of type (C^∨, C) and Stable Limit Koornwinder Polynomials

keywords: [stable limit DAHA, Koornwinder polynomials, almost symmetric Laurent polynomials, Cherednik operators, triangularity]
related_paper: "IW2 (stable limit DAHA of type A)"
one_liner_summary: "Constructs the stable limit double affine Hecke algebra of type (C^∨, C) acting on almost symmetric Laurent polynomials in infinite rank, with two distinct stabilizations (positive t-adic and negative t^{-1}-adic), and proves that non-symmetric Koornwinder polynomials stabilize to eigenfunctions of the limit Cherednik operators."

## 🎯 核心定位

- **解决的问题**：在无限秩极限下构造 type (C^∨, C) 的稳定极限 DAHA 作用，并证明 Koornwinder 多项式的稳定化。
- **大图景位置**：这是 I.-S. Lee–Oh–Schiffler (IW2) 等构造的 type A 稳定极限 DAHA 的自然 type C 推广。type A 与 type (C^∨, C) 的稳定极限之间存在比较图谱。
- **主要贡献**：
  1. 构造 type (C^∨, C) DAHA 在 almost symmetric Laurent 多项式上的正/负稳定极限作用
  2. 证明极限 Cherednik 算子的 triangularity 性质（monomial 基底下的上三角性）
  3. 证明非对称 Koornwinder 多项式的 t-adic 和 t^{-1}-adic 稳定化并给出极限特征值
- **关键先驱工作**：IW2 的 stable limit DAHA of type A；Stokman 的 Koornwinder 多项式三角性公式；Sahashrabudhe 的 Koornwinder 多项式递推
- **结果边界**：stable limit Koornwinder 多项式不构成 Pas± 的基底（与 type A 相同），需要 tail symmetrization 获取完整特征基；负稳定化中 λ_i ≤ 0 的控制权重非零
- **开放问题**：tail symmetrization 在 type (C^∨, C) 中的构造；正/负稳定极限 Koornwinder 多项式之间的对偶性；与 type A 稳定极限理论的显式比较公式
- **应用与推广**：为 Macdonald–Koornwinder 多项式的无标度极限理论补全 type (C^∨, C) 版图；可用于相关可积系统和 (q,t) 变形理论

## 📐 主要定理

> **Theorem (Stable Limit DAHA Action, Theorem \ref{def: positive Limit DAHA action})**: The rescaled Cherednik operators $t^n Y_i^{(n)}$ converge in the $t$-adic topology to operators $\tilde{Y}_i^+$ on the space $\mathcal{P}_{\mathrm{as}}^{\pm}$ of almost symmetric Laurent polynomials, giving a positive stable limit DAHA action of type $(C^\vee,C)$. Similarly, $t^{-n} Y_i^{(n)}$ converge in the $t^{-1}$-adic topology to $\tilde{Y}_i^-$, giving a negative stable limit DAHA action.

> **Theorem (Stable Limit Koornwinder Polynomials, Theorem \ref{thm: stable limit Koornwinder})**: Let $\lambda \in \mathbb{Z}^k$ with $\lambda_k \neq 0$. Then the sequence $\{E_{\lambda 0^n}\}_{n\geq 0}$ of non-symmetric Koornwinder polynomials converges $t$-adically to $\mathcal{E}_{\lambda}^+ \in \mathcal{P}_{\mathrm{as}}^{\pm}$ and $t^{-1}$-adically to $\mathcal{E}_{\lambda}^- \in \mathcal{P}_{\mathrm{as}}^{\pm}$. Moreover, $\mathcal{E}_{\lambda}^+$ and $\mathcal{E}_{\lambda}^-$ are eigenfunctions with
$$\tilde{Y}_i^+ \mathcal{E}_{\lambda}^+ = \delta_i(\lambda) q^{\lambda_i} t^{u_{\lambda}(i)} \mathcal{E}_{\lambda}^+, \qquad
\tilde{Y}_i^- \mathcal{E}_{\lambda}^- = \delta_i'(\lambda) q^{\lambda_i}(t_0 t_{\infty}) t^{-u_{\lambda}(i)} \mathcal{E}_{\lambda}^-.$$

### 证明思路

- 第一步：利用 Stokman 的有限秩三角性公式将 $Y_i^{(n)} x^\lambda$ 展开为 Bruhat 序下更小的单项式之和
- 第二步：将 Cherednik 算子作用分解为 raising part + symmetric part + β-proportional term，分别证明各项在 t-adic (resp. t^{-1}-adic) 拓扑下的收敛性
- 第三步：对 Bruhat 序做归纳——顶端系数 $a_{\lambda 0^n,\lambda 0^n}^{(n)}=1$ 显然收敛；对较低项利用特征值方程和 Corollary 中的系数极限性质推导收敛性
- 第四步：利用递推关系 $E_{s_i \lambda} = (T_i + \text{rational function}) E_\lambda$ 将 $E_{\lambda 0^n}$ 表为有限个特定单项式的组合

## 🔑 关键组件

### 关键引理

> **Lemma (Plethystic identity for symmetric part)**: For $x_i^{\pm 1}$ in the raising/lowering operator action, the symmetric part satisfies plethystic identities involving $e_1[X_1^{\pm}] = \sum_{j=1}^\infty (x_j + x_j^{-1})$, enabling the convergence analysis.

> **Corollary (Stable convergence)**: The rescaled sequence $\{t^n Y_i^{(n)} \Pi_n m_{\lambda|\mu}\}$ converges $t$-adically in $\mathcal{P}_{\mathrm{as}}^{\pm}$. — *[新证，直接构造]*

### 关键定义

> **Definition (Almost symmetric Laurent polynomials $\mathcal{P}_{\mathrm{as}}^{\pm}$)**: The space of sequences of Laurent polynomials $\{f_n\}_{n \geq 0}$ with $f_n \in \mathbb{K}'[x_1^{\pm 1}, \dots, x_n^{\pm 1}]^{S_n \rtimes \mathbb{Z}_2^n}$ satisfying a compatibility condition $\pi_{n+1}f_{n+1} = f_n$, modulo sequences converging to 0 in the $t$-adic topology.
> **动机**：这是 type A stable limit DAHA 中"几乎对称多项式空间"的 type (C^∨, C) 类似物，承载稳定极限作用。

> **Definition (Positive/Negative stable limit):** The positive limit uses $t$-adic topology with $t \to 0$; the negative limit uses $t^{-1}$-adic topology with $t \to \infty$. The positive case emphasizes $\lambda_i > 0$ contributions ($\delta_i(\lambda)$), while the negative case emphasizes $\lambda_i \leq 0$ contributions ($\delta_i'(\lambda)$).
> **动机**：两种稳定化捕捉了 Koornwinder 多项式在参数空间两个边界上的渐近行为，与 type A 的单一稳定化形成对比。

## 💡 理解辅助

- **贯穿例子**：$\lambda=(0,1)$ 和 $\lambda=(-1)$ 的显式计算贯穿全文。
  - $\mathcal{E}_{(0,1)}^+ = x_2 + (1-t)x_1 + q^{-1}\alpha$, $\mathcal{E}_{(0,1)}^- = x_2$
  - $\mathcal{E}_{(-1)}^+ = x_1^{-1} + \frac{q(t-1)}{t-q}e_1[X_1^{\pm}] + \frac{q(t-1)}{t-q}x_1 - \frac{\alpha + q\beta}{t-q}$
