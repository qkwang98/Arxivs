# Recognizing CGW categories among pointed stable double Segal spaces

keywords: [CGW category, double Segal space, lifting property, classifying double category, triple category]
related_paper: "BOORS (2-Segal objects and the Waldhausen S-construction)"
one_liner_summary: "Characterizes CGW categories purely through lifting properties against a finite set of double functors, establishes the classifying double category as a strictly local construction generalizing Rezk's classifying diagram, and extends to classifying triple categories of double categories with shared isomorphisms."

## 🎯 核心定位

- **解决的问题**：CGW category（Campbell–Gepner–Waldhausen 范畴）是一个组合/范畴论公理系统，此前没有纯 lifting property 的等价刻画。本文给出这种刻画，从而将 CGW category 理论纳入正交 lifting property (OLP) 框架。
- **大图景位置**：与 Bergner–Osorno–Ozornova–Rovelli–Schembri (BOORS) 的稳定双 Segal 空间理论对接——CGW categories 通过 double nerve 对应 pointed stable double Segal spaces，lifting property 刻画使这一对应更加透明。
- **主要贡献**：
  1. 给出 CGW category 的完整 lifting property 刻画（8 个 double functor 的集合）
  2. 定义 classifying double category 并证明其由 lifting property 唯一确定
  3. 推广至 classifying triple category（双范畴情形），建立与 bisimplicial spaces 的桥梁
- **关键先驱工作**：Campbell 的 CGW category 定义；BOORS 的 stable double Segal spaces；Rezk 的 classifying diagram
- **结果边界**：需要一个预增广（preaugmentation）或 pointedness 结构来处理 zero object；reverse CGW category 需垂直对偶
- **开放问题**：triple category 与 triple Segal spaces 之间的比较；classifying triple category 的 homotopical 版本
- **应用与推广**：为 S_•-construction 和 algebraic K-theory 中使用 CGW categories 提供等价刻画；将 CGW 理论与组合模型范畴联系起来

## 📐 主要定理

> **Theorem (CGW Recognition, Corollary \ref{cgwliftingpropertiespointed})**: A left pointed double category $\mathbb{D}$ admits the structure of a CGW category if and only if it is local with respect to
> $$\{\toprightcorner, \bottomleftcorner, \mathbb{H}(\mathsf{mono}), \mathbb{V}(\mathsf{mono})\}$$
> and strictly local with respect to
> $$\{\mathsf{truncate}_h, \mathsf{truncate}_v, \mathsf{h}_{\mathrm{iso}}, \mathsf{v}_{\mathrm{iso}}, \mathsf{unique}_{\toprightcorner}, \mathsf{unique}_{\bottomleftcorner}\}$$
> in the category of pointed double categories.

> **Theorem (Classifying Double Category, Theorem in §5)**: A double category $\mathbb{D}$ is a classifying double category (i.e., of the form $S_{\mathsf{cl}}(\mathcal{C})$ for a category $\mathcal{C}$) if and only if it is strictly local with respect to the set
> $$S_{\mathsf{cl}} = \{\mathsf{flatten}, \mathsf{truncate}_h, \mathsf{truncate}_v, \mathsf{h}_{\mathrm{iso}}, \mathsf{v}_{\mathrm{iso}}, \mathsf{rotation}, \mathsf{unique}_{\toprightcorner}\}$$
> satisfying 7 distinct lifting properties.

### 证明思路

- 第一步：在双范畴中逐条翻译 CGW 的公理（I）shared isomorphisms、（M）horizontal monic + vertical epic、（Z）zero object、（K）completion of mixed morphisms 为 lifting property
- 第二步：证明 vertical/horizontal isomorphism 的 lifting property 等价于 shared isomorphisms（公理 I）
- 第三步：mono/epi 条件通过 $\mathbb{H}(\mathsf{mono})$ 和 $\mathbb{V}(\mathsf{mono})$ 的 lifting 捕获
- 第四步：completion axiom (K) 通过 corner 和 unique corner lifting 刻画
- 第五步：classifying double category 需额外加入 flatten（将任意方块展平为交换方块）和 rotation（旋转函子 $\mathsf{R}_{\mathbb{D}}$）

## 🔑 关键组件

### 关键引理

> **Lemma (Adjunction lift)**: If $F \dashv G$ is an adjunction between categories, then $X$ is $F(f)$-local if and only if $G(X)$ is $f$-local. — *[标准范畴论工具]*

### 关键定义

> **Definition (Classifying Double Category $S_{\mathsf{cl}}(\mathcal{C})$)**: For a category $\mathcal{C}$ with shared isomorphisms, the classifying double category has objects = objects of $\mathcal{C}$, horizontal morphisms = morphisms in $\mathcal{C}$, vertical morphisms = isomorphisms, and squares = commutative squares with vertical isomorphisms.
> **动机**：这是 Rezk 的 classifying diagram 的双范畴版本，捕获"一个范畴作为双范畴"的最小结构。

> **Definition (Rotation functor $R_{\mathbb{D}}$)**: Takes a square in $\mathbb{D}$ and rotates it, swapping horizontal and vertical directions. A double category is *vertically flexible* when the rotation functor is an equivalence.
> **动机**：classifying double category 的旋转不变性是其区别于一般 CGW category 的关键特征。

> **Definition (Triple Category)**: A strict 3-fold category structure with objects, three kinds of 1-morphisms, three kinds of 2-dimensional squares, and 3-dimensional cubes, satisfying strict interchange laws in all directions.
> **动机**：classifying triple category 将"双范畴的分类图"概念推广到双范畴本身，为 bisimplicial 比较铺路。

> **Definition (CGW Category)**: A double category satisfying (I) shared isomorphisms, (M) horizontal monic + vertical epic, (Z) pointed (left initial object), (K) mixed morphism completion unique up to unique isomorphism.
> **动机**：这是 Campbell 为构造 algebraic K-theory 的 Waldhausen S-construction 引入的公理系统。

## 💡 理解辅助

- **贯穿例子**：分类双范畴 $S_{\mathsf{cl}}(\mathcal{C})$ 和分类三范畴 $S_{\mathsf{cl}}(\mathbb{D})$ 的构造贯穿全文。$S_{\mathsf{cl}}$ 将普通范畴"提升"为双范畴，将双范畴"提升"为三范畴。
- **lifting property 词典**：论文建立了一个完整的词典——每个 CGW 公理 ↔ 一组 lifting properties。例如 shared isomorphisms ↔ $\{\mathsf{truncate}_h, \mathsf{truncate}_v, \mathsf{h}_{\mathrm{iso}}, \mathsf{v}_{\mathrm{iso}}\}$。
