# Möbius functions for pseudo-Levi subgroups in finite general linear and symplectic groups

keywords: [Möbius function, pseudo-Levi subgroup, finite general linear group, symplectic group, poset]
related_paper: "Nam (2025) — decomposition of tensor products of characters"
one_liner_summary: "Explicit computation of the Möbius function on the poset of pseudo-Levi subgroups containing a fixed maximal torus for GL_n(q) and Sp_{2n}(q), enabling closed-form evaluation of character tensor product decomposition formulas."

## 🎯 核心定位

- **解决的问题**：计算有限群 GL_n(q) 和 Sp_{2n}(q) 中包含固定极大环面的伪 Levi 子群所成偏序集的 Möbius 函数。
- **大图景位置**：为 Nam (2025) 的特征标张量积分解公式提供显式 Möbius 函数值，将其从存在性推进到可计算性。
- **主要贡献**：
  - 将伪 Levi 子群偏序集与集合分区偏序集建立同构，通过组合方法给出 Möbius 函数的完整闭式公式
  - GL_n(q) 情形：μ(G₁, G₂) = (−1)^(k−p)（k, p 分别为 G₁, G₂ 的 GL 因子数），或 0（除 p<k 且指数集匹配+相邻因子指数不等时）
  - Sp_{2n}(q) 情形：引入 underlined set partitions 及带型 (GL/GU) 区分，给出完整的零/非零判定和值公式
- **关键先驱工作**：Nam (2025, multiplicity formula for tensor products), Malle–Testerman (2011, 伪 Levi 子群与 Frobenius 映射), Stanley (EC1, Möbius 函数与 Weisner 定理)
- **结果边界**：适用于 GL_n(q) 和 Sp_{2n}(q)；Sp 情形要求 Frobenius 在 Weyl 群上平凡作用
- **开放问题**：未处理其他经典群（正交群等）；对更高秩的李型有限群有待推广
- **应用与推广**：直接代入 Nam 公式得到 GL_n(q) 和 Sp_{2n}(q) 的显式特征标张量积分解

## 📐 主要定理

### GL_n(q) 情形

> **Theorem 2(a)** (Theorem 2.2): Let 0 and 1 be the lowest and highest elements of Π_n, respectively. Then μ_n(0,1) = (−1)^(n−1).

> **Theorem 3** (Theorem 2.3): Let G₁ = ∏ᵢ₌₁ᵏ GL_{a_i}(q) and G₂ = ∏ⱼ₌₁ᵖ GL_{bⱼ}(q) with G₁ ⊆ G₂. Then μ(G₁, G₂) = (−1)^(k−p).

> **Theorem 4** (非分裂环面一般情形): If the set of exponents of G₁ and G₂ is the same, then μ(G₁, G₂) = (−1)^(k−p). Otherwise, if p < k and the maximal element H (same exponent set as G₁) is consecutively distinct and μ(H, G₂) = 0, then μ(G₁, G₂) = 0.

> **Theorem 5** (p < k, d = cp): Let G₁ = ∏ᵢ₌₁ᵏ GL_{a_i}(qᵈ) and G₂ = GL_b(qᶜ) where d = cp for some prime p and b = ap (a = Σ a_i). Then μ(G₁, G₂) = (−1)ᵏ.

### Sp_{2n}(q) 情形

> **Theorem 6** (仅有 GL 因子、所有 d_i = 1): If G₁ = ∏ᵢ₌₁ᵖ GL_{a_i}(q) ⊆ Sp_{2k}(q), then μ(G₁, G₂) = (−1)ᵖ·2^(p−1).

> **Theorem 7** (GL + GU 因子、所有指数 = 1): If G₁ = ∏ᵢ₌₁ᵖ GL_{a_i}(q) · ∏ⱼ₌₁ᵘ GU_{bⱼ}(q) ⊆ Sp_{2k}(q), then μ(G₁, G₂) = (−1)^(p+u)·2^(p+u−2).

> **Theorem 8** (非平凡指数): If G₁ has unit factors whose count is strictly less than the total number of factors of G₁, then μ(G₁, G₂) = 0.

### 证明思路

- **第一步**：建立伪 Levi 子群偏序集 → 集合分区偏序集 Π_n 的显式同构（Lemma 2.1）
- **第二步**：对 Π_n 引入"染色+合并"组合论证：将 k^(|x|) 同时用 Möbius 反演公式和"相邻异色"计数表达，比较 k 的系数
- **第三步**：一般环面对应于非平凡分区 λ，通过因子指数集的精细化分析 + Weisner 定理逐次降阶
- **第四步**：Sp 情形引入 underlined set partitions，区分 Sp 吸收的 GL/GU 因子与独立因子，通过带下划线染色的多重计数得到幂因子 2^(p−1)

## 🔑 关键组件

### 关键引理

> **Lemma 2.1**: The poset of pseudo-Levi subgroups of GL_n(q) containing a split torus T₁ is isomorphic to Π_n (the poset of ordered set partitions of [n]). — *构造性双射*

> **Lemma 2.8** (Weisner's Theorem): Let L be a finite lattice, a ≠ 1. Then Σ_{x: x∧a=0} μ(x, 1) = 0. — *引用自 Stanley EC1*

> **Lemma 2.10**: If G ∧ G₃ = G₁, then the set of exponents of G equals that of G₁. — *关键约化技术*

### 关键定义

> **Big element** (Def 2.4): In [G₁, G₂], the unique maximal element G₃ with the same number of factors as G₁.
> **动机**：通过 Big element 利用 Weisner 定理将高因子数元素递归约化到低因子数情形

> **Consecutively distinct** (Def 2.5): G = ∏ᵢ₌₁ˢ GL_{n_i}(q^{m_i}) is consecutively distinct if m_i ≠ m_{i+1} for all i.
> **动机**：相邻指数不等时，任何非平凡合并都会改变指数多集，从而强制 Möbius 函数为零

> **Underlined set partition** (Section 3.1.1): A set partition of [k] where some blocks are underlined; partial order defined via sub-block relation and consistent underlining.
> **动机**：Sp 情形中 Sp 因子吸收 GL/GU 因子的代数结构对应 underlined partitions，下划线标记被吸收的块

## 💡 理解辅助

- **贯穿例子**：GL_n(q) 分裂环面情形：伪 Levi 子群 = ∏ GL_{a_i}(q)，对应 n 的有序整数分拆 (a₁, …, a_k)。偏序关系对应分拆的合并/细分，Möbius 函数 (−1)^(k−p) 仅依赖于合并步数（如图 2.1）。

- **小 n 示例**：
  - n = 3, p = 2, G₁ = GL₁(q) × GL₂(q), G₂ = GL₃(q)：μ = (−1)^(2−1) = −1
  - n = 3, p = k = 3：μ = 1（所有 GL₁）
