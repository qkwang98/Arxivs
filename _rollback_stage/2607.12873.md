# Record compositions of alternating permutations and noncommutative symmetric functions

keywords: [alternating permutations, record compositions, noncommutative symmetric functions, Euler numbers, sprout sequences]
related_paper: "ASS (Amdeberhan-Shareshian-Stanley, arXiv:2605.27828)"
one_liner_summary: "Refines the count of alternating permutations by record composition, giving an explicit product formula for N(α) and showing that these counts arise as coordinates of a canonical lift in the algebra of noncommutative symmetric functions."

## 1.  🎯 核心定位

- **解决的问题**：对偶数长度的交替排列按其奇位置子词（odd subword）的 record composition `\rc(\hat w)` 进行精化计数。回答 ASS (2026) 提出的两个开放问题：(1) 给出 `N(\alpha)` 的显式枚举公式；(2) 解释这些计数在对称函数理论中的代数来源。
- **大图景位置**：ASS 通过 sprout sequences 构造了对称函数 `A_n`，其幂和展开系数 `|\varphi(\lambda)|` 计数具有给定 record partition 的交替排列。本文给出 record composition 级别的精化，并通过 NSym 给出完整的代数解释。
- **主要贡献**：
  1. 显式公式：`N(\alpha) = \prod_{j=1}^{\ell} \binom{2s_j-1}{2\alpha_j-1} E_{2\alpha_j-1}`，其中 `s_j` 是部分和，`E_k` 为 Euler 数
  2. 乘法形式：`N(\alpha) = (2n)! b_\alpha / \piu(\alpha)`，其中 `b_k = kE_{2k-1}/(2k)!` 是种子 `\sec(\sqrt{t})` 的系数
  3. NSym 提升：构造 `\bA_n \in \NSym` 使得 `\chi(\bA_n) = A_n` 且 `(2n)![\Psi^\alpha]\bA_n = N(\alpha)`
- **关键先驱工作**：
  - ASS (2026)：sprout sequences 和 `A_n` 的构造
  - GKLLRT (1995)：非交换对称函数理论
  - André (1879)：Euler 数的经典组合
  - Stanley：交替排列综述
- **结果边界**：`N(\alpha)` 的公式仅适用于种子 `\sec(\sqrt{t})`；一般指数种子的精化由 Proposition (expseed) 给出。`\bA_n` 在 S-word 基和 ribbon 基下可以有负系数（`n \ge 4`）。
- **开放问题**：对于哪些 sprout sequences，提升 `\bR_n` 是 ribbon-正的（即 ribbon 基展开系数非负）？已知 `\sec(\sqrt{t})` 种子不满足（首个反例 `n=4`）。
- **应用与推广**：该方法适用于任何指数型种子的 sprout sequence（Proposition on expseed），包括图的连通分支计数、集合划分类等。

## 2.  📐 主要定理

> **Theorem 1**: For every composition `α = (α_1,…,α_ℓ) ⊨ n` with partial sums `s_j = α_1 + … + α_j`,
> \[ N(α) = \#\{w ∈ \Alt_{2n} : \rc(\hat w) = α\} = \prod_{j=1}^{\ell} \binom{2s_j-1}{2α_j-1} E_{2α_j-1}. \]

> **Theorem 2 (b-form)**: `N(α) = (2n)! \prod_{j=1}^{\ell} \frac{b_{α_j}}{s_j}` where `b_k = \frac{k E_{2k-1}}{(2k)!}` are the seed coefficients of `\sec(\sqrt{t})`.

> **Theorem 3 (NSym lift)**: There exists a unique graded element `\bA_n ∈ \NSym_n` such that `χ(\bA_n) = A_n` and `(2n)![\Psi^α]\bA_n = N(α)`. Explicitly, `\bA_n = \phi_b(S_n)` where `\phi_b(\Psi_k) = b_k\Psi_k`.

### 2.1.  证明思路

- 第一步：构造"块数据"（block data）`\mathcal B(\alpha)`：将 `[2n]` 划分为 `\ell` 个偶大小块，块最大元递增，每块携带一个以最大元开头的交替词。
- 第二步：证明拼接映射 `\kappa` 是双射：`\mathcal B(\alpha) \leftrightarrow \{w \in \Alt_{2n} : \rc(\hat w) = \alpha\}`（Lemma concat + Lemma decomp）。
- 第三步：分别计数：有序集划分数由 `\prod_j \binom{2s_j-1}{2\alpha_j-1}` 给出（Lemma orderedpartitions）；每块交替词数 = `E_{2\alpha_j-1}`（Lemma blockwords）。
- 第四步：NSym 提升：利用 `S_n = \sum_\alpha \Psi^\alpha / \piu(\alpha)`（GKLLRT），通过代数自同态 `\phi_b(\Psi_k) = b_k\Psi_k` 缩放得 `\bA_n`。`\chi` 投射恢复 `A_n`。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma (Ordered partitions)**: `X` 为有限全序集，`\#B_j = m_j` 且 `\max B_1 < … < \max B_\ell` 的有序集划分数为 `\prod_{j=1}^{\ell} \binom{m_1+…+m_j-1}{m_j-1}`。 — *[新证]*

> **Lemma (blockwords)**: 在偶大小集 `B`（`\#B = 2k`）上以最大元开头的交替词数 = `E_{2k-1}`（割线 Euler 数）。 — *[已知，André]*

### 3.2.  关键定义

> **Definition (Record composition)**: 对交替排列 `w ∈ \Alt_{2n}`，取奇位置子词 `\hat w_i = w_{2i-1}`。`\rc(\hat w)` = 记录位置间距构成的有序组合。
> **动机**：此统计量精化了 ASS 的 record partition——其 sort（排序）即为 record partition。

> **Definition (Ψ basis of NSym)**: `\Psi_k` 由 `\sigma'(t) = \sigma(t)\psi(t)`（其中 `\sigma(t) = \sum S_k t^k`，`\psi(t) = \sum \Psi_k t^{k-1}`）递归定义。`\Psi^\alpha = \Psi_{\alpha_1}\cdots\Psi_{\alpha_\ell}` 为基。
> **动机**：此基的非交换坐标精确对应 record composition 计数——`\Psi` 的递归结构与非交换 Newton 恒等式 `n S_n = \sum_{k=1}^n S_{n-k} \Psi_k` 是块分解算法的代数影子。

## 4.  💡 理解辅助

- **贯穿例子**：`w = 7,2,5,4,8,3,10,6,9,1 ∈ \Alt_{10}`，`\hat w = 7,5,8,10,9`，`\rc(\hat w) = (2,1,2)`。分块：`u^1=7,2,5,4`，`u^2=8,3`，`u^3=10,6,9,1`。`N(2,1,2) = \binom{3}{3}E_3·\binom{5}{1}E_1·\binom{9}{3}E_3 = 1680`。
- **小 `n` 数据**：`n=2: N(2)=2, N(1,1)=3`；`n=3: N(3)=16, N(2,1)=10, N(1,2)=20, N(1,1,1)=15`。注意 `N(1,2) \neq N(2,1)` 体现有序性。
- **NSym 提升实例**：`4!\bA_2 = 3\Psi^{(1,1)} + 2\Psi^{(2)}`。转换为 S-word 基：`S^{(1,1)} + 4S^{(2)}`（系数均为正）。但 `8!\bA_4` 中 `[S^{(1,2,1)}] = -8`（首个负系数）。
