- **解决的问题**（中文）：在直觉主义逻辑的 Topos 语义中，"常值域公理"（CD 公理，Constant Domain Axiom）何时成立？
- **大图景位置**（中文）：CD 公理是 Kripke 语义中框架条件的范畴对应物——它规定了"可能世界中域不增大"的直觉条件。本文在任意初等 Topos 中研究 CD 公理与经典逻辑公理的相互作用。
- **主要贡献**（中文）：1）定义 CD 对象（同时是 covert 与 decidable 的对象）；2）在 Boolean pretopos 中证明 CD 等价于选择公理（AC）；3）在预层 Topos $\mathrm{Set}^{\mathcal{C}^{\mathrm{op}}}$ 中给出 CD 对象的完整分类——恰好是 $\mathcal{C}$ 上的常值预层。

## 2.  📐 主要定理

> **Theorem (Boolean pretopos)**: In a Boolean pretopos, the Constant Domain axiom holds iff the Axiom of Choice holds.

> **Theorem (Presheaf topos)**: In $\mathrm{Set}^{\mathcal{C}^{\mathrm{op}}}$, an object is CD iff it is isomorphic to a constant presheaf $\Delta(S)$ for some set $S$.

### 2.1.  证明思路

- 第一步：称对象 $X$ 为 CD 对象若 $\square(X \to 1)$ 是 epi（covertness）且对角线 $X \to X \times X$ 在幂等意义下可判定（decidability as a property）。
- 第二步：在 Boolean pretopos 中，epi 有截面这一性质通过 covertness 升级为全局截面，由此推出 AC。
- 第三步：预层 Topos 中，decidability 要求每个截面局部常值——结合 covertness（截面在每个阶段存在）推出全局常值。

## 3.  🔑 关键组件

### 3.1.  关键定义

> **Definition**: An object $X$ in a topos $\mathcal{E}$ is **CD** if it is both **covert** ($X \to 1$ is epimorphic with respect to the $\square$-modality) and **decidable** (the diagonal $\Delta: X \to X \times X$ is complemented in the internal logic).

> **动机**：Covert 对应于 "每个世界有元素"（存在性），decidable 对应于 "元素相等可判定"（离散性）——两者共同刻画了"在所有可能世界中对象不变"的常值性直觉。

### 3.2.  关键引理

> **Lemma**: In a presheaf topos, decidable objects are precisely subobjects of constant presheaves. — *来自 Johnstone*

## 4.  💡 理解辅助

- **贯穿例子**：在 $\mathrm{Set}^{\Delta}$（单纯集范畴，即预层 Topos over simplex category）中，CD 对象恰好是离散单纯集——所有 face/degeneracy 映射均为恒等的常值单纯集。
