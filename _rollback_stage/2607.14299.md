# Koszul Duality for Coherent Sheaves

keywords: [Koszul duality, bounded derived category, singularity category, BGG correspondence, tails category, coherent sheaves, Koszul algebras, quadratic monomial algebra, absolutely Koszul algebra]
related_paper: "Beilinson-Ginzburg-Soergel, Koszul duality patterns in representation theory (1996)"
one_liner_summary: "建立无穷维 Koszul 代数的有界导出 Koszul 对偶，应用于交换 Noether Koszul 代数的 Proj 概形，得到凝聚层有界导出范畴的 Koszul 对偶描述。"

## 🎯 核心定位

- **解决的问题**：对无穷维 Koszul 代数，建立有界导出范畴层面的 Koszul 对偶，并将其应用于代数几何中凝聚层范畴的描述。
- **大图景位置**：经典的 BGG 对应用于多项式代数/外代数对，BGS Koszul 对偶适用于有限维 Koszul 代数。本文在无穷维非交换（和非交换）设定下填补了有界导出版本的空白。
- **主要贡献**：
  1. 对无穷维 Koszul 代数建立一般有界导出 Koszul 对偶（不假设有限维性或 Noetherian 性）
  2. 对二次单项式代数和满足额外同调条件的绝对 Koszul 代数，得到特别良好的有界对偶形式
  3. 应用于交换 Noether Koszul 代数 $\\Lambda$，得到 $\\mathsf{D}^b(\\operatorname{coh}(\\operatorname{Proj}(\\Lambda)))$ 的 Koszul 对偶描述
- **关键先驱工作**：Beilinson-Ginzburg-Soergel (1996) 的 Koszul 对偶；Bernstein-Gelfand-Gelfand (1978) 的 BGG 对应；Buchweitz (1987) 和 Orlov (2009) 的奇点范畴
- **结果边界**：要求 Koszul 代数由有限箭图定义（局部有限维），对一般无穷箭图仍需要额外技术
- **开放问题**：一般 Koszul 代数的有界对偶何时给出有界导出范畴的"好"描述？
- **应用与推广**：适用于 Grassmannian、Schubert 簇、射影齐性空间等几何对象的齐次坐标环（均已知为 Koszul）

## 📐 主要定理

> **Theorem (有界导出 Koszul 对偶)**：对任意 Koszul 代数 $\\Lambda$（不假设有限维性），Koszul 对偶函子诱导三角等价
> $$\\mathsf{D}^b(\\Lambda^!\\text{-}\\mathrm{Acl}^{\\mathbb{Z}}) \\xrightarrow{\\sim} \\mathsf{D}^b(\\Lambda\\text{-}\\mathrm{Al}^{\\mathbb{Z}})$$
> 其中 $\\mathrm{Al}^{\\mathbb{Z}}$ 为 almost linear 模范畴，$\\mathrm{Acl}^{\\mathbb{Z}}$ 为 almost colinear 模范畴。

### 证明思路

- 第一步：定义合适的精确子范畴：$\\Lambda^!\\text{-GMod}^{-,b}$ 由那些 Koszul 复形 $K(M)$ 具有有界上同调的模组成；利用 Koszul 函子将模映射到线性投射复形
- 第二步：将 Koszul 对偶函子限制到有界导出范畴层面，构造 $\\mathfrak{F}: \\mathsf{D}^b(\\Lambda^!\\text{-GMod}^{-,b}) \\to \\mathsf{D}^b(\\Lambda\\text{-GMod}^{+,b})$
- 第三步：证明 coKoszul 模对应到 Koszul 模；通过 truncation 论证将 almost linear/colinear 模与导出范畴关联，得到最终等价

## 🔑 关键组件

### 关键引理

> **Lemma (coKoszul 模与 Koszul 模的对偶)**：Koszul 对偶将 $\\Lambda^!$ 上的 coKoszul 模映为 $\\Lambda$ 上的 Koszul 模。具体地，对 coKoszul 模 $M$，$K(M)$ 的上同调集中在 0 次，且 $H^0(K(M))$ 是 Koszul 模。
> — *本文新证，通过 $\\operatorname{Ext}$ 消没条件的计算完成*

### 关键定义

> **Definition (almost linear / almost colinear 模)**：一个分次模 $M$ 称为 almost linear，若存在 $r$ 使截断 $M_{\\geq r}\\langle r\\rangle$ 是 Koszul 的；对偶地定义 almost colinear 模。
> **动机**：这是构造"好的"有界导出范畴的关键：对多项式代数上的有限生成模，Eisenbud-Goto (1984) 证明了每个有限生成模都有线性截断；本文将此推广到二次单项式代数。

## 💡 理解辅助

- **贯穿例子**：$\\Lambda = k[x_0,\\ldots,x_n]$ 为多项式代数，$\\Lambda^! = \\bigwedge(\\xi_0,\\ldots,\\xi_n)$ 为外代数。此时 $\\mathsf{D}^b(\\Lambda\\text{-Al}^{\\mathbb{Z}})$ 等同于 $\\mathsf{D}^b(\\operatorname{coh}(\\mathbb{P}^n))$，对偶给出经典的 BGG 对应。
