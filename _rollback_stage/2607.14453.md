# Simply Typed Reverse-Mode AD with Variants: Denotational Correctness via Idempotent Completion

keywords: [reverse-mode automatic differentiation, category theory, CHAD, Karoubi envelope, variants, denotational semantics, bicartesian closed, idempotent completion, coproduct obstruction]
related_paper: "Vákár (2021) - CHAD; Lucatelli Nunes & Vákár (2023) - Expressive CHAD; Kelly (1982) - Basic Concepts of Enriched Category Theory"
one_liner_summary: "解决反向模式自动微分中 variant/sum 类型的障碍：通过 Karoubi 完备化将依赖的余切空间族嵌入到普通非依赖目标范畴中，证明了 $\Kar(\Copow_\kappa(\mathcal C))\simeq\Fam_\kappa(\mathcal C)$ 当且仅当 $\mathcal C$ 是 Cauchy 完备的且每个 $\kappa$-小族有公共收缩宿主，并由此构造了 bicartesian closed 解释——其中的投影子和反向传播器都是普通非依赖目标项的显式公式。"

## 1.  🎯 核心定位

- **解决的问题**：CHAD 的反向模式自动微分中，variant（和类型）的余切空间依赖于运行时选择的 branch，因此从普通简单类型目标 $\Copow(\mathbf{Vect}^{\mathrm{op}})$ 中无法获得 $\amalg$。传统 Expressive CHAD 使用依赖类型 $\Fam(\mathbf{Vect}^{\mathrm{op}})$，而被执行时又需要用公共载体。本文明确回答：为什么简单类型可以呈现依赖语义，以及载体外的行为由什么决定。
- **大图景位置**：本文定位在 CHAD（Combinatory Homomorphic Automatic Differentiation）语义驱动 AD 的规划中。CHAD 基本框架（Vákár 2021）使用常余切模型 $\Copow(\mathbf{Vect}^{\mathrm{op}})$，只能处理 Cartesian 闭结构（乘积、指数），不能处理余积（variant）。本文在基本 CHAD 和依赖 CHAD 之间架起一座桥梁——Karoubi 完备化。
- **主要贡献**：① 证明了公共收缩宿主生成 Karoubi 完备化后的 $\kappa$-小余积，并得到等价条件：$\Kar(\Copow_\kappa(\mathcal C))\simeq\Fam_\kappa(\mathcal C)$ 当且仅当 $\mathcal C$ 是 Cauchy 完备且每个 $\kappa$-小族有公共收缩宿主（对 $\mathbf{Vect}^{\mathrm{op}}$，直和提供了这样的宿主）。② 构造了反向 AD with variants 的 bicartesian 闭解释到完备化后普通目标中：$\overleftarrow{\mathcal D}_{\mathrm{Kar}}:\Synp\to\Kar(\T_{\Tar}^{\leftarrow})$。③ 证明了分裂生成幂等元后得到的解释与依赖 CHAD 自然同构。④ 给出了唯一与投影子兼容的 ambient backpropagator 公式：$\widehat R_t(x)=\iota_{\tau,x}Df(x)^{\mathsf T}\rho_{\sigma,f(x)}$。
- **关键先驱工作**：Vákár (2021) + Vákár-Smeding (2022) 基本 CHAD；Lucatelli Nunes-Vákár (2023) 依赖 CHAD；Kelly (1982) 和 Borceux-Dejean (1986) Karoubi 包络的万有性质；Mac Lane (1998) CWM 关于分裂幂等元。
- **结果边界**：定理要求 $\mathcal C$ 是 Cauchy 完备且每个族有公共收缩宿主——对 $\mathbf{Vect}^{\mathrm{op}}$ 通过直和满足；更一般的范畴（如某些 topoi）是否满足需要单独验证。结果适用于 tuple-and-variant 数据类型的源语言。
- **开放问题**：更一般的代数数据类型（递归类型、GADT）的 idempotent completion 策略是否有效？executable CHAD 中稀疏表示的冗余消除是否与这里的投影子兼容？
- **应用与推广**：直接使 CHAD 的实现者可以使用普通简单类型（不需要依赖类型基础设施）来获得 variant 的正确导数；揭示了反向 AD 中的 "ambient backpropagator 在无效 fibre 上的行为" 由投影子自然决定。

## 2.  📐 主要定理

> **Theorem (完成等价定理)**：对正则无限基数 $\kappa$ 和范畴 $\mathcal C$，包含函子 $J_{\mathcal C}:\Copow_\kappa(\mathcal C)\hookrightarrow\Fam_\kappa(\mathcal C)$ 延拓为等价
> $$\Kar(\Copow_\kappa(\mathcal C))\simeq\Fam_\kappa(\mathcal C)$$
> 当且仅当 $\mathcal C$ 是 Cauchy 完备的且每个 $\kappa$-小族 $\mathcal C$ 中有公共收缩宿主。

> **Theorem (Bicartesian 闭解释)**：对自由生成的 bicartesian 闭语法 $\Synp$ 和反向目标 $\T_{\Tar}^{\leftarrow}$，存在结构保持函子
> $$\overleftarrow{\mathcal D}_{\mathrm{Kar}}:\Synp\longrightarrow\Kar(\T_{\Tar}^{\leftarrow}),$$
> 其在数据类型处的幂等元是 $(1,p_\tau)$，在函数类型处 Cartesian 闭结构投射整个函数-反向传播器包 $h\mapsto e_\sigma h e_\tau$。

### 2.1.  证明思路

- 第一步：$\Copow(\mathbf{Vect}^{\mathrm{op}})$ 是 Cartesian 闭的但无余积——Proposition 显示 $(1,0)\amalg(1,\mathbb R)$ 不存在。障碍在于不同 branch 的余切 fibres 不同。
- 第二步：在 $\Fam$ 中，variant 的余切是分 branch 定义的。$\Fam$ 等价于将常族范畴完备化：$\Fam\simeq\Kar(\Copow)$ 当满足上述条件。
- 第三步：在具体模型中，完备化后的 $\Kar(\Copow(\mathbf{Vect}^{\mathrm{op}}))$ 中，幂等元 $p_{\mathsf{inl}(a)}(v,w)=(v,0)$ 和 $p_{\mathsf{inr}(b)}(v,w)=(0,w)$ 将公共载体 $V\oplus W$（直和为宿主）分裂为正确的 fibre。这正是 variant 的余积构造。
- 第四步：对函数类型，Cartesian 闭结构在完备化中自动生成新的幂等元 $h\mapsto e_\sigma h e_\tau$。最终将 splitting 后得到的对象与 Expressive CHAD 的对象比较，获得自然同构。

## 3.  🔑 关键组件

### 3.1.  关键定义

> **Definition (公共收缩宿主)**：$\mathcal C$ 中一族对象 $(X_i)_{i\in I}$ 有公共收缩宿主若存在对象 $P$ 及箭头 $X_i\xrightarrow{s_i}P\xrightarrow{r_i}X_i$ 满足 $r_is_i=1_{X_i}$。
> **动机**：这是使 Karoubi 完备化后的常族范畴获得余积的充要条件——在 $\mathbf{Vect}^{\mathrm{op}}$ 中，直和扮演宿主的角色。

## 4.  💡 理解辅助

- **核心例子**：variant $A+B$ 的反向 AD。基值在左分支时，有效余切空间是 $V$；在右分支时是 $W$。直和 $V\oplus W$ 作为公共宿主，投影子 $p_{\mathsf{inl}(a)}$ 和 $p_{\mathsf{inr}(b)}$ 正确地挑选出有效子空间。完备化后，投影子的像成为显式的 fibre 对象，恢复了依赖 CHAD 的语义。
- **幂等元在函数类型上的行为**：一个函数 $f:A\to B$ 的反向传播器是一个函数 $f^*:A\;(W\to V)$。当 $A$ 和 $B$ 通过幂等元 $e_A$、$e_B$ 分裂时，整个函数包被投射为 $e_B\circ(f,f^*)\circ e_A$。
