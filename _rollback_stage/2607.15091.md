# Comonads as spaces

keywords: [comonads, formal topology, presheaf toposes, spatial quotient, discrete objects, idempotent completion]
related_paper: "Spivak, Toposic vs. topological spaces (2024)"
one_liner_summary: "将余单子（comonad）视为广义空间：在任意 Grothendieck 拓扑斯中，任何 idempotent 完成范畴的余单子定义了空间对象，其离散对象为不动点，空间族为其余代数。提供了一类统一的广义空间语言，桥接拓扑斯、形式拓扑与范畴论。"

## 1.  🎯 核心定位

- **解决的问题**：给定任意范畴的正规余单子（normal comonad），它何时定义一个"空间"？本文的核心洞察：任何范畴上的任何 idempotent 完成（Cauchy 完备）范畴上的任何正规余单子，其 Eilenberg-Moore 范畴的边缘双函子自动成为**拓扑斯**——余代数范畴本身是一个空间。
- **大图景位置**：本研究为"空间"概念提供了范畴论的内生定义，基于抽象的余单子结构而非拓扑/测度/光滑的预设。
- **主要贡献**：
  1. 提出余单子即空间的核心哲学：任何 idempotent 完成范畴上的正规余单子定义一个空间对象
  2. 定义空间中的离散对象（余单子的不动点）和空间族（余代数）
  3. 研究空间之间的映射（colax 函子；等价于几何态射）
  4. 建立函数空间构造：两个空间之间的 Map 空间，其离散对象为空间映射
  5. 对接拓扑斯理论：预层拓扑斯中的余单子经 idempotent 完成得到一般空间——因此预层范畴可视为空间"胚"的站点
- **关键先驱工作**：Isbell 的对偶；Barr 和 Kennison 的 injective hull；Taylor（2002）和 Leinster-Weber（2003）的范畴论背景
- **结果边界**：需假定范畴 idempotent 完成；大型范畴的处理可使用任意正规余单子然后取 Cauchy 完备化
- **开放问题**：形式拓扑（locale）理论、Isbell 对偶、以及具体数学实例中的余单子空间解释
- **应用与推广**：统一处理拓扑空间、locale、凝聚拓扑斯、预层拓扑斯、度量空间等不同类型的"空间"

## 2.  📐 主要定理

> **Theorem（余单子即空间）**：设 $\mathcal{D}$ 是一个 idempotent 完成范畴，$(\mathcal{D}, !^*, !_*)$ 是 $\mathcal{D}$ 上一个正规余单子。则 $\mathrm{EM}(!^*)$ 是拓扑斯，且其离散对象为 $!^*$ 的不动点（$!^*X \cong X$）。

### 2.1.  证明思路

- 余代数范畴 $\mathrm{Coalg}(!^*)$ 是 Eilenberg-Moore 范畴，自动完备和余完备
- 正规余单子的关键性质保证了余代数范畴是笛卡尔闭的且子对象分类子存在
- $!^*$ 的地图 $!_M: M \to !^*M$ 是离散化的通用映射

## 3.  🔑 关键组件

### 3.1.  关键定义

> **Definition（正规余单子）**：一个余单子 $(!^*, \epsilon, \delta)$ 称为正规的（normal），若 $!^*$ 保持有限极限，且余单位的每个分量是满态射。
> **动机**：正规性条件确保余代数范畴像空间一样良好——具有笛卡尔闭结构和子对象分类子。

## 4.  💡 理解辅助

- **贯穿例子**：经典拓扑空间对应 $\mathcal{D} = \mathbf{Set}$ 上的恒等余单子——每个集合都是离散的，余代数就是任意集合，即离散空间。更一般的空间（如拓扑空间、locale）对应与预层拓扑斯相关的余单子。
