# Learning in Infinitesimal Non-Compositional Sketches

keywords: [tangent categories, sketches, categorical machine learning, diagrammatic backpropagation, Lie brackets, coalgebras, Kan extensions, reinforcement learning]
related_paper: "Mahadevan, Diagrammatic Backpropagation (2026)"
one_liner_summary: "将机器学习重构为范畴论中合成性失败问题的修复：将学习问题表示为 sketch（含交换条件、极限锥和余极限锥），然后通过切函子提升到切范畴，提出无穷小非合成性（INC）概念，并通过 coalgebra 不动点定理建立学习的收敛理论。"

## 1.  🎯 核心定位

- **解决的问题**：标准机器学习语言是优化——选择损失函数并最小化。本文提出一个范畴论替代方案：学习 = 修复图表的合成性失败（non-compositionality），损失函数仅是"基底层面的影子"。
- **大图景位置**：这是继 Diagrammatic Backpropagation (DB) 之后的深化：DB 证明了非交换图表驱动学习，本文进一步将这条线提升到切范畴，并建立了 coalgebra 不动点理论。
- **主要贡献**：
  1. 定义无穷小非合成性（Infinitesimal Non-Compositionality, INC）：图表分解障碍的切提升
  2. 构造 INC endofunctor $T_{\\text{INC}}$，其迭代产生塔 $D, TD, T^2D, \\ldots$，学习即寻找 coalgebra 不动点（$\\nu T_{\\text{INC}}$）
  3. 用 Aczel-Mendler 定理证明当 $T_{\\text{INC}}$ 有 set-based class 实现时 final INC coalgebra 存在
  4. 对完备度量空间，证明增量逼近的几何收敛性和有限误差界
  5. 引入 Lie-bracket 闭包（反对称特化）、connection（对称加速度）等交互富化
- **关键先驱工作**：Cockett-Cruttwell 切范畴理论；Makkai-Paré sketch 理论；Mahadevan 的 DB / UDL / KET 系列
- **结果边界**：本文为理论框架论文，具体实验在配套 paper 中报告
- **开放问题**：Kan-不变学习到切 Kan-不变学习的一般提升定理
- **应用与推广**：DDL（DIAGRAMMATIC BACKPROP）、ALLORA（Lie-algebraic LoRA adapters）、LASKO（Lie-algebroidal skill optimization）、因果 Lie-bracket 学习

## 2.  📐 主要定理

> **Theorem（Final INC Coalgebra）**：设 $T_{\\text{INC}}$ 有基于类实现的集合语义。则根据 Aczel-Mendler 定理，存在 $T_{\\text{INC}}$ 的 final coalgebra。当 $T_{\\text{INC}}$ 在完备度量实现中是收缩的，INC 行为稳定化的迭代塔几何收敛，近似展开有有限误差界。

### 2.1.  证明思路

- 第一步：将学习 sketch $\mathbb{S}$ 的模型 $D:J \\to \mathcal{C}$ 及其 factorization 障碍 $\mathrm{Fact}_{\\mathbb{S}}(D)$ 作为基础层
- 第二步：施加切函子 $T$，得到切图 $TD:J \\to \mathcal{C}$ 及其分解障碍——定义 $\mathrm{INC}(D) = \\mathrm{Obs}(\\mathrm{Fact}_{\\mathbb{S}}(TD))$
- 第三步：构造 $T_{\\text{INC}}$ endofunctor，对学习数据对 $(\mathrm{Fact}_{\\mathbb{S}}(D), \\mathrm{Fact}_{\\mathbb{S}}(TD))$ 迭代切提升
- 第四步：应用 coalgebra 理论获得不动点和收敛性

## 3.  🔑 关键组件

### 3.1.  关键定义

> **Definition（无穷小非合成性 INC）**：给定学习 sketch $\mathbb{S} = (S, \\mathcal{D}, \\mathcal{L}, \\mathcal{K})$ 和切范畴 $(\mathcal{C}, T)$ 中的模型 $D$，定义
> $$\\mathrm{INC}(D) = \\mathrm{Obs}(\\mathrm{Fact}_{\\mathbb{S}}(TD))$$
> 即切模型 $TD$ 在 sketch 商下的分解障碍。非合成性不是算术误差，而是万有分解问题的失败。
> **动机**：将学习信号从标量损失提升为结构化范畴障碍，同时考察基础层和切层的一致性。

## 4.  💡 理解辅助

- **贯穿例子**：Transformer 的置换等变性：标准 Transformer 满足 $F(PX) = P F(X)$。INC 进一步考察：这个等变方块在嵌入、注意力图和参数的扰动下是否保持一致？更高阶 $T^2, T^3$ 是否产生新的障碍？本文证明：精确光滑等变性贯穿所有切阶，而非零高阶障碍则精确定位了近似等变性失效的位置。
