# A cubical formalisation of topos causal models: intervention, sheaf gluing, and the intuitionistic do-calculus

keywords: [topos causal models, Cubical Agda, formal verification, sheaf theory, do-calculus, Kripke-Joyal semantics, Lawvere-Tierney topology]
related_paper: "Mahadevan (2025) — Topos Causal Models"
one_liner_summary: "用 Cubical Agda 对 Mahadevan 的 topos causal models 进行完整机器验证——修复 Lawvere-Tierney 公理缺陷，证明 sheaf gluing，并发现新的 contextuality obstruction。"

## 1.  🎯 核心定位

- **解决的问题**：Mahadevan 的 topos causal models (TCMs) 声称将因果推断嵌入 topos 中——但若干核心断言未经严格证明（sheaf gluing）、且模态公理有缺陷。如何用形式化方法验证并修复？
- **大图景位置**：这是形式化验证（formal verification）在因果推断基础中的首次大规模应用。也是 Cubical Agda 在应用范畴论（causal inference）中的前沿案例。位于证明助手 × 因果推断 × topos 理论的交叉点。
- **主要贡献**：1) 证明 sheaf gluing（原论文声称但未证明的核心定理）；2) 修复 Lawvere-Tierney 公理——三标准公理不足以推出膨胀性，需补充第四条；3) 给出双否定拓扑作为非平凡具体实例；4) 验证全部 Kripke-Joyal forcing 从句；5) 发现并验证 contextuality obstruction。
- **关键先驱工作**：Mahadevan (2025a,b,c) 的 topos causal models 原始论文；Sargsyan 的 cubical-dsep（伴生开发，概率 monad + d-separation）；Mac Lane-Moerdijk 的 topos 理论。
- **结果边界**：仅处理 1-topos（presheaf）片段。type-level sheafification 和 directed/∞-categorical lift 超出当前 Cubical Agda 范围。
- **开放问题**：type-level sheafification 的形式化难度？∞-topos 框架是否需要新的 cubical 原语？
- **应用与推广**：为因果推断的形式化验证提供了坚实基础；contextuality obstruction 对模块化因果发现有直接实践意义（需全局一致性检查）。

## 2.  📐 主要定理

> **Theorem (Intervention Classifier)**: For a natural global element x₀, the map χ: X ⇒ Ω defined by χ_c(b) = {f : d → c | X(f)(b) = x₀ d} is the characteristic map of the subobject "X = x₀", satisfying χ_c(b) = ⊤ ⟺ b = x₀ c.

> **Theorem (Sheaf Gluing)**: The pullback X ×_Z Y, with (X ×_Z Y)(c) = {(x, y) | p_c(x) = q_c(y)}, has the universal property of the fiber product in PSh(C). For any cone (a, b) agreeing on Z, there exists a unique glued mechanism ⟨a, b⟩.

> **Theorem (Lawvere-Tierney Repair)**: The three standard axioms (j⊤ = ⊤, j(S ∧ T) = jS ∧ jT, jjS = jS) do not entail inflationarity S ≤ jS. A three-element chain provides a countermodel. Adding S ≤ jS as a fourth axiom makes j a closure operator.

> **Theorem (Contextuality Obstruction)**: Over a three-context poset, pairwise-consistent local causal data exist that admit no global model.

### 2.1.  证明思路

- 第一步（Intervention Classifier）：定义 sieve presheaf Ω 和 χ，验证 naturality（sieve closure under precomposition + functoriality of X）和 classification（identity in sieve ⟺ equality）
- 第二步（Sheaf Gluing）：在 presheaf topos 中，极限是 pointwise 的——直接构造 pullback presheaf 并验 universal property
- 第三步（LT 修复）：机器验证反模型（三元素链满足三公理但不满足膨胀性），补充第四条公理后验证 closure operator 性质
- 第四步（Contextuality）：将 pairwise-consistent 数据编码为 presheaf，验证无 global section

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Kripke-Joyal Clauses**: c ⊩ S ∧ T ⟺ (c ⊩ S) and (c ⊩ T); c ⊩ S ⇒ T ⟺ ∀f : d → c, (d ⊩ S·f) ⇒ (d ⊩ T·f); c ⊩ ∀_D φ(a) ⟺ ∀(f : d → c)(t ∈ D(d)), d ⊩_φ (a·f, t). — *全部在 Cubical Agda 中验证*

### 3.2.  关键定义

> **Definition**: A sieve on a context c is a downward-closed family of morphisms into c. Ω(c) is the set of all sieves on c, forming the subobject classifier.
> **动机**：Sieve 是 topos 中的"真值"——Ω 是 subobject classifier，干预即通过 χ 将 "X = x₀" 映射为 sieve。Sieve 的非布尔性（三值而非二值）是 intuitionistic logic 的核心。

> **Definition**: A Lawvere-Tierney topology j: Ω → Ω is a closure operator on the subobject classifier. The j-closed truth values are the modal truths of the internal logic.
> **动机**：在因果推断中，j 选择"稳定于局部化"的因果命题——j-stability 是 counterfactual transportability 的范畴论表述。

## 4.  💡 理解辅助

- **贯穿例子**：取 base category C = {0 → 1}（两对象一态射的 poset）。Ω(0) 有 2 个 sieve，Ω(1) 有 3 个 sieve——中间那个（仅包含 0→1，不包含 id₁）显示了 intuitionistic 而非 Boolean 特征。
- Sheaf gluing 的意义：两个本地因果机制在重叠区域一致时，存在唯一全局机制——这正是模块化因果发现的理论基础。
- Contextuality obstruction 的意义：在实际因果发现中，两两局部一致的因果模型可能无法拼接为全局模型——需要对因果模块进行全局一致性检查，而不能仅检查 pairwise 一致。
