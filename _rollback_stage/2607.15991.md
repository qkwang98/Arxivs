# Wide subcategories and brick-finiteness for length categories

keywords: [brick-finiteness, wide subcategories, torsion pairs, abelian length categories, brick Brauer-Thrall]
related_paper: "Asai — Bicompact torsion pairs"
one_liner_summary: "将有限维代数中 brick-finiteness 的特征推广到 Abel 长度范畴：brick-finite 等价于所有 torsion class 均为 widely generated 且所有 torsionfree class 均为 widely cogenerated。"

## 🎯 核心定位

- **解决的问题**：在一般 Abel 长度范畴（不必来自有限维代数）中，如何用 wide subcategory 的语言刻画 brick-finiteness？
- **大图景位置**：这是 brick-finiteness 理论的推广——从 artin 代数推广到更一般的长度范畴。也是 Asai 用 compact torsion pair 刻画 functorial finiteness 工作的延续。
- **主要贡献**：1) 给出 brick-finite 等价于所有 torsion class 都由 wide subcategory 生成的纯 lattice-theoretic 特征；2) 证明 First Brick Brauer-Thrall 猜想在此推广设定下成立；3) 引入 brick labels 在 wide intervals 上的交换关系。
- **关键先驱工作**：Ringel 的 semibricks 与 wide subcategories 之间的双射定理；Enomoto 的 torsionfree class 被其 simple 对象确定的结论；DIRRT（Demetrescu-Iyama-Reiten-Read-Thomas）对 tors(A) 的 lattice-theoretic 研究。
- **结果边界**：假设 A 仅有有限多同构类单对象。若单对象无限多，结论可能不成立。
- **开放问题**：在更一般的 exact category 中是否有类似的特征？brick labels 的交换关系是否对应 derived category 中 simple minded collection mutation 的 Abel 影子？
- **应用与推广**：该结果可用来在 more general exact categories 中研究 wide subcategories 的格结构，以及 torsion class 的 Hasse quiver。

## 📐 主要定理

> **Main Theorem**: Let A be an abelian length category with finitely many isomorphism classes of simple objects. Then A is brick-finite if and only if for every torsion pair (t, f), there exist wide subcategories W, W' such that t = T(W) and f = F(W').

> **Theorem (Brick Brauer-Thrall)**: A is brick-finite if and only if there exists N in N such that every brick in A has length less than N.

### 证明思路

- 第一步：利用 brick labels 在 wide intervals 上的交换关系——当 t ⊂ u 且 u ∩ t^{⊥₀} 为 wide 时，存在 t 的邻域与 u 的邻域在 tors(A) 的 Hasse quiver 中的双射对应
- 第二步：通过 brick labels 的逼近序列显式计算该对应，展示 brick-finiteness 与 wide generation/cogeneration 的等价性
- 第三步：Brick Brauer-Thrall 作为推论直接得出

## 🔑 关键组件

### 关键引理

> **Ringel's Theorem**: There is a bijection between semibricks and wide subcategories via S ↦ filt(S). — *引用自 Ringel*

> **Enomoto's Theorem**: Every torsionfree class is determined by its f-simple objects. — *引用自 Enomoto*

### 关键定义

> **Definition**: A brick is an object whose endomorphism ring is a division ring.
> **动机**：Brick 是表示论中最基本的"不可分解"构件——它们构成了模范畴的原子结构，brick-finiteness 控制着整个范畴的复杂度。

> **Definition**: A wide subcategory is a full subcategory closed under kernels, cokernels, and extensions.
> **动机**：Wide subcategories 是 Abel 范畴中最自然的"子范畴"概念——它们在 derived category 层面不对应三角子范畴，但对应 heart 结构中保持 Abel 性质的子范畴。

## 💡 理解辅助

- **贯穿例子**：论文没有给出单一贯穿例子，但可以取 A = mod-Λ（有限维代数上的有限生成模范畴）作为典型实例。在此情形下，定理退化为 Asai (2021) 的主要结果：Λ 是 tau-tilting finite 当且仅当每个 torsionfree class 被 wide subcategory 余生成。
- 在 artin 代数情形，更弱的条件（仅需每个 torsionfree class 被 wide subcategory 余生成）即可推出 brick-finiteness。
