# Nilpotent quiver varieties with multiplicities and symmetrisable crystals

keywords: [quiver varieties, multiplicities, symmetrisable Kac-Moody, Kashiwara crystal, Hecke correspondence]
related_paper: "2607.14634"
one_liner_summary: "为带重数的箭图构造 Nakajima 型幂零箭图簇，并利用 Hecke 对应将 Saito 的 Kashiwara 晶体几何构造从对称推广到可对称化 Kac-Moody 代数。"

## 1.  🎯 核心定位

- **解决的问题**：如何将 Nakajima 幂零箭图簇与 Saito 的晶体几何构造推广到可对称化（而非仅对称）Kac--Moody 代数。
- **大图景位置**：是 Geiss--Leclerc--Schröer 用带重数箭图实现可对称化 Kac--Moody 代数包络代数的几何表示工作的延续与晶体层面的补全。
- **主要贡献**：(1) 为带重数箭图构造幂零箭图簇（非约化群作用下的 GIT 商）；(2) 证明稳定轨迹不可约分支集上的晶体结构与 $B(C;\lambda)$ 同构；(3) 通过 Hecke 对应递归构造切片。
- **关键先驱工作**：Nakajima 箭图簇、Saito 晶体构造、Geiss--Leclerc--Schröer 带重数箭图工作、Lusztig 幂零锥。
- **结果边界**：要求箭图无环箭头；基域为任意特征代数闭域；构造依赖 E-filtered 表示与截断幂级数环。
- **开放问题**：能否像 Nakajima 对称情形那样，从簇的 Borel--Moore 同调直接构造表示本身（因缺乏恰当前推映射而困难）。
- **应用与推广**：为可对称化 Kac--Moody 代数的晶体提供几何实现，连接几何不变量理论与表示论。

## 2.  📐 主要定理

> **Theorem A (quotient construction)**: The quotient stack $[\Lambda_\bfr^\st/\GL_{\bfm,\bfr}]$ is an algebraic space. Moreover, for each irreducible component $Z\subset\Lambda_\bfr^\st$, there is an explicit dense open $\GL_{\bfm,\bfr}$-invariant subset $Z_{\mathrm{filt}}^\st\subset Z$ which admits a geometric quotient, such that the quotient map is a Zariski-locally trivial principal $\GL_{\bfm,\bfr}$-bundle.

> **Theorem B (crystal construction)**: There is an isomorphism of crystals $B_\bff^\st\simeq B(C;\lambda)$.

### 2.1.  证明思路

- 第一步：引入带重数箭图表示的新稳定性条件，构造稳定轨迹 $\Lambda_\bfr^\st$ 及其非约化群商。
- 第二步：对 rank 向量 $\bfr$ 归纳，利用 Hecke 对应 $\Lambda_{\bfr',\bfr}$ 递归构造相对商与切片。
- 第三步：在稳定轨迹不可约分支集上用 Hecke 算子赋予 Kashiwara 晶体结构，并证明与 $B(C;\lambda)$ 同构。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma (Hecke correspondence)**: 对不可约分支 $Z\subset\Lambda_\bfr$，存在 $\bfr'<\bfr$ 使 $p$ 在开集 $Z_{\mathrm{filt}}$ 上限制为主丛，从而可相对构造商。 — *[引用自本文]*

### 3.2.  关键定义

> **Definition (quiver with multiplicities)**: 箭图 $(Q,\bfm)$，其中 $\bfm=(m_i)$ 为顶点上的正整数重数；表示中 $M_i$ 为 $k_{m_i}$-模，箭头映射为 $k_{m_{ij}}$-线性。
> **动机**：重数用于编码可对称化 Cartan 矩阵的非平凡对称子，是处理非对称情形的关键结构。

## 4.  💡 理解辅助

- **贯穿例子**：带重数 framed 箭图 $(Q_\bff,\widehat{\bfm})$ 及其幂零锥 $\Lambda_\bfr$，对应最高权 $\lambda$ 的晶体构造。
