# Model structures arising from weak cotorsion pairs

keywords: [Model structures, Cotorsion pairs, Left weak cotorsion pairs, tau-tilting modules]
related_paper: "2607.15586"
one_liner_summary: "定义弱投射模型结构，证明其与满足温和条件的左弱余挠对之间的双射对应，并由此给出 support τ-倾斜模的同伦解释。"

## 1.  🎯 核心定位

- **解决的问题**：support τ-倾斜模诱导的是左弱余挠对（而非经典余挠对），本文研究其与模型结构的联系。
- **大图景位置**：将 Beligiannis--Reiten 对应从 hereditary 余挠对推广到左弱余挠对，是 τ-倾斜理论视角的推广。
- **主要贡献**：(1) 定义弱投射模型结构并建立其与左弱余挠对的双射对应；(2) 证明任意 support τ-倾斜模诱导模型结构；(3) 建立 support τ-倾斜模与一类模型结构的双射。
- **关键先驱工作**：Quillen 模型范畴、Hovey 双余挠对对应、Beligiannis--Reiten 投射模型结构对应、τ-倾斜理论（Adachi--Iyama--Reiten）。
- **结果边界**：对应要求左弱余挠对具有逆变有限核并满足温和条件；结论在 Abel 范畴中建立。
- **开放问题**：能否将弱模型结构进一步推广到 exact/extriangulated 范畴？
- **应用与推广**：为 τ-倾斜模提供同伦论解释，连接表示论与同调代数。

## 2.  📐 主要定理

> **Theorem 1.2**: Let $\mathcal{A}$ be an abelian category. There is a bijective correspondence between weak projective model structures on $\mathcal{A}$, and $lw$-cotorsion pairs in $\mathcal{A}$ with contravariantly finite core which satisfies some mild conditions.

> **Theorem 4.5**: For an Artin algebra $\Lambda$, there is a bijective correspondence between support $\tau$-tilting modules and model structures satisfying: (i) all modules in $\modd\text{-}\Lambda$ are fibrant; (ii) trivial fibrations coincide with epics with trivially fibrant kernel; (iii) the subcategory of trivially fibrant objects is closed under factor modules.

### 2.1.  证明思路

- 第一步：弱化 Beligiannis--Reiten 的投射模型结构定义，得到弱投射模型结构。
- 第二步：验证弱投射模型结构与左弱余挠对之间的构造互逆。
- 第三步：将 support τ-倾斜模诱导的左弱余挠对代入，得到与模型结构的双射。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma 2.2**: 余挠对 $(\mathcal{X},\mathcal{Y})$ 为 hereditary 当且仅当 $\mathcal{X}$ 对满射核封闭（或 $\mathcal{Y}$ 对单射余核封闭）。 — *[引用自 S]*

### 3.2.  关键定义

> **Definition 2.1 (cotorsion pair)**: 对 $(\mathcal{X},\mathcal{Y})$ 满足：$\mathcal{X},\mathcal{Y}$ 对直和项封闭；$\Ext^1(\mathcal{X},\mathcal{Y})=0$；每个对象有逼近短正合列。
> **动机**：余挠对是 Abel 范畴上模型结构的同调代数对应物，比模型结构更易处理。

## 4.  💡 理解辅助

- **贯穿例子**：Artin 代数 $\Lambda$ 上的 support τ-倾斜模，及其诱导的左弱余挠对。
