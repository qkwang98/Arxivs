# Space of norms on locally algebraic representations

keywords: [locally algebraic representation, non-Archimedean norm, Goldman--Iwahori metric, Bruhat--Tits building, invariant norm]
related_paper: "2607.15406"
one_liner_summary: "将局部代数表示上非阿基米德范数的集合刻画为有界投射极限，并给出 G-不变范数存在性与轨道有界性的等价判据。"

## 1.  🎯 核心定位

- **解决的问题**：在局部代数表示 $V=\pi_{\mathrm{sm}}\otimes_E\sigma_{\mathrm{alg}}$ 上，研究非阿基米德范数空间的结构，以及 $G$-不变范数何时存在。
- **大图景位置**：把 Breuil--Schneider 猜想等算术问题背后的一个纯几何事实分离出来，推广了 Goldman--Iwahori 在有限维情形引入的度量。
- **主要贡献**：(1) 证明有限距离分量 $\Norm_{\alpha_0}(V)$ 是扩展 Bruhat--Tits 建筑的有界投射极限；(2) 给出 $G$-轨道有界 $\iff$ 存在 $G$-不变范数 的等价性；(3) 给出不变范数存在的积分群代数与 type-Hecke 条件。
- **关键先驱工作**：Goldman--Iwahori 度量（有限维）、Haettel 的注入几何、Bruhat--Tits 建筑理论。
- **结果边界**：度量 $\dinf$ 是 $\ell^\infty$ 型而非 CAT(0) 度量，一般不具有 CAT(0) 性质；结论依赖 $V$ 的局部代数分解结构。
- **开放问题**：如何由 Jacquet 指数或 Hecke 特征值的不等式构造出整体一致有界的轨道（与 Breuil--Schneider 猜想的整性问题相关）。
- **应用与推广**：为局部代数表示上构造 $G$-不变范数提供了几何判据，可用于 p-adic 表示论中整性问题的研究。

## 2.  📐 主要定理

> **Theorem (intro)**: Fix a norm $\alpha_0$ on $V$. The finite-distance component $\Norm_{\alpha_0}(V)$ contains a $G$-invariant norm if and only if the orbit $G\alpha_0$ is bounded for the Goldman--Iwahori metric.

### 2.1.  证明思路

- 第一步：若轨道有界，则 $\alpha_G(v)=\sup_{g\in G}\alpha_0(g^{-1}v)$ 给出有限、非退化、$G$-不变的等价范数。
- 第二步：利用有限维穷竭 $V=\bigcup_K V_K$ 将范数空间识别为建筑的有界投射极限。
- 第三步：由度量 $\dinf$ 的均匀收敛拓扑得出轨道有界与不变范数存在等价。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma (Reconstruction from algebraic levels)**: 若对每个紧开子群 $K$ 给定 $V_K$ 上的范数 $\alpha_K$ 且限制相容，则唯一延拓为 $V$ 上的范数。 — *[新证]*

### 3.2.  关键定义

> **Definition (finite-distance component)**: $\Norm_{\alpha_0}(V)=\{\alpha:\dinf(\alpha,\alpha_0)<\infty\}$，其上 $\dinf$ 为真正度量。
> **动机**：分离出与参考范数有限距离的范数，构成可研究的度量空间分量，是处理有界轨道的正确对象。

## 4.  💡 理解辅助

- **贯穿例子**：对 $G=\GL_n(F)$ 取 $V=\operatorname{BS}(r)=\pi_{\mathrm{gen}}(r)\otimes_E\pi_{\mathrm{alg}}(r)$ 的具体局部代数表示。
