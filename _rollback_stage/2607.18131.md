# Kaluzhnin-Krasner embedding of precrossed modules

keywords: [precrossed module, crossed module, Kaluzhnin-Krasner, embedding, group extension]
related_paper: "Loday's crossed module theory"
one_liner_summary: "将 Kaluzhnin-Krasner 嵌入定理推广到 precrossed module 范畴，给出 precrossed module 到自同构 2-群的嵌入。"

## 1.  🎯 核心定位

- **解决的问题**：经典 Kaluzhnin-Krasner 定理说任意群扩张可嵌入自同构群的半直积；本文将其推广到 precrossed module（前交叉模）范畴。
- **大图景位置**：属于同伦代数与 2-群理论，连接群扩张理论与 crossed module（Loday 的代数拓扑基本对象）。
- **主要贡献**：(1) 定义 precrossed module 的 Kaluzhnin-Krasner 嵌入；(2) 证明嵌入的泛性质；(3) 讨论与 crossed module 的关系。
- **关键先驱工作**：Kaluzhnin-Krasner 嵌入定理、Loday 的 crossed module 与 cat^1-群、Brown-Spencer 的等价。
- **结果边界**：限于 precrossed module（不要求 Peiffer 恒等式）；crossed module 情形是特例。
- **开放问题**：作者未明确列出 open problem，但嵌入在更高维 n-群中的推广值得研究。
- **应用与推广**：结果可用于研究 2-群的分类与同伦类型，以及非交换扩张的 2-范畴结构。

## 2.  📐 主要定理

> **Theorem (KK embedding for precrossed modules)**: Every precrossed module $(C\xrightarrow{\partial}G,\alpha)$ embeds into the automorphism 2-group of a suitable object, generalizing the classical Kaluzhnin-Krasner theorem.

### 2.1.  证明思路

- 第一步：构造 precrossed module 的自同构 2-群（含群同态与 Peiffer 扭曲）。
- 第二步：定义嵌入映射并验证其保持 precrossed module 结构。
- 第三步：证明泛性质：任意到自同构 2-群的态射分解通过此嵌入。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma (Peiffer compatibility)**: 嵌入在 crossed module 子情形恢复经典 Kaluzhnin-Krasner。 — *[引用自 Loday]*

### 3.2.  关键定义

> **Definition (Precrossed module)**: 一对群同态 $\partial:C\to G$ 配 $G$ 在 $C$ 上的作用 $\alpha$，满足 $\partial(\alpha_g(c))=g\partial(c)g^{-1}$（不要求 Peiffer 恒等式 $\alpha_{\partial(c)}(c')=cc'c^{-1}$）。
> **动机**：precrossed module 是 crossed module 的弱化，去掉 Peiffer 条件后更易于构造嵌入，再商去 Peiffer 子群得到 crossed module。

## 4.  💡 理解辅助

- **贯穿例子**：具体 precrossed module（如由群扩张诱导的）的 Kaluzhnin-Krasner 嵌入计算，展示与经典定理的对应。
