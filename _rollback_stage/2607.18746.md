# Polynomiality of Stretched Schubert Structure Constants and Key Coefficients

## 🎯 核心定位

- **解决的问题**：研究 Schubert 多项式的结构常数和 Key 多项式（Demazure 原子）的系数在所谓的"拉伸"操作下的行为。拉伸指将排列/权同时乘以一个缩放因子 t。
- **大图景位置**：Schubert 多项式是 Schubert 微积分和几何表示论的核心对象。其结构常数的多项式性是经典 Littlewood-Richardson 系数的拉伸多项式性的推广（Knutson-Tao 的蜂巢模型）。
- **主要贡献**：① 证明拉伸 Schubert 结构常数作为拉伸因子 t 的拟多项式（实际上是多项式）；② 对 Key 多项式系数建立类似的多项式性结果。
- **关键先驱工作**：Schubert 多项式的理论（Lascoux-Schützenberger）、Knutson-Tao 的蜂巢模型与 LR 系数的多项式性、Key 多项式与 Demazure 特征标。
- **结果边界**：结果限于 A 型（即 GL_n 的 Schubert 微积分）。
- **开放问题**：其他 Lie 类型的推广、拉伸系数的正性。
- **应用与推广**：为 Schubert 微积分中结构常数的渐近分析提供工具；可能与表示稳定性和同调稳定性的现代研究有关。

## 📐 主要定理

> **Theorem (Polynomiality of stretched Schubert constants)**: For permutations w,u,v in S_n, the stretched Schubert structure constant c_{t·w, t·u}^{t·v} is a polynomial in the stretching parameter t for t sufficiently large. The same holds for stretched Key polynomial coefficients.

### 证明思路

- 第一步：将 Schubert 多项式的结构常数用多面体几何（Gelfand-Tsetlin 模式、蜂巢）表示。
- 第二步：证明拉伸操作对应多面体的扩张，使整数点的计数成为 Ehrhart 拟多项式。
- 第三步：通过对称函数理论验证该拟多项式退化为真正的多项式。

## 🔑 关键组件

### 关键引理

> **Polytope description of structure constants**: Schubert 结构常数可表示为某些有理凸多面体的整数点计数。 — *引用自组合几何方法*

### 关键定义

> **Stretched coefficient c_{t·w, t·u}^{t·v}**: 将排列 w 替换为 t*w（其中 t 是正整数的缩放），并考察对应的结构常数。
> **动机**：拉伸在表示论中有自然对应——将最高权乘以 t 相当于取表示的第 t 次 Cartan 幂或 Frobenius 幂。
