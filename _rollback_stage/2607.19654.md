# Derived representation schemes with arbitrary coefficients and associative smoothness

keywords: [derived representation scheme, representation homology, associative smoothness, Kontsevich-Rosenberg principle, finite-dimensional coefficients]
related_paper: "Berest-Felder-Ramadoss (BFR14) 关于 representation homology 的开创性工作"
one_liner_summary: "将表示同调从矩阵系数推广到任意有限维代数系数，证明形式光滑性蕴含高阶消失，且非矩阵系数可检测经典矩阵系数无法捕捉的非光滑性。"

## 🎯 核心定位

- **解决的问题**：经典的表示同调（representation homology）使用矩阵系数研究结合代数的形式光滑性，但矩阵系数的消失定理的逆命题不成立（存在非光滑代数其表示同调为零）。本文用任意有限维代数替换矩阵代数，研究是否可获得更强的光滑性检测工具。
- **大图景位置**：这是导出 Kontsevich-Rosenberg 原理在系数选取上的根本性推进。原原理断言代数的几何性质反映在表示概形的几何中；本文揭示了系数选择本身就是一个重要的自由度。
- **主要贡献**：(1) 有限生成形式光滑代数的表示同调对任意有限维系数在正次消失；(2) 给出新证明（用余切复形和 Neeman 定理替代 Ciocan-Fontanine-Kapranov 比较定理）；(3) 量子平面和 Jordan 平面的非矩阵系数表示同调非零，证明新框架严格更强；(4) 有限维代数情形，任意系数表示同调消失等价于形式光滑性。
- **关键先驱工作**：BFR14（表示同调基础）、BK13、Kontsevich-Rosenberg（非交换几何哲学）、Ciocan-Fontanine-Kapranov（DG 概形比较定理）。
- **结果边界**：需要有限生成和 Noether 条件；Weyl 代数等"表示太少"的代数不适用。
- **开放问题**：对于有限生成 Noetherian 代数，"任意系数表示同调消失 ⇔ 形式光滑"是否普遍成立？（作为猜想明确提出）
- **应用与推广**：为非交换代数几何中的光滑性提供新的同调判别法；可与 Van den Bergh 的双模方法互补。

## 📐 主要定理

> **Theorem**: Let M be a finite-dimensional k-algebra. If A is a finitely generated formally smooth k-algebra, then HR_i(A, M) vanishes for all i > 0.

> **Proposition**: A finite-dimensional k-algebra A over an algebraically closed field k is formally smooth if and only if HR_i(A, M) vanishes for all i > 0 and for every finite-dimensional algebra M.

### 证明思路

- 第一步：用余切复形论证替代 BFR14 中依赖局部有限维半自由消解的 Ciocan-Fontanine-Kapranov 方法。
- 第二步：利用 Neeman 的 fiberwise detection 定理进行局部-整体过渡。
- 第三步：计算量子平面 k[x,y]_q 和 Jordan 平面 k⟨x,y⟩/(yx-xy-x²) 对特定有限维代数 (n₃)_+（3 维幂零代数）的表示同调 H₁，得到非零结果。

## 🔑 关键组件

### 关键引理

> 余代数 C 对应的表示概形函子 (-)_C 是 Quillen 对，其导出函子给出表示同调。

### 关键定义

> **Definition**: 余代数系数的表示同调 HR_*(A,C) = H_*(𝕃(A)_C)。当 C = M* 为有限维代数 M 的对偶余代数时，记为 HR_*(A,M)。
> **动机**：矩阵系数 End(V) 只是有限维代数的一个特例；更一般的代数 M 可捕捉更多表示论信息。

## 💡 理解辅助

- **贯穿例子**：量子平面（q 非单位根）和 Jordan 平面在经典矩阵系数下表示同调为零，但对 (n₃)_+ 系数 HR₁ 非零，直观展示了新框架的检测能力。
