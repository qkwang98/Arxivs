# Higher cluster tilting objects in locally finite triangulated categories

keywords: [higher cluster tilting, triangulated category, d-cluster tilting, locally finite, derived category]
related_paper: "Iyama 关于 higher Auslander-Reiten theory 的工作"
one_liner_summary: "在局部有限三角范畴中研究 higher cluster tilting 对象的结构，建立其与经典 cluster tilting 理论的联系，推广了 Iyama 的 higher Auslander-Reiten 理论到更一般的范畴框架。"

## 🎯 核心定位

- **解决的问题**：在局部有限（locally finite）三角范畴中系统研究 higher cluster tilting 对象（d-cluster tilting）的存在性、结构和 mutation 性质。
- **大图景位置**：Iyama 的 higher Auslander-Reiten 理论最初在有限维代数的模范畴中建立；本文将其推广到局部有限三角范畴这一更广阔、更适合∞-范畴化处理的框架中，连接了 cluster tilting 理论与三角范畴的公理化研究。
- **主要贡献**：(1) 定义局部有限三角范畴中的 higher cluster tilting 对象；(2) 证明其基本性质（如 rigid 性、mutation 的存在性）；(3) 建立与经典 d-cluster tilting 子范畴的关系。
- **关键先驱工作**：Iyama 的 higher Auslander-Reiten 理论、Keller-Reiten 的 cluster category 和 cluster tilting、Neeman 的三角范畴公理化。
- **结果边界**：要求三角范畴满足局部有限性条件；对无穷维或非 Krull-Schmidt 范畴可能不适用。
- **开放问题**：在何种条件下可保证 d-cluster tilting 对象的存在性？是否有类似于 Amiot 构造的 cluster category 的万有构造？
- **应用与推广**：可应用于导出范畴的 silting 理论、非交换代数几何中的 tilting 理论。

## 📐 主要定理

> 本文的核心定理刻画了局部有限三角范畴中 d-cluster tilting 对象与其 endomorphism algebra 的 derived equivalence 之间的关系，以及 mutation 操作在保持 d-cluster tilting 性质下的封闭性。

### 证明思路

- 第一步：从三角范畴的公理出发，利用局部有限条件确保对象的直和分解性质。
- 第二步：通过 Ext 和 Hom 群的正交条件刻画 d-cluster tilting 对象的 rigid 性。
- 第三步：利用 mutation 构造新的 d-cluster tilting 对象，验证其保持所需性质。

## 🔑 关键组件

### 关键引理

> 局部有限三角范畴中的 d-cluster tilting 对象诱导出与其自同态代数之间的 derived equivalence。

### 关键定义

> **Definition**: d-cluster tilting 对象是满足双正交条件 functorially finite 的子范畴或其生成元；局部有限性确保 Hom 和 Ext 群满足有限维条件。
> **动机**：经典的 1-cluster tilting 已在 cluster 代数中取得巨大成功，higher 版本对应于高维 Auslander-Reiten 理论，是研究高维表示论的基石。

## 💡 理解辅助

- **贯穿例子**：有限维代数的导出有界范畴 D^b(mod A) 中的 n-cluster tilting 子范畴，以及对应的 n-representation finite 代数。
