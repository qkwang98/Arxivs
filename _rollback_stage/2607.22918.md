# K-theory of Weighted Blowups
keywords: algebraic K-theory, weighted blowup, algebraic stack, equivariant K-theory, Gysin morphism, Keel's formula, Lambda polynomial
related_paper: Keel, "Intersection theory of moduli space of stable N-pointed curves of genus zero"
one_liner_summary: 建立光滑 Artin stack 上加权 blowup 的 K-理论环的精确描述公式，推广经典的 Keel 公式，并应用于 M_{1,2} 的 K-理论计算。

## 🎯核心定位
1. **核心问题**：对光滑有限型 Artin stack 上正则加权的加权 blowup \widetilde{Y} → Y，建立 K-理论环 K(\widetilde{Y}) 的精确结构定理。
2. **与其他文献的关系**：推广 Keel 对经典 blowup 的 K-理论公式到加权情形；基于 Quek-Rydh 的加权 blowup 一般理论；利用 Thomason 的等变 K-理论框架。
3. **主要贡献**：Theorem 1：K(\widetilde{Y}) 的显式表现（由 K(Y)[t^{±1}] 和 K(X) 的 push-pull 关系生成）；推广 Keel 公式到加权 blowup；计算 M_{1,2} 的 K-理论；计算 blowup 态射的切复形的 Lambda 多项式。
4. **技术难点**：加权 blowup 的例外除子不是基变换（pullback），需额外处理；加权法锥的扭曲加权向量丛结构需要拆分原理；Gysin 态射在等变 K-理论中的构造。
5. **方法**：G-等变 K-理论 + splitting principle；加权 blowup 局部模型（A^d 中原点的加权 blowup）→ 变形到加权法锥 → 正合序列 → 整体拼接；利用等变 K-理论中 homotopy invariance 的加权扭曲向量丛推广。
6. **局限性**：要求 stack 光滑且满足 resolution property；仅计算了 K_0，未及高阶 K-群。
7. **可扩展方向**：高阶 K-群和 motivic 层面；与 derived algebraic geometry 中的加权 blowup 衔接；加权 blowup 的 Chow 环公式。

## 📐主要定理
**Theorem 1 (主定理)**：设 i: X↪Y 为光滑有限型 Artin stack 的正则闭嵌入（满足 resolution property 且有仿射稳定化子），w 为权重。则加权 blowup \widetilde{Y} → Y 的 K-理论环由以下正合序列给出：
$$\Kring(X)[t^{±1}] \to \Kring(Y)[t^{±1}] \oplus \Kring(X) \to \Kring(\widetilde{Y}) \to 0$$
其中第一个映射由特定的 push-pull 公式定义。

**Theorem (Lambda 多项式)**：加权 blowup 的切复形 T_{\widetilde{Y}/Y} 的 Lambda 多项式由下式显式给出：
$$\lambda_z(T_{\widetilde{Y}/Y}) = q\left(\left(\frac{(1+zt^{-1})Q_z(t)}{(1+z)Q_z(1)}-1\right)\frac{-1}{1-t}, 1\right)$$
其中 Q_z(t) 为加权法丛在 X 上的 Lambda 多项式。

**Corollary (Keel 公式推广)**：当所有权重为 1 时，该公式退化为 Keel 的经典公式。

**Application**：计算 M_{1,2}（亏格 1 带两个标记点的稳定曲线的模空间）的 K-理论环。

## 🔑关键组件
- **加权 blowup**：经典 blowup 的推广，对每个法坐标赋予不同权重 w_i，例外除子为加权射影 stack 丛 P(w_1,...,w_d)。
- **等变 K-理论**：K_G(Y) 为 G-等变局部自由层的 Grothendieck 环，同构于商 stack [Y/G] 的 K-理论。
- **变形到加权法锥**：D_{X_•}Y → A^1 的平坦族，特 fiber 为加权法锥 C_{I_•}，一般 fiber 为 Y，blowup 为其 G_m-商。
- **加权法丛 N_{X/Y}**：由加权法锥的零截面的法丛定义，是 X 上的分次向量丛，不同于经典情形的 I/I^2。
- **Gysin 态射**：等变 K-理论中的 refined Gysin pullback，用于处理 blowup 中 push-pull 关系的精确定义。
- **Splitting principle**：利用极大环面的表示论将等变 K-理论归约为环面的 K-理论（Laurent 多项式环）。

## 💡理解辅助
1. **加权 vs 经典 blowup**：经典 blowup 的例外除子为 P^{d-1} 丛；加权 blowup 的例外除子为加权射影 stack 丛 P(w_1,...,w_d)，对应不同的 G_m-作用。因此例外除子的 K-理论不同，导致整体公式的差异。
2. **局部-整体拼接**：A^d 中原点的加权 blowup 给出局部模型 → 光滑覆盖 × 平坦下降将局部计算拼接为整体公式 → Gysin 态射处理交叉项。
3. **Lambda 多项式的含义**：λ_z(E) = Σ [Λ^i E] z^i 编码了向量丛 E 的外幂类，是 K-理论中的"特征类"类比。
4. **M_{1,2} 的应用**：该模空间的边界由加权 blowup 构造给出（标记点相碰的奇点），故可用主定理计算其 K-理论。
