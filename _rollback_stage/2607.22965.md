# Rankin-Selberg duality via gluing
keywords: Rankin-Selberg duality, relative Langlands duality, moment map, hyperkähler quotient, Bezoutian matrix
related_paper: Ben-Zvi--Sakellaridis--Venkatesh, "Relative Langlands Duality"
one_liner_summary: 利用 Ginzburg gluing 构造证明超球面 (GL_n×GL_m)-簇 T^*(Hom(C^m,C^n)) 的相对 Langlands 对偶同构于三角形部分 M_{(m,n)}。

## 1.  🎯核心定位
1. **核心问题**：构造并证明超球面 (GL_n×GL_m)-簇 T^*(Hom(C^m,C^n)) 的相对 Langlands 对偶空间的显式同构。
2. **与其他文献的关系**：基于 Ben-Zvi--Sakellaridis--Venkatesh 的相对 Langlands 对偶纲领，利用 Ginzburg 的 gluing 技术给出一个具体的对偶实现。
3. **主要贡献**：Theorem 1.1 给出 $$\mathfrak{gl}_n \times \mathfrak{gl}_m$$ 的 hypertoric 簇版本的对偶同构；构造 Bezoutian 矩阵 K_{p,q}, L_{p,q} 及关键恒等式；定义三角形部分 M_{(m,n)} 并证明 $$\operatorname{spec}(A_\sigma) \cong M_{(m,n)}$$；m=n 时恢复 Rankin-Selberg 情形同构于 T^*(GL_n×C^n) 的退化。
4. **技术难点**：Ginzburg gluing 在 hypertoric 设置下的正确实现；Bezoutian 矩阵的构造及其二次恒等式。
5. **方法**：利用 Ginzburg gluing 将对偶空间拼合为三角形部分；通过 Bezoutian 矩阵建立等变开嵌入 $$\Phi_1, \Phi_2 = \Phi_1 \circ \sigma_\rho$$；利用矩映射的 Hamiltonian 约化构造对合同构。
6. **局限性**：目前仅处理 type A 的特殊情形；一般约化群的推广尚待开发。
7. **可扩展方向**：其他经典群的类似对偶；与 Coulomb branch 构造的联系；算术情形（如函数域上的迹公式）中的应用。

## 2.  📐主要定理
**Theorem 1.1**：超球面 (GL_n×GL_m)-簇 T^*(Hom(C^m,C^n)) 的相对 Langlands 对偶同构于三角形部分 M_{(m,n)}，其中 M_{(m,n)} 由 Bezoutian 矩阵关系定义的仿射簇闭包给出。

**Proposition main**：存在从 Wh_{G^∨} 到 M_1, M_2 的 G^∨-等变开嵌入 $$\Phi_1, \Phi_2 = \Phi_1 \circ \sigma_\rho$$，其中 $$\sigma_\rho$$ 是附加的反辛对合。

**Corollary**：$$\operatorname{spec}(A_\sigma) \cong M_{(m,n)}$$，即对偶代数 A_σ 的谱同构于三角形部分。

**m=n 的特殊情形**：此时对偶空间退化为 Rankin-Selberg 情形，同构于 T^*(GL_n×C^n) 的某种退化。

## 3.  🔑关键组件
- **相对 Langlands 对偶**：将两个 Hamiltonian G-空间 X 和 X^∨ 配对，使得它们的分支对应的代数簇在谱层面互相对偶。
- **Hypertoric 簇 T^*(Hom(C^m,C^n))**：余切丛的矩映射零纤维的 Hamiltonian 约化，自然地承载 (GL_n×GL_m) 作用。
- **Bezoutian 矩阵**：由多项式系数构造的矩阵 K_{p,q}, L_{p,q}，满足重要二次恒等式，用于参数化对偶空间。
- **三角形部分 M_{(m,n)}**：由 Bezoutian 关系定义的仿射簇，是相对 Langlands 对偶的目标空间。
- **Ginzburg gluing**：将两个 Hamiltonian 空间沿共同的分支拼合的技术，确保辛结构与群作用的相容性。
- **Wh_{G^∨}**：Whittaker 约化空间，是构造对偶嵌入的起点。

## 4.  💡理解辅助
1. **直观**：相对 Langlands 对偶类似于傅里叶变换——将一侧的 Hamiltonian G-空间（如余切丛）变换为另一侧的"对偶"空间，保持群作用的谱信息。
2. **Bezoutian 矩阵的作用**：类似于经典结式理论中 Bezout 矩阵用于描述两个多项式的结式，这里的 Bezoutian 矩阵编码了矩映射关系的代数约束。
3. **三角形部分的命名**：M_{(m,n)} 的结构由两个 Bezoutian 矩阵关系确定，其代数结构在参数化上呈三角形式。
4. **Rankin-Selberg 情形**：当 m=n 时，对偶空间对应经典的 Rankin-Selberg 积分表示，该对偶在 L-函数理论中有重要应用。
