# The factorization system of a radical on a homological category
keywords: radical, homological category, factorization system, torsion-free class, reflective subcategory, pre-radical
related_paper: Grandis, "Homological Algebra: The interplay of homology with distributive lattices and orthodox semigroups"
one_liner_summary: 在同调范畴上对任意 radical r 构造其无挠对象类的全反射子范畴，并通过迁移算子将 (正则 epi, 单同态) 分解系统转化为 (E, M)-分解系统。

## 1.  🎯核心定位
1. **核心问题**：在同调范畴（homological category）上，给定任意 radical r，如何构造一个与其无挠对象类关联的 (E, M)-分解系统。
2. **与其他文献的关系**：基于 Grandis 的同调范畴框架及 Janelidze-Márki-Tholen 的 radical 与非交换环上的挠理论工作；推广经典环论中 radical 与挠理论的关系到纯粹范畴论层面。
3. **主要贡献**：对任意 radical r，其无挠对象 τ_r 形成全反射子范畴，且包含函子 τ_r → C 有左伴随；通过迁移算子将 (正则 epi, mono) 分解系统转化为 (E, M) 分解系统，其中 E 为反射单元类，M 为无挠嵌入类。
4. **技术难点**：radical r 需满足 r ≅ r ∘ r 的条件以生成好性质的反射子范畴；迁移算子保持正交性的验证；同调范畴中短正合列与 radical 的兼容性。
5. **方法**：同调范畴的公理体系（pointed, regular, protomodular）；radical 函子 r: C → C 及其幂等性；反射子范畴与分解系统的对应（Cassidy-Hébert-Kelly）。
6. **局限性**：假设同调范畴满足某些额外条件（如正则 epi 覆盖的稳定性）；非 pointed 情形待推广。
7. **可扩展方向**：与 torsion theory 在一般范畴中的统一；导出范畴中 radical 的导出函子行为。

## 2.  📐主要定理
**Theorem (反射子范畴)**：对同调范畴 C 上的任意 radical r，其无挠对象全子范畴 r-TF 为 C 的全反射子范畴，包含函子有左伴随。

**Theorem (分解系统)**：(E, M) 构成 C 上的 (正交) 分解系统，其中
- E = {f | r(ker f) 为同构}（反射单元态射类）
- M = {f | ker f ∈ r-TF}（无挠嵌入类）

**Theorem (迁移)**：若 C 原具有 (正则 epi, mono) 分解系统，则通过迁移算子可将其转化为上述 (E, M) 分解系统，且两系统之间的变换保持正交性。

## 3.  🔑关键组件
- **同调范畴 (homological category)**：pointed、正则 (regular) 且 protomodular 的范畴，是半阿贝尔范畴和阿贝尔范畴的自然推广。
- **Radical r: C → C**：满足 r(id_C) = id_C 且对任意 f: A→B 有方块交换的函子，通常要求 r^2 ≅ r（幂等）。
- **r-无挠对象 (r-torsion-free)**：满足 r(X) = 0 的对象。
- **反射子范畴 (reflective subcategory)**：全子范畴满足包含函子有左伴随。
- **反射单元**：伴随的单位 η_X: X → R(X) 属于 E 类，是分解中 E-部分的关键。

## 4.  💡理解辅助
1. **环论类比**：环 R 上的 radical（如 Jacobson radical, nil radical）给出模范畴的两个正交类——挠模（被 radical 消灭）和无挠模（被 radical 零化）。本文将此推广到任意同调范畴。
2. **分解系统的直观**：每个态射 f: X → Y 被分解为 X → R(X)（"模去 radical"的商）→ Y（无挠嵌入）。这类似于群论中模去根子群的商同态。
3. **迁移算子的作用**：原分解系统 (正则 epi, mono) 给出标准分解，radical r 通过"提取无挠部分"将其扭曲为新的分解，两系统可相互转化。
