# Guarded Realization Semantics: Occurrence-Sensitive Certificates and Behavior-Dependent Lower Bounds
keywords: guarded recursion, categorical semantics, realizability, topos, certificate, lower bound, occurrence sensitivity
related_paper: Birkedal--Møgelberg--Schwinghammer--Støvring, "First steps in synthetic guarded domain theory"
one_liner_summary: 在 guarded 递归的范畴语义中引入 occurrence-sensitive 证书系统与行为相关下界，建立 Err(r) 的 guard 计数的代数结构，给出非平凡的不等式链。

## 1.  🎯核心定位
1. **核心问题**：如何在 guarded 递归的范畴语义中定义"错误对象的护符计数"，并基于此推导行为相关的复杂度下界。
2. **与其他文献的关系**：基于 guarded domain theory (Birkedal 等) 和 realizability topos 传统；将传统 recursion-theoretic 的复杂度概念提升到范畴语义层面。
3. **主要贡献**：引入错误对象 Err(r)（具有 r 重 guarded 结构）、上证书 (upper certificate) U(r) 和行为相关下界 Q；证明核心不等式 Q(O(Err(r))) ≤ A(Err(r)) ≤ U(r)，建立了 guard 计数与计算复杂度之间的范畴对应。
4. **技术难点**：将组合的护符计数抽象为体现 (occurrence) 敏感的范畴构造；上证书与下界的精确定义需要结合 topos 的内部逻辑。
5. **方法**：guarded recursion 的 topos 模型；occurrence 敏感的类型系统；realizability 解释中证书结构的代数化。
6. **局限性**：当前仅处理有限阶的 guarded 结构，无限阶的极限行为未讨论。
7. **可扩展方向**：多参数 guard 的交互；与时钟类型系统的统一；下界紧致性分析。

## 2.  📐主要定理
**Core Inequality**：对任意带有 r 重 guarded 结构的对象 Err(r)，存在由 occurrence-sensitive 证书系统定义的函数 Q、A、U 使得

$$Q(O(\mathrm{Err}(r))) \le A(\mathrm{Err}(r)) \le U(r).$$

其中 O(Err(r)) 为 Err(r) 的 observable behavior，U(r) 为与 guard 计数直接相关的上证书，A 为实际行为度量。

**Theorem**：U(r) 具有递归结构 U(0)=0，U(r+1)=▷ U(r) 在合适的 guarded 范畴中。

**Theorem**：Q 的构造是 occurrence-sensitive 的：对 Type-1 和 Type-2 的错误表现给出不同的下界证书。

## 3.  🔑关键组件
- **Guarded recursion**：通过 ▷ (later) 模态控制递归，保证 productivity。▷^r X 表示 r 步后才能访问的 X。
- **错误对象 Err(r)**：封装了 r 个 guard 保护的计算结果（或错误），是 complexity 分析的载体。
- **上证书 U(r)**：由 guard 结构直接给出的复杂度上界证书，具有组合代数结构。
- **发生敏感 (occurrence-sensitive) 证书**：证书不仅依赖于"是否发生错误"，还依赖于错误发生的具体模式（Type-1 vs Type-2）。
- **行为相关下界 Q**：与具体的计算行为绑定的下界，不同计算轨迹 (trace) 给出不同的 Q 值。

## 4.  💡理解辅助
1. **直观类比**：传统复杂度理论中"算法至少需要 n 步"是全局下界；occurrence-sensitive 证书类比于"若输入中出现模式 P，则至少需要 f(P) 步"。
2. **不等式链的含义**：Q ≤ A ≤ U 表示 observable behavior 决定的下界不超过实际成本，实际成本不超过理论容量上界——三者之间的 gap 即为对具体数据依赖的粒度度量。
3. **Err(r) 的结构**：类比于 monad 中封装了 r 层 ▷ 的延迟错误，r 越大表示"越晚暴露的错误"，对应的证书也越大。

## 5.  ✏️主动思考区
- 是否能将此不等式框架应用于具体编程语言（如 Haskell 的 guarded recursion 库）的静态复杂度分析？
- occurrence-sensitive 证书与 session type 中的 behavioral type 是否有共通的范畴结构？
