# Beyond the Adams Conjecture
keywords: [Adams conjecture, local theta correspondence, local Arthur packet, tempered representation, extended multi-segment]
related_paper: "Atobe, On the local Arthur packet conjecture for classical groups (2022)"
one_liner_summary: "确定 p-进辛群 tempered 表示经 theta 首次提升后所属局部 Arthur 包的数量，在七种情形中的六种给出递归计数公式，表明 Adams 猜想预测之外还有更多包。"


## 🎯 核心定位

- **研究对象**：$p$-进域上辛群 $G_n=\operatorname{Sp}_{2n}(F)$ 的 tempered 表示 $\pi$，经局部 theta 对应提升到偶正交群 $H_m^\pm=\operatorname{OO}_{2m}^\pm(F)$ 的表示 $\theta_{-m^{\uparrow,\alpha}(\pi)}^\uparrow(\pi)$ 在首个出现指数处的局部 Arthur 包计数。
- **问题意识**：Adams 猜想断言 theta 对应保持局部 Arthur 包（$\pi\in\Pi_\psi\Rightarrow\theta(\pi)\in\Pi_{\psi_\alpha}$）。已知此猜想在高 tower 处成立但低 tower 处可失败。问题是：在首个出现处，$\theta(\pi)$ 属于多少个不同的局部 Arthur 包？即确定 $|\Psi(\theta(\pi))|$。
- **主要结果**：
	1. **Theorem**：在七种情形中的六种确定了 $|\Psi(\theta_{-m^{\uparrow,\alpha}(\pi)}^\uparrow(\pi))|$ 的递归公式。
	2. **Applications**：对 supercuspidal $\pi$ 得 $|\Psi(\theta(\pi))|=3|\Psi(\pi)|$；对 generic $\pi$ 得 $|\Psi(\theta(\pi))|\in\{1,2,3\}$；对 unramified $\pi$ 得 $\in\{2,3\}$；对 anti-tempered $\pi$ 有递归公式。
	3. 第七种情形以猜想形式给出。
- **方法技术**：扩展 multisegment 参数化局部 Arthur 包（Atobe 理论），Liu-Lo-Hazeltine 的包交理论，Bakić-Hanzer 的 theta 对应算法，tempered 表示 $\Psi(\pi)$ 的递归计数公式（Hazeltine-Kumar-Tung 早期工作）。
- **核心创新**：将几何/表示论的 theta 对应问题完全转化为扩展 multisegment 的组合计数问题，并通过 block 分解给出递归公式。
- **理论定位**：位于局部 Langlands 纲领（Arthur 分类）与 theta 对应理论的核心交汇处，系统推进了 Adams 猜想"失效"程度的定量研究。
- **未解决的开放问题**：第七种情形的完整证明；对非 tempered 表示（特别是非 Arthur 型）的推广；$G_n$ 与 $H_m^\pm$ 之外的经典群配对。

## 📐 主要定理

**Theorem（主定理，六种情形的验证）**：对 tempered $\pi\in\Pi(G_n)$，在七种情形的六种中，$|\Psi(\theta_{-m^{\uparrow,\alpha}(\pi)}^\uparrow(\pi))|$ 由 $\Psi(\pi)$ 的 block 分解递归确定。具体递归公式取决于 theta 对应如何影响 extended multi-segment 的各个 block。

**Theorem（supercuspidal 推论）**：若 $\pi$ 是 supercuspidal，则 $|\Psi(\theta(\pi))|=3|\Psi(\pi)|$。

**Theorem（generic 推论）**：若 $\pi$ 是 generic，则 $|\Psi(\theta(\pi))|\in\{1,2,3\}$（而 $|\Psi(\pi)|=1$）。

**Theorem（unramified 推论）**：若 $\pi$ 是 unramified，则 $|\Psi(\theta(\pi))|\in\{2,3\}$（而 $|\Psi(\pi)|=1$）。

**Theorem（anti-tempered 推论）**：若 $\pi$ 是 anti-tempered，$|\Psi(\theta(\pi))|$ 由递归公式 $\sum_{k=0}^r\binom{r+k}{2k+1}$ 型（或类似）给出。

### 证明思路

1. **扩展 multi-segment 参数化**（§2-§3）：Atobe 理论将 $\operatorname{Sp}_{2n}(F)$ 的局部 Arthur 包参数化为满足特定组合条件的扩展 multi-segment。$\Psi(\pi)$ 对应满足固定"底 segment"条件的 multi-segment 集合。

2. **Tempered 计数公式**（HKT 早期结果，§4）：对 tempered $\pi$，其扩展 multi-segment 由多个 block 组成，$|\Psi(\pi)|$ 等于各 block "可容纳"的局部 Arthur 包数的乘积。各 block 的计数公式分两种类型给出。

3. **Theta 对应的组合翻译**（§5）：Bakić-Hanzer 算法将 theta 对应 $\theta_{-m^{\uparrow,\alpha}(\pi)}^\uparrow(\pi)$ 翻译为对底 segment 的特定组合操作。该操作仅影响部分 block，其余 block 不变。

4. **Block 交互分析**（§6-§7）：将 block 分解后，按 theta 对应影响 block 的方式划分为七种情形。对前六种情形，因 block 之间不会产生新的交互约束，可直接用 block 计数公式的乘积给出递归公式。

5. **第七种情形的困难**：涉及某些 block 经 theta 对应后在新的 multi-segment 中可能产生跨 block 约束（commutativity 条件），使得不能简单乘积，需附加的组合分析（以猜想形式给出）。

## 🔑 关键组件

### 关键引理

> **局部 Arthur 参数 $\psi:W_F\times\operatorname{SL}_2(\mathbb{C})\times\operatorname{SL}_2(\mathbb{C})\to{}^LG$**：由 Deligne $\operatorname{SL}_2$ 因子、Arthur $\operatorname{SL}_2$ 因子和 Weil 群表示组成。
- **$\theta$-relevant pair**：Arthur 参数对 $(\psi,\psi')$ 满足 $\psi'=\psi_\alpha=(\chi_W\chi_V^{-1}\otimes\psi)\oplus\chi_W\otimes S_1\otimes S_\alpha$。
- **Block 分解**：扩展 multi-segment 按不可再分解为更小 multi-segment 直和的极大子集进行分解，各 block 在 theta 对应下独立演化。
- **Adams 猜想的精确表述**：若 $\pi\in\Pi_\psi$ 且 $\theta_{-\alpha}^\pm(\pi)\neq 0$，则 $\theta_{-\alpha}^\pm(\pi)\in\Pi_{\psi_\alpha}$。

## 💡 理解辅助

- 局部 Arthur 包是 $L$-包的推广，允许 Arthur $\operatorname{SL}_2$ 因子捕捉非 tempered 部分的表示论信息。同一个表示可属于多个不同的 Arthur 包。
- 首个出现指数 $m^{\uparrow,\alpha}(\pi)$ 是 theta 提升首次非零的 tower 高度，是 Howe 对偶理论的核心参数。
- 本文的核心洞察：theta 对应在首个出现处"保持大部分 Arthur 参数结构"，仅对特定 block 做可预测的组合修改，从而可通过递归计数。

### 批判性思考

- 第七种情形是 block 交互的障碍，反映了 theta 对应与 Arthur 分类之间的深层非可交换性——这是本领域的核心困难所在。
