# Convex Biproducts, Stochastic Matrices and Tape Diagrams
keywords: convex biproduct, stochastic matrix, string diagram, monoidal category, CDU category, CMon-enriched, probabilistic Boolean circuit
related_paper: Bonchi--Piedeleu--Sobocinski--Zanasi, "Contextual Equivalence for Signal Flow Graphs"
one_liner_summary: 引入凸双积范畴作为随机矩阵的范畴语义，利用 CDU 范畴（CMon-富化 + 双积）与 tape 图建立概率布尔电路完全公理系统的图表演算。

## 1.  🎯核心定位
1. **核心问题**：为概率计算（随机/次随机矩阵的合成）建立一个完整的范畴语义，使其支持图形化推理和完全公理系统。
2. **与其他文献的关系**：基于 CDU 范畴（CMon-enriched compact closed 范畴 + 双积），推广到概率/凸可加性情形；将 Kontsevich 的矩阵演算和传统的概率布尔电路统一。
3. **主要贡献**：引入凸双积范畴的公理结构；证明该范畴中态射恰为（次）随机矩阵；用 tape diagram（带状的弦图推广）给出矩阵演算的完全图形化表示；建立概率布尔电路（含随机源与扇出）的完全公理系统。
4. **技术难点**：凸双积在 CMon-富化范畴中的正确定义（需处理凸组合的对角可加性）；tape 图的拓扑不变量与随机矩阵行列对应关系的证明；概率布尔电路公理系统的完备性证明。
5. **方法**：CMon-富化范畴论；CDU 范畴与双积理论；tape diagram 的拓扑弦图演算；布尔电路的代数化。
6. **局限性**：限于有限维概率空间；连续概率测度和量子概率未涉及。
7. **可扩展方向**：量子概率（完全正映射）的 tape 图版本；与 convex probabilistic programming 的联系。

## 2.  📐主要定理
**Theorem (凸双积范畴 = 随机矩阵)**：在凸双积范畴中，对象 n 到 m 的态射一一对应于 n×m 的次随机矩阵（或随机矩阵，取决于公理版本）。合成对应矩阵乘法，张量积对应 Kronecker 积。

**Theorem (Tape 图完全性)**：tape diagram 的拓扑等价类与随机矩阵的等式完全一一对应。任何两个表示同一矩阵的 tape 图通过局部变换可互化。

**Theorem (概率布尔电路的完全公理)**：带概率门的布尔电路在 tape diagram 的公理系统下是完全的——电路的等价性可由图形重写规则完整刻画。

## 3.  🔑关键组件
- **凸双积 (convex biproduct)**：对象上同时有类双积结构（对角 Δ: X → X⊕X，余对角 ∇: X⊕X → X）满足凸组合律：∇ ∘ (p ⊗ q) ∘ Δ 定义了概率分布 p 和 q 的凸组合。
- **CDU 范畴**：Copy（复制）- Discard（丢弃）- Uniform（均匀分布）范畴——由 Δ（copy）、▽（discard）和 u（uniform）三条生成规则组合的 CMon-富化范畴。
- **Tape diagram**：传统弦图的 "带状" 推广，带子可以分支和合并以编码凸组合。比传统弦图多出一条维度表示概率流。
- **次随机矩阵**：非负矩阵每列和 ≤ 1，表示总概率 ≤ 1（允许信息丢失）。随机矩阵每列和 = 1。
- **Kronecker 积**：矩阵的块结构张量积，对应 tape 图中两个独立子块的平行排布。

## 4.  💡理解辅助
1. **凸双积的直观**：普通双积让态射可加（f+g），凸双积让态射可做凸组合（p·f + (1-p)·g），对应概率的混合。这在范畴论层面捕获了古典概率的凸结构。
2. **Tape 图 vs 传统弦图**：弦图中线不可分裂；tape 图中带子可分裂（对应 Δ: 复制概率流）和合并（对应 ∇: 合并概率流），分裂/合并的宽度编码概率分布的权重。
3. **CDU 的物理直觉**：copy = 信息复制，discard = 信息丢弃/边际化，uniform = 均匀先验——三者的交互捕获了整个有限概率论。
