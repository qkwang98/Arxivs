# Twisted automorphic descent to odd GSpin groups and applications

keywords: 扭曲自守下降, GSpin 群, Langlands 函子性, 自守表示, 广义 Ramanujan 猜想, GGP 猜想, Jacquet-Langlands 对应
related_paper: 
one_liner_summary: 建立了从 $(\operatorname{GL}_{2n},\operatorname{GSpin}_2^\delta)$ 到奇 GSpin 群的扭曲自守下降映射，利用 GGP 猜想和 Jacquet-Langlands 对应证明下降的尖性（cuspidality）并在广义 Ramanujan 猜想中给出应用。

## 1.  🎯 核心定位

- **研究对象**：从经典群到奇 GSpin 群的自守下降（automorphic descent）——Langlands 函子性在非分裂群情形下的精细化构造
- **核心构造**：给定 $(\operatorname{GL}_{2n},\operatorname{GSpin}_2^\delta)$ 上的自守表示，通过 twisted endoscopic 转移构造奇 $\operatorname{GSpin}_{2n+1}$ 上的自守表示
- **理论归属**：Langlands 纲领的显式构造方向，连接了 Arthur 的 trace formula、Gan-Gross-Prasad 猜想和自守下降理论
- **解决的问题**：对于奇 GSpin 群（非分裂的特殊正交群的二重覆盖），此前缺少从一般线性群下降的显式构造。本文填补了这一空白，推广了 Ginzburg-Rallis-Soudry 的经典下降理论
- **核心结论**：(1) 在适当条件下，下降表示是尖的；(2) 下降映射遵守 Langlands 函子性，将 $L$-参数自然地转移；(3) 在广义 Ramanujan 猜想中给出 temperedness 的新证据
- **方法论**：综合利用 Fourier 系数（Ginzburg-Rallis-Soudry 方法）、twisted trace formula、以及 GGP 猜想的最新进展
- **关系图谱**：连接了 Ginzburg-Rallis-Soudry 的经典下降、Arthur 的内窥分类、Atobe-Gan 的 Bessel 模型、以及 Jacquet-Langlands 对应

## 2.  📐 主要定理

**Theorem 1（下降定理）**：设 $\pi$ 为 $\operatorname{GL}_{2n}(\mathbb{A})$ 上满足某种正则性条件的尖自守表示，配备到 $\operatorname{GSpin}_2^\delta(\mathbb{A})$ 的扭曲映射，则存在奇 $\operatorname{GSpin}_{2n+1}(\mathbb{A})$ 上的自守表示 $\sigma$ 满足 $L$-参数对应。

**Theorem 2（尖性判据）**：若 $\pi$ 的极点在 $s=1$ 处为单极点且局部数据满足一定条件，则下降表示 $\sigma$ 为尖表示。

**Theorem 3（广义 Ramanujan 猜想应用）**：利用下降构造，证明了一类 $\operatorname{GSpin}_{2n+1}$ 上的自守表示是 tempered 的。

## 3.  🔑 关键组件

- **$\operatorname{GSpin}$ 群**：一般自旋群，是特殊正交群 $\operatorname{SO}(n)$ 的连通二重覆盖。奇 $\operatorname{GSpin}_{2n+1}$ 的对偶群为 $\operatorname{Sp}_{2n}(\mathbb{C})$
- **扭曲自守下降**：利用 Fourier-Jacobi 系数或 Bessel 系数将高秩群上的表示"下降"到低秩群上——"扭曲"意指使用了额外的自同构或外自同构
- **$(\operatorname{GL}_{2n},\operatorname{GSpin}_2^\delta)$ 对**：$\operatorname{GL}_{2n}$ 与 $\operatorname{GSpin}_2^\delta$ 构成一个 twisted endoscopic 对，前者的 $L$-参数可以自然地转移为后者的 $L$-参数
- **GGP 猜想**：Gan-Gross-Prasad 关于经典群上 Bessel 模型与 Fourier 系数非消没的猜想，在本文中用于验证下降表示的局部-整体相容性
- **Jacquet-Langlands 对应**：将 $\operatorname{GL}_{2n}$ 的表示转移到内形式上的经典函子性，在本文中处理局部表示的非分歧性条件

## 4.  💡 理解辅助

**直觉**：自守下降好比"投影"——给定高维空间中的一个对称对象，通过取某种 Fourier 系数（本质上是沿某个非交换子群的周期积分），得到一个低维空间中的对称对象。本文的"扭曲"版本意味着下降过程还引入了额外的自同构相因子，类似于投影时旋转了投影方向。

**证明思路**：
1. 从 $(\operatorname{GL}_{2n},\operatorname{GSpin}_2^\delta)$ 的尖表示出发，定义 Fourier 系数作为下降到 $\operatorname{GSpin}_{2n+1}$ 的候选。
2. 利用 GGP 猜想的局部非消没性验证候选表示非零。
3. 通过 twisted trace formula 证明该表示满足 Langlands 函子性。
4. 应用 Jacquet-Langlands 对应和 Arthur 分类判定尖性。

**关键定义**：下降的 Fourier 系数为 $\int_{[U]}\varphi(ug)\psi(u)du$，其中 $U$ 为极大幂幺子群，$\psi$ 为适当选取的 generic 特征标。

## 5.  ✏️ 主动思考区

- **与 Arthur 分类的比较**：Arthur 的内窥分类给出了 GSpin 群上自守表示的参数化，但本文的下降构造是显式的、构造性的，不依赖于 trace formula 的技术边界。这两种方法在何处重合？
- **偶 GSpin 群的情形**：文章聚焦于奇 GSpin 群，对于偶情形 $\operatorname{GSpin}_{2n}$，下降理论是否也有类似构造？技术障碍在哪里？
- **批判性思考**：尖性判据依赖于 $s=1$ 处极点的单重性——这等价于 Arthur 参数中的某种正则性。对于非正则参数情形，下降表示是否仍为尖的？若否，其 Arthur 包结构如何？
- **值得探索的问题**：下降映射是否是一个函子？即自守表示范畴之间的下降是否可构造为一个 functorial lifting 的逆？
