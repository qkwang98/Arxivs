# Irreducible non-holonomic modules for rational Cherednik algebras

keywords: [Weyl algebra, invariant differential operators, non-holonomic modules, Gelfand-Kirillov dimension, rational Cherednik algebras]
related_paper: "Stafford (1985), Non-holonomic modules over Weyl algebras and enveloping algebras"
one_liner_summary: "对任意复反射群 G 和 n ≥ 2，证明了不变量环 A_n(K)^G 和积分参数的有理 Cherednik 代数 H_c 均存在 GK 维数为 2n-1 的不可约非完整模，并给出了显式构造。"

## 🎯 核心定位

- **解决的问题**：对 Weyl 代数不变量环 A_n(K)^G 和有理 Cherednik 代数 H_c，构造 GK 维数为 2n-1 的不可约非完整模。此前仅知 Weyl 代数自身存在此类模（Stafford 1985），推广到不变量环和 Cherednik 代数是全新的。
- **大图景位置**：填补了从 Weyl 代数向不变量环和 Cherednik 代数推广非完整表示论的空白。同时，附录中对 A_n 在区间 [n, 2n-1] 内每个整数都存在不可约模的证明，统一了完整模（GKdim=n）与非完整模（GKdim=2n-1）之间的所有中间情形。
- **主要贡献**：（1）对任意复反射群 G（n≥2），A_n(K)^G 存在 GK 维数 2n-1 的不可约非完整模，并给出显式构造；（2）对积分参数的有理 Cherednik 代数 H_c（n≥2），同样存在 GK 维数 2n-1 的不可约非完整模；（3）附录中 O. Mathieu 的证明表明 A_n 在 [n, 2n-1] 中每个整数都存在不可约模。
- **关键先驱工作**：Stafford (1985) 首次构造了 A_n 的 GK 维数 2n-1 的不可约非完整模；Coutinho (1999) 系统发展了 d-单环和 select variety 上的 D-模理论；Etingof-Ginzburg (2002) 引入有理 Cherednik 代数；Futorny-Schwarz (2020, 2021) 建立了不变量环的 Bernstein 不等式和完整模范畴理论；Berest-Etingof-Ginzburg (2003) 证明了积分参数 Cherednik 代数与 A_n(K)^G 的 Morita 等价。
- **结果边界**：（1）n=1 时不适用——此时 A_1(K)^G 的所有不可约模都是完整的；（2）参数 c 必须是积分参数（更确切地说，需要 Morita 等价于 A_n(K)^G，当参数非积分时 Morita 等价不成立）；（3）构造仅保证 GK 维数 2n-1，对中间值 [n+1, 2n-2] 的非完整模存在问题仍为 open problem。
- **开放问题**：对任意有限自同构群 G，A_n(K)^G 是否在区间 [n, 2n-1] 内每个整数值 GK 维数都存在不可约模？（注意附录已对 A_n 自身解决此问题，但 A_n^G 的情况尚不清楚）
- **应用与推广**：此结果可用于研究 Cherednik 代数的表示范畴结构——特别地，它表明在积分参数下，完整模范畴并非表示范畴的全部。结合 Bellamy-Etingof-Thompson (2024) 的 pull-back/push-forward 函子理论，这些非完整模可能在参数变化的表示范畴之间产生新的联系。技术层面，证明中使用的 "d-单环 + select variety 局部化 + 不变量环交截" 方法可推广到其他有限群作用下的微分算子环。

## 📐 主要定理

> **Theorem 4** (main, Theorem 4 in §4): Let G be a complex reflection group, n ≥ 2, and let I = D(X_f)(d+h), J = I ∩ A_n(K)^G. Then A_n(K)^G / J is an irreducible A_n(K)^G-module of Gelfand-Kirillov dimension 2n-1.

> **Theorem 5** (Cherednik case, Theorem 5 in §5): Let H_c be a rational Cherednik algebra with integral parameter c, and let n = dim h > 1. Then H_c has irreducible non-holonomic modules with Gelfand-Kirillov dimension 2n-1.

> **Theorem (Appendix, Olivier)**: For the Weyl algebra A_n(K) and any j ∈ [n, 2n-1], there exists an irreducible A_n(K)-module M with GKdim M = j.

### 证明思路

- 第一步：利用 Chevalley-Shephard-Todd 定理，复反射群 G 的多项式不变量是多项式代数 K[e_1,...,e_n]。通过局部化判别式 Δ，得到同构 D(K[X])^G_Δ ≃ D(K[E])_f，且 X_f = Spec K[E]_f 是 select variety。
- 第二步：在 select variety X_f 上，利用 Coutinho (1999) 的 Shamsuddin 型构造：选择适当的导数 d（使 K[E] 为 d-单）和多项式 h，使 D(K[E])/D(K[E])(d+h) 为 GK 维数 2n-1 的不可约模。由 Knop 定理，d+h ∈ A_n(K)^G。通过定理 "select variety 上的 D-模的不可约性在 D(X_f) 中保持"（Coutinho 定理 2.2），D(X_f)/D(X_f)(d+h) 也是 GK 维数 2n-1 的不可约模。
- 第三步：设 J = (D(X_f)(d+h)) ∩ A_n(K)^G。利用局部化的平坦性和 S = {Δ^k} 是 Ore 集的良好性质（定理 3.2, Lorenz），证明 GKdim(A_n^G/J) = GKdim(D(X_f)/I) = 2n-1。不可约性通过关键论证：若 J 被真包含于某左理想 L，则 L 必包含 S 中某元，从而 L ∩ K[E] 是非零 d-不变理想，但 K[E] 是 d-单的，矛盾。因此 J 是极大左理想。

## 🔑 关键组件

### 关键引理

> **Lemma** (d+h ∈ A_n^G): The element d+h constructed via Coutinho's method belongs to A_n(K)^G. — *[来自 Knop 定理的直接应用：D(X)^G = {D ∈ D(X) | D(K[X]^G) ⊂ K[X]^G}]*

> **Theorem** (Knop, 2006): Let X be a smooth affine variety over an algebraically closed field of characteristic zero, and G a finite group acting on X. Then D(X)^G = {D ∈ D(X) | D(K[X]^G) ⊂ K[X]^G}.

> **Theorem** (Eshmatov-Futorny-Ovsienko-Schwarz, 2017, Proposition 5.1-5.7): D(K[X])^G_Δ ≃ D(K[E])_f，其中 Δ 是判别式，f 是 Δ 用 e_i 表示的多项式。所有同构保持微分算子的阶滤过。

> **Theorem** (Berest-Etingof-Ginzburg, 2003, Theorem 3.1+Lemma 8.2): 积分参数的有理 Cherednik 代数 H_c 与斜群环 A_n * G Morita 等价，从而与 A_n(K)^G Morita 等价。

### 关键定义

> **Definition**: A_n(K)^G-模 M 称为完整的（holonomic），若 GKdim M = n；否则称为非完整的（non-holonomic）。

> **Definition** (select variety): 光滑仿射簇 X 称为 select variety，若其 Kähler 微分模 Ω_K X 是秩 n 的自由模，且存在基 dx_1,...,dx_n。

> **Definition** (d-simple): 含导数 d 的交换代数 A 称为 d-单的，若它没有非零真理想 I 满足 d(I) ⊂ I。
> **动机**：d-单性是构造不可约 D-模的核心技术条件——当 d 作用在多项式代数上时，d-单性保证由 d+f 生成的左理想是极大的，因为任何更大的左理想必须与 O(X) 相交得到 d-不变理想，从而必包含 1。

## 💡 理解辅助

- **贯穿例子**：论文在 §4.1 给出了 n=2, G=S_2 的具体计算：Δ=(x_1-x_2)^2, e_1=x_1+x_2, e_2=x_1x_2, f=e_1^2-4e_2。导数取 d = ∂_{e_1} + (e_2 e_1^2+1)∂_{e_2}，h=e_2。此时 A = A_2(K)^{S_2}，A/A(d+h) 是 GK 维数 3 的不可约非完整模。这个例子是理解一般构造的最小非平凡情形。

- **步骤拆解**：（1）d-单性验证：d 作用于 K[e_1,e_2] 满足 Shamsuddin 条件（a_2=e_1^2, b_2=1，且 deg a_2 > deg b_2），故 K[e_1,e_2] 是 d-单的；（2）Coutinho 定理 3.6 保证 D(K[e_1,e_2])/D(K[e_1,e_2])(d+e_2) 是不可约非完整模；（3）因为 G=S_2，Δ=(x_1-x_2)^2，全局不变量环 D(A_2)^{S_2} 局部化后同构于 D(K[e_1,e_2])_f；（4）Knop 定理保证 d+e_2 ∈ A_2(K)^{S_2}，且 J = (D(X_f)(d+e_2)) ∩ A_2(K)^{S_2} 是极大左理想。

- **与 Stafford 原始构造的关系**：Stafford (1985) 的构造是在 A_n(K) 中直接取导数 d 使得 K[x_1,...,x_n] 是 d-单的，然后证明 A_n/A_n d 是不可约非完整模。本文的关键创新是：通过局部化技术将 d+h 从不变量环 "提升" 到 D(X_f)，利用 select variety 的 D-模理论保持不可约性和 GK 维数，再通过交截 J = I ∩ A_n^G 回到不变量环。

## ✏️ 主动思考区

### 与其他工作的联系

- 与 Futorny-Schwarz (2021) "Holonomic modules for rings of invariant differential operators" 的深化：FS21 建立了 A_n^G 的完整模范畴理论（Bernstein 不等式、完整模是挠模、范畴 O 中的模都是完整的），本文则是对非完整模方向的推进，证明非完整不可约模确实存在。
- Bellamy-Etingof-Thompson (2024) "Pull-Back and Push-Forward Functors for Holonomic Modules over Cherednik Algebras"：本文构造的非完整模不在完整模范畴内，因此 BET24 的函子理论无法直接处理这些模，可能需要发展新的参数变化下的非完整模范畴工具。
- Stafford (1985)：本文的构造方法本质上是 Stafford 构造的 "不变量版本"。Stafford 构造了 A_n/A_n d，本文构造了 A_n^G / ((D(X_f)(d+h)) ∩ A_n^G)。

### 可以尝试的方向

- [ ] 能否对更一般的有限群 G（不仅仅是复反射群）构造 A_n(K)^G 的非完整不可约模？当前证明依赖两个关键点：（1）Chevalley-Shephard-Todd 定理保证不变量环是多项式代数；（2）EFOS 定理给出局部化后的 D-模同构。对于一般有限群，不变量环未必是多项式代数，可能更复杂。
- [ ] 对非积分参数的有理 Cherednik 代数，非完整不可约模是否仍然存在？当前证明完全依赖积分参数下的 Morita 等价。对于正则但非积分参数，H_c 仍然是单纯环，但不再与 A_n^G Morita 等价，GK 维数的概念需要其他方式来控制。
- [ ] 能否构造 GK 维数严格介于 n 和 2n-1 之间的 A_n^G 不可约模？论文附录已对 A_n 自身解决了此问题（通过 A_r ⊗ A_ℓ 的张量积构造），但对 A_n^G 这仍是一个 open problem。p-进不变量群或特殊的不变量环可能是突破口。

### 批判性思考

- 证明中 "select variety" 的框架本质上依赖于 D(X_f) 包含 Weyl 代数作为子环（因为 {e_i} 是代数无关的）。这意味着 D(X_f) 中 d+h 生成的模的不可约性和 GK 维数完全由 Weyl 代数部分决定。这引发一个自然问题：在什么意义上这是 "真正" 的全局 D-模构造，而非仅仅是把 Weyl 代数上的已知构造嵌入到更大的环中？
- 对 Cherednik 代数情形的推导 "Invar has such modules... by Morita equivalence we are done" 简洁但可能掩盖了一些微妙之处：Morita 等价保持 GK 维数（定理 1.7, BH08），但完整模的定义在 H_c 的情形（GKdim=n）是否与不变量环情形完全对应？Thompson (2018) 的 Proposition 3.7 仅在 c 正则时定义完整模为 GKdim=n，而本文的积分参数都是正则的，因此不存在冲突，但值得注意这一隐含条件。
- 证明的最关键步骤——"若 L 严格包含 J，则 L ∩ S ≠ ∅"——依赖于局部化的忠实平坦性和 D(X_f) 是主理想整环（作为 Ore 局部化）的性质。这一论证在非交换局部化中并不总是成立，但本文中 {Δ^k} 是满足定理 3.2 (Lorenz) 条件的 Ore 集（Δ 的共轭作用是局部幂零导数），因此论证严密。不过，对不熟悉 D-模局部化理论的读者而言，这一步的 "忠实平坦" 论证可能需要更多展开。
