## 3.  One-liner summary

本文证明 Grothendieck 余纤维化的分裂传输数据通过一个 colax 2-单子态射被精确地转化为总范畴上的严格分解系统，这一转化在严格和伪代数两个层面上都是 2-函子性的。

## 4.  🎯 核心定位

1. **研究问题**：如何从 Grothendieck 余纤维化的传输结构（分裂 cleavage）系统地导出总范畴上的（正交）分解系统，并证明这一导出过程是 2-函子性的。
2. **方法论框架**：使用 Street 的形式 2-单子理论。核心工具是全局逗号 2-单子 C（编码 Grothendieck 传输）和平方 2-单子 Sq（编码分解系统），以及它们之间的 colax 2-单子态射 κ。
3. **关键构造**：定义 colax 态射 κ_P: E^2 → P↓B，将交换方形映射为逗号箭头。通过标量限制（restriction of scalars），C-代数（余纤维化）被拉回为 Sq-代数（分解系统）。
4. **主要结果**：严格 2-函子 Fact: SCoFib → Alg(Sq)，将分裂余纤维化变为严格分解代数；伪代数版本 Fact_n: NClCoFib → PsAlg_n(Sq)，对应正交分解系统 (CoCart(P), P^{-1}Iso(B))。
5. **严格与正交分解的区分**：严格分解系统 (Δ_P, Vrt(P)) 由指定的 cocartesian 箭头和垂直箭头组成；其同构闭包给出正交分解系统，后者仅依赖于底余纤维化 P，与 cleavage 的选择无关。
6. **对偶理论**：通过取对偶范畴和逗号范畴的重新排序，整套理论对偶地适用于分裂纤维化，给出严格 2-单子性定理。
7. **应用**：该构造直接应用于 Grothendieck 构造，其标准分解 (u, φ) = (1_c, φ)(u, 1_{Xu x}) 正是 Sq-作用在态射上的取值。

## 5.  📐 主要定理

**定理 A（严格 2-单子性）**：比较 2-函子 Γ: SCoFib → Alg(C) 是 CAT^2 上的 2-范畴同构。因此遗忘 2-函子 SCoFib → CAT^2 是严格 2-单子的。

**定理 B（正规伪代数比较）**：存在 CAT^2 上的 2-范畴同构 Γ_n: NClCoFib → PsAlg_n(C)。在此同构下，伪同态恰为保持 cocartesian 箭头的平方，严格同态恰为严格保持指定 lifts 的平方，所有 2-胞腔均为代数变换。

**定理 C（Grothendieck 分解 2-函子）**：colax 2-单子态射 (Dom, κ) 与定理 A 的比较同构确定严格 2-函子 Fact := κ* ∘ Γ: SCoFib → Alg(Sq)。对于分裂余纤维化 P，其 Sq-作用为 F^P = L^P ∘ κ_P: E^2 → E，选定的分解为 f = ν_f ∘ δ^x_{Pf}。

**定理 D（伪代数 Grothendieck 分解）**：标量限制和定理 B 给出 2-函子 Fact_n: NClCoFib → PsAlg_n(Sq)。在 Sq-伪代数与正交分解系统的同构下，该伪代数对应正交分解系统 (CoCart(P), P^{-1}Iso(B))。

**证明骨架（定理 C 的核心论证）**：
1. 验证 κ_P 满足单位和乘法的 colax 方程：κ_P I_E = H^P 和 κ_P m_E = M^P κ_{C P} (κ_P)^2。
2. 利用 C-代数律和 κ 的 2-自然性验证：F^P I_E = A κ_P I_E = A H^P = 1_E 以及 F^P m_E = F^P (F^P)^2。
3. 左因子 e_f = F^P(1_x, f) = δ^x_{Pf}，右因子 m_f = F^P(f, 1_y) = ν_f，给出分解 f = ν_f δ^x_{Pf}，唯一性由 cocartesian 万有性质保证。

## 6.  🔑 关键引理/定义

- **全局逗号 2-单子 C**：对 P: E → B，C P = (Cod_P: P↓B → B)；单位 H^P(x) = (Px, 1_{Px}, x)；乘法 M^P(a, u, (x, v)) = (x, vu)
- **平方 2-单子 Sq**：Sq E = E^2（箭头范畴）；单位 I_E(x) = 1_x；乘法 m_E 取交换方形的对角线
- **Colax 态射 κ**：κ_P(f: x→y) = (x, Pf)，κ_P(r, s) = (r, Ps)，满足单位和乘法相容方程
- **分裂余纤维化**：带有指定 cocartesian lifts δ^x_u 的函子 P，满足 δ^x_{1_{Px}} = 1_x 和 δ^{u_! x}_v δ^x_u = δ^x_{vu}
- **吸收引理**：严格情形 A(δ^x_u, 1_b) = 1_{u_! x}；伪情形有相应的伪吸收等式
- **传输连贯性引理**：正规 cloven 余纤维化中有唯一垂直同构 χ^x_{v,u}: v_!(u_! x) → (vu)_! x 满足五边形公理

## 7.  💡 贯穿例子

Grothendieck 构造 ∫_B X 是其典范应用。对于严格函子 X: B → CAT，分裂 cleavage 的指定 cocartesian 箭头为 (u, 1_{Xu x})。Fact(π_X) 选取的分解为：(u, φ) = (1_c, φ)(u, 1_{Xu x})。严格分解系统由指定箭头 (u, 1) 和垂直箭头 (1_b, ψ) 组成；关联的正交分解系统中，左类为 φ 可逆的态射，右类为 u 可逆的态射。

## 8.  ✏️ 批判性思考

本文的核心贡献是将 Grothendieck 纤维化理论与形式单子论之间的两个经典结果——分裂纤维化的 2-单子性和正交分解系统的 Sq-代数刻画——通过一个精妙的 colax 单子态射 κ 连接起来。κ 构造极其自然：将交换方形映射为逗号箭头正是对总范畴中「箭头 = 基箭头 + 纤维态射」这一直觉的形式化。其技术优雅在于全程严格——所有 2-胞腔方程均为等式而非同构。

主要局限有二：(1) 整套工作在 CAT 中进行，未涉及 2-范畴纤维化（如 Hermida 意义下），文中也明确指出这是未来方向；(2) 对弱分解系统（algebraic weak factorization systems）的处理仍需不同的代数结构（如 Grandis–Tholen 的 comonad-monad 配对），本文的单一 Sq-作用不能直接覆盖。此外，富集版本和幺半版本的推广仍有待展开。

关于数学史的注记：第二作者的早期工作（Korostenski–Tholen, 1993）已建立了严格的 Sq-代数与严格分解系统的对应，本文的新意在于将其系统地连接到 Grothendieck 传输，并证明这一连接是 2-函子性的——这补充了传统教材中「cocartesian–vertical 分解只是平凡观察」的认知空白。

## 9.  证明思路

1. **第一层：严格代数**。定义逗号 2-单子 C，证明 SCoFib ≅ Alg(C)（定理 A）：对象层面，从分裂 cleavage 重构作用 L^P(f, v) 满足 δ^y_w f = L^P(f, v) δ^x_u；1-胞腔层面，严格保持指定 lifts 恰为严格代数同态；2-胞腔层面，所有自然变换均为代数 2-胞腔。核心是吸收引理：A(δ^x_u, 1_b) = 1_{u_! x} 由单位律导出。

2. **第二层：伪代数**。将严格等式替换为同构 χ^x_{v,u}，证明 NClCoFib ≅ PsAlg_n(C)（定理 B）。伪吸收引理证明 δ^x_u 仍为 cocartesian，伪态射比较胞腔 θ 的存在性等价于总函子保持 cocartesian 箭头。基不变版本允许非正规 cleavage，此时伪单位 ι_x = δ^x_{1_{Px}} 非平凡。

3. **第三层：标量限制**。构造 colax 态射 (Dom, κ)，应用标量限制 2-函子 κ* 和 κ*_ps。在严格层面，得到分解 2-函子 Fact，将每根箭头 f 分解为 δ^x_{Pf}（左因子）和 ν_f（右因子）。通过 cocartesian 万有性质验证左类 = 指定 cocartesian 箭头、右类 = 垂直箭头（严格情形）或同构闭包（正交情形）。对角线填充论证直接验证正交性。
