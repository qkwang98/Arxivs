# Set-theoretic universes and paradoxes in 2-topoi

keywords: [2-topos, DOF classifier, 集合论宇宙, Burali-Forti 悖论, topos sketch]
related_paper: "Helfer, Topoi in topoi（\cite{helfer-topoi-in-topoi}）"
one_liner_summary: "本文证明任意 2-topos 内部都含有直觉主义 ZF 集合论模型，并据此说明当尺寸限制缺失时，2-topos 公理会导出 Burali-Forti 型悖论。"

## 1.  核心定位

- **解决的问题**：证明（elementary）2-topos 内部可以构造出集合论宇宙，即直觉主义 ZF 的内部模型，并判定 2-topos 公理本身是否蕴含悖论。
- **大图景位置**：本文延续 Weber 提出的 2-topos 公理化以及作者前作 Topoi in topoi 的纲领，把"1-topos 内部可做集合论"的经典图景整体提升到 2-范畴层面；同时与"代数集合论（algebraic set theory）"接轨，给出从"类范畴"构造集合论宇宙的新途径。
- **主要贡献**：
  1. 证明任意 2-topos \(\cC\) 都包含直觉主义 ZF 集合论的内部模型；
  2. 在尺寸限制缺失（每个 DOF 都 small）的前提下导出 Burali-Forti 型悖论，即 2-topos 等价于平凡 2-范畴；
  3. 用"topos sketch"+有限高阶理论的一般 cotensor 构造统一产出集合论宇宙，并借 hs-classifier 得到 MK 的模型。
- **关键先驱工作**：Weber 的 2-topos 定义；作者前作 Topoi in topoi（证明 DOF 分类子是内部 1-topos）；Mostowski 的 collapsing lemma；1-topos 内部集合论（Lambek–Scott 传统）。
- **结果边界**：需要 groupoidant / corepita 假设与公理 (UA)，以保证 \(\DOF(A)\) 成为 topos；悖论定理依赖"所有 DOF/SOF 都 \(\rS\)-small"这一尺寸缺失；所得模型是直觉主义版本（非古典 ZF/MK），且 \(\rS\) 不像 \(\Omega\) 那样由万有性质唯一决定。
- **开放问题**：2-topos 的最终公理化仍"处于发展之中"；如何以恰当尺寸限制避开悖论而又保留非平凡例子，是作者明确留下的方向。
- **应用与推广**：为"集合的范畴不止一个"（依赖 Grothendieck 宇宙选取）这一现象提供了内部化的公理框架；其 \(\unein\)-object 技术、cotensor 技术可迁移到高阶范畴与代数集合论的比较研究中。

## 2.  主要定理

> **全局假定 / 背景**: 设 \(\cC\) 为（elementary）2-topos，其核心对象是 discrete opfibration classifier（DOF 分类子）\(\rS\in\cC\)，配备万有 DOF \(p\colon \rS_*\to\rS\)；在原型 \(\cC=\Cat\) 情形 \(\rS\) 即 \(\Set\)。对每个 \(A\in\cC\) 有自然函子 \(\El^A\colon\cC(A,\rS)\to\DOF(A)\)（拉回 \(p\) 而得），一般情形只要求 fully faithful，而非等价；落在其本质像中的 DOF 称为 small（relative to \(\rS\)）。后续定理在 groupoidant / corepita 2-范畴及公理 (UA) 下成立。

> **Theorem**: Any 2-topos \(\cC\) contains an internal model for intuitionistic ZF set theory.

*动机 / 作用*：这是全文的中心结论，把 1-topos 的"内部集合论"图景提升到 2-topos，从而支持"2-topos 可作为基础理论"的纲领。
*证明思路*：先在 2-topos 中构造遗传集合的结构 \((\rV,\unin_\rV)\) 与元素关系层，证明其外延性、良基性与传递闭包性质；再由 Mostowski collapsing 把 hs-set 等同于"树状祖先结构"；最后验证 ZF 的构造在该内部结构上封闭，得到解释。

> **Theorem (\label{thm:universe})**: Let \(\cC\) be a groupoidant 2-category satisfying (UA). Then the 1-topos \(\DOF(\tm)\) contains an internal model for MK.

*动机 / 作用*：把"集合论宇宙"定位在 DOF 分类子处，得到比 ZF 更强的 Morse–Kelley 类理论模型，从而在同一框架内同时容纳集合与真类。
*证明思路*：以 topoculus \(\fS\) 上的 hs-classifier \(\cV\) 构造 MK 模型；用有限高阶理论 \(\cT\) 的（半严格）cotensor \((E^\cT)^\iso\) 把内部 topos \(E\) 升级为承载类结构的对象，再借 \(\El^{A}\) 与拉回函子的逻辑性完成解释。

> **Theorem (\label{thm:paradox})**: If \(\cC\) is a groupoidant 2-category, and there exists a DOF classifier \(\rS \in \cC\) such that every SOF in \(\cC\) is \(\rS\)-small, then \(\cC\) is equivalent to the trivial 2-category.

*动机 / 作用*：说明尺寸限制不可回避——若所有结构都 small，2-topos 会塌缩，这正是 Burali-Forti 型悖论在 2-范畴层面的体现。
*证明思路*：若每个 SOF 都 small，可在 \(\cC\) 内部构造"全体序数"式的自指对象，重现 Burali-Forti 论证，迫使相应命题成立为 \(0\simeq1\)（从而 \(\cC\) 等价于平凡 2-范畴）。

> **Theorem (\label{thm:theory-cotensors})**: If \(\cC\) is a corepita 2-category and \(\cT\) is a finite higher order theory, then any internal topos \(E \in \cC\) admits a semi-strict cotensor \((E^{\cT})^\iso\).

*动机 / 作用*：这是全文"一般构造"的引擎：任意有限高阶理论都能在内部 topos 上产生 cotensor，集合论宇宙不过是取 \(\cT\) 为 ZF/MK 理论的特例。
*证明思路*：以 topos sketch 刻画 \(\cT\) 的模型类；在 corepita 2-范畴中构造同构对象 \((E^\cT)^\iso\)，再用半严格伪函子结构把 \(\cT\) 的模型解释为 \(\cC\) 中的内部范畴。

> **Theorem (\cite[Theorems~5.4.6~and~5.4.7]{helfer-topoi-in-topoi}, \label{thm:topoi-in-topoi-main-thm})**: Let \(\cC\) be a groupoidant (or more generally, corepita) 2-category. Then: (i) Any plentiful DOF classifier \(\rS \in \cC\) is an internal topos; thus, \(\DOF_\rS(A)\) is a topos for each groupoid \(A \in \cC\), and the pullback anafunctor \(f^* \colon \DOF_\rS(A) \to \DOF_\rS(A')\) is logical for each morphism \(f \colon A' \to A\) between groupoids. (ii) Given plentiful DOF classifiers \(\rS\) and \(\rS'\) such that the generic DOF \(p \colon \rS_* \to \rS\) over \(\rS\) is \(\rS'\)-small, and letting \(f \colon \rS \to \rS'\) be a morphism classifying \(p\), the functor \(f_* \colon \cC(A, \rS) \to \cC(A, \rS')\) is fully faithful and logical for each \(A \in \cC\). (iii) If \(\cC\) satisfies axiom (UA), then \(\DOF(A)\) is a topos for each \(A \in \cC\), and the inclusion \(\DOF_\rS(A) \hto \DOF(A)\) is logical for each plentiful DOF classifier \(\rS\).

*动机 / 作用*：这是从作者前作继承的技术基座：把 2-topos 中的分类子还原为内部 1-topos 及其间的逻辑包含，是后文所有集合论构造的前提。
*证明思路*：对 plentiful DOF 分类子证明其内部 topos 结构；再以分类 DOF 的 smallness 条件得到逻辑全忠实函子，最后在 (UA) 下统一为 topos \(\DOF(A)\)。

### 2.1.  证明思路

- 第一步：在 2-topos 中发展 \(\unein\)-set / \(\unein\)-object 理论，建立遗传集合 \(\rV\)、元素关系 \(\unin_\rV\)、传递闭包、外延性与良基性等基础命题。
- 第二步：用 Mostowski collapsing 证明每个 hs-set 都同构于某个 \((\tc(\set x),\ein_x)\)，把集合论对象翻译为树状结构；并证明初始映射的唯一性、单性与保守性，为"集合相等"提供范畴判据。
- 第三步：以有限高阶理论的 cotensor（topos sketch）统一构造模型，得到直觉主义 ZF 的内部模型；再把 DOF 分类子处的类结构升级为 MK，并说明一旦取消 smallness 限制即得 Burali-Forti 型塌缩。

## 3.  关键组件

### 3.1.  关键引理

> **Lemma (\label{lem:v-and-tc-facts})**: A set is hereditary if and only if all of its elements are hereditary. (In particular, \(\rV\) is a transitive class.) A subclass \(A \subset \rV\) is downward-closed in \((\rV, \unin_\rV)\) if and only if it is transitive. (More generally, if \(B \subset \rV\) is transitive, then \(A \subset B\) is downward-closed in \((B, \unin_B)\) if and only if it is transitive.) (In particular \(\dwnfn_B(A) = \tc(A)\) for any \(A \subset B\).) \((\rV, \unin_\rV)\) is a (large) extensional and well-founded \(\unein\)-set. (And so is \((A, \unin_A)\) for any transitive \(A \subset \rV\).) The transitive closure of any hereditary set \(x \in \rV\) is again a (small) set. (Hence, it is the least transitive \emph{set} \(y\) with \(x \subset y\).) \(\tc(\set{x})\) is an hs-set for any \(x \in \rV\), with top element \(\rt_{\tc(\set{x})} = x\).

*[新证]*

> **Proposition（Mostowski collapsing lemma, \cite[Theorem~3]{mostowski-undecidable-statement}, \label{propn:mostowski-collapse}）**: Given any hs-set \(X\), there is a unique hereditary set \(x\) such that \(\pbig{\tc(\set{x}), \ein_x} \cong (X, \ein_X)\).

*[引用自 Mostowski]*

> **Proposition (\label{propn:no-loops})**: If \(X\) is well-founded, then \(\bC \vDash \forall x \tolon X.\ \neg (x \prec x)\) and hence \(\bC \vDash \forall x \tolon X.\ \neg (x \ein x)\) and \(\bC \vDash \forall x,y \tolon X.\ (x \preceq y \wedge y \preceq x) \to x = y\).

*[新证]*

> **Proposition (\label{propn:init-cons-mono})**: If \(X\) is extensional and well-founded, then any initial morphism \(f \colon X \to Y\) is monic and conservative. (A more precise statement is: any initial mono \(f \colon X \to Y\) is conservative, without any assumptions on \(X\); and if \(X\) is extensional and well-founded, then any initial morphism \(f \colon X \to Y\) is monic.)

*[新证]*

### 3.2.  关键定义

**关键概念（DOF 分类子与 small 性）**：2-topos \(\cC\) 的中心对象是 DOF classifier \(\rS\in\cC\)，配备万有 DOF \(p\colon\rS_*\to\rS\)；对每个 \(A\in\cC\) 有自然函子 \(\El^A\colon\cC(A,\rS)\to\DOF(A)\)，由拉回 \(p\) 而得，在原型 \(\Set\in\Cat\) 情形正是"元素范畴"构造。该函子只要求 fully faithful，而非等价；称 \(A\) 上的 DOF 为 small（更准确地：small relative to \(\rS\)）若它落在 \(\El^A\) 的本质像中。

**直观动机与作用**：\(\rS\) 与 \(\Omega\) 的关键差别是它不被万有性质唯一决定，因为"集合的范畴"本就依赖 Grothendieck 宇宙的选取。把 small 定义为相对 \(\rS\) 的本质像，正是把这种多解性内化进公理系统：在 \(\Set\in\Cat\) 中，\(\El^A\) 的本质像恰是"小纤维"的 DOF，而非全部 DOF——这也解释了后文悖论中"尺寸限制"为何不可省。

**关键概念（hereditary set 与 hs-set）**：若集合的所有元素都是 hereditary，则称该集合 hereditary；\((\rV,\unin_\rV)\) 为遗传集合（大）类，\(\ein\) 为（内蕴的）元素关系；hs-set 指带有顶端元素、满足相应良基/外延条件的 \(\unein\)-set。\(\tc(x)\) 表示传递闭包，\(\dwn\) 为下行闭包算子。

## 4.  理解辅助

- **贯穿例子**：原型 2-topos \(\Cat\) 中 \(\rS=\Set\)，\(\El^A\colon\Cat(A,\Set)\to\DOF(A)\) 即元素范畴构造；其本质像只含小纤维的离散纤维化，说明"DOF 分类子"实际分类的是小 DOF——这是"relative to \(\rS\)"的直接来源。
- **尺寸对照**：\((\rV,\unin_\rV)\) 是"大"的外延良基 \(\unein\)-set，而 hereditary 集合 \(x\) 的传递闭包仍为小集合；大小之别在 \(\rV\) 与 \(\tc(\set x)\) 的对比中可见，也正是悖论定理所依赖的分界线。

- 技术迁移：把"small relative to \(\rS\)"的尺寸控制移植到 \(\infty\)-topos，可能得到 \(\infty\)-层面的对应塌缩定理与内部集合论。

### 5.3.  批判性思考

- 论文依赖 (UA) 与 groupoidant / corepita 假设，而这些假设尚未成为该领域的公认公理；作者本人也把这些假设视为"2-topos 定义仍在开发"的一部分，说明结论的适用范围需谨慎对待。
- 悖论定理的结论（\(\cC\) 等价于平凡 2-范畴）在原型 \(\Cat\) 中前提明显不成立，因此它更像"公理不可省"的判定性结果，而非对具体 2-topos 的断言。
- 文中大量 \(\unein\)-object 技术命题（局部外延性、初始映射唯一性、下行闭包等）承担的是"把 2-范畴语言翻译为集合论语言"的职责；阅读时应把它们与该翻译目标绑定，而不宜当作独立的表示论结论。
