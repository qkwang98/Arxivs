# Cluster Algebras for Bosonic Plethysm

keywords: [plethysm, cluster algebras, theta bases, invariant theory, polyhedral cones, symmetric matrices]
related_paper: "Fei, Cluster structures on semi-invariant rings of flagged Kronecker quivers (2023)"
one_liner_summary: "通过折叠 flagged Kronecker 箭图的行列式种子构造对称平方 plethysm 不变环上的 cluster 结构，用 theta 基给出 plethysm 系数作为有理多面锥中整点的公式。"

## 🎯 核心定位

- **解决的问题**：对 bosonic plethysm（内分划为 (2) 的 plethysm，即对称平方函子）的乘数 a_{μ,(2)}^λ 给出正的组合/几何解释。将 plethysm 不变环 \mathcal{R}_{ℓ,m} = \operatorname{Sym}(\operatorname{Sym}^2 V ⊗ W)^{U_V} 实现为上 cluster 代数。
- **大图景位置**：这位于簇代数表示论与古典不变量理论的交汇处。对称平方是仅次于行列式（外平方，fermionic plethysm, 己由 Fei–Fang–Pietro 2024 处理）的最自然的 plethysm 情形。bosonic 与 fermionic 形成对称。
- **主要贡献**：1. 对所有 ℓ,m ≥ 2 构造显式的 skew-symmetrizable 种子 Σ_{ℓ,m}，通过对 flagged Kronecker 行列式种子进行转置轨道折叠得到；2. 证明 \mathcal{R}_{ℓ,m} = \mathcal{U}(Σ_{ℓ,m})（上 cluster 代数相等）；3. 证明 Σ_{ℓ,m} 存在 reddening 序列；4. theta 基跨过 frozen 边界的充要条件是参数属于一个有理多面锥 \mathscr{C}_{ℓ,m}，其整点纤维计数给出 multigraded highest-weight multiplicities b_{α,(2)}^λ；5. 通过 Jacobi-Trudi 公式将 plethysm 系数表示为这些计数的有限交错和。
- **关键先驱工作**：Fock–Goncharov (2006, cluster ensembles)；Gross–Hacking–Keel–Kontsevich (2018, theta 基)；Fei (2023, flagged Kronecker 的 cluster 结构)；Dupont (2011, 可容许轨道折叠)；Fang–Fei–Pietro (2024, fermionic plethysm 的 cluster 结构)。
- **结果边界**：仅给出 b_{α,(2)}^λ 的正公式（多面锥整点计数），而未给出 plethysm 系数 a_{μ,(2)}^λ 本身的正组合公式（后者涉及 Jacobi–Trudi 的符号交错和）。优化 frozen 种子构造仅在 ℓ 奇数且 m 偶数时完整给出。
- **开放问题**：能否直接得到 a_{μ,(2)}^λ 的正公式？对更大的内分划 ν（如 ν=(3), (2,1) 等）能否有类似 cluster 构造？
- **应用与推广**：plethysm 系数在代数组合、表示稳定性和几何复杂度理论中起核心作用。theta 基给出新的 polyhedral 组合模型。

## 📐 主要定理

> **Theorem A (Upper Cluster Equality)**: 对所有 ℓ,m ≥ 2，折叠种子 Σ_{ℓ,m} 具有满行秩和 skew-symmetrizable 主部，且 \mathcal{R}_{ℓ,m} = \mathcal{U}(Σ_{ℓ,m})（frozen 变量作为多项式系数）。

> **Theorem C (Theta Basis)**: 族 \{ϑ_g : g ∈ \mathscr{C}_{ℓ,m} ∩ M_{ℓ,m}\} 构成 \mathcal{R}_{ℓ,m} 的一组基，且 multigraded highest-weight multiplicity b_{α,(2)}^λ = |\mathscr{P}_{ℓ,m}(λ;α) ∩ M_{ℓ,m}|。

### 证明思路

- 第一步：从 flagged Kronecker 的 χ 函子构造出发，通过矩阵模型转移到两则矩阵不变量代数 \mathcal{T}_{ℓ,m}，再通过对转置 involution 取不变子代数得到对称矩阵不变环 \mathcal{R}_{ℓ,m}。
- 第二步：对转置轨道进行可容许折叠，构造折叠交换矩阵 B_{ℓ,m} 和交换关系。轨道大小函数给出 skew-symmetrizer。
- 第三步：通过 Gauss 开集的局部化论证证明上 cluster 代数相等，利用 factoriality 和初始函数不可约性。
- 第四步：通过 Fock–Goncharov disk flip 的转置配对下降构造 reddening 序列，从而启用 GHKK theta 基理论。

## 🔑 关键组件

### 关键定义

> **折叠种子 Σ_{ℓ,m}**：mutable 指标集大小为 (m-1)(ℓ-1)(ℓ+2)/2，frozen 指标集大小为 m+ℓ-1。交换关系按五类给出：底边变量、n=2 块的另一边、chamber 内部、偶数边界粘合、奇数边界粘合。
> **动机**：两则情形中左/右 chamber 函数在对称矩阵限制下重合，每个转置轨道贡献一个折叠变量。轨道大小为 1 或 2，前者对应转置不动点。
