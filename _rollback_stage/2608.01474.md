# A uniform decomposition theorem for invariant differential operators on imprimitive complex reflection groups $G(r,p,n)$

keywords: [complex reflection groups, invariant differential operators, higher Specht polynomials, Galois descent, discriminant, double centralizer]
related_paper: "Nonkané, Decomposition theorem for W(D_n) (2021)"
one_liner_summary: "统一处理全部 G(r,p,n) 族群的判别式局部化多项式环在不变微分算子环上的模结构，用 Jacobian 引理与双中心化子论证给出简单子模的显式生成元，统一并大幅缩短了此前逐群处理的证明。"

## 1.  🎯 核心定位

- **解决的问题**：对于任意非本原复反射群 G(r,p,n)，局部化多项式环 \widetilde{\mathcal{O}}_X 在不变微分算子环 \widetilde{\mathcal{D}}_Y 上的简单子模及其重数如何描述？此前只有对称群、圈积 G(r,1,n) 和 W(D_n) 的逐群结果。
- **大图景位置**：这是 G(r,p,n) 不变理论—Weyl 代数表示论—Galois 下降范畴等价三者交汇的统一定理。将 Nonkané 等人的逐群工作提升到一次覆盖全部分类的层面。
- **主要贡献**：1. 一个统一的 Jacobian 引理（Lemma 2.1）计算 G(r,p,n) 的判别式，作为变量变换的行列式；2. 一个自足的双中心化子论证（double centralizer）扩展为 \mathbb{C}[W] ≅ End_{\widetilde{\mathcal{D}}_Y}(\widetilde{\mathcal{O}}_X)；3. 以 Higher Specht 多项式为生成元给出所有简单子模的显式描述。
- **关键先驱工作**：Nonkané (2019, S_n); Nonkané–Lawson (2022, G(r,1,n); 2021, W(D_n)); Morita–Yamada (1998, G(r,p,n) 的 Higher Specht 多项式); Ariki–Terasoma–Yamada (1997)。
- **结果边界**：依赖于判别式非零（需在 Galois 扩张 L/K 成立），不涉及特征 p（所有工作在 \mathbb{C} 上进行）。
- **开放问题**：能否将类似的双中心化子技术推广到 exceptional complex reflection groups（G_4, …, G_37）？
- **应用与推广**：特例 r=p=2 恢复 W(D_n) 的分解定理；p=1 恢复圈积 G(r,1,n)；p=r 给出 G(r,r,n)。所有已知逐群结果作为两行推论得到。

## 2.  📐 主要定理

> **Theorem 3.4 (Main)**: Fix λ ∈ \mathcal{P}_{r,n}/∼, 0 ≤ l < e(λ). Enumerate STab(λ)_d = {S_1,…,S_{f^l_λ}}. For each i, the primitive idempotent e^{λ,l}_i ∈ \mathbb{C}[W] satisfies: (i) e^{λ,l}_i \widetilde{\mathcal{O}}_X is a nonzero \widetilde{\mathcal{D}}_Y-submodule; (ii) it is simple; (iii) e^{λ,l}_i \widetilde{\mathcal{O}}_X = \widetilde{\mathcal{D}}_Y F^l_{S_i,T} for some higher Specht polynomial F^l_{S_i,T}.

### 2.1.  证明思路

- 第一步：通过 Jacobian 引理将判别式 Δ 重述为 Jacobian 行列式，从而 \widetilde{\mathcal{O}}_X 获得 \widetilde{\mathcal{D}}_Y-模结构。
- 第二步：证明双中心化子同构 \mathbb{C}[W] ≅ End_{\widetilde{\mathcal{D}}_Y}(\widetilde{\mathcal{O}}_X)（用正则表示的忠实性 + 纯 Galois 理论或链式法则的矩阵论证）。
- 第三步：对半单代数 \mathbb{C}[W] 应用抽象双中心化子引理得到分解，再用 Higher Specht 多项式的 Morita–Yamada 定理将 idempotent 与生成元对应起来。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma 2.1 (Jacobian)**: 置基本不变量 y_j = Σ x_i^{jr} (j < n) 与 y_n = (x_1⋯x_n)^d，则 Jacobian 行列式 det(∂y_i/∂x_j) 为非零常数乘以 \prod x_i^{d-1} \prod_{i<j} (x_j^r - x_i^r) = c·Δ，因此 \widetilde{\mathcal{O}}_X 成为 \widetilde{\mathcal{D}}_Y-模。

### 3.2.  关键定义

> **G(r,p,n)**：p|r 时由单项矩阵组成，非零元为 r 次单位根，非零元乘积的 d = r/p 次幂为 1。当 p=r 时为子群 G(r,r,n)，p=1 时为全单项群 G(r,1,n)。
> **动机**：这类群是 Shephard–Todd 分类中最丰富的无穷族，捕捉了从实 Coxeter 群到一般复反射群的系统性推广。

## 4.  💡 理解辅助

- **贯穿例子**：W(D_n) = G(2,2,n) 作为特例直接恢复 Nonkané–Lawson 2021 的结果。B_2 = G(2,1,2) 通过 5 个分块（4 个一维特征标 + 1 个 2×2 矩阵代数）的具体分解验证了定理的两种重数计数方式（rank 8 = 1+1+1+1+2+2 与 1+1+1+1+2·2）。
