# Comparing self-dual corings, Frobenius corings and Ringel self-duality

keywords: [self-dual corings, Frobenius corings, Ringel self-duality, quasi-hereditary algebras, Borel subalgebras]
related_paper: "Koenig-Külshammer-Ovsienko -- Quasi-hereditary algebras and Ringel duality"
one_liner_summary: "证明有限维代数上自对偶 coring 等价于 Frobenius coring，并以此统一 Burt-Butler 对偶与 Ringel 自对偶；作为应用，刻画了标准分层代数的正则精确 Borel 子代数为 Frobenius 扩张当且仅当代数是半单的。"

## 🎯 核心定位

- **解决的问题**：Ringel 自对偶代数（Ringel 对偶与自己 Morita 等价）与 Burt-Butler 对偶之间的关系是什么？能否在一个统一的 coring 框架下理解这两类对偶？
- **大图景位置**：Ringel 对偶是拟遗传代数理论中的核心概念，Burt-Butler 对偶则来自倾斜理论。两者看似独立，但都涉及某种"对偶运算"——本文证明两者可以通过 Frobenius coring 结构和自对偶 coring 的概念在一个范畴论框架中统一理解。
- **主要贡献**：
  1. 证明有限维代数 A 上的 coring C 满足 C ≅ {}_{A}\operatorname{Hom}(C,A)_A 当且仅当 C 是 Frobenius coring（定理 2.1），赋予自对偶 coring 以 Frobenius 代数结构。
  2. 用此框架比较 Ringel 自对偶与 Burt-Butler 自对偶：将 Burt-Butler 双模实现为某个 canonical coring，证明 Ringel 自对偶成立当且仅当该 coring 是 Frobenius coring（定理 3.1）。
  3. 刻画了标准分层代数的正则精确 Borel 子代数：若 B 是 A 的 Frobenius 扩张，则 A 必为半单代数（定理 3.5）。
- **关键先驱工作**：Koenig-Külshammer-Ovsienko 关于拟遗传代数和 Ringel 对偶的工作；Brzeziński-Wisbauer 的 coring 理论；Hirata 关于 Frobenius 扩张的定理。
- **结果边界**：定理 3.5 对拟遗传代数的正则精确 Borel 子代数成立，但并非所有拟遗传代数都拥有正则精确 Borel 子代数。
- **开放问题**：对于没有正则精确 Borel 子代数的拟遗传代数，是否有其他 coring 结构可以编码 Burt-Butler 对偶？
- **应用与推广**：该框架可用于分类两两 Morita 等价的基本代数之间的对偶关系，并在高阶 Auslander-Reiten 理论（n-拟遗传代数）中推广 Ringel 自对偶的判别条件。

## 📐 主要定理

> **Theorem 2.1**: Let C be an A-coring over a finite-dimensional algebra A. Then C is a Frobenius coring (i.e., C is finitely generated projective as a left A-module and C ≅ {}^*C as A-bimodules) if and only if C is a self-dual coring.

> **Theorem 3.1**: Let A be a quasi-hereditary algebra with a regular exact Borel subalgebra B. The Burt-Butler bimodule defines an A-coring C_{BB}. Then A is Ringel self-dual if and only if C_{BB} is a Frobenius coring.

> **Theorem 3.5**: Let A be a standardly stratified algebra with a regular exact Borel subalgebra B. If B⊆A is a Frobenius extension, then A is semisimple (equivalently, A = B).

### 证明思路

- 第一步：构造 coring C 到其对偶 {}^*C = \operatorname{Hom}_A(C,A) 的典范映射，利用有限维性和投射性建立自对偶与 Frobenius 条件之间的等价。
- 第二步：对 Burt-Butler 双模做 coring 构造，验证其作为 A-coring 的自对偶性恰等价于 Ringel 自对偶条件——将双模对偶转化为 coring 的对偶。
- 第三步：利用 Hirata 定理（Frobenius 扩张的 separability 判别）证明在正则精确 Borel 子代数情形下，B 的 Frobenius 扩张性质强制 A 半单。

## 🔑 关键组件

### 关键引理

> **Lemma 2.3**: A finitely generated projective left A-module P is a Frobenius coring if and only if the regular representation A is a direct summand of P⊗_A P as A-bimodules. — *[基于 Hirata 定理]*

### 关键定义

> **Definition 2.1 (Self-dual coring)**: An A-coring C is self-dual if there exists an A-bimodule isomorphism C ≅ {}^*C = \operatorname{Hom}_{A}(C,A), where the A-bimodule structure on {}^*C is induced by the coring comultiplication.
> **动机**：此概念从 Frobenius 代数的自对偶性抽象而来——Frobenius 代数的一个等价定义是 A ≅ \operatorname{Hom}_k(A,k) 作为 A-双模。将这一概念推广到 coring，自对偶 coring 自动携带 Frobenius 结构。

## 💡 理解辅助

- **贯穿例子**：论文以 path algebra kQ/I 的典范 coring 为引导例子：当 Q 是线性定向 A_n 箭图时，Burt-Butler 双模显式可计算，此时 coring C_{BB} 是否 Frobenius 直接对应于 A 是否 Ringel 自对偶。

### 批判性思考

- 定理 2.1 中左 A-投射性条件是关键：有限维代数上并非所有 coring 都左 A-投射，因此自对偶 coring 自动暗含的投射性实际上是一个很强的约束。
- 定理 3.5 将"B 是 Frobenius 扩张"推至"A = B"的证明使用了 Hirata 定理，该定理要求极为特定的 separability 条件。正则精确 Borel 子代数是否总是 separable over B？若不是，是否存在非半单的反例？
