# A Comment On Topological Degeneracy In Gauged WZW Models

keywords: [gauged WZW model, GKO coset construction, topological degeneracy, commutative Frobenius algebra, End(B), common center]
related_paper: "Correspondences of ribbon categories (arXiv:math/0309465, FFRS03b)"
one_liner_summary: 本文证明在 $Z$-regular 条件下，规范化的 WZW 模型 $WZW(G,H;k)$ 的态空间同构于 GKO coset 态空间与 $End(B)$（$B$ 为模范畴中的代数对象，$End(B)$ 是交换 Frobenius 代数）的完备化张量积，从而把拓扑简并度精确刻画为共同中心 $Z$ 的群代数 $\mathbb{C}[Z]$，并给出若干具体例证与一般猜想。

## 1.  🎯 核心定位

- **解决的问题**：阐明 gauged WZW 模型 $WZW(G,H;k)$（与 GKO coset 构造）中拓扑简并的来源与大小：态空间因子的"额外简并因子"到底是什么、何时出现、由什么数据决定。
- **大图景位置**：把 GKO 余集构造（Goddard–Kent–Olive）与 2d TFT 的 Frobenius 代数语言（Fuchs–Runkel–Schweigert 系列）对接，给出"真空扇区 = GKO 真空扇区 $\widetilde{\otimes}$ 2d TFT $End(B)$"的精确陈述，是弦论中 gauged WZW 模型研究的一个定量注记。
- **主要贡献**：① 证明主定理 $\mathscr{H}^{\mathrm{WZW}}_{G/H}\cong\mathscr{H}^{\mathrm{GKO}}_{\mathfrak{g}/\mathfrak{h}}\,\widetilde{\otimes}\, End(B)$（$Z$-regular 情形）；② 识别 $End(B)\cong\mathbb{C}[Z]$（$Z$ 为共同中心），即拓扑简并度等于 $|Z|$；③ 通过最小模型、parafermion、共形嵌入（含 $G/G$ 模型与 Maverick coset）等大量例子验证并推广猜想。
- **关键先驱工作**：GKO coset 构造（Goddard–Kent–Olive）；Fuchs–Runkel–Schweigert 的 2d TFT 与代数对象理论（FFRS03a, FFRS03b, arXiv:math/0309465）；拓扑简并与 Ishibashi 态、场等同（field identifications）与选择定则（selection rules）的既有讨论。
- **结果边界**：主定理要求 $H<G$ 为连通、单连通、紧李群对且 $V(G,H;k)$ 是 $Z$-regular（共同中心作用无不动点等条件）；同构对 $\bmu\neq 0$ 不自然（仅保持 rank-1 free $\mathbb{C}[G_{\mathrm{id}}]$-module 结构）；非 $Z$-regular 与 $H$ 非单连通情形需靠猜想与特例验证。
- **开放问题**：作者明确提出猜想：对任意紧李群对 $H<G$，$WZW(G,H;k)\cong GKO(G,H;k)\,\widetilde{\otimes}\,End(B)$，其中 $B$ 是 $\mathcal{C}(G;k)\boxtimes_D\mathcal{C}^{\mathrm{opp}}(H;\tilde{k})$ 中的代数对象；非 $Z$-regular 情形下 $End(B)$ 的完整刻画尚待给出。
- **应用与推广**：为弦论中的拓扑简并（如弦耦合下的有限重正化、2d YM 红外相、零形式与一形式对称由 $End(B)$ 拓扑点算子给出）提供精确的数学表述；$End(B)$ 的 Frobenius 代数结构可直接用于计算环面配分函数的多重因子。

## 2.  📐 主要定理

> **Theorem (main_thm)**: "Let $H < G$ be a pair of connected, simply-connected, compact Lie groups such that $V(G,H;k)$ is $Z$-regular, then  
> $$\mathscr{H}^{\mathrm{WZW}}_{G/H}\cong \mathscr{H}^{\mathrm{GKO}}_{\mathfrak{g}/\mathfrak{h}} \, \widetilde{\otimes}\, \mathrm{End}(B)~,$$  
> where $B$ is the algebra object defined in \eqref{eq:B_def_affine} and $\mathrm{End}(B)$ is endowed with the commutative Frobenius algebra structure."

> **Conjecture**: "Let $G,H$ be any pair of compact Lie groups with $H< G$. Then we have $WZW(G,H;k)\cong GKO(G,H;k)\,\widetilde{\otimes}\, End(B)$, where $B$ is an algebra object in the category $\mathcal{C}(G;k)\boxtimes_D\mathcal{C}^{\mathrm{opp}}(H;\tilde{k})$."

### 2.1.  证明思路

- 第一步：把 gauged WZW 态空间按 GKO 分支函数分解为 $\bigoplus_{(\boldsymbol{\lambda},\boldsymbol{\mu})\in\mathcal{E}}\left(\mathbb{C}^{n_{(\boldsymbol{\lambda},\boldsymbol{\mu})}}\otimes\widetilde{\mathbb{C}}^{n_{(\boldsymbol{\lambda},\boldsymbol{\mu})}}\right)\otimes\mathbb{C}|\boldsymbol{\mu}\rangle\!\rangle$，其中 $|\boldsymbol{\mu}\rangle\!\rangle$ 为 Ishibashi 态，指数集合 $\mathcal{E}$ 由选择定则与场等同确定。
- 第二步：构造代数对象 $B$（沿共同中心求和的自同构对象，$B=L(G;k,0)\boxtimes_D L^{\mathrm{opp}}(H;\tilde{k},0)\oplus\cdots$），并证明 $End(B)$ 携带交换 Frobenius 代数结构（乘法与 Frobenius 迹由公式给出）。
- 第三步：在 $Z$-regular 条件下证明 $End(B)\cong\mathbb{C}[Z]$（$Z$ 为共同中心），并通过真空扇区的逐项比较得出态空间同构；非真空扇区则是 rank-1 free $End(B)$-模。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma ($Z$-regular 刻画)**: $V(G,H;k)$ 为 $Z$-regular 当且仅当共同中心 $Z$ 在指数集上的作用无不动点（fixed-point-free）；此时场等同恰好由 $Z$ 的作用给出，拓扑简并等于 $|Z|$。 — *[文中以枚举形式给出；例：$SU(2)_k\times SU(2)_1/SU(2)_{k+1}$ 的 $Z=\mathbb{Z}_2$]*

### 3.2.  关键定义

> **Definition ($B$ 与 $End(B)$)**: $B$ 是 $\mathcal{C}(G;k)\boxtimes_D\mathcal{C}^{\mathrm{opp}}(H;\tilde{k})$ 中的代数对象（对共同中心求和得到），$End(B)$ 是 $B$ 的自同态代数，带交换乘法与 Frobenius 迹，构成一个 2d TFT。
> **动机**：$End(B)$ 精确编码了 gauged WZW 相对 GKO 的"拓扑简并因子"；它是交换 Frobenius 代数意味着该因子对应一个平凡的 2d TFT，从而把拓扑简并从动力学内容中分离出来。

## 4.  💡 理解辅助

- **贯穿例子**：① 幺正最小模型 $G=SU(2)_k\times SU(2)_1,\ H=SU(2)_{k+1}$（$k=1$ 即 Ising 模型）：$\mathscr{H}^{\mathrm{WZW}}_{G/H}$ 显式写成 Virasoro 模与 Ishibashi 态的张量积，拓扑简并 $End(B)\cong\mathbb{C}[\mathbb{Z}_2]$；② $G=Spin(4n)_1,\ H=Sp(n-1)_1\times SU(2)_1\times SU(2)_n$（$n=2$ 亦为 Ising）：简并为 $\mathbb{C}[\mathbb{Z}_2\times\mathbb{Z}_2]$；③ parafermion $G=SU(2)_k,\ H=U(1)_k$：虽 $H$ 非单连通，仍有 $End(B)\cong\mathbb{C}[\mathbb{Z}_2]$；④ 共形嵌入（含 $G/G$ 模型）：$End(B)\cong V_k(G)$（Verlinde 代数），给出 $\mathscr{H}^{\mathrm{WZW}}_{G/H}\cong End(B)$。

### 5.1.  与其他工作的联系

- 这让我想起：Fuchs–Runkel–Schweigert 的 2d TFT 与模张量范畴框架，以及 Verlinde 代数在 $G/G$ gauged WZW 中的角色 — 见 [[2608.11193]]
- [[2608.11193]]：该笔记处理模张量范畴（MTC）的高阶同调结构，与本文的 $\mathcal{C}(G;k)\boxtimes_D\mathcal{C}^{\mathrm{opp}}(H;\tilde{k})$ 及 $End(B)$ 代数对象属同一数学对象谱系。
- [[2608.10585]]：Verlinde 范畴中的结构对象与 $G/G$ 模型 $End(B)\cong V_k(G)$ 中的 Verlinde 代数直接相关。
- 技术迁移：把"态空间 = GKO 态空间 $\widetilde{\otimes}$ 2d TFT"这一分解模式推广到其他 coset 类模型（如 parafermion 之外的 $\mathcal{W}$-代数模型），可能给出拓扑简并的系统刻画。

### 5.2.  可以尝试的方向

- [ ] 能否把 $End(B)\cong\mathbb{C}[Z]$ 的证明推广到 $H$ 非单连通（parafermion 类）的一般情形？

### 5.3.  批判性思考

- 主定理的同构对 $\bmu\neq 0$ 不自然，作者用"rank-1 free $\mathbb{C}[G_{\mathrm{id}}]$-module"（群的 torsor 类比）处理，这是否掩盖了某个更深层的模范畴结构（如模块范畴的等价而非仅向量空间同构）值得追问。
- $Z$-regular 条件的作用在证明中至关重要，但其物理意义（共同中心无不动点）与文献中"场等同可一致地实现"的假设之间的一致性未见系统讨论。
