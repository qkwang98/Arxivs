# Scopes equivalence for blocks of Ariki-Koike algebras

keywords: [Ariki-Koike algebras, Scopes equivalence, moving vector, pyramid numbers, Specht modules, blocks]
related_paper: "Li–Qi–Tan, Core blocks of Ariki–Koike algebras (LQT); Uglov 的 canonical basis / $\ell$-partition 理论"
one_liner_summary: 对 Ariki–Koike 代数 $\mathcal{H}_n$ 的块给出 Scopes 等价的完全分类判据：两个块 Scopes 等价当且仅当它们有相同的 Scopes vector 与相同的 pyramid numbers，并显式刻画 Specht 模在此等价下的对应规则。

## 1.  🎯 核心定位

- **解决的问题**：对 Ariki–Koike 代数 $\mathcal{H}_n$（带 $e$-根单位 $\br$ 与参数 $\ell$）的块，给出 Scopes 等价（沿减分支/加分支移动产生的 Morita 等价）的完全分类——这是 Ariki 层等价理论与 RoCK 块理论的组成部分。
- **大图景位置**：Ariki–Koike 代数是 Iwahori–Hecke 代数的多参数广义化，其块论（特别是核心块与 RoCK 块）是量子群表示与顶点算子代数的桥梁。Scopes 等价是 Ariki 层等价（crystal 算子）在块水平上的 Morita 形式。
- **主要贡献**：①把 Scopes 等价分解为"移动向量（moving vector）等价 + 同一 $\mathcal{AW}_e$-轨道"两个层级，给出等价条件 (1)-(3) 的精细刻画（Thm T:equiv1）；②主定理 T:Scopes：块 $B,C$ Scopes 等价 $\Leftrightarrow$ 有相同 Scopes vector 与 pyramid numbers，且给出 Specht 模对应准则 $(\bl^{*})^{\sigma_B}=(\bm^{*})^{\sigma_C}$；③推论 C 用 moving vector、Scopes vector 与 pyramid numbers 三个组合不变量完全决定 Scopes 等价类。
- **关键先驱工作**：Uglov 的 $\ell$-partition / canonical basis；Li–Qi–Tan 对核心块（$m_B=0$）的分类；Ariki 对块层等价的工作；Scopes 在对称群块上的原始等价定理。
- **结果边界**：$m_B=0$ 的情形由 [LQT, Thm 4.24] 覆盖（此时 pyramid numbers 全为 0），本文主定理处理 $m_B>0$ 情形；等价判据是组合的（Scopes vector + pyramid numbers），但并未显式构造等价函子。
- **开放问题**：给出 Scopes 等价的显式函子构造；把分类推广到带循环参数 $\ell$ 与 $e$-根单位 $\br$ 更一般的 $(e,\br)$-块。
- **应用与推广**：Scopes 等价类与 $\mathcal{AW}_e$-轨道一一对应（moving vector 决定轨道），可用于计算块的 Grothendieck 群与 decomposition numbers 的约化；与 RoCK 块理论结合可研究平凡源模与 Specht 模的对应。

## 2.  📐 主要定理

> **Theorem (T:Scopes)**: Let $B$ be a block of $\mathcal{H}_n$ with $m_B>0$, and let $C\in\mathcal{AW}_e\cdot B$. Then $B$ and $C$ are Scopes equivalent if and only if they have the same Scopes vector and the same pyramid numbers, in which case the Specht module $\mathsf{S}^{\bl}$ lying in $B$ corresponds to the Specht module $\mathsf{S}^{\bm}$ lying in $C$ if and only if $(\bl^{*})^{\sigma_B}=(\bm^{*})^{\sigma_C}$.

> **Theorem (T:equiv1)**: 设 $B$ 为 $\mathcal{H}_n$ 的块，$j\in\mathbb{Z}/e\mathbb{Z}$。以下条件等价：(1) 存在 $x\in[x_j^B+(m_B+\delta_{j0})\ell,\ x_{j+1}^B]$ 且 $x\equiv_\ell i$（某 $i\in\mathsf{I}_B$）；(2) $y_{j+1}^B-y_j^B-\delta_{j0}+\mathbf{1}_{z_j^B\leq\mathsf{Ht}_{\mathsf{I}_B}(z_{j+1}^B)}\geq m_B+1$；(3) $B\xrightarrow{j}\mathsf{c}_j\cdot B$，即 $B$ 中所有 $\ell$-partition 都没有 $(e,\br)$-residue $j$ 的可加节点。

> **Corollary (C:)**: $B$ 与 $C$ Scopes 等价当且仅当 $B,C$ 有相同的 moving vector、相同的 Scopes vector 与相同的 pyramid numbers。

### 2.1.  证明思路

- 第一步：建立组合框架——用 $\bij_{\ell,e}$（Uglov 双射）、$w_0$、$(\bl;\br)^{w_0}$ 编码 $\ell$-partition 与 abacus/$\beta$-set 数据，定义移动向量、Scopes vector 与 pyramid numbers（Definition D、D:pyramid、D:Scopes-initial）。
- 第二步：证明"Scopes 等价 $\Rightarrow$ 相同 Scopes vector/pyramid numbers"（Cor C:Scopes 与 P:Scopes 的反向链），以及必要性由层等价沿链跟踪 $\sigma$ 参数得到。
- 第三步：充分性——把 $B,C$ 分别 Scopes 等价到 Scopes-initial 块 $B_0,C_0$，用 P:unique（Scopes-initial 块由 Scopes vector + pyramid numbers 唯一确定）得到 $B_0=C_0$；Specht 模对应由 $\sigma_C=\overline{\mathsf{c}_{j_k}}\cdots\overline{\mathsf{c}_{j_1}}\sigma_B$ 的追踪与 Lemma L:cs_j 完成。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma (L:cs_j)**: 对 $j$ 的可加节点运算 $\mathsf{c}_j$，其诱导的 $\sigma$-参数变换满足 $\sigma_{\mathsf{c}_j\cdot\by}=\overline{\mathsf{c}_j}\sigma_{\by}$（对 abacus 的 Weyl 群作用），且 $\bij_{\ell,e}$ 与 $\mathsf{c}_j$ 在适当意义下交换。
> **Proposition (P:unique)**: 若 $B_0,C_0$ 为 Scopes-initial 块且具有相同 Scopes vector 与 pyramid numbers，则 $B_0=C_0$。

### 3.2.  关键定义

> **Definition (moving vector / Scopes vector / pyramid numbers)**: moving vector 是块在 $\mathcal{AW}_e$-轨道下的规范参数（决定轨道）；Scopes vector 与 pyramid numbers 是决定块在同轨道内 Scopes 等价类位置的组合不变量，后两者对 $m_B=0$ 时退化为平凡值。
> **动机**：这三个不变量把抽象的块等价翻译成纯组合条件，使分类可机械验证。

> **Definition (Scopes equivalence)**: 块 $B$ 与 $C$ 称为 Scopes 等价，若存在块链 $B=B_0,\dots,B_k=C$ 使相邻块沿某个 residue $j$ 的减/加分支移动，且所有 $\ell$-partition 在移动前或移动后没有该 residue 的可加节点（即无分支合并情形）。
> **动机**：Scopes 等价保持块的 Morita 型结构与 Specht 模的分布，是研究块稳定性的标准等价关系。

## 4.  💡 理解辅助

- **贯穿例子**：对对称群（$e=1$ 或取 $\br$ 退化）情形，moving vector 退化为经典 Scopes 等价中的轨道参数，本文判据重现 Scopes 原始定理；对一般 $(e,\br)$，Thm T:equiv1 的条件 (2) 把"无 residue $j$ 可加节点"翻译为坐标不等式，可直接用于计算机验证。
