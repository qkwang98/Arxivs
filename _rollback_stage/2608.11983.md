# Modules over the Takiff Block type Lie algebra

keywords: [Takiff type Lie algebra, Block type Lie algebra, U(h)-free modules, non-weight modules, simple modules]
related_paper: "Chen–Guo, Non-weight modules over the Heisenberg-Virasoro algebra and the W algebra W(2,2), J. Algebra Appl. 16(5) (2017)"
one_liner_summary: 给出 Takiff Block 型李代数 $\mathcal{B}(q)$ 上秩一 $U(\mathfrak h)$-自由模的完全分类，用参数 $(\lambda,\alpha,\beta,\gamma,\mathbf h(\alpha))$ 显式构造全部互不同构的单模并给出单性判据。

## 🎯 核心定位

- **解决的问题**：对单参数族 Takiff Block 型李代数 $\mathcal{B}(q)$（$q\in\mathbb C$，含 Block 型代数 $L(q)$ 的 Takiff 化），完全分类秩一 $U(\mathfrak h)$-自由模，其中 $\mathfrak h=\mathbb C L_{0,0}\oplus \mathbb C W_{0,0}$。
- **大图景位置**：这是非权重模理论在 Takiff 化代数上的自然延伸——Nilsson 引入 $U(\mathfrak h)$-自由模，Chen–Guo 分类了 $W(2,2)$ 代数上的对应模类；本文将 $W(2,2)\subset\mathcal{B}(q)$ 的模论结果整体推广到更大的 Takiff Block 型代数。
- **主要贡献**：①当 $-2q\notin\mathbb N$、$-2q\in\mathbb N, q\neq -1$ 与 $q=-1$ 三种情形下分别显式构造模 $\Omega(\lambda,\alpha,\mathbf h)$、$\Omega(\lambda,\alpha,\gamma,\mathbf h)$、$\Omega(\lambda,\alpha,\beta,\gamma,\mathbf h(\alpha))$；②证明同构判据（参数完全决定模，Proposition 3.2）；③给出单性判据（Theorem 3.5）：$\alpha\neq 0$ 或 $q=-1,\beta_1\neq 0$。
- **关键先驱工作**：Nilsson 的 $U(\mathfrak h)$-自由模框架；Chen–Guo (CG17) 对 $W(2,2)$ 上非权重模的分类；$W$-代数 $W(2,2)$ 的 Whittaker 型模理论。
- **结果边界**：分类限于秩一 $U(\mathfrak h)$-自由模；对 $q$ 的例外值（$q=-1$ 及 $-2q\in\mathbb N$）需要额外参数 $\beta,\gamma$，且单性判据出现例外族。
- **开放问题**：文中以 $U(\mathfrak h)$-自由模理论为基础，更高秩的 $U(\mathfrak h)$-自由模分类、以及 $\mathcal{B}(q)$ 上更一般的非权重模族的分类仍是开放方向。
- **应用与推广**：$\mathcal{B}(q)$ 包含 $W(2,2)$ 作为子代数，其模论结果可限制回 $W(2,2)$；Takiff 构造与其他 Block 型/广义 Virasoro 代数的组合可用同一套"参数化 + 同构/单性判据"的框架处理。

## 📐 主要定理

> **Theorem 3.5**: For any $\lambda\in\mathbb{C}^*$, $\alpha\in\mathbb{C}$, $\beta=(\beta_1,\beta_2)\in\mathbb{C}^{2}$, $\gamma=(\gamma_1,\gamma_2)\in \mathbb{C}^{2}$, $\mathbf{h}(\alpha)\in \mathcal T_\alpha$, $\Omega(\lambda,\alpha,\beta,\gamma,\mathbf h(\alpha))$ is simple if and only if $\alpha\neq 0$ or $q=-1$ and $\beta_{1}\neq 0$.

> **Proposition 3.2** (同构判据): $\Omega(\lambda,\alpha,\mathbf{h})\cong \Omega(\lambda_{1},\alpha_{1},\mathbf{h}_{1})$ if and only if $\lambda=\lambda_{1},\alpha=\alpha_{1}$ and $\mathbf{h}=\mathbf{h}_{1}$. $\Omega(\lambda,\alpha,\gamma,\mathbf{h})\cong \Omega(\lambda_{1},\alpha_{1},\gamma^{'},\mathbf{h}_{1})$ if and only if $\lambda=\lambda_{1},\alpha=\alpha_{1},\gamma=\gamma^{'}$ and $\mathbf{h}=\mathbf{h}_{1}$. $\Omega(\lambda,\alpha,\beta,\gamma,\mathbf h(\alpha))\cong \Omega(\lambda_{1},\alpha_1,\beta^{'},\gamma^{'},\mathbf h_{1}(\alpha_1))$ if and only if $\lambda=\lambda_{1},\alpha=\alpha_{1},\gamma=\gamma^{'},\beta=\beta^{'}$ and $\mathbf{h}=\mathbf{h}_{1}$.

### 证明思路

- 第一步：利用包含 $W(2,2)\cong \mathcal W\subset\mathcal B(q)$ 的结构，把 $\mathcal{B}(q)$ 的作用写成 $\mathbb C[t,s]$ 上的显式作用公式（见 (action) 式），其中 $s=L_{0,0}\cdot 1,\ t=W_{0,0}\cdot 1$，并引入参数化多项式 $\mathbf h=(h_m(t))$ 与 $\Theta_{\mathbf h,\beta_1}(t)$。
- 第二步：同构判据通过对生成元 $W_{0,1},L_{0,1},W_{0,-2q},L_{0,-2q}$ 的作用逐参数比对证明；单性判据分 $\alpha\neq 0$（沿用 CG17 命题 3.1）与 $\alpha=0$（取非零子模中关于 $s$ 次数最小的多项式 $f(t,s)$，借助 $f(t,s+m)$ 的平移论证化归到 $f(t)\in\mathbb C[t]$，再用 $L_{m,1}$ 作用导出 $f'(t)\in N$，最终迫出 $N=\mathbb C[t,s]$）。
- 第三步：在 $\alpha=\beta_1=0$ 时构造 $t^{i}\mathbb C[t,s]$ 作为真子模，证明模非单，从而完成"当且仅当"的闭环。

## 🔑 关键组件

### 关键引理

> **Theorem 2.3 (th2.3, 引自 CG17 在 $\mathcal W$ 上的推广)**: 给出了 $\mathcal W=W(2,2)$ 上秩一 $U(\mathfrak h)$-自由模的作用公式，本文 (action) 式即其向 $\mathcal B(q)$ 的延拓。 — *[引用自 CG17]*

### 关键定义

> **Definition (秩一 $U(\mathfrak h)$-自由模)**: 设 $\mathfrak h=\mathbb C L_{0,0}\oplus\mathbb C W_{0,0}$，模 $M$ 称为秩一 $U(\mathfrak h)$-自由模，若 $M\cong \mathbb C[t,s]$（作为 $U(\mathfrak h)$-模由单一生成元生成且无关系）。
> **动机**：这一模类是 Whittaker 模与权重模之间的重要桥梁，刻画了代数上"最自由"的一类非权重表示；对 $\mathcal{B}(q)$ 而言它绕开了中心元 $C_1,C_2$ 的刚性限制，能覆盖更丰富的表示现象。

> **Definition (参数化函数族 $\mathcal T_\alpha$)**: 用于编码模结构中的多项式参数 $\mathbf h(\alpha)=(h_m(t))_{m\in\mathbb Z}$，其具体形式决定 $\mathbb C[t,s]$ 上 $L_{m,0}$ 的作用；当 $-2q\notin\mathbb N$ 时 $\beta,\gamma$ 相关项消失，出现简并记号 $\Omega(\lambda,\alpha,\mathbf h)$ 与 $\Omega(\lambda,\alpha,\gamma,\mathbf h)$。
> **动机**：参数的引入使得同一"形状"的模可以携带不同的多项式数据，而同构判据恰好表明这些参数是模的完全不变量。

## 💡 理解辅助

- **贯穿例子**：取 $q$ 的一般值（$-2q\notin\mathbb N$），模族 $\Omega(\lambda,\alpha,\mathbf h)$ 由三个参数完全确定且全部单（因 $\alpha\neq 0$ 或退化情形）——这是最简单的"干净"情形；当 $q=-1$ 时出现 $\beta_1$ 参数，且 $\alpha=\beta_1=0$ 时模恰有真子模族 $t^{i}\mathbb C[t,s]$，直观展示了例外参数如何破坏单性。

### 批判性思考

- 同构判据的证明本质上依赖对有限个特殊生成元作用的比对，其完备性依赖 $\mathcal{B}(q)$ 的表示结构是否由这些生成元完全控制，读者需注意该判据仅在秩一 $U(\mathfrak h)$-自由模这一特殊模类内成立。
- 单性判据在 $q=-1$ 时出现例外，说明参数空间中存在"临界值"现象，这暗示 $\mathcal{B}(q)$ 在不同 $q$ 值处的表示论行为有本质差异。
