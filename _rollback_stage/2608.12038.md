# Towards Koszulity for categorical structures: category of 2-nets

keywords: [operadic categories, Koszul duality, 2-nets, 2-trees, locally constant maps, elementary maps]
related_paper: "Batanin–Markl 的一般 operadic category 上的 Koszul 对偶（Ginzburg–Kapranov 精神）; Batanin 的 n-trees 与 categorical structures; Markl 的 dendroidal 理论"
one_liner_summary: 构造 locally constant $2$-nets 的范畴 $2\mathsf{Net}$：它是包含 $2$-trees 为全子范畴的 operadic category，且每个映射可分解为初等映射链，从而克服 Batanin–Markl 的 Koszul 对偶理论向 $2$-trees 推广时遇到的主要困难。

## 1.  🎯 核心定位

- **解决的问题**：Batanin–Markl 在 Ginzburg–Kapranov 精神下发展了"一般 operadic category 上的 operad 的 Koszul 对偶"理论，但其方法不直接适用于描述 categorical structures 的 $n$-trees 的 operadic category（如 2-trees）；本文构造 locally constant $2$-nets 范畴来消解这一推广障碍。
- **大图景位置**：Koszul 对偶是代数（operad 与代数结构）同调论的基石；把 Ginzburg–Kapranov 型对偶从树状图推广到更一般的 categorical 图（2-trees）是 operadic 范畴理论的前沿。2-nets 的 operadic 结构使 2-trees 以全子范畴嵌入，为 categorical Koszul 性提供新的工作对象。
- **主要贡献**：①定义（locally constant）2-nets 范畴 $2\mathsf{Net}$、$2\mathsf{Net}^{\mathsf{ulc}}$，并证明其是 operadic category；②定理 J：嵌入 $J\colon(2\mathsf{Tree}, \mathsf{Epi}_1)\to 2\mathsf{Net}$ 完全忠实，$2$-trees 构成全子范畴；③thm_net_homs：$\mathsf{Hom}_{2\mathsf{Net}}(S,T)\cong\mathsf{colim}_{\tilde S\in W(S)}\pi\mathsf{Hom}(\tilde S, m(T))$，hom 集可约化到 minimal prenet 的弱等价类；④thm_factor_elem：locally constant $2$-nets 间每个映射可分解为初等映射（tassel collapse / vertex collapse 链）；⑤ULC 变体 thm_ulcnet_homs 与特殊 prenet 局部化等价 cor_comp_special。
- **关键先驱工作**：Batanin–Markl 的 operadic category Koszul 对偶；Batanin 的 $n$-trees 与 $n$-operads；Ginzburg–Kapranov 的 Koszul 对偶经典理论；Baez–Dolan 的 higher operads 图景。
- **结果边界**：本文解决"范畴结构"（2-trees）层面的主要困难；Koszul 对偶本身在 2-nets 上的完整展开（bar/co-bar、Koszul 判定）留给后续；weak blow-up 公理在 2-nets 上不成立，这是引入 locally constant 条件的原因。
- **开放问题**：在 $2\mathsf{Net}$ 上建立 Batanin–Markl 式的完整 Koszul 对偶（需处理 weak blow-up 的替代物）；$q$-tassels 的细粒度版本与 lifting 的非函子性修复的进一步应用。
- **应用与推广**：2-nets 的 hom 集 colim 公式为 categorical operad 的表示/模理论提供计算入口；初等分解定理把任意映射约化到两种 collapse，利于归纳论证与胞腔结构研究。

## 2.  📐 主要定理

> **Theorem (thm_net_homs)**: For any two $2$-nets $S,T$, there is an isomorphism
> $$\mathsf{Hom}_{2\mathsf{Net}}(S,T)\cong\mathsf{colim}_{\tilde S\in W(S)}\pi\mathsf{Hom}(\tilde S, m(T)),$$
> where $m(T)$ denotes the minimal prenet of $T$, $W(S)$ the poset of weak equivalences over $S$, and $\pi\mathsf{Hom}$ the set of path components.

> **Theorem (thm_factor_elem)**: Let $f\colon S\to T$ be a map in the category of locally constant $2$-nets. Then there exists a factorization
> $$S\xrightarrow{f^{(1)}} S^{(1)}\xrightarrow{f^{(2)}}\cdots\xrightarrow{f^{(n)}} S^{(n)}=T$$
> such that each map $f^{(i)}$ is elementary (a tassel collapse or a vertex collapse).

> **Theorem (J is fully faithful)**: The embedding $J\colon(2\mathsf{Tree},\mathsf{Epi}_1)\to 2\mathsf{Net}$ is fully faithful, realizing $2$-trees as a full subcategory of $2$-nets.

> **Theorem (thm_ulcnet_homs)**: In the locally constant category, $\mathsf{Hom}_{2\mathsf{Net}^{\mathsf{ulc}}}(S,T)\cong\mathsf{colim}_{\tilde S\in W(S)}\pi^\circ\mathsf{Hom}(\tilde S,m(T))$; the localization $K^s\colon 2\mathsf{PreNet}^{\mathsf{ulc},s}[W^{-1}]\to2\mathsf{Net}^{\mathsf{ulc},s}$ is an equivalence.

### 2.1.  证明思路

- 第一步：构造与基本性质——定义 prenet（带全序与 parent 映射）、带 tassel 的 prenet、weak equivalence（同伦条件 (a)(b)），通过"装配过程"（assembly, prop_assembly）把 fiber prenet 数据粘合成新的 prenet，从而得到 2-nets 及其映射；证明 $2\mathsf{Net}$ 的 operadic 结构（纤维化/张量积与截面构造），并验证 $J$ 完全忠实。
- 第二步：hom 集 colim 公式——对 $S\to T$ 用 ULC 代表元 $\tilde S\to T$，把映射等价类编码为 minimal 化 $m(T)$ 上的路径分量，再对 $S$ 的弱等价闭包取 colim；ULC 版本用 fiber 良定义性与 $K^s$ 等价（cor_comp_special）完成。
- 第三步：初等分解——对 ULC 映射 $\tilde f\colon\tilde S\to T$（$T$ minimal），固定 core vertices 的序，用 lemma_map_factor 先做 vertex collapse，再用 prop_lift 沿 tassel collapse 提升（处理非函子性），逐一证明装配出的 $h$ 为 ULC 且 elementary、$g$ 为 ULC，迭代减少非平凡 fiber 数直至 $T$。

## 3.  🔑 关键组件

### 3.1.  关键引理

> **Lemma (lemma_map_factor / lemma_tc_factor / lemma_vc_factor)**: 每个（ULC）映射可分解为"tassel collapse + vertex collapse"的合成；fiber prenet 上的唯一分解给出初等步骤的候选。
> **Lemma (lifting, prop_lift)**: 沿 tassel collapse $u\colon\tilde T\to T'$ 的映射 $f'\colon\tilde S\to T'$ 可提升为 $\tilde f'\colon\tilde S'\to\tilde T$（具规范结构），这是分解迭代的关键工具（也解释了为何需要 $q$-tassels 修复非函子性）。

### 3.2.  关键定义

> **Definition (prenet / 2-net / locally constant)**: 高度 $n$ 的 prenet 是全序有限集列 $\{S_0,\dots,S_n\}$ 与映射 $p_i\colon S_i\to\mathsf{Int}(S_{i-1})$（映到区间）；带 tassel 的 prenet 把顶点分为 core 与 tassel；2-net 是由 prenet 按 weak equivalence 局部化得到的范畴对象；映射 $f$ 为 locally constant（ULC）若 fiber 的 parent 结构满足"相容接口"条件（对每个 tassel collapse 存在规范 retraction）。
> **动机**：prenet 的区间结构编码 2-树的"分支+顺序"，tassel 提供 collapse 的柔软性，locally constant 条件替代失效的 weak blow-up 公理。

> **Definition (elementary map)**: tassel collapse（把 tassel 并入相邻 core）与 vertex collapse（把 fiber 收缩为一点）的合成。
> **动机**：初等映射是分解定理的基本砖块，类似单纯集范畴中的初等 collapse，为胞腔/归纳论证提供基础。

## 4.  💡 理解辅助

- **贯穿例子**：exa_factor_elem 展示了对一个具体 2-net 映射的初等分解过程：先在 core vertex $z$ 上加 tassel 做提升、再逐 fiber 收缩，最终得到 $f^{(1)},\dots,f^{(n)}$ 的链——直观上是"先展开、再逐层压扁"。
- **贯穿例子**：$m(T)$ 的 minimal 化把 hom 集计算化为"只看最小代表元"，colim 公式在 2-trees 情形退化为 $\mathsf{Hom}$ 的路径分量——与经典树范畴的 hom 集结构类比。

### 5.3.  批判性思考

- 本文的"解决主要困难"限于构造层面：Koszul 对偶本身的展开（bar 构造收敛、Koszul 判定）尚未给出，标题"Towards"即此意。
- thm_factor_elem 的证明高度依赖 $T$ minimal 与 core vertex 的固定序；当 $T$ 不 minimal 或存在多 tassel 相邻时，$h$ 为 ULC 的论证需要逐个情形检查（文中三情形分类），读者应核对"相容接口"条件在装配后的保持性。
