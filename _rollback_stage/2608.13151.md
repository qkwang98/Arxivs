# The q-model category of multipointed d-spaces is not left proper

keywords: [directed algebraic topology, multipointed d-space, execution path, model category, left properness, globular cell]
related_paper: "P. Gaucher, Homotopy theory of multipointed d-spaces"
one_liner_summary: "本文构造反例证明：对任意重参数化范畴 P ∈ {G, M}，P-多尖点 d-空间的 q-模型范畴都不是左真的，且左真性失效已发生在单个 globular 生成 q-余纤维的 cobase change 上。"

## 🎯 核心定位

- **解决的问题**：P-多尖点 d-空间（P ∈ {G, M}）的 q-模型结构是否左真？本文回答：否，并给出最小反例。
- **大图景位置**：这是 directed homotopy 理论模型结构性质研究的关键负面结果；它说明 multipointed d-spaces 的 q-模型范畴不满足 left properness，而 companion 论文（2608.13165）证明 Moore flows 的 q-模型结构左真——两者对比澄清了"哪个模型才是正确的有向同伦理论"之争。
- **主要贡献**：1) 构造弱等价 s: A → B（执行路径空间 Path A = E_1 与 Path B = E_{>0} 的可缩性）作为反例输入；2) 证明沿单个 globular 生成 q-余纤维做 cobase change 后 pushout 映射不是弱等价，从而 q-模型范畴非左真；3) 指出反例只用 globular 生成 q-余纤维，完全不涉及 C/R 状态生成元。
- **关键先驱工作**：Gaucher 关于 multipointed d-spaces 模型结构的系列工作（q-model 结构定义）；Hirschhorn 的左真性理论；对 Moore flows 左真性的 companion 结果（2608.13165）。
- **结果边界**：反例对任意 P ∈ {G, M} 都成立；非左真性源自执行路径空间包含退化路径（E_{>0}）的拓扑结构——这正是 Moore flows（其 Path^+ X 不含此类退化段）左真而 d-spaces 不左真的分水岭；结论不适用于 Moore flows 的 q-模型结构。
- **开放问题**：作者未显式列出开放问题，但可推断：能否通过修改 q-模型结构的余纤维生成元（如加入 C/R 生成元的组合）修复左真性；是否存在另一种模型结构（如 h-model 结构）使 multipointed d-spaces 左真。
- **应用与推广**：负面结果指导实践：需要左真模型结构时（如计算 homotopy pushout、构造稳定化），应改用 Moore flows 而非 multipointed d-spaces；对并发理论中状态空间建模的工具选择有直接影响。

## 📐 主要定理

> **Theorem (counterexample)**: For every P ∈ {G, M}, the pushout map s̄: X → Y is not a weak equivalence. Consequently, the q-model category of P-multipointed d-spaces is not left proper. More precisely, left properness already fails for the cobase change A → X of the single globular generating q-cofibration; neither state generator C nor R is involved.

> **Lemma (contractibility)**: The spaces E_1 and E_{>0} are contractible. Consequently s is a weak equivalence.

> **Lemma (separated components)**: The paths c and c *_N b belong to distinct path components of Path X.

> **Lemma (same component after pushout)**: The paths s̄(c) = c and s̄(c *_N b) = c *_N b belong to the same path component of Path Y.

### 证明思路

- 第一步：构造对象 A 与 B：Path A = E_1（单条执行路径），Path B = E_{>0}（正时间退化路径族），证明二者都可缩，故 s: A → B 是弱等价。
- 第二步：取 globular 生成 q-余纤维 i: A → X，沿 s 做 cobase change 得 pushout X → Y；用 Lemma separated/connected 分析 Path X 与 Path Y 的路径分量：在 X 中 c 与 c *_N b 分离，在 Y 中二者并合。
- 第三步：因 Path X → Path Y 在路径分量层面非单射、诱导的 π_0 映射不保持分离性，故 s̄: X → Y 不是弱等价；由左真性定义（弱等价沿余纤维 pushout 保持）即得 q-模型范畴非左真。

## 🔑 关键组件

### 关键引理

> **Lemma (connected after pushout)**: The paths s̄(c) = c and s̄(c *_N b) = c *_N b belong to the same path component of Path Y. — *[新证：反例核心]*

### 关键定义

> **Definition (multipointed d-space)**: A multipointed d-space X = (|X|, X^0, Path X) consists of a topological space |X| with a distinguished subset X^0 of states and a subspace Path X of the space of continuous paths [0,1] → |X| whose endpoints lie in X^0, closed under constant paths, concatenation and reparametrization by P. The q-model structure is generated by globular cells and state inclusions C, R.
> **动机**：multipointed d-space 是并发理论中"带方向的状态空间"的标准模型；Path X 含退化路径（如 E_{>0}）是 d-space 的本质特征，但正是它导致左真性失效。

> **Definition (globular generating q-cofibration)**: A globular cell attachment A → X adds a globular cell (a copy of the interval with prescribed execution path space) to a multipointed d-space; the generating q-cofibrations are the inclusions of such cells together with state generators C (adding a state) and R (adding an execution path).
> **动机**：globular cell 是 d-space 的"单元自由度"，q-模型结构的余纤维由这些单元附件生成；本文的反例只使用 globular cell，说明左真性失效与状态/路径生成元无关，是结构性的。

## 💡 理解辅助

- **贯穿例子**：执行路径空间 Path X 取 E_1 = {c}（一条路径）与 E_{>0} = {c *_N b | b ∈ (0,1)}（一族"在时间 N 处暂停"的路径）构成反例的两端；直观上：在 X 中路径 c 与暂停路径 c *_N b 属于不同分量（暂停点不可达），而在 Y 中暂停点被"缝合"到同一条路径，分量并合导致弱等价性破坏。
