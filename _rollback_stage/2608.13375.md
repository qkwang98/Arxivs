# Moduli of super-representations of quivers

keywords: [Super geometric quotient, quiver representation, Super varieties, 超 GIT 商, 模空间]
related_paper: "Moduli of representations of quivers"
one_liner_summary: "本文将 King 的箭图表示 GIT 模空间理论推广到超表示范畴，构造箭图超表示的 θ-半稳定模空间并证明其点与 S-等价类一一对应。"
## 🎯 核心定位

- **解决的问题**：为箭图 Q 的超表示（super-representations）构造 θ-半稳定对象的模空间，即把 King 的 GIT 商构造从普通表示推广到超表示。
- **大图景位置**：这是超代数几何与表示论模空间理论的交叉；填补了「超表示的模空间」这一空白，将 King 模空间（Ki94）纳入超几何框架，并证明其 bosonic 化与经典 King 模空间一致。
- **主要贡献**：①建立超表示空间与 kQ-Smod 的等价，定义超表示空间及 GL(sd)_ev 作用；②发展仿射超 GIT 商理论（超几何不变量理论）；③证明存在超概型 sms ⊆ smss corepresent 相应模函子，其 k-点与 S-等价类双射对应。
- **关键先驱工作**：依赖 King 的箭图表示 GIT 商（Ki94）、超代数几何的基础（Deligne-Morgan、Manin 的超概型理论）以及经典 GIT（Mumford）与几何不变量理论的稳定性判据。
- **结果边界**：构造依赖域 k 上超概型的良好性质与 G(sd) 的约化性；对特征 p 或非仿射超概型情形需要额外假设；θ-稳定性判据在超情形通过超一般线性群偶部作用定义，奇部不进入判据。
- **开放问题**：对超表示模空间的奇点结构、超 Poincaré 多项式与超 toric 情形的进一步研究；文章未讨论模空间的维数公式与超 Chow 环，留待后续。
- **应用与推广**：可用于超弦理论中 quiver 超势能模型的几何研究、超代数几何中的不变量理论，以及超表示范畴的导出等价与稳定对象的分类。

## 📐 主要定理

> **Theorem (主定理)**: There exist super schemes $\sms \subseteq \smss$ corepresenting the respective moduli functors $\smfs \subseteq \smfss$. Furthermore, the points in $\smss(k)$ correspond bijectively to the $S$-equivalence classes of $\btheta$-semistable super-representations $Q$ of super dimension vector $\sd$.

> **Corollary (bosonic reduction)**: The bosonic reduction of the super moduli space is isomorphic to the classical King moduli space of $\btheta$-semistable representations of $Q$ of dimension vector $\sd$.

### 证明思路

- 第一步：将箭图超表示等价于有限维超代数 k\widehat{Q} 上的超模（k\widehat{Q}-Smod），从而把问题转化为超线性空间上的 G(sd)-作用。
- 第二步：构造超表示空间 SR(sd) 及超 GIT 商，用 χ_θ 线性化的半稳定判据（χ(Δ)={1} 且对单参数子群 λ 有 ⟨χ,λ⟩ ≥ 0）刻画 θ-半稳定/稳定点。
- 第三步：证明 GIT 等价类与 S-等价类一致（闭轨道当且仅当 polystable），从而模函子被超概型 corepresent，得到模空间 sms ⊆ smss。

## 🔑 关键组件

### 关键引理

> **Proposition (稳定性判据)**: A point $x \in \mathbb{V}(k)$ is $\chi$-semistable if and only if $\chi(\Delta)=\{1\}$ and every one parameter subgroup $\lambda$ of $G$, for which $\lim_{t \rightarrow 0} \lambda(t) \cdot x$ exists, satisfies $\langle \chi, \lambda \rangle \ge 0$. Such a point is $\chi$-stable if and only if the only one-parameter subgroups of $G$, for which $\lim_{t \rightarrow 0} \lambda(t) \cdot x$ exists and $\langle \chi, \lambda \rangle = 0$, are in $\Delta$. — *[引用自 King 稳定性判据的超推广]*

> **Proposition (S-等价)**: Let $M$ be a $\btheta$-semistable super-representation. Then: (i) The $G(\mathbf{\sd})$-orbit of $M$ is closed in the semistable locus $\mathbf{SR}(\sd)^{\chi_{\btheta}\text{-ss}}$ if and only if $M$ is $\btheta$-polystable. (ii) Two $\btheta$-semistable representations define the same point in the GIT quotient if and only if they are $S$-equivalent.

### 关键定义

> **Definition (super-representation of a quiver)**: A super-representation of a quiver $Q$ is an assignment of a finite-dimensional super vector space to each vertex and a parity-preserving linear map to each arrow, subject to the usual composition rules; equivalently, a supermodule over the super path algebra $k\widehat{Q}$.
> **动机**：超表示把超对称性纳入组合表示论，使模空间的构造能覆盖超势能、超弦理论中出现的超代数对象。

> **Definition (θ-半稳定超表示)**: A super-representation $M$ of super dimension vector $\sd$ is $\theta$-semistable if the associated point is $\chi_\theta$-semistable for the GIT linearization, i.e. $\theta$-weighted slope conditions hold on all sub-super-representations.
> **动机**：稳定性的引入是为在商空间中筛去轨道不闭的坏点，保证模空间 Hausdorff 化后具有良好的几何结构，S-等价类给出其点的精确分类。

## 💡 理解辅助

- **贯穿例子**：作者用 A2 箭图（两个顶点一条箭头）的超表示作显式说明，给出偶部与奇部半不变量函数的具体形式，展示 θ-半稳定区域与模空间点在超情形下的差异。
