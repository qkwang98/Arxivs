## 📐 主要定理

> **Main Theorem**: Let $T$ be a consistent complete first-order theory and let $\mathcal{U}$ be a monster model.
> 1. $T$ eliminates imaginaries if and only if $\mathrm{defT}(T)$ is exact.
> 2. $T$ eliminates hyperimaginaries if and only if $\mathrm{Pro}(\mathrm{defT}(T)_{ex/reg})$ is exact.
> 3. $T$ eliminates imaginaries and hyperimaginaries if and only if $\mathrm{Pro}(\mathrm{defT}(T))$ is exact.
> 4. We have the following equivalences of categories: $\mathrm{defT}(T^{eq})\simeq\mathrm{defT}(T)_{ex/reg}$, and $\mathrm{tpdefT}(\mathcal{U}^{heq})\simeq(\mathrm{Pro}(\mathrm{defT}(T)))_{ex/reg}$.

> **Theorem (Saturation characterization)**: 模型 $\mathcal{M}$ 是 $\kappa$-饱和的当且仅当对 $\mathrm{Pro}(\mathrm{defT}(T))$ 中每个余定义域变元长度严格小于 $\kappa$ 的正则满态射，其在 $\mathcal{M}$ 中的解释是满射。

### 证明思路

- 第一步：回顾 $\mathrm{defT}(T)$ 的正则/相干/Boolean 结构，证明 $\mathrm{defT}(T^{eq})\simeq\mathrm{defT}(T)_{ex/reg}$ 且无需非退化假设。
- 第二步：证明若 $\mathrm{Pro}(\mathrm{defT}(T))$ exact 则 $\mathrm{defT}(T)$ exact（类型可定义等价关系的商可定义），从而归约到 $T$ 消去像元情形；再利用"消去超像元 $\Leftrightarrow$ 每个类型可定义等价关系可分解为可定义等价关系的余过滤极限"证明 $\mathrm{Pro}(\mathrm{defT}(T)_{ex/reg})$ 的 exactness 等价性。
- 第三步：对 $\mathcal{U}^{heq}$ 定义无限句法范畴 $\mathrm{tpdefT}(\mathcal{U}^{heq})$（用 $\infty$-coherent 逻辑），验证其 $\infty$-exact 性并建立与 $(\mathrm{Pro}(\mathrm{defT}(T)))_{ex/reg}$ 的范畴等价；饱和度刻画用正则满态射在模型中的满射性直接翻译。
