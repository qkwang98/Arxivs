## 📐 主要定理

> **Theorem 6.4**: If $G=\{1,g_1,\dots,g_n\}$ is a finite group, then $Q_\lambda(z_0,z)=\prod_{[\pi]\in\widehat{G}}(Q_\pi(z_0,z))^{d_\pi}$. Moreover, each $Q_\pi$ is an irreducible polynomial, and it determines $\pi$ up to unitary equivalence.

> **Theorem (Kippenhahn's conjecture)**: Let $A_1$ and $A_2$ be Hermitian matrices of equal size. If $\det(z_0I+z_1A_1+z_2A_2)$ has a repeated factor, then $(A_1,A_2)$ is reducible.

> **Theorem (Algebraic extension criterion)**: A tuple $A=(A_1,\ldots,A_n)$ is irreducible if and only if there exists an algebraic extension $\widetilde{A}=(A_1,\ldots,A_n,B)$ such that $Q_{\widetilde{A}}$ is irreducible.
