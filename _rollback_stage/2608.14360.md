## 2.  📐 主要定理

> **Theorem (uniqueness)**: Let $A$ be a string algebra. The geometric model of $A$ is unique if and only if every non-gentle vertex of Type (I) or Type (III) (if any) satisfies the three conditions of Lemma three-conditions.

> **Theorem (no red punctures)**: Let $A=\mathbf{k}Q/I$ be a string algebra. Then all geometric models of $A$ contain no red puncture if and only if every primitive oriented cycle in $Q$, if any, is gentle-bounded.

> **Theorem (common red puncture)**: Let $A=\mathbf{k}Q/I$ be a string algebra. Then all geometric models of $A$ have a common red puncture if and only if $Q$ contains an essential cycle.

> **Theorem (sufficiency)**: Let $A=\mathbf{k}Q/I$ be a string algebra. If $Q$ contains an essential cycle, a shuttle cycle, or a multi-coupled cycle, then every geometric model of $A$ contains a red puncture.

### 2.1.  证明思路

- 第一步：回顾 BC24 的几何模型：string 代数 = locally gentle 代数的商（$A=(\mathbf{k}Q/J)/(I/J)$）= 带标号铺砖代数；非 gentle 顶点按 Type (I)/(III) 分类，铺砖曲面上的标号与"箭头—面"对应编码弦与带模。
- 第二步：唯一性：两个几何模型的差异恰由非 gentle 顶点的标号选择造成；证明 Type (I)/(III) 顶点的标号选择自由被三个条件（循环 gentle-bounded、无分叉、无多重耦合等）完全消除，从而等价类唯一。

### 3.1.  关键命题

> **Proposition (loops)**: Let $A=\mathbf{k}Q/I$ be a string algebra. For any vertex $v\in Q_0$, there are at most two distinct loops at $v$. ### 3.2.  关键定义

> **Definition (Red puncture)**: 带标号铺砖曲面上的尖刺（puncture）若带有红色标号则称红尖刺；其存在性反映 string 代数在局部非 gentle 顶点处需要"异常"的曲面标号才能编码关系。
> **动机**：gentle 代数的曲面模型无红尖刺；string 代数是否"几乎 gentle"可由红尖刺的出现与否读出，因此红尖刺是几何化程度的度量。
