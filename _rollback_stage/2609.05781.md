# Thick subcategories over weakly symmetric algebras with radical cube zero

keywords: [thick subcategory, weakly symmetric algebra, 谱半径, Gorenstein 环, dominance]
related_paper: "Takahashi, Dominant local rings (\cite{T23})"
one_liner_summary: "本文对根立方为零的有限维弱对称代数，按 Ext 矩阵谱半径 λ 与 2 的大小关系完整刻画了含代数的厚子范畴：λ≠2 时只有平凡情形，λ=2 时由某阿贝尔范畴的 Ω-稳定 Serre 子范畴分类，并据此给出首批非完全交的交换 Noether 局部 Gorenstein dominant 环。"

## 1.  核心定位

- **解决的问题**：刻画有限维弱对称 \(k\)-代数 \(\L\)（根立方为零）的模范畴 \(\mod\L\) 与其稳定范畴 \(\underline{\mod}\L\) 中含 \(\L\) 的厚子范畴（thick subcategories）的结构，并把它与 Ext 矩阵的谱半径 \(\lambda\) 的临界值 \(2\) 联系起来。
- **大图景位置**：本文处在表示论（tame/wild 型、Euclidean 型遗传代数）与交换代数（Gorenstein 环、dominance、完全交）的交汇处；其分类定理把 Benson 的谱三分（\(\lambda<2\) 有界、\(\lambda=2\) 线性增长、\(\lambda>2\) 指数增长）从"投射分解的增长"转译为"厚子范畴的结构"。
- **主要贡献**：
  1. 证明 \(\lambda\ne2\)（即 \(\lambda<2\) 或 \(\lambda>2\)）时，\(\mod\L\) 中含 \(\L\) 的厚子范畴仅有 \(\add\L\) 与 \(\mod\L\)，稳定范畴无真非零厚子范畴（thm1.1、more than two、stable corollary、less than two）；
  2. 在临界情形 \(\lambda=2\) 给出保持序的双射：含 \(\L\) 的厚子范畴 ↔ \(\A\) 的 \(\Omega\)-稳定 Serre 子范畴 \(\sqcup\{\gmod\L\}\) ↔ \(\underline{\mod}\L\) 的厚子范畴（thm1.2），并给出更细的四对象交换图（classification equal two）；
  3. 把 \(\A\) 识别为 Euclidean 型遗传代数的正则模范畴，从而把 Euclidean 正则表示理论作为临界情形的模型；
  4. 处理非不可分解（blockwise）的一般情形，得到 general classification：厚子范畴 ↔ \(\mathcal{P}(I_{\ne2})\times\prod_{i\in I_2}\mathfrak{S}_i\)；
  5. 交换代数应用：给出首个"交换 Noether Gorenstein dominant 局部环但不是完全交"的例子（main commutative、cor1.4），并得到 Ext/Tor 刚性结论（Ext Tor rigidity）。
- **关键先驱工作**：Benson（极小投射分解的增长与 \(\lambda\) 的临界性）；Erdmann（Ext-有限非投射模只能在 \(\lambda=2\) 出现）；Takahashi 的 dominance 框架；遗传代数 Euclidean 型正则表示的经典理论；Auslander–Reiten 型厚子范畴与 Serre 子范畴对应。
- **结果边界**：定理主要针对根立方为零的弱对称代数（此假设给出自然分次与 \(J^2=\soc({}_\L\L)\)）；无需代数闭域，只需 \(\L\) 是 split 的；dominance 的结论限于交换 Gorenstein 局部环且附加"非完全交 + 立方为零"（或 \(e(R)\le\codim R+2\)）条件。
- **开放问题**：根立方不为零的弱对称代数是否有类似分类；\(\lambda\ne2\) 情形可否一般地（去掉 \(J^3=0\)）证明厚的平凡性；dominance 的其他来源与完备刻画。
- **应用与推广**：dominance 提供了"厚子范畴 ↔ 谱的 specialization-closed 子集"的框架，本文的代数类给出了该框架中一个此前空缺的例子族；Ext/Tor 刚性可作为"高阶 Ext-正交强制投射性"的判定工具。

## 2.  主要定理

> **全局假定 / 背景**: \(k\) 为代数闭域（实际只需 \(\L\) split），\(\L\) 为不可分解的有限维弱对称 \(k\)-代数且 \(J^3=0\)，\(S_1,\dots,S_r\) 为单模完全代表系，Ext 矩阵 \(E_{ij}=\dim_k\Ext_\L^1(S_i,S_j)\) 为实对称矩阵，\(\lambda\) 为其谱半径；\(\mod\L\) 为有限生成左模范畴，\(\underline{\mod}\L\) 为其稳定范畴。当 \(\lambda=2\) 时，\(\A\) 表示由"极小投射分解有界"的模组成的阿贝尔范畴，\(\Omega\) 为 \(\L\) 上 syzygy 函子诱导的 \(\A\) 的精确自等价。

> **Theorem (\label{thm1.1})**: If $\lambda\ne 2$, then the only thick subcategories of $\mod\L$ containing $\L$ are $\add\L$ and $\mod\L$. In particular, the stable module category $\underline{\mod}\L$ has no nonzero proper thick subcategory.

*动机 / 作用*：这是全文的"刚性"一侧：在临界值之外（无论有限型还是野型），厚子范畴结构完全退化，说明 \(\lambda=2\) 是唯一可能出现丰富厚子范畴的位置。
*证明思路*：用带分次版本的数值递推（zenkashki）分析投射分解的维数向量：若存在真非零厚子范畴，则可在其中构造满足递推 \(q_{n+1}=Eq_n-q_{n-1}\) 的非零向量序列，而当 \(\lambda\ne2\) 时该递推的符号/增长性质将被破坏，矛盾；这一论证在 Section 4 完成并推广了 Erdmann 的结果。

> **Theorem (\label{more than two})**: If $\lambda>2$, then the only thick subcategories of $\mod\L$ containing $\L$ are $\add\L$ and $\mod\L$.

*动机 / 作用*：把 \(\lambda>2\)（野型）一侧单独列出，与 \(\lambda<2\)（prop:less than two）合起来给出 thm1.1。
*证明思路*：同上递推论证，在 \(\lambda>2\) 时利用 Perron 特征向量 \(\bfv>0\) 与不等式条件 \(\lambda\alpha\ge2\beta,\ \lambda\beta\ge2\alpha\) 导出矛盾项 \(\bfq_n^{\T}\bfa-\bfq_{n-1}^{\T}\bfb>0\)。

> **Theorem (\label{thm1.2})**: If $\lambda=2$, then there are order-preserving bijections
> $$\left\{\text{Thick subcategories of } \mod\L \text{ containing } \L\right\}\longleftrightarrow\left\{\text{$\Omega$-stable Serre subcategories of $\A$}\right\}\sqcup\{\gmod\L\}\longleftrightarrow\left\{\text{Thick subcategories of } \underline{\mod}\L\right\}.$$

*动机 / 作用*：临界情形是唯一有真非零厚子范畴的情形；该定理把"厚子范畴的分类"翻译为"阿贝尔范畴 \(\A\) 中 \(\Omega\)-稳定 Serre 子范畴的分类"，从而可借助经典表示论工具。
*证明思路*：对含 \(\L\) 的厚子范畴 \(\X\) 取 \(\A_\X\)（分次集中在前两度且底层模在 \(\X\) 中的对象），证明 \(\A_\X\) 是 \(\A\) 的 \(\Omega\)-稳定 Serre 子范畴，反之由 Serre 子范畴生成厚子范畴；两方向互逆且保序，稳定范畴一侧由 \(\pi\) 与 \(\pi^{-1}\) 对应。

> **Theorem (\label{classification equal two})**: There is a commutative diagram of order-preserving mutually inverse bijections
> $$\left\{\text{$\Omega$-stable Serre subcategories of $\A$}\right\}\longleftrightarrow\left\{\text{Proper thick subcategories of } \mod\L \text{ containing } \L\right\}\longleftrightarrow\left\{\text{Proper thick subcategories of } \underline{\mod}(\L)\right\}$$

*补充说明（中文）*：该交换图还联系 \(\Omega\)-稳定子集 \(\operatorname{Sim}(\A)\)、\(\mod\L\) 中介于 \(\add\L\) 与 \(\BB(\L)\) 之间的厚子范畴、\(\underline{\BB}(\L)\) 的厚子范畴构成交换图（映射为 \(\thick((-)\cup\{\L\})\)、\((-)\cap\operatorname{Sim}(\A)\)、\(\A_{(-)}\)、\(\pi,\pi^{-1}\)）。

*动机 / 作用*：给出 thm1.2 的显式函子形式：真厚子范畴一侧由"有界 Betty 数"厚子范畴 \(\BB(\L)\) 作为唯一极大真厚子范畴（prop:bounded betti thick）来界定，使分类更可操作。
*证明思路*：在同一交换图中验证各映射互逆、保序且与包含关系、交、并相容。

> **Theorem (\label{general classification})**: There are order-preserving bijections
> $$\left\{\text{thick subcategories of } \mod\L \text{ containing } \L\right\}\longleftrightarrow\mathcal{P}(I_{\ne2})\times\prod_{i\in I_2}\mathfrak{S}_i\longleftrightarrow\left\{\text{thick subcategories of } \underline{\mod}\L\right\},$$
> where $\mathcal{P}$ denotes the power set.

*动机 / 作用*：去掉不可分解假设后，把整体分类分解为 block 部分：谱半径不为 2 的 block 只贡献二值选择（\(\mathcal{P}(I_{\ne2})\)），谱半径为 2 的 block 各自贡献一个因子 \(\mathfrak{S}_i\)。
*证明思路*：由 Section 6 的 blockwise 化：厚子范畴按 block 分解，逐个 block 应用 thm1.1 / thm1.2 再取积。

> **Theorem (\label{main commutative})**: (1) Every commutative Noetherian Gorenstein local ring containing a field is dominant if it is not a complete intersection and its maximal ideal has cube zero. (2) Every equicharacteristic commutative Noetherian Gorenstein local ring $R$ with an infinite residue field that is not a complete intersection and satisfies $e(R)\le \codim R+2$ is dominant.

*动机 / 作用*：这是本文最重要的应用：把非交换表示论的刚性结论转译为交换代数命题，得到"非完全交但 dominant"的 Gorenstein 局部环的构造性来源。
*证明思路*：把条件转译为对应的弱对称代数根立方为零且谱半径 \(\lambda\ne2\) 的情形（对 (2) 用重数 \(e(R)\le\codim R+2\) 与无限剩余域把情形化为临界之外），再用 thm1.1 证明含 \(R\) 的厚子范畴平凡，而 Artinian 情形下 dominance 等价于该平凡性。

### 2.1.  证明思路

- 第一步（Section 3）：用 \(J^3=0\) 与 \(J^2=\soc({}_\L\L)\) 给出 \(\L\) 与 \(P_i\) 的自然分次（\(\L=\L_0\oplus\L_1\oplus\L_2\)，\(\dim_k e_i\L_1e_j=E_{ij}\)），把厚子范畴问题变为分次模问题，并证明"含单模则等于 \(\mod\L\)"（thick to abelian）。
- 第二步（Section 4）：建立分次 syzygy/cosyzygy 的维数向量递推 \(\bft(\Omega M)=E\bft-\bfs\)、\(\bfs(\Omega M)=\bft\)，用递推的数值行为（zenkashki 与 two sided zenkashiki）证明 \(\lambda\ne2\) 时无真非零厚子范畴（\(\lambda<2\) 与 \(\lambda>2\) 分别处理）。
- 第三步（Section 5）：在 \(\lambda=2\) 时构造阿贝尔范畴 \(\A\)（有界投射分解度的模），证明 \(\Omega\) 是其精确自等价，且厚子范畴与 \(\Omega\)-稳定 Serre 子范畴一一对应；再用 \(\Omega\)-轨道分解（orbit decomposition、stable orbit decomposition）把分类化为对简单对象的组合数据。
- 第四步（Section 6）：去掉不可分解性，按 block 分解得到 general classification。
- 第五步（Section 7）：把代数情形代入 Takahashi 的 dominance 框架，得到交换环应用。

## 3.  关键组件

### 3.1.  关键引理

> **Lemma (\label{basic properties1})**: The following statements hold. (1) For all $1\le i,j\le r$, the equality $\dim_k e_i\L e_j=\dim_k e_j\L e_i$ holds. (2) One has $J^2=\soc({}_\L\L)$. More precisely, $J^2e_i=\soc(P_i)\cong S_i$ and $\dim_k e_jJ^2e_i=\delta_{ij}$ for all $1\le i,j\le r$. (3) The matrix $E$ is symmetric. (4) There is no nonempty proper subset $I\subset\{1,\ldots,r\}$ such that $E_{ij}=0$ for every $i\in I$ and $j\notin I$.

*动机 / 作用*：把"弱对称 + 根立方为零"转化为可计算的分次数据（第 (2) 条给出 \(J^2=\soc\)，是分次构造的基石），第 (4) 条保证 Ext 矩阵的连通性，防止分类退化为互不相干的块。

> **Lemma (\label{basic properties2})**: Let $M\in\mod\L$. The following statements hold. (1) There exists a grading $\L=\L_0\oplus\L_1\oplus\L_2$ such that $J=\L_1\oplus\L_2$, $\L_2=J^2$, and $\dim_k e_i\L_1e_j=E_{ij}$ for all $1\le i,j\le r$. In particular, for all $1\le i\le r$, $P_i$ admits a grading $P_i=\L_0 e_i\oplus\L_1 e_i\oplus\L_2 e_i$ as a graded left $\L$-module. (2) Assume that $J^2M=0$. With respect to any such grading of $\L$ as in (1), $M$ admits a grading $M=M_0\oplus M_1$ as a graded left $\L$-module such that $\rad M=M_1$. (3) If $M$ has no nonzero projective direct summand, then $J^2M=0$. (4) If $M$ satisfies $J^2M=0$ and has no simple direct summand, then $\soc M=\rad M$.

*动机 / 作用*：确立全文的技术范式——每个相关模都可分次且集中在两个度数上（\(M=M_0\oplus M_1\)），从而使 \(\Omega\)-轨道与维数向量成为完全可计算的组合对象；第 (3)(4) 条保证非投射模自动落进该框架。

> **Lemma (\label{syzygy functors})**: Let $\X$ be a proper thick subcategory of $\mod\L$ containing $\L$, fix a grading of $\L$ as in Lemma \ref{basic properties2}(1), and let $\A_\X$ be as in Lemma \ref{thick to abelian}(2). Then there exist mutually inverse exact functors $\Omega, \Omega^{-1}:\A_\X\to\A_\X$ satisfying the following: for $M=M_0\oplus M_1\in\A_\X$, there are exact sequences
> $$0\to (\Omega M)(-1)\to P(\bft)\to M\to0,\quad 0\to M\to P(\bfs)(1)\to (\Omega^{-1}M)(1)\to0$$
> in $\gmod\L$. Moreover, for $\bft=\bft(M)$ and $\bfs=\bfs(M)$, one has
> $$\bft(\Omega M)=E\bft-\bfs,\quad \bfs(\Omega M)=\bft,\quad \bft(\Omega^{-1}M)=\bfs,\quad \bfs(\Omega^{-1}M)=E\bfs-\bft.$$
> In particular, $M=0$ if and only if $\Omega M=0$ if and only if $\Omega^{-1}M=0$.

*动机 / 作用*：这是全文的计算核心：把 syzygy 函子写成分次精确函子，并获得维数向量的线性递推；"\(M=0\iff\Omega M=0\)"保证 \(\Omega\) 可用于判定非零性，使厚子范畴的平凡性能被递推的数值行为所控制。

> **Lemma (\label{zenkashki})**: The following statements hold. (1) $\lambda$ is an eigenvalue of $E$ having multiplicity one, and there exists $\bfv\in\mathbb{R}_{>0}^r$ such that $E\bfv=\lambda\bfv$. (2) Assume that $\lambda>2$. Let $\bfv\in\mathbb{R}_{>0}^r$ with $E\bfv=\lambda\bfv$, let $\bfa,\bfb\in\mathbb{Z}_{\ge0}^r$ be nonzero, set $\alpha=\bfv^{\T}\bfa$ and $\beta=\bfv^{\T}\bfb$, and assume that $\lambda\alpha\ge2\beta$ and $\lambda\beta\ge2\alpha$. Define $\bfq_0=\bfa$, $\bfq_1=\bfb$, and $\bfq_{n+1}=E\bfq_n-\bfq_{n-1}$ for $n\ge1$. Then there exists $n\ge2$ such that $\bfq_n^{\T}\bfa-\bfq_{n-1}^{\T}\bfb>0$.

*动机 / 作用*：Perron–Frobenius 型结论 (1) 给出正特征向量；递推判据 (2) 是"\(\lambda>2\) 时厚子范畴必平凡"的定量引擎（所谓 zenkashki，"渐化式"）。

> **Lemma (\label{two sided zenkashiki})**: Let $(\bfq_m)_{m\in\Z}$ be a bi-infinite sequence of nonzero vectors in $\Z_{\ge0}^r$ satisfying $\bfq_{m+1}=E\bfq_m-\bfq_{m-1}$ for every $m\in\Z$. Then $\lambda\ge2$. If $\lambda=2$, then the set $\{\bfq_m\mid m\in\Z\}$ is finite.

*动机 / 作用*：给出双向（\(\Z\)-索引）递推的刚性：这样的序列只能在 \(\lambda\ge2\) 存在，且在临界值时必为有限集——这是"\(\lambda<2\) 时厚子范畴平凡"（prop:less than two）的关键，也说明 \(\lambda=2\) 时 \(\Omega\)-轨道是周期性的。

> **Lemma (\label{orbit decomposition})**: The following statements hold. (1) If $\O$ and $\O'$ are distinct $\Omega$-orbits and $M\in\Serre_{\A}(\O)$, $N\in\Serre_{\A}(\O')$, then $\gHom_\L(M,N)=0=\Ext_\L^1(M,N)_0$. (2) Every object $M\in\A$ admits a decomposition $M\cong M_{\O_1}\oplus\cdots\oplus M_{\O_n}$ for some $n\ge0$ and some $\Omega$-orbits $\O_1,\ldots,\O_n$, where $M_{\O_i}\in\Serre_{\A}(\O_i)$ for each $1\le i\le n$.

*动机 / 作用*：把 \(\A\) 中的对象按 \(\Omega\)-轨道正交分解，使"\(\Omega\)-稳定 Serre 子范畴"的分类简化为对轨道集合的选择——这正是分类最终呈现为幂集与乘积形式的代数学原因。

> **Lemma (\label{Serre})**: Let $\X$ be a proper thick subcategory of $\mod\L$ containing $\L$. Then $\A_\X$ of Lemma \ref{thick to abelian}(2) is a Serre subcategory of $\A$.

*动机 / 作用*：保证 thm1.2 的对应是"厚子范畴 \(\to\) Serre 子范畴"这一自然方向（而非仅是对象集），从而两个分类问题在范畴层面等价。

> **Lemma (\label{Ext calculation})**: Let $M,N\in\A$, and write $\bft=\bft(M)$, $\bfs=\bfs(M)$, $\bfp=\bft(N)$, $\bfq=\bfs(N)$. Then
> $$\dim_k\gHom_\L(M,N)-\dim_k\Ext_\L^1(M,N)_0=\bft^{\T}\bfp+\bfs^{\T}\bfq-\bft^{\T}E\bfq.$$

*动机 / 作用*：给出分次 Hom 与 \(\Ext^1\) 的精确数值公式，使正交性（从而轨道分裂）可被纯粹线性代数地验证。

> **Lemma (\label{graded Ext1}) / (\label{graded Ext2})**: (graded Ext1) Let $L,M,N\in\gmod A$ with $\Ext_A^1(N,L)_0=0$. Then every short exact sequence $0\to L\to M\to N\to0$ in $\gmod A$ splits. (graded Ext2) Let $L,N\in\gmod A$ and $a=\inf\{i\in\Z\mid N_i\ne0\}$. Suppose that there is $b\in\Z$ such that $L_i=0$ for all $i\ge b$. Then, for all $p\ge0$ and $q\in\Z$, one has $\Ext_A^p(N,L)_q=0$ whenever $p+q\ge b-a$.

*动机 / 作用*：为分次模给出 Ext 消失与分裂判据，是分次 syzygy 递推（syzygy functors）与正交性论证的技术前提。

### 3.2.  关键定义

**关键概念（thick subcategory）**：在阿贝尔情形，子范畴称为 thick 若它关于直和项、满射的核、单射的余核与扩张封闭；在三角情形，thick 指关于直和项封闭的全三角子范畴。

**关键概念（Ext matrix 与谱半径 \(\lambda\)）**：\(E_{ij}=\dim_k\Ext_\L^1(S_i,S_j)\)，\(\lambda\) 为 \(E\) 的谱半径；由 basic properties1 知 \(E\) 对称、\(\lambda\) 是重数一的正特征值（zenkashki(1)）。

**关键概念（dominance，Takahashi）**：交换 Noether 局部环 \((R,\m,k)\) 称为 dominant，若对每个无限投射维数的有限生成 \(R\)-模 \(M\)，含 \(R\) 与 \(M\) 的最小厚子范畴包含 \(k\)。特别地，当 \(R\) 为 Artinian 时，\(R\) dominant 当且仅当含 \(R\) 的厚子范畴仅有 \(\add R\) 与 \(\mod R\)。

**关键概念（阿贝尔范畴 \(\A\) 与 \(\Omega\)）**：\(\A\) 由极小投射分解有界的模组成；\(\L\) 的自内射性使 syzygy 函子在 \(\A\) 上诱导精确自等价 \(\Omega\)（详见 Section 3–5 的构造：分次化后对象集中在度数 0,1）。

**直观动机与作用**：上述定义把"表示论的增长型（tame/wild）"与"厚子范畴的丰富程度"绑定：\(\lambda\) 决定增长，而 \(\Omega\)（即 syzygy 的周期结构）决定厚子范畴的组合形态；dominance 则提供交换代数侧的对应语言，使 thm1.1 具有"非完全交的 Gorenstein 例子"这一具体产出。

## 4.  理解辅助

- **贯穿例子（Euclidean 型遗传代数的正则模）**：\(\lambda=2\) 时的 \(\A\) 可识别为 Euclidean 型遗传代数的正则模范畴（Remark \ref{hereditary}），其 \(\Omega\)-轨道对应正则分量；因此临界情形的厚子范畴结构与经典 Euclidean 正则表示理论同构——这是本文把"非交换分类"接回"经典理论"的关键观察。
- **贯穿判据（"含单模即全范畴"）**：thick to abelian(1) 说明含单模的厚子范畴必为 \(\mod\L\)；配合 basic properties2(4)（无单直和项时 \(\soc M=\rad M\)），可看出"简单对象"在分类中承担边界角色。
- **贯穿不等式（\(\lambda\alpha\ge2\beta,\ \lambda\beta\ge2\alpha\)）**：在 \(\lambda>2\) 时，维数向量在 Perron 特征向量下的投影 \(\alpha,\beta\) 必须满足该不等式才能"避免"递推矛盾；这两个条件具体体现了临界值 2 的几何含义。
- **\(\ZZ_4\) 之外的对照**：\(\lambda<2\)（有限型）时双向递推不可能存在（two sided zenkashiki），故无真非零厚子范畴；与 \(\lambda>2\) 用 zenkashki(2) 排除的情形形成两种不同的排除机制。

### 5.3.  批判性思考

- 全文的关键假设 \(J^3=0\)（根立方为零）同时提供"自然分次"与"\(J^2=\soc\)"两大便利；这使得分类在结构上非常干净，但也意味着结论对更一般的自内射代数不能直接照搬，作者本人也在正文中反复强调该假设的必要性。
- \(\lambda=2\) 的分类虽然形式完整（双射 + 交换图），但其"可计算性"依赖于 \(\Omega\)-轨道与简单对象 \(\operatorname{Sim}(\A)\) 的结构；对具体代数，判断这些组合数据本身仍可能不平凡。
- 交换代数应用（main commutative）的表述条件较强（非完全交 + 立方为零 / \(e(R)\le\codim R+2\) + 无限剩余域）；读者应把它读作"从代数类构造出的新例子族"，而非 dominance 的刻画定理。
