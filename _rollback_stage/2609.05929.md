# Cartesian closedness of the category of real-valued sets, II

keywords: [quantale 值集, quantaloid 富化, 实值集范畴, 左连续 t-范数, 笛卡尔闭范畴, Cauchy 完备化, 幂等下确界, topos]
related_paper: "Cartesian closedness of the category of real-valued sets, I（Shen 2026，本文第一部分）"
one_liner_summary: "本文证明以装备左连续 t-范数的单位区间为真值表的实值集范畴 $\\RSet$ 是笛卡尔闭范畴当且仅当该 t-范数为最小 t-范数，从而把第一部分关于连续 t-范数的分类完整推广到全部左连续 t-范数，并给出基于「幂等下确界这一规范局部障碍 + 两个变类型测试对象的 Cauchy 完备化」的全新证明。"

## 核心定位

- **解决的问题**：确定实值集范畴 $\RSet$（对象为 $[0,1]_*$-集，态射为左伴随分配子）何时是笛卡尔闭范畴。对任意左连续（可以不连续）的 t-范数 $*$，给出 $\RSet$ 笛卡尔闭的充要条件。
- **大图景位置**：属于「量值集 / 富化范畴」理论中"范畴性质随真值表选择而分化"的分类问题。当量 $Q$ 是 frame 时，$Q$-集范畴是 topos；而对一般 quantale，$Q$-集范畴不必是 topos，甚至可以不是笛卡尔闭。本文把第一部分对连续 t-范数的分类**完整延伸到左连续 t-范数**，并与全局富化范畴 $[0,1]_*\text{-}\Cat$ 的 Lai–Luo 分类形成明确对照：在 $\RSet$ 的非最小情形中不会出现任何笛卡尔闭的例外。
- **主要贡献**：
  1. 主定理：$\RSet$ 笛卡尔闭当且仅当 $*$ 是 $[0,1]$ 上的最小 t-范数；
  2. 推论：$\RSet$ 是 topos 也当且仅当 $*$ 是最小 t-范数；
  3. 证明方法上作出实质改变：不再使用连续 t-范数的结构描述去选取局部构型并计算假设指数的 hom 的完整公式，而是给每个非幂等元 $c\in[0,1]$ 附着"规范局部障碍"——幂等下确界 $a_c=\bigvee\{e\leq c\mid e*e=e\}$，再用两个小的"变类型"测试对象及其 Cauchy 完备化，从指数伴随导出 hom 的下界，与求值给出上界相矛盾。
- **关键先驱工作**：Higgs 与 Fourman–Scott 的 frame 值集理论；Höhle 及其合作者建立的 quantale 值集理论；Stubbe 关于 Cauchy 完备化与 quantaloid 富化的结果（Cauchy 完备性刻画、Cauchy 完备化反射）；本文第一部分（连续 t-范数情形）；Lai–Luo 关于 $[0,1]_*\text{-}\Cat$ 的左连续分类；Stubbe–Yu 的一般 quantaloid 刻画；Hu 关于一般 quantale 下 $Q$-集不必为 topos 的结果。
- **结果边界**：结论限定于真值表为 $[0,1]$ 装备左连续 t-范数的情形。证明**本质依赖变类型（variable types）数据**：测试对象 $B$ 与 $B'$ 同时使用非幂等类型 $c$ 与类型 $1$，这种构型在全局富化的 $[0,1]_*\text{-}\Cat$ 中不可用，故 Lai–Luo 分类中的非最小情形不构成反例；作者进一步强调，这一对照不能仅归因于变类型本身，对称性与"取左伴随分配子作态射"同样是 $\RSet$ 框架的一部分。
- **开放问题**：一般 quantale / quantaloid 值集范畴（真值表不限于 $[0,1]$）的笛卡尔闭性与 topos 性分类；除笛卡尔闭与 topos 之外，局部笛卡尔闭性、正则性等范畴论性质在量值集层面的完整图谱；"幂等下确界"这一局部障碍机制在多大范围内具有普适性。
- **应用与推广**：文中"幂等下确界 + 两个变类型小对象 + Cauchy 完备化给下界 / 求值给上界"的局部障碍模式，可作为判定其他富化范畴中内蕴 hom（指数）不存在的通用技术；对模糊序理论、quantaloid 值范畴以及"变类型富化 vs 全局富化"的对照研究有直接迁移价值。

## 主要定理

> **全局假定 / 背景**: 全文固定左连续 t-范数 $*$，即 $([0,1],*,1)$ 是交换幺半群且 $*$ 在每一变量上保持上确界；$[0,1]_*$ 表示所得真值表结构，对每个 $p$ 存在伴随对 $(p*-)\dv(p\ra -)$ 满足 $p*q\leq r\iff q\leq p\ra r$。记 $\RSet$ 为 $[0,1]_*$-集与其态射（左伴随分配子）构成的范畴，$\RSetM$ 为 $[0,1]_*$-集与单调函数构成的范畴，$\RCcSetM$ 为 $\RSetM$ 中分离且 Cauchy 完备对象构成的全子范畴（以 $\sCd$ 为反射子）。记号约定：$\sCd X$ 为 $X$ 的 Cauchy 完备化，$\Fyd_X\colon X\to\sCd X$ 为反射单位，$\overline{p}\colon\{p\}\oto\{q\}$ 表示单元素 $[0,1]_*$-集之间的态射，$\ev_Z\colon Z^Y\times Y\to Z$ 为求值映射。

> **Theorem (QSet-topos-frame)**: The category $\RSet$ is cartesian closed if and only if $*$ is the minimum t-norm on $[0,1]$.

*动机 / 作用（中文）*: 全文主定理。它给出了实值集范畴笛卡尔闭性的**完整分类**：唯一的正例是最小 t-范数（此时 $\RSet$ 就是 frame $[0,1]$ 上的集值层 topos），其余一切左连续 t-范数都给出笛卡尔闭性的失败。相对于第一部分只在连续 t-范数中作分类，这里取消了连续性假设，说明"连续性"并非该现象的分界线。

*证明思路（中文）*: 先经由 Cauchy 完备化把问题化归到等价范畴 $\RCcSetM$（Proposition RSet-RCcSetM）；正例方向用 frame 值集 topos 得到；反例方向取非幂等 $c$，用幂等下确界 $a_c$ 构造两个变类型测试对象，把指数 hom 的下界与上界逼到矛盾，从而 $Z^Y$ 不存在（详见下方三步骨架）。

### 证明思路

- **第一步（化归）**：$\RSet$ 与分离 Cauchy 完备 $[0,1]_*$-集及单调函数构成的范畴 $\RCcSetM$ 等价（Proposition RSet-RCcSetM），故只需讨论 $\RCcSetM$ 的笛卡尔闭性。
- **第二步（正例）**：若 $*$ 为最小 t-范数，则 $\RSet$ 是 frame $[0,1]$ 上的集值层 topos，自然笛卡尔闭；由等价性，$\RCcSetM$ 亦然。
- **第三步（障碍）**：若 $*$ 非最小，则存在非幂等元 $c$（否则 $p*q=p\wedge q$）；由 Lemma sup-idem，幂等下确界 $a_c$ 幂等且 $a_c<c$。
- **第四步（测试对象）**：取 $X=\{x,x'\}$（类型均为 $1$、互 hom 为 $a_c$）、$Y=\sCd\{1\}$、$Z=\sCd X$，构造三个单调映射 $F\colon\sCd\{1\}\times Y\to Z$、$G\colon\sCd\{c\}\times Y\to Z$、$H\colon\sCd\{1\}\times Y\to Z$（分别把零点映到 $x$、$x$、$x'$），并利用指数伴随与 Cauchy 反射给出的自然双射 $Z^Y_q\cong\RCcSetM(\sCd\{q\}\times Y,Z)$ 得到 $f\in Z^Y_1$、$g\in Z^Y_c$、$h\in Z^Y_1$。
- **第五步（两个下界）**：构造两个变类型对象 $B=\{b_0,b_1\}$（$1^{\nat}(b_0,b_0)=1$，$1^{\nat}(b_1,b_1)=c$，$1^{\nat}(b_0,b_1)=c$）与 $B'=\{b'_0,b'_1\}$（类型配置反过来），由 $K\colon\sCd B\times Y\to Z$ 与 $K'\colon\sCd B'\times Y\to Z$ 的转置配合 Lemma Z^Y-hom 得 $c\leq1_{Z^Y}^{\nat}(f,g)$ 与 $c\leq1_{Z^Y}^{\nat}(g,h)$；反向不等式由类型给出，故两者都等于 $c$。
- **第六步（上界矛盾）**：求值的单调性给出 $1_{Z^Y}^{\nat}(f,h)\leq1_Z^{\nat}(\ev_Z(f,\overline{1}_1),\ev_Z(h,\overline{1}_1))=a_c$；而由公理 (S3) 应用于 $f,g,h$ 及 $1_{Z^Y}^{\nat}(g,g)=c$ 得 $c*(c\ra c)=c\leq1_{Z^Y}^{\nat}(f,h)$。于是 $c\leq a_c<c$，矛盾，$Z^Y$ 不存在。
- **结论**：$\RCcSetM$ 不是笛卡尔闭的，从而 $\RSet$ 不是笛卡尔闭的；结合正例方向即得主定理。

> **Corollary**: The category $\RSet$ is a topos if and only if $*$ is the minimum t-norm on $[0,1]$.

*动机 / 作用（中文）*: 把主定理立即转译为 topos 分类。注意方向是单向可推的：每个 topos 都是笛卡尔闭的，故反例方向直接由主定理得到；而正例方向来自 Höhle 关于 frame 值集的经典结果。文献中已知一般 quantale 下 $Q$-集范畴不必是 topos，本推论给出 $[0,1]_*$ 情形的精确分界。

*证明思路（中文）*: 若 $*$ 为最小 t-范数，$\RSet$ 是 frame $[0,1]$ 上的集值层 topos；反之，topos 必笛卡尔闭，由主定理即得 $*$ 为最小 t-范数。

## 关键组件

### 关键引理

> **Lemma (phi-p-q)**: For $p,q\in[0,1]$, the following statements are equivalent: (i) There exists a morphism $\phi\colon\{p\}\oto\{q\}$ of one-element $[0,1]_*$-sets. (ii) $p$ is divisible by $q$ and satisfies $p=p*(q\ra p)$. In this case, it necessarily holds that $\phi(p,q)=p$. Therefore, a morphism between one-element $[0,1]_*$-sets, when it exists, will be denoted by $\overline{p}\colon\{p\}\oto\{q\}$. When the codomain needs to be indicated, we write $\overline{p}_q$ instead of $\overline{p}$.

*动机 / 作用（中文）*: 单元素 $[0,1]_*$-集之间的态射刻画。它是全文的"原子计算"来源：Cauchy 完备化 $\sCd\{q\}$ 的元素、其 hom 的显式公式都建立在这条引理之上。与第一部分相比，这里的描述必须处理**左连续但可能不连续**的 t-范数，正是这条引理取代了连续情形中关于单元素集间态射的结构性描述。

*证明思路（中文）*: (i)$\Rightarrow$(ii)：设 $\phi(p,q)=r$，由 (M1) 与 (M4) 得 $r\leq p\wedge q$ 与 $p\leq r*(q\ra r)$，从而 $p\leq r\leq p$ 即 $r=p$，再由 (M1) 得 $p=q*(q\ra p)$（可除性）与 $p=p*(q\ra p)$。(ii)$\Rightarrow$(i)：直接验证 $\phi(p,q)=p$ 满足 (M1)–(M4)。

> **Lemma (sup-idem)**: For $c\in[0,1]$, put $a_c=\bigvee\{e\leq c\mid e*e=e\}$. Then $a_c$ is idempotent. Consequently, if $c$ is non-idempotent, then $a_c<c$, and every idempotent element below $c$ is at most $a_c$.

*动机 / 作用（中文）*: 本文的核心技术构造——**幂等下确界（idempotent floor）**。它把"非幂等性"这一整体性缺陷局部化为一个不等式 $a_c<c$，从而为每个非幂等元提供一个可操作的局部障碍；正是 $a_c<c$ 这一差距驱动了后面两个变类型测试对象的构造。

*证明思路（中文）*: 记 $E_c=\{e\leq c\mid e*e=e\}$，由 $*$ 在每一变量上保持上确界得 $a_c*a_c=\bigvee_{e,e'\in E_c}e*e'$；对 $e,e'\in E_c$ 有 $e*e'\leq e\leq a_c$，而对角项给出 $e=e*e\leq a_c*a_c$，故 $a_c*a_c=a_c$。若 $a_c=c$ 则 $c$ 幂等，故非幂等 $c$ 满足 $a_c<c$；又由定义 $a_c$ 是 $c$ 以下所有幂等元的上确界。

> **Lemma (Z^Y-hom)**: Let $B$ be a $[0,1]_*$-set, let $Y,Z\in\RCcSetM$, and suppose that $Z^Y$ exists in $\RCcSetM$. For every monotone function $K\colon\sCd B\times Y\to Z$, put $k=\sE K\colon\sCd B\to Z^Y$. Then $1_B^{\nat}(b,b')\leq1_{Z^Y}^{\nat}(k(\Fyd_Bb),k(\Fyd_Bb'))$ for all $b,b'\in B$.

*动机 / 作用（中文）*: 从指数伴随中抽取出的**唯一定量后果**：转置后的映射必须把源对象的 hom 值传成指数对象中的 hom 下界。全文的反例证明只用这一条伴随推论，从而避免了对假设指数 $Z^Y$ 的 hom 作完整计算。

*证明思路（中文）*: 复合 $k\circ\Fyd_B\colon B\to Z^Y$ 是单调函数，直接由单调函数定义中 $\al(x,x')\leq\be(fx,fx')$ 这一不等式即得。

> **Proposition (divisible)**: In every left-continuous t-norm $[a,b]_*$, $v*(q\ra u)=(q\ra v)*u$ whenever $u,v\in[a,b]$ are divisible by $q$.

*动机 / 作用（中文）*: 关于"可除性"的基本交换性恒等式，用于把分配子复合与单元素集间态射的计算统一成 $p*q$ 形式；它是后面在 $\sCd X$ 上算出诸 hom 值的技术前提。

*证明思路（中文）*: 由 $u=q*(q\ra u)$ 与 $v=q*(q\ra v)$，用结合律与交换律直接变形即得。

### 关键定义

> **Definition ($[0,1]_*$-set)**: By a $[0,1]_*$-set (or a $[0,1]_*$-valued set) we mean a set $X$ equipped with a map $\al\colon X\times X\to[0,1]$, such that (S1) $\al(x,y)=\al(x,x)*(\al(x,x)\ra\al(x,y))=\al(y,y)*(\al(y,y)\ra\al(x,y))$, (S2) $\al(x,y)=\al(y,x)$, (S3) $\al(y,z)*(\al(y,y)\ra\al(x,y))\leq\al(x,z)$ for all $x,y,z\in X$. Here $\al(x,y)$ is understood as the truth-value of the statement that $x$ is equal to $y$.
> **直观动机与作用**: $\al(x,x)$ 称为 $x$ 的**类型（type）或存在度（extent）**，理解为"$x$ 存在的程度"；$\al(x,y)\leq\al(x,x)\wedge\al(y,y)$ 说明相等的真值不超过两端的存在度。公理 (S1) 是"对称 $\sD[0,1]_*$-范畴"中 hom 值被端点类型决定的表达，(S3) 是三角不等式。允许 $\al(x,x)$ 取不同值正是"**变类型**"的来源，也是本文与 $[0,1]_*\text{-}\Cat$ 的全局富化设定相区别的关键。

> **Definition (distributor)**: A distributor $\phi\colon(X,\al)\oto(Y,\be)$ of $[0,1]_*$-sets is a function $\phi\colon X\times Y\to[0,1]$ such that (M1) $\phi(x,y)=\al(x,x)*(\al(x,x)\ra\phi(x,y))=\be(y,y)*(\be(y,y)\ra\phi(x,y))$, (M2) $(\be(y,y)\ra\be(y,y'))*\phi(x,y)*(\al(x,x)\ra\al(x',x))\leq\phi(x',y')$ for all $x,x'\in X$, $y,y'\in Y$. The opposite of $\phi$ is the distributor $\phi^{\circ}\colon(Y,\be)\oto(X,\al)$ with $\phi^{\circ}(y,x)=\phi(x,y)$. Its composite $\psi\circ\phi\colon(X,\al)\oto(Z,\ga)$ with another distributor $\psi\colon(Y,\be)\oto(Z,\ga)$ is given by $(\psi\circ\phi)(x,z)=\bv_{y\in Y}\psi(y,z)*(\be(y,y)\ra\phi(x,y))$, with $\al\colon(X,\al)\oto(X,\al)$ serving as the identity distributor. The category of $[0,1]_*$-sets and their distributors is denoted by $\RDist$, and it is a quantaloid.
> **直观动机与作用**: 分配子是"以真值加权的二元关系"，其复合用上确界下的 $*$ 卷积定义；$\RDist$ 构成 quantaloid 这一事实保证每个 hom-集是完全格且复合在每一变量上保上确界，从而给出一对伴随 $(-\circ\phi)\dashv(-\lda\phi)$ 与 $(\psi\circ-)\dashv(\psi\rda-)$，满足 $\psi\circ\phi\leq\xi\iff\psi\leq\xi\lda\phi\iff\phi\leq\psi\rda\xi$。这一伴随结构是 $\RSet$ 中"态射=左伴随分配子"这一定义的来源。

> **Definition (morphism)**: A morphism $\phi\colon(X,\al)\oto(Y,\be)$ of $[0,1]_*$-sets is a left adjoint distributor, whose right adjoint is necessarily its opposite; equivalently, it is a distributor satisfying (M3) $\phi\circ\phi^{\circ}\leq\be$, (M4) $\al\leq\phi^{\circ}\circ\phi$. The category of $[0,1]_*$-sets and their morphisms is denoted by $\RSet$.
> **直观动机与作用**: (M3)(M4) 是对"$\phi$ 有右伴随且该伴随就是 $\phi^{\circ}$"的显式化。此外还定义**单调函数** $f\colon(X,\al)\to(Y,\be)$（满足 $\al(x,x)=\be(fx,fx)$ 且 $\al(x,x')\leq\be(fx,fx')$），其范畴记为 $\RSetM$；每个单调函数 $f$ 诱导态射 $f_{\nat}(x,y)=\be(fx,y)$（$f$ 的 graph）与其反向 $f^{\nat}$（cograph），恒等函数给出 $\al=(1_X)_{\nat}=1_X^{\nat}$，故行文把 $(X,\al)$ 简记为 $X$ 并写 $1_X^{\nat}(x,y)$。

> **Definition (Cauchy completion)**: For every $[0,1]_*$-set $X$, let $\CdX\coloneqq\bigcup_{q\in[0,1]}\RSet(\{q\},X)$ be the set of all singletons on $X$. Its hom is $1_{\CdX}^{\nat}(\lam,\lam')={\lam'}^{\circ}\circ\lam$. The $[0,1]_*$-set $\CdX$ is separated and Cauchy complete; it is called the Cauchy completion of $X$. The canonical monotone function $\Fyd_X\colon X\to\CdX$, $\Fyd_X x=1_X^{\nat}(x,-)$ is the unit of the Cauchy-completion reflection.

> **Proposition (Cauchy-complete-def)**: A $[0,1]_*$-set $X$ is Cauchy complete if and only if for each singleton $\lam\colon\{p\}\oto X$, there exists $x\in X$ such that $\lam=1_X^{\nat}(x,-)$. In this case, necessarily $1_X^{\nat}(x,x)=p$.

*动机 / 作用（中文）*: 把抽象的 Cauchy 完备性化为"每个单元素集出发的态射都被 $X$ 中的元素表示"这一可检验条件，是构造 $\RCcSetM$ 并证明 $\RSet\simeq\RCcSetM$ 的基础。

> **Proposition (RSet-RCcSetM)**: The category $\RSet$ is equivalent to $\RCcSetM$.

*动机 / 作用（中文）*: 允许在 Cauchy 完备对象上研究笛卡尔闭性。$\RCcSetM$ 是 $\RSetM$ 中分离 Cauchy 完备对象构成的全子范畴，以 $\sCd$ 为反射子；等价性由与 Pu 2012 中相同论证给出，且对左连续 t-范数仍成立。$\RCcSetM$ 有有限乘积 $A\times B=\{(x,y)\mid x\in A,\ y\in B,\ 1_A^{\nat}(x,x)=1_B^{\nat}(y,y)\}$，其 hom 为 $1_{A\times B}^{\nat}((x,y),(x',y'))=1_A^{\nat}(x,x')\wedge1_B^{\nat}(y,y')$。

> **Proposition (RCcSetM-cc)**: The category $\RCcSetM$ is cartesian closed if and only if $*$ is the minimum t-norm on $[0,1]$.

*动机 / 作用（中文）*: 主定理的技术核心，也是整个局部障碍论证的实际发生地；主定理由它与 Proposition RSet-RCcSetM 立即推出。

## 理解辅助

- **贯穿例子（非最小 t-范数）**：论文用 **nilpotent minimum t-范数** 作为"左连续但不连续"的典型：
  > **Example (MLP-def)**: The nilpotent minimum t-norm $*_{\mathrm{NM}}$ on $[0,1]$ is a left-continuous but non-continuous t-norm, which is given by $p*_{\mathrm{NM}}q=0$ if $p+q\leq1$, and $p*_{\mathrm{NM}}q=p\wedge q$ if $p+q>1$. Its residual is $p\ra q=1$ if $p\leq q$, and $p\ra q=(1-p)\vee q$ if $p>q$.
  它是检验"取消连续性后结论是否仍成立"的试金石，也是与 Lai–Luo 在 $[0,1]_*\text{-}\Cat$ 中得到非最小正例的对照背景。
- **单元素集的 Cauchy 完备化**：由 Lemma phi-p-q，$\sCd\{q\}=\{\overline{p}\mid p\text{ is divisible by }q\text{ and }p=p*(q\ra p)\}$，且 $1_{\sCd\{q\}}^{\nat}(\overline{p},\overline{p'})=p'*(q\ra p)$。这是全文所有 hom 计算的模板。
- **二元集的 Cauchy 完备化**：对 $X=\{x,y\}$，每个单元素形如 $1_X^{\nat}(z,-)\circ\overline{p}$（$z\in\{x,y\}$），故 $\sCd X=\{1_X^{\nat}(z,-)\circ\overline{p}\mid z\in\{x,y\},\ \overline{p}\colon\{p\}\oto\{1_X^{\nat}(z,z)\}\}$。反例中正是用 $Z=\sCd X$ 承载三个测试映射的像。
- **证明的实际抓手**：非幂等元 $c$ 与幂等下确界 $a_c$ 之间的"缝隙" $a_c<c$。测试对象 $B,B'$ 把 $c$ 与 $1$ 同时用作类型，使指数对象必须同时容纳"$c$ 处的信息"和"$1$ 处的信息"，而 $a_c$ 只能提供更小的 hom 上界。
- **量值集视角**：$\RSet$ 即对称 $\sD[0,1]_*$-范畴与左伴随 $\sD[0,1]_*$-分配子构成的范畴，$\RSetM$ 即对称 $\sD[0,1]_*$-范畴与 $\sD[0,1]_*$-函子构成的范畴，其中 quantaloid $\sD[0,1]_*$ 的对象为 $[0,1]$ 的元素、$\sD[0,1]_*(p,q)=\{u\mid u\text{ 同时被 }p,q\text{ 整除}\}$、复合为 $v\circ u=v*(q\ra u)$。

## 主动思考区

### 与其他工作的联系

- 本文是第一部分的直接续作：Part I 用连续 t-范数的结构定理选取局部构型并计算假设指数的 hom 公式，本文改以幂等下确界给出规范局部障碍，说明"连续性假设"在方法上曾经承载了不必要的负担。暂无匹配的已有笔记。
- 与 Lai–Luo（$[0,1]_*\text{-}\Cat$，全局富化）的对照：同样的非最小左连续 t-范数，在全局富化中可以使范畴笛卡尔闭，在变类型设定中却一律失败。这提示"变类型 + 对称性 + 左伴随分配子"三者共同构成了 $\RSet$ 的刚性。
- 与 Stubbe–Yu 的 quantaloid 一般刻画相比，本文是该刻画在 $\sD[0,1]_*$ 这一具体族的定域化验证。
- 技术迁移：Lemma sup-idem 的"幂等下确界"是纯序-代数构造，只用到 $*$ 保上确界；任何格序幺半群（尤其是其他左连续 t-范数族、residuated lattice）都可复用该构造与"两个变类型对象夹逼"的策略去检验内蕴 hom 的存在性。

### 可以尝试的方向

### 批判性思考

- 反例论证只用 Lemma Z^Y-hom 这一条伴随推论，说明结论其实不依赖指数的具体构造；这一点很漂亮，但也提示该障碍对"指数对象存在的必要条件"非常敏感——若把态射类放宽（例如不使用左伴随分配子），结论可能变化，作者本人在 Remark 中已指出对称性与态射选择同样是框架的一部分。
- 幂等下确界 $a_c$ 的定义依赖 $c$ 以下的幂等元集合，其"规范性"来自 $*$ 保上确界这一左连续性；若 t-范数仅满足较弱的（如仅保非空有向上确界）条件，Lemma sup-idem 是否仍成立值得核查。
- 正例方向的论述依赖"frame $[0,1]$ 上的集值层构成 topos"这一经典结果，而反例方向的论证完全不使用连续 t-范数的分类——两者在方法上并不对称，这使全文读起来像"用解析方法证明一个分类定理"。是否存在一条纯范畴论的统一证明，仍值得追问。
- 论文使用 ChatGPT 辅助组织与校核（致谢中明确声明），但不影响数学内容的可验证性；反例的每一步 hom 计算均可逐字复算。
