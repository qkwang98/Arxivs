# Exactness of the 2-categories of abelian and triangulated categories

keywords: [2-范畴, 同调范畴, 强双零对象, 三元分数演算, Serre 商, Verdier 商]
related_paper: "Caviglia–Janelidze–Mesiti, 以 2-理想刻画零 1-胞与零 2-胞框架（文内引用 [CJM]）"
one_liner_summary: "本文把 Grandis 的指针同调范畴提升到二维：以强双零对象定义 2-指针性，证明由 di-exact 同调范畴、三角范畴、Abel 范畴、加性范畴、指针范畴以及交换环上的线性范畴所构成的 2-范畴都是 2-同调的，其 2-核与 2-余核分别是饱和厚子范畴与其局部化（Serre 商、Verdier 商、精确局部化）。"

## 1.  核心定位

- **解决的问题**：把 Grandis 的"指针同调范畴（形式 i–iii 三条公理）"整体抬升一个维度，回答 Abel 范畴与三角范畴所构成的 2-范畴在何种意义上也具有同调结构。
- **大图景位置**：性态上是 Grandis 同调代数框架的 2-范畴化；在方向上它既推广了 Puppe–Mitchell 的精确范畴理论（其 1-截断是 Grandis 已知的同调范畴），又推广了经典代数几何中"厚子范畴—Serre 商"与"厚三角子范畴—Verdier 商"这两组对应，把后两者统一识别为同一类 2-余核构造。
- **主要贡献**：①给出二维指针性——强双零对象（2-零对象）这一看似新的概念，并证明在该概念下 2-核与 2-余核可定义为 2-零对象上的双拉回与双推出；②把 Puppe 精确范畴的三元分数演算推广到 di-exact 同调范畴，从而具体给出 $\\DiHom$ 的 2-余核；③抽象出两条直接证明的共同结构，得到一般性判据，据此一次性覆盖指针、加性、Abel、三角以及交换环 $R$ 上半模富化范畴（含与不含有限双积两种情形）。
- **关键先驱工作**：Grandis 的指针同调范畴与 Abel 范畴同调结构（其 1.9 节、5.6 节）；Puppe、Mitchell、Brinkmann–Puppe 的 Puppe 精确范畴与精确商定理；Peschke–Van der Linden 与 Afsa 的 di-exact 概念；Dupont 与 Vitale 的群胚富化 2-Abel 范畴纲领（作为对照的分支）。
- **结果边界**：本文一律在小范畴层面工作；2-核与 2-余核的存在性以及强指针性是显式前提，因为从 2-范畴到其 1-截断的反射论证必须用到它们；把零 1-胞的"强性"放松或改用 2-理想数据，是作者明确指出的未完成方向。
- **开放问题**：作者提出猜想——（指针）同调范畴所构成的 2-范畴本身是 2-同调的，并只给出很小的一步；此外，是否可以把整套理论从指针情形推广到非指针情形（以 $2$-理想取代双零对象，并写出理想相对的"条件同调公理"）也是明确的开放方向。
- **应用与推广**：由于 2-同调结构恰好刻画出"局部化—商—核"的三段式，本文可视为把同调代数机器（正合列、K-理论中的商构造、导出范畴中厚子范畴的 Verdier 商、Abel 情形的 Serre 商）统一放置到 2-范畴语言的模板：只要某类范畴上的"结构保持函子 + 任意自然变换"满足 2-指针性与两条复合封闭性，就自动获得一套 2-同调演算。

## 2.  主要定理

> **全局假定 / 背景**: 全程只讨论小范畴；$\\Lcat$ 表示一个 2-范畴，$\\Lcat(A,B)$ 是对象 $A$ 到 $B$ 的 hom-范畴；1-胞之间的 2-胞方向记为 $\\Rightarrow$。所谓"指针同调范畴"指满足 Grandis 三条公理（指针性、核与余核存在、正规单态/满态对复合封闭、以及条件同调公理）的范畴。文中把 $\\Pt$、$\\Add$、$\\pExact$、$\\AbCat$、$\\Tri$、$\\TriAll$、$\\DiHom$ 统一为以"保持零对象及所有核与余核的函子 + 任意自然变换"为 2-胞的 2-范畴。

> **Definition（bizero object、strong bizero object、2-pointed）**: An object $0$ of a $2$-category $\\Lcat$ is a bizero object if both $\\Lcat(0,A)$ and $\\Lcat(A,0)$ are equivalent to the terminal category for every object $A$. Relative to $0$, a $1$-cell is null if it is isomorphic to a $1$-cell factoring through $0$. The bizero object $0$ is strong, or a $2$-zero object, if, for every pair $A,B$, every null $1$-cell $z:A\\to B$ is a zero object of the hom-category $\\Lcat(A,B)$. Equivalently, for every $1$-cell $f:A\\to B$ and every parallel null $1$-cell $z:A\\to B$, there is exactly one $2$-cell in each of the two directions $f\\Rightarrow z$, $z\\Rightarrow f$. A $2$-category admitting a strong bizero object is called $2$-pointed.

*动机 / 作用（中文）*："双零对象"只要求两侧 hom-范畴等价于终范畴，这在一维情形已足够刻画零对象；但在二维情形它太弱，因为 hom-范畴之间的零对象属性并不会自动传递到 1-胞的复合上（文中 Example 用二元偏序集 $1_A<z$ 给出了反例）。加入"强"这一条，等价于要求任意与零 1-胞平行的 $f$ 与它之间在两个方向上各只有唯一 2-胞，于是每个 hom-范畴都是指针范畴、且其零对象恰为 null 1-胞——这使 2-核与 2-余核可以被构造为双拉回与双推出。

> **Definition（2-homological 2-category）**: A $2$-category $\\Lcat$ is 2-homological if it is $2$-pointed in the sense of Definition above and satisfies the following axioms: (H1) every 1-cell has a 2-kernel and a 2-cokernel; (H2) 2-kernels are closed under composition, and so are 2-cokernels; (H3) if $m:M\\to A$ is a 2-kernel and $e:A\\to Q$ is a 2-cokernel, and $\\twoker(e)$ factors through $m$ up to invertible 2-cell, then $em$ is 2-normal.

*动机 / 作用（中文）*：(H3) 是 Grandis 条件同调公理（"边界落在圈中"）的二维版本；(H1)(H2) 与一维同调范畴的三条公理一一对应。该定义的判别价值在于：它与 1-截断严格相容，因此本文可以先用 1-截断把已知的一维结果搬到二维，再单独处理"2-核/2-余核如何具体构造"这一真正二维的困难。

> **Proposition（The 1-truncation）**: Let $\\Lcat$ be $2$-pointed and have all $2$-kernels and $2$-cokernels. Its $1$-truncation $\\tau_1\\Lcat$, whose arrows are invertible-isomorphism classes of $1$-cells, is pointed and has all kernels and cokernels. A $1$-cell is a $2$-kernel, respectively a $2$-cokernel, exactly when its class is a kernel, respectively a cokernel. Consequently $\\Lcat$ is $2$-homological exactly when $\\tau_1\\Lcat$ is homological in Grandis's pointed sense.

*动机 / 作用（中文）*：这是全文的"降维桥梁"：它把二维同调性完全化归为一维 Grandis 同调性。正因如此，证明某个具体 2-范畴是 2-同调的，只剩下两件可操作的事——造出各 1-胞的 2-核与 2-余核，并验证复合封闭性。

> **Theorem（Main Theorem）**: Each of $\\Pt$, $\\Add$, $\\pExact$, $\\AbCat$, $\\Tri$, $\\TriAll$, and $\\DiHom$ is $2$-pointed and $2$-homological. For every commutative rig $R$, the same holds for $\\mathbf{Lin}_{R,0}$, $\\mathbf{Lin}_{R}^{\\oplus}$, $\\mathbf{PEx}_{R}$, and $\\mathbf{PEx}_{R}^{\\oplus}$. Their $2$-kernels are, up to equivalence, full annihilation subcategories. For nested normal subcategories $\\N\\subseteq\\M\\subseteq\\C$, the homology axiom is realised by $\\M\\longrightarrow\\M/\\N\\longrightarrow\\C/\\N$, where the first arrow is a 2-cokernel and the second is the 2-kernel of $\\C/\\N\\to\\C/\\M$.

*解析（中文）*：主定理把"正规子范畴—正规商"的对应做成一张统一清单，各情形的 2-核一律是"完全消没子范畴"（即被某函子送到零对象的对象所组成的全子范畴）：

| 设定 | 正规子范畴 | 正规商 |
| --- | --- | --- |
| 指针范畴 | 对收缩封闭的全、replete 指针子范畴 | 把经过该子范畴的态射坍缩为零 |
| 加性范畴 | 对收缩封闭的全、replete 加性子范畴 | 加性理想商 |
| Puppe 精确范畴 | 厚子范畴（商-子对象与扩张封闭） | 精确局部化 |
| Abel 范畴 | Serre 子范畴 | Serre 商 |
| $\\mathbf{Lin}_{R,0}$、$\\mathbf{Lin}_{R}^{\\oplus}$ | 满足文中定义（rig-normal）的全、replete 子范畴 | 按同余关系的线性理想商 |
| $\\mathbf{PEx}_{R}$ | 厚子范畴 | 精确 $R$-线性局部化 |
| $\\mathbf{PEx}_{R}^{\\oplus}$ | Serre 子范畴 | $R^{\\mathrm{gp}}$-线性 Serre 商 |
| 三角范畴 | 厚三角子范畴 | Verdier 商 |
| di-exact 同调范畴 | 饱和厚子范畴 | 关于相伴正规分母的精确局部化 |

线性情形在 $R=\\mathbb Z$ 时退化为加性情形、在 $R=\\mathbb N$ 且要求有限双积时退化为 Abel 情形；这解释了为什么"加性"与"Abel"能在同一框架内被同时处理。

### 2.1.  证明思路

- 第一步：定义 2-指针性（强双零对象），证明此时每个 hom-范畴都是指针的、零对象恰为 null 1-胞，并由此把 2-核、2-余核刻画为"零对象上的双拉回 / 双推出"，得到可用的展开型泛性质（(K1)–(K3)）与同构意义下的唯一性。
- 第二步：对指针、加性、Puppe 精确、Abel、三角、di-exact 各情形分别构造 2-核与 2-余核。指针/加性/Abel/三角四类经 1-截断化归为已知的一维定理；真正需要新工作的是 di-exact 同调范畴，作者在此发展饱和厚子范畴、正规分母与三元分数演算，得到"饱和商定理"。
- 第三步：用 1-截断验证 (H2) 的复合封闭性与 (H3) 的条件同调公理；对 di-exact 情形则直接验证两条复合律与 Grandis 条件同调公理，无需一般的商判据；最后证明 Puppe 精确情形是饱和性自动成立的特例。

> **Theorem（di-exact 情形的主定理）**: The $2$-category $\\DiHom$ of small di-exact homological categories, functors preserving zero objects and all kernels and cokernels, and arbitrary natural transformations, is $2$-pointed and $2$-homological. Its $2$-kernels are, up to equivalence, saturated thick inclusions, and its $2$-cokernels are their localizations. For $\\N\\subseteq\\M\\subseteq\\C$ saturated thick, the square $\\M\\to\\C$, $\\M/\\N\\to\\C/\\N$ is both a bipullback and a bipushout.

*动机 / 作用（中文）*：这条定理给出"饱和厚子范畴 ∼ 其精确局部化"作为 2-核—2-余核对的完整二维对应，并把一维的"厚子范畴/精确商"理论（Grandis 的精确商定理）作为其特例收回；同时说明嵌套饱和厚子范畴的商方块同时是双拉回与双推出，即越界到二维也不会丢掉一维的拉回-推出对偶性。

## 3.  关键组件

### 3.1.  关键引理

> **Lemma（Local zero objects and whiskering）**: In a $2$-pointed $2$-category, every hom-category is pointed and its zero objects are precisely the null $1$-cells. The unique $2$-cell between parallel null $1$-cells is invertible. Pre- and postcomposition preserve both the zero objects and the zero morphisms of the hom-categories. In particular, the condition of Definition above is invariant under reversing $1$-cells or reversing $2$-cells. — *[新证]*

*作用（中文）*：把"全局的强双零对象"翻译成"每个 hom-范畴局部带零对象"，这是后面一切构造的技术底座，也解释了为何 2-指针性在反转 1-胞或反转 2-胞下不变——对偶论证因此可以整段照搬。

> **Lemma（Kernels as bipullbacks）**: In a $2$-pointed $2$-category, a $2$-kernel of $f:A\\to B$ is precisely the projection to $A$ of a bipullback of $f$ and a $1$-cell $z_B:0\\to B$. Dually, $2$-cokernels are the corresponding bipushouts over $0$. — *[新证]*

*作用（中文）*：这是全文最可操作的判据：想验证某 1-胞是 2-核，只需把它认成"沿零对象方向的双拉回投影"。由此立即可得 2-核与 2-余核在可逆 2-胞与表示对象等价下的不变性，以及"null 1-胞的 2-余核是等价"这类消没性结论。

> **Proposition（Expanded universal properties）**: A $1$-cell $k:K\\to A$ is a $2$-kernel of $f:A\\to B$ precisely when: (K1) $fk$ is null; (K2) every $u:X\\to A$ with $fu$ null admits a factorization $u\\cong kv$; (K3) for any $v,w:X\\to K$, every $2$-cell $kv\\Rightarrow kw$ is $k\\beta$ for a unique $\\beta:v\\Rightarrow w$. Dually, $q:B\\to Q$ is a $2$-cokernel of $f$ precisely when $qf$ is null, every $u:B\\to X$ annihilating $f$ is isomorphic to $vq$, and every $2$-cell $vq\\Rightarrow wq$ is $\\beta q$ for a unique $\\beta:v\\Rightarrow w$. In particular $2$-kernels are representably fully faithful and $2$-cokernels are representably co-fully faithful. — *[新证]*

*作用（中文）*：(K2) 与 (K3) 分别对应核泛性质函子的本质满性与完全忠实性；由"2-核可表示地完全忠实"可推出它反射 null 性，这一点在正规分解的比较态射是等价性时反复被使用。

> **Theorem（Grandis's exact quotient theorem）**: Let $\\N$ be a thick subcategory of a small Puppe exact category $\\C$, and put $W_{\\N}=\\{f\\in\\Mor\\C\\mid\\Ker(f),\\Coker(f)\\in\\N\\}$. The ordinary localization $\\C[W_{\\N}^{-1}]$ has a Puppe-exact structure for which its identity-on-objects quotient $q$ is exact. It annihilates precisely the objects of $\\N$ and inverts precisely $W_{\\N}$. Every morphism of the localization has a ternary representative $X\\xleftarrow{m}U\\xrightarrow{f}V\\xleftarrow{e}Y$, $m\\in W_{\\N}$ monic, $e\\in W_{\\N}$ epic, with value $q(e)^{-1}q(f)q(m)^{-1}$. — *[引用自 Grandis]*

*作用（中文）*：这是 di-exact 情形 2-余核构造的原型。关键是把"局部化中的态射"表示成"正规单态—普通态射—正规满态"的三元组，从而把二维泛性质的计算压缩到一维分母的运算上；本文正是把该演算从 Puppe 精确范畴推广到 di-exact 同调范畴（引入饱和厚子范畴与稳定正规分母），才能给出 $\\DiHom$ 中 2-余核的具体描述。

> **Proposition（反例：Abel 与 Puppe 精确都不是 2-di-exact）**: Neither $\\AbCat$ nor $\\pExact$ is $2$-di-exact in the sense of Definition above. In each, the class of $2$-normal functors is not closed under composition. — *[新证]*

*作用（中文）*：这条否定性结果划出了 2-同调性与更强"2-di-exact 性"的边界：Abel 范畴与 Puppe 精确范畴虽都是 2-同调，却不是 2-di-exact，说明 (H3) 这类条件性公理在二维情形不能被无条件复合律替代。

### 3.2.  关键定义

> **Definition（Pointed homological categories）**: A category $\\C$ is homological in the pointed sense of Grandis if it satisfies the following conditions: (i) $\\C$ is pointed and every morphism has a kernel and a cokernel; (ii) normal monomorphisms are closed under composition, and normal epimorphisms are closed under composition; (iii) if $k:B\\to C$ is a normal monomorphism and $c:C\\to D$ is a normal epimorphism such that $\\ker c$ factors through $k$, then $ck$ is normal. Condition (iii) is the homology axiom.

> **Definition（thick 与 saturated thick 子范畴）**: A full replete subcategory $\\N$ of a pointed homological category $\\C$ is thick if it contains the zero objects and is closed under normal subobjects, normal quotients, and extensions. A thick subcategory is called saturated if, for every morphism $f:X\\to Y$ of $\\C$, it satisfies $Y,\\Ker f\\in\\N\\Longrightarrow X\\in\\N$ and $X,\\Coker f\\in\\N\\Longrightarrow Y\\in\\N$.

> **直观动机与作用（中文）**："厚"是把经典 Abel 情形的 Serre 子范畴（对子对象、商对象、扩张封闭）搬到只有正规态射可用的同调范畴上；"饱和"则额外要求子范畴在核与余核方向上对对象可"双向反推"，这恰是让局部化函子成为 2-余核、其包含成为 2-核所必需的额外条件。在 Puppe 精确范畴中饱和性自动成立，故该定义在旧理论中隐性存在、无需单独提出；一旦放宽到 di-exact 同调范畴（正规态射未必对复合封闭），饱和性就成为非平凡约束，决定了哪些局部化确实是 2-余核。

*说明（中文）*：文中另一处关键构造是"饱和厚子范畴对应的正规分母 $\\Sden$ / $\\Eden$"及 epidd 偏序集上的三元分数演算；由于预处理文本仅保留了这些结果的形式陈述片段，此处不逐条抄录，读者可回到源码第 2 节查看。

## 4.  理解辅助

- **贯穿例子**：作者用一个只有两个对象 $0,A$ 的严格 2-范畴 $\\mathcal E$ 说明"双零对象未必强"：

> **Example（bizero-not-strong）**: A bizero object need not be strong. Consider the strict $2$-category $\\mathcal E$ with objects $0,A$, with $\\mathcal E(0,0)$, $\\mathcal E(0,A)$ and $\\mathcal E(A,0)$ terminal, and with $\\mathcal E(A,A)$ the two-element poset $1_A<z$. If $i:0\\to A$ and $p:A\\to0$ are the unique $1$-cells, composition is given by $pi=1_0$, $ip=z$, $z^2=z$, $zi=i$, $pz=p$, together with the identity laws. The object $0$ is a bizero and $z=ip$ is null. However, $z$ is terminal but not initial in $\\mathcal E(A,A)$, since there is no $2$-cell $z\\Rightarrow1_A$. Thus $0$ is not strong.

- **直觉图像（中文）**：这一例子把二维的额外信息显性化——同一对 1-胞之间可能有多个 2-胞，而"强"恰恰要求零 1-胞与其平行者之间的 2-胞"两个方向各唯一"，即要求 null 1-胞在该 hom-范畴中同时是初始与终止对象。相比之下，经典情形（如 Abel 范畴、三角范畴）中零态射两侧的 2-胞由零对象的终/初性质自动唯一，故强性自动成立，二维现象只在一般 2-范畴中显现。
- **三个递进的"维度阶梯"**：一维设定（Grandis 同调范畴、Puppe 精确范畴、Abel 范畴）→ 2-同调 2-范畴（本文主定理的七个例子）→ 2-di-exact / 2-Puppe 精确（更强条件，Abel 与 Puppe 精确都不满足）；1-截断 $\\tau_1$ 是上下贯通的降维对照。

### 5.3.  批判性思考

- "强双零对象"这一概念看似新，其实等价于"每个 hom-范畴的零对象恰为 null 1-胞"这一局部条件；论文已指出定义可只对"严格经过 $0$ 分解"的 1-胞提出要求。是否可以不引入"强"这一名字，而直接用"hom-范畴逐点指针 + null 1-胞为局部零对象"的整体条件，从而让定义更易被同调代数读者接受？命名上的陌生感可能掩盖了概念的朴素性。
- 证明的整体策略依赖 1-截断 $\\tau_1$ 的反射论证，因此 2-核与 2-余核的"存在性"是硬性前提；这也意味着该方法难以直接处理"只知道部分核/余核存在"的范畴（如某些非完备的导出构造），作者虽已显式声明该前提，但对其必要性的讨论仅停留在"存在性对反射论证不可缺少"这一句，缺乏反例支撑。
- 对 di-exact 情形，作者选择"直接验证两条复合律与条件性公理"而绕开一般商判据，这在技术上把复杂性集中到三元分数演算；该演算的等价关系（"两表示经共同细化后分子相等"）是否在实用中可判定，文中未给出算法化或有限情形下的简化，这会影响结论在具体范畴上的可验证性。
- 论文刻意把线性情形（交换 rig 上的半模范畴）纳入同一框架，但未给出 $R$ 上的"厚"与经典 $R$-线性 Serre 子范畴之间的完整比较定理；把 $R=\\mathbb Z$、$\\mathbb N$ 之外的 rig 情形视为"统一推广"，在缺少细例的情况下略显形式化。
- 一处可追问的隐含假设：所有构造都在小范畴上进行，而表示论与代数几何中常用的 Abel 范畴、三角范畴通常只满足局部小性；尽管可以通过 Grothendieck 宇宙做常规处理，文中未明确说明这一步，读者若直接套用主定理到局部小范畴需自行补充。
