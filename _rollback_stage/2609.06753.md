# Derived Reconstruction of Semisimple Tensor and Module Categories

keywords: [semisimple tensor category, module category, bounded t-structure, monoidal triangulated equivalence, universal grading group, stabilizer subgroup, reconstruction, separable algebra object]
related_paper: "对比文献：Xu–Zheng（monoidal $t$-structure 与 tensor reducedness 下的重构）、Yu（有限多个单对象情形下的重构与 module $t$-structure 的相容性定义）、Biglari（normalized 情形的相容有界 $t$-structure）"
one_liner_summary: "本文对本质小、局部有限的半单张量范畴 $\C$ 及其半单左模范畴 $\M$（允许无穷多个单同构类）作出双重分类：$D^b(\C)$ 上的有界 monoidal $t$-structure 由「万有分次群 $U_{\C}$ 的整值特征 $\chi$ + 整数偏差 $d$」唯一决定（定理 A）；与给定 monoidal $t$-structure 相容的 $D^b(\M)$ 上有界 $t$-structure 则由每个模连通分支的稳定化子群 $H_\Omega$ 是否落在 $\chi$ 的核中决定，并可逐分支独立平移一个整数（定理 B）；由此证明 monoidal 三角等价 $D^b(\C)\simeq_\otimes D^b(\D)$ 能还原出 $\C\simeq_\otimes\D$，而「monoidal 三角等价 + 相干模等价」这一对数据能同时还原出 $\C$ 与 $\M$（定理 C）。"

## 1.  核心定位

- **解决的问题**：三角等价（乃至 monoidal 三角等价）到底在多大程度上决定底层的（张量）阿贝尔范畴？有界 $t$-structure 以其心给出一个阿贝尔范畴，但同一三角范畴上有许多 $t$-structure，因此重构问题的关键在于**弄清哪些 $t$-structure 与张量积/模作用相容**，并对它们作完全分类。
- **大图景位置**：Xu–Zheng 与 Yu 的重构结果都依赖「一致比较（uniform comparison）」与 tensor reducedness，或在「单同构类有限」的前提下工作（此时不同 $t$-structure 的平移函数只相差有界函数）。Yu 在文末明确提出了「单同构类无限」时的相应问题。本文在**半单**情形下回答了该问题，并指出无限多单对象时出现全新现象：平移函数可以相差**无界**函数（例如 $\Vect_{\mathbb Z}^{\mathrm{fd}}$ 上 $L_n[a]\mapsto L_n[a+cn]$），因此一致比较方法失效，必须改用万有分次群的**特征**来参数化。
- **主要贡献**：
  1. 定理 A / thm:monoidal-classification：$\MT(D^b(\C))\leftrightarrow\Hom(U_{\C},\mathbb Z)\times\mathbb Z$、$\MT_0(D^b(\C))\leftrightarrow\Hom(U_{\C},\mathbb Z)$，$(\chi,d)\mapsto p(X)=\chi(\deg X)+d$，且偏差恰为 $\{d\}$；推论 cor:unique-standard：标准 normalized monoidal $t$-structure 唯一 $\iff\Hom(U_{\C},\mathbb Z)=0$；
  2. 定理 B / thm:module-compatibility + thm:stabilizer：模 $t$-structure 的相容性判据 $p(P)=p(M)+\chi(\deg X)$（$P\le X\odot M$），它在分支 $\Omega$ 上可实现 $\iff\chi(H_\Omega)=0$，且此时解恰为 $p(P)=c_\Omega+\chi(g)$（$P\in\M_{gH_\Omega}$），各分支的常数 $c_\Omega$ 相互独立；
  3. 定理 C / thm:simultaneous-reconstruction：一对相容的（monoidal, module）三角等价可还原出 $(\C,\M)$ 的精确 $k$-线性张量等价与模等价；特例 cor:algebra-objects 给出可分代数对象 $A,B$ 的 Morita 类重构；例 ex:nonsemisimple 用 BGP 反射说明「半单性假设不可省」。
- **关键先驱工作**：EGNO 的 tensor category 框架与 Morita 等价定义；Xu–Zheng（monoidal $t$-structure 定义 2.6/2.10、定义 2.23 的唯一性定理、2.11/2.15 关于 normalized 与 deviation）；Zhang–Zhou（monoidal $t$-structure 的动机）；Biglari（compatible bounded $t$-structure）；Yu（Definitions 3.1/3.4、Theorem 4.5、Corollary 4.7 及提出的无限情形问题）；ENOtwisted（半单张量范畴中万有分次群的万有性质）；Stroiński、Stroiński–Zorman（循环生成元、Tambara 数据、余代数对象等对模范畴的重构）；Galindo、Galindo–Graded、Meir–Musicantov（群集分次与 Clifford 理论、稳定化子子群）；Happel（BGP 反射给出的导出等价）；BBD（$t$-structure 的标准定义）。
- **结果边界**：全文以**半单**、局部有限、本质小、$k$ 代数闭为基本假设，且要求模范畴非零、作用在各变量上精确；推导所用的关键输入是「半单阿贝尔范畴中每个有界复形同构于其同调对象平移的有限直和」（lem:split-derived）。例 ex:nonsemisimple 表明去掉半单性后定理 C 不成立；例 ex:graded-vector-spaces 表明 $c\ne0$ 时移位自等价不是 $t$-exact、相应 $t$-structure 与标准结构不等价（尽管其心仍张量等价于 $\C$）。
- **应用与推广**：可用于由导出层面的（带张量/模结构的）等价反推阿贝尔层面的范畴与 Morita 类，特别是可分代数对象的模范畴（cor:algebra-objects）；万有分次群特征 $U_{\C}\to\mathbb Z$ 这一新不变量也是判别「单对象无限多时 monoidal $t$-structure 是否唯一」的直接工具（推论 cor:unique-standard），并可望用于分级张量范畴与 Clifford 理论中的分支/稳定化子分析。
- **开放问题**：作者未单列 open questions；但从例 ex:nonsemisimple 可见「半单性消去后重构是否还成立、或需要何种额外结构（如张量理想、Frobenius 性、有限维数）才能补救」是自然延伸；此外 $\chi(H_\Omega)=0$ 这一判别条件对非阿贝尔群值 grading（即 $\chi$ 取值非 $\mathbb Z$）的推广亦未展开。

## 2.  主要定理

> **Theorem (theoremA)**: Let $\C$ be an essentially small locally finite semisimple tensor category. There are bijections
> \begin{equation*}
>     \MT(D^b(\C)) \longleftrightarrow \Hom(U_{\C},\mathbb Z)\times\mathbb Z, \quad \MT_0(D^b(\C)) \longleftrightarrow \Hom(U_{\C},\mathbb Z).
> \end{equation*}
> The pair $(\chi,d)$ corresponds to the shift function $p(X)=\chi(\deg X)+d$. The corresponding $t$-structure has deviation $\{d\}$. Moreover, if $\D$ is another essentially small locally finite semisimple tensor category, then
> \[
> D^b(\C)\simeq_\otimes D^b(\D)\quad\Longrightarrow\quad\C\simeq_\otimes\D.
> \]

*动机 / 作用（中文）*: 这是全文第一主定理：它把「$D^b(\C)$ 上所有有界 monoidal $t$-structure」这一看似无穷复杂的对象，完全参数化为「$U_{\C}$ 的整值特征 + 一个整数」，并把「monoidal 三角等价 $\Rightarrow$ 张量等价」这一重构结论从有限多单对象的情形推广到任意（甚至无限多单对象）的半单张量范畴。它同时回答了 Yu 在 Corollary 4.7 之后提出的问题。

*证明思路（中文）*: 由 prop:semisimple-t，有界 $t$-structure 由平移函数 $p\colon\Irr(\C)\to\mathbb Z$ 唯一决定。给定 $d\in\dev(t_p)$，对 $Z\le X\otimes Y$ 用 monoidal 条件 \eqref{eq:monoidal-t} 的两条包含关系分别作用于 $X[p(X)]$、$Y[p(Y)-d]$，得到等式 $p(Z)=p(X)+p(Y)-d$；取 $X=Y=Z=\one$ 得 $p(\one)=d$，故 $X\mapsto p(X)-d$ 在张量积的单直和项上可加，由 $U_{\C}$ 的万有性质得到唯一特征 $\chi$ 使 $p(X)=\chi(\deg X)+d$。反向由核验包含关系即得偏差 $\{d\}$，并证明 $d=p(\one)$ 唯一。重构部分见 thm:tensor-reconstruction。

> **Theorem (theoremB)**: Let $\M$ be nonzero. Let the monoidal $t$-structure on $D^b(\C)$ have shift function $q(X)=\chi(\deg X)+d$, and let $p\colon\Irr(\M)\to\mathbb Z$ determine a bounded $t$-structure on $D^b(\M)$. An integer $m$ is a module deviation if and only if
> \[
> p(P)=q(X)+p(M)-m
> \]
> whenever $X\in\Irr(\C)$, $M,P\in\Irr(\M)$, and $P$ is a direct summand of $X\odot M$.
> A module deviation exists if and only if
> \[
> p(P)=p(M)+\chi(\deg X)
> \]
> for every such triple. In this case, $\dev_{t_q}(t_p)={d}$.
> For a component $\Omega$, a function $p$ satisfying this relation exists if and only if $\chi(H_\Omega)=0$. When this condition holds, all such functions on $\Omega$ have the form
> \[
> p(P)=c_\Omega+\chi(g),\quad P\in\M_{gH_\Omega},
> \]
> where $c_\Omega\in\mathbb Z$ is arbitrary. The constants on different components can be chosen independently.

*动机 / 作用（中文）*: 第二主定理：$D^b(\M)$ 本身没有内蕴张量积，无法直接套用张量重构，因此必须研究「与 $D^b(\C)$ 上 monoidal $t$-structure 相容」的模 $t$-structure。该定理给出了相容性的**显式判别公式**，并把解空间刻画为「每个模连通分支一个自由整数平移」，从而说明模偏差与张量偏差必然相等（都是 $d$）。

*证明思路（中文）*: 先设 $m$ 是模偏差，把 $X[q(X)]$、$M[p(M)-m]$ 置于相应 $t$-structure 的截断层/余截断层，其模作用落在心中，于是 $P[q(X)+p(M)-m]\in\Hh_p$，而 $P$ 在心内的唯一平移是 $P[p(P)]$，得一般公式；取 $X=\one,P=M$ 得 $m=q(\one)=d$，代入即得相容公式。反向只须在单对象平移上核验 $\eqref{eq:module-deviation}$ 的两条包含，并计算 $X=\one$ 得唯一性；$d=0$ 时相容公式等价于 $\Hh_\chi\odot\Hh_p\subseteq\Hh_p$。分支与稳定化子的分析（def:component-stabilizer、prop:coset-grading、thm:stabilizer）进一步把解写成 $c_\Omega+\chi(g)$。

> **Theorem (theoremC)**: Let $\C$ and $\D$ be essentially small locally finite semisimple tensor categories, and let $\M$ and $\N$ be nonzero essentially small locally finite semisimple left module categories over $\C$ and $\D$, respectively. Suppose that $F: D^b(\C)\to D^b(\D)$ is a monoidal triangulated equivalence and that $G: D^b(\M)\to D^b(\N)$ is a triangulated equivalence with a coherent $F$-module-functor structure. Then there are an exact $k$-linear tensor equivalence $f:\C\to\D$ and an exact $k$-linear $f$-module equivalence $g:\M\to\N$.

*动机 / 作用（中文）*: 第三主定理，也是全文的终点：**同时**重构张量范畴与其模范畴。与 Xu–Zheng / Yu 依赖「限制某个环境 monoidal 函子」或「有限多单对象」不同，这里处理的是无穷多单同构类、可能可分解、且平移函数可以无界的一般半单情形。

*证明思路（中文）*: 沿 $F$、$G$ 运输标准 $t$-structure，由 prop:transported-pair 得 $D^b(\D)$ 上带唯一特征 $\chi$ 的 normalized monoidal $t$-structure与 $D^b(\N)$ 上的 $p$，且满足相容公式。于是限制 $F|_\C$、$G|_\M$ 给出到心 $\Hh_\chi$、$\Hh_p$ 的精确（张量/模）等价；再由 thm:tensor-regrading 与 thm:module-regrading 造出 $R_\chi:\D\to\Hh_\chi$、$R_p:\N\to\Hh_p$，取拟逆 $S,Q$，用 $R$ 的满忠实唯一确定 $S$ 的张量结构、用 $P$ 的满忠实唯一确定 $Q$ 的 $S$-模结构（\eqref{eq:S-tensorator}、\eqref{eq:kappa}），最后把 $\overline G$ 的模约束倒置并与 $\kappa$ 复合得到 $g$ 的 $f$-模结构，相干性由 $\mu,\rho,\varepsilon,\delta$ 的相干性自动给出。

### 2.1.  证明思路

- **第一步（半单导出范畴的拆卸）**：由 lem:split-derived，$D^b(\A)$ 中每个对象都是 $S[a]$（$S$ 单、$a\in\mathbb Z$）的有限直和，且 $\Hom(S[a],T[b])\cong\Ext^{b-a}(S,T)$ 仅在 $a=b$、$S\cong T$ 时非零。这把一切问题化归为「对单对象平移逐一指定位置」，是 prop:semisimple-t 的基础。
- **第二步（有界 $t$-structure 的参数化）**：用截断三角形证明单对象平移 $S[a]$ 必落在 aisle 或 coaisle 之一（不可能两者都落，否则与正交性矛盾），且 $\{a:S[a]\in\mathcal U\}$ 上闭、非空、真，故由唯一整数 $p(S)$ 截断；反之任意函数 $p$ 给出有界 $t$-structure $t_p$，心为 $\add\{S[p(S)]\}$。
- **第三步（张量情形：特征 + 偏差）**：在单直和项关系 $Z\le X\otimes Y$ 上使用 monoidal 条件，得到 $p(Z)=p(X)+p(Y)-d$；由 $U_{\C}$ 的万有性质唯一提升为特征 $\chi$，从而得到定理 A 的分类与 thm:monoidal-classification；偏差唯一为 $\{p(\one)\}$。
- **第四步（等价性的判据）**：prop:uniform-comparison 说明两个有界 $t$-structure 等价 $\iff$ 平移函数之差有界；推论 cor:characters-not-comparable 进一步说明不同特征给出的 normalized monoidal $t$-structure 必不等价（因为存在无限阶元素 $g$ 使 $r\delta(g)$ 无界）。这一步是「无限多单对象情形与有限情形根本不同」的技术核心。
- **第五步（模情形：相容公式与稳定化子）**：由 lem:derived-action 把模作用提升为三角作用，定义相容（def:compatible-module-product）与模偏差（def:triangulated-module-t）；用 thm:module-compatibility 得相容公式；用分支图与稳定化子 $H_\Omega$（def:component-stabilizer、prop:coset-grading：$H_\Omega$ 确为子群、$\Omega$ 按 $U_{\C}/H_\Omega$ 分次）证明 thm:stabilizer：分支上可解 $\iff\chi(H_\Omega)=0$，解形如 $c_\Omega+\chi(g)$。
- **第六步（重构函子的构造）**：定义 $R_\chi(X)=\bigoplus_nX_n[n]$、$T_\chi(K)=\bigoplus_nK_n[n]$、$R_p(M)=\bigoplus_rM_r[r]$，用 lem:shift-isomorphism 的 Koszul 型符号 $\sigma_{a,b}(x\star y)=(-1)^{bi}x\star y$ 构造张量与模的 tensorator 并核验相干性，得到 thm:tensor-regrading、prop:derived-regrading、thm:module-regrading，最后组装成 thm:tensor-reconstruction 与 thm:simultaneous-reconstruction。
- **第七步（不可省性验证）**：用 BGP 反射给出 $\Vect^{\mathrm{fd}}$ 上两个非同构路径代数 $A=k(1\to2\to3)$、$B=k(1\leftarrow2\to3)$ 的导出模块等价，说明半单性不可删（ex:nonsemisimple）；用 $k$ 与 $M_n(k)$ 说明 Morita 等价未必同构。

## 3.  关键组件

### 3.1.  关键定义

> **Definition (def:monoidal-t-structure)**: Let $(\T,\otimes,\one)$ be a monoidal triangulated category. Let $t=(\T^{\leq0},\T^{\geq1})$ be a bounded $t$-structure on $\T$. The $t$-structure $t$ is \emph{monoidal} if there exists $d\in\mathbb Z$ such that
> \begin{equation}\label{eq:monoidal-t}
> \T^{\leq0}\otimes\T^{\leq d}\subseteq\T^{\leq0},\quad \T^{\geq0}\otimes\T^{\geq d}\subseteq\T^{\geq0}.
> \end{equation}
> Its \emph{deviation} $\dev(t)$ is the set of all integers $d$ satisfying \eqref{eq:monoidal-t}. A monoidal $t$-structure is \emph{normalized} if $0\in\dev(t)$.

*直观动机与作用*: 这是全篇的起点定义（取自 Xu–Zheng，动机来自 Zhang–Zhou，normalized 情形与 Biglari 的 compatible bounded $t$-structure 一致）：它把「$t$-structure 与张量积兼容」精确化为两条层级包含关系，而偏差 $d$ 则度量兼容性的「偏移量」。作者后来证明（thm:monoidal-classification）偏差集合总是单点集 $\{d\}$，因此 monoidal $t$-structure 的分类退化为「特征 + 偏差」的分类。

> **Definition (def:module-components)**: The graph associated with $\M$ has vertex set $\Irr(\M)$. Two vertices $M$ and $P$ are joined when $P$ is a direct summand of $X\odot M$ for some $X\in\Irr(\C)$. A connected component of this graph is called a \emph{component of $\M$}.

*直观动机与作用*: 把模范畴按「$\C$-作用连通性」拆成若干块。作者随后证明这些连通分支恰是 $\M$ 的**不可分解半单模直和项**，因此模 $t$-structure 的构造可以逐分支独立进行——这正是定理 B 中「常数 $c_\Omega$ 可独立选取」的范畴论根源，也是与 Clifford 理论中群集分次/轨道分解的类比所在。

> **Definition (def:component-stabilizer)**: Define $H_\Omega\subseteq U_{\C}$ by
> \begin{equation}\label{eq:stabilizer}
> H_\Omega=\{g\in U_{\C}:M_0\text{ is a direct summand of }X_g\odot M_0\text{ for some }X_g\in\C_g\}.
> \end{equation}

*直观动机与作用*: 这是「模的稳定化子」的范畴化：$H_\Omega$ 收集那些（在万有分次下）把基准单对象 $M_0$ 作用回自身的次数。作者证明它是子群（prop:coset-grading），并使 $\Omega$ 成为左 $U_{\C}$-集 $U_{\C}/H_\Omega$ 分次的集。它与 Clifford 理论中「群分次」的情形类比，是判别相容 $t$-structure 存在性的唯一障碍：$\chi(H_\Omega)=0$。

> **Definition (def:triangulated-module-t)**: The bounded $t$-structure $t_p$ is a \emph{triangulated module $t$-structure with respect to $t_q$} if there exists $m\in\mathbb Z$ such that
> \begin{equation}\label{eq:module-deviation}
> D_q^{\leq0}\odot D_p^{\leq m}\subseteq D_p^{\leq0},\quad D_q^{\geq0}\odot D_p^{\geq m}\subseteq D_p^{\geq0}.
> \end{equation}
> The set of all such integers is the \emph{deviation of $t_p$ with respect to $t_q$}, denoted by $\dev_{t_q}(t_p)$.

*直观动机与作用*: 相对版本的定义（取自 Yu, Definition 3.4）：把张量情形的偏差概念换成「在与 $t_q$ 相容的意义下，$t_p$ 需要整体平移多少」。定理 B 的结论 $\dev_{t_q}(t_p)=\{d\}$ 说明模偏差与张量偏差必须一致——这是两个 $t$-structure 相容的「代价」被环境范畴的偏差锁定。

### 3.2.  关键引理

> **Lemma (lem:split-derived)**: Let $\A$ be an essentially small semisimple abelian category in which every object has finite length. Then every object of $D^b(\A)$ is a finite direct sum of objects $S[a]$ with $S\in\Irr(\A)$ and $a\in\mathbb Z$. Moreover,
> \[
> \Hom_{D^b(\A)}(S[a],T[b])\cong\Ext_{\A}^{b-a}(S,T),
> \]
> so this group is zero unless $a=b$ and $S\cong T$.

*动机 / 作用（中文）*: 全文的「原子分解引理」：它把一个本质上含无穷多单对象、看起来难以把握的导出范畴，还原为「单对象 + 整数平移」的离散组合数据。没有它，后续所有 $t$-structure 的参数化、平移函数 $p$ 的定义、以及无界 $p$ 仍给出有界 $t$-structure 的断言都无法进行。

*证明思路（中文）*: 半单性使 $\A$ 中每个短正合列分裂，故有界复形在导出范畴内同构于其同调对象按原次数摆放的直和；同调对象有限多个且各具有限长度，分解为单对象直和；再用 $\Hom(S[a],T[b])\cong\Ext^{b-a}(S,T)$ 与半单性（正次数 Ext 全灭、$\Hom(S,T)=0$ 除非同构）得正交性。

> **Lemma (lem:tensor-reduced)**: If $0\ne K\in D^b(\C)$, then $K\otimes K\ne0$.

*动机 / 作用（中文）*: 说明半单张量范畴的导出范畴是 tensor reduced（无零因子），这是 Xu–Zheng 重构定理的输入条件；它也表明 normalized monoidal $t$-structure 之间可能不等价（与 cor:characters-not-comparable 配合），因此不能照搬有限情形的唯一性论证。

*证明思路（中文）*: 先在阿贝尔层面：对非零 $A,Y\in\C$，令 $\{B:B\otimes Y=0\}$ 为左 Serre 张量理想；若含非零 $A$，则含 $A^*\otimes A$，而求值 $A^*\otimes A\to\one$ 由三角恒等式非零、因 $\one$ 单纯而为满射，故该理想含 $\one$，与 $Y\ne0$ 矛盾，于是 $A\otimes Y\ne0$。再取 $q$ 为 $K$ 的最高同调次数，由张量积的精确性与半单性得 $H^{2q}(K\otimes K)\cong H^q(K)\otimes H^q(K)\ne0$。

> **Lemma (lem:derived-action)**: For bounded complexes $K\in C^b(\C)$ and $L\in C^b(\M)$, set
> \[
> (K\odot L)^r=\bigoplus_{i+j=r}K^i\odot L^j,
> \]
> with differential
> \begin{equation}\label{eq:total-action-differential}
> d(x\odot y)=d_Kx\odot y+(-1)^i x\odot d_Ly,\quad x\in K^i.
> \end{equation}
> This construction induces a triangulated action $D^b(\C)\times D^b(\M)\to D^b(\M)$. The module associator acts degreewise, with no additional sign.

*动机 / 作用（中文）*: 提供「导出层面的模作用」这一基础设施：定理 B、C 中出现的 $D^b(\C)\odot D^b(\M)\subseteq D^b(\M)$ 才有意义。同时它固定了符号约定（Koszul 型），后续 lem:shift-isomorphism 与各 tensorator 的相干性计算都依赖于此。

*证明思路（中文）*: 总复形因和有限而良定义；在半单阿贝尔范畴中，有界无环复形可缩，故只须验证作用保持可缩复形：若 $h$ 收缩 $K$，则 $\tilde h(x\odot y)=h(x)\odot y$ 收缩 $K\odot L$；若 $h$ 收缩 $L$，则 $\tilde h(x\odot y)=(-1)^i x\odot h(y)$ 收缩之。故作用在每一变量上保持拟同构并下降到导出范畴。模结构方面把模结合子逐次数应用：在 $K_1^i\odot K_2^j\odot L^r$ 上两种括号下的三项微分系数都是 $1,(-1)^i,(-1)^{i+j}$，故结合子是链映射；五边形与单位图逐次数归结为 $\M$ 中原图。

> **Lemma (lem:shift-isomorphism)**: Let $K\in C^b(\C)$ and let $L$ be a bounded complex in $\C$ or $\M$. For integers $a,b$, there is a natural chain isomorphism
> \[
> \sigma_{a,b}: K[a]\star L[b]\rightarrow(K\star L)[a+b]
> \]
> defined by
> \begin{equation}\label{eq:shift-isomorphism}
> \sigma_{a,b}(x\star y)=(-1)^{bi}x\star y,\quad x\in K[a]^i.
> \end{equation}
> For three factors, these isomorphisms are compatible with associativity.

*动机 / 作用（中文）*: 这是构造所有重构函子（$R_\chi$、$T_\chi$、$R_p$）的**唯一技术工具**：张量/模函数子的 tensorator 就定义在「先分别平移再相乘」与「先相乘再平移」之间，而 Koszul 符号 $(-1)^{bi}$ 恰好保证了与总复形微分及结合律的相容性。作者还显式验证了三因子的符号相等（$(-1)^{bi+c(i+j)}=(-1)^{cj+(b+c)i}$），这是相干性证明的关键一步。

*证明思路（中文）*: 直接计算源与目标两边的微分系数：源为 $(-1)^ad_Kx\star y+(-1)^{i+b}x\star d_Ly$，经 $\sigma_{a,b}$ 后系数为 $(-1)^{a+b(i+1)}$ 与 $(-1)^{bi+i+b}$；先在目标上取微分再与 $\sigma$ 比较得相同系数，故为链同构，且对 $K,L$ 自然。三因子的结合相容性通过比较两个复合的符号而归结为原结合图（总复形结合子逐次数作用、不贡献额外符号）。

> **Proposition (prop:coset-grading)**: The subset $H_\Omega$ is a subgroup of $U_{\C}$. Every $P\in\Omega$ is a direct summand of $X_g\odot M_0$ for some $g\in U_{\C}$ and some $X_g\in\C_g$. If $P$ is also a direct summand of $Y_h\odot M_0$ for some $Y_h\in\C_h$, then $gH_\Omega=hH_\Omega$.

*动机 / 作用（中文）*: 这条命题把「稳定化子」从一个定义升级为可用的结构定理：$H_\Omega$ 是子群、且 $\Omega$ 是分次集 $U_{\C}/H_\Omega$。这既使 $\deg_\Omega(P)=gH_\Omega$ 良定义，也使 thm:stabilizer 中的解形式 $p(P)=c_\Omega+\chi(g)$ 有意义（良定义性正依赖 $g^{-1}g'\in H_\Omega\Rightarrow\chi(g')=\chi(g)$）。

*证明思路（中文）*: 单位元由单位约束给出；乘法由两次分裂包含的复合 $M_0\to X_g\odot M_0\to X_g\odot(Y_h\odot M_0)\cong(X_g\otimes Y_h)\odot M_0$ 给出，逆元由刚性给出的非零映射 $X_g^*\odot M_0\to M_0$ 因 $M_0$ 单纯而为分裂满射、配合 $X_g^*\in\C_{g^{-1}}$ 得到。连通性通过沿路径用对偶替换推进方向，逐步复合分裂包含。同一对象的两个次数由另一个分裂包含构造 $M_0\to(X_g^*\otimes Y_h)\odot M_0$ 并因 $\M$ 半单而分裂，得 $g^{-1}h\in H_\Omega$。

### 3.3.  其余关键命题

> **Proposition (prop:semisimple-t)**: For every bounded $t$-structure on $D^b(\A)$, there is a unique function $p:\Irr(\A)\to\mathbb Z$ such that $S[p(S)]$ belongs to its heart for every simple object $S$. Conversely, every such function defines a bounded $t$-structure $t_p$ by
> \[
> D_p^{\leq0}=\add\{S[a]:a\geq p(S)\},\quad D_p^{\geq1}=\add\{S[a]:a<p(S)\}.
> \]
> Its coaisle and heart are
> \[
> D_p^{\geq0}=\add\{S[a]:a\leq p(S)\},\quad \Hh_p=\add\{S[p(S)]:S\in\Irr(\A)\}.
> \]

*动机 / 作用（中文）*: 把「有界 $t$-structure」与「函数 $p\colon\Irr(\A)\to\mathbb Z$」一一对应起来，成为整篇文章的坐标系；特别地，$p$ 本身**不需要有界**，这正对应「无限多单对象时平移函数可相差无界函数」这一新现象。等价关系则由 $S[a]\in D_p^{\leq m}\iff a\ge p(S)-m$（式 \eqref{eq:shifted-halves}）给出。

*证明思路（中文）*: 对单对象平移 $S[a]$ 取截断三角形 $U\to S[a]\to V\to U[1]$：若首映射非零，则限制到某个 $S[a]$ 直和项上为同构，从而首映射是分裂满射、$S[a]\in\mathcal U$；若为零，则 $V\cong S[a]\oplus U[1]$、$S[a]\in\mathcal V$。由正交性两者不能同时成立，故诸单对象平移被划分。固定 $S$ 后集合 $\{a:S[a]\in\mathcal U\}$ 因 $\mathcal U[1]\subseteq\mathcal U$ 上闭、由有界性非空且真，故为 $\{a\ge p(S)\}$；反向由直和项按阈值分离构造截断三角形并验证有界性。

> **Theorem (thm:monoidal-classification)**: There is a bijection
> \begin{equation*}
>     \MT(D^b(\C)) \longleftrightarrow \Hom(U_{\C},\mathbb Z)\times\mathbb Z.
> \end{equation*}
> More precisely, suppose that $t_p$ is monoidal and $d\in\dev(t_p)$. Then there is a unique homomorphism $\chi: U_{\C}\to\mathbb Z$ such that
> \begin{equation}\label{eq:p-character-d}
> p(X)=\chi(\deg X)+d
> \end{equation}
> for every simple object $X$. Conversely, every pair $(\chi,d)$ defines a monoidal $t$-structure by this formula with deviation $\{d\}$.

*动机 / 作用（中文）*: 定理 A 的「内部」精细版，把分类双射具体化为平移函数公式 \eqref{eq:p-character-d}，并顺带证明偏差集合总是单点集 $\{d\}$——这既简化了定义 def:monoidal-t-structure 中偏差的不确定性，也为定理 B 中「模偏差 = 张量偏差」埋下伏笔。

*证明思路（中文）*: 见「主要定理」中 theoremA 的证明思路：由 $Z\le X\otimes Y$ 用两条包含推出 $p(Z)=p(X)+p(Y)-d$，得 $p(\one)=d$，再用 $U_{\C}$ 的万有性质提升为 $\chi$；反向逐项验证包含关系得到偏差 $\{d\}$，并由 $e=p(\one)=d$ 得唯一性。

> **Proposition (prop:uniform-comparison)**: Let $p,q:\Irr(\C)\to\mathbb Z$. The bounded $t$-structures $t_p$ and $t_q$ are equivalent if and only if $p-q$ is bounded on $\Irr(\C)$.

> **Corollary (cor:characters-not-comparable)**: Distinct characters $\chi,\psi\in\Hom(U_{\C},\mathbb Z)$ define inequivalent normalized monoidal $t$-structures.

*动机 / 作用（中文）*: 这两条刻画了「一致比较」的适用边界：有限多单对象时任何两个平移函数之差都有界（这正是 Xu–Zheng 与 Yu 的 finiteness 步骤），但一旦单对象无限多、且存在无限阶元素 $g$，则 $(p_\chi-p_\psi)(S_r)=r\delta(g)$ 无界，不同特征给出**不可比**的 $t$-structure。这解释了为何必须放弃一致比较、转而构造新的 regrading 函子。

*证明思路（中文）*: 由式 \eqref{eq:shifted-halves}，包含 $D_p^{\leq m}\subseteq D_q^{\leq0}\subseteq D_p^{\leq n}$ 恰好等价于对一切 $S$ 有 $m\le p(S)-q(S)\le n$。取 $\delta=\chi-\psi\ne0$，某 $g$ 满足 $\delta(g)\ne0$，则 $g$ 无限阶、万有分次忠实，故对每个 $r$ 存在次数 $g^r$ 的单对象 $S_r$，$(p_\chi-p_\psi)(S_r)=r\delta(g)$ 无界。

> **Theorem (thm:module-compatibility)**: Assume that $\M$ is nonzero. Let $p:\Irr(\M)\to\mathbb Z$ determine a bounded $t$-structure on $D^b(\M)$. An integer $m$ belongs to $\dev_{t_q}(t_p)$ if and only if
> \begin{equation}\label{eq:compatibility-general}
> p(P)=q(X)+p(M)-m
> \end{equation}
> whenever $X\in\Irr(\C)$, $M,P\in\Irr(\M)$, and $P$ is a direct summand of $X\odot M$. Such an integer exists if and only if
> \begin{equation}\label{eq:compatibility}
> p(P)=p(M)+\chi(\deg X)
> \end{equation}
> for every such triple. In this case, $\dev_{t_q}(t_p)=\{d\}$. When $d=0$, relation \eqref{eq:compatibility} is also equivalent to $\Hh_\chi\odot\Hh_p\subseteq\Hh_p$.

*动机 / 作用（中文）*: 定理 B 的第一半，给出模相容性的**判定等式**与「模偏差与张量偏差相等」这一结论；并指出 $d=0$（normalized）时它可以等价地写成心对模作用封闭——这把抽象的定义 def:compatible-module-product 变成了可计算的判据。

*证明思路（中文）*: 见「主要定理」theoremB 的证明思路：利用 $X[q(X)]$、$M[p(M)-m]$ 同时落在相应层中、其乘积落在心中，而心内单对象的平移唯一（由 prop:semisimple-t），得 \eqref{eq:compatibility-general}；取 $X=\one$、$P=M$ 得 $m=q(\one)=d$；反向在单对象平移上核验两条包含，并用三角不等式平移到更一般层级；$d=0$ 时把心内封闭性逐单直和项展开即回到 \eqref{eq:compatibility}。

> **Theorem (thm:stabilizer)**: Fix $\chi: U_{\C}\to\mathbb Z$. On a component $\Omega$, a function $p$ satisfying \eqref{eq:compatibility} exists if and only if
> \begin{equation}\label{eq:stabilizer-condition}
> \chi(H_\Omega)=0.
> \end{equation}
> When this condition holds, all such functions have the form
> \begin{equation}\label{eq:component-functions}
> p(P)=c_\Omega+\chi(g),\quad P\in\M_{gH_\Omega},
> \end{equation}
> where $c_\Omega\in\mathbb Z$ is arbitrary. The constants on distinct components are independent.

*动机 / 作用（中文）*: 定理 B 的第二半，也是最富「结构性」的结论：它把「相容模 $t$-structure 存在性」完全归结为**一个群论条件** $\chi(H_\Omega)=0$（在 $\chi$ 为阿贝尔群 $\mathbb Z$ 值时，共轭不变，故与 $M_0$ 的选取无关），并在存在时给出完整解集：每个分支上一个自由整数参数 $c_\Omega$。这解释了标准 $t$-structure（$\chi=0$）下「每个模分支可任意平移一个整数，且互不干涉」的直观图景。

*证明思路（中文）*: 必要性：若 $h\in H_\Omega$，取 $X_h\in\C_h$ 使 $M_0$ 是 $X_h\odot M_0$ 的直和项，再取其单直和项 $Y_h\in\C_h$ 同样作用到 $M_0$，代入 \eqref{eq:compatibility} 得 $p(M_0)=p(M_0)+\chi(h)$，故 $\chi(h)=0$。存在性：对 $P\in\M_{gH_\Omega}$ 取 $Y_g\in\C_g$ 使 $P$ 是其与 $M_0$ 作用的直和项，代入得 $p(P)=p(M_0)+\chi(g)$，故形如 \eqref{eq:component-functions}。充分性：需验证良定义（若 $gH_\Omega=g'H_\Omega$ 则 $\chi(g')-\chi(g)=\chi(g^{-1}g')=0$）与相容性（若 $Q$ 是 $X\odot P$ 的单直和项，则 \eqref{eq:coset-action} 给出 $Q\in\M_{xgH_\Omega}$，于是 $p(Q)=c_\Omega+\chi(xg)=p(P)+\chi(x)$）。

> **Theorem (thm:tensor-regrading)**: The functor
> \[
> R_\chi:\C\rightarrow\Hh_\chi,\quad R_\chi(X)=\bigoplus_n X_n[n],
> \]
> admits a strong monoidal structure and is an exact tensor equivalence.

> **Proposition (prop:derived-regrading)**: The functor
> \[
> T_\chi: D^b(\C)\rightarrow D^b(\C),\quad T_\chi(K)=\bigoplus_n K_n[n],
> \]
> is a strong monoidal triangulated autoequivalence. Its restriction to the standard heart is $R_\chi$. In particular, it sends the standard heart onto $\Hh_\chi$.

*动机 / 作用（中文）*: 这是「重构」的实际执行者：$R_\chi$ 把原来的张量范畴 $\C$ 精确地搬到对某个特征 $\chi$ 的心 $\Hh_\chi$ 上，且保持张量结构；$T_\chi$ 则把标准心送到 $\Hh_\chi$，并在 $D^b(\C)=\bigoplus_nD^b(\C_n)$ 上扮演「各齐次分量平移 $n$」的角色。二者一起说明：即使 $t$-structure 与标准结构不等价（例 ex:graded-vector-spaces 中 $c\ne0$），其心仍与原范畴张量等价——这正是「$t$-structure 不唯一但重构仍成立」的关键。

*证明思路（中文）*: $R_\chi$：半单性给出 $\Hom_{\Hh_\chi}(R_\chi(X),R_\chi(Y))\cong\bigoplus_n\Hom_\C(X_n,Y_n)\cong\Hom_\C(X,Y)$，故满忠实，且每个 $\Hh_\chi$ 中对象是单对象按指定平移的有限直和，故本质满射；张量结构取 $\mu_{X,Y}$ 在 $X_n[n]\otimes Y_m[m]$ 上为 $\sigma_{n,m}$ 与自然包含 $(X_n\otimes Y_m)[n+m]\to(X\otimes Y)_{n+m}[n+m]$ 的复合，结合相干性由两边的符号 $(-1)^{nm+(n+m)\ell}$ 与 $(-1)^{m\ell+n(m+\ell)}$ 相等给出。$T_\chi$：逐次数应用精确的齐次投影得函子性分解 $K=\bigoplus_nK_n$，在 $D^b(\C_n)$ 上 $T_\chi=[n]$，故为三角自等价；张量器由 $\sigma_{n,m}$ 给出，单位约束为恒等。

> **Theorem (thm:module-regrading)**: The functor
> \[
> R_p:\M\rightarrow\Hh_p,\quad R_p(M)=\bigoplus_r M_r[r],
> \]
> is an exact equivalence. It admits a coherent $R_\chi$-module-functor structure and is an $R_\chi$-module equivalence.

*动机 / 作用（中文）*: 模版本的重构执行者，把 $\M$ 精确搬到 $\Hh_p$ 并赋予与 $R_\chi$ 相干的模函子结构。其关键在于相容公式 \eqref{eq:graded-action}：$\C_n\odot\M_r\subseteq\M_{n+r}$，保证 $\rho_{X,M}$ 的每个直和项都落在正确的齐次分量中，从而模结合图的符号 $(-1)^{ns+(n+s)r}$ 与 $(-1)^{sr+n(s+r)}$ 相等。

*证明思路（中文）*: 与 thm:tensor-regrading 平行：满忠实由 $\Hom_{\Hh_p}(R_p(M),R_p(N))\cong\bigoplus_r\Hom_\M(M_r,N_r)\cong\Hom_\M(M,N)$ 给出，本质满射由 $\Hh_p$ 中对象皆为单对象指定平移的有限直和给出；模 tensorator $\rho_{X,M}$ 在 $X_n[n]\odot M_r[r]$ 上取 $\sigma_{n,r}$ 与包含 $(X_n\odot M_r)[n+r]\to(X\odot M)_{n+r}[n+r]$ 之复合；结合相干性由符号相等得到，单位图因 $\one\in\C_0$ 而符号为 $1$。

> **Theorem (thm:tensor-reconstruction)**: Let $\C$ and $\D$ be essentially small locally finite semisimple tensor categories. If $F: D^b(\C)\to D^b(\D)$ is a monoidal triangulated equivalence, then there is an exact $k$-linear tensor equivalence $\C\simeq_\otimes\D$.

*动机 / 作用（中文）*: 定理 A 第二部分的重构证明（此前由 Xu–Zheng / Yu 在有限情形成立），此处覆盖无限多单对象情形。

*证明思路（中文）*: 沿 $F$ 运输标准 $t$-structure，得 $D^b(\D)$ 上的有界 normalized monoidal $t$-structure，由 cor:normalized-classification 其心为某个唯一 $\chi$ 对应的 $\Hh_\chi$；按定义，$F$ 的限制给出精确张量等价 $\C\to\Hh_\chi$；再由 thm:tensor-regrading 得 $R_\chi:\D\to\Hh_\chi$ 为精确张量等价，取 $R_\chi$ 的张量拟逆复合即得 $\C\to\D$。

> **Corollary (cor:t-exact-regrading)**: Let $F: D^b(\C)\to D^b(\D)$ be a monoidal triangulated equivalence. There is a unique $\chi_F\in\Hom(U_{\D},\mathbb Z)$ such that $T_{-\chi_F}\circ F$ is $t$-exact for the standard $t$-structures. If $\Hom(U_{\D},\mathbb Z)=0$, then every monoidal triangulated equivalence $D^b(\C)\to D^b(\D)$ is $t$-exact for the standard structures.

*动机 / 作用（中文）*: 量化「$F$ 离 $t$-exact 有多远」：偏差由唯一特征 $\chi_F$ 度量，而 $T_{-\chi_F}$ 正好把它修正回 $t$-exact。同时给出一个漂亮的判据：$\Hom(U_{\D},\mathbb Z)=0$（例如单对象有限时）就意味着每个 monoidal 三角等价自动 $t$-exact。结论中 $\chi_F$ 的唯一性依赖 $U_{\D}$ 的万有性质（特征由其在单对象次数上的取值决定）。

*证明思路（中文）*: 取 $\chi_F$ 为运输所得结构对应的特征，其平移函数为 $X\mapsto\chi_F(\deg X)$；由 prop:derived-regrading，$T_{-\chi_F}$ 把该 $t$-structure 送回标准结构，故复合为 $t$-exact。唯一性：若 $T_{-\eta}\circ F$ 亦 $t$-exact，则对一切单对象 $\chi_F(\deg X)=\eta(\deg X)$，由万有性质 $\eta=\chi_F$。

> **Theorem (thm:simultaneous-reconstruction)**: Let $\C$ and $\D$ be essentially small locally finite semisimple tensor categories, and let $\M$ and $\N$ be nonzero essentially small locally finite semisimple left module categories over $\C$ and $\D$, respectively. Suppose that $F: D^b(\C)\to D^b(\D)$ is a monoidal triangulated equivalence and that $G: D^b(\M)\to D^b(\N)$ is a triangulated equivalence with a coherent $F$-module-functor structure. Then there are an exact $k$-linear tensor equivalence $f:\C\to\D$ and an exact $k$-linear $f$-module equivalence $g:\M\to\N$.

*动机 / 作用（中文）*: 与定理 C 同一陈述的内部版本；它把「张量重构」与「模重构」耦合起来：$f$ 由张量数据给出，而 $g$ 必须同时是**关于 $f$** 的模等价——即导出层面的相干性（coherent $F$-module-functor structure）恰好对译为阿贝尔层面的模等价。注意其结论允许 $\M$ 可分解、允许无限多单对象、允许 $p$ 无界。

*证明思路（中文）*: 见「主要定理」theoremC 的证明思路：运输标准结构得 $\Hh_\chi$、$\Hh_p$ 与相容公式（prop:transported-pair）；限制得 $\overline F\colon\C\to\Hh_\chi$、$\overline G\colon\M\to\Hh_p$；取 $R=R_\chi$、$P=R_p$ 的拟逆 $S,Q$，用 $R$ 满忠实唯一确定 $S$ 的 tensorator（\eqref{eq:S-tensorator}）与单位映射，用 $P$ 满忠实唯一确定 $Q$ 的 $S$-模结构图 $\kappa$（\eqref{eq:kappa}）；最后以 $\overline G$ 的模约束 $\gamma$ 与 $\kappa$ 复合定义 $f=S\overline F$、$g=Q\overline G$ 之间的 $\beta$，其结合与单位条件由 $\kappa,\gamma$ 及 $f$ 的张量结构给出。

> **Corollary (cor:algebra-objects)**: Let $A\in\C$ and $B\in\D$ be separable algebra objects. Suppose that a pair $(F,G)$ as in Theorem~\ref{thm:simultaneous-reconstruction} relates
> \[
> D^b(\Mod_{\C}(A))\quad\text{and}\quad D^b(\Mod_{\D}(B)).
> \]
> Then the reconstructed tensor equivalence $f:\C\to\D$ carries $A$ to an algebra object Morita equivalent to $B$.

*动机 / 作用（中文）*: 把抽象重构定理落到「可分代数对象」这一具体场景：由导出层面的等价即可反推 $f(A)$ 与 $B$ 的 Morita 等价。这给出了一条从导出数据恢复 Morita 类的路径，也提示 Morita 等价未必同构（作者以 $\Vect^{\mathrm{fd}}$ 中 $k$ 与 $M_n(k)$ 为例）。

*证明思路（中文）*: 先证可分代数 $A$ 的右模范畴 $\Mod_\C(A)$ 半单且局部有限：可分性给出作用映射的 $A$-线性截面，故每个右模是自由模的直和项；因 $-\otimes A$ 精确，遗忘函子 $U$ 精确且 $\Hom_A(X\otimes A,-)\cong\Hom_\C(X,U(-))$，而 $\C$ 中一切对象投射，故自由 $A$-模投射、进而一切 $A$-模投射，$\Mod_\C(A)$ 半单；$\Hom_A(M,N)\subseteq\Hom_\C(M,N)$ 与有限长度给出局部有限性。于是 thm:simultaneous-reconstruction 给出 $f$-模等价 $\Mod_\C(A)\simeq\Mod_\D(B)$；用 $f$ 搬运 $A$-模结构把 $\Mod_\C(A)$ 等同于 $\Mod_\D(f(A))$，故 $\Mod_\D(f(A))$ 与 $\Mod_\D(B)$ 作为 $\D$-模范畴等价，即 $f(A)$ 与 $B$ Morita 等价。

## 4.  理解辅助

- **贯穿例子（$\Vect_{\mathbb Z}^{\mathrm{fd}}$ 与无界移位）**：取 $\C=\Vect_{\mathbb Z}^{\mathrm{fd}}$，$L_n$ 为次数 $n$ 的一维对象，则 $L_m\otimes L_n\cong L_{m+n}$、$U_{\C}\cong\mathbb Z$，特征 $\mathbb Z\to\mathbb Z$ 即乘某个整数 $c$。对应 normalized 心为 $\Hh_c=\add\{L_n[cn]\}$，$T_c(L_n[a])=L_n[a+cn]$。当 $c\ne0$ 时 $T_c$ 不是 $t$-exact，所得 $t$-structure 与标准结构不等价（因平移函数之差 $n\mapsto cn$ 无界），但其心仍张量等价于 $\C$——这就是「无限多单对象」情形的标志性现象，也说明为何不能依赖一致比较。
- **贯穿例子（稳定化子如何阻止延拓）**：在上例中取 $\M=\Vect^{\mathrm{fd}}$，作用是遗忘函子诱导的，则 $L_n\odot k\cong k$，唯一单对象的稳定化子是 $U_{\C}\cong\mathbb Z$。由 thm:stabilizer，$\chi(n)=cn$ 只有在 $c=0$ 时才能延拓为 $D^b(\M)$ 上的相容 $t$-structure——即「模范畴能承受的张量重分次只能是平凡的」。
- **贯穿例子（标准结构的唯一性）**：若 $\Irr(\C)$ 有限，则 $U_{\C}$ 有限、$\Hom(U_{\C},\mathbb Z)=0$，由 cor:unique-standard 标准 normalized monoidal $t$-structure 唯一；但每个 $d\in\mathbb Z$ 仍给出常数平移函数 $p(S)=d$ 的 monoidal $t$-structure（偏差 $\{d\}$），故唯一性只对 normalized 结构成立。
- **贯穿例子（半单性不可省的 BGP 反例）**：取路径代数 $A=k(1\to2\to3)$、$B=k(1\leftarrow2\to3)$，BGP 反射给出三角等价 $D^b(A\text{-mod})\simeq D^b(B\text{-mod})$，但 $A\text{-mod}\not\simeq B\text{-mod}$（基本代数的 Gabriel 箭图不同构）。该等价由与有界双模复形的导出张量积给出，故在 $D^b(\Vect^{\mathrm{fd}})$ 上线性；取 $\C=\D=\Vect^{\mathrm{fd}}$、$F=\mathrm{id}$ 即得一个相干导出模等价，从而定理 C 的半单性假设不能被去掉。
- **符号约定备忘**：本文采用上链复形与 $(K[a])^i=K^{i+a}$、$d^i_{K[a]}=(-1)^ad^{i+a}_K$，故集中在次数 $0$ 的柱复形 $S$ 平移后 $S[a]$ 集中在次数 $-a$；这正是 tensorator 中出现 $(-1)^{nm}$ 型符号的来源。

## 5.  主动思考区

### 5.1.  与其他工作的联系

- [[2609.06248]]：该文用「正则满射的推出 + 比较态射」刻画 arithmetic 范畴（Pixley 定理的范畴版本），同属 math.CT 且都在做「抽象代数性 ⟺ 图表/结构条件」的翻译；可与本文「用万有分次群特征参数化 $t$-structure」对照，体会两种不同的「把不可数结构化为离散不变量」的策略。
- [[2609.06278]] 与 [[2609.06428]]：同批次论文，分别讨论阿贝尔范畴与三角范畴 2-范畴的精确性、以及二范畴形式的蛇引理；本文的推导本质上是「三角范畴层面 + 半单阿贝尔层面」的往返，三者在 2-范畴语言（模函子、相干结构、正合性）上有直接的技术邻接。
- **与 Clifford 理论的联系**：$U_{\C}/H_\Omega$ 分次与稳定化子子群的结构（def:component-stabilizer、prop:coset-grading、thm:stabilizer）与有限群分次融合范畴中的 Clifford 理论（Galindo、Meir–Musicantov）形式一致；本文在一般半单张量范畴中重演了同一机制，并额外给出了「$\chi(H_\Omega)=0$」这一可计算的存在性判据。
- **与 Morita 理论/可分代数的联系**：cor:algebra-objects 说明可分代数对象的 Morita 类可由导出数据恢复，这与 EGNO 框架下 Morita 等价理论互补：后者关心模范畴层面的等价，本文给出的是「导出层面数据 ⟹ 阿贝尔层面等价」的反向重构。

### 5.3.  批判性思考

- 本文的核心假设是**半单性**，它使得 lem:split-derived 成立，从而一切问题降维为「离散数据 + 平移」。这既是优点的来源（分类完全、参数简洁），也是限制所在：ex:nonsemisimple 明确表明该框架不能覆盖非半单情形，而后者恰是代数表示论中最富内容的部分（BGP 反射、倾斜理论等）。因此本文更像是在「半单世界」里把重构问题一劳永逸地解决，而不是提出了一个可推广到一般导出范畴的方法。
- 「$\Hom(U_{\C},\mathbb Z)$」这一不变量在无限情形的核心地位值得注意：它同时控制 normalized $t$-structure 的唯一性（cor:unique-standard）、自动 $t$-exact 性（cor:t-exact-regrading）以及移位自等价是否 $t$-exact（ex:graded-vector-spaces）。但该不变量对 $\C$ 的依赖只经由 $U_{\C}$，是一个较粗的信息；文章未讨论 $\Hom(U_{\C},\mathbb Z)\ne0$ 时是否存在更细的分类不变量。
- 定理 B 中「各分支常数 $c_\Omega$ 可独立选取」意味着相容模 $t$-structure 的集合在分支无穷时是 $\mathbb Z^{\oplus|\Omega|}$ 型的巨大自由度，而作者紧接指出所得 $t$-structure 仍然有界（因为每个对象只有有限多个非零分量）。这一「局部有限的整体无界」是全文最反直觉也最有意思的现象，但它也提示：定理 C 的重构在多大程度上是「唯一」的？作者通过 $R_p$ 的显式构造说明重构是**函子式**的，却未讨论在分支无穷时不同参数选取是否给出本质相同的重构对 $(f,g)$。
- 证明的安排上，tensorator 的相干性完全依赖 Koszul 符号的显式验证（lem:shift-isomorphism 与各定理证明中的符号比较），这属于「体力活」但也是整体正确性的关键；读者若要复用这些构造，最保险的做法是直接引用 lem:shift-isomorphism 而非重新推符号。
- 与 Xu–Zheng / Yu 的差别上，作者诚实地把它定位为「去掉一致比较、去掉有限多单对象假设」的推广，并明确说明定理 A 回答了 Yu 提出的问题；但从表述看，主要技术（万有分次、特征、稳定化子）在 Grothendieck 群理论中并不陌生，本文的真正增值在于证明「分类 + 重构」在半单无限情形可以完全走通，而非发明全新工具。
