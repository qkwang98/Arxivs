# Christoffel transform and symplectic skew Howe duality

keywords: [Christoffel 变换, 离散正交多项式系综, 行列式点过程, 辛 Howe 对偶, 随机杨图]

related_paper: "Nazarov–Selemenchuk（2025）：由 Christoffel 变换得到 Krawtchouk 系综及其体渐近（本文最主要的前作）"

one_liner_summary: "论文证明对称权下迭代 Christoffel 变换所对应的共轭投影与原正交投影在原点处消失的函数子空间上只相差一个秩一算子，据此给出把局部渐近结果从正交多项式系综转移到其 Christoffel 变换版本的一般机制，并完整刻画了辛 skew Howe 对偶所诱导随机杨图的四类局部涨落。"

## 1.  核心定位

- **解决的问题**：如何在只知道原正交多项式系综局部渐近的前提下，直接得到其迭代 Christoffel 变换（权乘 $x^{2d}$）后系综的局部极限核，并把这套机制用于辛型 skew Howe 对偶给出的随机杨图。
- **大图景位置**：Christoffel 变换是正交多项式理论中经典的正交化变换，此前只有极少数工作（Poisson 化 Plancherel 测度、$z$-测度以及 Krawtchouk 系综）讨论过其渐近；本文把问题提升为"投影算子之差为秩一"这一算子层面的一般机制，从而把体极限、软边缘极限等普适结果整体搬运过去。辛情形填补的空白在于：辛 Schur 测度不像经典 Schur 测度那样有自由费米子构造，因此不能直接沿用既有的行列式点过程渐近工具。
- **主要贡献**：
  1. 证明在原点消失的函数子空间 $\ell^2_0(\mathfrak X)$ 上，共轭后的 Christoffel 变换投影 $X\hat{\mcK}_{2n}X^{-1}$ 与原正交投影 $\mcK_{2n+2}$ 之差是秩一算子（Proposition Main Lemma）；
  2. 由此建立两条转移原则：远离原点的宏观点的局部极限核在迭代 Christoffel 变换下不变（Proposition As_prop_neq0），原点处则由"主项 + 反射项"给出 hard-wall 型核（Proposition As_prop_0）；
  3. 把上述机制应用于辛 skew Howe 对偶诱导的修正 Krawtchouk 系综，得到随机杨图局部涨落的四个完整区域，并延伸到对称 Hahn 系综（含离散 Laguerre 退化）。
- **关键先驱工作**：正交多项式系综与 Christoffel–Darboux 核的一般理论（Baik–Kriecherbauer–McLaughlin–Miller）；Borodin–Olshanski 的谱投影方法；Nazarov–Selemenchuk 关于 Christoffel 变换后 Krawtchouk 系综体极限的前作；Betea 关于临界 Krawtchouk 到离散 Hermite 转移的工作；Borodin–Kuan 关于离散 hard-wall sine 核的表示论出现。
- **结果边界**：本文只处理"支撑在原点的迭代对称 Christoffel 变换" $w(x)\mapsto x^{2d}w(x)$；转移原则要求局部化中心满足 $x_N/N\to v\neq 0$，即必须远离原点，原点处必须单独分析；方法本质上依赖底层正交测度的离散格点结构；Hahn 情形中临界值 $\gamma=\gamma_{\mathrm c}(\kappa)$ 被排除在引用文献的适用形式范围之外（作者指出该处体极限可通过夹逼与连续性恢复）。
- **开放问题**：作者在结论中明确留下三条——(1) 有限秩比较能否推广到更一般的 Christoffel 变换乃至完整的 Christoffel–Geronimus–Uvarov 框架；(2) 该比较技术能否用于连续区间上的绝对连续测度，还是格点结构是方法本质；(3) $q$-形变情形下是否仍有类似的算子比较与局部极限定理。
- **应用与推广**：秩一比较只用到"投影 + 三项递推 + 权在原点消失"这三件事，因此原则上可迁移到任何由 Weyl 维数公式、Lindström–Gessel–Viennot 引理或其它组合计数产生的离散正交多项式系综（Hahn、Meixner、Charlier、离散 Laguerre 等），也可用于研究 Christoffel 变换不改变体普适性这一现象的更一般版本。

## 2.  主要定理

*全局假定 / 背景（中文）*: 设 $N\in\NN$，$w(x)=w^{(0)}(x)$ 是定义在对称格点 $\mathfrak X=\{-N,\dots,N\}$ 上的对称正权，$\{P_m\}$ 为相应的首一正交多项式，$p_m(x)=P_m(x)\|P_m\|^{-1}\sqrt{w(x)}$ 为 $\ell^2(\mathfrak X)$ 中的标准正交函数；第 $d$ 次 Christoffel 变换后的权记为 $w^{(d)}(x)=x^{2d}w(x)$。$\mathfrak K_n^{(d)}$ 表示二次格点上的 Christoffel–Darboux 核，$\mcK_{2n}$ 表示到 $\langle p_{2m}\rangle_{m=0}^{n-1}$ 的正交投影。

> **Proposition（Main Lemma，秩一比较）**: On the subspace $\ell^2_0(\mathfrak X)$, the operator $X\hat{\mcK}_{2n}X^{-1}-\mcK_{2n+2}$ is represented, for $y\neq0$, by the kernel $\frac{x}{2y}\mathfrak K_n^{(1)}(x,y) - \frac{1}{2\eta(x)}\mathfrak K_{n+1}^{(0)}(x,y) = -\frac{\sqrt{\beta_{2n+1}}}{y} p_{2n}(x)p_{2n+1}(y).$ In particular, this operator has rank one. Moreover, if $w(0)=0$, it simplifies to $\frac{x}{2y}\mathfrak K_n^{(1)}(x,y) - \frac{1}{2}\mathfrak K_{n+1}^{(0)}(x,y) = -\frac{\sqrt{\beta_{2n+1}}}{y} p_{2n}(x)p_{2n+1}(y).$

*动机 / 作用（中文）*: 这是全文的技术心脏。Christoffel 变换本身不是正交投影，但它与"乘以 $x$ 再共轭"的算子 $X\hat{\mcK}_{2n}X^{-1}$ 只差一个秩一修正量 $\Delta_{2n}$；由于秩一算子在局部标度下通常趋于零，原系综的局部极限核便可原封不动地传给变换后的系综。
*证明思路（中文）*: 观察到 $\Delta_{2n}$ 在一组显式基 $\{x\hat p_m\}$ 上作用极其简单——除 $m=2n$ 外全部为零，于是像空间一维、核空间为 $\ell^2_{-,0}(\mathfrak X)$；再由三项递推与 $\hat P_{2m}=P_{2m+1}/x$ 把该基向量上的取值化为 $-\sqrt{\beta_{2n+1}}p_{2n}$，即得核的显式表达。

> **Proposition（As_prop_neq0，远离原点的转移原则）**: Let $N\to\infty$, and let $n=n(N)$ be a sequence of positive integers such that $n\longrightarrow\infty,\qquad N-n\longrightarrow\infty.$ Let $v\in[-1,1]\setminus\{0\}$, $\mathbb X\in\{\ZZ,\ZZ_{\geq0},\ZZ_{\leq0},\RR\}$, and let $\{D_N\}$ be a positive sequence. Suppose that there is a sequence of maps $x_N:\mathbb X\longrightarrow\mathfrak X=\{-N,\ldots,N\}$ such that, for every fixed $A\in\mathbb X$, ${x_N(A)}/{N}\longrightarrow v$. Suppose that there exists a limiting kernel $\mathbb K_{\lim}$ on $\mathbb X^2$ such that, for every fixed $j\in\ZZ$ and all fixed $A,B\in\mathbb X$, $\lim_{N\to\infty}D_N\,\mathbb K_{2n+j}\bigl(x_N(A),x_N(B)\bigr)=\mathbb K_{\lim}(A,B)$. Then, for every fixed $d\in\ZZ_{\geq0}$ and all $A,B\in\mathbb X$, $\lim_{N\to\infty}D_N\,\mathfrak K_n^{(d)}\bigl(x_N(A),x_N(B)\bigr)=\mathbb K_{\lim}(A,B)$.

*动机 / 作用（中文）*: 把秩一比较迭代 $d$ 次，并证明每一级的秩一项与反射项在局部标度下都被 $D_N$ 压成 $0$，从而"体核与软边缘核的局部普适性对任意固定次 Christoffel 变换保持不变"。它是后文四个区域结论的统一入口。
*证明思路（中文）*: 先由 $\sqrt{\beta_m^{(d)}}\le N$ 控制递推系数；再由核在固定秩平移下的收敛性推出 $\sqrt{D_N}\,p_{2n+i}\to0$ 的逐点估计；随后对 $d$ 作归纳：用 Christoffel 关系 $p_{2m}^{(d+1)}=p_{2m+1}^{(d)}$ 传递逐点估计，并把秩一修正项乘以 $D_N$ 后化为 $0$；对 $d=0$ 情形额外说明反射项由 Christoffel–Darboux 公式与分母 $|x_N+y_N|\asymp N$ 控制。

> **Proposition（As_prop_0，原点处的极限）**: Let $\lim\limits_{N\to \infty}n/N=\gamma\in(0,1)$. (1) If there exists a limiting kernel $\mathbb{K}_{\lim}$ such that for all $A,B\in\ZZ$ we have $\lim_{N\to \infty} \mathbb{K}_{2n}(A,B)= \mathbb{K}_{\lim}(A,B),$ then for any $A,B\in\ZZ$ $\lim_{N\to \infty} \mathfrak{K}^{(0)}_n(A,B) = \eta(A)\eta(B)\left[\mathbb K_{\lim}(A,B)+\mathbb K_{\lim}(-A,B)\right],$ $\lim_{N\to \infty} \mathfrak{K}^{(1)}_n(A,B) = \mathbb{K}_{\lim}(A,B)-\mathbb{K}_{\lim}(-A,B);$ (2) If there exist a sequence $\{D_n\}$, with $D_n = o(n)$, $D_n\to\infty$, and a limiting kernel $\mathbb{K}_{\lim}$ such that for all $A,B\in\RR$ we have $\lim_{N\to \infty}D_n \mathbb{K}_{2n}([ D_n A],[ D_n B])= \mathbb{K}_{\lim}(A,B),$ then for any $A,B\in\RR$ $\lim_{N\to \infty} D_n\mathfrak{K}^{(0)}_n([ D_n A ], [ D_n B ]) = \eta(A)\eta(B)\left[ \mathbb{K}_{\lim}(A,B)+\mathbb{K}_{\lim}(-A,B)\right],$ $\lim_{N\to \infty} D_n\mathfrak{K}^{(1)}_n([ D_n A ], [ D_n B ]) = \mathbb K_{\lim}(A,B)-\mathbb K_{\lim}(-A,B).$

*动机 / 作用（中文）*: 转移原则在 $v=0$ 处失效，原因是 $x\mapsto x^2$ 把原点与自身配对，反射项不再可忽略。该命题说明：$d=0$ 时极限核是"原核与反射核之和"，而 $d=1$ 时两者相减——正是"hard-wall"修正的来源。
*证明思路（中文）*: 由对称格点核与二次格点核的关系 $\mathfrak K_n^{(0)}(x,y)=\eta(x)\eta(y)[\mathbb K_{2n}(x,y)+\mathbb K_{2n}(-x,y)]$，以及偶/奇分解给出的 $\mathfrak K_n^{(1)}(x,y)=\mathbb K_{2n}(x,y)-\mathbb K_{2n}(-x,y)$，代入缩放坐标并利用取整映射的对称性 $[-t]=-[t]$ 与 $\eta$ 的最终常值性直接取极限。

> **Proposition（Bulk regime）**: Fix $\gamma\in(0,1)$ and set $n=\lfloor\gamma N\rfloor,\qquad u_\ast(\gamma)=2\sqrt{\gamma(1-\gamma)}.$ Let $0<|u|<u_\ast(\gamma)$. Then, for every fixed $d\in\ZZ_{\geq0}$ and all $A,B\in\ZZ$, $\lim_{N\to\infty}\mathfrak K_{n,\mathrm{Kr}}^{(d)}\bigl(\lfloor uN\rfloor+A,\lfloor uN\rfloor+B\bigr)=\mathbb K_{\sin,\;\phi_\gamma(u)}(A,B),$ where $\phi_\gamma(u)=\arccos\left(\frac{1-2\gamma}{\sqrt{1-u^2}}\right).$

*动机 / 作用（中文）*: 说明修正 Krawtchouk 系综（即辛 Schur 测度对应的系综）在带内部满足与经典 Krawtchouk 系综相同的离散 sine 核普适性，且该普适性与 Christoffel 次数 $d$ 无关。
*证明思路（中文）*: 验证 Proposition As_prop_neq0 的全部假设：取 $D_N=1$、$x_N(A)=\lfloor uN\rfloor+A$，则 $x_N/N\to u\neq0$；再引用 Baik–Kriecherbauer–McLaughlin–Miller 中关于 Krawtchouk 核在固定秩平移下稳定的体极限结论，直接得到结论。

> **Proposition（Soft-edge regime）**: Fix $\gamma\in\left(0,\frac12\right)\cup\left(\frac12,1\right),$ and set $n=\lfloor\gamma N\rfloor.$ Define $u_\ast(\gamma)=2\sqrt{\gamma(1-\gamma)},\qquad \xi_N=Nu_\ast(\gamma),$ and $C_\gamma^{-1}=2^{2/3}\gamma^{1/6}(1-\gamma)^{1/6}|1-2\gamma|^{-2/3},\qquad D_N=C_\gamma N^{1/3}.$ For $A\in\RR$, set $x_N(A)=\left\lfloor\xi_N+D_NA\right\rfloor.$ If $\gamma<\frac12$, then, for every fixed $d\in\ZZ_{\geq0}$ and all $A,B\in\RR$, $\lim_{N\to\infty}D_N\mathfrak K^{(d)}_{n,\mathrm{Kr}}\bigl(x_N(A),x_N(B)\bigr)=\mathbb K_{\mathrm{Ai}}(A,B).$ If $\gamma>\frac12$, then, for every fixed $d\in\ZZ_{\geq0}$ and all $A,B\in\RR$, $\lim_{N\to\infty}D_N\Khat^{(d)}_{n,\mathrm{Kr}}\bigl(x_N(A),x_N(B)\bigr)=\mathbb K_{\mathrm{Ai}}(A,B).$

*动机 / 作用（中文）*: 给出右软边缘的 Airy 普适性，并说明在粒子表象失效的饱和区（$\gamma>\frac12$）应改用对偶（洞）核来陈述同一极限；Airy 核由 $\mathbb{K}_{\mathrm{Ai}}(x,y)=\int_{0}^{\infty}\operatorname{Ai}(x+t)\operatorname{Ai}(y+t)\,dt$ 定义。
*证明思路（中文）*: 取 $\mathbb X=\RR$、$v=u_\ast(\gamma)$、$D_N=C_\gamma N^{1/3}=o(N)$，此时 $x_N(A)/N\to u_\ast(\gamma)\neq0$；再利用 $2n+i=2\gamma N+O(1)$ 说明固定秩平移只把边缘中心平移 $O(1)$、把 Airy 尺度改变 $1+o(1)$ 倍，随后引用 Betea 的临界 Krawtchouk 渐近并在子情形（$\gamma<\frac12$ 用粒子核、$\gamma>\frac12$ 用对偶核）中通过共轭与镜像操作完成。

> **Proposition（Discrete Hermite regime）**: Fix $r\in \mathbb{R}$ and suppose that $\frac{n}{N}=\frac{1}{2}-\frac{r}{2\sqrt{N}}+o(N^{-1/2}).$ Then for any fixed $d\in\ZZ_{\ge0}$ and any $x,y\in\ZZ_{\ge0}$ we have $\lim_{N\to\infty}\mathfrak K_{n,\mathrm{Kr}}^{(d)}\bigl(N-x,N-y\bigr)=\mathbb K_{\mathrm{DHe^{+}}}^{r}(x,y).$

*动机 / 作用（中文）*: 描述临界情形 $n/N\to\frac12$：此时极限带的右端恰好触到格点端点 $u_\ast(\gamma)=1$，软边缘的 Airy 机制退化为离散 Hermite 核 $\mathbb K_{\mathrm{DHe^{+}}}^r(x,y)=(\pi 2^{x+y}x!y!)^{-1/2}\int_{r}^{+\infty}H_x(t)H_y(t)e^{-t^2}dt$；这解释了论文中"临界区"这一独立区域的来源。
*证明思路（中文）*: 在临界标度 $n/N=\frac12-\frac{r}{2\sqrt N}+o(N^{-1/2})$ 下，把秩 $2n$ 的投影写成 $N-r\sqrt N+o(\sqrt N)$，再用 Proposition As_prop_neq0 的同一套比较机制（此时局部化中心虽接近端点但仍在宏观非零位置）把 $d>0$ 的核化归到 $d=0$，最后引用 Borodin–Olshanski 关于 Krawtchouk 到离散 Hermite 转移的定理。（原文此处对 Borodin–Olshanski 定理 6.4 中临界标度的 $\sqrt{1-p}$ 因子给出了一处勘误。）

> **Proposition（Hard-wall sine kernel regime）**: Suppose that $\frac{n}{N}\longrightarrow\gamma\in(0,1),$ and set $\phi_\gamma=\arccos(1-2\gamma).$ Then, for every fixed $A,B\in\ZZ$, $\lim_{N\to\infty}\mathfrak K_{n,\mathrm{Kr}}^{(0)}(A,B)=\eta(A)\eta(B)\left[\mathbb K_{\sin,\phi_\gamma}(A,B)+\mathbb K_{\sin,\phi_\gamma}(-A,B)\right],$ $\lim_{N\to\infty}\mathfrak K_{n,\mathrm{Kr}}^{(1)}(A,B)=\mathbb K_{\sin,\phi_\gamma}(A,B)-\mathbb K_{\sin,\phi_\gamma}(-A,B).$

*动机 / 作用（中文）*: 这是与经典 Schur 测度情形最不同的新现象：在左角（原点）处主项与反射项同为 $O(1)$，无法用秩一算子抹去，于是极限核变成"离散 sine 核 $\pm$ 其反射"，即离散 hard-wall sine 核。它在表示论中曾由 Borodin–Kuan 得到，也出现在 XX 链与手征随机矩阵系综中。
*证明思路（中文）*: 先指出含 $u=0$ 的体极限论证依然适用（$u\neq0$ 的限制只为调用 As_prop_neq0 而设）：$\gamma\le\frac12$ 时由普通核、$\gamma>\frac12$ 时由粒子—洞论证（利用 $\phi_\gamma=\pi-\phi_{1-\gamma}$）得到 $\mathbb K_{2n,\mathrm{Kr}}(A,B)\to\mathbb K_{\sin,\phi_\gamma}(A,B)$；再代入 Proposition As_prop_0 第 (1) 部分即得 $d=0$ 与 $d=1$ 的两个极限。

### 2.1.  证明思路

- 第一步（算子层面）：把 Christoffel 变换的核与"乘以 $x$ 后共轭"的投影 $X\hat{\mcK}_{2n}X^{-1}$ 通过一组显式基 $\{x\hat p_{2m}\}$ 联系起来，证明其差 $\Delta_{2n}$ 只在第 $2n$ 个基向量上非零，从而得到秩一性及显式核。
- 第二步（传递层面）：在 $x_N/N\to v\neq0$ 的宏观尺度上，把秩一修正项与反射项都估计为 $o(D_N^{-1})$，并证明逐点估计 $\sqrt{D_N}p^{(d)}_{2n+i}\to0$ 对指标 $d$ 作归纳时保持成立，从而把 $d=0$ 的极限核传给一切固定 $d$。
- 第三步（原点与例证层面）：原点处用对称格点与二次格点的核关系得到极限公式；随后在 Krawtchouk 与 Hahn 两个具体系综上逐区域验证第二步的假设（体区与右边缘用已知的 Krawtchouk 渐近，临界区与左角分别用离散 Hermite 与 hard-wall sine 结论），并把四类区域合并成随机杨图局部涨落的完整描述。

## 3.  关键组件

### 3.1.  关键定义

> **Definition（Dual-ensemble kernel）**: Let $w$ be a weight on the symmetric lattice $\mathfrak{X}=\{-N,...,N\}$, let $\mathfrak{K}^{(d)}_{n}$ be the associated ($d$-fold Christoffel-transformed) correlation kernel on the quadratic lattice, written in the square-root coordinates $x,y\in\{0,\dots,N\}$, and set $D=\operatorname{diag}\bigl((-1)^{x}\bigr)_{x\in\{0,\dots,N\}}$. For $d\in\ZZ_{\ge0}$ and $x,y\in\{0,\dots,N\}$ define $\Khat^{(d)}_{n}(x,y) = (-1)^{x-y}\bigl(\delta_{xy}-\mathfrak{K}^{(d)}_{n}(x,y)\bigr)=\bigl(D(\II-\mathfrak{K}^{(d)}_{n})D\bigr)(x,y).$ Similarly, for any kernel $K$ on the symmetric lattice $\mathfrak X=\{-N,\ldots,N\}$, we define the dual kernel $\widehat{K}(x,y)$ by $\widehat{K}(x,y) = (-1)^{x-y}\bigl(\delta_{xy}-K(x,y)\bigr),\quad x,y\in \mathfrak X.$

*动机 / 作用（中文）*: 该定义把"从粒子的视角看"换成"从洞的视角看"，但只用对角相似变换 $M\mapsto DMD$ 而非补投影 $\delta_{xy}-K$，因此保持对称性、幂等性与全部主子式，两种写法给出同一个行列式洞过程。技术上，对偶核在固定秩平移下的收敛性会立刻转化为 $\sqrt{D_N}p_k\to0$ 的逐点估计，这正是把转移原则推广到饱和区（$\gamma>\frac12$）的关键。

### 3.2.  关键构造

- **二次格点与对称格点的转换**：二次格点 $\{i^2\mid 0\le i\le N\}$ 上的权 $W$ 通过 $w^{(d)}(x)=\frac12 x^{2d}W(x^2)$ 升到对称格点 $\mathfrak X=\{-N,\dots,N\}$；由于 $x\mapsto x^2$ 把正负点配对、原点只对应一点，二次格点核与对称格点核之间差一个归一化因子 $\eta(x)=1/\sqrt{1+\delta_{x,0}}$，即 $\mathfrak K^{(0)}_n(x,y)=2\eta(x)\eta(y)\sum_{\ell=0}^{n-1}p_{2\ell}(x)p_{2\ell}(y)$。当 $d>0$ 时权在原点消失，$\eta$ 因子整体消失：$\mathfrak K^{(d)}_n(x,y)=2\sum_{\ell=0}^{n-1}p^{(d)}_{2\ell}(x)p^{(d)}_{2\ell}(y)$。
- **Krawtchouk 权与递推系数**：标准 Krawtchouk 情形取二项权 $w_{\mathrm{Kr}}^{(0)}(x)=\binom{2N}{N+x}2^{-2N}$（$x\in\mathfrak X$），其首一正交多项式满足三项递推 $x\widetilde K_m(x)=\widetilde K_{m+1}(x)+\beta_m\widetilde K_{m-1}(x)$，$\beta_m=\frac{m(2N-m+1)}{4}$，正交范数为 $h_m^2=(m!)^2\binom{2m}{m}2^{-2m}$ 形式下的标准表达式；修正 Krawtchouk 权即 $w_{\mathrm{Kr}}^{(d)}(x)=x^{2d}w_{\mathrm{Kr}}^{(0)}(x)$。该权的 $\beta_m=O(N^2)$ 增长与 $\sqrt{\beta_m}\le N$ 正是证明中一切估计的来源。
- **辛 Schur 测度**：在 $(\mathrm{Sp}_{2n},\mathrm{Sp}_{2k})$ skew Howe 对偶下，$\bigwedge(\mathbb C^{2n}\otimes\mathbb C^k)\cong\bigoplus_{\lambda\subset n\times k}V_{\mathrm{Sp}_{2n}}(\lambda)\otimes V_{\mathrm{Sp}_{2k}}(\overline\lambda{}')$，取维数特化即得 $\mu_{n,k}(\lambda)=\dim V_{\mathrm{Sp}_{2n}}(\lambda)\dim V_{\mathrm{Sp}_{2k}}(\overline\lambda{}')/2^{2nk}$；在"俄罗斯"约定与 $a_i=\lambda_i+n-i+1$ 的坐标下，它正是 $\mu^{W,d}_n(a_1,\dots,a_n)\propto\prod_{i<j}(a_i^2-a_j^2)^2\prod_i a_i^2\binom{2N}{N+a_i}$，即 $d=1$ 的 Krawtchouk–Christoffel 系综（$N=n+k$）。
- **离散 sine 核**：$\mathbb K_{\sin,\phi}(A,B)=\frac{\sin(\phi(A-B))}{\pi(A-B)}$（$A\neq B$）与 $\mathbb K_{\sin,\phi}(A,A)=\frac{\phi}{\pi}$，$\phi\in[0,\pi]$；体极限的 $\phi$ 为 $\phi_\gamma(u)=\arccos\frac{1-2\gamma}{\sqrt{1-u^2}}$，原点极限的 $\phi$ 为 $\phi_\gamma=\arccos(1-2\gamma)$。

### 3.3.  关键引理

- **附录 A 的引理（Hahn particle density and edge parameters）**：该引理给出对称 Hahn 系综在比例极限下的极限粒子密度 $\rho_{\gamma,\kappa}$（按 $q_{\gamma,\kappa}>0$、$=0$、$<0$ 三种情形分别给出反正切表达式），带右端点 $u_\ast(\gamma,\kappa)=\frac{2\Delta_{\gamma,\kappa}}{\kappa+2\gamma}$（其中 $\Delta_{\gamma,\kappa}=\sqrt{\gamma(1-\gamma)(\kappa+\gamma)(\kappa+\gamma+1)}$，$q_{\gamma,\kappa}=\kappa-2\gamma(\kappa+\gamma)$，$r_{\gamma,\kappa}=\kappa(\kappa+1)+2\gamma(\kappa+\gamma)$），临界值 $\gamma_{\mathrm c}(\kappa)=\frac{\sqrt{\kappa^2+2\kappa}-\kappa}{2}$ 及其对应的 void–band–void 与 saturated–band–saturated 两种构型，并给出临界密度与 $N^{1/3}$ 软边缘标度下的归一化常数 $C_{\gamma,\kappa}^{-1}$。为避免与原文符号系统脱节，此处只转述其内容与记号，完整公式以原文 Appendix 为准。

- *作用（中文）*: 把 Hahn 系综的宏观极限形状固定下来，从而为 Hahn 版本的体、软边缘与 hard-wall 三个命题提供可验证的假设。
- *与本文主线的关系*: Hahn 例证说明秩一比较机制不依赖 Krawtchouk 的特殊超几何结构，只要权在原点消失、递推系数满足 $\sqrt{\beta_m}\le N$ 即可运行；在固定参数退化下还给出离散 Laguerre 型极限。

## 4.  理解辅助

- **贯穿例子**：全文的算例是 $p=\frac12$ 的 Krawtchouk 系综（辛 skew Howe 对偶诱导的修正 Krawtchouk 系综），其 $\gamma=\frac12$ 临界情形同时演示两种"非普适"现象：一方面带端触及格点端点而出现离散 Hermite 核，另一方面原点处主项与反射项耦合而出现离散 hard-wall sine 核。把 $\gamma=\frac12$ 换成一般的 $\gamma_{\mathrm c}(\kappa)$ 后，同一套讨论在 Hahn 系综上重演，只是软边缘归一化常数换成 $C_{\gamma,\kappa}$。
- **参数地图（中文速查）**：$\gamma=n/N$ 为粒子密度（二次格点坐标下）；$u=x/N$ 为宏观坐标；$u_\ast(\gamma)=2\sqrt{\gamma(1-\gamma)}$ 为极限带的右端点（Krawtchouk，$d=1$ 情形）；$\gamma<\frac12$ 时带外为空（void），$\gamma>\frac12$ 时带外饱和（saturated），此时须改用对偶核陈述。
- **四个区域的判定**（由论文命题合并给出）：$0<|u|<u_\ast(\gamma)$ 且 $\gamma\neq\frac12$ 为体区（离散 sine 核）；右软边缘在 $N^{1/3}$ 标度上为 Airy 核；$n/N=\frac12-r/(2\sqrt N)+o(N^{-1/2})$ 为临界区（离散 Hermite 核）；原点 $u=0$ 为左角（离散 hard-wall sine 核）。

### 5.3.  批判性思考

- 秩一比较的证明非常简洁，但其"信息损失"也值得注意：它只保局部极限核，不保局部化中心的具体位置与整体涨落的联合分布；若要做多点或过程级别的收敛，需要比秩一更强的算子范数估计。
- 论文在 Remark（关于 Borodin–Olshanski 定理 6.4 的标度）中修正了原文献中缺失的 $\sqrt{1-p}$ 因子。这类"文献勘误"提示离散 Hermite 区域的标度参数在不同论文中可能相差常数因子，使用时需核对其归一化约定（概率学家/物理学家 Hermite 参数相差 $\sqrt2$）。
- 作者明确承认 Hahn 情形的临界值 $\gamma=\gamma_{\mathrm c}(\kappa)$ 被排除在外，理由是所引文献的端点假设失效，并用夹逼与嵌套投影的 Cauchy–Schwarz 论证说明极限仍可恢复。这一处属"形式范围"而非"现象改变"，但严格写出该临界情形的证明仍是一个值得补齐的空缺。
- 论文的 hard-wall sine 核只对 $d=0$ 与 $d=1$ 给出原点极限，而对 $d\ge2$ 只描述为"偶指标核出现有限秩修正、奇指标核出现反射 sine 核的有限秩修正"。这种表述是定性而非显式的，若要与具体随机杨图统计量比较，仍需显式写出修正算子。
