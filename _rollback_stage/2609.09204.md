# Counting Type I and Type II solutions of the Erd\H{o}s--Straus equation: concentration, local obstructions, and a pointwise comparison

keywords: [Erdős–Straus 方程, Type I/Type II 解计数, Bradford 计数恒等式, 局部障碍与二次特征, 除子函数, 逐点比较]

related_paper: "Elsholtz–Tao, Counting the number of solutions to the Erdős–Straus equation on unit fractions"

one_liner_summary: "本文不讨论 Erdős–Straus 猜想本身，而是研究 $4/p=1/x+1/y+1/z$ 的 Type I 与 Type II 解个数 $\fI(p)$、$\fII(p)$：把 Bradford 的双射升级为精确计数恒等式（两个计数分别是 $n^{2}$ 的除子在模 $e_n=4n-p$ 的单剩余类中的个数），证明 Type II 解集中于 $x/p\to1/m$ 而无对应的 Type I 集中现象，给出局部不等式 $2B(n)\ge A(n)$ 在 $e_n\\le5$ 时成立且 $e\\ge7$ 时失效的尖锐结论，证明一般分子下二次特征只能区分两种类型当且仅当分子不是完全平方，并提出 $\fI(p)>\\fII(p)$（$p>5$、$p\\not\\equiv1\\bmod8$）与 $\\sum\\fI/\\sum\\fII\\to3$ 两条猜想。"

## 1.  核心定位

- **解决的问题**：在 Elsholtz–Tao 的框架下确定 Erdős–Straus 方程 $4/p=1/x+1/y+1/z$ 的 Type I 与 Type II 解个数的结构：精确计数恒等式、解的分布（集中性）、以模特征标表述的局部障碍，以及两者的逐点比较 $\fI(p)$ 与 $\fII(p)$。
- **大图景位置**：作者明确声明不触及 Erdős–Straus 猜想（在正整数范围内是否总有解），而是研究 Elsholtz–Tao 开创的「解个数」问题；本文把 Bradford 关于最小分母的双射推广为对全体与 $p$ 互素的分母的精确计数，并把 Elsholtz–Tao 关于可解性不受 $p$ 的模同余支配的观察精细化到计数层面（$m=4$ 时二次层次完全失明）。
- **主要贡献**：①计数恒等式与对偶：$\fI(p)=\sum_n B(n)$、$\fII(p)=\sum_n A(n)$，并改写为同一除子集合、同一模 $e_n$、仅剩余类不同的两个计数（Type I 类 $-4^{-1}$ 与 $n$ 无关，Type II 类 $-n$ 随 $n$ 移动）；②无条件集中定理：Type II 解中 $Y\le K$ 者至多 $D(K)=\sum_{n\le K}\tau(n)\ll K\log K$（对 $p$、$m$ 一致），平均情形仅 $O_m((\log K)^{3}\log\log K)$，故 Type II 解集中于 $x/p\to1/m$，而 Type I 无此现象；③局部不等式 $2B(n)\ge A(n)$ 当 $e_n\in\{1,3,5\}$ 时成立，且 $7\le e\le2\cdot10^{4}$ 的反例说明该范围不可扩大。
- **关键先驱工作**：Elsholtz–Tao（计数函数与 Type I/II 划分、Type II 参数化、界 $\fI\ll n^{3/5+o(1)}$、$\fII\ll n^{2/5+o(1)}$ 及 $\log\log$ 因子）；Bradford（把 $A(n)$、$B(n)$ 型同余条件与解一一对应）；Monks–Velingker（可解性判据与最小分母范围）；Sierpiński、Schinzel、Obláth、Rosati、Yamamoto（恒等式与模 $840$ 的几个剩余类）；Mihnea–Dumitru（数值规模与 Type I 占优的经验观察）。
- **结果边界**：全部结果关于「解个数」，不给出任何新的可解性；所获得正性的同余类都是经典可解类。集中定理只对 Type II 有效，Type I 的两个与 $p$ 互素的分母始终超过 $(p+1)/3$，不受 $p$ 的任何有界倍数约束。二次特征的判别在分子为完全平方（尤其 $m=4$）时失效，故任何 $\fI>\fII$ 的证明必须使用至少三阶特征。$e\le5$ 的局部不等式是尖锐的，无法仅靠扩大 $e$ 的范围来加强。
- **开放问题**：改进逐点界 $D(K)\ll K\log K$（猜测对任意 $\varepsilon>0$ 有 $K^{\varepsilon}$，但要突破需处理「该 $c$ 是否整除 $g$」的等分布型问题）；在附加假设下把 $2B(n)\ge A(n)$ 推广到 $e=7,9$ 并确定全部反例对 $(p,n)$；证明猜想的平均形式 $\sum_{p\le N}\fI(p)>\sum_{p\le N}\fII(p)$；为全为 $p\equiv1\pmod8$ 的例外集寻找互反律解释。
- **应用与推广**：一般分子 $m$ 下的计数恒等式与二次二分（Type II 由 $-1$ 阻碍、Type I 由 $-m$ 阻碍；$m$ 为完全平方时二者不可分）给出「分子本身携带算术信息」的范式；$4\mid m$ 时奇数完全平方处计数为零的定理是 Elsholtz–Tao 结果的精确加强；关于 $\log\log N$ 因子的分析把 Elsholtz–Tao 上界中的损失定位在 Brun–Titchmarsh 的大模数区间，去掉它等价于在该处多获得一个对数。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：同批处理的数论计数与特征和方法 — 见 [[2609.16081]]
- [[2609.16081]]：该文研究「内部恰含 $n$ 个格点的最大圆」，属初等数论中的计数与数值验证型工作，其把几何判定转化为整除/勾股三元组条件的思路，与本文把单位分数解数转化为除子同余类计数（$A(n)$、$B(n)$）的思路同属「离散计数 + 显式数值验证」范式。
- [[2609.16030]]：该文用有限域上的特征标与傅里叶和刻画零点集刚性；本文的局部障碍分析本质上也是用实特征标（Jacobi 符号）在 $(\Z/e_n\Z)^{\times}$ 上分离两个元素 $-1$ 与 $-m$，并用二次互反律把 $(\frac{q}{e})$ 转为 $(\frac{-p}{q})$ 来判定哪一类被消灭，是同一类「用特征标的非平凡性制造障碍」的技术。
- [[2609.16741]]：该文研究强乘性集合与 $S$-素现象，处理的是乘法结构与局部化；本文 Type I 类 $-4^{-1}$ 与 Type II 类 $-n$ 在模 $e_n$ 下的不对称性同样源于乘法群 $(\Z/e_n\Z)^{\times}$ 中元素的平方类归属，二者可互相参照。
- 技术迁移：把「同一除子集合、不同剩余类」的对偶视角迁移到其他丢番图方程的解数比较问题（例如 $\sum a_i/x_i=1$ 型单位分数方程），可能同样能把类型差异归约为模算术中的平方类/特征标问题。

### 2.2.  可以尝试的方向

- [ ] 对 Type II 的解数尝试超越 $K\log K$：由平均界 $O_m((\log K)^{3}\log\log K)$ 与等分布直觉猜测 $\ll_{\varepsilon}K^{\varepsilon}$，可从参数化中 $c\mid g$ 的等分布入手。
- [ ] 用 $p\equiv3\pmod4$ 时残差命题退化为 $T(p)\ge0$ 的观察，尝试把该情形从数值验证推进为无条件证明，并检验 $T(p)$ 与 $L$ 函数零点的可能联系。
- [ ] 把「分子 $m$ 的平方性 vs $4\mid m$」这两个独立机制分别推广到其他分母结构（如 $mn/p$ 的多元推广），检验二者是否始终独立。
- [ ] 为 $\fI-\fII$ 的差值构造一个中心化/加权版本，使其在二次层次上不再失明（即寻找至少三阶特征标的显式判别式）。

### 2.3.  批判性思考

- 全文结论分两类：可证的无条件结果（计数恒等式、集中定理、$e\le5$ 的局部不等式、二次二分、$4\mid m$ 的消失定理）与依赖数值验证的猜想（$\fI>\fII$、比值 $\to3$、$m$ 版推广），后者的验证范围（$p\le10^{6}$、$4\le m\le20$ 且 $p\le2\cdot10^{4}$）虽标注清楚，但作为「主结论」的支撑仍偏经验，尤其是例外集全为 $p\equiv1\pmod8$ 这一现象尚无结构性解释。
- 关于 $\fI>\fII$ 的「诊断」把优势归因于集中现象而非除子分布的不平衡，论证依赖启发式的求和次序比较（$\tau_3$ 在单尺度与 $1/n$ 加权平均之比 $3$），文中亦承认需要至少三阶特征标，说明该比较目前处在现象描述而非机制证明的阶段。
- 局部不等式 $2B(n)\ge A(n)$ 的反例搜索止于 $2\cdot10^{4}$，而恰好 $e_n\ge7$ 是残差猜想唯一涉及的层，两个工作的范围衔接处（$e$ 稍大的精确分类）仍是空白。
- 文中「七个失败路径 + 两个部分结果的反例」一节颇具诚实性，但也表明该问题的现有工具箱（初等整除、二次特征、求和估计）已接近其解释力上限。

## 3.  附：原文主要结论索引

- 计数恒等式（定理 thm:count）：对素数 $p\ge5$，$\fII(p)=\sum_n A(n)$、$\fI(p)=\sum_n B(n)$，求和遍历所有对 $p$ 可容许的 $n$（$4n>p$、$p\nmid n$），其中 $e_n=4n-p$，$A(n)=\#\{s\mid n^{2}:e_n\mid s+n\}$，$B(n)=\#\{s\mid n^{2}:e_n\mid s+pn\}$。
- 单剩余类形式：$\fI(p)=\sum_n\#\{s\mid n^{2}:s\equiv-4^{-1}\ (\mathrm{mod}\ e_n)\}$，$\fII(p)=\sum_n\#\{s\mid n^{2}:s\equiv-n\ (\mathrm{mod}\ e_n)\}$。
- 集中定理（定理 thm:conc 及推论）：$Y\le K$ 的 Type II 解数至多 $D(K)=\sum_{n\le K}\tau(n)=K\log K+O(K)$，对 $p$、$m$ 一致；推论给出除 $O_{\delta}(1)$ 个例外外 $p/m<x<p/(m-\delta)$。
- 除子下界（定理 thm:Abound）：$A(n)\le 2(\lfloor 2n/e\rfloor-\lfloor n/e\rfloor)\le 2(n/e+1)$；$B(n)$ 仅有平凡界 $\tau(n^{2})$。
- 尖锐局部不等式（定理 thm:e5）：$e_n\in\{1,3,5\}$ 时 $2B(n)\ge A(n)$；对每个满足 $7\le e\le2\cdot10^{4}$ 的奇数 $e$ 都存在反例。
- 逐点比较（猜想 conj:main）：$p>5$ 且 $p\not\equiv1\pmod8$ 时 $\fI(p)>\fII(p)$；在 $p\le10^{6}$ 的 $78\,496$ 个素数中仅 $12$ 个例外，除 $p=5$ 外均 $\equiv1\pmod8$；已归约到长度约 $p/12$ 的窗口（推论 cor:reduction）与仅涉及层 $e_n\ge7$ 的残差不等式（猜想 conj:residual）。
- 比值猜想（猜想 conj:ratio-intro）：$R(N)=\sum_{p\le N}\fI(p)/\sum_{p\le N}\fII(p)\to3$；对 $10^{3}\le N\le10^{6}$ 的 $41$ 个值做 $a-b/\log N$ 最小二乘拟合得 $a=3.016$。
- 二次二分（定理 thm:dich）：设 $m\ge3$、$p\nmid m$、$\chi$ 为模 $e_n$ 的实特征标且在整除 $n$ 的素数处取 $1$，$m_0$ 为 $m$ 的无平方核；则 $A_m(n)>0\Rightarrow\chi(-1)=1$，$B_m(n)>0\Rightarrow\chi(-1)\chi(m_0)=1$。故 $m$ 为完全平方时障碍对两类型同等（即类型不可分），否则可区分；对 $m=4$ 二次层次完全失明。
- 奇数平方处消失（定理 thm:vanish）：$4\mid m$ 时对每个奇数完全平方 $n$ 有 $\fI^{(m)}(n)=\fII^{(m)}(n)=0$；$m\le32$ 中该类之外无此性质。
- 一般分子推广（猜想 conj:gm）：$p\equiv-1\pmod m$ 时应推出 $\fI^{(m)}(p)>\fII^{(m)}(p)$；已验证 $4\le m\le20$、$p\le2\cdot10^{4}$，并用定理 thm:redm 把它归约到长度 $2p/(m(m-2))$ 的窗口，从而在 $3\le m\le20$、$p\le6\cdot10^{3}$ 的 $3\,028$ 对中除两对外全部证明。
- 数值参照：Mihnea–Dumitru 在其计算范围内报告 Type I 解 $12\,763\,383$ 个、Type II 解 $5\,838\,200$ 个。
