# Generalizations of two Ramanujan series for $1/\pi$

keywords: [Ramanujan 型级数, 超几何求和恒等式, 调和数, 奇调和数, Pochhammer 符号]
related_paper: "2609.10642"
one_liner_summary: "借助两个已知的超几何求和恒等式，把 Ramanujan 关于 $1/\pi$ 的两个经典级数各自扩展为一个含参数 $r$ 的无穷族，并给出相应的调和数与奇调和数版本，$n=0$ 时退化为 Bauer-Ramanujan 级数及其已知的调和数补形式。"

## 核心定位

- **解决的问题**：把两个著名的 Ramanujan 型 $1/\pi$ 级数（及其 $n=0$ 特例）纳入统一的无穷族，并给出含调和数 $H_j$、奇调和数 $O_j$ 的对应族，使每一次求和都能由一个超几何求和恒等式通过参数替换与参数求导得到。
- **大图景位置**：属于 Bauer-Ramanujan 级数研究的延长线。1859 年 Bauer 用 Fourier-Legendre 展开发现 $\sum (-1)^k \left(\frac12\right)_k^3 (4k+1)/k!^3 = 2/\pi$，1914 年 Ramanujan 在给 Hardy 的第一封信中重新发现它；本文把这一族与 Levrie 早先给出的推广统一为同一框架的成员。
- **主要贡献**：其一，用 Dougall 型恒等式（经 Hou 等人给出的形式）导出 $\sum_k$ 型的参数 $r$ 族并证出其闭形式含 $r!^2/\left((\frac12)_r^2\cos(\pi r)\right)$；其二，对求和参数求导，得到同一族在权中含 $2O_{k-r}+H_{k+r}$ 的调和数版本；其三，给出第二类（$4^{-k}$ 权、$6k+1+2r$ 因子）的对应族及其 $n=0$ 特例 $-8/(3\pi)$ 与 $-8\ln 2/\pi$。
- **关键先驱工作**：Bauer（1859）与 Ramanujan（1914）的原始级数；Dougall 的双边超几何定理；Levrie 2010 对 gen1 的最早推导；Ekhad 与 Zeilberger 关于特例的 WZ 方法证明；Hou 等人 2024 与 Campbell 2026 关于调和数补形式的近期结果；Campbell 与 Levrie 的综述。
- **结果边界**：所有定理均要求参数 $r$ 不是半整数，因为闭形式含 $\cos(\pi r)$ 于分母；$n$ 为负整数或使 $(\frac12)_n$ 出现在分母的取值会破坏收敛形式。级数本身对 $r$ 半整数处需要另作极限处理。
- **开放问题**：原文未提供明确的开放问题清单；作者仅指出更一般的推广（把 gen1、gen2 作为更一般结果的特例）已在文中实现。
- **应用与推广**：这类恒等式可用于 $1/\pi$ 的快速数值计算与级数加速（逐项含 $1/\pi$ 的闭形式便于误差控制）；参数求导产生调和数加权求和的技巧可迁移到其他 well-poised 求和中，用于生成新的 Euler 和与超几何闭形式。

## 主要结果（原文陈述逐字抄录）

> **Lemma** (Hou 等人给出的 Dougall 型恒等式，原文与之等价形式):
> If $c$ is a complex number, then
> \[
> \sum_{k = 0}^\infty  {( - 1)^k \frac{{\left( {\frac{1}{2}} \right)_k^2 \left( c \right)_k }}{{k!^2 \left( {3/2 - c} \right)_k }}\left( {4k + 1} \right)}  = \frac{2}{{\sqrt \pi  }}\,\frac{{\Gamma \left( {3/2 - c} \right)}}{{\Gamma \left( {1 - c} \right)}}= \frac{2}{{\sqrt \pi  }}(1-c)_{1/2}.
> \]

这是全文的引擎：$n$ 为非负整数时该式由 Ekhad 与 Zeilberger 用 WZ 方法证明过。作者的做法是把 $c$ 替换为 $1/2-r$（以及 $1/2+r$）后用 Pochhammer 符号的初等关系改写，从而生成下面两个族的"纯 $1/\pi$ 形式"。

> **Theorem**:
> If $r$ is a complex number that is not a half-integer, then
> \[
> \sum_{k = 0}^\infty  {( - 1)^k \frac{{\left( {\frac{1}{2}} \right)_k^3 }}{{k!^3 }}\frac{{\left( {4k + 1} \right)}}{{\binom{{k + r}}{k}\binom{{k - 1/2}}{r}}}}  = \frac{2}{\pi }\,\frac{{r!^2 }}{{\left( {\frac{1}{2}} \right)_r^2 }}\,\frac{1}{{\cos \left( \pi r \right)}}.
> \]

证明思路：在求和恒等式中取 $c=1/2-r$，再用 $\left( {r + 1} \right)_k  = k!\binom{{r + k}}{k}$ 与 $\left( {r + \frac{1}{2}} \right)_{\frac{1}{2}}  = \frac{{\Gamma \left( {r + 1} \right)}}{{\Gamma \left( {r + \frac{1}{2}} \right)}} = \frac{{r!}}{{\left( {\frac{1}{2}} \right)_r \sqrt \pi  }}$ 把广义二项式系数化为题中的分式形式；$r$ 为半整数时 $\cos(\pi r)=0$，故条件不可去。

> **Corollary**:
> If $n$ is a non-negative integer, then
> \[
> \sum_{k = 0}^\infty  {( - 1)^k \frac{{\left( {\frac{1}{2}} \right)_k^3 }}{{k!^3 }}\frac{{\left( {4k + 1} \right)}}{{\prod_{j = 1}^n {\left( {2k - 2j + 1} \right)\left( {k + j} \right)} }}}  = \frac{{( - 1)^n }}{{\left( {\frac{1}{2}} \right)_n^2 2^{n - 1} }}\,\frac{1}{\pi }.
> \]

这正是引言中的 $\eqref{gen1}$：取 $r=n$ 后用 $(-n+\frac12)_k$ 的乘积表达式与 $n!\binom{k+n}{n}=\prod_{j=1}^n (k+j)$ 即得，$n=0$ 回到 Bauer-Ramanujan 级数。

> **Theorem**:
> If $r$ is a complex number that is not a half-integer, then
> \[
> \sum_{k = 0}^\infty  {( - 1)^k \frac{{\left( {\frac{1}{2}} \right)_k^3 }}{{k!^3 }}\frac{{\left( {4k + 1} \right)\left( {2O_{k - r}  + H_{k + r} } \right)}}{{\binom{{k + r}}{k}\binom{{k - 1/2}}{r}}}}  = \frac{2}{\pi }\,\frac{{r!^2 }}{{\left( {\frac{1}{2}} \right)_r^2 }}\,\frac{{\left( {4O_r  - 2\ln 2} \right)}}{{\cos \left( \pi r \right)}}.
> \]

证明思路：把上述求和恒等式对参数 $c$ 求导（产生 $H_{k-r-1/2}+H_{k+r}$ 的权重），再令 $c=1/2-r$，最后用 $H_{n-1/2}=2O_n-2\ln 2$ 把半整数自变量处的调和数化为奇调和数与 $\ln 2$。这一步是全文技术核心：参数求导把一个"纯常数"求和变成带调和数权重的求和。

> **Corollary**:
> If $n$ is a non-negative integer, then
> \[
> \sum_{k = 0}^\infty  {\frac{{( - 1)^k \left( {\frac{1}{2}} \right)_k^3 \left( {4k + 1} \right)\left( {2O_{k - n}  + H_{k + n} } \right)}}{{k!^3 \prod_{j = 1}^n {\left( {k + j} \right)\left( {2k - 2j + 1} \right)} }}}  = \frac{{( - 1)^n }}{{2^{n - 2} }}\frac{1}{{\left( {\frac{1}{2}} \right)_n^2 }}\left( {2O_n  - \ln 2} \right)\,\frac{1}{\pi }.
> \]
>
> In particular,
> \[
> \sum_{k = 0}^\infty  {( - 1)^k \frac{{\left( {\frac{1}{2}} \right)_k^3 }}{{k!^3 }}\left( {4k + 1} \right)H_{2k} }  =  - \frac{2}{\pi }\ln 2.
> \]

$n=0$ 的特例即 Hou 等人与 Campbell 给出的调和数补形式；作者把它作为整个族的边界情形，说明新族确实把已知结果吸收在内。

> **Lemma**:
> If $c$ is a complex number, then
> \[
> \sum_{k = 0}^\infty  {\frac{1}{{4^k }}\frac{{\left( {\frac{1}{2}} \right)_k \left( c \right)_k \left( {1 - c} \right)_k }}{{k!^2 \left( {3/2 - c} \right)_k }}\,\frac{{3k - c + 1}}{2}}  = \frac{1}{{\sqrt \pi  }}\,(1-c)_{1/2}.
> \]

这是第二个族的引擎（Hou 等人得到），与第一个引擎平行：权重由 $(-1)^k(4k+1)$ 换为 $4^{-k}(3k-c+1)/2$。

> **Theorem**:
> If $r$ is a complex number that is not a half-integer, then
> \[
> \sum_{k = 0}^\infty  {\frac{{\left( {\frac{1}{2}} \right)_k^3 }}{{4^k k!^3 }}\frac{{\binom{{2k + 2r}}{{2r}}}}{{\binom{{k + r}}{r}^2 \binom{{k - 1/2}}{r}}}\left( {6k + 1 + 2r} \right)}  = \frac{4}{\pi }\frac{{r!^2 }}{{\left( {\frac{1}{2}} \right)_r^2 }}\,\frac{{1 }}{{\cos\left( {\pi r} \right)}}.
> \]

证明思路：取 $c=1/2-r$ 后用 $(-x+\frac12)_k$ 与 $(x+\frac12)_k$ 的两条 Pochhammer 恒等式把 $\left(\frac12-r\right)_k\left(\frac12+r\right)_k$ 拆成含 $\prod (2k+j)$ 的乘积形式，恰好给出引言中的 $\eqref{gen2}$ 的参数形式。

> **Corollary**:
> If $n$ is a non-negative integer, then
> \[
> \sum_{k = 0}^\infty  {\frac{{\left( {\frac{1}{2} \right)_k^3 }}{{4^k k!^3 }}\frac{{\prod_{j = 1}^{2n} {\left( {2k + j} \right)} }}{{\prod_{j = 1}^n {\left( {k + j} \right)^2 \left( {2k - 2j + 1} \right)} }}\left( {6k + 1 + 2n} \right)}  = \frac{{( - 1)^n\,2^{n+2} }}{{\left( {\frac{1}{2}} \right)_n }}\, \frac1{\pi }.
> \]
>
> In particular,
> \[
> \sum_{k = 0}^\infty  {\frac{{\left( {\frac{1}{2}} \right)_k^3 }}{{4^k k!^3 }}\frac{{\left( {2k + 1} \right)^2 }}{{\left( {k + 1} \right)\left( {2k - 1} \right)}}}  =  - \frac{8}{{3\pi }}.
> \]

$n=0$ 给出阶数为 $0$ 的边界情形；作者用同一个族的第二成员说明参数 $n$ 的取零与非零给出完全不同的算术结构（前者是无理常数 $-8/(3\pi)$ 的闭形式）。

> **Corollary**:
> If $n$ is a non-negative integer, then
> \[
> \sum_{k = 0}^\infty  {\frac{{\left( {\frac{1}{2}} \right)_k^3 }}{{4^k k!^3 }}\frac{{\prod_{j = 1}^{2n} {\left( {2k + j} \right)} }}{{\prod_{j = 1}^n {\left( {k + j} \right)^2 \left( {2k - 2j + 1} \right)} }}\left( {\left( {6k + 1 + 2n} \right)\left( {2O_{k - n}  - 2O_{k + n}  + H_{k + n} } \right) - 2} \right)}
> \]
> \[
> \qquad  =( - 1)^n\,\frac{{2^{n + 3} }}{{\left( {\frac{1}{2} \right)_n }}\left( {O_n  - \ln 2} \right)\frac{1}{\pi }.
> \]
>
> In particular,
> \[
> \sum_{k = 0}^\infty  {\frac{{\left( {\frac{1}{2} \right)_k^3 }}{{4^k k!^3 }}\left( {\left( {6k + 1} \right)H_k  - 2} \right)}  =  - \frac{{8\ln 2}}{\pi }.
> \]

这是第二族的调和数版本，由对 $c$ 求导并对 $r=n$ 取整得到；$n=0$ 的特例即 Hou 等人的结果，从而两个族在 $n=0$ 处同时回收文献中的调和数补形式。

## 理解辅助

- **贯穿例子**：$n=0$。整个论证的可检验性都压在 $n=0$ 上——此时 gen1 族退化为 Bauer-Ramanujan 级数 $2/\pi$，其调和数版本退化为 $-\frac{2}{\pi}\ln 2$；gen2 族退化为 $4/\pi$，其调和数版本退化为 $-\frac{8\ln 2}{\pi}$，而 $n$ 非零时的"纯常数"边界为 $-8/(3\pi)$。把所有特殊值对齐，就能确认参数化写法没有把原级数改错。
- **技术工具链**：广义二项式系数 $\binom{r}{s}=\Gamma(r+1)/(\Gamma(s+1)\Gamma(r-s+1))$、扩展 Pochhammer 关系 $(x)_y=\Gamma(x+y)/\Gamma(x)$、以及三条初等引理（$\binom{k}{x+1/2}$ 的转换、$\left(x+\frac12\right)_k$ 的两条分解、$\frac{d}{dx}(x)_y=(x)_y(H_{x+y-1}-H_{x-1})$）。

## 主动思考区

### 与其他工作的联系

- [[2609.10642]]：该文用四亏格 Kronecker 极限公式计算交错 Rogers-Ramanujan 连分数的代数值，与本文同属"Ramanujan 传统下用超几何/特殊函数恒等式求闭形式"的技术路线；差别在于本文处理的是 $1/\pi$ 级数的参数族，而该文处理的是 CM 点处的连分数代数证书。
- Dougall 的双边超几何定理：本文的两个引擎恒等式都可以从 Dougall well-poised 级数经替换得到，因此本文的族本质上是 Dougall 定理的"低阶影子"。
- 技术迁移：参数求导（对 $c$ 求导产生 $H$ 权重）这一手法的可迁移性很强——任何形如 $\sum_k t_k(c) = F(c)$ 的超几何闭形式都可立即产生一个调和数加权族；把这一招式用于其他 well-poised 求和（如 Watson、Whipple 定理）很可能产出新的 $1/\pi$ 或 $\zeta$ 值级数。
- [[2607.28626]]：本文的"参数族 + 求导"结构与 Yang-Baxter 算子同调中出现的代数不变量计算虽领域不同，但都以"把离散组合对象提升为含参数的代数族"为手段，可作为方法论上的类比。

### 可以尝试的方向

- [ ] 把参数 $r$ 推广到半整数处的极限形式：$\cos(\pi r)$ 归零，但级数的极限应当是一个正的 $1/\pi$ 常数，其闭形式是否仍含 $\ln 2$ 与 $O_n$？
- [ ] 能否用同一套引擎处理更高次幂 $\left(\frac12\right)_k^4$ 的权（即提高超几何的阶），得到 $1/\pi^2$ 型的族？
- [ ] 文中所有结果都是"级数 $= 常数/\pi$"方向的恒等式，是否存在反向的加速级数（用 $1/\pi$ 的截断误差反推调和数）的算法应用？
- [ ] 把 $H_{n-1/2}=2O_n-2\ln 2$ 换成其他特殊函数（如 $\psi$ 函数在有理点的值），是否得到含 $\pi$ 与 $\sqrt3$ 等的同时出现的族？

### 批判性思考

- 论证的核心依赖不在本文：两个引擎恒等式直接引自 Hou 等人的工作，本文的贡献是把替换与求导执行到底并整理成族。因此"新结果"与"已知结果的机械推广"之间的界线值得谨慎对待——作者也确实只声称结果是 Levrie 与 Hou 结果的统一与延伸。
- $r=n$ 为整数时把 $\binom{k-1/2}{r}^{-1}$ 化为 $\prod(2k-2j+1)$ 的步骤，本质上是把条件"$r$ 非半整数"替换为"乘积不消失"，对 $n\ge1$ 的正确性依赖 $2k-2j+1\neq0$ 对所有 $j\le n$、$k\ge0$ 成立，这一点在正文中未逐项讨论，读者需自行核算小 $k$ 的情形。
- 全文没有给出任何收敛性或截断误差估计：级数都是正项或交错项的和，闭形式成立在"求和有意义"的默认假设下，对 $r$ 的实部取值范围的讨论被省略了。
