# The Diophantine equation $p^{x}+6^{y}=z^{2n}$: a complete solution for half of the primes

keywords: [指数丢番图方程, Legendre 符号, Zsigmondy 定理, Catalan 猜想, Ramanujan–Nagell 型方程, 二次剩余]

related_paper: "2609.09204 —— 同为 math.NT 的丢番图方程解数研究，同样以模算术的局部障碍（平方类、剩余类）刻画解的存在性，与本文以 Legendre 符号作为障碍的思路同源"

one_liner_summary: "本文证明：对满足 $\\left(\\frac{6}{p}\\right)=-1$（等价于 $p\\equiv 7,11,13,17\\pmod{24}$，按 Dirichlet 密度占全体素数的一半）的素数 $p$，方程 $p^{x}+6^{y}=z^{2n}$ 对一切 $n\\geq 1$ 在正整数范围内无解，唯一例外为 $(p,n,x,y,z)=(13,1,1,2,7)$，并顺带完全解决了 Ramanujan–Nagell 型方程 $p^{x}=2\\cdot 6^{m}+1$（此时必有 $x=1$）。"

## 1.  核心定位

- **解决的问题**：彻底求解指数丢番图方程 $p^{x}+6^{y}=z^{2n}$（$p$ 为素数，$n\geq 1$，$x,y,z$ 为正整数），但仅限"一半的素数"，即 Legendre 符号 $\left(\frac{6}{p}\right)=-1$ 的那些 $p$；结论是此时方程无解，唯一例外是 $13+6^{2}=7^{2}$。此结果对指数 $n$ 一致成立，而非只处理 $n=1$。
- **大图景位置**：本文属于 $a^{x}+b^{y}=z^{2}$（$a,b$ 为素数）这一经典问题的谱系，与 Suvarnamani、Acu、Sroysang、Burshtein、Mina–Bacani、Tadee–Thaneepoon 等人的工作同族。它把作者此前对 $n=1$ 且 $p\not\equiv 1\pmod{16}$ 的部分结果推广为对全体 $n$ 一致的完整结论，从而填补了"对一半素数完全解决、且指数任意"这一空白。作者强调方程的难点在于它**确实**对某些素数有解（如 $5^{4}+6^{3}=29^{2}$、$53^{2}+6^{3}=55^{2}$、$433+6^{6}=217^{2}$），因此非存在性定理必须找出真正的算术障碍——本文指出这一障碍正是 Legendre 符号 $\left(\frac{6}{p}\right)$。
- **主要贡献**：
  1. 主定理（定理 1）：若 $\left(\frac{6}{p}\right)=-1$ 且 $n\geq 1$，则 $p^{x}+6^{y}=z^{2n}$ 无正整数解，唯一例外为 $(p,n,x,y,z)=(13,1,1,2,7)$；
  2. 独立意义的辅助结果（定理 2）：Ramanujan–Nagell 型方程 $p^{x}=2\cdot 6^{m}+1$（$p\geq 5$ 为素数）只有 $x=1$ 的情形，从而解决了作者先前工作中遗留的开放问题，并去掉了原先额外的同余假设；
  3. 例外素数定理（定理 3）：$13^{x}+6^{y}=z^{2}$ 在正整数中只有唯一解 $(x,y,z)=(1,2,7)$；
  4. 尖锐性（第 6 节）：论证 Legendre 条件不可放松——对 $\left(\frac{6}{p}\right)=+1$ 的素数，分解论证的每一条分支都被真实解所实现。
- **关键先驱工作**：Mihăilescu（2004）对 Catalan 猜想的证明，即 $u^{r}-v^{s}=1$ 只有解 $3^{2}-2^{3}=1$；Zsigmondy（1892）关于 $a^{n}-b^{n}$ 的本原素除子的定理（其本原素除子 $\ell\equiv 1\pmod n$）；Nagell（1948）开创的 Ramanujan–Nagell 型方程 $x^{2}+D=p^{n}$ 研究传统；Sangam（2020）关于 $p=3,n=1$ 情形的三个解；以及 Dirichlet 算术级数素数定理（Apostol）。此外作者此前对 $n=1$ 情形的工作及其提出的开放问题也是直接起点。
- **结果边界**：结论只覆盖 $\left(\frac{6}{p}\right)=-1$ 的素数（模 $24$ 的 $7,11,13,17$ 四个剩余类），对 $\left(\frac{6}{p}\right)=+1$ 的一半素数完全不适用；$p=2,3$ 以及 $p=5$ 等小素数被排除在定理之外（$5^{4}+6^{3}=29^{2}$ 即反例之一）；方法本质依赖 $z^{2n}$ 为**偶数次**幂，对奇数指数 $z^{2n+1}$ 情形平方剩余论证失效；对 $n\geq 2$ 的验证虽有数值支持，但一般性证明仍依赖偶数次幂这一结构。
- **开放问题**：作者明确提出五个问题——(1) 对 $\left(\frac{6}{p}\right)=+1$ 的素数，完全确定 $p^{x}+6^{y}=z^{2}$ 的全部解，这被归约为三个指数丢番图方程 $z^{2}-6=p^{x}$（$x\geq 2$）、$p^{a}=3^{y}-2^{y-2}$、$p^{a}=2^{y-2}3^{y}-1$ 以及 $2\cdot 6^{m}+1$ 的素性；(2) 证明 $5^{a}=3^{y}-2^{y-2}$ 在 $y$ 为奇数时只有解 $(a,y)=(2,3)$，从而推出 $5^{x}+6^{y}=z^{2}$ 的唯一解 $(4,3,29)$；(3) $2\cdot 6^{m}+1$ 为素数的 $m$ 是否有无穷多个（$m=1,2,3,4,10,11,17,\dots$）；(4) 研究奇数指数的方程 $p^{x}+6^{y}=z^{2n+1}$；(5) 把方法推广到 $p^{x}+(2q)^{y}=z^{2n}$（$q$ 为奇素数）在条件 $\left(\frac{2q}{p}\right)=-1$ 下的情形。
- **应用与推广**：本文的技术骨架是"分解 + 互素因子各为单素数幂 + Zsigmondy/Catalan 限制指数"与"模 $p$ 的二次特征标障碍"两条主线，可以迁移到任何形如 $a^{x}+b^{y}=z^{2n}$（$a$ 为素数、$b$ 为偶数幂型底数）的方程：只要能算出 $\left(\frac{b}{a}\right)$ 并控制 $y$ 为奇数、$x$ 为偶数时分解出的两类因子结构（$3^{y}-2^{y-2}$ 与 $2^{y-2}3^{y}-1$ 型），同样的同余排除法就能给出"对一半素数成立"的非存在性定理。Ramanujan–Nagell 型辅助定理（$x=1$）尤其具有独立价值，它把"指数只能为 $1$"这类刚性结论用 Zsigmondy 定理一次性解决，可复用于其他 $p^{x}=c\cdot q^{m}+1$ 型方程。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Erdős–Straus 方程解数计数中的"局部障碍"思想 — 见 [[2609.09204]]
- [[2609.09204]]：该文研究 Erdős–Straus 方程 Type I / Type II 解的数量与局部同余障碍，与本文同属"用模算术条件（剩余类、平方类）解释解的有无与多寡"的范式。差别在于：该文是计数与渐近比较，本文是单方程的完全求解；但两者的核心信念一致——解的存在性由某个体面的局部不变量（那里是 $p\bmod 24$ 型条件，这里是 Legendre 符号 $\left(\frac{6}{p}\right)$）决定。
- [[2609.09209]]：同为 math.NT 方向，讨论 Ramanujan 型 $1/\pi$ 级数的新推广。两文的共同点是都以 Ramanujan 的经典结果作为出发点并给出统一框架，但工具完全不同（该文用超几何求和与 Dougall 恒等式，本文用 Zsigmondy 定理与 Catalan 猜想）。本文引用的 Ramanujan–Nagell 方程 $x^{2}+7=2^{n}$ 正是 Ramanujan 本人提出的问题，可作为两篇笔记之间的历史线索。
- [[2609.09205]]：同为把"最小充分尺度"这类尖锐常数问题彻底定性的工作（该文确定连通 LEGO 模型所需的最少砖块类型数为四），方法论上都是"给出构造 + 证明下界不可再降"，与本文"证明 Legendre 条件不可放松"的尖锐性论证形成对照。
- 技术迁移：本文用 Zsigmondy 定理把 $p^{x}-1$ 的本原素除子逼到 $\{2,3\}$ 从而排除 $x\geq 2$ 的手法，可直接迁移到一切"指数不确定但底数被限制为少数素数"的方程；而"对 $\left(\frac{6}{p}\right)=-1$ 用二次非剩余直接矛盾、对 $+1$ 则需真刀真枪分解"这一二分结构，也提示在同类问题中应当先算特征标再决定证明路线。

### 2.2.  可以尝试的方向

- [ ] 能否把 $\left(\frac{6}{p}\right)$ 这一障碍替换为一般 $\left(\frac{b}{p}\right)$，对 $p^{x}+b^{y}=z^{2n}$（$b$ 为偶数）给出统一的"一半素数"定理？关键难点是 $y$ 偶、$x$ 偶两种情形下的分解因子是否仍能被压成两类。
- [ ] 方程 $z^{n}-6^{m}=1$ 在 $n=1$ 时给出 $z=2\cdot 6^{m}+1$；若改用 Catalan 定理处理 $n\geq 2$，是否可以量化"$z$ 与 $6$ 的幂相差 $1$"的完整解集？
- [ ] 作者留下的 $5^{a}=3^{y}-2^{y-2}$ 问题（问题 2）看起来是纯初等可攻的：能否用模 $5$ 或模 $8$ 的更高阶同余、或对奇 $y$ 使用 引理的 $5\mid 3^{y}-2^{y-2}$ 结构直接排除？
- [ ] 奇数指数情形 $p^{x}+6^{y}=z^{2n+1}$ 中平方剩余论证失效，能否改用在 $\mathbb{Z}[\sqrt{-3}]$ 或分圆整数环中的因子分解（因为 $6^{y}$ 与 $z^{2n+1}$ 的差分解涉及三次单位根）？
- [ ] 计算验证范围有限（$p<500$、$x,y\leq 60$；$n=2$ 时 $p<800$、$x,y\leq 21$），能否把搜索推到 $p<10^{6}$ 借助模 $24$ 预筛加速，看是否存在违反主定理的罕见解？

### 2.3.  批判性思考

- 全文最关键的一步是 $y$ 偶情形中的互素分解：作者断言 $z^{n}-6^{m}$ 与 $z^{n}+6^{m}$ 的公因子整除 $2$ 且为奇，因而互素。这一推理依赖 $z$ 为奇数（由 $p^{x}$ 奇、$6^{y}$ 偶推出），推理正确但宜明确指出 $z^{n}$ 与 $6^{m}$ 一奇一偶是前提。类似地，$y$ 奇、$x$ 偶情形中把公因子确定为 $2$ 时用到了 $p\geq 5$ 不整除 $6^{y}$，这一步也应显式说明 $p\neq 2,3$——文中确实写了 $p\geq 5$，但依赖关系较隐蔽。
- 引理（$3^{y}-2^{y-2}\equiv 0\pmod 5$ 对奇 $y\geq 3$）看似只是小工具，实际上承担了两处关键排除（主定理 $y$ 奇 $x$ 偶情形推出 $p=5$，与例外素数 13 情形排除第一分支）。一个自然的疑问是：是否存在比逐项讨论更统一的"用 $5$ 作为额外障碍"的框架？若把模 $5$ 信息与 Legendre 符号合并成一个联合障碍条件，或可把若干分支一次性排除。
- 主定理对 $n$ 的一致性（$y$ 偶时用 Catalan 处理 $n\geq 2$、用 定理 2 处理 $n=1$）是本文最优雅之处：$n\geq 2$ 直接被 Catalan 的"唯一解 $3^{2}-2^{3}=1$ 不是 $z^{n}-6^{m}=1$ 型"切断，$n=1$ 则交给 Ramanujan–Nagell 型定理并配合 引理（$m\geq 2$ 时 $p\equiv 1\pmod{24}$）完成。这一分工说明 Catalan 与 Zsigmondy 两大定理在指数方程中更像"指数控制器"而非主攻工具。
- 值得追问的是对 $\left(\frac{6}{p}\right)=+1$ 一侧，作者仅展示了若干具体解（$19+6=5^{2}$、$73+6^{4}=37^{2}$、$433+6^{6}=217^{2}$ 等）来证明条件尖锐，但并未论证这些解是全部；问题 1 的归约虽是清晰的三方程分解，然而其中 $z^{2}-6=p^{x}$（$x\geq 2$）本身就是一个尚无一般理论的方程，因此"另一半素数"的完全解决恐怕不会很快到来。
