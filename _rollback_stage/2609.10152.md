# Hybrid Kazhdan-Lusztig basis and parabolic induction

keywords: [Kazhdan-Lusztig 基, Hecke 代数, BGG 范畴 O, 抛物诱导, 分层结构, 倾斜模]
related_paper: "Kazhdan--Lusztig 1979 年关于 Coxeter 群与 Hecke 代数表示的工作（KL 基与 KL 多项式的源头）"
one_liner_summary: "本文为 Hecke 代数的混合 Kazhdan-Lusztig 基提供范畴化：对每个抛物子群与左/右侧选择，在主块的分级提升上构造对应的分层结构，使其标准模与混合基元素相匹配，并由此给出正性现象（当一个抛物子群包含于另一个时，两个混合基之间转移矩阵的系数非负）的范畴解释。"

## 1.  核心定位

- **解决的问题**：混合 Kazhdan-Lusztig 基由一个抛物子群与一个左/右侧选择确定，其元素是抛物子群 KL 基元素与整群标准基元素（下标为最短陪集代表元）的乘积；已有工作证明当两个抛物子群有包含关系时，两个混合基之间转移矩阵的系数具有正性。本文追问：这种正性是否有范畴层面的解释？
- **大图景位置**：处在 Kazhdan-Lusztig 组合学、Hecke 代数与 BGG 范畴 O 主块这一经典三角之中。经典情形下，分级主块的 Grothendieck 群与 Hecke 代数同构，单模对应对偶 KL 基、Verma 模对应标准基、不可分解投射模对应 KL 基，正性由投射模具有 Verma 旗（最高权范畴、拟遗传代数）解释。本文在这三个基之间插入由抛物子群参数化的一族中间基，并给出相应的分类学（分层结构）。
- **主要贡献**：(1) 对给定抛物子群与左/右侧选择，证明分级主块 $\mathcal{O}_0$ 上存在分层结构（CPS 意义下的 stratified structure），其标准模与相应的混合 KL 基元素一致；(2) 描述该分层结构下的倾斜模；(3) 确定混合 KL 基的自然对偶；(4) 作为技术副产品，发现投影函子与 shuffling 函子之间的新关系，其证明归结为奇异辫幺半群中的组合恒等式。
- **关键先驱工作**：Kazhdan--Lusztig 的 KL 基与 KL 多项式；BGG 与 Humphreys 对范畴 O 组合学的建立；CPS 的最高权范畴与分层代数理论；拟遗传代数的 Dlab--Ringel 理论；混合基的定义（原文引用标记 [GH07]）及其正性结果（原文引用标记 [BMS]）；抛物诱导构造分层结构的原有范式（原文引用标记 [FKM]）；用于把 proper standard 模从另一侧转移的等价（原文引用标记 [So86]）；关于 Serre 商等价的结论（原文引用标记 [CMZ]）；奇异辫幺半群经由 shuffling 函子与投影函子作用在主块上的观察（原文引用标记 [MS2, J-Z]）；源自 $\nabla$-滤过维数的技术工具（原文引用标记 [Pa, MO]）。
- **结果边界**：左/右两侧在范畴层面并非对称——组合层面左右对称，但由于主块上不存在诱导 $w\mapsto w^{-1}$ 的自等价，范畴层面的右侧情形无法沿用投影函子方法，必须借助文献 [So86] 的等价与 Serre 商等价绕行；分层结构的存在性与倾斜模刻面对左右两侧分别证明，两个结构一般不同；技术引理依赖逐型分类讨论，$E_7$ 与 $E_8$ 需要 SageMath 辅助大量计算。
- **开放问题**：作者在引言中未单列开放问题，但指出左右不对称的根源是主块缺少实现逆元映射的自等价。可引申：是否能在更大的范畴（导出范畴或 Soergel 双模范畴）中恢复这种对称？混合基的自然对偶能否组织为一个整体的对偶函子而非逐个基的描述？$E_7$、$E_8$ 的情形能否给出概念化证明以替代逐型验证？
- **应用与推广**：为混合基的正性提供范畴机制：若第二个抛物子群包含第一个，则第二个结构的标准对象具有以第一个结构的标准模为子商的滤过，于是转移系数非负；该"分层结构—倾斜模—正性"模板可移植到其他最高权范畴（有限维代数模、Schur 代数、Ariki--Koike 代数等）；投影函子与 shuffling 函子的关系可迁移到 Soergel 双模与图式 Hecke 范畴。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：[[2607.19112]]：该笔记讨论 KL 多项式取值与 Verma 模重数的关系（重数不小于二时置换对的分类），与本文一样把 KL 侧的数值性质翻译为范畴 O 中的结构常数正性问题，只是本文的翻译方向是"为基的正性找范畴模型"。
- [[2607.25224]]：该文引入 H-表示与 KL 相容性，用箭图表示解释 Hecke 代数结构常数的正性；与本文"标准模具有滤过"的范畴解释构成正性问题的两条互补路线（箭图表示路线与分层结构路线）。
- [[2608.02187]]：该笔记讨论图式 Hecke 范畴与 Soergel 双模这条 KL 范畴化路线；本文则在经典范畴 O 内部用文献 [So86] 的等价替代投影函子以打通困难的一侧，两者都体现"用更富结构的范畴替换难以直接操作的一侧"这一策略。
- [[2607.15991]]：该文用 wide 子范畴与 torsion class 的格刻画 brick 有限性；torsion 类格的滤过语言与本文分层结构中"标准模的滤过"在形式上同源，可作为"格结构决定正性"的另一个例子。
- 技术迁移：把"用一个子结构（抛物子群）的参数化基构造分层结构，再用标准模滤过解释正性"的范式，迁移到其他带子结构参数的基（例如有限型代数的 g-向量与支撑 $\tau$-倾斜模）是否可行？

### 2.2.  可以尝试的方向

- [ ] 当两个抛物子群没有包含关系时，转移矩阵是否出现负系数？能否用分层结构的滤过性给出判据？
- [ ] 把分层结构的构造从有限 Weyl 群推广到仿射 Weyl 群（仿射 Hecke 代数）或复反射群？
- [ ] 混合基能否用倾斜模的同构类直接刻画，从而绕开奇异辫幺半群的逐型计算？
- [ ] 左/右两侧的差异能否在导出范畴中消解，即是否存在交换两侧的导出自等价？

### 2.3.  批判性思考

- 左右不对称被归因于主块缺少实现 $w\mapsto w^{-1}$ 的自等价，这是已有事实；但作者未讨论能否在更大的范畴中恢复对称，因此"不对称"是否本质仍不清楚。
- 技术引理依赖逐型验证（$E_8$ 尤甚），这类证明不提供结构性理解；是否存在用最长元共轭作用与辫群表示表示的优雅论证，作者明确表示未找到。
- 右侧情形的倾斜模刻画借助 $\nabla$-滤过维数等间接工具与 Serre 商等价绕行，使人怀疑是否存在更直接的导出范畴论证（例如用倾斜或 silting 理论）来统一两侧。
