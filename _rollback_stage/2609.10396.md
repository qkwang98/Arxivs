# Cluster Morita theorem for negative cluster categories

keywords: [负簇范畴, simple-minded system, Koszul 对偶, Calabi-Yau 结构, dg 代数]
related_paper: "2609.10110"
one_liner_summary: "本文证明带 (-d)-simple-minded system 的 Hom-finite 代数三角范畴必可实现为局部有限严格正 dg 代数的余奇异商，并在 Calabi-Yau 假设下用有限维分级扩张代数刻画无环负簇范畴。"

## 1.  核心定位

- **解决的问题**：给定一个抽象代数三角范畴以及其中的 (-d)-simple-minded system，如何从这一有限数据反向重构范畴本身。由于 basic simple-minded system 的零次自同态只给出 $\End(L)\simeq k^r$，作者转而以 dg 自同态代数 $\REnd(L)$ 及其正/非正 Koszul 对偶作为不变量。
- **大图景位置**：这是 Keller--Reiten 识别定理在负 Calabi--Yau 侧的对应物。Keller--Reiten 用 cluster-tilting 对象的自同态代数控制代数 $2$-Calabi--Yau 范畴，本文则以 simple-minded system 取代 cluster-tilting 对象、以高阶扩张取代零次自同态，从而填补了"从 simple-minded 数据反向重构环境范畴"这一 Morita 型空白。
- **主要贡献**：
  1. cosingular realization 定理（Theorem main:realization）：每个带 $(-d)$-simple-minded system 的 Hom-finite 代数三角范畴都存在局部有限、严格正、$d$-stable 的 dg 模型 $A$（$A^0\simeq k^r$），使得 $\cosg_{\dg}(A)=\per_{\dg}(A)/\pvd_{\dg}(A)\simeq\C_{\dg}$；等价地 $\C\simeq\underline{\CM}(B)$，其中 $B=A^!$ 是 $(-d)$-自入射的 Koszul 对偶。
  2. 负 Keller--Reiten 识别定理（Theorem main:negative-KR）：若 $d\leq-3$、$\C$ 是 Hom-finite 代数 $d$-Calabi--Yau 范畴且 $\bigoplus_{i=0}^{-d-1}\Hom_\C(L,\Sigma^iL)\simeq kQ^!$（$Q$ 为有限无环箭图），则 $\C\simeq\C_d(kQ)=\D^b(kQ)/(\Sigma^{-d}\Serre)$；$d=-2$ 时在 $\Hcal_\Lcal$ 遗传的额外假设下同样成立。
  3. 链层面的 Calabi--Yau 对应：Hochschild 局部化边界 $\partial_{\mathrm{HH}}:\HHom_{-d}(\cosg_{\dg}(A))\xrightarrow{\sim}\HHom_{-d-1}(\pvd_{\dg}(A))$ 的对偶保持并检测非退化性，从而在 $\pvd_{\dg}(A)$ 上的右 $(d+1)$-Calabi--Yau 结构与 $\cosg_{\dg}(A)$ 上的 $\ell$-规范化右 $d$-Calabi--Yau 结构之间建立双射（Theorem main:normalized-CY）；当 Koszul 对偶 $B$ proper 时，Brav--Dyckerhoff 求值态射 $M(\per_{\dg}(A))\xrightarrow{\sim}\DD M(\pvd_{\dg}(A))$ 是混合复形的拟同构，给出左右 Calabi--Yau 对称（Theorem main:left-right-CY）。
- **关键先驱工作**：Keller 为簇范畴赋予典范三角结构；Keller--Reiten 的识别定理（[KR08]）及其高维变体；Koenig--Liu 与 Dugas 的 simple-minded system 理论；Jin 的 $w$-自入射 dg 代数与 Cohen--Macaulay 对偶（[Jin20, Theorem 5.6]），本文正是以其余奇异商 $\underline{\CM}(B)$ 描述作为对照的逆向构造；Fushimi 自身的局部有限 dg 代数反变 Koszul 对偶（[Fus24, Theorem D]）；Hanihara--Liu 的局部化形式化与 Keller--Nicolás 权结构；Brav--Dyckerhoff 的求值态射（[BravDyckerhoff19]）。
- **结果边界**：全程要求 $d\leq-2$（识别定理要求 $d\leq-3$，$d=-2$ 需额外遗传假设）；范畴须 Hom-finite 且带预三角 dg 增强；构造出的模型须是局部有限、严格正、$d$-stable；左右 Calabi--Yau 对称依赖 Koszul 对偶 proper；局部有限性会迫使 $B$ proper。文中例示（exa:cyclic-family）说明 $d$-stability 严格弱于要求余奇异商本身是 $d$-Calabi--Yau，因此定理的适用面比"余奇异商 $d$-CY"更宽，但也意味着二者不可混用。
- **开放问题**：核心文本未单列开放问题；可辨识的遗留包括：$d$-stable 与余奇异商 $d$-Calabi--Yau 之间的差距如何在不引入循环族例外的情形下量化，以及能否在放弃局部有限性、严格正性或 proper 假设后维持同一 Morita 描述。
- **应用与推广**：负 Calabi--Yau 范畴的识别被归约为有限维分级扩张代数（其一次部分给出箭图 $Q$）的有限数据，可由箭图组合计算；链层面结果可把左 Calabi--Yau 结构经 $\pvd_{\dg}(A)$ 运输为右结构，与 Keller--Liu 型 Calabi--Yau 对偶、Holstein--Rivera 的相关结果形成同一技术族；与 silting 理论、约化、Coxeter 组合学（[CoelhoPauksztello20, Jin23Reduction, IyamaJin23]）以及奇点范畴描述（Jin）天然互通。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起 Keller--Reiten 的 $2$-Calabi--Yau 识别定理与 Amiot--Guo--Keller 的基本域实现 — 见 [[2608.03212]]：该文研究 $n$-cotorsion pair 的"心"构造，与本文用正窗口作为余奇异商的基本域，都是"在三角范畴里找一块有限基本域来控制整体"的思路。
- [[2609.10110]]：Derived equivalences between diagram categories of finite posets 用有限偏序集上的图表范畴刻画导出等价，与本文用有限扩张窗口 $\bigoplus_{i=0}^{-d-1}\Hom_\C(L,\Sigma^iL)$ 决定范畴的路线同源——都由有限组合/分级数据决定无穷结构的等价性。
- [[2609.09732]]：A counterexample to the periodicity conjecture for finite-dimensional algebras 表明有限维代数的组合数据未必总表现良好；本文把识别归约到 $kQ^!$（集中在 $0,1$ 次）的强假设，正可视为对"有限数据够用"的精细刻画，同时提示一旦扩张代数出现更高次分量，结论可能崩坏。
- 技术迁移：把"截断到有限窗口 + 反变 Koszul 对偶"作为 Morita 模型的套路，或许可用于全局维数无穷的倾斜代数，或用于把 $\tau$-tilting 有限性等性质翻译成 dg 层面的 proper/平滑条件。

### 2.2.  可以尝试的方向

- [ ] 去掉 strictly positive 假设（允许 $A^0$ 非半单），余奇异商是否仍能刻画原范畴？
- [ ] 对一般的 non-positive dg 代数，能否建立类似的 cosingular realization，并保持 $d$-stability 的等价刻画？
- [ ] 例循环族中 $d$-stability 与 $d$-Calabi--Yau 的差距，是否可以用某个可计算的障碍类（如 $\pvd$ 上的自入射位移）来度量？

### 2.3.  批判性思考

- 构造的关键是把 $\REnd_{\C_{\dg}}(L)$ 截断到与窗口 $C=\Hcal_\Lcal*\Sigma^{-1}\Hcal_\Lcal*\cdots*\Sigma^{d+1}\Hcal_\Lcal$ 相关的上同调上；被丢弃的窗口外上同调是否可能承载诸如 Serre 函子之类的不变量，从而影响结论的可判别性，值得追问。作者以负 Keller--Reiten 定理说明有限范围（$i\leq-d-1$）足够，实际上也是对这一疑问的部分回答。
- 在局部有限情形，$d$-stability 会"迫使 $B$ proper"是一个相当强的隐含约束；若 $B$ 非 proper，定理各部分的陈述是否需相应改写（例如 $\underline{\CM}$ 的替代描述），论文未展开。
- 定理的证明走 Koszul 对偶、内在形式性与 Jin 的奇点范畴描述三条路线，链条较长；对"识别"类结论而言，更强的做法也许是直接给出从 $\C$ 到 $\C_d(kQ)$ 的显式三角函子，而非经由上同调计算。
