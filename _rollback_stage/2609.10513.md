# Unimodality shenanigans in Ehrhart theory

keywords: [IDP 多胞体, $h^*$-多项式, 单峰性, 对数凹性, Ehrhart 级数, Cayley 和]
related_paper: "Ferroni–Higashitani 的综述与猜想 [Conjecture 1.2]（IDP 多胞体 Ehrhart 级数的对数凹性）——本文正是在搜寻该猜想反例的过程中反过来推翻了 Stanley 的单峰性猜想"
one_liner_summary: "本文以矩形棱柱的 Cayley 和构造出一族具有正规单模旗三角剖分（从而自动满足 IDP）的多胞体，给出 $h^*$-多项式非单峰、Ehrhart 级数非对数凹、以及 Gorenstein 情形下 $h^*$-多项式与内部 Ehrhart 级数非对数凹的反例，从而推翻 Stanley 单峰猜想、Brenti 猜想与 Ferroni–Higashitani 猜想；对 Stanley 猜想甚至可给出光滑多胞体的反例。"

## 1.  核心定位

- **解决的问题**：给出四十年悬案——「IDP 多胞体的 $h^*$-多项式是否单峰」（Stanley 猜想）——的反例；顺带给出 Brenti 关于 Gorenstein 标准分次 Gorenstein 整环 Hilbert 分子对数凹性的猜想、以及 Ferroni–Higashitani 关于 IDP 多胞体 Ehrhart 级数对数凹性的猜想、其关于"存在非对数凹内部 Ehrhart 级数的 very ample 多胞体"的问题的反例/肯定回答。
- **大图景位置**：该猜想是 Stanley [Conjecture 4] 的一个特例的弱化形式，由 Schepers–van Langenhoven 重新提出为 Question 1.1；近年的两个突破（Adiprasito–Papadakis–Petrotou–Steinmeyer 与 Adiprasito–Papadakis–Petrotou 在 Gorenstein 假设下证明单峰性；Hofscheier–Kurylenko–Nill 证明对数凹性版本为假）使人们以为该猜想"最可能为真"，本文表明这些结果在某种意义上是"最优可能"的：既不能升级为对数凹性，Gorenstein 假设也不能丢。
- **主要贡献**：
  1. 构造矩阵 $A$ 的矩形棱柱 Cayley 和 $\mathcal C(A)$，证明它总具有正规单模旗三角剖分（故满足 IDP），并给出其维数、顶点数、不等式描述、光滑性与 Gorenstein 性的判别条件。
  2. 给出 $\mathcal C(A)$ 的 Ehrhart 多项式的显式组合求和公式与 $h^*$-多项式公式（用 Newton 基展开系数 $c_i(A)$ 表出），以及内部格点数公式与 Ehrhart 互反形式。
  3. 通过具体参数（$d=n=20$、$\alpha=50$、$\beta=800$）给出 $h^*_{18}>h^*_{19}<h^*_{20}$ 的 IDP 反例；通过加一全 1 矩阵给出光滑反例；通过 $6\times4$ 矩阵 $B_{s,s}+J$ 给出非对数凹 Ehrhart 级数；通过 $6m\times4$ 行和为 2 的矩阵给出 75 维 Gorenstein 反例与内部 Ehrhart 级数非对数凹的推论。
- **关键先驱工作**：Ehrhart 的 Ehrhart 多项式存在性定理与 Ehrhart 互反；Stanley [Conjecture 4] 及其综述传统（Braun、Ferroni–Higashitani 的综述）；Haase–Paffenholz–Piechnik–Santos 的 Nakajima 多胞体与 integral chimney 定理（Corollary 2.9 / Theorem 2.8）；Athanasiadis 关于正规单模三角剖分下 $h^*$ 后半递减的定理；Adiprasito–Papadakis–Petrotou–Steinmeyer 与 Adiprasito–Papadakis–Petrotou 的 Gorenstein 情形证明；Hofscheier–Kurylenko–Nill 的 very ample 非单峰例子；Brenti 的猜想 5.2。
- **结果边界**：反例全部落在"矩形棱柱的 Cayley 和"这一特殊类中，其有效性依赖逐例的精确整数计算（如 $100(h^*_{18}-h^*_{19})>h^*_{20}$）；Gorenstein 反例要求每行和为 2，从而指数为 $d+1=4$；作者明确表示该类中未能找到 $\gamma$-正性（Gal 猜想类比）的反例，并预告将证明此类中不存在反例；Ferroni–Higashitani 的 Question 5.12(a)（要求 $|E_P(-2)|^2<|E_P(-1)||E_P(-3)|$）未被本文的例子解决，因为 $|E_R(-1)|=|E_R(-2)|=|E_R(-3)|=0$。
- **开放问题**：是否存在属于此类（Gorenstein、正规单模旗三角剖分）但 $h^*$-多项式非 $\gamma$-正的例子（即 Gal 猜想类比的反例）？作者未能找到，且预告将证明此类中不存在；Question 5.12(a) 的强形式（在 $|E_P(-1)|,|E_P(-2)|,|E_P(-3)|$ 均非零时的对数凹性破坏）仍开放。
- **应用与推广**：提供了一个"用 IDP 多胞体族同时检验多条单峰性/对数凹性猜想"的通用构造与计算框架——只需选定非负整数矩阵 $A$，即可用求和公式数值搜索非单峰/非对数凹的 $h^*$；该框架原则上可用于检验其它关于 $h^*$ 系数、$\gamma$-正性、Ehrhart 级数或局部 $h$-多项式的猜想；"Cayley 和 + integral chimney + Nakajima 多胞体"的三段式证明也是验证多胞体具有正规单模旗三角剖分的可复用模板。

## 2.  主要定理

> **全局假定 / 背景**: 设 $P\subseteq\mathbb{R}^n$ 为格多胞体。称 $P$ 具有**整数分解性质**（IDP），若对每个正整数 $k$，每个格点 $p\in kP\cap\mathbb{Z}^n$ 都可写成 $p=p_1+\cdots+p_k$（$p_1,\ldots,p_k\in P\cap\mathbb{Z}^n$）；若该性质只对充分大的 $k$ 成立，则称 $P$ 为 **very ample**。Ehrhart 多项式 $E_P(t)\in\mathbb{Q}[t]$ 满足 $E_P(m)=\#(mP\cap\mathbb{Z}^n)$；$h^*_P(z)$ 由 $\sum_{m\geq 0}E_P(m)z^m=h^*_P(z)/(1-z)^{\dim P+1}$ 定义。称 $h(z)=h_0+\cdots+h_sz^s$ 为**单峰**的，若存在 $j$ 使 $h_0\leq\cdots\leq h_j\geq\cdots\geq h_s$；称系数非负的 $h$ 为**对数凹**的，若 $h_i^2\geq h_{i-1}h_{i+1}$（$0<i<s$）。取值方式：矩阵 $A\in\mathbb{Z}_{\geq0}^{n\times(d+1)}$ 无零行，$D_j=\prod_{i=1}^n[0,a_{ij}]$ 为矩形棱柱，$\mathcal C(A)$ 为 $D_0,\ldots,D_d$ 的 Cayley 和，维数恒为 $n+d$。

> **Conjecture 1.1**: If $P$ is an IDP polytope, then the $h^*$-polynomial of $P$ is unimodal.

*动机 / 作用（中文）*: 这是全文要推翻的目标，是 Stanley [Conjecture 4] 特殊情形的弱化，也被 Schepers–van Langenhoven 作为 Question 1.1 提出；它只要求 IDP 这一较弱的代数和条件，而不要求光滑性或三角剖分。
*证明思路（中文）*: 本文不证明它，而是给出其反例；反驳策略是先对一般的 $A$ 写出 $E_{\mathcal C(A)}(k)$ 的求和公式（Theorem 1.3 所在的 Section 3），再把"找反例"化为"在 $d,\alpha,\beta$ 上暴力搜索非单峰的 $h^*$"。

> **Theorem 1.2**: There exist infinitely many IDP lattice polytopes for which the $h^*$-polynomial is not unimodal.

*动机 / 作用（中文）*: 主结果之一，直接推翻 Conjecture 1.1；由于所构造的多胞体带正规单模旗三角剖分，反例甚至落在"三角剖分良好"的最强情形中，出人意料。
*证明思路（中文）*:
- 第一步：取 $d=n=20$、$\alpha=50$、$\beta=800$，令 $P=\mathcal C(A_{50,800})$，由 Proposition 2.1 与 2.2 得 $\dim P=40$ 且它具有正规单模旗三角剖分（故 IDP）。
- 第二步：用求和公式与 $h_P^*(z)=(1-z)^{41}\sum_kE_P(k)z^k$ 得系数抽取式 $h_r^*=\sum_{k=0}^r(-1)^{r-k}\binom{41}{r-k}E_P(k)$，精确算出 $h_{18}^*=949^{20}-2879\cdot899^{19}+1\,288\,210\cdot849^{18}$、$h_{19}^*=899^{20}-1829\cdot849^{19}$、$h_{20}^*=849^{20}$。
- 第三步：给出紧凑整数证书 $100(h^*_{18}-h^*_{19})>h^*_{20}>0$ 与 $100(h^*_{20}-h^*_{19})>h^*_{20}$，从而 $h^*_{18}>h^*_{19}<h^*_{20}$。
- 第四步：注意到给 $A$ 追加零列相当于对 $\mathcal C(A)$ 作格金字塔（新层只有一个点），而格金字塔与原底有相同 $h^*$-多项式（Ehrhart 级数差一个 $1-z$），故得到一切维数 $\geq40$ 的反例。

> **Theorem 2.3 (smooth counterexample)**: There are smooth polytopes admitting regular unimodular flag triangulations and whose $h^*$-polynomials are not unimodal.

*动机 / 作用（中文）*: 说明反例不仅存在于一般 IDP 多胞体中，还存在于最"几何良好"的光滑多胞体中，进一步压缩了可能为该猜想辩护的空间。
*证明思路（中文）*: 取 $J$ 为 $20\times21$ 全 1 矩阵、$P_s=\mathcal C(A_{50s,800s}+J)$（$s\geq1$）；所有元素为正故由 Proposition 2.3 得 $P_s$ 光滑；对 $s=100$ 计算 $E_{P_s}(k)=\sum\prod_i(50sb_0+800sb_i+k+1)$，用系数抽取式得 $100(h^*_{18}-h^*_{19})>h^*_{20}>0$ 与 $100(h^*_{20}-h^*_{19})>3h^*_{20}$，故 $h^*_{18}>h^*_{19}<h^*_{20}$。

> **Theorem 1.4**: There exist infinitely many IDP lattice polytopes whose Ehrhart series is not log-concave.

*动机 / 作用（中文）*: 推翻 Ferroni–Higashitani [Conjecture 1.2]；即存在 IDP 多胞体使无穷序列 $E_P(0),E_P(1),E_P(2),\ldots$ 非对数凹。作者自述正是在搜寻该猜想反例时找到突破口，才反过来解决 Stanley 猜想。
*证明思路（中文）*:
- 第一步：取 $6\times4$ 矩阵 $B_{\alpha,\beta}$（前 3 行形如 $(\alpha,\alpha,0,0)$ 等，后 3 行形如 $(0,\beta,0,0)$ 等），令 $P_s=\mathcal C(B_{s,s}+J)$：由 Proposition 2.1、2.2、2.3 得它是 9 维光滑、带正规单模旗三角剖分的 IDP 多胞体。
- 第二步：计数公式特化为 $E_{P_s}(k)=\sum_{b_0+b_1+b_2+b_3=k}\prod_{i=1}^{3}(s(b_0+b_i)+k+1)(sb_i+k+1)$。
- 第三步：逐次数值阶：$E_{P_s}(1)$ 是 $s$ 的三次多项式、首项 $8s^3$；$E_{P_s}(2)$ 次数 $\leq4$；$E_{P_s}(3)$ 次数为 6、首项 $s^6$（唯一来源是 $(b_0,b_1,b_2,b_3)=(0,1,1,1)$ 贡献的 $(s+4)^6$）。
- 第四步：得 $E_{P_s}(1)E_{P_s}(3)-E_{P_s}(2)^2=8s^9+O(s^8)>0$ 对充分大 $s$ 成立，且体积随 $s$ 严格增加，故有无穷多反例；$s=1000$ 给出显式整数证书（差值 $1\,955\,178\,315\,558\,917\,866\,776\,927\,420>0$）。

> **Theorem 1.5**: There exist Gorenstein IDP polytopes whose $h^*$-polynomial is not log-concave.

*动机 / 作用（中文）*: 推翻 Brenti [Conjecture 5.2]；并说明 Adiprasito 等人的 Gorenstein 单峰性定理确实"不能再加强"为对数凹性。由于 $R_m$ 的 Ehrhart 环是标准分次 Gorenstein 整环、其 Hilbert 分子恰为 $h^*_{R_m}$，该例同时构成 Brenti 猜想的反例。
*证明思路（中文）*:
- 第一步：取 $A_m$ 为 $6m\times4$ 矩阵（六种行 $e_0+e_i$、$2e_i$（$1\leq i\leq3$）各取 $m$ 份），$R_m=\mathcal C(A_m)$；每行和为 2，故由 Proposition 2.1、2.2、2.4 得 $R_m$ 是 $6m+3$ 维、指数为 4 的 Gorenstein IDP 多胞体，带正规单模旗三角剖分，且 $|E_{R_m}(-k-4)|=E_{R_m}(k)$。
- 第二步：由计数公式得 $E_m(k)=\sum_{b_0+\cdots+b_3=k}\prod_{i=1}^{3}(b_0+b_i+1)^m(2b_i+1)^m$，分组 $k=1,2,3$ 得 $E_m(1)=8^m+3\cdot6^m$、$E_m(2)=27^m+6\cdot36^m+3\cdot15^m$、$E_m(3)=64^m+3\cdot108^m+3\cdot80^m+3\cdot162^m+3\cdot28^m+6\cdot90^m+216^m$。
- 第三步：取 $m=12$（维数 75），算出 $E_R(1),E_R(2),E_R(3)$，再由 $h_R^*(z)=(1-z)^{76}\sum_kE_R(k)z^k$ 读出 $h_1^*,h_2^*,h_3^*$。
- 第四步：得到 $h_1^*h_3^*-(h_2^*)^2=33\,767\,772\,755\,382\,700\,161\,244\,430\,421\,001\,196\,588>0$，故 $h_R^*$ 非对数凹。

> **Corollary 5.2**: There exists a Gorenstein polytope admitting a regular unimodular flag triangulation whose interior Ehrhart series is not log-concave.

*动机 / 作用（中文）*: 肯定回答 Ferroni–Higashitani [Question 5.12(b)]；由 Ehrhart 互反 $|E_R(-5)|=E_R(1)$、$|E_R(-6)|=E_R(2)$、$|E_R(-7)|=E_R(3)$ 直接把 Gorenstein 反例转成内部 Ehrhart 级数的反例。
*证明思路（中文）*: 取同一 $R=R_{12}$；由 $(k+d+1)\mathcal C(A)$ 的内部格点平移公式得上述互反对应，再用同样的 $E_R(1),E_R(2),E_R(3)$ 计算 $|E_R(-5)E_R(-7)|-|E_R(-6)|^2>0$。

> **Proposition 5.3**: There exists a smooth member of the class with a non-log-concave interior Ehrhart series.

*动机 / 作用（中文）*: 把 Corollary 5.2 从 Gorenstein 提升到光滑情形，说明内部 Ehrhart 级数的对数凹性破坏也发生在几何条件最好的成员中。
*证明思路（中文）*: 取 $J$ 为 $180\times4$ 全 1 矩阵、$S=\mathcal C(1000A_{30}+J)$（维数 183、光滑、带正规单模旗三角剖分）；对 $k=5,6,7$ 用内部计数公式写出 4、10、20 项整数和，验证 $107|E_S(-6)|^2<100|E_S(-5)||E_S(-7)|<108|E_S(-6)|^2$，从而 $|E_S(-6)|^2<|E_S(-5)||E_S(-7)|$。

> **Theorem 3.3**: For every nonnegative integer $k$, $$E_{\mathcal C(A)}(k)=\sum_{\substack{b_0+\cdots+b_d=k\\b_j\in\mathbb{Z}_{\ge0}}}\prod_{i=1}^n\left(1+\sum_{j=0}^d a_{ij}b_j\right).$$ Its $h^*$-polynomial is $$h^*_{\mathcal C(A)}(z)=\sum_{i=0}^n c_i(A)z^i(1-z)^{n-i}.$$

*动机 / 作用（中文）*: 全文的计算基础设施：把 $\mathcal C(A)$ 的 Ehrhart 多项式化为一个有限组合和，从而把"找非单峰 $h^*$"变成可以暴力搜索与精确整数验证的问题；$c_i(A)$ 是 $F_A(u)=\prod_{i=1}^n(1+\sum_ja_{ij}u_j)$ 在多元二项基下的展开系数按次数分组。
*证明思路（中文）*:
- 第一步：固定基坐标 $b_j=y_j$（$j\geq1$）、$b_0=k-\sum_jy_j$，每个纤维坐标 $x_i$ 有 $1+\sum_ja_{ij}b_j$ 个选择，独立性给出求和公式。
- 第二步：把 $F_A(u)=\sum_{|\nu|\leq n}c_\nu(A)\binom{u}{\nu}$ 代入求和，用组合恒等式 $\sum_{b_0+\cdots+b_d=k}\prod_j\binom{b_j}{\nu_j}=\binom{k+d}{d+|\nu|}$（其生成函数为 $z^{|\nu|}/(1-z)^{d+1+|\nu|}$）。
- 第三步：按 $|\nu|$ 归并得 $\sum_{k\geq0}E_{\mathcal C(A)}(k)z^k=\sum_{i=0}^nc_i(A)z^i/(1-z)^{d+i+1}$，再乘 $(1-z)^{n+d+1}$ 即得 $h^*$ 公式。

> **Proposition 2.1**: The polytope $\mathcal C(A)$ is an $(n+d)$-dimensional lattice polytope, and $$\mathcal C(A)=\left\{(x,y)\in\mathbb{R}^n\times\Delta_d:0\le x_i\le\sum_{j=0}^d a_{ij}\lambda_j(y)\quad(1\le i\le n)\right\}.$$ Its vertices are precisely $$\bigcup_{j=0}^d\left\{(x,v_j):x_i\in\{0,a_{ij}\}\text{ for }1\le i\le n\right\},$$ where repeated coordinate choices are counted only once. In particular, if $s_j=\#\{i:a_{ij}>0\}$, then the number of vertices of $\mathcal{C}(A)$ is $\sum_{j=0}^d 2^{s_j}$.

*动机 / 作用（中文）*: 给出 $\mathcal C(A)$ 的完整几何描述（维数、不等式、顶点），是后续三角剖分、光滑性、Gorenstein 性与计数公式的共同基础。
*证明思路（中文）*: 对固定 $y\in\Delta_d$，投影纤维是 Minkowski 和 $\sum_j\lambda_j(y)D_j$，因各 $D_j$ 是坐标棱柱故等于 $\prod_{i=1}^n[0,\sum_ja_{ij}\lambda_j(y)]$；$y$ 取 $\Delta_d$ 内部时所有纤维长度为正（无零行），故维数为 $n+d$；每层 $D_j\times\{v_j\}$ 是投影下基单形顶点的原像，故为面、其顶点即 $\mathcal C(A)$ 的顶点。

> **Proposition 2.2**: Every polytope $\mathcal C(A)$ admits a regular unimodular flag triangulation. In particular, it has the integer decomposition property.

*动机 / 作用（中文）*: 保证所有反例都属于 IDP 类（从而才有资格反驳只要求 IDP 的猜想），同时也是"反例带正规单模旗三角剖分"这一意外之处的来源。
*证明思路（中文）*: 用 Haase–Paffenholz–Piechnik–Santos 的 integral chimney 定理：若 $P$ 有正规单模旗三角剖分，则 $\operatorname{Chim}(P,0,f)$ 也有；从 $\Delta_d$ 的平凡三角剖分出发，逐个添加 $x_1,\ldots,x_n$，其上方函数 $f_i(y)=\sum_ja_{ij}\lambda_j(y)$ 是整仿射且非负，故每步都适用；等价地说 $\mathcal C(A)$ 是 Nakajima 多胞体。

> **Proposition 2.3**: If every entry of $A$ is positive, then $\mathcal C(A)$ is smooth.

*动机 / 作用（中文）*: 给出光滑性的充分条件，用于 Theorem 2.3、Section 4 与 Proposition 5.3 中的光滑反例。
*证明思路（中文）*: 在顶点 $(x,v_j)$ 处恰有 $d$ 个基不等式与每个纤维坐标的一条界取等，正性保证两条界不重合，故 $n+d$ 个法向量线性无关、顶点是单形的；层内 $n$ 条边的本原方向为 $(\pm e_i,0)$，其余 $d$ 条边的方向具有整纤维坐标与基分量 $v_\ell-v_j$，而 $\{v_\ell-v_j\}$ 构成 $\mathbb{Z}^d$ 的基，拼成块三角矩阵且对角块幺模，故得 $\mathbb{Z}^{n+d}$ 的基。

> **Proposition 2.4**: Suppose every row of $A$ sums to two. Then $\mathcal C(A)$ is Gorenstein of index $d+1$. For every $k\ge0$, $$((k+d+1)\mathcal C(A)^{\operatorname{relint}})\cap\mathbb{Z}^{n+d}=\mathbf1+\left(k\mathcal C(A)\cap\mathbb{Z}^{n+d}\right).$$ In particular, $|E_{\mathcal C(A)}(-k-d-1)|=E_{\mathcal C(A)}(k)$, by Ehrhart reciprocity.

*动机 / 作用（中文）*: 提供 Gorenstein 性的组合判别与"内部点平移"公式，是 Section 5 中 Gorenstein 反例与内部 Ehrhart 级数反例的技术核心。
*证明思路（中文）*: 内部格点对应正整数 $b_0,\ldots,b_d$ 和为 $k+d+1$ 及满足 $1\leq x_i\leq\sum_ja_{ij}b_j-1$ 的纤维坐标；对每个 $b_j,x_i$ 减 1，行和为 2 使所得不等式恰为 $k\mathcal C(A)$ 的，遂得平移公式；$d+1$ 次膨胀前无内部格点，而 $d+1$ 次膨胀时所有重心与纤维坐标都等于 1；把 $(d+1)\mathcal C(A)$ 按该点平移后所有面到原点格距离为 1，即得自反性。

## 3.  关键组件

### 3.1.  关键引理

> **引理（Ehrhart 互反的生成函数形式，式 (3.7)）**: $$\sum_{k\ge1}|E_{\mathcal C(A)}(-k)|z^k=\frac{z^{n+d+1}h^*_{\mathcal C(A)}(z^{-1})}{(1-z)^{n+d+1}}.$$ — *[引用自经典 Ehrhart 理论]*

*动机 / 作用（中文）*: 把内部格点数与 $h^*$-系数互为反向读取，是 Corollary 5.2 与 Proposition 5.3 中"内部 Ehrhart 级数非对数凹"的直接工具。
*证明思路（中文）*: 由 $k\geq1$ 时纤维的严格不等式给出内部计数式 $|E_{\mathcal C(A)}(-k)|=\sum_{b_0+\cdots+b_d=k,b_j\geq1}\prod_i(\sum_ja_{ij}b_j-1)$，再与 $h^*$ 的生成函数对照即得。

> **引理（Newton 系数与 $c_i(A)$，式 (3.1)–(3.2)）**: $$F_A(u)=\sum_{|\nu|\le n}c_\nu(A)\binom{u}{\nu},\qquad c_i(A)=\sum_{|\nu|=i}c_\nu(A)\quad(0\le i\le n),$$ where $c_\nu(A)=\sum_{0\le\mu\le\nu}(-1)^{|\nu|-|\mu|}\binom{\nu}{\mu}F_A(\mu)$.

*动机 / 作用（中文）*: 把 $\prod_i(1+\sum_ja_{ij}u_j)$ 的乘法信息转成可按次数归并的整系数 $c_i(A)$，使 Theorem 3.3 的 $h^*$ 公式成为有限可算的表达式（前向差分给出了可编程的计算方式）。
*证明思路（中文）*: 直接用多元二项基的前向差分公式展开 $F_A$；再由 $E_{\mathcal C(A)}(k)$ 的组合恒等式按 $|\nu|$ 归并。

> **引理（系数抽取式，式 (4.1)）**: $$h_r^*=\sum_{k=0}^r(-1)^{r-k}\binom{41}{r-k}E_P(k).$$ — *[新证]*

*动机 / 作用（中文）*: 把所有反例的验证归结为"先算少数几个 $E_P(k)$，再做一次有限交错和"，从而每个反例都能给出整数的紧凑证书（形如 $100(h^*_{18}-h^*_{19})>h^*_{20}$）。
*证明思路（中文）*: 由 $h_P^*(z)=(1-z)^{41}\sum_{k\geq0}E_P(k)z^k$ 比较 $z^r$ 系数即得。

> **引理（Ehrhart 多项式的阶数估计，Section 4）**: $E_{P_s}(1)$ 是 $s$ 的三次多项式、首项系数 $8$；$\deg_sE_{P_s}(2)\le4$；$E_{P_s}(3)$ 的次数为 $6$、首项系数 $1$。 — *[新证]*

*动机 / 作用（中文）*: 这是非对数凹性论证的"无穷族"部分：只需阶数信息就能断定 $E_{P_s}(1)E_{P_s}(3)-E_{P_s}(2)^2=8s^9+O(s^8)$ 最终为正，而不必逐个 $s$ 验证。
*证明思路（中文）*: 数各次膨胀中非零乘积项的数量与阶：$k=1$ 时 $(1,0,0,0)$ 贡献 $8(s+2)^3$、其余三个组合各贡献 $16(s+2)^2$；$k=2$ 时六个系数中至多四个非零；$k=3$ 时只有 $(0,1,1,1)$ 让六个系数全非零，贡献 $(s+4)^6$。

### 3.2.  关键定义

> **Definition（单峰性）**: Recall that a polynomial $h(z) = h_0 + h_1z + \cdots + h_sz^s$ is said to be \emph{unimodal} if $h_0 \leq \cdots \leq h_{j-1}\leq h_j \geq h_{j+1} \geq \cdots \geq h_s$ for some index $j$.
> **直观动机与作用**: 这是全文要反驳的核心性质；注意它只要求"先增后减"存在一个峰，因此反例只需构造出 $h^*_{i-1}>h^*_i<h^*_{i+1}$ 这样一处"谷"即可。

> **Definition（对数凹性）**: Recall that a polynomial $h(z) = h_0 + h_1z+\cdots+h_sz^s$ with nonnegative coefficients is said to be \emph{log-concave} if $h_i^2\geq h_{i-1}h_{i+1}$ for each index $0< i < s$; if the sequence $(h_0,\ldots,h_s)$ has no internal zeros, then log-concavity is in fact stronger than unimodality.
> **直观动机与作用**: 它是比单峰性更强的性质（无内部零点时蕴含单峰），因此推翻更强的对数凹性猜想（Brenti、Ferroni–Higashitani）在逻辑上更困难；本文同时给出两类反例，用 $h_1^*h_3^*-(h_2^*)^2>0$ 与 $|E(-5)E(-7)|-|E(-6)|^2>0$ 这类整数证书验证。

> **Definition（IDP 与 very ample）**: A lattice polytope $P$ is said to have the \emph{integer decomposition property} (IDP) if for every positive integer $k$, each lattice point $p\in kP\cap\mathbb{Z}^n$ can be written as a sum $p = p_1+\cdots+p_k$ where $p_1,\ldots,p_k\in P\cap \mathbb{Z}^n$. If this holds instead only for sufficiently large $k$, the polytope $P$ is said to be \emph{very ample}.
> **直观动机与作用**: IDP 正是 Stanley 猜想所需的假设（等价于 Ehrhart 环标准分次），而 very ample 是更弱的版本；本文的反例属于 IDP，其内涵是"即使满足很强的代数条件也挡不住非单峰"。

> **Definition（Cayley 和）**: Recall that the \emph{Cayley sum} of a collection of polytopes $P_0,\ldots, P_d\subseteq \mathbb{R}^n$ is the convex hull of $(P_0\times \{(0,\ldots,0)\})\cup (P_1\times \{e_1\}) \cup\cdots\cup (P_d\times \{e_d\})$ in $\mathbb{R}^{n+d}$, where each $e_j$ stands for the $j$-th canonical vector in $\mathbb{R}^d$.
> **直观动机与作用**: 这是全文唯一的构造手段：把矩形棱柱按单形顶点分层叠放，使多胞体自动继承基单形的良好三角剖分，同时纤维长度随重心坐标线性变化，从而获得可控的 Ehrhart 计数与 $h^*$ 系数。

> **Definition（光滑、余次数与 Gorenstein 指数）**: A full-dimensional lattice polytope is \emph{smooth} if it is simple and the primitive edge directions at every vertex form a lattice basis. Recall that the \emph{codegree} of a lattice polytope is the smallest positive integer $k$ for which $kP$ contains an interior lattice point. A polytope is \emph{Gorenstein of index $k$} if a lattice translate of $kP$ is reflexive.
> **直观动机与作用**: 光滑性用于说明反例出现在几何条件最优的类中；余次数（本文中等于 $d+1$）与 Gorenstein 指数决定了内部 Ehrhart 级数反例中"从第几次膨胀开始非零"，也是 Corollary 5.2 与 Question 5.12(a) 无法被解决的技术原因。

> **Definition（Nakajima 多胞体与 integral chimney）**: Following \cite{haase-paffenholz-piechnik-santos}, an \emph{integral chimney} over a lattice polytope $P$ is $$\operatorname{Chim}(P,0,f)=\{(z,t):z\in P,\ 0\le t\le f(z)\},$$ where $f$ is an integral affine function nonnegative on $P$.
> **直观动机与作用**: 把"逐坐标堆叠棱柱"的过程解释为逐次取 integral chimney，从而直接引用 Haase–Paffenholz–Piechnik–Santos 的定理把 $P$ 的正规单模旗三角剖分传递到 $\mathcal C(A)$；这也解释了 $\mathcal C(A)$ 的 Nakajima 多胞体身份。

## 4.  理解辅助

- **贯穿例子 1（非单峰反例）**：取 $d=n=20$、$(\alpha,\beta)=(50,800)$，$A_{50,800}=[\,50\mathbf 1_{20}\mid 800I_{20}\,]$，$P=\mathcal C(A_{50,800})$ 是 40 维 IDP（乃至）多胞体；其 $h^*$ 的三个系数满足 $h^*_{18}>h^*_{19}<h^*_{20}$，其中 $h^*_{20}=849^{20}$（$849=50+800-1$ 型常数），$h^*_{19}=899^{20}-1829\cdot849^{19}$，$h^*_{18}=949^{20}-2879\cdot899^{19}+1\,288\,210\cdot849^{18}$。光滑版本 $P_{100}=\mathcal C(A_{5000,80000}+J)$ 用同样三个指标给出"先降后升"。
- **贯穿例子 2（非对数凹 Ehrhart 级数）**：$6\times4$ 的 $B_{s,s}+J$（$s=1000$）给出 $E(1)=8\,096\,288\,256$、$E(2)=82\,112\,599\,942\,290$、$E(3)=1\,074\,277\,139\,082\,321\,920$，破坏 $E(1)E(3)\geq E(2)^2$；其无穷族版本由 $8s^9+O(s^8)>0$ 保证。
- **贯穿例子 3（Gorenstein 与内部级数）**：$R_{12}$（75 维、指数 4）给出 $h_1^*h_3^*-(h_2^*)^2>0$，同一多胞体经 Ehrhart 互反给出 $|E_R(-5)E_R(-7)|-|E_R(-6)|^2>0$；光滑版本 $S=\mathcal C(1000A_{30}+J)$（183 维）通过 4、10、20 项整数和验证 $|E_S(-6)|^2<|E_S(-5)||E_S(-7)|$。

### 5.2.  可以尝试的方向

- [ ] 能否把非单峰反例的参数从 $d=n=20$ 降到更小的维数？即 $\mathcal C(A_{\alpha,\beta})$ 中使 $h^*$ 非单峰的最小 $(d,\alpha,\beta)$ 是多少？
- [ ] 该类多胞体（Nakajima / 矩形棱柱 Cayley 和）中 Gal 猜想的类比（$\gamma$-正性）是否真的成立？作者预告将证明此类中无 $\gamma$-正性反例；这个证明能否推广到更大的多胞体类（例如所有有正规单模旗三角剖分的多胞体）？若能，则说明"旗性 + 单模性"恰是 $\gamma$-正性的充分条件。

- [ ] 本文的构造本质是"纤维长度线性变化"；若把矩形棱柱换成一般格多胞体（要求仍为 Nakajima 多胞体），能否得到更丰富的 $h^*$ 形状，从而测试更多猜想？

### 5.3.  批判性思考

- 反例的验证依赖精确的大整数计算（如 $949^{20}$ 量级）与若干"紧凑证书"不等式；这些证书虽然自包含，但**论文没有给出这些整数的可验证脚本或形式化证明**（仅在 Proposition 5.3 处提到"随论文提供的验证脚本"）。从可复现性角度，读者需要自行实现 $E_P(k)$ 的求和与系数抽取，工作量不小；若这些计算有一处符号或指数错误，整篇的反例链条将失效。
- 论文自述大量使用 Codex 与 ChatGPT（超过五十条 prompt、历时一个月），并承认"研究方向的转折点来自向 ChatGPT 询问 Nakajima 多胞体"。这不影响数学结论的有效性，但提示读者：核心构造类（矩形棱柱 Cayley 和 / Nakajima 多胞体）的选择强烈依赖工具搜索，人类可读的"为什么是这个类"的动机在文中较弱。
- 从"反驳猜想"的角度看，本文的例子都集中在同一构造族内，这既使证明经济，也带来一个隐患：所有反例可能共享某个未被察觉的退化特征（例如 $h^*$ 的"谷"总出现在系数序列末端 $18,19,20$ 处，且与 $A$ 的常数列 $50\mathbf 1_d$ 引起的线性项有关）。作者没有讨论"末尾谷"是否为该族的普遍现象。
- 作者把"Gorenstein 单峰性定理不能被加强为对数凹性"作为"最优可能"的论据，但严格说这只能说明该定理的**假设**不能弱化（不能去掉 Gorenstein 性）以及**结论**不能加强（不能升级为对数凹），而不能说明该定理在其陈述范围内不可改进（例如能否给出单峰的定量界、能否刻画峰的位置）。这一措辞值得保留态度。
- 关于正性/单峰性的"旗性限制"：文中提到旗性对 $h^*$ 的形状有很强的限制（引用 Ferroni–Higashitani [Theorem 3.14]），而反例却是旗的；这表明"旗性 + 单模性"的限制不足以强制单峰，但文中并未量化该限制究竟还剩多少（例如是否仍决定峰的个数、是否限制谷的深度），这是可以追问的方向。
