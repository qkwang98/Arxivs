# A General Approach to Enharmonicism

keywords: [等音体系, 句法音乐理论, 音阶理论, 反射性质, 最大均匀性]
related_paper: "Hook, Enharmonic Systems: A Theory of Key Signatures, Enharmonic Equivalence and Diatonicism"
one_liner_summary: 该文在完全不涉及声学考量的句法层面建立一般化的等音体系理论，并论证反射性质（RP）与最大均匀性（ME）是判断任意等音体系是否具有音乐实用性的两条基本判据，从而从纯数学视角解释了标准等音体系（SES）的优越性。

## 1.  核心定位

- **解决的问题**：在句法音乐理论（syntactic music theory）框架内，为等音现象（enharmonicism）建立不依赖任何声学考量的一般化抽象结构，并回答"为什么标准等音体系在数学上也值得偏爱"。
- **大图景位置**：推广了 Hook 基于 7 个标准音级的等音理论，将构造起点从固定 7 音级推广到任意音级基数；同时以纯句法视角补充了历史上以声学为主导的等音研究传统。
- **主要贡献**：(1) 从任意基数音级出发，形式化音阶理论（diatonic theory）、半音理论（chromatic theory）与等音理论（enharmonic theory）的完整抽象框架；(2) 提出反射性质（RP）与最大均匀性（ME）两条判据，定义 RP-ME 等音体系；(3) 证明标准等音体系 SES 是唯一的 RP-ME 体系，为 SES 的优先地位给出脱离音高考量的数学动机。
- **关键先驱工作**：Hook 的等音体系理论（Enharmonic Systems）；Clough 与 Douthett 的最大均匀性（maximal evenness）与 ME 集合；Lewin 的广义音程系统（Generalized Interval System）；Mandelbaum 对 19 音等音体系的独立一致性论证。
- **结果边界**：全部结论建立在纯句法层面，不预设平均律，因此不保证可移调性（transposability），也不处理音高、音分或调律方面的内容；键盘图示不预设任何音高顺序。
- **开放问题**：如何高效判定一个等音体系是否为 RP-ME；RP-ME 体系在多大程度上唯一；给定音级集合时是否存在保证所得体系为 RP-ME 的 n 元组公式，若不存在能否证明；固定音级集合下生成多个 RP-ME 体系时，此类 n 元组集合的结构与性质。
- **应用与推广**：为作曲家提供在非标准等音体系中进行音乐实验的一致语法，有助于标准化非标准等音体系内和声观念的传达；未来可推广形式化调号（key signature）、调式、和弦、三和弦、和弦进行、负和声（negative harmony）与和弦替代等概念。

## 2.  主要定理

> **全局假定 / 背景**: 全文在句法层面工作：音阶集合 $D=\{d_0,\dots,d_{n-1}\}$ 的指标取 $\mathbb{Z}_n$，半音为音级与修饰符的乘积 $D^\ast=D\times\mathbb{M}$，等音为半音集合上某个等价关系的等价类；不涉及任何声学或音高考虑，不预设平均律。

> **Definition (Diatonic Set)**: A finite set $D=\{d_0,\dots,d_{n-1}\}$ with indices in $\mathbb{Z}_n$ is called a *diatonic set*, the elements of a diatonic set are called *diatonics* (or *diatones*), and the number $n$ of diatonics is called the *diatonic cardinality*.

> **Definition (Diatonic Transposition)**: Let $D$ be a diatonic set and $x\in\mathbb{Z}$; a function $t_x:D\to D$ defined by the equation $t_x(d_i)=d_{i+x}$ is called the *diatonic transposition* by $x$. If the diatonic cardinality of $D$ is $n$, then the index $i+x$ of the diatonic $d_{i+x}\in D$ is understood to be $i+x\pmod{n}$.

> **Definition (Prime Diatonic Ordering)**: Let $D=\{d_0,\dots,d_{n-1}\}$ be a diatonic set with $n>1$. Given an interval length $p$, such that $p-1$ is coprime with $n$, let $\delta_p:D\to D$ be a function defined by the equation $\delta_p(d_x)=d_{(p-1)x}$. Elements in the range of $\delta_p$ are denoted $d_i'$, where $d_i'=\delta_p(d_i)$, and are called *prime diatonics*. An ordering $d_0',d_1',\dots,d_{n-1}'$ of $D$ is called a *prime diatonic ordering* (*PDO*), and if $p$ is known, we call the resulting PDO a *diatonic circle of $p$ths*.

> **Definition (Diatonic Space / Rotation)**: A *diatonic space* $\mathfrak{d}_{p,\alpha}^D$ is a diatonic set $D$ ordered by a circle of $p$ths and equipped with a diatonic transposition $t_\alpha$. A diatonic space $\mathfrak{d}_{p,\alpha}^D$ is a *rotation* of a diatonic space $\mathfrak{d}_{q,\beta}^{D'}$ if and only if $D=D'$ and $p=q$; the diatonic space $\mathfrak{d}_{p,\alpha}^D$ is the *trivial rotation* of $\mathfrak{d}_{p,\alpha}^D$. A set containing a diatonic space $\mathfrak{d}_{p,\alpha}^D$ and all of its rotations is called a *rotation class*, denoted $\mathfrak{d}_p^D$.

> **Definition (Diatonic System)**: The *diatonic system* of a diatonic set $D=\{d_0,\dots,d_{n-1}\}$ is the collection of rotation classes $\mathfrak{d}^D=\{\mathfrak{d}_p^D\,|\,\gcd{(p-1,n)}=1\}$.

> **Definition (Diatonic Reflection / Reflection Property)**: Let $\mathfrak{d}^D$ be a diatonic system of a diatonic set $D$, where $|D|=n$. A rotation class $\mathfrak{d}_p^D\in\mathfrak{d}^D$ is a *diatonic reflection* of a rotation class $\mathfrak{d}_q^D\in\mathfrak{d}^D$ if and only if $p+q-2=n$; that is, if $p-1$ and $q-1$ are additive inverses in $\mathbb{Z}_n$. A diatonic system $\mathfrak{d}^D$ is said to have the *reflection property* (*RP*) if and only if $\mathfrak{d}_p^D$ is reflectable for all $\mathfrak{d}_p^D\in\mathfrak{d}^D$.

> **Definition (Chromatic Set / Modifier)**: The symbols $\flat$ (*flat*), $\natural$ (*natural*), and $\sharp$ (*sharp*) are called *modifiers*; the set $\mathbb{M}=\{\dots$, $\flat\flat\flat$, $\flat\flat$, $\flat$, $\natural$, $\sharp$, $\sharp\sharp$, $\sharp\sharp\sharp$, $\dots\}$ is called the *modifier set*. The *chromatic set* corresponding to a diatonic set $D$ is the set $D^\ast=D\times\mathbb{M}$ of elements called *chromatics*.

> **Definition (Enharmonic Assignment)**: Let $E=(e_0,\dots,e_{n-1})$ be an $n$-tuple of positive integers, where the indices $i$ of each $e_i$ are the elements of $\mathbb{Z}_n$. The function $A_E:\mathbb{Z}_{n}\to\mathbb{Z}$ defined by the equation $A_E(x)=\begin{cases} 0 & \textrm{if }x=0 \\ \sum_{i\,=\,0}^{x-1}e_i & \textrm{if }x\ne 0 \end{cases},\qquad e_i\in E\textrm{ for each }i=0,\dots,n-1,$ is called the *enharmonic assignment* of $E$; the *weight* of an enharmonic assignment $A_E$ is the sum of the elements of $E$.

> **Definition (Enharmonic Equivalence Relation)**: Let $D=\{d_0,\dots,d_{n-1}\}$ be a diatonic set and $D^\ast$ be its corresponding chromatic set; let $E$ be an $n$-tuple of positive integers and $A_E$ be the enharmonic assignment of $E$ of weight $N$. Let $\approx_E$ be the relation defined on $D^\ast$ by $(d_i)^x\approx_E(d_j)^y$ if and only if $x+A_E(i)\equiv y+A_E(j)\pmod{N}$. The relation $\approx_E$ is called the *enharmonic equivalence relation* of $E$, and if $(d_i)^x\approx_E(d_j)^y$, we call $(d_i)^x$ and $(d_j)^y$ *enharmonically equivalent* by $E$.

> **Definition (Enharmonic Set)**: A diatonic set $\mathcal{P}_E=\{\pi_0,\dots,\pi_{N-1}\}$ is called *enharmonic* if and only if there exists a diatonic set $D$ such that the diatones $\pi_i\in\mathcal{P}_E$ are the equivalence classes generated by an enharmonic equivalence relation $\approx_E$ on $D^\ast$. The elements of an enharmonic set $\mathcal{P}_E$ are called *enharmonics*, and the diatonic cardinality of $\mathcal{P}_E$ is called the *enharmonic cardinality*.

### 2.1.  证明思路

- 第一步：先建立音阶理论，将音级集合、移调、素数音级序（PDO）、音阶空间与音阶系统全部编码为 $\mathbb{Z}_n$ 及其单位群 $U(\mathbb{Z}_n)$ 上的结构。
- 第二步：引入修饰符集合 $\mathbb{M}\cong\mathbb{Z}$，把半音集合 $D^\ast=D\times\mathbb{M}$ 上的等音等价关系定义为模权重 $N$ 的同余条件 $x+A_E(i)\equiv y+A_E(j)\pmod{N}$。
- 第三步：以等价类定义等音集合与等音系统，再引入 RP 与 ME 两条性质，最终证明在文中构造的三个体系中仅 SES 同时满足两者。

## 3.  关键组件

### 3.1.  关键引理

> **Lemma (Diatonic Sets are Trivially Enharmonic)**: Every diatonic set is enharmonic by trivial enharmonic equivalence. — *[直接由定义推出]*

*动机 / 作用（中文）*: 平凡等音等价（取 $E=(1,\dots,1)$）使每个音级集合都自动成为等音集合，说明只有非平凡的等音等价关系才使等音主义（enharmonicism）具有实质内容。
*证明思路（中文）*: 当所有 $e_i=1$ 时权重 $N=n$，且 $A_E(i)=i$，等价条件化为 $x+i\equiv y+j\pmod{n}$，每个等价类恰含一个自然半音，故等价类构成的集合与 $D$ 同构。

> **Lemma (Identifying pths)**: A $p$th in $D$ is perfect in $\mathcal{P}_E$ if and only if $A_E(p-1)\ne N-1$ and $A_E(p-1)$ is coprime with $N$. If a $p$th in $D$ is not perfect in $\mathcal{P}_E$, then it is major in $\mathcal{P}_E$ except for perfect unison. — *[直接由定义推出]*

*动机 / 作用（中文）*: 给出快速判定某度音程在等音集合中为纯（perfect）还是大（major）的判据，例如由此可知标准等音集合 $\mathfrak{p}$ 中仅四度与五度为纯音程。
*证明思路（中文）*: 由纯音程定义要求其半音长度 $c=A_E(p-1)$ 落在 $A_E$ 的值域、非平凡地与 $N$ 互素且不等于 $N-1$；不满足纯条件且非纯一度者按定义即归为大音程。

> **Lemma (Not All PDOs are PEOs)**: All PEOs are PDOs, but not all PDOs are PEOs. — *[直接由定义推出]*

*动机 / 作用（中文）*: 说明等音层面可生成循环序的度数值集合是音阶层面可生成循环序的度数值集合的真子集，体现了等音结构对音阶结构的约束。
*证明思路（中文）*: PDO 允许 $p-1=n-1$，而 PEO 因纯音程要求排除了 $A_E(p-1)=N-1$ 的情形，故生成 PEO 的整数 $p$ 集合严格包含于生成 PDO 的集合。

> **Lemma (Spectrums Unique)**: The spectrum of a diatonic is unique and $|\langle d_i\rangle|=e_i$ for all $i\in\mathbb{Z}_n$. — *[由前述定义推出]*

*动机 / 作用（中文）*: 谱（spectrum）的大小由元组 $E$ 的分量 $e_i$ 决定，这是形式化最大均匀性（ME）的度量基础。
*证明思路（中文）*: 谱定义为 $\langle d_i\rangle=\{\tau_x(\pi_{A_E(i)})\,|\,x=0,\dots,e_i-1\}$，其元素按半音步连续排布，基数恰为 $e_i$，唯一性由等音指标的模 $N$ 同余条件保证。

### 3.2.  关键定义

> **Definition (Enharmonic Interval)**: Let $\mathcal{P}_E$ be an enharmonic set, $c$ be a nonnegative integer, and $\pi_\ell\in\mathcal{P}_E$ be $c$ chromatic steps above $\pi_k\in\mathcal{P}_E$. A diatonic interval $[\pi_k,\pi_\ell]_{\mathcal{P}_E}$ in $\mathcal{P}_E$ is called an *enharmonic interval*; the *chromatic length* of $[\pi_k,\pi_\ell]_{\mathcal{P}_E}$ is $c$. Suppose $c$ is in the range of $A_E$. We call the interval $[\pi_k,\pi_\ell]_{\mathcal{P}_E}$ *perfect* if and only if $c\ne N-1$ is coprime with $N$; for all other $c\ne 0$, we call the interval *major*, and for the special case $c=0$, we call the interval $[\pi_k,\pi_k]_{\mathcal{P}_E}$ a *perfect unison* of trivial length $0$.
> **直观动机与作用**: 将音阶层面的度（$p$th）与半音层面的长度（chromatic length）挂钩，从而把纯/大/小/增/减等传统音程分类提升到任意等音体系；纯音程要求半音长度与 $N$ 互素（$N-1$ 视为平凡互素情形单独排除）。

> **Definition (Prime Enharmonic Ordering)**: Given an enharmonic set $\mathcal{P}_E=\{\pi_0,\dots,\pi_{N-1}\}$ with $N>1$ and an integer $p$ such that a $p$th is perfect in $\mathcal{P}_E$, let $\eta_p:\mathcal{P}_E\to\mathcal{P}_E$ be a function defined by the equation $\eta_p(\pi_x)=\pi_{A_E(p-1)x}$. Elements in the range of $\eta_p$ are denoted $\pi_i'$, where $\pi_i'=\eta_p(\pi_i)$, and are called *prime enharmonics*. An ordering $\pi_0',\pi_1',\dots,\pi_{N-1}'$ of $\mathcal{P}_E$ is called a *prime enharmonic ordering* (*PEO*), and if $p$ is known, we call the resulting PEO an *enharmonic circle of perfect $p$ths*.
> **直观动机与作用**: 类比音阶层面的 PDO 构造等音层面的纯音程循环序；由于 $A_E(p-1)$ 与 $N$ 互素，$\eta_p$ 是双射，从而任意有效的 $p$ 都产生完整的等音循环序（如标准 PEO 为五度圈 C, G, D, A, E, B, F♯/G♭, C♯/D♭, G♯/A♭, D♯/E♭, A♯/B♭, F）。

> **Definition (Enharmonic System)**: The diatonic system of an enharmonic set $\mathcal{P}_E=\{\pi_0,\dots,\pi_{N-1}\}$ is called an *enharmonic system*, denoted $\mathfrak{e}^{\mathcal{P}_E}=\{\mathfrak{e}_{p}^{\mathcal{P}_E}\,|\,A_E(p-1)\ne N-1,\,\gcd{(A_E(p-1),N)}=1\}$.
> **直观动机与作用**: 等音系统的旋转类仅由纯音程度数构成；标准等音系统 SES 因标准等音集合 $\mathfrak{p}$ 中只有四度与五度为纯音程，恰含两个旋转类 $\mathfrak{e}^\mathfrak{p}=\{\mathfrak{e}_4^\mathfrak{p},\mathfrak{e}_5^\mathfrak{p}\}$，且两者互为反射，故 SES 具有 RP。

> **Definition (Practical Chromatic)**: Given an enharmonic set $\mathcal{P}_E$ generated by an enharmonic equivalence relation $\approx_E$ on a chromatic set $D^\ast$, let $(d_i)^m\in D^\ast$. The chromatic $(d_i)^m$ is *practical* for $\mathcal{P}_E$ if and only if $-e_{i-1}\le m\le e_i$, where $e_{i-1}$ and $e_i$ are elements of $E$; otherwise, $(d_i)^m$ is *impractical*.
> **直观动机与作用**: 尽管每个等音集合都包含可数无穷多个半音，实际记谱与演奏只使用极小的子集；该定义给出"实用半音"的严格界限（由相邻两个 $e_i$ 分量约束修饰符范围），避免在陌生非标准体系中任意取舍半音。

> **Definition (Maximally Even)**: Let $\mathcal{P}_E$ be an enharmonic set and denote the smallest element of $E$ by $e_{\textrm{min}}$. Then $\mathcal{P}_E$ is *maximally even* if and only if $e_{\textrm{min}}\le|\langle d_i\rangle|\le e_{\textrm{min}}+1$ for all spectra $\langle d_i\rangle$ of $\mathcal{P}_E$. An enharmonic system $\mathfrak{e}^{\mathcal{P}_E}$ is said to be *maximally even* (*ME*) if and only if $\mathcal{P}_E$ is maximally even.
> **直观动机与作用**: 推广 Clough 与 Douthett 的 ME 集合定义（原定义要求每个谱的大小在 1 与 2 之间，仅适用于标准体系）；推广后的定义允许任意等音集合的谱大小至多相差 1，从而可判定非标准体系的"均匀性"。

## 4.  理解辅助

- **贯穿例子**：标准钢琴键盘——12 个琴键（7 白 5 黑）对应标准等音集合 $\mathfrak{p}$；元组 $\mathcal{E}=(2,2,1,2,2,2,1)$ 编码白色琴键之间插入黑键的指令（$e_i-1$ 个黑键），其元素和 $12$ 即总琴键数；键盘按模 $12$ 循环。
- **非标准例子一**：$\mathcal{E}'=(3,3,2,3,3,3,2)$ 生成 19 等音体系 $\mathfrak{p}_{19}$（对应历史与当代微音音乐中的 19-TET），其等音系统含 6 个旋转类、非 RP 但 ME，其中四度类与五度类互为反射。
- **非标准例子二**：$D_5=\{H,I,J,K,L\}$ 与 $E=(3,1,2,4,1)$ 生成 11 等音体系 $\mathcal{P}_E$，其等音系统既非 RP 也不含任何可反射旋转类，且不 ME——作为"音乐上不实用"体系的对照样本。
