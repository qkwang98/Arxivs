# A New Sparse Algorithm for Polynomial GCD over Integers

keywords: [稀疏多元多项式, 整数系数多项式, 最大公因式, 分离变量替换, 位复杂度]
related_paper: "Sparse Polynomial GCD Algorithms Asymptotically Linear in All Fundamental Parameters（arXiv:2609.08074）"
one_liner_summary: "本文提出一种新的整数系数多元稀疏多项式最大公因式随机化算法：通过随机 Kronecker 型替换 $x_i\\to p_iy^{s_i}$ 把多元 GCD 归约为单个一元 GCD，并用小素数模像与系数分解还原结果，首次给出稀疏表示下的显式位复杂度 $O^\\sim(n^2d^2T_{\\rm out}^2\\log^2(1/\\varepsilon)\\log C+n^2dT_{\\rm in}\\log^2T_{\\rm out}\\log^2(1/\\varepsilon)\\log C)$。"

## 1.  核心定位

- **解决的问题**：整数系数多元稀疏多项式最大公因式（GCD）的计算长期以来没有显式的位复杂度。已有工作要么只断言复杂度是变量数、次数与项数的多项式而不给出公式，要么只在附加条件下成立；本文给出一个随机化算法，其位复杂度同时显式依赖输入项数、输出项数与偏次数界，并敏感于稀疏表示。
- **大图景位置**：该工作处于"模方法 + 稀疏插值 + Kronecker 型替换"这条主线上，把多元 GCD 归约为单个一元 GCD。与 Kaltofen 1988 的稀疏多项式时间算法相比，本文在变量数 $n$ 与偏次数 $d$ 上的次数由 3 降为 2；与 Tang–Li–Zeng 2018 相比在 $T_{\rm in}$ 与 $T_{\rm out}$ 上更优；与 Hu–Monagan 2021 相比改用随机 Kronecker 替换且只用小素数，从而可以给出精确复杂度。
- **主要贡献**：其一，提出新的变量替换 $A(x_1y^{s_1},\dots,x_ny^{s_n})$，它把多元多项式化为关于新变量 $y$ 分离（separable）的多项式，使每个 $y$-系数都是单项式；其二，提出新的求值点（小素数）选取方式与随机化验证算法，使只需一个模像即可还原 GCD；其三，给出完整的位复杂度分析与 Maple 实现，实验表明在项数少的 GCD 上优于 Maple 默认算法。
- **关键先驱工作**：Collins 1967 的伪余式序列、Brown 1971 的模方法、Moses–Yun 1973 的 EZ-GCD、Wang 1980 的 EEZ-GCD、Zippel 1979 的稀疏模算法、Kaltofen 1988 与 Kaltofen–Trager 1990 的黑箱算法、Cuyt–Lee 2008 的截断幂级数方法、Tang–Li–Zeng 2018 与 Hu–Monagan 2021 的多元到一元归约。
- **结果边界**：对稠密输入（$T_{\rm in}$、$T_{\rm out}$ 达到 $O(d^n)$）本文复杂度不再占优；当 GCD 的项数 $T_{\rm out}$ 较大时，因归约后一元 GCD 的次数为 $O(DT^2)$，实际运行慢于 Maple 的 Zippel 路线；算法为 Monte Carlo 型随机算法，结果需经随机化验证步骤确认。
- **开放问题**：作者明确指出，下一步需要寻找对高次、大系数更有效的一元 GCD 算法（Hensel 提升在当前框架中成为瓶颈）；此外，如何把该归约框架推广到其它系数环或去随机化，文中均未给出答案。
- **应用与推广**：GCD 是符号积分、多项式因式分解、理想成员判定、纠错码与密码学攻击中的核心子程序；本文"分离替换 → 一次一元 GCD → 整系数分解还原"的三段式框架可迁移到稀疏结式计算、稀疏因式分解与多元稀疏插值等问题的复杂度分析。

## 2.  主要定理

> **全局假定 / 背景**: 设 $A,B\in\Z[x_1,\dots,x_n]$ 为非零多项式，$G=\gcd(A,B)$，$T_{\inp}=\#A+\#B$ 为输入项数、$T_{\out}=\#G$ 为输出项数，$D$ 为总次数界，$d=\max_{i=1}^n\max(\deg_{x_i}A,\deg_{x_i}B)$ 为偏次数界，系数满足 $\max\{\|A\|_\infty,\|B\|_\infty\}\le C$。文中 $\#$ 表示项数，$\LC$ 表示首系数，$\MoCont$ 与 $\MoPrim$ 分别表示单项式内容与单项式本原部分，$\res_y$ 表示关于 $y$ 的结式。算法是随机化的（假设以 $O(1)$ 位代价取得随机位），复杂度统一用 Soft-Oh 记号 $O^\sim(\phi)=O(\phi\cdot\mathbf{polylog}(\phi))$ 陈述。

> **Theorem（主结果，§1.1 Introduction）**: Let $A,B$ be polynomials  in $\Z[x_1,\dots,x_n]$ with partial degree bound $d=\max_{i=1}^n \max(\deg_{x_i}A,\deg_{x_i}B)$ and $0<\varepsilon<1$.
> Then there exists a randomized algorithm that takes as inputs $A,B$ and
> returns $G=\gcd(A,B)$ with probability $\geq 1-\varepsilon$, using expected $O^\sim(n^2d^2T_{\out}^2\log^2 \frac{1}{\varepsilon}\log C+n^2dT_{\inp}\log^2 T_{\out}\log^2\frac{1}{\varepsilon}\log C)$ bit operations, where $T_{\inp}=\#A+\#B,T_{\out}=\#G$ and $\max\{\|A\|_{\infty},\|B\|_{\infty}\}\leq C$.

### 2.1.  证明思路

- 第一步（问题拆分）：把 GCD 写成单项式内容与单项式本原部分之积 $G=\gcd(\MoCont(A),\MoCont(B))\cdot\gcd(\MoPrim(A),\MoPrim(B))$，前者只是单项式的指数与系数运算，于是问题化归为单项式本原多项式的 GCD（Algorithm alg-1 的前置假设）。
- 第二步（分离替换）：随机选取整向量 $\mathbf{s}$，用替换 $x_i\to x_iy^{s_i}$ 把多元问题压到 $\Z[y]$。由 Lemma the-5 该替换与取 GCD 可交换（至多相差 $y$ 的幂），由 Lemma the-1 以不小于 $8/9$ 的概率使代入后的 $G$ 关于 $y$ 分离，从而代入后每个系数都是单项式。
- 第三步（小素数求值与一元 GCD）：随机选取互异的素数 $\mathbf{p}=(p_1,\dots,p_n)$ 使之成为 good point（Lemma the-13 把该条件化归为 $L(\mathbf{p})\neq0$），再用小素数加 Hensel 提升的路线计算一元 GCD，得到 $G_{(\mathbf{s},y)}(\mathbf{p},y)$；Lemma the-2 保证该模像的内容为 1，故其本原部分与 $G_{(\mathbf{s},y)}(\mathbf{p},y)$ 的本原部分一致。
- 第四步（还原与验证）：对模像的整数系数逐一关于 $p_1,\dots,p_n$ 做试除分解，还原出各单项式的指数；再用随机化验证算法确认候选（Theorem the-15 给出"$H|A$、$H|B$ 且各偏次数一致"的判据），把失败概率压到 $\varepsilon$ 以下。
- 第五步（消去项数界）：Algorithm alg-4、alg-41 与 alg-5 通过把项数界 $T$ 由 $2$ 倍增到 $(d+1)^n$ 并反复调用 alg-1，消去"已知 $T_{\rm out}$ 上界"这一假设，最后对循环次数取期望即得主定理。

> **Theorem（the-7，Algorithm alg-1 的复杂度）**: The complexity of Algorithm \ref{alg-1} is $O^\sim(n^2T^2d^2\log C+n^2dT_{\inp}\log T\\ \log C)$ bit operations, where $T_{\inp}:=\#A+\#B$.

### 2.2.  证明思路

- 第一步（替换代价）：在给定项数界 $T$ 下执行替换并计算 $F_1:=A_{(\mathbf{s},y)}$、$F_2:=B_{(\mathbf{s},y)}$，代价为 $O^\sim(nT_{\rm in}(\log T+\log D)+T_{\rm in}\log C)$ 位运算。
- 第二步（素数表与分解代价）：找出前 $N$ 个素数并完成系数关于 $p_i$ 的试除分解，代价为 $O^\sim(N)$ 加 $O^\sim(nTd\log(e^{nd}CP^D))$，即 $O^\sim(n^2Td^2\log C)$。
- 第三步（一元 GCD 代价）：调用 Lemma lm-13 的界 $O^\sim(nSdD+SD^2\log P+SD\log C)$，代入 $S=\max s_i=O(T^2)$、$P=\max p_i=O^\sim(T^2D^2+n^2Td+n^2T\log C)$，并注意 $d\le D\le nd$，主项化为 $O^\sim(n^2T^2d^2\log C+n^2dT_{\rm in}\log T\log C)$。

> **Theorem（th-11，Algorithm alg-5 的期望复杂度）**: Let $A,B\in \Z[x_1,\dots,x_n]$ with partial degree bound $d$.
> Then Algorithm \ref{alg-5} computes the correct GCD $G=\gcd(A,B)$ using expected $O^\sim(n^2T_{\out}^2d^2$ $\log^2 \frac{1}{\varepsilon}\log C+n^2dT_{\inp}\log^2 T_{\out}\log^2\frac{1}{\varepsilon}\log C)$ bit operations where $T_{\inp}=\#A+\#B$ and $T_{\out}=\#G$.

### 2.3.  证明思路

- 第一步（倍增猜测）：alg-5 依次取 $T=2,2^2,\dots,2^L$（不超过 $(d+1)^n$）调用 alg-1，并对每个输出调用验证算法 alg-4；第 $r$ 次调用时 $T\ge2^r>2T_{\rm out}$（或 $2^r\ge(d+1)^n$）即停止并输出。
- 第二步（错误率分摊）：把整体容差拆开——单次 alg-1 以 $\ge3/4$ 正确，故在同一 $T$ 下重复 $m$ 次可使其失败概率小于 $\varepsilon'/(2\kappa L)$；同时把 alg-4 的容差取为 $\eta=\varepsilon'/(2\kappa m L)$，令事件 A1（全部验证步骤正确）与 A2（第 $L$ 次层级的至少一次输出正确）各以 $\ge1-\varepsilon'/2$ 成立。
- 第三步（正确性与期望）：由 $P(\mathrm{A1}\cap\mathrm{A2})\ge(1-\varepsilon'/2)^2\ge1-\varepsilon$ 得算法以 $1-\varepsilon$ 返回正确 GCD；期望代价按循环停止时间的几何分布求和，$\sum_\ell P(\mathrm{E}_\ell)(2^\ell)^\Lambda$ 收敛到 $T_{\rm out}^\Lambda$ 量级，代入 $\Lambda=2$ 与各项代价即得所示界。

## 3.  关键组件

### 3.1.  关键引理

> **Lemma（the-5）**: Let $A,B\in \Z[x_1,\dots,x_n]$, $G=\gcd(A,B)$, and $\mathbf{s}=(s_1,\dots,s_n)\in \N^n$.
> Then $\gcd(A_{(\mathbf{s},y)},B_{(\mathbf{s},y)})= G_{(\mathbf{s},y)}$.

**动机与作用（中文）**：这是全文合法性的基石。它保证"先做替换 $x_i\to x_iy^{s_i}$ 再取一元 GCD"与"先取多元 GCD 再做替换"彼此一致（最多差 $y$ 的一个幂），所以在一元框架中算出的结果可以无损地翻译回原问题。
**证明思路（中文）**：先证 $\gcd(A(y^\mathbf{s}\X),B(y^\mathbf{s}\X))\sim y^mG(y^\mathbf{s}\X)$，其关键是分别用 $P|A(y^\mathbf{s}\X)$ 与 $P|B(y^\mathbf{s}\X)$ 回代 $x_i/y^{s_i}$、并比较 $y$ 的最低次幂；再按 Eq. (1) 的定义除掉 $y$ 的最低次项（$d_G\le\min\{d_A,d_B\}$），最后利用 $\Z$ 的单位只有 $\pm1$ 与首系数一致完成单位规范化，两个方向的整除关系即给出等式。

> **Lemma（the-1）**: Assume $f\in \Z[x_1,\dots,x_n]$ and $T\geq \#f$. If $\mathbf{s}=(s_1,\dots,s_n)\in\N^n$ is chosen randomly from $[0,\frac92T(T-1)]^n$, then with probability $\geq 8/9$, $f(x_1y^{s_1},\dots,x_ny^{s_n})$ is separated w.r.t. $y$.

**动机与作用（中文）**：它说明"分离"这一目标形态可以用极廉价的随机化换取：只要 $\mathbf{s}$ 从 $[0,\frac92T(T-1)]$ 内独立均匀选取，代入后各单项式的 $y$-指数 $\sum_i s_ie_{j,i}$ 互不相同就是高概率事件，于是每个 $y$-系数恰为单项式。
**证明思路（中文）**：构造多项式 $P(s_1,\dots,s_n)=\prod_{i<j}(S_i-S_j)$，其总次数为 $\frac12t(t-1)\le\frac12T(T-1)$；"存在两个 $y$-指数相同"恰是 $P(\mathbf{s})=0$，于是对取值区间 $[0,\frac92T(T-1)]$ 应用 Schwartz–Zippel 引理（Lemma lm-6），得失败概率不超过 $\frac{\frac12T(T-1)}{\frac92T(T-1)}=\frac19$。

> **Lemma（the-13）**: Let $F_1,F_2\in \Z[x_1,\dots,x_n,y]$ be non-zero and $\mathbf{p}=(p_1,\dots,p_n)\in \Z^n$. Let $$R=\res_y(F_1/\gcd(F_1,F_2),F_2/\gcd(F_1,F_2)).$$ Let $L=R\cdot \LC_y(F_1)\cdot \LC_y(F_2)$. Then
> $\mathbf{p}$ is a good point for $F_1,F_2$ if and only if $L(\mathbf{p})\neq 0$.

**动机与作用（中文）**：它把"代入点是否保持 GCD 次数"这一定性条件等价地化归为单个多项式 $L$ 的非零判定，使坏点可以被 Schwartz–Zippel 型计数直接估计，从而算法只需随机选点即可以高概率取到好点。
**证明思路（中文）**：充分性方向，由 Sylvester 判据知两个余因子互素时 $R\neq0$，再由 $\LC_y(F_1)(\mathbf{p})\neq0$ 得余因子的首系数也不为零，配合 Lemma lm-2 的第 (2) 条推出 $\deg_y\gcd(F_1(\mathbf{p},y),F_2(\mathbf{p},y))=\deg_y C(\mathbf{p},y)$；必要性方向，由 good point 定义知代入后余因子的 GCD 为常数，再用 Lemma lm-2 把"GCD 次数为 0"翻译回"结式非零"，一并得到 $L(\mathbf{p})\neq0$。

> **Lemma（lm-9）**: Let $A,B\in \Z[x_1,\dots,x_n]$, $\mathbf{p} =(p_1,\dots,p_n)\in\N^n$ and $P=\max\{p_1,\dots,p_n\}$. Let $\mathbf{s}=(s_1,\dots,s_n)\in\N^n$ and $S=\max\{s_1,\dots,s_n\}$. Let $D= \max(\deg A,\deg B)$ and $d=\max_{i=1}^n \max(\deg_{x_i}A,\deg_{x_i}B)$. Let $C=\max \{\|A\|_{\infty},\|B\|_{\infty}\}$. Let $R=\res_{y}(H_1/\gcd(H_1,H_2),H_2/\gcd(H_1,H_2))$.  Let $N\geq 16(SD\ln(SD+1)+SD(2SD+2)+n(2SD+2)\ln(d+1)+D(2SD+2)\ln P+(2SD+2)\ln C)$. If we randomly choose a prime $p$ in $(N,2N]$, then $p\nmid R\cdot \LC(H_1)\cdot \LC(H_2)$ with probability $\geq \frac{7}{8}$.

**动机与作用（中文）**：它为 Hensel 提升所需的"好素数"给出定量阈值：素数只需达到 $\Theta(SD\log(SD)+\cdots)$ 的量级，就能以不小于 $7/8$ 的概率同时不整除两个首系数与余因子结式，从而保证模像 GCD 的次数与真 GCD 一致。
**证明思路（中文）**：先用 Lemma lm-1 与 lm-5 界定 $\kappa=|R|\cdot|\LC(H_1)|\cdot|\LC(H_2)|\le(SD+1)^{SD}[e^{SD}(d+1)^nP^DC]^{2SD+2}$；再由 Lemma lm-3 知区间 $(N,2N]$ 内素数不少于 $\frac12N/\ln N$，从而坏素数比例不超过 $2\ln\kappa/N$；把 $N$ 的下界代入即得概率不小于 $7/8$。

### 3.2.  关键定义

> **Definition（def-0，UFD 上的 GCD）**: Let $A,B$ be given nonzero elements of a UFD. Then $G$ is called the greatest common divisor (GCD) of $A,B$ if
> 1. $G$ divides $A,B$,
> 2. every common divisor of $A,B$ divides $G$, and
> 3. $G$ is $unit\ normal$.
> Condition 3 imposes uniqueness on $G$. For integers $\Z$, $unit\ normal$ means $G$ is positive. For polynomials in $\F_q[\X]$, $unit\ normal$ means  $\LC(G)$ is $1$. For polynomials in $\Z[x_1,\dots,x_n]$, $unit\ normal$ means $\LC(G)$ is positive. We say that $A$ is similar to $B$, $A\sim B$, if there exists a unit $a\in \mathcal{R}^*$ such that $a A=B$.

**动机与作用（中文）**：把 GCD 定义在一般 UFD 上并用"单位正规化"消去 $G$ 与 $ua\cdot G$ 之间的歧义（整数取正、有限域上取首一、$\Z[x]$ 上取正首系数），使 GCD 唯一；文中所有等式（如 the-5、the-15）都按此规范化解释，$\sim$ 记号则为证明中反复出现的"相差一个单位"提供了统一写法。

> **Definition（def-1，separated）**: We call a polynomial $f\in \Z[x_1,\dots,x_n,y]$ {\em separable} w.r.t. $y$ if $f$ has the form
> $$f=c_1M_1y^{d_1}+c_2M_2y^{d_2}+\cdots+c_tM_ty^{d_t},$$
> where $c_i(\neq 0)\in \Z$, $M_i,i=1,\dots,t$ are monomials in $\Z[x_1,\dots,x_n]$ and $d_i,i=1,\dots,t$ are different exponents.

**动机与作用（中文）**：这是算法追求的目标形态。"关于 $y$ 分离"等价于每个 $y$-系数只含一个单项式，因此一元 GCD 一旦算出，把整数系数按 $p_1,\dots,p_n$ 分解即可直接读出各单项式的指数，完全省去了插值或 Hensel 恢复多元结构的开销。

> **Definition（def-2，good point）**: Let $F_1,F_2\in \Z[x_1,\dots,x_n,y]$ and $C=\gcd(F_1,F_2)$. Let $\mathbf{p}=(p_1,\dots,p_n)\in\Z^n$. We say $\mathbf{p}$ is a {\em good point} for $F_1,F_2$ if $\sigma_{\mathbf{p}}\left( \LC_y(F_1) \right) \neq 0$, $\sigma_{\mathbf{p}}\left( \LC_y(F_2) \right) \neq 0$ and $\deg \sigma_\mathbf{p}(C) =\deg \gcd(\sigma_\mathbf{p}(F_1),\sigma_\mathbf{p}(F_2))$.

**动机与作用（中文）**：它精确刻画"代入 $x_i=p_i$ 之后 GCD 次数不下降"的求值点。由于总有 $\sigma_\mathbf{p}(C)|\gcd(\sigma_\mathbf{p}(F_1),\sigma_\mathbf{p}(F_2))$，只要 $\mathbf{p}$ 是好点，模像与 $C$ 就只相差一个非零常数，这正是"一个模像即可还原 GCD"的依据；Lemma the-13 进一步说明好点等价于 $L(\mathbf{p})\neq0$。

> **Definition（def-3，monomial content 与 monomial primitive part）**: A term $cM$ is called the {\em monomial content} of a polynomial $f=c_1M_1+\cdots+c_tM_t\in \Z[x_1,\dots,x_n]$, if
>  $c=\gcd(c_1,\dots,c_t)$ and $M=\gcd(M_1,\dots,M_t)$, where $M_i,i=1,\dots,t$ are different monomials and $c_i,i=1,\dots,t$ are non-zero coefficients.
> Here $c$ is the content of $f$. Denote $c=\Cont(f)$ and denote the primitive part $f/c$ as $\Prim(f)$.
> Denote $cM$ by $\mathrm{MoCont}(f)$ and we call $f/\mathrm{MoCont}(f)$ the {\em monomial primitive part} of $f$ and denote it by $\mathrm{MoPrim}(f)$.

**动机与作用（中文）**：它把"系数的内容"与"单项式部分的公因式"打包成一个单项式 $cM$，从而有分解 $G=\gcd(\MoCont(A),\MoCont(B))\cdot\gcd(\MoPrim(A),\MoPrim(B))$。算法因此可以先廉价地算出单项式内容，把主要精力放在单项式本原部分上，最后只需乘回一个单项式。

## 4.  理解辅助

- **贯穿例子一（分离替换如何工作）**：取原文 Example ex-11 的多项式 $f=4x_1^2x_2^3+5x_1^5x_2^6+10x_1^4x_2^4\in\Z[x_1,x_2]$。代入 $x_1\to x_1y^{s_1}$、$x_2\to x_2y^{s_2}$ 后三项的 $y$-指数分别是 $S_1=2s_1+3s_2$、$S_2=5s_1+6s_2$、$S_3=4s_1+4s_2$。取 $s_1=2,s_2=3$ 得 $(S_1,S_2,S_3)=(13,28,20)$，三者互不相同，故 $f(x_1y^2,x_2y^3)$ 关于 $y$ 分离；此时三个 $y$-系数恰好是单项式 $4x_1^2x_2^3$、$5x_1^5x_2^6$、$10x_1^4x_2^4$，一元结果中的整数系数可以直接"读回"指数。若换一组坏的 $\mathbf{s}$，三个指数就可能相撞，例如 $S_1=S_3$ 时两个不同单项式会被压到同一个 $y$-幂上，分离失败——这正是 Lemma the-1 要排除的情形。
- **贯穿例子二（为什么必须验证）**：原文在 Theorem the-15 之后给出反例 $A=B=(5x_1-3x_2+1)(2x_1x_2+7)$。若 alg-1 取 $s=[1,1]$、$\mathbf{p}=[3,5]$，则因子 $5x_1-3x_2+1$ 被映为常数 $1$（在模像中彻底消失），第二个因子映为 $30y^2+7$ 且恰好分离，算法于是输出 $G=2x_1x_2+7$，而真实 GCD 应为整个乘积。这说明"分离 + 好点"仍不足以保证正确，必须借助 $H|A$、$H|B$ 以及各偏次数与真 GCD 一致的验证条件兜底。
- **实验图景**：论文以 Maple 2021 的默认 GCD（LINZIP，即 Zippel 路线）为对照，设计了变动变量数 $n$（2 到 100）、变动总次数（5 到 1000）、变动 $T_{\rm out}$（2 到 50）三组基准。前两组中新算法因只需处理一个一元问题而明显更快；第三组当 GCD 项数增大时，归约后一元多项式的次数达到 $O(DT^2)$、系数也变高，新算法转而慢于对照实现。

## 5.  主动思考区

### 5.1.  与其他工作的联系

- [[2609.08074]]：这是同一问题域的最新进展（Sparse Polynomial GCD Algorithms Asymptotically Linear in All Fundamental Parameters）。该文沿着"分离 + Hensel 提升"的路线在变量数、项数、总次数与系数位长四个参数上取得渐近线性，属于把本方向复杂度推到新台阶的工作；而本文 2609.10626 的独特价值在于首次给出整数情形下的显式位复杂度公式，并把对 $n$ 与 $d$ 的依赖压到二次。两篇合读可以清楚看到该方向从"给出显式界"到"全参数线性"的演进脉络。
- [[2609.07223]]：该文处理参数化构造的多项式方程组，核心手法是引入辅助变量后消元再回代。其"引入辅助变量—消元—回代"骨架与本文"引入 $y$—把多元问题压到一元—由系数分解还原"的写法在方法论上同源，只是本文的辅助变量 $y$ 承载的是指数编码而非约束求解。
- 技术迁移：本文反复使用的"用结式与首系数构造控制多项式 $L$，再用 Schwartz–Zippel 计数坏素数（坏点）比例"的技巧（Lemma the-13、lm-9），可以直接搬到稀疏结式估计与稀疏因式分解的复杂度分析中，属于可复用的证明组件。

### 5.2.  可以尝试的方向

- 能否去随机化：对控制多项式 $L$ 的零点集合做确定性界定（例如用有效版的高度或素理想估计），从而把 Monte Carlo 型算法升级为 Las Vegas 或确定性算法？
- 把一元 GCD 子程序替换为对高次、大系数更快的算法（如半 GCD、快速 Euclid 或改进的模 GCD 小素数版本），能否抹平基准三中 $T_{\rm out}$ 大时的劣势？
- 分离参数目前取自 $[0,\frac92T(T-1)]^n$，使代入后 $y$ 的次数高达 $O(T^2D)$。能否用混合基或分块指数编码把该次数降到 $O(TD)$ 量级，从而直接改善一元子问题的代价？
- 结论能否推广到其它唯一分解环（如代数整数环 $\mathcal{O}_K[x_1,\dots,x_n]$）或小特征有限域上的稀疏 GCD？

### 5.3.  批判性思考

- 全文的随机性来自三个相互独立的环节：分离向量 $\mathbf{s}$、求值点 $\mathbf{p}$、Hensel 提升的素数 $p$，三处失败概率相乘才得到 $3/4$。这种多源随机化让分析高度模块化，但代价是常数因子偏保守；论文实际实现时随机取 $O(nT\log C)$ 量级的小素数并默认坏点稀少，已经偏离了理论阈值（$N$ 中与 $S D$ 相关的项），理论界与工程实现之间存在明显缝隙。
- 复杂度界中的 $T_{\rm out}^2$ 与归约后一元 GCD 的 $O(DT^2)$ 次数是同一枚硬币的两面。作者把"寻找更好的一元 GCD 算法"列为未来工作，实际上等于承认该框架的瓶颈不在多元归约本身，而在归约之后的一元问题——这提示后续改进应优先攻一元侧，而非继续优化替换与取点。
- Theorem the-15 给出的验证条件（$H|A$、$H|B$、各偏次数与真 GCD 相等）在数学上是完备的，但实现它的 Algorithm alg-4 自身依然是随机化的：它用随机点上的整除性检验 $P_H\nmid P_A$ 来排除错误候选，因此所谓"验证"并不提供确定性证书，只是把出错概率再压低一次；对于追求可证明正确性的应用（如密码学场景），这一层随机性仍需要在工程上另行处理。
