# ON THE TRANSFER OF ARTINIANESS AND COHEN-MACAULAYNESS UNDER MODULE-FINITE EXTENSIONS

keywords: [模有限扩张, 局部上同调, Attached primes, 理想化, Cohen-Macaulay 模]
related_paper: "2609.06297（Matlis duality, reflexive modules, local cohomology）"
one_liner_summary: "本文证明在模有限扩张 $\varphi: R\hookrightarrow S$ 之下，Artinian 模结构与 attached primes 可在 $R$ 与 $S$ 之间双向转移，六类 Cohen-Macaulay 性（含 sequentially 系列）在两侧等价，且 $R$ 是 Cohen-Macaulay 局部环的商当且仅当 $S$ 是，并用此刻画 Nagata 理想化的环结构。"

## 1.  核心定位

- **解决的问题**：当 $\varphi: R\hookrightarrow S$ 是 Noether 局部环之间的模有限扩张时，一个模的 Artinian 性（及其维数、attached primes）在限制与扩张标量下如何变化；局部上同调模 $H^i_{\frak n}(N)$ 与 $H^i_{\frak m}(N)$ 有何关系；以及 Cohen-Macaulay 性、generalized Cohen-Macaulay 性、$1$-Cohen-Macaulay 性及它们的 sequentially 版本能否在 $R$ 与 $S$ 之间来回传递。
- **大图景位置**：本文处在两条主线的交汇处。一条是模有限扩张主线（Direct Summand Conjecture、Noether 归一化、Cohen-Macaulayfication 与 Macaulayfication）；另一条是局部上同调与二次表示理论主线（Melkersson 判据、Macdonald 的 attached primes）。它把"环的 CM 性"提升为"模在两侧标量下的 CM 性"这一双向等价问题，并顺带给出理想化这一典型模有限扩张的完整结构刻画，填补了"哪些 CM 类性质是模有限扩张的不变量"这一空白。
- **主要贡献**：其一，Theorem T:1 建立 Artinian $S$-模与 Artinian $R$-模的等价（并给出 $\dim$ 等式与 $\Att$ 的包含关系），且证明 $\Att$ 的等式成立当且仅当 $\varphi^*: \Spec(S)\to\Spec(R)$ 是双射；其二，Theorem T:2 给出 $H^i_{\frak n}(N)\cong H^i_{\frak m}(N)$ 的 Artinian $R$-模同构，证明六类 Cohen-Macaulay 性在 $R$ 与 $S$ 之间等价，并证明"是 Cohen-Macaulay 局部环的商"这一性质双向传递；其三，应用上述结果刻画 Nagata 理想化 $R\ltimes M$ 的 CM、generalized CM、$1$-CM 与 sequentially 版本（Corollary C:1、C:2），并给出反例说明这类性质既不能从 $R$ 传到 $S$，也不能从 $S$ 传回 $R$（Example E:2）。
- **关键先驱工作**：Melkersson 的 Artinian 模判据；Macdonald 的二次表示（secondary representation）与 attached primes 理论；Hochster 与 André 关于 Direct Summand Conjecture 的工作；Cuong-Schenzel-Trung 的 generalized Cohen-Macaulay 模；Stanley（分次情形）与 Schenzel（局部情形）的 sequentially Cohen-Macaulay 模；Cuong 关于 $p$-standard system of parameters 与"CM 局部环之商"的判据；Nagata 的理想化构造；以及 TPDA 关于模有限扩张下维数滤链的结果。
- **结果边界**：Theorem T:1 中 attached primes 的关系一般只是包含而非等式，等式需要 $\varphi^*:\Spec(S)\to\Spec(R)$ 为双射这一额外条件才能保证；Theorem T:1(b) 的逆问题（$A\otimes_RS$ Artinian 是否蕴含 $A$ Artinian）在一般情况下仍未解决，仅在 $\varphi$ 平坦、$R$ 是 $S$ 的 $R$-模直和项、或 $\frak mA=0$ 三种情形下有肯定答案；Example E:1 表明 Artinian 模之间的单射以及自然映射 $A\to A\otimes_RS$、$A'\otimes_RS\to A\otimes_RS$ 在模有限扩张下都不再保持单射。
- **开放问题**：作者明确留下一个问题——若 $A\otimes_RS$ 是 Artinian 的 $R$-模，是否 $A$ 必为 Artinian $R$-模？作者指出由于 $A\otimes_RS$ 只是 $A^t$（$t=\ell_R(S/\frak mS)$）的商，而 $A^t$ 本身是否 Artinian 不可知，一般情形下这一问题似乎难以判定。
- **应用与推广**：可直接用于理想化 $R\ltimes M$ 的环性质判定，把关于模 $M$ 的问题化归为环 $R\ltimes M$ 的问题；在 Macaulayfication 与 Cohen-Macaulayfication 的构造中提供"两侧 CM 性同步"的依据；在局部上同调层面与 Faltings 零化定理、shifted principles 相关（因为"是 CM 局部环的商"这一条件正是这些定理的核心假设）。技术上，这套"先用 Melkersson 判据在下层环建立 Artinian 性，再用 Independence Theorem 对齐局部上同调"的两步策略，可迁移到非交换模有限扩张、幂等支撑上的广义局部上同调，以及特征 $p$ 下 $F$-奇点类不变量的传递性问题。

## 2.  主要定理

> **全局假定 / 背景**: Throughout this paper, let $(R,\frak m )$ and $(S,\frak n )$ be Noetherian local rings. Let $\varphi: R\hookrightarrow S$ be a module-finite extension, i.e. $\varphi$ is a ring monomorphism and $S$ is finitely generated as an $R$-module defined by $\varphi$. If $A$ is an Artinian $R$-module, set $\dim_R(A)=\dim(R/\Ann_RA).$ For a finitely generated $R$-module $M$, set $$\Assh_R(M)=\{\frak p\in\Ass_R(M)\mid \dim(R/\frak p)=\dim_R(M)\}.$$

> **Theorem T:1**: The following statements are true.
> (a) Let $B$ be an $S$-module. Then $B$ is Artinian as an $S$-module if and only if $B$ is Artinian as an $R$-module defined by $\varphi$. In this case we have $\dim_{S}(B)=\dim_R(B)$ and $$\Att_S(B)\subseteq\bigcup_{\frak p\in\Att_R(B)}\Assh_S(S/\frak pS).$$
> (b) If $A$ is an Artinian $R$-module then $A\otimes_RS$ is an Artinian $S$-module. In this case we have $\dim_S(A\otimes_RS)=\dim_R(A)$ and $$\Att_S(A\otimes_RS)\subseteq\bigcup_{\frak p\in\Att_R(A)}\Assh_S(S/\frak pS).$$
> (c) $\Att_S(B)=\bigcup_{\frak p\in\Att_R(B)}\Assh_S(S/\frak pS)$ for every Artinian $S$-module $B$ if and only if the induced map $\varphi^*:\Spec(S)\to\Spec(R)$ sending $\frak P$ to $\frak P\cap R$ is a bijection.

### 2.1.  证明思路

- 第一步（正向）：设 $B$ 是 Artinian $S$-模。对任意 $b\in B$，由 $B$ 的 Artinian 性存在 $t$ 使 $\frak n^tb=0$；再由 Remark R:3(a) 的 $\frak mS\subseteq\frak n$ 得 $\frak m^tb=0$，故 $B$ 作为 $R$-模是 $\frak m$-torsion 的，满足 Melkersson 判据的第一个条件。
- 第二步（有限长性）：由 $\frak mS\cap R=\frak m$（Lemma L:3a(b)）与 $S$ 的 $R$-有限生成性，$R/\frak m\hookrightarrow S/\frak mS$ 仍是模有限扩张，故 $\dim(S/\frak mS)=0$，从而 $(0:_B\frak mS)$ 作为 Artinian $S$-模长度有限；再由 Lemma L:4(b) 把 $\ell_S$ 换算为 $\ell_R$，得 $(0:_B\frak m)$ 是 Artinian $R$-模。两步合起来由 Melkersson 判据给出 $B$ 是 Artinian $R$-模；反向只需注意 $S$-子模链同时是 $R$-子模链。
- 第三步（维数对齐）：用 Lemma L:2(a)(c) 做双向夹逼。取 $\frak P\in\Att_S(B)$ 使 $\dim(S/\frak P)=t$，令 $\frak p=\frak P\cap R$，则 $\frak p\in\Att_R(B)$ 且 $R/\frak p\hookrightarrow S/\frak P$ 是模有限扩张，由 $\dim(R/\frak p)=\dim(S/\frak P)$ 得 $t\le t'$；反向取 $\frak p\in\Att_R(B)$ 使 $\dim(R/\frak p)=t'$，由 $S$ 上存在收缩到 $\frak p$ 的 attached prime 得 $t'\le t$。两个方向的等号都来自 Lemma L:3a(a)。
- 第四步（包含关系）：对 $\frak P\in\Att_S(B)$，由 Lemma L:2(c) 知 $\frak p=\frak P\cap R\in\Att_R(B)$，再由 Lemma L:3a(c) 知 $\frak P\in\Assh_S(S/\frak pS)$，包含关系随即成立。
- 第五步（等式的充要条件）：充分性用反证——若 $\frak P,\frak Q$ 收缩到同一 $\frak p$，令 $t=\dim(S/\frak pS)$、$B_1=H^t_{\frak n}(S/\frak P)$、$B_2=H^t_{\frak n}(S/\frak Q)$，由 Lemma L:2(d) 知 $\Att_S(B_1)=\{\frak P\}$、$\Att_S(B_2)=\{\frak Q\}$ 而二者作为 $R$-模的 attached primes 都是 $\{\frak p\}$，代入等式假设即得 $\frak P=\frak Q$，故 $\varphi^*$ 单射，结合 Remark R:3(a) 的满射性得双射；必要性则用 Lemma L:3a(b)(c) 与模有限扩张下的维数等式把 $\frak P$ 的收缩与 $\frak p$ 对齐，再由 $\varphi^*$ 的单射性把 $\frak P$ 归入 $\Att_S(B)$。

> **Theorem T:2**: Let $N$ be a finitely generated $S$-module. The following statements hold true.
> (a) For each integer $i$, there is an isomorphism $H^i_{\frak n}(N)\cong H^i_{\frak m}(N)$ of Artinian $R$-modules. Moreover, if $H^i_{\frak n}(N)\neq 0$ then $\dim_S(H^i_{\frak n}(N))=\dim_R(H^i_{\frak m}(N)).$
> (b) $N$ is Cohen-Macaulay (resp. generalized Cohen-Macaulay, $1$-Cohen-Macaulay, sequentially Cohen-Macaulay, sequentially generalized Cohen-Macaulay, sequentially $1$-Cohen-Macaulay) as an $S$-module if and only if so is $N$ as an $R$-module.
> (c) $R$ is a quotient of a Cohen-Macaulay local ring if and only if so is $S$.

### 2.2.  证明思路

- 第一步（同构的建立）：$H^i_{\frak n}(N)$ 是 Artinian $S$-模，由 Theorem T:1(a) 它同时是 Artinian $R$-模且两边的维数相等；再由 Lemma L:4(a) 得 $\ell_R(S/\frak mS)<\infty$，即 $\dim(S/\frak mS)=0$，于是局部上同调的 Independence Theorem 给出 $H^i_{\frak n}(N)=H^i_{\frak mS}(N)\cong H^i_{\frak m}(N)$ 作为 $R$-模同构。
- 第二步（CM 与广义 CM 的等价）：由第一步的"同构 + 维数相等"立即得到 $H^i_{\frak n}(N)\neq 0$ 当且仅当 $H^i_{\frak m}(N)\neq 0$，于是 $\dim_S(N)=\dim_R(N)$ 且 $\depth_S(N)=\depth_R(N)$，Cohen-Macaulay 性等价；generalized / $1$-CM 性则把定义改写为"$i<\dim$ 时 $\dim H^i\le 0$（或 $\le 1$）"，逐项对应即得。
- 第三步（sequentially 系列）：取 $N$ 作为 $S$-模的维数滤链 $H^0_{\frak n}(N)=D_t\subset\ldots\subset D_0=N$，由模有限扩张下维数滤链不变的结果知它同时也是 $N$ 作为 $R$-模的维数滤链，从而只需对每个商 $D_i/D_{i+1}$ 使用第二步的等价性，sequentially CM、sequentially generalized CM 与 sequentially $1$-CM 三个版本同时成立。
- 第四步（"CM 环之商"的双向传递）：使用 Cuong 的判据——$R/\Ann_R(M)$ 是 CM 局部环的商当且仅当 $M$ 具有 $p$-standard system of parameters。设 $\dim R=n$，由第一步得 $\dim(S/\frak a_S(S))=\dim(R/\frak a_R(S))$；若 $R$ 是 CM 局部环的商，则 Lemma L:2(e) 给出 $\dim_R(H^i_{\frak m}(S))\le i$，从而 $\dim(S/\frak a_S(S))<n$，用 Prime Avoidance 逐步选出属于相应 $\frak a$ 的参数 $s_n,s_{n-1},\ldots,s_1$，得到 $S$ 的 $p$-standard 序列。反向论证同理，最后用 $\Ann_R(S)=0$ 把结论从 $R/\Ann_R(S)$ 提升回 $R$ 本身。

## 3.  关键组件

### 3.1.  关键引理

> **Lemma L:1（Melkersson 判据）**: Let $A$ be an $R$-module. Then $A$ is an Artinian $R$-module if and only if there exists an ideal $I$ of $R$ such that $A$ is $I$-torsion and $(0:_AI)$ is Artinian.

*动机 / 作用（中文）*：这是全文处理 Artinian 性的总入口。它把"整条子模链稳定"这一难以直接验证的条件，拆成"$I$-torsion"（每个元素被 $I$ 的某个幂杀死）与"$I$-torsion 子模有限长"两个可操作条件，Theorem T:1(a) 的正向证明正是按这两个条件逐条落实的。
*证明思路（中文）*：引用自 Melkersson，本文只作引用，未重证。

> **Lemma L:2a**: Let $A$ be an Artinian $R$-module. Then $A\otimes_RS$ is an Artinian $R$-module and $$\Att_R(A\otimes_RS)=\Att_R(A).$$ In particular, $A\neq 0$ if and only if $A\otimes_RS\neq 0$.

*动机 / 作用（中文）*：扩张标量会把 $A$ 变成 $S$-模，但它作为 $R$-模的二次表示结构完全不变，这使 Theorem T:1(b) 可以把问题从 $A$ 转嫁到 $A\otimes_RS$ 上，再调用 (a) 部分。
*证明思路（中文）*：由 $S$ 的 $R$-有限生成性得 $A\otimes_RS$ 是 Artinian $R$-模；由于 $\varphi$ 单射有 $\Supp_R(S)=\Spec(R)$，于是 [MSch, Proposition 5.2] 给出 $\Att_R(A\otimes_RS)=\Att_R(A)\cap\Supp_R(S)=\Att_R(A)$；非零性的断言由 Lemma L:2(b) 得到。

> **Lemma L:3a**: The following statements are true. (a) $\dim (R)=\dim (S).$ (b) $\frak pS\cap R=\frak p$ for all $\frak p\in\Spec(R).$ (c) If $\frak P\in\Spec(S)$ and $\frak p=\frak P\cap R,$ then $\frak P\in\Assh_S(S/\frak pS).$

*动机 / 作用（中文）*：这是"模有限扩张下素谱行为"的三条基础设施。(a) 保证两侧维数一致，是定理中一切维数等式的根据；(b) 说明扩张再收缩不改变素理想，使 $R/\frak p\hookrightarrow S/\frak pS$ 仍为模有限扩张；(c) 把任取的上方素理想 $\frak P$ 归入 $\Assh_S(S/\frak pS)$，是 attached primes 包含关系成立的关键一环。
*证明思路（中文）*：(a) 用 Remark R:3(a)(b) 的满射性与 going-up 性质，从 $R$ 的饱和链提升到 $S$、再从 $S$ 的饱和链下压到 $R$，双向不等式夹出等号；(b) 由满射性取 $\frak P$ 覆盖 $\frak p$，再用 $\frak p\subseteq\frak pS\cap R\subseteq\frak P\cap R=\frak p$ 夹逼；(c) 取 $\frak Q\in\Ass(S/\frak pS)$ 满足 $\frak P\supseteq\frak Q$，对 $R/\frak p\hookrightarrow S/\frak P$ 与 $R/\frak p\hookrightarrow S/\frak pS$ 两个模有限扩张各用一次 (a)，得三个维数相等，从而 $\frak Q=\frak P$ 落在 $\Assh_S(S/\frak pS)$ 中。

> **Lemma L:4**: Let $B$ be an $S$-module. The following statements are true. (a) $\ell_R(S/\frak mS)<\infty.$ In particular, $\ell_R(S/\frak n)<\infty.$ (b) $\ell_S(B)<\infty$ if and only if $\ell_R(B)<\infty.$ In this case, we have $$\ell_R(B)=\ell_S(B)~\ell_R(S/\frak n).$$

*动机 / 作用（中文）*：给出长度在两侧标量之间的换算公式，使 Theorem T:1(a) 中"证明 $(0:_B\frak m)$ 有限长"的步骤得以完成；它也是 $\dim(S/\frak mS)=0$ 这一 Independence Theorem 适用条件的来源。
*证明思路（中文）*：(a) 由 $S/\frak mS$ 是 $R/\frak m$ 上有限维向量空间得有限长，再用 $\frak mS\subseteq\frak n$ 得 $S/\frak n$ 也有限长；(b) 取 $B$ 的 $S$-合成列，逐段把 $S/\frak n$ 的长度相加，得到 $\ell_R(B)=t\,\ell_R(S/\frak n)$。

> **Lemma L:5**: Let $A$ be an $R$-module such that $A\otimes_RS$ is an Artinian $R$-module. If one of the following conditions is satisfied then $A$ is Artinian. (a) $\varphi: R\hookrightarrow S$ is flat. (b) $R$ is a direct summand of $S$ as an $R$-module. (c) $\frak mA=0$, i.e. $A$ is a vector space over $R/\frak m$.

*动机 / 作用（中文）*：这是 Theorem T:1(b) 逆问题的三个部分肯定答案。它界定了"Artinian 性能否从 $A\otimes_RS$ 反推回 $A$"的已知疆界：平坦、直和项、以及零维（$\frak mA=0$）三种情形。
*证明思路（中文）*：(a) 若 $A$ 有一条不稳定的降链，平坦性使张量后仍是不稳定降链，与 $A\otimes_RS$ 的 Artinian 性矛盾；(b) 直和项使 $A$ 成为 $A\otimes_RS$ 的直和项；(c) 由 $\frak mA=0$ 得 $A\otimes_RS\cong A\otimes_kS/\frak mS$，再用 $S/\frak mS$ 有限维反推 $A$ 的 Artinian 性。

### 3.2.  关键定义

> **Definition（二次表示与 attached primes）**: We say that $A$ is {\it $\mathfrak p$-secondary} if $A\neq 0$ and the multiplication by $r$ on $A$ is surjective for all $r\in R\setminus \mathfrak p$ and it is nilpotent for all $r\in\mathfrak p$. We say that $A$ is {\it representable} if either $A=0$ or $A$ has a minimal secondary representation $A=A_1+\ldots+A_n$, where each $A_i$ is a non-redundant $\frak p_i$-secondary component and $\frak p_i\ne\frak p_j$ for all $i\ne j.$ The set $\{\frak p_1,\ldots,\frak p_n\}$ is independent on the choice of the minimal secondary representation of $A$. It is called the set of {\it attached primes} of $A$ and denoted by $\Att_R(A).$
> **直观动机与作用**: 二次表示是 Artinian 模的"素分解"，$\Att_R(A)$ 扮演的角色恰如有限生成模的 $\Ass_R$：它记录 Artinian 模的"支撑信息"，且其极小元由 $\Var(\Ann_RA)$ 决定、模的维数等于这些 prime 对应商环维数的最大值。本文全部关于 Artinian 结构的结论都是以 $\Att$ 的收缩—扩张行为来陈述的。

> **Definition（Nagata 理想化）**:  Let $M$ be a finitely generated $R$-module. We provide a multiplication on the additive group $R\oplus M$    $$(a, x).(b, y) = (ab, ay+bx)$$ for all $(a, x), (b, y)\in R\oplus M$, then $R\oplus M$ forms a Noetherian local ring with the unique maximal ideal $\mathfrak{m} \oplus M$ and $\dim(R\ltimes M)=\dim(R)$. This local ring is called the {\it idealization} of $M$ over $R$ and denoted by $R\ltimes M$.
> **直观动机与作用**: 理想化把一个模塞进环里变成理想，从而把"模的性质"转译成"环的性质"；典范单射 $\sigma: R\hookrightarrow R\ltimes M$ 本身是模有限扩张，因此本文的定理可直接作用于它，把 $R\ltimes M$ 的 CM 类性质完全翻译成 $R$ 与 $M$ 的性质（Corollary C:1、C:2）。

> **Definition（CM 类性质的 $\frak a$-判据）**: Set $\frak a_i(M):=\Ann_RH^i_{\frak m}(M)$ for $i\leq d$ and $\frak a(M)=\frak a_0(M)\ldots \frak a_{d-1}(M).$ If we stipulate the dimension of zero module to be $-1$, then $M$ is Cohen-Macaulay (resp. generalized Cohen-Macaulay, $1$-Cohen-Macaulay) if and only if $\dim (R/\frak a(M))=-1$ (resp. $\dim (R/\frak a(M))\leq 0$, $\dim (R/\frak a(M))\leq 1$).
> **直观动机与作用**: 把抽象的 CM 类条件统一写成"局部上同调模的零化子之积所支撑的维数不超过某阈值"，从而把性质比较转化为维数比较；这正是 Theorem T:2(b) 能把六类性质一次性在 $R$ 与 $S$ 之间搬运的技术原因。

> **Definition（$p$-standard system of parameters）**: Following Cuong, a system of parameters $x_1, \ldots , x_d$ of $M$ is  a {\it $p$-standard system of parameters}  of $M$ if $x_d\in \frak a(M)$ and $x_i\in\frak a(M/(x_{i+1}, \ldots , x_d)M)$ for all $i$. Here, $\frak a(M):=\Ann_R(H^0_{\frak m}(M))\ldots \Ann_R(H^{d-1}_{\frak m}(M)).$
> **直观动机与作用**: 这是"$R/\Ann_R(M)$ 是 CM 局部环的商"的可检验判据——参数序列要一步步落在局部上同调零化子之积里。Theorem T:2(c) 的双向传递正是靠它把"环层次"的性质翻译成"参数序列存在性"，再用 Prime Avoidance 逐步构造。

## 4.  理解辅助

- **贯穿例子一（反例警示）**：取 $S=K[[t]]$、$R=K[[t^2,t^3]]$、$\frak m=(t^2,t^3)$，则 $R\hookrightarrow S$ 是模有限扩张。令 $A=R/\frak m^2$、$A'=\frak m/\frak m^2$、$E=E_R(R/\frak m)$，三者都是 Artinian $R$-模。由于 $\frak mA'=0$，有 $A'\otimes_RS\cong A'\otimes_{R/\frak m}(S/\frak mS)$，它是 $R/\frak m$ 上以 $\{t^2\otimes1,\ t^2\otimes t,\ t^3\otimes1,\ t^3\otimes t\}$ 为基的 $4$ 维向量空间；而 $A\otimes_RS\cong S/\frak m^2S\cong K[[t]]/(t^4)$，满足 $t^4(A\otimes_RS)=0$。于是 $f^*(t^3\otimes t)=t^4(1\otimes1)=0$，映射 $f^*: A'\otimes_RS\to A\otimes_RS$ 不单。类似地，若 $E\to E\otimes_RS$ 单射，对偶后可得 $\Hom_R(S,R)\to R$ 的满射，从而存在 $g$ 使 $g(1)=1$，再由 $t^2g(t)=g(t^3)=t^3$ 得 $g(t)=t\notin R$，矛盾。这个例子说明了为什么 Theorem T:1(b) 的逆问题一般难以回答。
- **贯穿例子二（理想化下的三类性质分离）**：取 $R=K[[x_1,\ldots,x_d]]$、$M_i=R/(x_1,\ldots,x_i)R$，则 $S=R\ltimes M_i$ 对任意 $i$ 都是 sequentially Cohen-Macaulay 的；但当 $i=d$ 时 $S$ 不是 Cohen-Macaulay，$i=d-1$（$d\ge2$）时不是 generalized Cohen-Macaulay，$i=d-2$（$d\ge3$）时不是 $1$-Cohen-Macaulay。若改用 $M'_i=(x_1,\ldots,x_i)R$，则相应条件下 $S$ 连 sequentially 版本也不满足。这一族例子把"逐层滤链"与"整体 CM"之间的强度差异显示得非常清楚。
- **贯穿例子三（Macaulayfication 给出的不可反向传递）**：设 $V$ 由 $x_1=s^4,\ x_2=s^3t,\ x_3=st^3,\ x_4=t^4,\ x_5=s^2t^2v,\ x_6=v$ 定义，其 Macaulayfication 为 $W$：$x_1=s^4,\ x_2=s^3t,\ x_3=st^3,\ x_4=t^4,\ x_5=s^2t^2,\ x_6=v$，中间有正合列 $0\to K[V]\to K[W]\to L\to 0$（$L$ 是非零 $0$ 维模）。令 $R_1=K[[s^4,s^3t,st^3,t^4,s^2t^2v,v]]$、$S_1=K[[s^4,s^3t,st^3,t^4,s^2t^2,v]]$，则 $R_1\hookrightarrow S_1$ 是模有限扩张，$S_1$ 是 Cohen-Macaulay 而 $R_1$ 只满足 generalized Cohen-Macaulay（$H^1_{\frak m_1}(R_1)\neq0$ 且维数为 $0$）。再对 $R_1,S_1$ 各添加 $d-3$ 个形式变量，可把上述分离现象推到任意维数 $d\ge3$，由此得到 Example E:2(b) 中的反向不传递实例。

## 5.  主动思考区

### 5.1.  与其他工作的联系

- 这让我想起：在完备局部环上"Artinian 模"与"Matlis 自反模"的对偶关系——见 [[2609.06297]]。该文用 Matlis 对偶与 minimax 条件刻画自反性，本质上是把"有限性条件"翻译成模结构条件；本文则是在模有限扩张下把 Artinian 结构与 attached primes 一并搬运，两者都在回答"哪些有限性/对偶性质在基变换下稳定"，可以说本文的结果是该类稳定性问题在模有限扩张方向上的对偶版本。
- [[2609.06297]]：该文的核心工具是 Matlis 对偶与局部上同调的有限性（Belshoff–Slattery–Wickham 型定理），而本文 Theorem T:2(a) 给出的 $H^i_{\frak n}(N)\cong H^i_{\frak m}(N)$ 同构同样是把局部上同调放在两层环上比较；技术上可以设想把该文的自反性判据用于本文扩张后的模，检验自反性是否也具备类似的"双向传递"性质。
- [[2609.10295]]：该文研究有限投射维数 Cohen-Macaulay 模的 Hilbert 系数界，核心对象与本文一致（Cohen-Macaulay 模），但切入点不同：该文关心数值不变量（Hilbert 系数、Castelnuovo-Mumford 正则度）的上界，本文关心 CM 类性质在模有限扩张下的传递性。两者可以结合——若 $N$ 作为 $S$-模与 $R$-模的 CM 性等价，则这类数值不变量是否也随之对齐，是一个自然的问题。
- [[2609.09558]]：该文用 $F$-depth、广义 $F$-depth 刻画 $F$-nilpotent 环与 Frobenius 检验指数，同样以局部上同调模 $H^j_{\frak m}(R)$ 的消失性/幂零性为核心；本文则给出"$R$ 是 CM 局部环的商 $\Leftrightarrow$ $S$ 是"这一结构性结论。将两者对照，一个值得尝试的方向是把 $\dim(R/\frak a(M))\le i$ 型判据替换为 $F$-depth 型不变量，考察模有限扩张下的传递性。
- [[2609.06456]]：该文以极大 Cohen-Macaulay 模与奇异范畴为核心，本文的模有限扩张视角（把 $N$ 在 $R$ 与 $S$ 两侧同时看作模）与"同一模在不同环上的表现"这一主题相通，技术迁移上可设想在奇异范畴层面考察模有限扩张诱导的函子是否保持相应的有限性条件。

### 5.2.  可以尝试的方向

- [ ] 能否把 Theorem T:2(a) 的同构从局部上同调推广到一般的导出函子（如 $\Ext$、$\Tor$）层面，得到"限制/扩张标量不改变 Artinian 性"的导出版本？
- [ ] 对 Theorem T:1(c) 中的双射条件，能否用更易验证的同调条件（如 $\varphi$ 是 étale、或 $\Spec(S)\to\Spec(R)$ 是万有同胚）来替代？
- [ ] Lemma L:5 之外，是否还有其他自然条件能保证"$A\otimes_RS$ Artinian $\Rightarrow$ $A$ Artinian"？例如 $R$ 是 $S$ 的直和项的弱化版本，或对 $R$ 的奇点类型加约束。
- [ ] 把 $p$-standard system of parameters 的传递性结果（Theorem T:2(c)）推广到"$R$ 是 Gorenstein 局部环之商"或"$R$ 是正规局部环之商"等更强结构性质上。
- [ ] 考察非交换情形：当 $S$ 是 $R$ 上的模有限代数但不必交换时，attached primes 理论需要替换为哪些不变量，Theorem T:1 的结论是否仍有类比。

### 5.3.  批判性思考

- 全文最强的两处技术依赖是 Melkersson 判据与 Independence Theorem；两者都是"局部—有限性"型工具，因此定理的结论本质上是"有限性在模有限扩张下不增不减"。这一图景暗示：真正起作用的可能不是 Noether 局部环的具体结构，而是"$S$ 作为 $R$-模有限生成 + $\frak mS\subseteq\frak n$"这两条抽象性质，因此结果或许可以在更弱的框架（如分级环、滤过环）中重述。
- Theorem T:1(c) 把 $\Att$ 的等式归结为 $\varphi^*$ 的双射性，这个条件偏强（对非正规扩张如 $K[[t^2,t^3]]\hookrightarrow K[[t]]$ 就不成立）。作者没有给出双射性在不分歧扩张中的等价刻画，这使 (c) 的操作性打折扣。
- Theorem T:2(b) 关于 sequentially Cohen-Macaulay 的部分，作者自己指出已在 [TPDA] 中出现，因此 (b) 的"新意"主要落在 generalized / $1$-CM 与 sequentially 版本的统一处理上；读者在引用时应注意区分哪些部分是真正的新结果。
- 关于 Theorem T:1(b) 的逆问题，作者的论述（$A\otimes_RS$ 是 $A^t$ 的商，而 $A^t$ 是否 Artinian 未知）实际上表明该障碍是"子模的 Artinian 性不可由商继承"这一普遍现象，而非模有限扩张特有的困难；这也意味着任何肯定性答案都必须借助某种平坦性或直和项性质，Lemma L:5 的三种情形很可能是接近最优的。
