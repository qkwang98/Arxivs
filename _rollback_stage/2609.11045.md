# Rankin--Selberg integrals of opposite conductor--one newforms

keywords: [Rankin--Selberg 积分, 对偶 newform, 导子一表示, 局部相对特征, Disegni--Zhang 猜想, 多重性一]
related_paper: "Jacquet--Piatetski-Shapiro--Shalika 关于 Rankin--Selberg 积分与 Whittaker newform 的经典工作；Disegni--Zhang 关于局部相对特征非消没的猜想（本文验证其导子一情形并改进其 Theorem C）"
one_liner_summary: "对非阿基米德局部域上导子为一、中心特征平凡的 temper 表示 $\Pi_{n+1}$ 与 $\Pi_n$，本文显式算出「对偶 newform」的 Rankin--Selberg 积分，证明它等于 Rankin--Selberg $L$-函数的显式常数倍，因而中心值非零，并由此验证 Disegni--Zhang 关于局部相对特征非消没的猜想在导子一情形的成立。"

## 核心定位

- **解决的问题**：设 $F$ 为特征零的非阿基米德局部域，$G_r=\mathrm{GL}_r(F)$，$K_r=\mathrm{GL}_r(\mathfrak{o})$，$K_{c,r}$ 为保持末行向量 $(0,\ldots,0,1)$ 模 $\mathfrak{p}^c$ 的 congruence 子群，$\Pi_r$（$r=n,n+1$）是导子为 $c(\Pi_r)$ 的不可约 generic 表示。当 $c(\Pi_n)=0$（$\Pi_n$ 非分歧）时，经典 Whittaker newform 的 Rankin--Selberg 积分等于 Rankin--Selberg $L$-函数的常数倍；本文处理相反的情形，即 $\Pi_n$ 与 $\Pi_{n+1}$ 的导子都恰为一，求出此时正确的测试向量并显式算出积分值。
- **大图景位置**：本文处在「局部 Rankin--Selberg 积分 $L$-函数理论」与「newform／test vector 理论」的交汇处（Jacquet--Piatetski-Shapiro--Shalika 的传统），并直接服务于相对迹公式侧的问题：局部相对特征（local relative character）的非消没是周期积分、区分表示与 Gross--Prasad 型问题的中心议题之一，Disegni--Zhang 猜想正是该方向的猜想。本文的定位是把一条经典的非分歧计算，推广到「两边都有 ramification」的最小非平凡情形（双方导子均为一）。
- **主要贡献**：
  1. 指出经典 newform 在此情形不够用：由多重性一定理知 $\dim\mathrm{Hom}_{G_n}(\Pi_{n+1}\otimes\Pi_n,\mathbb{C})=1$，取 $\ell$ 为该一维空间的非零元素、$v_r$ 为 newform，则 $v\mapsto\ell(v_{n+1}\otimes v)$ 是 $\Pi_n$ 上的 $K_n$-不变线性泛函；又因 $c(\Pi_n^\vee)=c(\Pi_n)>0$ 而 $(\Pi_n^\vee)^{K_n}=\{0\}$，故必有 $\ell(v_{n+1}\otimes v_n)=0$。于是作者引入对偶 congruence 子群 $K^-_{1,r}=w_rK_{1,r}w_r^{-1}=\{k\in K_r:(1,0,\ldots,0)k\equiv(1,0,\ldots,0)\bmod\mathfrak{p}\}$（$w_r$ 为反对角置换矩阵），利用 $w_r$ 的作用在 $\Pi_r^{K_{1,r}}$ 与 $\Pi_r^{K^-_{1,r}}=:\sigma_r$ 之间给出线性同构，并定义归一化 $W_r^-(w_r)=1$ 的对偶 Whittaker newform $W_r^-$。
  2. 主定理：设 $\Pi_r$（$r=n,n+1$）tempered、导子为一、中心特征平凡，则作为 $q^s$ 的有理函数有
     $Z(s,W^-_{n+1},W^-_n)=-\dfrac{\chi(\varpi)q^{ns-\frac12}}{\#\mathbb{P}^{n-1}(\mathbb{F}_q)}\,L(s,\Pi_{n+1}\times\Pi_n)$，
     其中 $\chi$ 是 $\Pi_{n+1}$ 的 $L$-参数 $\phi_{\Pi_{n+1}}=\mathrm{St}_2\otimes\chi\oplus\bigoplus_{i=1}^{n-1}\chi_i$ 中的非分歧酉特征。特别地中心值 $Z(\tfrac12,W^-_{n+1},W^-_n)\neq0$，从而对每个非零 $\ell$ 都有 $\ell|_{\sigma_{n+1}\otimes\sigma_n}\neq0$。
  3. 推论：Disegni--Zhang 的猜想（其文献中编号 3.6.10）在 $\Pi_{n,v}$ 与 $\Pi_{n+1,v}$ 都具有导子一时成立，这改进了其 Theorem C。作者把证明分为两部分：第 3 节对 Whittaker newform 的 Rankin--Selberg 积分作用 Hecke 算子，第 4 节对偶 newform 作同样处理，最后在第 5 节解释推论的证明。
- **关键先驱工作**：Jacquet--Piatetski-Shapiro--Shalika 建立 Rankin--Selberg 积分与 Whittaker newform 理论；Jacquet、Matringe、Miyauchi 关于 Whittaker newform 理论的发展；AGRS 的多重性一定理（保证 $\mathrm{Hom}_{G_n}(\Pi_{n+1}\otimes\Pi_n,\mathbb{C})$ 一维）；Disegni--Zhang 关于局部相对特征非消没的猜想（本文改进其 Theorem C）；另有一个结构性的引理（本文 Lemma，用于导出 $n\geq2$ 与 $\Pi_{n+1}$ 的 $L$-参数形状 $\mathrm{St}_2\otimes\chi\oplus\bigoplus_{i=1}^{n-1}\chi_i$），它把「导子一 $+$ 中心特征平凡 $+$ tempered」翻译为 L-参数的显式形状，是后续计算的入口。
- **结果边界**：假设包括 $\Pi_r$ tempered、导子恰为一、中心特征平凡，且讨论的是对角嵌入 $G_n\hookrightarrow G_{n+1}\times G_n$ 下的 $G_n$-不变线性泛函；$F$ 须为特征零非阿基米德局部域。推论只覆盖 Disegni--Zhang 猜想在「双方导子均为一」这一情形，并未触及一般的 ramification 情形。中心值非零的结论依赖 $q$ 的幂、$\chi(\varpi)$ 与 $\#\mathbb{P}^{n-1}(\mathbb{F}_q)$ 均非零，这一点由 $\chi$ 为酉特征与剩余域有限而自动满足。
- **开放问题**：正文没有集中列出开放问题清单。自然遗留的方向是：把对偶 newform 的显式计算推广到导子大于一的表示；在去掉「中心特征平凡」或「tempered」假设后，中心值的精确公式与非消没性是否仍成立；以及把同一套对偶测试向量技术用到 Disegni--Zhang 猜想的一般情形或其它多重性一型的局部周期积分上。
- **应用与推广**：对偶 newform 作为 test vector 的做法可直接移植到其它局部周期与不变泛函问题——凡存在成熟 newform 理论、且经典 newform 的积分恒为零的多重性一情形，换用 $w_r$-共轭同余子群一侧的向量往往是恢复非零的正确选择。显式积分值还给局部 Rankin--Selberg 积分提供了一个精确的常数因子，可服务于局部--整体实验、相对迹公式中的局部项计算，以及区分表示（distinguished representation）判据的验证。

## 主动思考区

### 与其他工作的联系

- [[2609.16381]]：该文为 Yu 构造产生的任意系数尖点表示显式构造半单惯性 $L$-参数并给出局部 Langlands 对应的部分刻画定理；本文的输入恰是 $\mathrm{GL}_{n+1}$ 与 $\mathrm{GL}_n$ 上导子一 temper 表示的 $L$-参数形状，两者一个从局部 Langlands 参数出发刻画表示、一个从具体积分出发读出周期非消没，可对照「参数信息如何转化为函子性／非消没结论」。
- [[2609.16387]]：该文比较 Fargues--Scholze 与 Kaletha 的局部 Langlands 参数并证明二者在惯性上一致；与本文共享「用 $L$-参数刻画 $\mathrm{GL}_n$ 上不可约表示」的框架，本文进一步把参数形状直接翻译成 Rankin--Selberg 积分的显式取值，体现了同一参数的两种用法。
- [[2609.10483]]：该文在阿基米德情形判定 $\mathrm{GL}_{2m}(\mathbb{C})/\mathrm{GL}_m(\mathbb{H})$ 的标准模是否被区分并给出重数上界；与本篇同属「局部周期与不变泛函」主题，一个在实／四元数域用重数上界与对合条件，一个在非阿基米德域用显式积分证明非消没，可对照两者处理区分性问题的不同手法。
- 技术迁移：本文「先判定经典 newform 的积分恒为零，再以 $w_r$-共轭造出对偶 newform 作为正确 test vector」这一模式，可用于任何具备 Whittaker 模型与 newform 理论的局部周期问题；当一侧的常规测试向量消失时，取对偶侧向量（或取对偶表示上的对应向量）是最自然的补救路径。

### 可以尝试的方向

- [ ] 导子大于一时，对偶 newform 的 Rankin--Selberg 积分能否同样显式算成 $L$-函数的常数倍？此时常数会依赖哪些局部数据（导子、$\varepsilon$-因子、$\chi(\varpi)$ 的推广形式）？
- [ ] 去掉中心特征平凡或 temper 假设后，中心值非零的结论是否仍成立？例如在一般 Steinberg 型 $L$-参数下，对偶侧向量是否仍给出非零泛函？
- [ ] 这套对偶测试向量技术能否推广到 $\mathrm{GL}_{n+1}\times\mathrm{GL}_n$ 之外的多重性一情形（如正交／辛群相关的局部 Gan--Gross--Prasad 问题）？

### 批判性思考

- 论证的关键杠杆是 $L$-参数的显式形状 $\phi_{\Pi_{n+1}}=\mathrm{St}_2\otimes\chi\oplus\bigoplus_{i=1}^{n-1}\chi_i$，它是「导子一 $+$ 中心特征平凡 $+$ tempered」的直接后果。一旦离开导子一，参数形状复杂化，Hecke 算子计算的可控性会迅速下降——这正是本文只覆盖导子一的结构性原因，也是该方法的天然边界。
- 经典 newform 的消失（$\ell(v_{n+1}\otimes v_n)=0$）由 $(\Pi_n^\vee)^{K_n}=\{0\}$ 这一维数论证得到，简洁但只说明「选错了向量」；真正有信息量的是对偶侧的中心值恰好非零，而这依赖积分在 $s=\tfrac12$ 处的绝对收敛性（由 tempered 保证）与逐项计算。
- 常数项中同时出现 $\chi(\varpi)$、$q^{ns-\frac12}$ 与 $\#\mathbb{P}^{n-1}(\mathbb{F}_q)$，提示积分值对中心特征与剩余域大小相当敏感。在只关心非消没性的应用中这些常数无害（酉性与有限性保证非零），但它们表明该结果的精确形式与具体归一化约定（测度、$\psi_r$ 的定义、$W_r^-(w_r)=1$）高度耦合，跨文献引用时需要逐项对齐约定。
- 论文对「为什么必须换到对偶侧」给出了清晰的维数论证，但没有系统说明对偶侧向量在何种一般条件下会给出非零泛函；从本文看，这依赖于 $\Pi_{n+1}$ 的 $L$-参数含 $\mathrm{St}_2\otimes\chi$ 这一特殊结构，其可推广性尚需进一步论证。
