# Gelfand--Tsetlin bases for representations of $\U_{q}(\mathfrak{gl}_n)$ at roots of unity

keywords: [量子群, 单位根, Gelfand--Tsetlin 基, 奇异模, baby Verma 模, 合成列]
related_paper: "Jimbo (1988) 关于 $U_q(\mathfrak{gl}_n)$ 的 Gelfand--Tsetlin 基构造（本文在 $q$ 为单位根情形的推广对象）"
one_liner_summary: "本文把经典的 Gelfand--Tsetlin 构造推广到奇阶单位根处的量子群 $U_q(\mathfrak{gl}_n)$：对每个 generic tableau 构造出无穷维模、其不同子模给出互不同构的商且 GT 重数不超过 1，对 $1$-singular tableau 构造出重数不超过 2 的奇异 GT 模，并据此给出 $U_q(\mathfrak{gl}_3)$ 的 baby Verma 模显式基与合成列。"

## 1.  核心定位

- **解决的问题**：当 $q$ 为单位根时，量子群 $\mathrm{U}_q(\mathfrak{gl}_n)$ 含有较大的中心子代数，有限维表示范畴不再半单，显式不可约模的构造在一般情况下仍属未知。本文在单位根处建立 Gelfand--Tsetlin 基：对每个 generic tableau 构造一个无穷维模，不同的子模选取给出互不同构的商，且这些商的 GT 重数均被 1 所界；对 $1$-singular tableau 则构造奇异 GT 模，其 GT 重数被 2 所界。作为应用，给出 $\mathrm{U}_q(\mathfrak{gl}_3)$ 的若干 baby Verma 模的显式基，并确定其合成列。
- **大图景位置**：对 generic $q$，$\mathrm{U}_q(\mathfrak{g})$ 的表示论与经典包络代数 $\mathrm{U}(\mathfrak{g})$ 平行，量子情形的 GT 基由 Jimbo 构造、Ueno--Shibukawa--Takebayashi 补证；而单位根处量子群的表示论基础由 De Concini--Kac--Procesi 与 Lusztig 的一系列工作奠定，其与特征 $p$ 代数群表示论的深刻联系亦已确立。物理一侧，Witten 与 Reshetikhin--Turaev 正是用单位根处的量子群为 Chern--Simons 理论构造链环不变量。本文填补的正是"单位根 + 显式基"这一格：在保留 GT 组合框架的同时容纳非半单现象，从而把"显式构造不可约模"这一难点就地处理为"子模与商的组合描述"。
- **主要贡献**：
  1. 在奇阶单位根处给出 generic tableau 与 $1$-singular tableau 两类 GT 模的显式构造，并证明其 GT 重数分别被 1 与 2 所界；特殊情形下的子商回收文献中已有的有限维模构造，并给出新的实现与不可约性判定。
  2. 明确指出方法同样适用于偶阶单位根处的量子群以及特征 $p$ 的 Lie 代数，例如可回收 [W2017] 中的全部非限制表示并进一步扩展已知分类。
  3. 应用层面：对 $\mathrm{U}_q(\mathfrak{gl}_3)$ 的 baby Verma 模给出显式基并确定合成列，从而把 GT 基从"构造工具"变为"计算重数与合成因子的工具"。
- **关键先驱工作**：Gelfand--Tsetlin (1950) 的原始构造与 Molev 的经典综述；$\mathfrak{gl}_n$ 上 GT 模的一系列工作（[FGR2016]、[FGR2017]、[FRZ2019]、[V2017]、[V2018]、[Za2017]）；Jimbo (1988) 对 $\mathrm{U}_q(\mathfrak{gl}_n)$（generic $q$）GT 基的构造与 Ueno--Shibukawa--Takebayashi 的证明；Mazorchuk--Turowska (2000) 的 generic GT 模；Futorny--Ramires--Zhang 关于 generic 模不可约性与奇异 GT 模的构造；De Concini--Kac--Procesi 与 Lusztig 关于单位根处量子群的基础工作，以及特征 $p$ 代数群与单位根量子群表示论之间的对应框架（AJS94）。有限维模的既有构造来自 [AAC1995]、[AC1991]、[DT1997]。
- **结果边界**：构造主要针对单位根（奇阶为主，偶阶作为方法的延伸）；重数界 1 与 2 分别只覆盖 generic 与 $1$-singular 两类 tableau，不涉及更一般的 $k$-singular（$k\geq2$）情形；对 generic tableau 得到的模是无穷维的，有限维模仅作为其特殊子商出现，因此"有限维不可约分类"并未被一次性给出；与 [W2017] 等既有分类的对接被表述为"回收并扩展"，其中的参数对应需要读者自行对齐。
- **开放问题**：正文未集中列出 open questions。自然遗留的问题是：$k$-singular tableau（$k\geq2$）的重数界与构造应如何给出，界是否随 $k$ 增长；偶阶单位根与特征 $p$ 情形下的重数界与不可约性判定能否写成完整平行的理论；以及对 $n\geq4$ 的 $\mathrm{U}_q(\mathfrak{gl}_n)$，baby Verma 模的合成列是否同样可由 GT 基显式给出。
- **应用与推广**：GT 基把模表达为组合标号（tableau）的直和，重数有界即意味着"用表索引基"这一做法在单位根处依然有效，这为单位根处量子群范畴 $\mathcal{O}$ 型结构（baby Verma 模、标准模、投影模）的研究提供可计算模型；同时它也把特征 $p$ 代数群表示论中的分类问题翻译为 tableau 的组合条件，使"非限制表示"这类概念获得组合坐标。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- [[2607.24334]]：该文基于 Gelfand--Tsetlin 基把 Molev 的张量积不可约准则从 Yangian $\mathrm{Y}(\mathfrak{gl}_n)$ 推广到超 Yangian $\mathrm{Y}(\mathfrak{gl}_{m|n})$，作者之一 Jian Zhang 亦为本文作者。两文都以 GT 基为工作坐标，一个在 Yangian/超框架下讨论张量积何时不可约，一个在单位根量子群框架下讨论重数界与合成列，可对照 GT 基在"半单"与"非半单"两种环境下的效力差异。
- [[2609.11337]]：该文在分离条件下把 A 型平移量子仿射代数的有限维表示显式化为以半标准表为基的模，并给出其 $q$-特征；本文则把单位根处 $\mathrm{U}_q(\mathfrak{gl}_n)$ 的模显式化为以 tableau 为基的模。两文都以"组合标号索引基"为技术核心，区别在于一个处在 generic 参数、一个处在单位根，因此可作为"同一构造在两类参数下的成败对照"来读。
- [[2607.19112]]：该文分类满足 Verma 模重数 $[M(p):L(q)]\geq2$ 的置换对，建立重数的组合描述与 Bruhat 序之间的对应；本文的应用部分恰是确定 $\mathrm{U}_q(\mathfrak{gl}_3)$ 的 baby Verma 模合成列，即"由显式模算出重数"，与该文"给定重数反推组合条件"形成对偶，两者合读可看清 Verma 型模的重数在经典与量子单位根两个环境中的异同。
- [[2609.08353]]：该文给出 mirabolic 量子 Schur 代数 $\mathcal{MS}_v(2,d)$ 的生成元-关系呈现。量子 Schur 代数是量子群与对称群表示之间的桥梁，若要在单位根处把 GT 模与 Schur--Weyl 对偶下的模对应起来，这类显式呈现正是可用接口。
- 技术迁移："先在 generic tableau 上构造无穷维模，再通过子模的选取控制商"这一策略，可迁移到其它在非半单点处退化但仍带组合基的代数，例如单位根处分圆 Hecke 代数的模、仿射 Hecke 代数的退化点，以及有限 $W$ 代数的表示。

### 2.2.  可以尝试的方向

- [ ] 把重数界从 generic 的 1 与 $1$-singular 的 2 推进到 $k$-singular tableau：界随 $k$ 是线性增长还是呈其它规律？相应的模何时不可约？
- [ ] 在偶阶单位根与特征 $p$ 情形下，本文构造的模与 [W2017] 的非限制表示分类之间能否给出显式的参数对应表，从而把"回收并扩展"落成逐条对照？
- [ ] 对 $n\geq4$ 的 $\mathrm{U}_q(\mathfrak{gl}_n)$，baby Verma 模的合成列能否同样由 GT 基显式给出，重数是否仍受 1/2 型界控制？

### 2.3.  批判性思考

- 文章的主线是"对每个 generic tableau 构造无穷维模、以不同子模给出互不同构的商"，有限维不可约模只是作为特殊子商出现。这意味着真正的不可约分类仍需在子模格上做遍历式讨论，而文中对子模格的组合刻画并不算显式，工作被推向后续或读者一侧。
- 重数界与分类之间仍有距离：重数有界并不自动给出合成因子表。论文确实用这些界推出了部分有限维模的不可约性，但读者需要分清"界"的适用范围，避免把有界性直接读成"已完成分类"。
- "方法也适用于偶阶单位根与特征 $p$"是本文的重要卖点，然而可见正文的主要篇幅仍集中在奇阶单位根与 $\mathrm{U}_q(\mathfrak{gl}_3)$ 的应用上。将偶阶与特征 $p$ 放在"延伸"位置，读者应据此调整对结论普适性的预期。
- 与 generic $q$ 的经典 GT 理论相比，单位根情形的核心困难在于中心子代数变大、范畴不再半单。本文通过"无穷维模 + 选取子模取商"绕开了中心作用的处理，构造因此简洁，但模的中心特征与块结构等表示论信息未必因此变得清楚；若要与其他分类结果对接，这层信息很可能是缺失的一环。
