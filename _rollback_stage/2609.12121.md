# Border rank lower bounds beyond weak border apolarity

keywords: [border rank, border apolarity, matrix multiplication tensor, algebraic complexity, annihilator ideal]
related_paper: "Border apolarity (Buczyńska--Buczyński, BB19) 及其算法实现 Conner--Harper--Landsberg"
one_liner_summary: "本文首次给出必须超越弱 border apolarity 才能得到的 border rank 下界：通过两种基于半连续性的拓扑条件判别法，证明了 Schönhage 三重和、$T_{\mathrm{skewcw},2}$ 的二重直和以及 Leitner 张量与 $W$ 的 Kronecker 积的 border rank 均无下降。"

## 1.  核心定位

- **解决的问题**：确定若干具体张量的 border rank（边界秩），这些张量的下界无法由已有的"弱 border apolarity"技术给出，即：使 border apolarity 在弱版本失效的情形下仍然能够工作。
- **大图景位置**：border rank 是衡量双线性映射计算复杂度的标准度量，与矩阵乘法指数 $\omega$ 的上界直接相关。此前所有用 border apolarity 建立下界的应用都只使用了它的弱版本（仅数值条件），本文填补了"必须使用完整版本（数值条件 + 拓扑条件）"这一空白，是该方法论的第一个实质性推广。
- **主要贡献**：①给出首个超越弱 border apolarity 的 border rank 下界例子，证明 $\brk(M_{\langle 1,1,4\rangle}\oplus M_{\langle 2,2,1\rangle}\oplus M_{\langle 2,2,1\rangle})=12$；②证明 $\brk(T_{\mathrm{skewcw},2}\boxtimes M_{\langle 1\rangle}^{\oplus 2})=10$（即该直和无 drop，堵死了弱 border apolarity 允许的 $9$ 的可能性）；③证明 $\brk(T_{\mathrm{Leit},5}\boxtimes W)=12$；④提出两个可计算机验证的拓扑条件判别法，并用 $8$ 个理想（而非此前的 $512$ 个）重新得到 $M_{\langle 3\rangle}$ 的当前最佳下界，其中一个理想给出可手工核验的证明。
- **关键先驱工作**：Buczyńska--Buczyński 的 border apolarity（BB19）；Conner--Harper--Landsberg 枚举满足数值条件的理想的算法（chl19）；Koszul flattenings 与 Young flattenings（LO15、LO11）及其前身 Strassen 方程（Str83）；$2\times2$ 矩阵乘法张量 border rank $=7$ 的 Strassen（1969）上界与 Landsberg（2006）下界；Schönhage（1981）的三重和构造与指数上界 $2.55$；作者自己关于拓扑条件判别的前期工作（Man22、Man23）。
- **结果边界**：完整 border apolarity 的拓扑条件至今缺乏通用判定算法，本文的两个判别法只是**必要条件**（基于半连续性：切空间维数下界、相干层纤维维数下界），仅在小维数/低次部分即可计算；方法要求张量具有非平凡连通可解群稳定化子（此时只需考察被该群固定的理想），并要求先枚举出满足数值条件的理想；若枚举列表为空则仍退化为弱版本。此外，判别法本身不直接给出上界匹配性，需借助已知上界（如 Schönhage 的 $2uv+2v+4u+4$）确认最优。
- **开放问题**：如何发展更好的拓扑条件判别法（作者明确指出这是当前主要障碍）；对更大的 $(u,v)$，Schönhage 三重和的 border rank 能否达到理论最小值 $2uv+2v+u$；其他由张量 drop 现象（Kronecker 积、直和）引发的问题；$T_{\mathrm{skewcw},2}$ 与其他张量的乘积是否还有 drop 空间（如与 $M_{\langle 2\rangle}$ 等）。
- **应用与推广**：更精确的 border rank 下界直接改进矩阵乘法指数 $\omega$ 的估计；本文的判别法（切空间维数与相干层纤维维数的半连续性）是可计算且原则上可手工执行的，可迁移到任意具有可解群对称性的张量（包括 Coppersmith--Winograd 张量的各种变体、小张量的 Kronecker 幂/积、A-abelian 张量等），也为研究 unrestricted 情形下的最小 border rank 提供工具。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Landsberg 等人的"scaffolding / database reduction"式计算策略 — 见 [[2609.16221]]，其"初始脚手架 + 数据库约减"正是枚举满足数值条件的理想这一环节的工程化版本，本文的拓扑条件判别法可作为该流程的下游过滤器。
- [[2609.16221]]：Vector fields, initial scaffolds and database reduction — 与本文共享"先用对称性把理想列表压到可枚举规模，再逐个排除"的技术框架。
- [[2609.09633]]：Representation Varieties of Stacks and Trace Maps — 同属用代数几何工具研究张量/表示型对象不变量，其中关于 trace map 与表示簇的计算与本文用参数空间切空间维数做排除的思路相通。
- 技术迁移：本文"用切空间维数的半连续性排除参数空间中的点"的技术，可尝试用于其他需要证明某类理想不存在的情形，例如证明某个张量的最小 border rank 不可达；相干层纤维维数的半连续性判别同样适用于研究平坦族上的维数跳跃问题。

### 2.2.  可以尝试的方向

- [ ] 对 $M_{\langle 3\rangle}$ 的 $8$ 个理想中未手工核验的其余 $7$ 个，补全可手工验证的证明，形成完整的无计算机证明。
- [ ] 将两个拓扑条件判别法实现为通用软件，接入 Conner--Harper--Landsberg 的理想枚举算法，形成端到端的 border apolarity 流水线。
- [ ] 对更大参数的 Schönhage 三重和 $(u,v)$ 与四重和、以及小 Coppersmith--Winograd 张量的 Kronecker 积，检验是否存在新的 border rank drop。
- [ ] 能否把"仅需理想的低次部分"这一观察系统化为一个不依赖枚举的判据（例如只检查某个次数上的乘性映射秩）？

### 2.3.  批判性思考

- 两个判别法给出的都只是拓扑条件的必要条件，因此"排除"是可靠的，但无法保证一旦通过判别法就真能构造出满足拓扑条件的理想；这在方法上是单向的，读者需要清楚论文的结论是下界而非刻画。
- 论文对可解群固定理想的枚举依赖 chl19 的算法实现，而该算法的输出规模在张量对称群较小时可能爆炸；作者用"很多理想通常同时出现"来解释为何必须只看低次部分，但这一经验性描述缺少定量估计。
- 三个新下界中的两个（$T_{\mathrm{Leit},5}\boxtimes W$ 与 $T_{\mathrm{skewcw},2}$ 直和）本质上是在证明"没有 drop"，其正面上界由显然的构造给出；因此这些结果的信息量集中在排除性上，是否具有独立的技术纲领价值（例如能否用于 $M_{\langle 4\rangle}$）尚待观察。
- 作者把部分证明写成可手工核验的形式，这对领域信任度很重要，但 $8$ 个理想只给出 $1$ 个手工证明，其余依赖计算机，间接削弱了"可手工核验"的宣称强度。
