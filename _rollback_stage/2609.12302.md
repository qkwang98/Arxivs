# The Eisenbud--Huneke--Ulrich conjecture and bounds on minimal generators

keywords: [Eisenbud--Ulrich conjecture, linearly presented ideal, higher syzygy bundle, Castelnuovo--Mumford regularity, minimal number of generators]
related_paper: "Eisenbud--Huneke--Ulrich, 关于 $\mathfrak{m}$-primary 理想幂稳定性的原始工作（EHU）"
one_liner_summary: "本文在特征零下证明了 Eisenbud--Ulrich 猜想（线性表现 $\mathfrak{m}$-primary 理想 $I$ 满足 $I^t=\mathfrak{m}^{td}$ 当 $t\ge n$），把 Eisenbud--Huneke--Ulrich 猜想在 $p$-步线性分解情形的成立范围推进到 $n\le5$ 与 $n=7$，并给出极小生成元个数的下界与相应猜想。"

## 1.  核心定位

- **解决的问题**：对 $\mathfrak{m}$-primary 理想 $I=(f_0,\dots,f_m)$（$f_i$ 为同次 $d$ 形式），确定其幂何时等于 $\mathfrak{m}$ 的相应幂（$I^t=\mathfrak{m}^{td}$），以及在"分解线性到 $p$ 步"的条件下极小生成元个数 $\mu(I)$ 的下界。
- **大图景位置**：$I$ 为 $\mathfrak{m}$-primary 等价于定义的有理映射 $\phi\colon\mathbb{P}^n\dashrightarrow\mathbb{P}^m$ 是态射；线性表现（syzygy 模由线性关系生成）时，Eisenbud--Huneke--Ulrich 证明 $\phi$ 是闭浸入。本文所证的 Eisenbud--Ulrich 猜想把这一结论定量化为 $t=n$ 处的精确界，并进一步在 $p$-步线性分解的推广框架（Eisenbud--Huneke--Ulrich 猜想）中给出目前最强的有效界，是把"线性的步数在幂运算下如何乘性传播"这一启发式观念落地的关键一步。
- **主要贡献**：①**证明 Eisenbud--Ulrich 猜想**：若 $I$ 为 $\mathfrak{m}$-primary 且线性表现，则对一切 $t\ge n$ 有 $I^t=\mathfrak{m}^{td}$；并额外得到 $\mu(I)\ge nd+1$ 以及 $\reg(\phi(\mathbb{P}^n))\le n$（后者是最优的，作者构造了生成元更少的例子说明界 $n$ 不可改进）；②把 Eisenbud--Huneke--Ulrich 猜想在 $p$-步线性分解情形推进到 $n\le5$ 与 $n=7$，给出统一界 $s(n,p)=2\lfloor n/(p+1)\rfloor+1$（当 $n\equiv p\bmod(p+1)$）或 $2\lfloor n/(p+1)\rfloor$（否则），即 $I^t=\mathfrak{m}^{td}$ 对一切 $t\ge s(n,p)$ 成立，并用表格与猜想值逐项比较（$n=6,8,9,10,11$ 上有差距，被标注出）；③提出并部分证明生成元下界猜想 $\mu(I)\ge N(n,p,d)=\binom{p+d}{p}+(n-p)\binom{p+d-1}{p}$：在 $p=1$ 或 $d=2$ 时成立，且 $p=1$ 时尖锐；④证明更一般的几何下界 $\mu(I)\ge\binom{p+d}{d}+(n-p)(p+1)$（虚拟线性 $p$ 步情形），把 Eisenbud--Huneke--Ulrich 在线性情形下的 Proposition 7.11 / Corollary 5.2 推广到虚拟情形。
- **关键先驱工作**：Eisenbud--Huneke--Ulrich 的原始工作（EHU，含猜想 1.1、1.4 与 $n\le2$ 的情形）；作者此前把 Eisenbud--Ulrich 猜想推广到 $n\le3$ 并给出幂的正则性界的工作（yang）；Chardin--Nemati 用 Jacobian 对偶矩阵的研究（CN）；Manivel--Miró-Roig 关于常秩线性形式矩阵与 syzygy bundle 的观察（MRM）；Raicu 等关于 $\SL(U)$-子表示生成的理想 $I_{d,n}$ 的虚拟线性表现性（RSWY、BFL）；$N_p$ / $N_{d,p}$ 性质（GL、EGHP）与子可加性猜想（M-Subadd）。
- **结果边界**：基域特征零（$\mathbb{C}$ 上多项式环）；结论只对 $\mathfrak{m}$-primary 理想成立（理想缺乏该条件时 $\phi$ 非态射，全部框架失效）；生成元下界猜想 $N(n,p,d)$ 只在 $p=1$ 或 $d=2$ 时被证明；$s(n,p)$ 型界只在 $n\le5$ 与 $n=7$ 得到验证，更大 $n$ 上仍有被圈出的差距；虚拟情形需要额外假设 $E_p(d+p)$ 全局生成（作者用 Theorem lem:gg 证明了该假设在 $p$-步线性分解情形自动满足）；极端 Veronese 情形 $I=\mathfrak{m}^d$ 中 $\mu(I)$ 取最大值，是最优性验证的对照端。
- **开放问题**：证明一般情形的生成元下界猜想（Conjecture conj:numgens）；确定 $S/I$ 是否满足子可加性条件 $\reg\Tor_{a+b}\le\reg\Tor_a+\reg\Tor_b$（作者明确称"将会很有趣"）；填补 $n=6,8,9,10,11$ 上 $s(n,p)$ 与猜想界之间的差距；Eisenbud--Huneke--Ulrich 猜想在全部 $n,p$ 上的完整情形。
- **应用与推广**：证明手段是上同调的——构造复形 $\widehat{\mathcal{S}}^\bullet_n$，把问题归约为超上同调 $\mathbb{H}^1$ 的消没，再用"高次 syzygy bundle 的全局生成"这一新工具处理其中一段；该全局生成结论本身对向量丛与射影几何有独立价值（例如控制 $\phi$ 的像的 Castelnuovo--Mumford 正则性）；生成元下界与表示论中的具体理想 $I_{d,n}$（由 $\SL_2$-子表示 $\Sym^{nd}U\subseteq\Sym^d(\Sym^nU)$ 生成，与二元形式理论相关）联系紧密，说明抽象界的尖锐性有真实表示论来源；向虚拟线性表现的推广使结果可用于那些仅 sheafification 后仍线性、但本身非线性的理想族（如 $I_{d,n}$），扩大了适用面。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：syzygy bundle 的全局生成性与向量丛在射影空间上的分裂型问题，这是"表示簇/迹映射"型研究的典型工具 — 见 [[2609.09633]]。
- [[2609.09633]]：Representation Varieties of Stacks and Trace Maps — 同属"用射影几何 + 向量丛/syzygy 数据控制代数对象"的技术族，本文的 $E_p(d+p)$ 全局生成可视为该族中一个新的可计算不变量例证。
- [[2609.12253]]：Numerical invariants for three-generated ideals — 同批次、同属齐次理想的极小自由分解研究：该文以 Betti 数据约束 $\deg(R/J)$ 与 Bourbaki degree，本文以 Betti 数据（线性/虚拟线性的步数 $p$）约束幂的稳定次数与 $\mu(I)$ 下界，两者共用"分解形态决定数值不变量"的范式。
- [[2609.16221]]：Vector fields, initial scaffolds and database reduction — 都涉及用具体的代数数据组织 $\mathbb{P}^n$ 上理想/向量场的计算，其约减与枚举思想可用于测试本文猜想在中等规模 $n,p$ 下的实例。
- 技术迁移：本文"把一个涉及幂的消没问题拆成复形两段，分别用正则界与新工具处理"的策略，可尝试迁移到其他幂稳定性问题，例如 symbolic power 与 ordinary power 相等的判定、以及 ideal containment 问题（Harbourne 型猜想）；高次 syzygy bundle 全局生成的证明思路也可能用于有界正则性猜想相关的问题。

### 2.2.  可以尝试的方向

- [ ] 对 $n=6,8,9,10,11$ 中被圈出的条目（如 $n=6,p=2$ 得 $4$ 而非 $3$；$n=11,p=2$ 得 $7$ 而非 $6$），检查差距是方法局限还是猜想本身在这些参数上偏强。
- [ ] 检验 $S/I$ 的子可加性条件：先用本文的复形技术在小 $n$、$p=1,2$ 上做计算性验证（Macaulay2），再尝试证明。
- [ ] 把 $\mu(I)\ge N(n,p,d)$ 的证明从 $d=2$ 推进到 $d=3$，观察"维数计数 + Veronese 分解"这一路线在哪一步失效。
- [ ] 将 Theorem D 的几何下界 $\binom{p+d}{d}+(n-p)(p+1)$ 与 $N(n,p,d)$ 的差在 $d\ge3$ 时的渐近行为量化，判断两个界是否应合并为同一个统一猜想。

### 2.3.  批判性思考

- 论文把"$\mathbb{H}^1$ 消没"作为核心机制，但其中最关键的输入（高次 syzygy bundle 全局生成，Theorem lem:gg）只在线性分解情形被证明自动成立；虚拟情形仍需假设 $E_p(d+p)$ 全局生成，这一假设在多大范围内能被独立验证，文中没有给出反面例子，读者难以评估其限制强度。
- $s(n,p)$ 界在 $n\le5$ 与 $n=7$ 与猜想一致，而 $n=6,8,9,10,11$ 上偏弱且被以红色圈出，作者未说明圈出是技术性（复形截断位置）还是本质的；这种"部分最优性"的展示方式容易让读者高估结果的完整程度。
- 生成元下界的证明对 $p=1$ 与 $d=2$ 用了两种不同机制（前者由 Theorem A 直接推出 $nd+1=N(n,1,d)$，后者借由虚拟情形的自对偶复形），因此猜想的一般形式目前更像"两个独立现象的统一陈述"而非有统一证明的定理。
