# Torus actions on compactified braid varieties and polytopality of subword complexes

keywords: [braid variety, cluster dilation group, brick compactification, subword complex, Richardson variety]
related_paper: "Escobar 关于 brick variety 的构造（escobar）与 Pilaud--Stump 关于 brick polytope 及 double root free 词的工作（pilaud_stump_15, PilaudStump-EL）"
one_liner_summary: "本文证明辫簇的 cluster dilation 群作用总是可以扩展到每个 brick 紧化上，由此给出两个应用：闭 Richardson 簇上存在秩为 Kazhdan--Lusztig $d$-不变量的忠实环面作用；以及 brick 紧化为簇环面当且仅当词是 double root free——后者使 moment 多面体的极对偶实现对应的子词复形，从而在远超 root independent 词的范围内构造出球面子词复形的多面体实现。"

## 1.  核心定位

- **解决的问题**：设 $\mathcal A$ 是 Fomin--Zelevinsky 簇代数对应的簇簇，$\dil A$（由把每个簇变量送到自身标量倍的自同构组成）忠实代数作用于 $\mathcal A$；对部分紧化 $\mathcal A\hookrightarrow\overline{\mathcal A}$，问 $\dil A$ 的作用是否扩展为 $\overline{\mathcal A}$ 上的代数作用。一般答案是否定的（簇环面 $(\C^\times)^n$ 的紧化只有在环面簇时才为真），本文证明在两类重要情形下答案为肯定：简单 Lie 群的辫簇 + brick 紧化，以及旗簇中的开 Richardson 簇 + 相应闭 Richardson 簇。并利用该结果给出多面体实现与 Bruhat 区间分类两个应用。
- **大图景位置**：辫簇近年因与切触/辛几何、范畴化链环不变量、镜像对称、特征簇的联系而成为 Lie 理论的核心对象，其坐标代数带局部无环、真满秩的簇结构，使得 cluster dilation 群是秩等于冻结变量个数的环面；把作用扩展到紧化是"对称性是否能穿过紧化"这一簇几何的普遍问题，与 GHKK 的 broken line 凸集框架互为对照（本文的证明更初等、更显式，不用极小模型纲领的重机器）。在组合侧，Knutson--Miller 提出的球面子词复形多面体化问题是长期公开问题，本文把 Pilaud--Stump 的 double root free 条件识别为恰好的可解族，并给出维数高于 Coxeter 群秩的无穷多族实现。
- **主要贡献**：①证明 cluster dilation 群作用扩展到 brick 紧化 $\brick(\word i)$，且作用代数、忠实、只有有限个不动点；不动点与满足 $s_{i_{j_1}}\cdots s_{i_{j_k}}=\dem(\word i)$ 的子词 $\word j$ 一一对应，长度 $r-1$ 的这类子词给出 $\Pic(\brick(\word i))$ 的一组生成，$\dil{\word i}$-moment 多面体投影到（放大后的）brick polytope（Theorem intro_properties；对 Richardson 情形有完全平行的结论，不动点与 Bruhat 区间 $[v,w]$ 一一对应）；②证明"$\brick(\word i)$ 相对 $\dil{\word i}$ 是环面簇"与"$X(\word i)$ 是环面/簇代数无可变顶点/是 toric pair/词 double root free/无病态子词"等六条陈述等价，从而把环面性完全组合化（Theorem toric-brick-intro）；③主定理：词 double root free 当且仅当 $\brick(\word i)$ 的 $\dil{\word i}$-moment 多面体的极对偶实现子词复形 $\Delta(\word i,\dem(\word i))$，据此在 double root free 词的范围内得到球面子词复形的多面体实现（维数可超过 Coxeter 群秩），并说明 double root free 是 brick 方法可用的"最大合理范围"（$111$ 的反例给出 $\mathbb{P}^1\times\mathbb{P}^1$ 与 $\mathbb{P}^2$ 的差别）；④在 Richardson 侧给出 $\orich{v,w}$ 为环面、$\rich{v,w}$ 为环面簇、Bruhat 区间不含 $S_3$ 子区间、$[v,w]$ 是格、区间偏序集 $\mathrm{Int}_{v,w}$ 是格、$[v,w]$ 是多面体面格、$d_{v,w}=\ell(w)-\ell(v)$ 等九条等价（Theorem toric-richardson-intro），肯定回答了 Gorsky--Kim--Sherman-Bennett 的问题并推广到 $A$ 型之外。
- **关键先驱工作**：Fomin--Zelevinsky 的簇代数理论（FominZelevinsky-I）；Gross--Hacking--Keel--Kontsevich 的簇簇紧化框架（GHKK）与 Bossinger--Cheung--Magee--Nájera Chávez 的相关工作（BCMNC）；Escobar 的 brick variety 构造（escobar）；Pilaud--Stump 关于 brick polytope 与 double root free 词（pilaud_stump_15, PilaudStump-EL）、Pilaud--Santos 的 $A$ 型构造（pilaud_santos_12）；Casals--Gorsky--Gorsky--Leclerc--Shen--Simental 等关于辫簇的簇结构（CGGLSS）、Gorsky--Leclerc--Simental 系列（GLSB, GLSBS）；Knutson--Miller 的子词复形与多面体化问题（knutson_miller_04, knutson_miller_05）；Gorsky--Kim--Sherman-Bennett 的问题（GKSB）与 Barkley--Gaetz--Lam、Patimo 关于 $d$-不变量与簇结构秩的结果（BarkleyGaetzLam, patimo）；Dyer 未发表的 Bruhat 区间面格工作（Dyer_unpublished）；Euler--Fomin--Magee 型 log Calabi--Yau 对的概念（EFM/EFMS）。
- **结果边界**：主结果限定在有限型（简单 Lie 群/有限晶体 Coxeter 群）的辫簇与 brick 紧化，以及有限型的 Richardson/Bruhat 区间；对无穷型 Coxeter 群（如仿射）没有陈述。多面体实现只覆盖 double root free 词，作者明确指出这不解决广义 multi-associahedra（$k>1$ 的球面子词复形）的多面体化问题，且这一族只给出"brick 方法能触及的最大范围"，用初等等价变换之外还可能存在别的实现路径。Richardson 侧虽然给出九条等价，但 (c)$\Longleftrightarrow$(d)$\Longleftrightarrow$(f) 部分来自 Dyer 的未发表工作，本文的独立贡献主要在簇/环面结构与 (a)$\Longleftrightarrow$(b)$\Longleftrightarrow$(h)$\Longleftrightarrow$(i) 等条目。文中未证明 brick variety 与闭 Richardson variety 落入 GHKK/BCMNC 的 broken line 凸集框架，作者只把它作为预期与后续方向。
- **开放问题**：把 brick variety、闭 Richardson variety 纳入 GHKK/BCMNC 的极小模型框架（作者计划后续研究）；广义 multi-associahedra（$k>1$）是否也能由 brick/更一般的簇几何给出多面体实现；哪些凸多面体的面格同构于某个 Bruhat 区间（Theorem toric-richardson-intro 中 (f) 的反向问题）；投影 Richardson 簇的进一步应用与奇异闭 Richardson 簇的分解性质；double root free 之外的词能否通过非平凡初等变换获得实现。
- **应用与推广**：环面性等价把"$\brick(\word i)$ 是否为环面簇"化为对词 $\word i$ 的组合检查（等价于 double root free），并给出 $(\brick(\word i),\brick(\word i)\setminus X(\word i))$ 是簇型 log Calabi--Yau 对，从而可用 EFM 的定理间接得到等价性；Theorem toric-richardson-intro 给出 Bruhat 区间是否为凸多面体面格的完全组合判据（不含 $S_3$ 子区间），把 Gorsky--Kim--Sherman-Bennett 在 $A$ 型的结果推广到所有有限晶体型；由于 $\dil{\word i}$ 的秩可远大于极大环面 $T$ 的秩（如 $\SL_n$ 时 $T$ 秩 $n-1$，而 $\dil{\word i}$ 维数可达 $\binom n2$），本文把 $\brick(\word i)$ 作为 $\mathsf T$-簇的复杂度上界从 $\dim-\rank T$ 降到任一簇种子中可变变量的个数，为低复杂度簇的镜像对称与簇理论推广提供了更大的作用环面。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：cluster dilation 群的作用能否穿过紧化，本质上与"环面簇/对偶图"的边界除子组合学有关；这与用 skein 理论刻画量子簇图中的缺陷（Weyl defects）的技术处在同一族簇/辫结构上 — 见 [[2609.09308]]。
- [[2609.09308]]：Weyl defects in skein theory and quantum cluster charts — 同属"辫结构 + 簇图 + 环面/对偶图"的框架，该文对图表上的缺陷与量子簇图的分析与本文对 $\dil{\word i}$-moment 多面体边界除子的分析在组合层面可以互补。
- [[2609.10396]]：Cluster Morita theorem for negative cluster categories — 本文的 $\dil{\word i}$ 为无环种子下秩等于冻结变量数的环面，该文关于负簇范畴的 Morita 定理刻画了簇倾斜的等价关系，为比较不同词 $\word i$ 给出的 cluster dilation 群 $\dil{\word i}$ 提供范畴化语言。
- [[2609.09998]]：Toric degeneration for hybrid qudit spaces — 同样以环面簇与多面体/简并的语言处理具体几何对象；本文 brick 紧化在 double root free 情形是环面簇，其 moment 多面体正是 brick polytope，与该文"用环面簇简并刻画组合不变量"的思路一致，可互相参照构造。
- [[2609.09308]] 与 [[2609.10396]] 的共同提示：辫簇的簇结构不是孤立的——cluster dilation 群、可交换变量的冻结数、以及 brick 紧化的边界除子三者由同一个组合对象（词 $\word i$ 的双重根自由度）统一控制，这为其它紧化（如闭 Richardson 簇的分辨率）提供了"用词来读几何"的模板。
- 技术迁移：本文"先在单个簇中显式写作用、再验证它在所有簇图间的过渡映射下相容"的证明手法，可迁移到任何以簇结构定义的紧化问题上（例如其它 cluster variety 的 GHKK 紧化、$\mathsf T$-簇复杂度优化）；而"双重根自由度决定环面性"这一现象提示：凡簇变量的交换关系中出现 $xy=1$ 型病态（如 Example $111$ 中 $X(\word i)\cong\C^2\setminus\{xy=1\}$），紧化都不会保留整个作用环面。

### 2.2.  可以尝试的方向

- [ ] 对 $\SL_3,\SL_4$ 的全部短词 $\word i$ 枚举双重根自由度，与 brick polytope 的 $f$-向量及 $\dil{\word i}$ 的秩列表对照，验证 Theorem toric-brick-intro 的六条等价在计算上的可操作性。
- [ ] 用 Dyer 未发表的面格判据检查含有 $S_3$ 子区间的 Bruhat 区间在簇侧对应什么（是否存在 $\dil{v,w}$ 的忠实作用但无多面体实现）。
- [ ] 尝试把主定理从简单 Lie 群推广到不分裂/扭型（即非有限晶体型的 Coxeter 群）的辫簇，看 double root free 条件是否需要替换。
- [ ] 计算 $\dil{v,w}$ 与 $d$-不变量的关系在 $D$、$E$ 型中的具体表现，检验 $d_{v,w}=\ell(w)-\ell(v)$ 的等价如何与 $[v,w]$ 的格性质挂钩。

### 2.3.  批判性思考

- 主定理"double root free $\Longleftrightarrow$ 极对偶 moment 多面体实现 $\Delta(\word i,\dem(\word i))$"被作者解释为"brick 方法的最大合理范围"，但这一判断主要是通过 $111$ 等小例子的失效与"不用非平凡初等等价变换"的限制得出的，属于启发式论证（作者自己也在正文中使用"at least without using nontrivial elementary transformations"这样的限定语），不宜当作严格的最优性定理引用。
- 论文多处依赖"$\brick(\word i)$ 相对 $\dil{\word i}$ 是环面簇"与"$X(\word i)$ 是环面"的等价，其中 (a)$\Longleftrightarrow$(d) 也可以用 EFM 的 log Calabi--Yau 对理论经间接路径得到；两条路径的相互独立程度有限，读者应区分哪些等价是本文直接证明的、哪些是借道他人定理的。
- Richardson 侧的九条等价中，(c)$\Longleftrightarrow$(d)$\Longleftrightarrow$(f) 归于 Dyer 的未发表工作，本文的论证在文献上并不自足，这一点对引用者尤其重要。
- "不动点与满足 $\dem(\word j)=\dem(\word i)$ 的子词一一对应"以及 Picard 群的生成描述都建立在作用有有限个不动点这一强事实上；本文把有限性作为结论陈述，但该有限性本身在无限型或非晶体情形是否保持未被讨论，而这恰是向无穷 Coxeter 群推广时的卡点。
- 论文声称该方法"短而显式、不用极小模型纲领的重机器"是优点，但也意味着它没有把 brick 紧化与 Richardson 簇真正嵌入 GHKK/BCMNC 的框架——这既是简洁性的来源，也是后续工作（作者已声明）无法回避的缺口。
