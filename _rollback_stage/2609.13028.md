# Frobenius functors and one-sided Hopf algebras in braided monoidal categories

keywords: [单侧 Hopf 幺半对象, 对极, Frobenius 函子, Hopf 模, 编织幺半范畴]
related_paper: "Green, Nichols, Taft, One-sided Hopf algebras（自由单侧 Hopf 代数构造的源头）"
one_liner_summary: "在满足温和假设的编织幺半范畴中证明：双幺半对象是单侧 Hopf 幺半对象且其对极是双幺半对象反同态，当且仅当其自由 Hopf 模函子是 Frobenius 函子；并给出由余幺半对象构造自由单侧 Hopf 幺半对象的方案与若干非平凡编织下的例子。"

## 1.  核心定位

- **解决的问题**：把线性情形下「对极存在性 ⟺ 自由 Hopf 模函子的 Frobenius 性」这一对应关系，从向量空间范畴推广到一般的编织幺半范畴，同时给出编织情形下自由单侧 Hopf 幺半对象的一般构造。
- **大图景位置**：本文是 Saracco 关于对极与 Frobenius 函子对应关系工作的编织化推广（core 中反复引用 `Saracco-Frobenius`、`SaraccoAntipodes`），并把 Green–Nichols–Taft 的自由单侧 Hopf 代数构造从 \(\Vect\) 提升到任意带温和假设的对称幺半范畴。它填补的空白是：此前所有单侧 Hopf 代数的例子都活在平凡编织（flip）之下，本文说明单侧 Hopf 幺半对象在编织非平凡的语境中同样自然出现。
- **主要贡献**：
  1. 证明主定理：在容许自反对余等化子与余自反对等化子的编织幺半范畴中，若 \(B \ot -\) 保持自反余等化子，则「\(B\) 是右 Hopf 代数且右对极既反乘又反余乘」与「自由右 Hopf 模函子 \(- \ot B \colon \cM \to \cM^B_B\) 是 Frobenius」以及两条关于典范态射的条件互相等价；
  2. 在任意满足额外温和假设的对称幺半范畴中，给出由余幺半对象出发构造自由单侧 Hopf 幺半对象的方案（GNT 构造的范畴化），并说明该构造有时产出双边 Hopf 幺半对象、有时产出真正的单侧 Hopf 幺半对象；
  3. 给出若干编织非平凡的实例，例如以超向量空间范畴中的矩阵余代数 \(M_2(\K)\) 出发得到的一侧超 Hopf 代数 \(\rH\left(\mathrm{M}_2(\K)\right)\)。
- **关键先驱工作**：Green–Nichols–Taft 关于单侧 Hopf 代数的构造（core 中 `GreenNicholsTaft`）；Nichols 用 Bergman 菱形引理对 \(\mathrm{H}\left(\mathrm{M}_n(\Bbbk)^*\right)\) 的基与约化公式的计算；Takeuchi 的自由 Hopf 代数；Saracco 关于对极与自由 Hopf 模函子 Frobenius 性的对应；Berger–Saracco–Vercruysse 关于单侧 Hopf 代数与 gabi-代数（skew-closed 结构）的联系。
- **结果边界**：主定理要求范畴具有自反对的余等化子与余自反对的等化子，并要求 \(B \ot -\) 保持自反余等化子；自由构造一节则在对称（而非一般编织）幺半范畴中进行，作者在 Remark 中明确说明，若要把构造推广到非对称的编织范畴，必须全程照看编织与其逆，且此时得到的候选对极 \(S\) 只是幺半对象的反同态、未必是余幺半对象的反同态（反余乘性可能失效）。
- **开放问题**：core 中并未以 open question 形式列出问题；从 Remark `rem:brd_cop_is_bialgebra` 可见作者把「把第 3 节的构造推广到一般编织（非对称）幺半范畴，并厘清何时能同时得到反乘性与反余乘性」留作未走完的路线。
- **应用与推广**：单侧 Hopf 幺半对象能把幺半结构与闭结构沿遗忘函子提升到其模范畴，使 \(\prescript{}{H}{\cM}\) 成为 skew-closed 范畴且遗忘函子严格闭（gabi-单子视角）；这为在非对称编织（如超向量空间、Yetter–Drinfeld 型范畴）中构造新的 Hopf 型结构与积分理论提供了模板。

## 2.  理解辅助

- **贯穿例子**：以 \(H = \K \Z_2 = \K[g \mid g^2 = e]\) 的左余模范畴 \({}^H\mathfrak{M}\)（即 \(\Z_2\)-分次向量空间范畴，编织由 \(\brd(u\ot v)=(-1)^{\overline{u}\cdot\overline{v}}v\ot u\) 给出）为背景，取矩阵余代数 \(C = M_r(\K)\)（由 \(\delta(E_{ij}) = g^{i+j}\ot E_{ij}\) 赋予余模余代数结构），再对其应用自由单侧 Hopf 幺半对象的构造。这里编织非平凡这一点是关键：只有在它之下才会出现真正的单侧（而非双边）对极。
