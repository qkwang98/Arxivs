# On Donkin's Tilting Module Conjecture IV: New Frontiers

keywords: [Donkin 倾斜模猜想, Frobenius 核, 好 $(p,r)$-滤过, Jantzen 问题, Humphreys--Verma 猜想, 模表示论]
related_paper: "Bendel--Nakano--Pillen--Sobaje 关于倾斜模猜想的系列前作（本文引言引作 BNPS20，即首次给出反例的那一篇）"
one_liner_summary: "本文综述 Donkin 倾斜模猜想近年的转折：在已知多族反例的背景下重新表述 TMC 与 Humphreys--Verma 猜想，给出新的可检验猜想版本，并通过新计算证明 $\\Phi=A_4$、$p=2$ 的情形 TMC 成立。"

## 1.  核心定位

- **解决的问题**：倾斜模猜想（TMC）被推翻之后，如何界定它在何种范围仍然成立，并把"已被证伪的整体断言"替换为可检验的局部判据与修订版猜想。
- **大图景位置**：TMC 由 Donkin 在 1990 年提出，三十年间被视为代数群模表示论的中心问题之一，却在 2019 年被本文作者等人发现反例；本文处在这一转折之后的重整阶段，把 TMC 与 $(p,r)$-滤过猜想、Jantzen 问题、Humphreys--Verma 猜想放在同一框架下重新审视。
- **主要贡献**：①系统回顾 TMC 的两条证明路线——控制扩张群 $\Ext^1_{G_1}(L(\lambda),L(\mu))^{(-1)}$ 的 $G$-结构，或把它约化为有限多个表示论条件（好 $(p,r)$-滤过、Schur 代数上重数为 $0$ 或 $1$ 的条件）；②在反例族之外提出 TMC 的修订版本，并指出其在 $A_n$ 型的等价刻画；③给出 $\Phi=A_4$、$p=2$ 时 TMC 成立的新计算证据，并给出 $\Phi=A_n$ 情形应成立的理由。
- **关键先驱工作**：Donkin 1990 的 TMC 与 $(p,r)$-滤过猜想；Jantzen 1980 提出的问题；Andersen 关于 $\Ext^1$ 为倾斜模的界 $p\ge3h-3$ 及后续由其他作者降到 $2h-2$、$2h-4$ 的工作；Kildetoft--Nakano 与 Sobaje 关于 TMC 与好 $(p,r)$-滤过关系的定理；Donkin--Geranios 关于 $\Phi=G_2$、$p=2$ 时 Humphreys--Verma 猜想成立的结果。
- **结果边界**：TMC 本身为假，除 $A_n$ 型与 $B_2$ 外各不可约根系都存在反例；$(p,r)$-滤过猜想目前只在 $G=SL_2$ 得到验证；Humphreys--Verma 猜想对所有素数 $p$ 仍开放；本文关于 $A_n$ 型的结论是证据与等价刻画，而非 TMC 在该型的证明。
- **开放问题**：TMC 是否在 $A_n$ 型的所有特征 $p>0$ 下成立；Humphreys--Verma 猜想的一般情形；$(p,r)$-滤过猜想的验证范围能否扩大。
- **应用与推广**：把 $\Ext^1$ 的 $G$-结构与好 $(p,r)$-滤过相连的方法可迁移到其他 Frobenius 核与 Schur 代数设置；修订版猜想给出了可计算的检验入口，为逐型推进提供了操作路径。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：倾斜模这一概念在有限维代数与代数群两条传统中各自发展，公理化定义来自 Happel--Ringel 一派，而 Donkin 的猜想完全是后者的问题。
- [[2607.19945]]：该文研究 gentle 代数上倾斜模自同态代数的几何模型，同属倾斜模主题但处于箭图与有限维代数一侧，可与本文的代数群设置形成对照。
- [[2605141610]]：该笔记梳理余挠对与倾斜模公理化定义的来历，可作为"倾斜"概念另一条发展主线的入口，有助于理解本文为何用滤过而非三角范畴语言陈述问题。
- 技术迁移：用低秩扩张群计算加归纳构造无穷反例族的策略，是否可用于其他以"限制结构的可实现性"为核心的猜想？

### 2.2.  可以尝试的方向

- [ ] 能否把 $A_4$、$p=2$ 的验证方法推向 $A_n$ 的一般秩，使"证据"升级为定理？
- [ ] 修订版 TMC 对应的 Schur 代数重数条件，能否整理为一套可判定的算法判据？
- [ ] 能否把 $(p,r)$-滤过猜想的验证从 $SL_2$ 推进到更高秩，从而为 TMC 提供新的必要或充分条件？

### 2.3.  批判性思考

- 本文带有综述性质，主体内容多为新证据与新猜想，读者须严格区分已证定理与猜想，避免把 $A_n$ 型的证据读成结论。
- $A_n$ 型目前无已知反例，但"未有反例"不等于定理；作者通过 TMC 与 Schur 代数重数条件的等价性把难度集中，这一等价本身也需要逐条核对引用。
- 全文依赖前作链条较长（BNPS 系列、Andersen、Kildetoft--Nakano、Sobaje、Donkin--Geranios），验证路径较深，引用时须回到原始文献确认条件边界。
