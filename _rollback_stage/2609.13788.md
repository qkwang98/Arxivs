# Bicategorical Idempotent Completion

keywords: [idempotent completion, Cauchy completion, bicategory, absolute weighted colimit, 2-idempotent, Karoubi envelope]
related_paper: "Gaiotto--Johnson-Freyd 提出的 n-范畴 Karoubi 包络（本文在两范畴情形对其作了严格化）"
one_liner_summary: "本文在两范畴框架中严格定义并刻画了仿射/量子场论视角下的双范畴幂等完备化：证明对 Hom-范畴均幂等完备的局部幂等完备双范畴，其 Cauchy 完备化与幂等完备化等价，从而得到「该双范畴在绝对加权余极限下完备当且仅当它在 2-幂等元分裂下完备」，并顺带证明幂等完备化构成左伴随伪函子。"

## 1.  核心定位

- **解决的问题**：把 Gaiotto--Johnson-Freyd 提出的「n-范畴的 Karoubi 包络」在两范畴（bicategory）情形落成严格定义与万有性质，并说明它与 Lawvere 意义下（局部幂等完备双范畴的）Cauchy 完备化之间的关系。
- **大图景位置**：经典 1-范畴中「幂等完备化 = Cauchy 完备化」（Lawvere 的绝对余极限刻画、Karoubi 包络）是常识；本文追问这一等价在高一维是否仍成立，答案是在「Hom-范畴皆幂等完备」的局部幂等完备假设下成立。由此把 Lawvere 关于「绝对（加权）余极限完备 ⇔ 幂等分裂完备」的刻画，从以集合为 Hom 对象的富化情形推广到以幂等完备范畴为 Hom 对象的弱富化情形，处于近年一系列高阶完备化工作（等变完备、Euler 完备、orbifold 完备、n-范畴 Karoubi 包络）的核心位置。
- **主要贡献**：
  1. 按 Gaiotto--Johnson-Freyd 的提纲给出局部幂等完备双范畴的幂等完备化 $\Kar(\mathcal B)$ 的严格构造（对象为二元组 $(x,e)$，$e$ 为 $x$ 上的 2-幂等元），并证明其万有性质（对应 GJF 的相应定理）；为此发展了一套局部幂等完备双范畴的图解演算，用于简化相干性计算。
  2. 证明给定 2-幂等元的分裂在局部幂等完备双范畴中定义了一个加权余极限，并证明该分裂构成一个平凡 groupoid（trivial groupoid）；此处需要用到伪函子的扩张（细节置于附录）。
  3. 定义局部幂等完备双范畴的 Cauchy 完备化 $\mathcal B^{\mathrm{Cauchy}}$（沿绝对加权余极限）并证明其万有性质；进而证明主定理：$\Kar(\mathcal B)\simeq\mathcal B^{\mathrm{Cauchy}}$。由此得到「在绝对加权余极限下完备 ⇔ 在 2-幂等元分裂下完备」。
  4. 为使上述等价成立所需的若干陈述，作者在附录中给出 $\Cat$ 与 $\Cat_P$ 中加权余极限的显式构造；并顺带证明「对一个范畴取幂等完备化」定义了左伴随伪函子，其证明以 1-范畴情形作为脚手架。
- **关键先驱工作**：Lawvere 关于富化范畴 Cauchy 完备化与绝对余极限的刻画；Karoubi 的 K 理论导引（幂等完备化的原型与「包络」术语来源）；Gaiotto--Johnson-Freyd 关于 n-范畴 Karoubi 包络的工作（本文的直接源头与严格化对象）；一系列高阶完备化文献（等变完备化、局部幂等完备双范畴的幂等完备化、pivotal 2-范畴的 Euler 完备化、3-范畴的 orbifold 完备化）；双范畴与 $\Cat$-富化范畴的基础理论（Bénabou、Street、Kelly、Gray、Verity／Lack 关于双范畴的相干性理论）。
- **结果边界**：全部结果在「Hom-范畴皆为幂等完备范畴」的局部幂等完备假设下成立；一般双范畴（Hom-范畴不幂等完备）是否仍有一致的 Cauchy／幂等完备化刻画未作讨论。所有双范畴被假设为小范畴；加权余极限的显式构造被限制在 $\Cat$ 与 $\Cat_P$（小范畴、小余极限）中。文中同时说明 2-幂等元分裂所定义的是一类特殊的绝对加权余极限，反向的「绝对加权余极限 ⇒ 2-幂等分裂」需借助显式构造与局部幂等完备性。
- **开放问题**：作者未给出显式的 open problem 列表；但从框架的假设看，至少有三处自然延伸未被触及——去掉局部幂等完备假设后两 种完备化是否仍等价（若不等价，差别是否恰为 Hom-范畴的幂等完备化）；把「绝对加权余极限 ⇔ 幂等分裂」提升到三范畴（与 orbifold／Euler 完备化的统一描述）；把「幂等完备化为左伴随伪函子」升级为 2-单子结构以给出完备化的代数刻画。
- **应用与推广**：本文为高阶结构的「包络」提供了一条可操作的路线：把高阶幂等对象（如拓扑／共形场论中出现的 2-幂等体与缺陷数据）的存在性问题转化为绝对加权余极限的存在性问题，从而可以借用余极限的普遍技巧（预层化、局部化、完备化的万有性质）处理。技术上，局部幂等完备双范畴的图解演算、伪函子扩张以及「把 1-范畴情形作为脚手架」的证明策略，都可迁移到其它高阶万有性质的验证（例如 2-单子代数的完备化、高阶范畴的局部化构造）。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Karoubi 完备化（幂等完备化）在范畴语义与自动微分中的使用 — 见 [[2607.14453]]
- [[2607.14453]]：该文用 Karoubi 完备化把依赖的余切空间族嵌入普通非依赖范畴，并证明 $\Kar(\Copow_\kappa(\mathcal C))\simeq\Fam_\kappa(\mathcal C)$ 当且仅当 $\mathcal C$ 是 Cauchy 完备的；本文同样以幂等／Cauchy 完备化为核心杠杆，但研究对象从 1-范畴升到双范畴、幂等元从 1-幂等元变为 2-幂等元，两文可对照「完备性等价」这一命题在不同层级上的表述与代价。
- [[2609.16798]]：该文证明半闭 multicategory 的幂等分裂完备化必为闭 multicategory，并借此得到平面版 Scott 表示定理；本文的幂等完备化服务于 2-幂等元分裂与绝对余极限的等价，两文都把「分裂幂等」当作打破结构性障碍的杠杆，可比较分裂完备化在 operad 世界与双范畴世界中的作用方式。
- [[2609.17467]]：该文证明单对象生成的自由刚性幺半范畴存在阿贝尔包络、且该包络不具有商性质，属于高阶「包络／完备化」构造的另一支；与本文可对比「包络是否具有万有性质、是否可表示为某个伴随函子值」这类问题在不同结构上的答案差异。
- 技术迁移：本文为局部幂等完备双范畴发展的图解演算与伪函子扩张方法（用于证明 2-幂等元分裂构成平凡 groupoid），能否用于把本文主定理提升到三范畴，或用于验证其它高阶万有性质（例如 orbifold 完备化的万有性）？

### 2.2.  可以尝试的方向

- [ ] 去掉「Hom-范畴幂等完备」这一前提后，Cauchy 完备化与幂等完备化是否仍等价？若不等价，二者的落差是否恰可由 Hom-范畴的幂等完备化来度量？
- [ ] 把主定理推广到三范畴：绝对加权余极限完备与 3-幂等元分裂完备是否等价？若能，是否能统一刻画 orbifold／Euler 完备化？
- [ ] 「幂等完备化是左伴随伪函子」能否升级为 2-单子（或伪单子）结构，从而给出完备化的代数刻画与自由完备化的一般构造？

### 2.3.  批判性思考

- 主等价的证明路线是「先在 $\Cat$ 与 $\Cat_P$ 中显式构造加权余极限，再把构造搬到一般局部幂等完备双范畴」。这意味着结论在形式上依赖一套基于具体模型的具体构造，而局部幂等完备性是这套构造能够搬迁的前提；作者未讨论该前提在常见应用中（例如算子代数或 TQFT 中出现的双范畴）是否普遍满足，这可能限制结论的直接适用面。
- 「Cauchy 完备化 = 幂等完备化」在 1-范畴中几乎是标准事实，本文的实质推进在于把它在弱富化情形下严格化并给出万有性证明。因此从贡献结构看，最重要的部分或许是幂等完备化的万有性质证明与配套的图解演算，而非等价命题本身的陈述；读者若只看摘要，容易误判创新点所在。
- 「2-幂等元的分裂构成平凡 groupoid」这一关键步骤依赖伪函子扩张，证明细节被放到附录，正文只给出结论。对复核者而言，最需要检验的技术环节恰被移出正文，增加了独立验证的成本；同时，这一步也决定了「分裂是绝对加权余极限」论断的严格程度。
- 「幂等完备化构成左伴随伪函子」是文中一条较容易被忽略的副产物，作者明确说这是以 1-范畴情形作为脚手架得到的；但它其实给出了构造自由完备化与比较不同完备化的工具，文中对其用途的展开不足，略显可惜。
