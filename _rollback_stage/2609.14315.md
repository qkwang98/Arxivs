# Holomorphic polyvector fields on toric varieties via Klyachko filtrations

keywords: [toric variety, polyvector field, Klyachko filtration, Demazure root, Gerstenhaber algebra]
related_paper: "2609.06597（Permutation Representations on Cohomology of Toric Varieties）"
one_liner_summary: "本文用 Klyachko 相容滤链给出光滑完备 toric 簇上全纯多重向量场的权空间分解、维数公式与形式特征标公式，并统一恢复 Demazure 根与反规范截面的经典描述。"

## 1.  核心定位

- **解决的问题**：对 n 维光滑完备 toric 簇 X_Δ，统一而自足地描述各阶全纯多重向量场的整体截面空间 H^0(X_Δ, ∧^k T_{X_Δ})（0 ≤ k ≤ n），即给出其按 torus 权分解的显式组合公式。
- **大图景位置**：把此前彼此分离的结果——k=1 时的 Demazure 根描述、k=n 时反规范截面的格点多边形描述、以及 X=CP^n 情形的作者先期工作——收拢到 Klyachko 滤链这一个框架下；属于"推广 + 统一"型工作，同时为变形量子化与扩展变形理论中出现的多重向量场提供可计算的等变模型。
- **主要贡献**：1）证明权空间分解 H^0(X_Δ, ∧^k T_{X_Δ}) = ⊕_{u ∈ P_Δ ∩ M, i(u) ≤ k} χ^u ρ_N(N_u^k)，其中 N_u^k 由反规范多面体 P_Δ 上"接触射线"（满足 ⟨u, v_ρ⟩ = -1 的 ρ）张成的子空间 L_u 与 N_C 的外幂拼合而成；2）给出每个权空间的维数 C(n-i, k-i)（i 为该权所对应面的余维数）与整体维数的格点计数公式；3）导出形式特征标公式（权分解的生成函数重述）与仿射解释，并在 P^3 于一个 torus 不动点处的爆破上显式计算全纯向量场。
- **关键先驱工作**：Demazure 关于 toric 簇上全纯向量场非零权的刻画；Klyachko 用相容滤链描述等变 toric 向量丛；Cox 与 Fulton 关于 torus 不变除子截面的格点描述；作者关于 CP^n 上多重向量场的先期论文与两篇预印本（后者被 Deng–Hong 引用为其定理 1.1）。
- **结果边界**：主定理要求 X_Δ 光滑且完备，即扇 Δ 光滑完备；当 i(u) > k 时对应权空间取零，故只有满足 i(u) ≤ k 的格点 u 才有贡献；维数公式依赖反规范多面体 P_Δ 的面结构与各面相对内部的格点计数，其计算量随面结构规模增长。
- **开放问题**：作者指出，Filip 曾给出仿射 toric 簇 Hochschild 上同调 Hodge 分解的凸几何描述，并以此证明某些（可能奇异的）仿射 toric 簇的变形量子化存在性；如何把本文（仿射情形）的多重向量场组合描述与 Filip 的描述对接，从而以组合方式理解变形量子化，是作者明确提出且尚未解决的问题。
- **应用与推广**：该分解是 Gerstenhaber 代数（楔积与 Schouten–Nijenhuis 括号）层面上的等变权分解，可直接用于 Batalin–Vilkovisky 算子的显式计算；Mandel–Ruddat 关于整多重向量场空间 A = Z[N] ⊗ ∧^• M 的 BV 结构与其中子模的 L_∞ 结构，与本文的等变权分解互为补充，进而服务于热带与对数 Gromov–Witten 不变量中重数的计算；对镜像对称中复结构变形空间的研究亦提供了可算的局部模型。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Klyachko 型"除子—滤链"对应在等变上同调计算中的广泛应用 — 见 [[2609.06597]]
- [[2609.06597]]：该文研究 toric 簇上同调中的置换表示，与本文同处"toric 簇整体截面/上同调按 torus 权分解"这一主题；本文的 Klyachko 滤链恰可作为其技术上的对偶视角，两者可比对"组合数据到表示论结论"的两条不同路径。
- [[2607.25944]]：该文计算带停顿圆环的对称平方的 Hochschild 上同调；光滑情形下 Hochschild 上同调与多重向量场本为同一对象的两面，本文给出的权分解或可为其提供 toric 型的可算实例。
- [[2608.11376]]：该文在等变拓扑 Hochschild 同调中做具体计算，其"等变分解 + 同调计算"的方法论与本文"等变权分解 + 格点计数"的思路同构，二者的技术可相互借鉴。
- [[2607.17433]]：该文研究主丛模空间上的重合 Poisson 结构，正处在本文多重向量场与 Schouten–Nijenhuis 括号所服务的同一几何语境之中。
- 技术迁移：Klyachko 滤链把等变向量丛的整体截面转化为若干滤链层级的相交，这一技术原则上可迁移到更一般的等变层上（如带对数结构的环面簇、orbi-toric 情形），用以计算其多重向量场与相应形变空间。

### 2.3.  批判性思考

- 主定理把"求整体截面"转化为"求滤链各级的相交并对格点计数"，这已是相当范畴化的处理；但权空间维数 C(n-i, k-i) 依赖于"u 落在余维 i 的面的相对内部"这一分层，该分层是否具有不依赖坐标表述的内蕴刻画，值得进一步追问。
- 维数公式中 C(n-i, k-i) 的推导隐含了 dim_C L_u 恰等于 u 所在面的余维数这一步，核心文本未展开该验证，读者需回查原文以确认其成立所依赖的假设。
- 形式特征标公式本质上只是权分解的生成函数重述，作者并未借此推出新的表示论或几何结论，其价值更多在于计算上的便利，而非结构性洞察。

- 全文的关键在于"接触射线集合 A(u) 决定权的重数"这一观察。一个自然的疑问是：若把 torus 换成一般约化群、把 toric 簇换成球簇（spherical variety），A(u) 的角色是否由某个 Weyl 群轨道上的组合数据接替，从而得到同型的分解公式。
