# Goldman primes and higher cyclic presentations for the small finitistic dimension

keywords: [small finitistic dimension, Koszul grade, Goldman prime, n-presented module, idealization]
related_paper: "2609.07700（Quasi-projective dimension and Gorenstein projective dimension）"
one_liner_summary: "本文刻画了小有限投射维数在多项式扩张下的行为——Noetherian 环上由 Goldman 素谱而非极大理想谱检测，并构造大理想化局部环证明循环 n-表现条件在 n ≥ 2 时完全无法控制小有限投射维数。"

## 核心定位

- **解决的问题**：小有限投射维数 fPD(R)（由具有有限生成投射分解的模所实现的投射维数上确界）在两种"受限同调测试"下会发生多少损失：一是把环换成多项式扩张 R[X]，二是只允许用循环模作为测试对象。
- **大图景位置**：fPD 属于 Bass 所开创的有限投射维数族，但因采用"有限生成投射分解"的定义而特别适用于非 Noetherian 交换环上的同调代数；由于 fPD(R) 恰等于 R 的极大理想的 Koszul grade 上确界，本文实质上是研究 Koszul grade 在换环与限制测试类两种操作下的"逃逸"现象，否定了文献中一个关于循环 (n,d)-条件的开放问题的 n ≥ 2 情形。
- **主要贡献**：1）对 Noetherian 环 R 证明 R[X] 的极大理想恰好检测 R 的 Goldman 素理想，从而得到公式 fPD(R[X]) = 1 + sup{depth R_p | p ∈ GSpec(R)}，并证明对任意整数 N ≥ 1 都存在 Noetherian 局部环 R 使 fPD(R) = 0 而 fPD(R[X]) = N；同时给出一对相邻素理想 P ⊊ Q 满足 Kgr(P) = 0 而 Kgr(Q) = 2，说明高度一关系并不强加一步的 grade 上界；2）对任意 n ≥ 2 与 h ≥ 1 构造局部理想化环 T，使每个 n-表现循环 T-模都是投射模而 fPD(T) = h，并且 T 有有限生成的真理想 I 满足 Ext_T^i(T/I, T) = 0（0 ≤ i < h）而 Ext_T^h(T/I, T) ≠ 0，形成 n = 1 与 n ≥ 2 之间的尖锐分界。
- **关键先驱工作**：Glaz 关于小有限投射维数及有限投射分解类 FPR(R) 的框架；Bass 提出的有限投射维数族；Costa 的 (n,d)-环、Zhou 的弱版本（用平坦维数）与 Mahdou 的循环版本（只测试 n-表现循环模）所构成的层级；Kaplansky 关于 G-域的刻画（说明极大理想在 R[X] 中的收缩恰为 Goldman 素理想）；作者先前关于 fPD 可由 Koszul grade 读出、以及多项式扩张情形的若干结果。
- **结果边界**：多项式公式要求 R 为 Noetherian；Jacobson 情形只保证 fPD(R[X]) = fPD(R) + 1 这一加法形式，不能给出 GSpec 形式的精确表达；下界 fPD(R[X]) ≥ fPD(R) + 1 对任意交换环成立，但上界方向在非 Jacobson 环上需要 Goldman 素谱介入；循环情形的反例依赖大平方零理想化构造，环本身相当病态——没有非零真有限表现理想，故不适合作为"良性环"上的判据。
- **开放问题**：作者指出，循环弱 (n,d)-条件在 n = 1 时确实给出 fPD ≤ d 的控制，而 n ≥ 2 时该控制完全失效，这否定了文献中的相应开放问题；至于是否存在介于两者之间的、弱于 n-表现但仍能控制 fPD 的测试类，作者在文中未予回答，只留下该分界本身作为结论。
- **应用与推广**：该结果给出了"表现论可见性"与"同调深度"彼此分离的一般机制——用可数多个高度一商副本提供新坐标，使非零真理想无法有限表现，而高度一商又保留预先指定的 Koszul grade；这一机制可迁移到同调代数中其他"测试类受限"的场合（如相对同调维数、Gorenstein 投射维数在循环测试下的失效），亦为构造新的反例族提供了模板。

### 批判性思考

- 全文的两半由"可见性原理"统一起来，但该原理目前只是描述性口号，尚未被提炼成可证明的一般定理；若能把它形式化为关于"测试类与其所遗漏对象的对应"的命题，本文的构造将获得更广的适用范围。
- 循环情形反例所构造的环 T 没有非零真有限表现理想，这在某种意义上使定理显得"过于容易"——因为测试类本身被限制得极小。作者也承认 n-表现要求在层数增加时把反例推向越来越病的环，这说明结论的强度依赖于构造的病态程度，其哲学意味值得斟酌。
- 多项式情形中把检测器由 Max(R) 换成 GSpec(R) 的想法固然自然，但公式中出现的是 depth R_p（p 为 Goldman 素理想），而非这些素理想的 Koszul grade，这暗示两类不变量在 Noetherian 假设下恰好吻合，而这步吻合的证明是全文最需要外部结果支撑的一环。
