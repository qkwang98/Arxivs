# On the iso-Artinianness of one-dimensional Noetherian rings

keywords: [iso-Artinian ring, one-dimensional Noetherian ring, conormal module, finite length, associated prime]
related_paper: "2609.11003（On the transfer of Artinianess and Cohen-Macaulayness under module-finite extensions）"
one_liner_summary: "本文给出唯一极小素理想的一维 Noetherian 环为 iso-Artinian 的完整判别：等价于该素理想的局部化为零、其具有有限长度、以及余法模 p/p^2 无挠秩为零，从而正面回答了 Daneshvar–Divaani-Aazar 的问题 3.9。"

## 核心定位

- **解决的问题**：如何判别一个具有唯一极小素理想 p、且商环 D = R/p 为主理想整环的一维交换 Noetherian 环 R 是否为 iso-Artinian；并据此回答 Daneshvar 与 Divaani-Aazar 留下的问题 3.9。
- **大图景位置**：iso-Artinian 性由 Facchini 与 Nazemian 引入，是"把链条件中最终相等替换为最终同构"后得到的弱化版本，严格弱于 Artinian 性（例如任何非域的主理想整环都是 iso-Artinian 而非 Artinian）。Daneshvar 与 Divaani-Aazar 建立了交换 iso-Artinian 环的结构理论，其分解定理把"唯一极小素理想的一维 Noetherian 环"孤立为尚未解决的重要情形；本文正是填补这一空白的完整解答。
- **主要贡献**：1）证明主定理：在 R 为一维交换 Noetherian 环、唯一极小素理想 p、D = R/p 为主理想整环的前提下，下列条件等价——(i) R 是 iso-Artinian；(ii) pR_p = 0；(iii) p 作为 R-模具有有限长度；(iv) D-模 p/p^2 是挠模；(v) rank_D(p/p^2) = 0；(vi) 存在 s ∈ R \ p 使 sp = 0；并得到推论 R 非 iso-Artinian 当且仅当 rank_D(p/p^2) > 0；2）完全回答问题 3.9：在其假设 Min R ⊊ Ass R 之下，环为 iso-Artinian 恰好等于其幂零根具有有限长度，环为非 iso-Artinian 恰好等于其余法模具有正秩。
- **关键先驱工作**：Facchini 与 Nazemian 关于 iso-Artinian 模与环的三篇工作（2016、2017、2019）；Daneshvar 与 Divaani-Aazar（2025）关于交换 iso-Artinian 环的结构理论与问题 3.9；以及 Noetherian 环、有限长度模、局部化与 Artin–Rees 引理的标准结果（Atiyah–Macdonald、Eisenbud、Matsumura）。
- **结果边界**：定理限定在一维、唯一极小素理想、且商环 D 为主理想整环的 Noetherian 环这一狭窄类别内；当 D 只是一般整环或环的维数更高时，本判别不适用。作者特别指出，即便 D 是离散赋值环（DVR），正面与反面的例子都会出现，说明该判别并非依赖于 D 的 Noetherian 性之强弱，而是本质地取决于余法模 p/p^2 的秩。
- **开放问题**：本文把待解情形完全解决，未再留下新的公开问题；不过其判别式意味着一维情形完全由余法模（或等价地由 p 的有限长度性）决定，这自然引出多维或非主理想整环商的情形是否也存在类似的秩判据这一后续方向。
- **应用与推广**：判别条件 (ii)、(vi) 把抽象的同构链条件翻译为"存在局部化之外的一个元素消灭 p"这类可验证的方程条件，便于在同调代数与交换代数中检验具体构造；iso-Artinian 性作为 Artinian 性的弱化，其对偶（iso-Noetherian 型条件）在模的稳定同构范畴中亦有对应，本文所用的"链的最终同构由余法模的挠性检测"这一机制可迁移到稳定范畴与导出范畴中的相应链条件研究。

## 主动思考区

### 与其他工作的联系

- 这让我想起：把抽象链条件下沉为有限长度或挠性等具体不变量的一般策略 — 见 [[2609.11003]]
- [[2609.11003]]：该文研究模有限扩张下 Artinian 性与 Cohen–Macaulay 性的转移，与本文同处"链条件在环扩张/局部化下如何传递"这一主题；本文条件 (ii) pR_p = 0 正是局部化使某类性质退化到极端的表现。
- [[2608.09701]]：该文给出交换 Artinian 环上的 Tor 与 Ext 消没结果；由于 iso-Artinian 是 Artinian 的弱化，该文的消没定理在本文所刻画的环类上何时仍成立，是一个自然的对照问题。
- [[2609.10295]]：该文讨论具有有限投射维数的 Cohen–Macaulay 模的 Hilbert 系数界，其中"用维数与重数刻画同调性质"的思路与本文"用 rank_D(p/p^2) 这一维数型不变量刻画 iso-Artinian 性"的做法同型。
- 技术迁移：本文把"链的最终同构"归约为"极小素理想 p 的局部化是否为零"，这一归约是否可用于稳定模范畴（即允许模同构而非相等）中的链条件，例如稳定 Artinian 性、稳定 Noetherian 性的判别，是值得尝试的迁移方向。

### 可以尝试的方向

- [ ] 当 D = R/p 不是主理想整环（例如只是一维 Noetherian 整环，或 Dedekind 但非主理想）时，等价条件表应如何修改？是否仍由余法模的秩主导？
- [ ] 对维数 ≥ 2 的环，存在唯一极小素理想时是否还能建立同型的等价刻画？此时可能需要引入高阶余法模（如 p/p^2 之外的同调层）。
- [ ] iso-Noetherian 型条件（递增链的最终同构）在一维 Noetherian 环上是否也有类似判别？

### 批判性思考

- 主定理的六条等价条件实质上围绕同一个现象展开：iso-Artinian 性等价于极小素理想在局部化后消失。这使得定理虽完整，却揭示该环类的判别完全由"p 是否被某个局部化外的元素消灭"这一单一机制主导，未能反映更一般的 iso-Artinian 结构理论。
- 问题 3.9 的原始表述询问在 Min R ⊊ Ass R 下是否必然 iso-Artinian，本文答案是否定的，并指出成败取决于幂零根是否有限长。这一回答依赖于把 R 的结构拆分为幂零部分与既约部分，而该拆分对一般交换环是否同样有效，是隐含在论证中的一个假设。
- 作者强调即便 D 为 DVR 也存在正反例，这说明"主理想整环商"这一假设本身并不带来实质简化，反过来提示定理的强项其实在于条件 (vi) 这类极易检验的代数表述。

- 从更广的视角看，本文的处理方式是把同调型的链条件"参数化"为余法模的秩，这种思路与形变理论中用切空间/障碍空间刻画形变族的方式颇为相似，两者是否共享一个更上层的框架（例如用模的截断或滤链来统一描述链条件与形变），是一个有趣的方向。
