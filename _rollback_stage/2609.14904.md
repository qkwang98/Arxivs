# Geometric Invariant Theory for Affine Superschemes

keywords: [仿射超概形, Hopf 超代数, 超几何不变量理论, Hilbert–Mumford 判据, 超商, 超箭图]
related_paper: "King 关于箭图表示模空间的几何不变量理论构造（本文的直接原型）"
one_liner_summary: "本文以坐标 Hopf 超代数的余作用为语言，为约化代数超群作用下的仿射超概形建立了几何不变量理论，构造了仿射超商，并在两条结构条件下证明了 Hilbert–Mumford 判据的超几何版本，使（半）稳定性化为纯数值检验。"

## 核心定位

- **解决的问题**：如何在仿射超概形上建立几何不变量理论，即在约化代数超群作用下构造定义良好的超商，并给出（半）稳定性的可计算判据。由于反交换且幂零的奇坐标存在，超概形的点一般不能像通常概形那样当作拓扑空间的普通点来处理，因此群作用与商必须完全在坐标超代数层面通过余作用对偶地描述。
- **大图景位置**：本文把 Mumford 的经典几何不变量理论与 King 的箭图表示模空间构造推广到超对称情形。作者指出，Amrutiya–Dubey 的并行工作处理的是普通代数群的作用，而本文处理一般约化代数超群的作用；当作用超群的奇维数为零时，前者的框架恰是本文的特例，故本文是严格推广。
- **主要贡献**：
  1. 以坐标 Hopf 超代数的余作用为语言，把代数超群在仿射超概形上的作用代数化，定义并构造仿射超商，在适当假设下证明其存在性与基本结构性质。
  2. 证明 Hilbert–Mumford 判据的超几何类比：在"奇部无穷小解耦的余作用"与"多项式余扩张"两条结构条件下，把点的半稳定性与稳定性转化为纯数值检验。
  3. 用该数值判据构造这些超概形的超几何不变量理论商，并给出例子展示超几何商与经典商的差异。
- **关键先驱工作**：Mumford 的几何不变量理论；King 用几何不变量理论构造并分类箭图表示模空间的工作，以及由此得到的射影环面簇、箭图旗簇、Mori 梦想空间等显式模空间实现；Van den Bergh 的非交换 crepant 消解；Ishii–Ueda 的二聚体模型；Leites、Manin、Kapranov–Vasserot、Bruzzo–Hernández-Ruipérez–Polishchuk 等关于超概形的奠基工作；Fan–Jarvis–Ruan 与 Favero–Kim 对 gauged linear sigma model 的代数化；Amrutiya–Dubey 的并行工作。
- **结果边界**：主定理依赖两条额外条件（奇部无穷小解耦的余作用、多项式余扩张），它们限定了可用几何论证成立的场景。没有这些条件，偶部与奇部变量之间的耦合会给"取极限"带来本质障碍，Hilbert–Mumford 判据的经典证明无法直接照搬。
- **开放问题**：把两条结构条件减弱到更一般的余作用；把理论推广到投影超概形与更一般的作用；作者列出的后续计划包括超箭图的表示模空间、Hilbert 超概形、Kronheimer 构造的超几何类比以及 Nakajima 箭图超簇。
- **应用与推广**：本文为超箭图表示模空间的构造提供了基础工具，目标之一是给出与 gauged linear sigma model 中"经典五次 Calabi–Yau 超曲面与投射超空间 $\mathbb{P}^{4|1}$ 对偶"相匹配的严格几何框架。在表示论一侧，作者在姊妹论文中证明射影超空间上例外线丛生成的导出范畴与"截面箭图"恰为超箭图，因此本文的数值判据是构造相应模空间的前置条件。

### 批判性思考

- 两条结构条件是本文最强的人为假设，它们既限制适用面，也令人怀疑定理是否只是"条件化"的经典结果；作者未给出条件必然成立的充分判据，例如哪些自然的超群余作用自动满足解耦性。
- 论证完全依赖坐标超代数层面的对偶化描述，几何直观被压到最低。若能为超概形补充某种"超点"的动力学刻画，或许可以像经典情形那样给出更透明的稳定性图像。
- 与 Amrutiya–Dubey 工作的关系处理得较为克制，仅在引言中说明包含关系；两套框架在例子层面的差异比较（而非仅仅包含关系）可能更具说服力。
