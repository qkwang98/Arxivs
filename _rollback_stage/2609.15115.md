# New runner removal theorems for the cyclotomic Hecke algebras of type $G(r,1,n)$

keywords: [分圆 Hecke 代数, Ariki--Koike 代数, $v$-分解数, 算盘展示, Uglov 映射, 移除算珠定理]
related_paper: "James--Mathas 关于 Iwahori--Hecke 代数 $\H_q(\Sym_n)$ 的「空算珠移除」定理（本文在分圆情形的推广原型）"
one_liner_summary: "本文借助 Uglov 映射把 James--Mathas 的空算珠移除定理与 Fayers 的满算珠移除定理从对称群的 Iwahori--Hecke 代数推广到型 $G(r,1,n)$ 的分圆 Hecke 代数：在 $r$-划分的算盘上定义「加空算珠」与「加满算珠」，证明相应的 $v$-分解数在 $e$ 与 $e+1$ 之间保持不变，并给出 Specht 模与单模之间复合重数的等式。"

## 核心定位

- **解决的问题**：如何在分圆 Hecke 代数 $\H_{r,n}$（即 Ariki--Koike 代数）的层面，比较不同量子特征 $e$ 与 $e+1$ 下的 $v$-分解数，并把 level one（对称群）情形中著名的「算珠移除」现象推广到 level $r$。
- **大图景位置**：这是 modular 表示论中 James--Mathas 空算珠移除定理与 Fayers 满算珠移除定理在分圆 Hecke 代数上的推广。作者强调，已有的若干推广（如 Dell'Acqua、Du--Park、秦）都是直接在给定的 $r$-划分各分支分量的 $e$-算盘上操作，而本文的新意在于通过 Uglov 映射统一实现「加空算珠」与「加满算珠」，因而在框架上不同于前人。
- **主要贡献**：
  1. 利用 Uglov 从「$r$-划分的 $r$-算盘」到「划分的 $e$-算盘」的映射，在 $r$-划分设定下定义「加空算珠」（定义 \ref{lamPlus}）与「加满算珠」（定义 \ref{Plusk}）。
  2. 分析这两类操作诱导的 Fock 空间映射下典范基元素的像（命题 \ref{KeyCanonicalBases} 与 \ref{KeyCanonicalBases2}），这是证明两条主定理的技术核心。
  3. 主定理一：对 $0 \le \alpha < e$ 与 $r$-划分 $\bmu$，在 $\bmu$ 为 $(e,\bs)$-正则等假设下，$\bmu^{+}$ 为 $(e+1,\bs)$-正则，且 $d^{e,\bs}_{\blam\bmu}(v) = d^{e+1,\bs}_{\blam^{+}\bmu^{+}}(v)$，特别地得到 $[S^\blam : D^\bmu] = [\hat{S}^{\blam^{+}} : \hat{D}^{\bmu^{+}}]$。
  4. 主定理二：在条件 $(k-1)e \ge s_r + n$ 下，把上述等式推广到「加满算珠」版本，即 $d^{e,\bs}_{\blam\bmu}(v) = d^{e+1,\bs^{+k}}_{\blam^{+k}\bmu^{+k}}(v)$ 及相应的 Specht 模、单模复合重数等式。
- **关键先驱工作**：Ariki--Koike 与 Broué--Malle 对分圆 Hecke 代数的奠基定义；Ariki 定理（又称 Ariki--Lascoux--Leclerc--Thibon 理论）与 Lascoux--Leclerc--Thibon 猜想；Brundan--Kleshchev 关于分块与分圆箭图 Hecke 代数、分次分解数的结果；James--Mathas 的空算珠移除定理与 Dipper--James $q$-Schur 代数版本；Fayers 的满算珠移除定理；Jacon--Lecouvey 关于 Uglov 映射与 $(e,\bs)$-核的观察。
- **结果边界**：定理的表述要求 $\bs$ 落在 $\tilde{\mathcal A}^r_e(\bmu)$ 中，并在同一分块假设下成立；主定理二额外要求 $(k-1)e \ge s_r + n$。作者指出该不等式不构成实质限制，因为 $\H_{r,n}^{\Lam_\bs}$ 只依赖 $e$ 与重集 $\{s_j+e\Z\}$，可通过对 $s_j$ 平移 $te$ 而不改变代数与模来满足条件。切分策略仍限于「加空算珠」与「加满算珠」两类，尚不覆盖其他形式的算盘操作。
- **开放问题**：作者未集中列出开放问题，但行文中指出其定义与前人「逐分量 $e$-算盘」的定义不同，暗示两类构造之间的比较与统一仍待澄清；此外，如何把该定理与分块移动向量、Scopes 等价、core 分块分类等近期成果进一步结合亦为自然追问。
- **应用与推广**：$v$-分解数实际上是抛物 Kazhdan--Lusztig 多项式的逆，因此本文的等式可看作分圆设定下分解数在「算珠操作」下的不变性，为分块不变量、仿射 Hecke 代数、李型有限群的模表示论与仿射量子群（通过分圆箭图 Hecke 代数的分次分解数）之间的翻译提供了新的计算手段。结合 Li--Tan、Li--Qi--Tan 关于 core 分块与 Scopes 等价的工作，该结果有望用于缩减高秩分解数的计算复杂度。

### 批判性思考

- 全文的技术重心落在两条命题（典范基元素在诱导映射下的像），其对 Uglov 映射组合性质的依赖较重；若能给出更概念化的、不依赖算盘显式坐标的证明（例如经由分圆箭图 Hecke 代数的分次范畴化），结论的适用范围可能更清晰。
- 与前人「逐分量算盘」定义的差异是本文反复强调的卖点，但两类定义在具体例子下的异同并未展开比较，读者难以判断新旧定义之间的真正关系。
- 条件 $(k-1)e \ge s_r + n$ 的「无关紧要」依赖于荷可以向 $s_j+te$ 平移这一自由度，这一论证在具体计算中最优平移的选取上仍留有不小的操作空间，可能影响实际可用性。
