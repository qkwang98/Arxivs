# On $\boldsymbol{p}$-rationality in double covers of symmetric and alternating groups

keywords: [p-理性特征标, spin 特征标, 对称群双覆盖, Galois–McKay 猜想, p-bar core tower]
related_paper: "Michler–Olsson, 关于对称群 Sylow 正规化子的 spin 表示"
one_liner_summary: "本文对奇素数 $p$ 为对称群与交错群的双覆盖 $\widetilde S_n$、$\widetilde A_n$ 建立了 $p'$-次数 spin 特征标与其 Sylow $p$-子群正规化子之间的双射，该双射与 spin 特征的相伴关系相容且等变于探测 $p$-理性的 Galois 子群 $G(p)$，并进一步给出高度零 spin 块与其 Brauer 对应块之间的分块加细。"

## 1.  核心定位

- **解决的问题**：为奇素数 $p$，在对称群与交错群的双覆盖 $\widetilde S_n$、$\widetilde A_n$ 上，构造 $p'$-次数 spin 不可约特征标与其 Sylow $p$-子群正规化子 $N=\operatorname{N}_{\widetilde S_n}(P)$ 的 $p'$-次数 spin 不可约特征标之间的双射，使该双射与 spin 特征的相伴关系相容、并且在探测 $p$-理性的 Galois 子群 $G(p)$ 下等变；等价地，说明全局一侧与局部一侧的 $p$-理性 $p'$-次数 spin 特征标个数相等。
- **大图景位置**：Galois–McKay 猜想（由 Navarro 提出）是 McKay 猜想在 Galois 层面的加细，而 McKay 猜想本身已由 Cabanes 与 Späth 完成证明。本文把这条纲领推进到对称群与交错群的双覆盖（即 spin 情形），与作者此前对交错群建立的 Galois 等变 McKay 对应、以及关于 spin 特征标上 Galois 作用与 Littlewood 分解相容性的研究，构成一条连续的工作线。
- **主要贡献**：
  1. 主定理：对奇素数 $p$ 给出 $\operatorname{Irr}^{\mathrm{spin}}_{p'}(\widetilde S_n)$ 与 $\operatorname{Irr}^{\mathrm{spin}}_{p'}(N)$ 之间相伴相容、$G(p)$-等变的双射 $\Omega$；$\widetilde A_n$ 的类似结论由 Clifford 理论得到；
  2. 显式化局部一侧的组合参数化：把 Michler–Olsson 工作中隐含的组合描述写明白，并修正其局部构造中未覆盖全部所需表示的实质性缺口（需要允许非线性初等表示）；
  3. 给出高度零 spin $p$-块与其 Brauer 对应块之间的分块版本定理。
- **关键先驱工作**：Navarro 的 Galois–McKay 猜想；Cabanes–Späth 对 McKay 猜想的证明；Navarro–Späth–Vallejo 的归约定理与 Ruhstorfer–Schaeffer Fry 对 Isaacs–Navarro 猜想的证明；Michler–Olsson 关于 Sylow 正规化子 spin 表示的工作；作者此前关于交错群 Galois 等变 McKay 对应以及 spin 特征标 Galois 作用的文章。
- **结果边界**：全文假设 $p$ 为奇素数，处理的对象是次数与 $p$ 互素的 spin 特征标；结论依赖 bar 分拆的 $p$-bar core tower 这一组合参数化，因此适用范围限于双覆盖的 spin 表示框架；分块版本只针对高度零特征标，未涉及正高度情形。
- **开放问题**：正文没有集中列出开放问题清单；自然的延伸方向是 $p=2$ 的情形（此时探测 $p$-理性的子群与 Isaacs–Navarro 框架中的子群差异更大），以及把等变对应从 $p'$-次数推广到更一般的块或更一般的中心扩张。
- **应用与推广**：$G(p)$-等变性使对应在 $p$-理性特征标层面逐项匹配，这为计算 $\widetilde S_n$ 的 $p$-理性 spin 特征标、以及 $\widetilde A_n$ 的相应计数，提供了从结构更简单的局部对象（Sylow 正规化子）出发的途径；论文中「用射影扩张的因子集显式控制自伴情形」以及「用同一套组合数据同时参数化全局与局部」的技术，对研究其它双覆盖或中心扩张的特征标表亦有参考价值。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：在算盘（abacus）上做算珠移除与 core 塔推广的那类工作 — 见 [[2609.15115]]
- [[2609.15115]]：该文借助 Uglov 映射把空算珠移除定理与满算珠移除定理推广到 $G(r,1,n)$ 的分圆 Hecke 代数；本文全局一侧的参数化同样以「bar 分拆的 $p$-bar core tower」这类算珠/分拆组合数据为坐标，两篇共享「用 core 塔组织表示论参数」的母题，区别在于本文还需要额外追踪 Galois 作用与相伴关系。
- [[2609.13905]]：该文用多重分拆与 $k$-core 的组合学刻画圈积特征标表零元个数的渐近；本文的 $p$-bar core tower 与那里的 $k$-core 多重分拆属同一族分拆组合工具，可用作「core 限制下计数的难易程度」的对照。
- 技术迁移：本文用「同一套组合数据同时参数化全局与局部」来制造等变双射的策略，可迁移到其它 Galois 加细问题——只要两侧的不可约对象都能被同一族组合对象标号，且 Galois 作用能被同一个奇偶不变量（此处为 $\beta\,\ell(\lambda_\beta^{(0)})\bmod 2$）控制，就有机会复制这一路线。

### 2.3.  批判性思考

- 作者指出 Michler–Olsson 的局部构造存在超出排印错误的缺口，并称本次修正可能有独立价值；这也意味着局部一侧的表示论高度依赖构造细节，读者宜对照原始文献判断哪些修正只是补上缺失的初等表示、哪些改变了原有参数化。
- 全局与局部的 Galois 指数被证明一致，但两侧计算路径截然不同（全局侧依赖分拆的组合递推，局部侧依赖诱导与射影扩张的因子集）；这种「殊途同归」在缺少统一范畴化语言的当下虽属常态，却也提示可能存在更概念化的证明。
