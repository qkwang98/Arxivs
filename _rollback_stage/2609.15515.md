# Coherent presentations for stylic monoids via row rewriting

keywords: [stylic 幺半群, $N$-tableau, 凝聚展示, 高维重写, polygraph, 同伦基, 凝聚 Tietze 变换, Squier 凝聚定理]

related_paper: "Gaussent--Guiraud--Malbos, 关于幺半群凝聚展示与 Tietze 变换的工作（本文所引 GaussentGuiraudMalbos15）"

one_liner_summary: "本文从高维重写的视角研究 stylic 幺半群：以 $N$-tableau 模型和已知的有限收敛行展示为起点，为每个临界分支添加生成合流 3-胞腔得到有限凝聚展示，再经两次同伦约简与凝聚 Tietze 变换，把构造从行生成元转移到标准字母生成元，从而给出标准字母展示的一个可有效计算的有限同伦基。"

## 核心定位

- **解决的问题**：一个幺半群的展示只记录定义关系；凝聚展示还要求记录"关系之间的关系"。对 stylic 幺半群，此前已知其行展示有限且收敛，但尚未有显式构造的有限凝聚展示与有限同伦基。
- **大图景位置**：它是 Squier 凝聚定理在具体组合幺半群族上的落地：把"收敛展示可扩张为凝聚展示"的一般框架，与 $N$-tableau 的组合学（行插入、行之间的支配关系）结合起来，并进一步完成生成元切换（行生成元到字母生成元）这一通常最为繁琐的步骤。
- **主要贡献**：
  1. 证明行展示 $\Sigma^{\mathrm{row}}(n)$ 的临界分支恰由满足 $u\not\triangleleft v$ 且 $v\not\triangleleft t$ 的临界三元组 $(u,v,t)$ 给出，并证明任一分支经初始一步后至多再走两步即到达共同正规形，且正规形至多含三行。
  2. 为每个临界分支显式给出生成合流 3-胞腔 $\mathcal{X}_{u,v,t}$，由 Squier 凝聚定理得到有限凝聚展示 $\Sigma^{\mathrm{row,coh}}(n)$，即 stylic 幺半群 $\operatorname{Styl}_n$ 的一个凝聚展示。
  3. 给出生成胞腔数目的封闭公式：1-胞腔 $2^n-1$ 个；2-胞腔 $\frac{2^{2n+1}-2^{n+1}-3^n+1}{2}$ 个；3-胞腔 $\frac{6\cdot 8^n-6^{n+1}-5\cdot4^n+3^{n+1}+3\cdot2^n-1}{6}$ 个（命题 Prop:CountingCells），并列出 $n\le 6$ 的数值表。
  4. 先用两次适配行组合学的同伦约简简化凝聚展示，再通过凝聚 Tietze 变换与进一步的同伦约简，把构造从行生成元搬运到标准字母生成元，得到标准字母展示的一个有限、可有效计算的同伦基；构造在秩 $n=2$ 时被详细图示。
- **关键先驱工作**：Squier 的凝聚定理与同调有限性理论；Guiraud--Malbos 以及 Gaussent--Guiraud--Malbos 关于 polygraph、凝聚展示与凝聚 Tietze 变换的系列工作；stylic 幺半群的 $N$-tableau 模型与有限收敛行展示（Godelle--Novelli 一系的结果）。
- **结果边界**：构造针对有限秩 $n$ 的 stylic 幺半群；前提是行展示的终止性与合流性（收敛性），该性质本身来自已有工作。胞腔数目随 $n$ 指数增长（$n=6$ 时 3-胞腔已达 212471 个），故"有限"与"可有效计算"并不等同于"规模小"。
- **开放问题**：本文以构造与计数为主，未显式列出开放问题；可注意的遗留方向是：把"行生成元到字母生成元"的同伦约简与 Tietze 搬运流程系统化，以便应用于其他具有行/表模型的重写系统。
- **应用与推广**：显式同伦基给出的是 3-胞腔级别的同调信息，可用于研究该幺半群（及其相关代数结构）的同调有限性与 $K(\pi,1)$ 型性质；同时，行重写与 $N$-tableau 的组合技术可迁移到其他以"行"为生成元的组合幺半群（例如相关的一类 J-平凡幺半群与 0-Hecke 型结构）。

## 主动思考区

### 与其他工作的联系

- 这让我想起：[[2607.28540]] — 该文用代数 coherator 与 computad 给出"由生成元/关系谱系定义的弱结构"的统一同伦代数工具，并以同伦假说为目标；本文的 polygraph 与凝聚展示正是这类工具在幺半群层面的组合化身，两者可以看作同一"coherence 工程"的代数端与组合端。
- [[2607.24476]]：该文以 $(d+1)$-余骨架刻画 $d$-Segal 条件，其开放问题提到"Wiggle 引理在 polygraphic 同伦论中是否有对应"——这与本文所处的高维重写/polygraph 世界直接相通，说明 polygraph 与高阶 Segal 条件之间可能存在尚未开发的词典。
- 技术迁移：本文"先构造凝聚扩张、再做同伦约简以消去冗余 3-胞腔"的流程，能否移植到群或其他算子代数（如 operad、monoidal category）的展示上，从而给出同一家族结构的统一同伦基？

### 可以尝试的方向

- [ ] 定理中的胞腔计数公式是否具有组合上的组合解释（例如与 $N$-tableau 的某类统计量对应），从而可用于猜测一般"表型幺半群"的胞腔数？
- [ ] 把生成元从行切换到字母的同伦约简是否可以抽象为一个关于 $2$-polygraph 的通用定理，使任何行展示收敛的幺半群都自动获得字母展示的有限同伦基？

### 批判性思考

- 由于 $\mathcal{X}_{u,v,t}$ 的数量随秩指数增长，构造虽然有限，但对较大的 $n$ 难以实际枚举；作者通过同伦约简压缩了展示，却未给出约简后胞腔数的封闭下界，因此"约简到底压缩了多少"这一问题并未被量化。
- 临界分支的显式合流依赖对插入顺序（按增序插入 $d$ 的字母）的细致追踪，这类论证可读性较差；是否存在更范畴化的方式，把行插入的单调性直接翻译成 3-胞腔上的交换性条件？
