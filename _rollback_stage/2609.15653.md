# Mixing Extriangulated Model Structures

keywords: [extriangulated category, proper class, mixed model structure, cotorsion pair, weakly idempotent complete]
related_paper: "Cole 混合定理（Mixing model structures，Cole 2006）"
one_liner_summary: "本文在弱幂等完备的 extriangulated 范畴中，把 Cole 的混合定理推广到相对两个相容 proper class 的 admissible 模型结构：保持一个模型结构的弱等价与另一个的纤维化（或余纤维化），得到混合 admissible 模型结构，并给出混合 cofibrant 对象关于原两个模型结构的显式刻画。"

## 1.  核心定位

- **解决的问题**：在弱幂等完备的 extriangulated 范畴 $(\mathscr{C},\mathbb{E},\mathfrak{s})$ 中，给定两个相对不同 proper class 的 admissible 模型结构，如何把它们混合为一个新的 admissible 模型结构，并把该混合结构的 cofibrant 对象用原有结构具体描述出来。
- **大图景位置**：把 Quillen 模型范畴、Hovey 的 abelian 模型结构与相容完全 cotorsion 对、Gillespie 的正合范畴模型结构这一条线索，推进到 Nakaoka--Palu 的 extriangulated 范畴与相对同调代数（proper class、相对 cotorsion 对）的框架中；正合范畴与三角范畴的情形都是本文结果的特例，因此它是 Cole 混合定理在相对扩张结构下的推广。
- **主要贡献**：
  1. 设 $\xi_1\subseteq\xi_2$ 为 $\mathbb{E}$-三角的两个 proper class，且 $\mathcal{M}_1=(\mathcal{C}_1,\mathcal{W}_1,\mathcal{F}_1)$ 与 $\mathcal{M}_2=(\mathcal{C}_2,\mathcal{W}_2,\mathcal{F}_2)$ 分别相对 $\xi_1$、$\xi_2$ admissible，$\mathcal{W}_1\subseteq\mathcal{W}_2$。若 $\mathcal{F}_1\subseteq\mathcal{F}_2$，则存在相对 $\xi_1$ 的 admissible 模型结构 $\mathcal{M}_m=(\mathcal{C}_m,\mathcal{W}_2,\mathcal{F}_1)$；对偶地，若 $\mathcal{C}_1\subseteq\mathcal{C}_2$，则存在相对 $\xi_1$ 的混合结构 $\mathcal{M}_m=(\mathcal{C}_1,\mathcal{W}_2,\mathcal{F}_m)$。
  2. 给出混合 cofibrant 对象的内在刻画：$C\in\mathcal{C}_m$ 当且仅当 $C\in\mathcal{C}_1$ 且存在某个 $C_2\in\mathcal{C}_2$ 与一个 $1$-弱等价 $C_2\longrightarrow C$；并且该弱等价可以取为 $\xi_2$-deflation。
  3. 把构造专门化到正合范畴与三角范畴，恢复正合模型结构的相应混合定理，并用有限乘积导出范畴中与 smashing 直和项相联系的 proper class 严格链构造出显式的非退化例子。
- **关键先驱工作**：Quillen 提出的模型范畴框架；Hovey 关于 abelian 模型结构与相容完全 cotorsion 对的对应；Gillespie 将其推广到正合范畴，并给出 Cole 混合构造在 exact 模型结构上的显式表述；Nakaoka--Palu 的 extriangulated 范畴；Krause 关于三角范畴纯度、纯内射对象与 smashing 子范畴的工作（说明相对扩张理论在三角同调代数中是内在的，而不只是形式变体）。
- **结果边界**：要求底范畴弱幂等完备；两个模型结构必须相对同一底范畴上的两个 proper class $\xi_1\subseteq\xi_2$，并满足 $\mathcal{W}_1\subseteq\mathcal{W}_2$ 与 $\mathcal{F}_1\subseteq\mathcal{F}_2$（或对偶的 $\mathcal{C}_1\subseteq\mathcal{C}_2$）等相容条件。作者强调本结果不是把短正合序列形式地换成 $\mathbb{E}$-三角：$\xi_1\subseteq\xi_2$ 携带两个相对扩张双函子 $\mathbb{E}_{\xi_1}$ 与 $\mathbb{E}_{\xi_2}$，因而一般有两套正交性与两套相对 cotorsion 理论，混合 cotorsion 对完备性的论证正是围绕这两套理论之间的比较展开的。
- **开放问题**：作者未在导言中显式列出开放问题；由本文条件可自然引出若干追问，例如去掉 $\xi_1\subseteq\xi_2$ 的包含假设后混合构造是否仍成立、混合模型结构的同伦范畴如何与相对导出范畴联系（见「可以尝试的方向」）。
- **应用与推广**：三角范畴中由纯度等动机给出的 proper class、以及由 smashing 直和项给出的 proper class 层级，都是本文定理的直接适用场景；结合 [[2608.03212]] 中在三角范畴上同时携带预三角与 extriangulated 结构的 heart 构造，可以进一步考察「heart 上诱导的模型结构」与本文相对混合结构之间的相容性。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：[[2608.03212]]（n-cotorsion 对的 heart 构造）— 该文在三角范畴上构造 n-cotorsion 对 $\mathrm{CH}/[\mathrm{CW}]$ 的 heart，并证明其同时携带相容的预三角与 extriangulated 结构；本文的相对 cotorsion 对与它是同一类对象在不同层次上的刻画。
- [[2608.03212]]：该文关注 cotorsion 对到 heart 的提升（并统一 Happel--Reiten--Smalø 与 Nakaoka--Palu 两种 heart 构造），本文关注两个相对 proper class 下模型结构的混合与混合 cotorsion 对的完备性，二者可在「heart 上能否自然诱导相对模型结构」这一问题上衔接。
- [[2609.13699]]：该文证明三角范畴中 HRS 倾斜与 $t$-结构完备化的相容性，HRS 倾斜正是从 cotorsion 对出发的构造，且同处三角/正合框架，故本文相对 cotorsion 对的完备性论证有望与之对接（见 [[2609.13699]]）。
- 技术迁移：证明的两步比较技巧——混合 $3\times3$ 构造（同时出现 $\xi_1$-与 $\xi_2$-三角）以及「对 $\mathcal{C}_2$ 中对象，相关 $\xi_2$-扩张已是 $\xi_1$-扩张」——本质上是比较两套正交给定关系，可迁移到其他需要比较两个扩张结构的问题，例如相对 Gorenstein 投射维数的比较、silting/tilting 变异的相对版本。

### 2.2.  可以尝试的方向

- [ ] 去掉 $\xi_1\subseteq\xi_2$，改用两个 proper class 之间更一般的相容性条件，混合构造是否仍能给出 admissible 模型结构？
- [ ] 混合模型结构的同伦范畴能否识别为关于 $\xi_1$ 的相对导出范畴的某个（局部化）子范畴？
- [ ] 把混合构造限制到相对 Gorenstein 投射对象或 Gorenstein 维数有界的子范畴上，是否可得到相对「混合 Gorenstein 模型结构」？

### 2.3.  批判性思考

- 混合 cotorsion 对完备性的证明依赖两个比较引理，逐对象地桥接两套正交关系；是否存在更范畴化的表述（例如用 extriangulated 范畴上的相对导出函子或局部化语言），使证明更短且不依赖具体 $3\times3$ 图追踪？
- 条件 $\mathcal{W}_1\subseteq\mathcal{W}_2$ 与 $\mathcal{F}_1\subseteq\mathcal{F}_2$（或对偶的 $\mathcal{C}_1\subseteq\mathcal{C}_2$）表明构造在纤维化/余纤维化的选择上仍有方向性；当两个方向的条件都不满足时，混合是否可能退化为平凡或不可定义，导言未作讨论。
- cofibrant 对象 $C$ 的刻画用到了 $\xi_2$-deflation 的存在性，说明混合结构的 cofibrant 对象并未完全由 $\xi_1$ 一侧决定；这与「混合结构相对 $\xi_1$」的表述之间存在值得注意的张力，值得追问该刻画是否可比 $\mathcal{C}_m$ 的初始定义给出更多信息。
