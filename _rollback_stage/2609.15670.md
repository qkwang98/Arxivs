# The Cuntz semigroup of rings with stable rank one

keywords: [Cuntz semigroup, stable rank one, projective modules, pure submodule, order-cancellation]
related_paper: "The Cuntz semigroup of a ring（Ara–Bose–Perera–Vilalta）"
one_liner_summary: "该文证明：对稳定秩一的任意环，可数生成投射模之间的 Cuntz 次等价恰好等价于同构于对方的纯子模，Cuntz 等价恰好等价于同构，并由此推出有限生成投射模可从与可数生成投射模的直和中消去等一系列序消去结果。"

## 1.  核心定位

- **解决的问题**：在稳定秩一环上，Cuntz 比较关系 $\precsim$ 与 Cuntz 等价 $\sim$ 究竟对应什么经典模论关系？本文给出完整答案：次等价对应"同构于纯子模"，等价对应"同构"，从而把环的 Cuntz 半群 $\mathrm{CP}(R)$ 的序结构完全翻译为模的子模语言。
- **大图景位置**：这是 Coward–Elliott–Ivanescu 关于稳定秩一 C\*-代数（Cuntz 次等价等于子同构、Cuntz 等价等于同构）的代数类比，但适用环类大得多（半局部环、单位正则环、局部有限群代数、强 $\pi$-正则环、无圈图的 Leavitt path algebra、一维紧 Hausdorff 空间上的连续函数环等）。它同时是 Ara–Bose–Perera–Vilalta 提出的"环的 Cuntz 半群"纲领中的关键一步：该纲领此前已证明 $\mathrm{CP}(R)$ 一般可还原拟纯理想的格、且在左正规环上 $R\mapsto \mathrm{CP}(R)$ 是连续函子。
- **主要贡献**：① 主定理（主定理）用纯子模刻画 $\prec$、$\precsim$ 与 $\sim$，并推论出对任意稳定秩一环自然映射 $\mathrm{V}^*(R)\to \mathrm{CP}(R)$ 是交换幺半群同构；② 引入紧算子代数的代数类比 $K(P)$，证明 $R$ 稳定秩一时 $K(P)$ 亦稳定秩一，这是主定理证明的核心工具；③ 建立不依赖有限生成性的更一般消去定理（$\prec$ 消去），并提出纯子模-补模（complement）概念作为 C\*-代数中公理 (O5)"几乎代数序"的代数替代。
- **关键先驱工作**：Coward–Elliott–Ivanescu 关于 Cuntz 半群与 Hilbert 模的定理；Ara–Bose–Perera–Vilalta 对环的 Cuntz 半群（$\mathrm{CP}(R)$、$\mathrm{S}(R)$）与左正规环的系列工作；Evans 的经典消去定理；Rørdam–Winter 关于稳定秩一 C\*-代数消去的结果；Vaserstein 关于稳定秩一的系统理论；Field、Chase、Lam、Whitehead 关于纯子模与局部分裂的工作。
- **结果边界**：全部结论都建立在稳定秩一这一假设之上，文中未讨论去掉该假设的情形；更一般的消去问题（$\prec$ 而无有限生成性）并未完全解决，作者只给出若干充分条件；补模（complement）在一般环中不一定存在（文中指出可以构造 $D\subseteq C\subseteq R^n$、$D\prec C$ 却无补模的例子），因此 (O5) 型结论只能对特定环类（如正规交换幺环、交换 exchange 环、一维空间上连续函数环）成立。
- **开放问题**：问句形式的 Problem（消去问题）在一般情形下仍未解决；此外文中提到，环的 Cuntz 半群 $\mathrm{CP}(R)$ 与 C\*-代数的 Cuntz 半群 $\mathrm{Cu}(A)$ 是否一般相等（已知后者是前者的收缩）仍是公开问题。
- **应用与推广**：一方面可把该文的纯子模刻画视为 $\mathrm{V}^*(R)$ 上"可数直和"语义的精确化（$\mathrm{CP}(R)$ 对递增序列取上确界），用于研究稳定秩一环的 K$_0$ 与投射模消去；另一方面，$K(P)$ 稳定秩一的传递性（理想-角-矩阵-直极限链）可迁移到其他"系数环继承性质"的问题；补模的存在性判据（借助正规环 $M_n(R)$ 与 $\ll$ 链）为在代数范畴内重建 (O5) 提供了模板。

## 2.  主要定理

> **全局假定 / 背景**: $R$ 为（不必带单位的）环，$R^+=\mathbb{Z}\oplus R$ 为其 Dorroh 单位化；$\mathcal{CP}(R)$ 为所有可数生成投射右 $R^+$-模 $P$ 且满足 $P=PR$ 的类，$\mathrm{CP}(R)=\mathcal{CP}(R)/{\sim}$ 是环 $R$ 的 Cuntz 半群。$P\precsim Q$ 指对 $P$ 的每个有限生成子模 $X$，存在 $\phi\colon X\to Q$、$\psi\colon Q\to P$ 使 $\psi\circ\phi=\mathrm{id}_X$；$P\prec Q$ 指存在 $Q$ 的有限生成子模 $Y$ 见证上述分解且 $\phi(X)\subseteq Y$。

> **Theorem（主定理）**: Let $R$ be an arbitrary ring with stable rank one and $P, Q \in \mathcal{CP}(R)$. Then
> (i) $P \prec Q$ if and only if $P \cong P' \leq_{\mathrm{pure}}Q$ and $P'$ is contained in a finitely generated submodule of $Q$.
> (ii) $[P] \leq [Q]$ in $\mathrm{CP}(R)$ if and only if $P$ is isomorphic to a pure submodule of $Q$.
> (iii) $[P] = [Q]$ in $\mathrm{CP}(R)$ if and only if $P \cong Q$.

*动机 / 作用（中文）*: 这是全文枢纽。在 C\*-代数情形（Coward–Elliott–Ivanescu）同样的结论依赖分析工具，而在纯代数框架下必须重新寻找机制；(i) 是 (ii)(iii) 的技术核心，(ii)(iii) 恰是导言中定理的内容，也说明稳定秩一环的 $\mathrm{CP}(R)$ 不携带比同构类更多的信息。
*证明思路（中文）*：
- 把 $P$ 与 $Q$ 分别写成 $\{P_i\}$、$\{Q_i\}$ 的递增并，且 $P_i\subset\!\subset P_{i+1}$、$Q_i\subset\!\subset Q_{i+1}$（紧包含塔引理）。
- 右到左方向由"纯 ⇒ 局部分裂 ⇒ 存在 $\sigma$ 分裂包含"给出（纯子模命题）。
- 左到右方向：由 $P\prec_Y Q$ 取各层的分解 $(\tilde\phi_i,\tilde\psi_i)$，用关键逼近引理（逼近引理）递推地以 $R^+$-自同构 $u_i$ 修正 $\tilde\phi_i$，使相邻层相容且像落入 $Y$。
- 相容性保证极限同态 $\phi\colon P\to Q$ 良定义且单射，$\phi(P)$ 落在 $Y$ 内；再用 $\phi_{n+1}=u_{n+1}\circ\tilde\phi_{n+1}$ 与 $\tilde\psi_{n+1}$ 显式构造局部分裂映射，得纯性。
- (iii)：交替构造互逆的嵌入对 $\phi_n\colon P_{4n}\to Q_{4n+1}$ 与 $\alpha_n\colon Q_{4n+2}\to P_{4n+3}$，极限同态 $\phi,\alpha$ 满足 $\phi\circ\alpha=\mathrm{id}_Q$、$\alpha\circ\phi=\mathrm{id}_P$，故 $P\cong Q$。

### 2.1.  证明思路（配套的消去与补模结果）

> **Theorem（一般环消去定理）**: Let $R$ be an arbitrary ring, $P$ and $Q$ be right $R$-modules and $T$ be a finitely generated right $R$-module with $\mathrm{sr}(\mathrm{End}_R(T)) = 1$. If $P \oplus T \precsim Q \oplus T$ then $P \precsim Q$.

> **Corollary（$\mathcal{CP}(R)$ 消去推论）**: Let $R$ be a unital ring with stable rank one, let $P$ and $Q$ be right $R$-modules and let $T$ be a finitely generated projective right $R$-module. Then $P \oplus T \precsim Q \oplus T$ implies $P \precsim Q$.

*动机 / 作用（中文）*: 这是 Evans 经典消去定理的 Cuntz 序版本：方程式中只假设 $T$ 有限生成且 $\mathrm{End}_R(T)$ 稳定秩一（对有限生成投射模自动成立），即可从直和中消去 $T$。它不依赖主定理，却给出 C\*-代数中 Rørdam–Winter 结果的另一证明路线。
*证明思路（中文）*：
- 取 $P$ 的有限生成子模 $X$，把分解写成 $2\times 2$ 矩阵方程，得到四条恒等式。
- 令 $x=\psi_4$、$a=\phi_4$、$b=\psi_3\phi_2$，由稳定秩一找到 $y$ 使 $a+yb$ 可逆。
- 用 $y\psi_3$ 构造 $Q\oplus T$ 的自同构 $\tau$，用 $\phi'=\tau\circ\phi$、$\psi'=\psi\circ\tau^{-1}$ 替换，使右下角块可逆。
- 代入恒等式解出 $\psi_2$，得到 $\iota_X=\psi_1(\phi_1-\phi_2\phi_4^{-1}\phi_3)$，即包含映射经 $Q$ 分解，故 $P\precsim Q$。

> **Theorem（补模消去定理）**: Let $R$ be a unital ring with stable rank one and let $A,B,C,D$ be countably generated projective right $R$-modules with $D \subseteq C \subseteq R^n$ for some $n \in \mathbb{N}$. Suppose that
> $$A \oplus C \precsim B \oplus D$$
> and that $D \subseteq C$ has a complement in $R^n$. Then $A \precsim B$.

*动机 / 作用（中文）*: 这是问题（消去问题）的一个正面特例：当 $D\subseteq C$ 在 $R^n$ 中有补模时，$D$ 在式子中的位置可被替换为 $R^n$，从而把一般消去归约到有限生成投射模的消去定理。
*证明思路（中文）*：由补模 $E$ 的性质（补模基本性质引理(i)）得 $D\oplus E\precsim R^n\precsim C\oplus E$；用函子性把不等式夹成 $A\oplus R^n\precsim B\oplus R^n$，再由（一般环消去定理）得 $A\precsim B$。

## 3.  理解辅助

- **贯穿例子**：文中反复使用的具体对象有两类。其一是**自由模的紧算子环**：$K(R)\cong R$、$K(R^n)\cong M_n(R)$、$K(R^{(\mathbb{N})})\cong\mathrm{RFM}(R)$，它把抽象的 $K(P)$ 落到矩阵环与有限行矩阵环上，并解释为何 $K(P)$ 可以看成 $K(R^{(\mathbb{N})})$ 的角（$P=e((R^+)^{(\mathbb{N})})$，$e$ 幂等）。其二是**补模的极端情形** $D=C\subseteq R^n$：此时补模 $E$ 满足 $C\oplus E=R^n$，即回到通常意义的直和补，直接说明 $C$ 有限生成投射；一般情形则通过 $D\oplus E\precsim R^n\precsim C\oplus E$ 把问题归约到有限生成投射模的消去。此外，一维紧 Hausdorff 空间上的复值连续函数环被用作"交换且稳定秩一"的典型例子，说明结论覆盖的环类远超 C\*-代数。

## 4.  主动思考区

### 4.1.  与其他工作的联系

- 这让我想起：[[2609.13908]]（The Nil K-groups of finite groups）中同样以代数 K 理论的对象（$K$ 群、投射模、有限生成假设）为骨架，只是那里研究群环的幂零 $K$ 群，本文研究投射模范畴上的 Cuntz 序；两篇合起来可见"$K$ 群丢失的序信息需要更细的半群"这一共同动机。
- [[2609.08679]]（The Auslander-Reiten conjecture for algebras with radical cube zero）同样在一般（非交换、非幺）环与模的层面讨论同构/消去型问题，其"有限生成模的稳定性质决定整体结构"的味道与本文的有限生成逼近塔技术相通。
- 技术迁移：本文"用有限生成子模逐步逼近可数生成模，并用自同构修正每一步"的递推模式，原则上可迁移到任何具有稳定秩一型"修正可逆元"机制的范畴（例如某些 $\mathcal{K}$-理论化的算子代数、或稳定秩有限的环），也可用于把 C\*-代数中依赖 (O5) 的结论逐条代数化。

### 4.2.  可以尝试的方向

- [ ] 问题（消去问题）在 $R$ 为稳定秩一但非正规的交换环时是否仍成立？可否用 $K(P)$ 的稳定秩一替换正规性假设？
- [ ] 稳定秩一假设能否弱化为"$K(P)$ 对某个 $P$ 稳定秩一"或"$\mathrm{sr}(R)\le 2$"而保持主定理 (ii)(iii) 中的一条？
- [ ] $\prec$ 与 way-below 关系 $\ll$ 在 $\mathrm{CP}(R)$ 上的一般差异有多大？主定理 (i) 是否可与 $\prec\neq\ll$ 的实例一起给出统一解释？
- [ ] 既然 $\mathrm{V}^*(R)\cong\mathrm{CP}(R)$，能否用该同构与 $\mathrm{V}^*(R)$ 的已知结果反推 $\mathrm{CP}(R)$ 的附加结构（例如对递增序列取上确界的连续性）？

### 4.3.  批判性思考

- 全文的技术核心是 $K(P)$ 稳定秩一与逼近引理（逼近引理）。后者依赖对右理想 $K(P,Y)$ 使用稳定秩一、以及 $v=1+v'$（$v'\in K(P,Y)$）时 $v^{-1}(Y)\subseteq Y$ 这一初等观察；若把 $K(P,Y)$ 换成一般理想，"自同构保持子模"这一步会失效，说明该证明路线对环的"紧算子式"结构有实质依赖。
- 主定理 (ii) 的证明实际上把 (i) 中 $Y$ 有限生成的假设弃置不用（取 $Y=Q$ 即可），这也解释了为何 (ii)(iii) 不需要 $\prec$ 概念：真正困难的是"次等价 ⇒ 纯子模"，而不是"纯子模 ⇒ 次等价"。
- 值得警惕的是补模定义中三条要求（$C+E=R^n$、$D\cap E=0$、$D+E$ 纯）在非正规环中的兼容性；文中已经指出无补模的例子存在，因此 (O5) 型结论不能无条件推广，作者在问题（消去问题）上的处理（只做特例）是诚实且必要的。
- 一个可能的简化方向：若能在 $\mathrm{CP}(R)$ 层面直接证明"$\precsim$ 是代数序且对递增序列连续"，则 (ii)(iii) 或可由抽象 Cuntz 半群的一般理论推出，从而绕开逐层构造的重技术；但文中并未给出这条路线，其可行性仍待检验。
