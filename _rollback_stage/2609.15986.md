# Cyclic Haagerup--Izumi fusion categories at every odd order

keywords: [Haagerup--Izumi 融合环, 球状融合范畴, 五边形方程, 重构定理, 伪幺正, 双曲 gamma 函数]
related_paper: "Derived Reconstruction of Semisimple Tensor and Module Categories（arXiv:2609.06753）"
one_liner_summary: "本文对每个奇数 $n\ge3$ 构造出融合规则为循环 Haagerup--Izumi 的复球状融合范畴，并由此推出伪幺正范畴的存在性；证明依赖显式实系数的二次恒等式、一段三次 Fourier 系数的围道计算、其余三次恒等式的代数补全与范畴重构，最后用维数域自同构的延拓得到正维数（伪幺正）情形。"

## 核心定位

- **解决的问题**：Haagerup--Izumi 融合环对任意有限阿贝尔群 $G$ 都有定义（$|G|=n$，有 $2n$ 个基元 $\alpha^a,\alpha^a\rho$，非可逆元被 $G$ 自由置换，$\rho^2=\one\oplus\bigoplus_a\alpha^a\rho$），但融合环不等于范畴：给定 $G$ 的范畴存在性需要解五边形方程。此前只有零散阶数有精确构造或分类，本文对每个奇数 $n\ge3$ 给出循环情形的存在性构造，并推出维数为 $d$ 的伪幺正范畴。
- **大图景位置**：Haagerup 子因子（指标为 $(5+\sqrt{13})/2$ 与 $(5+\sqrt{17})/2$）是高于指标 4 的最小子因子，其偶部给出"奇异对称"的基本例子；Izumi 发现其融合表对任意有限阿贝尔群都有意义，但存在性长期只在少数阶数被验证。本文把"逐阶数值求解"提升为"对全部奇数阶的一族显式构造"，并且正面处理了非幺正（维数 $-1/d$，即 Yang--Lee 型）一侧，再经维数域自同构得到伪幺正一侧。
- **主要贡献**：
  1. 存在性：对每个奇数 $n\ge3$ 构造出复球状融合范畴，其融合规则恰为循环 Haagerup--Izumi 规则；非可逆单对象的范畴维数取负根 $-1/d$，其中 $d=(n+\sqrt{n^2+4})/2$ 是 $d^2=nd+1$ 的正根。
  2. 伪幺正存在性：把 $\Q(\sqrt{n^2+4})$ 的非平凡自同构延拓为 $\C$ 的自同构并再次重构，得到维数为 $1$ 与 $d$ 的范畴，因而满足伪幺正不等式，由此推出伪幺正范畴存在；该范畴上的幺正结构未被建立。
  3. 方法：给出显式的实系数 $W_a$ 及其二次恒等式，用 gamma 移位恒等式导出的四项围道关系证明一段三次 Fourier 系数的消失，再以置换对称、多项式插值与矩阵求逆代数地补全所有三次恒等式，最后用 Evans--Gannon 重构定理与四次恒等式（收缩得到）完成范畴存在性。
- **关键先驱工作**：Haagerup 1993 年对指标落在 $(4,3+\sqrt2)$ 的有限深度子因子的主图搜索；Asaeda--Haagerup 对两个指标的具体连接计算与 Peters 的图平面代数重构；Izumi 用 Cuntz 代数自同态实现并推广到任意有限阿贝尔群；Evans--Gannon 以 Leavitt 代数自同态替代 $C^*$ 框架的重构定理（需要矩阵满足其式 (4.7)--(4.10)，参数 $\omega=1$，并选定满足 $\delta^2=n\delta+1$ 的根 $\delta$）；Huang--Lin 关于透明 $F$-符号与 $S_4$ 例子的分类；Zheng--Bao--Yu 关于循环 Haagerup--Izumi 环的 Casimir 数与形式余次数（满足伪幺正不等式）；Belousov--Sarkissian--Spiridonov 对双曲 gamma 函数的归一化与双 gamma 积分求值。
- **结果边界**：构造给出的是球状（spherical）范畴，非可逆单对象的维数为负根 $-1/d$，与幺正的 Fibonacci 情形不同；伪幺正范畴的幺正结构未建立；对 $n=1$ 之外的情形，奇 $n>1$ 时融合环非交换，故这些范畴都不是辫范畴，与其相伴的模对象是其 Drinfeld 中心；构造依赖 Evans--Gannon 重构定理的适用条件（阿贝尔群、奇阶、$\omega=1$、指定根 $\delta$）；被重构的是"满足 Evans--Gannon 恒等式的矩阵"所给出的范畴，而非一般地分类所有具有该融合规则的范畴。
- **开放问题**：原文未在导言中显式列出开放问题；由结果自然引出的是：伪幺正范畴能否升级为幺正（$C^*$）融合范畴；Huang--Lin 对一般 $G$ 提出的与 Izumi/Grossman--Snyder 系统的对应猜想；Evans--Gannon 曾提出的扭 Haagerup--Izumi 模数据的可实现性；以及偶阶（非循环或非奇阶）群的情形能否用同一 gamma 函数方法处理。文中"补充说明"指出 Gannon 与 Schopieray、Yadav 的在写工作将与本结果部分重叠。
- **应用与推广**：为奇异融合范畴（非群论型、非辫）提供了成族的显式例子，可用于检验模张量范畴的算术约束（形式余次数、Galois 条件、定义域限制）：例如 Morrison--Snyder 关于 Haagerup 偶部不能定义在分圆域上的结果，与本文在 $\Q(\sqrt{n^2+4})$ 上给出实系数构造形成对照；同时为物理侧（格模型、Haagerup 共形场论的数值证据、带 Haagerup 对称的无隙相构造）提供了可用的范畴数据。

## 主动思考区

### 与其他工作的联系

- 这让我想起：[[2609.06753]] — 该文研究半单张量范畴与模范畴的导出重构；本文最终一步正是用 Evans--Gannon 型重构定理把"满足多项式恒等式的矩阵"升级为融合范畴，两者都在"数据满足什么条件才能被重构为范畴"这一瓶颈上工作。
- [[2609.10440]]：该文把 Ocneanu 刚性局部化到固定 Hom-有限幺半范畴，给出代数结构、同态与子代数的有效有限性上界；Ocneanu 刚性说明融合范畴的结构受有限数据约束，这正是本文"存在性必须靠解五边形方程"的深层原因，二者在方法上可互补（一侧给一般有限性，一侧给具体阶数的显式解）。
- [[2609.17467]]：该文构造自由刚性幺半范畴（通用伪张量范畴）的阿贝尔包络并否证其商性质，涉及刚性、最高权范畴与格罗滕迪克型构造；与本文同属"用代数/范畴工具控制融合型结构的可实现性"的方向。
- 技术迁移：本文"用双曲 gamma 函数的反射与移位恒等式把求和恒等式转成围道关系、再以 Fourier 变换与插值补全"的技术，可迁移到其它由模数据或 $F$-符号给出的多项式方程组（如广义 Haagerup 类、扭模数据的可实现性问题），特别是当系数具有周期结构与反射对称时。

### 可以尝试的方向

- [ ] 伪幺正范畴能否赋予幺正结构（即构造出 $C^*$ 融合范畴）？维数为 $d$ 的范畴上的内积选择似乎是最自然的障碍点。
- [ ] 同一 gamma 函数方法能否处理非循环阿贝尔群（如 $\Z/3\Z\times\Z/3\Z$，Evans--Gannon 报告其限制方程无解）或偶阶群？
- [ ] Huang--Lin 提出的"透明 $F$-符号解 ↔ Izumi/Grossman--Snyder 系统"对应能否用本文的显式系数据加以验证？
- [ ] 本文构造的范畴其 Drinfeld 中心（即相应模数据）与 Evans--Gannon 提出的扭 Haagerup--Izumi 模数据是否一致？

### 批判性思考

- 构造的起点是"采样 $F(z)=1/\gamma^{(2)}(\omega_2+z)$ 于整数点"得到的实系数，其存在性与符号性质依赖 gamma 函数的特定归一化；文中把这部分作为给定的解析输入，读者难以判断该方法对参数（$n$、$\delta$ 的取根）的敏感程度，以及若改用其它归一化是否等价。
- 三步证明中"一段三次恒等式由围道关系给出、其余由代数补全"这一分工，依赖"剩余三次恒等式可由置换对称与插值唯一确定"这一论断；若该论断成立则补全合法，但文中未讨论在哪些 $n$ 上补全方程组可能退化，这使方法的稳健性存疑。
- 伪幺正性来自 $\Q(\sqrt{n^2+4})$ 的域自同构延拓，这是"用自同构搬运维数"的技巧；它给出存在性却不解释该范畴与幺正范畴之间的关系，因此"伪幺正 ⇒ 可用物理模型实现"这一常见期望在此处仍未被支持。
