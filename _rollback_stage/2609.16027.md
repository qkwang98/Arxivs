# Formalization of Sullivan's No Wandering Domains Theorem in Lean

keywords: [Lean 4 形式化, 无游荡域定理, 可测 Riemann 映射定理, 拟共形映射, 自动形式化]
related_paper: "[Sullivan] 无游荡域定理原著、[McMullen] 课程讲义（Theorem 5.33，本文证明路线来源）、[AhlforsBers] 可测 Riemann 映射定理、Carleson 项目（截断 Calderón–Zygmund 算子）"
one_liner_summary: "在 Mathlib、RMT4 与 Carleson 之上把 Sullivan 无游荡域定理完整形式化进 Lean 4（171 文件、约 157,000 行、无 sorry/admit），并配套形式化正规族、Sobolev/Wirtinger 导数、Cauchy 与 Beurling 变换、拟共形定义等价与可测 Riemann 映射定理，同时记录六步证明架构、可复用组件与自动形式化工作流。"

## 1.  核心定位

- **解决的问题**：把 Sullivan 无游荡域定理（$\deg\geq2$ 的有理自映射的每个 Fatou 分量最终周期）在 Lean 4 中完整形式化，并补齐其依赖链上在其开始时不存在的分析工具：正规族与 Montel–Carathéodory 定理、Julia/Fatou 集、局部 Sobolev 空间 $W^{1,2}_{\loc}$ 与 Wirtinger 导数、Cauchy 与 Beurling 奇异积分、解析拟共形与几何拟共形的等价、可测 Riemann 映射定理（MRMT）。论文同时披露仓库结构、可复用组件与自动形式化流程。
- **大图景位置**：工作位于"形式化数学 × AI 辅助自动形式化"的交叉点，并被作者定位为复动力系统中较早的形式化项目之一。与纯粹报告新定理的论文不同，本文是 formalization report：其学术价值既在"把一条长分析链搬进内核"，也在"给后续项目一套可复用的分层基础设施与一条可复制的人机协作流程"。
- **主要贡献**：
  1. Sullivan 无游荡域定理的 Lean 4 形式化落地：仓库基于 Mathlib、RMT4 与 Carleson，在 commit 1a39faf、Lean/Mathlib v4.33.0 下含 171 个 Lean 文件、约 157,000 行代码，全部位于 `NoWanderingDomains/` 下；源码无 `sorry`/`admit`，且不引入项目专属 `axiom`。
  2. 附带形式化了不属 NWD 依赖链的两个"终局性"结果：MRMT（存在性与归一化唯一性分列 `mrmt_exists`、`mrmt_unique_normalized`）以及解析/几何拟共形定义等价 `qc_analytic_iff_geometric`。
  3. 完整记录六步证明架构：准备游荡分量 → 用 $\nu_k$ 构造 $f$-不变 Beltrami 微分（$\dim_{\C}E=2d+2$）→ 经 $\bar\partial$-解算子得到全纯形变截面 $\eta_\nu$ → 维度计数（$\dim_{\C}H^0(\Sphere,f^*T\Sphere)=2d+1$）取 rank–nullity → 用排斥周期点在 $J(f)$ 稠密推出 $v_{\nu_*}$ 在 $\partial U$ 上为零 → 用 $\Phi_k$ 的显式解与边界唯一性导出 $c_k$ 全零的矛盾。
  4. 可复用组件层：对任意拓扑空间 $X$ 与一致空间 $Y$ 定义的正规族（`IsNormal`/`IsNormalAt`）、Montel–Carathéodory（`montel_caratheodory_sphere`）、Cauchy 变换的 $C^1$ 与 $L^p$ 理论（含 $P(\bar\partial\omega)=\omega$、$\bar\partial(P\omega)=\omega$、$p>2$ 时 $Ph$ 的 Hölder 连续性与衰减）、Beurling 变换（$T=\partial\circ P$、$\|T\mu\|_2=\|\mu\|_2$、$L^p$ 有界性）、弱 $L^2$ 紧性与 Jacobian 收敛（用于几何 $K$-拟共形的极限封闭性）。
  5. 自动形式化工作流与边界：由 Claude Code 配合 Fable 5 与 Opus 4.8 生成代码，但分层架构（正规族、双曲、Sobolev、奇异积分、拟共形、MRMT、形变）与层间接口由作者预先设计；内核拒绝错误证明步，但无法判断定义是否捕捉原意、定理的一般性是否恰当、假设是否被不自然地编码，这部分由作者人工核查；NWD 完成后再做人工清理（按依赖重整文件、去重、缩短证明、减少 import、加强 docstring、统一命名、区分公开端点与实现细节）。
- **关键先驱工作**：Sullivan 的原定理；McMullen 课程讲义（本文沿用的证明路线，其中 Theorem 5.33 即为不变微分的传播论证）；Ahlfors–Bers（MRMT）；Montel–Carathéodory（三值遗漏正规性）；Carleson 项目（截断 Calderón–Zygmund 算子，Beurling 变换由此搭建）；Mathlib 与 RMT4（基础库与分析依赖）。
- **结果边界**：本文是报告而非新定理；MRMT 与拟共形定义等价尽管被形式化，但按作者自陈不在 NWD 的依赖链内，属于"平行收益"；形式化保证的上限是内核层——定义是否忠实、假设是否自然仍需人工判断，论文没有给出形式化的规格（spec）与目标数学之间的自动校验手段；为绕开当时缺失的 Lean 版 Jordan 曲线定理，四边形被定义为单位方块的参数化映射（取其区域、两侧边与连接曲线族），这是一个有意的定义替代而非经典定义的等价改写；所有结论绑定在特定 commit 与 Lean/Mathlib 版本上。
- **开放问题**：原文未单列 open problems。可从正文读出的方向包括：(i) 补齐被绕开的基础结果（如 Jordan 曲线定理）并把参数化式四边形定义与经典定义互证；(ii) 把"数学意图/一般性/假设合理性"的核查从人工推进为可自动化的契约检查；(iii) 追踪 Mathlib 频繁重构下的长期维护与迁移成本（论文只给出锁定版本的可复现性，未讨论迁移）；(iv) 把该 repo 的层结构推广为复动力系统形式化的通用基底。
- **应用与推广**：结合表示论/范畴论之外的既有知识看，至少四条延伸路径：① `QC/`、`Analysis/SingularIntegral/`、`NormalFamilies/` 等层可直接作为复分析与拟共形映射形式化的底座，避免重复实现 Cauchy/Beurling 理论；② "不变 Beltrami 微分 + rank–nullity"的六步模板可迁移到同类形变刚性定理（例如 Ahlfors 有限性一类结论）的形式化；③ 解析与几何拟共形定义等价的形式化，使后续工作可按需要选用更自然的一侧并自由转移结论；④ 对大规模形式化项目而言，"人类设计分层架构与接口 + LLM 生成声明与证明 + 内核兜底 + 人工核查数学选择"这一流程及其失效边界，具备直接的方法论参考价值。

## 2.  理解辅助

- **贯穿例子（把定理算出来）**：设 $f$ 是有理映射、$d\geq2$，假设 $U$ 是游荡 Fatou 分量。取圆盘 $D=B(a,\rho)$ 且 $\overline D\subset U$，对 $0\leq k\leq2d+1$ 定义 $\nu_k(z)=(k+1)\overline{(z-a)}^k\mathbf{1}_D(z)$，其张成空间 $E$ 的维数是 $2d+2$；另一方面 $f^*T\Sphere\simeq\mathcal O(2d)$ 给出 $\dim H^0=2d+1$。$d=2$ 时即 6 维空间线性映射到 5 维空间，必然有非零 $\nu_*$ 使 $\eta_{\nu_*}=0$，这是整个矛盾的定量核心。随后用显式解 $\Phi_k(z)=\overline{(z-a)}^{k+1}$（$D$ 内）与 $\Phi_k(z)=\rho^{2(k+1)}(z-a)^{-(k+1)}$（$D$ 外）构造 $h=\sum c_k\Phi_k-v_{\nu_*}$，并由 $v_{\nu_*}$ 在 $\partial U$ 上为零与 $h$、$R$ 边界值相同，迫使所有 $c_k$ 为零。
- **贯穿例子（几何拟共形）**：四边形 $Q$ 用单位方块参数化给出，连接族 $\Gamma(Q)$ 为从左边到右边的绝对连续曲线族，其模为 $\Mod(\Gamma(Q))=\inf_{\rho\ \mathrm{admissible}}\int_\C\rho(z)^2\,dA(z)$；几何拟共形要求对每个 $Q$ 都有 $\Mod(\Gamma(fQ))\leq K\,\Mod(\Gamma(Q))$。这一对 $\Mod$-不等式的形式化，是把"几何定义"从图示语言搬进 Lean 的关键一步。
- **贯穿例子（Beltrami 数据）**：`BeltramiCoeff` 结构体把对象限定为可测且 $\|\mu\|_\infty<1$ 的 $\C\to\C$ 函数，`IsQCAnalytic f b` 则同时要求保向同胚、$W^{1,2}_{\loc}$ 与几乎处处 $\bar\partial f=b.\mu\cdot\partial f$——这三条正好构成"解析拟共形"的可机检版本。

### 3.3.  批判性思考

- 论文的核心定理（Sullivan 定理）与证明路线（McMullen 讲义）并非本文原创，本文的贡献是基础设施与流程记录；因此评价标准应是"复用性与可信度"，而不是数学新颖度。这一点作者自陈清楚，但读者容易被标题误导为"新定理"。
- "内核接受即正确"与"定义忠实"之间的鸿沟被作者明确承认，却没有任何自动化的缓解手段；于是整条 157,000 行的链条的可信度最终外接于作者的人工核查，这与形式化"把信任降到内核"的初衷存在张力。
- 论文只说明"许多专门结果在当时不存在于 Mathlib 或其它 Lean 项目"，但未给出覆盖度矩阵（哪些已有、哪些新写、行数占比），使复用价值的判断缺乏定量依据。
- 结果绑定在特定 commit 与 v4.33.0 上，而 Mathlib 的命名与结构演化速度很快；论文没有讨论升级/迁移成本，这对想把该 repo 作为底座的后续项目是一个真实风险。
- 依赖 RMT4 与 Carleson 两个外部项目，其自身的形式化质量与维护状态会传递影响本文可信度；论文对这两个依赖的可靠性只作引用，未作审计说明。

**关键定理原文抄录（逐字引用英文原文与 Lean 声明）**

> \begin{theorem}[Sullivan's No Wandering Domains theorem]
> If $f\colon\Sphere\to\Sphere$ is rational of degree at least two, then no connected component of $\Omega(f)$ is wandering. Equivalently, every Fatou component is eventually periodic.
> \end{theorem}

> theorem sullivan_no_wandering_domains
>     {f : $\CodeSphere \to \CodeSphere$}
>     (hf : IsRational f)
>     (hd : 2 $\leq$ degreeOfRational f) :
>     $\forall$ U : Set $\CodeSphere$,
>       IsFatouComponent f U $\to$ $\neg$ IsWandering f U

> \begin{theorem}[Measurable Riemann mapping theorem]
> For every Beltrami coefficient $\mu$, there exists an orientation-preserving quasiconformal homeomorphism $f\colon\C\to\C$ satisfying $\bar\partial f=\mu\partial f$ almost everywhere. There is a unique such solution satisfying $f(0)=0$ and $f(1)=1$
> \end{theorem}

> theorem mrmt_exists (b : BeltramiCoeff) :
>   $\exists$ f : $\C \to \C$, IsQCAnalytic f b
>
> theorem mrmt_unique_normalized (b : BeltramiCoeff) :
>   $\exists!$ f : $\C \to \C$,
>     IsQCAnalytic f b $\land$ f 0 = 0 $\land$ f 1 = 1

> theorem qc_analytic_iff_geometric
>     {f : $\C \to \C$} {K : $\R$} (hK : 1 $\leq$ K) :
>   ($\exists$ b : BeltramiCoeff,
>       b.normInf $\leq$ (K - 1) / (K + 1) $\land$
>       IsQCAnalytic f b)
>     $\leftrightarrow$ IsQCGeometric f K

（说明：以上为 core 文本中相应定理与 Lean 声明的逐字摘录。core 中球面类型以宏 \CodeSphere 呈现，此处照原样保留以避免改写；Lean 片段中原有的 `$\leq$`、`$\forall$`、`$\neg$`、`$\exists!$` 等 PDF 转写形式亦按原样保留。）
