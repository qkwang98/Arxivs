# Vector fields, initial scaffolds and database reduction

keywords: [categorical vector fields, acyclic categories, directed homotopy, beat objects, initial scaffolds, functorial databases]

related_paper: "The chain replacement of a poset flow（arXiv:2607.11639，同属有向同伦与范畴约化纲领）"

one_liner_summary: "本文在小范畴上引入左、右向量场（切范畴投影的截面，等价于带自然变换 $R\Rightarrow1_\CC$ 或 $1_\CC\Rightarrow L$ 的自函子），证明有限无环范畴上任意右（左）向量场迭代稳定后给出到不动子范畴的有向形变收缩，且其不动子范畴恰由有限次下（上）beat 对象删除得到；在此基础上证明右向量场约化保持右有向纤维化的有向截面范畴 $\mathrm{dsecat}$ 与函子式数据库的全局截面 $\Gamma(\CC,X)$，并把偏序集的 initial scaffold 推广到（下良基）无环范畴，证明它在右有向形变收缩下不变。"

## 1.  核心定位

- **解决的问题**：如何在保留"相关有向同伦信息"或"图表极限"的前提下，把一个复杂的（有限）无环范畴替换为更小的模型。论文给出两条互补的约化路线：一是以范畴向量场为工具的迭代式有向约化（把 Tanaka 的 beat 对象约化编码成单个自然变换）；二是把 Dey 与 Lesnick 的 initial scaffold 从偏序集推广到无环范畴，用以保留所有极限，特别是函子式数据库的全局截面。
- **大图景位置**：这是"用更简单模型替换复杂对象但保留相关信息"这一范式在**有向**方向上的范畴化。组合拓扑中有限 $T_0$ 空间与有限偏序集的 beat 点约化（Stong、Tanaka）、单纯坍缩（Whitehead）与离散 Morse 理论（Forman 等）构成了这一范式的无向版本；本文把它搬到小范畴的有向同伦论中，并同时接入函子式数据库（schema 是小范畴、实例是集合值函子）的极限计算问题。相对于 Tanaka 对无环范畴强同伦型的约化理论，本文补上的是有向信息与函子式（单一自然变换）描述；相对于 Dey 与 Lesnick 的偏序集 scaffold，本文补上的是无环范畴版本与"约化下不变性"。
- **主要贡献**：
  1. 定义左、右切范畴 $T_R\CC=\int^\CC(\CC\downarrow-)$ 与 $T_L\CC=\int_\CC(-\downarrow\CC)$。二者全范畴都同构于箭头范畴 $\CC^{\mathbb I_1}$，但投影分别是 $\operatorname{cod}$ 与 $\operatorname{dom}$；向量场定义为这两条投影的截面，并等价于配备自然变换 $\varepsilon\colon R\Rightarrow1_\CC$（右）或 $\eta\colon1_\CC\Rightarrow L$（左）的自函子。
  2. 稳定化定理：有限无环范畴上任意右向量场存在 $N$ 使 $R^N$ 幂等、取值落入不动子范畴 $\operatorname{Fix}(R)$，并给出到 $\operatorname{Fix}(R)$ 的右有向形变收缩；反过来，幂等的右（左）向量场与右（左）有向形变收缩一一对应。
  3. beat 对象刻画：右向量场的不动子范畴恰可由有限次下 beat 对象删除得到（对偶地，左向量场对应上 beat 对象删除）；反过来每个下 beat 对象删除给出一个幂等右向量场。该对应不是双射——不同向量场可以稳定到同一个收缩。
  4. 有向截面范畴的保持：若 $\iota r\Rightarrow1_\CC$ 给出右有向形变，则沿其基变换保持任意右有向纤维化的有向截面范畴，即 $\mathrm{dsecat}(\iota^*P)=\mathrm{dsecat}(P)$；对 Grothendieck opfibration 还保持普通截面范畴。于是截面（障碍）问题可以转移到不动子范畴上计算。
  5. 数据库的保持：右有向形变收缩的含入是 initial 函子，因而由余终定理保持所有极限；结合 $\Gamma(\CC,X)\cong\lim_\CC X$，得到右向量场约化保持全局截面：$\Gamma(\CC,X)\cong\Gamma(\operatorname{Fix}(R),X|_{\operatorname{Fix}(R)})$。
  6. initial scaffold 的推广：对下良基无环范畴，用穿孔下逗号范畴 $\partial(\CC\downarrow c)$ 取代偏序集的开下集，构建对象集为源集合 $M_\CC$ 与下本质对象集合 $E_\CC$ 之并、态射为每个连通分支中"选一个源指向该对象"的态射的子范畴，并证明其含入是 initial 函子，从而保持所有极限与数据库全局截面；进而证明下 beat 对象删除、右有向形变收缩与右向量场约化都不改变 initial scaffold。
- **关键先驱工作**：Stong 关于有限 $T_0$ 空间 beat 点的约化及其后续综述（MR3024764）；Whitehead 的单纯坍缩理论；Forman 的离散 Morse 理论（含 Scoville、Mosquera 对有限偏序集的版本）；Tanaka 对无环范畴的强同伦与简单同伦约化理论（StrongHomTan、SimpleHom_Tan）；Chocano 等人关于有限空间 semiflow 与下 beat 点、形变收缩的动力学刻画；Grandis 的有向同伦论；作者本人在有向同伦与数据库方向的前作（DirectedHomotopyDatabases）以及与弱 / 强纤维化相关的合作工作（carcaciacampos2026weakstrongfibrationsfunctors）；Spivak 等人的函子式数据库、data migration 与数据库查询；Dey 与 Lesnick 关于带有限下集的偏序集的 initial scaffold 与极限计算；Mac Lane 关于 initial / final 函子的余终性定理；d'Antonio 与 Delucchi 对无环范畴使用的离散 Morse 型向量场（基于偏无环匹配，服务于胞腔坍缩与 Morse 复形，本文明确与之不同）。
- **结果边界**：
  - 稳定化定理与 beat 对象分解只对**有限**无环范畴断言，证明依赖"严格下降链不能重复"与有限性；无限情形只在 initial scaffold 部分以"下良基"条件出现。
  - initial scaffold 的不变性仅由**右**有向形变收缩（含下 beat 对象删除、右向量场约化）保证，结论对方向敏感；作者明确表示对偶的 final scaffold 理论（使用穿孔上逗号范畴）不在本文展开。
  - initial scaffold 只保证保持极限（含入是 initial），它一般不是有向形变收缩，也不保持余极限；它探测的是穿孔下逗号范畴的**连通性**，而非完整范畴结构——文中平行态射的例子中，两个不同的范畴给出相同的 scaffold。
  - "稳定化向量场 ↔ beat 对象删除序列"不是双射：不同向量场可稳定到同一收缩，同一收缩也可有多种 beat 对象分解；向量场用一个自然变换函子式地记录约化，而删除序列只记录收缩的一种分解。
  - 截面范畴的保持定理不要求 $r\iota=1_\Uc$，只用 $\iota r\Rightarrow1_\CC$，但结论只覆盖**右**有向纤维化与右向形变（左向情形需对偶处理）。
- **开放问题**：作者未给出集中列出的开放问题清单，文中明确留下的方向是对偶的 final scaffold 构造（用穿孔上逗号范畴，作者表示不在此展开）。此外，定义 initial scaffold 时要求范畴下良基，非良基或无限情形的推广、以及不同的"源代表元选择"之间是否存在规范联系，文中均未讨论。
- **应用与推广**：一是数据库与知识组织。可以把庞大 schema 先按右向量场删去那些"取值被其它类型函子式决定"的记录类型（例如文中把两个外送报告中心从 schema 中删去），再用 initial scaffold 把全局截面问题压到少数关键平行态射上比较，从而降低一致性检索的计算规模；函子式数据库即集合值层，全局截面的保持可读作层一致性条件的骨架化。二是有向拓扑与并发理论。把并发模型对应的索引范畴做右有向形变收缩，可把截面（障碍）问题转移到不动子范畴，与 Grandis 的有向同伦以及偏序集流一类技术自然衔接。三是指标范畴的极限计算。initial scaffold 保持任意函子的极限，故可直接搬运到向量空间值图表（Dey 与 Lesnick 的原应用）乃至链复形值函子的极限算法中。

### 2.3.  批判性思考

- 切范畴的定义依赖对每个对象取"入态射范畴"或"出态射范畴"再作 Grothendieck 构造，但整篇论文实际只用到了投影的截面，也就是"带自然变换 $R\Rightarrow1$ 或 $1\Rightarrow L$ 的自函子"这一描述；换言之"切"与"向量场"的几何直觉承载了叙述上的动机，技术内容基本可以在自函子层面完成，第 2、3 节的不少陈述因此可写得更短。
- 稳定化定理的证明本质是"无环保证迭代链中对象不重复 + 有限保证链长有界"，与离散 Morse 理论中梯度路径不能重复的论证同构；作者没有讨论 $N$ 的有效估计，也没有给出用组合或计数方法改进界的路径。
- 关于 Grothendieck opfibration 保持普通截面范畴的推论，其证明把 $\mathrm{secat}=\mathrm{dsecat}$ 归给前作的两个命题（DirectedHomotopyDatabases 中的 Proposition 2.6 与 6.4），本文未给出该严格化（strictification）的独立论证；读者需回查前作才能验证，这在自足性上是一处隐含依赖。
- initial scaffold 的定义在每个连通分支中"选择一个源作为代表元"，而不同的选择只共享"含入是 initial"这一性质；文中未讨论不同选择之间是否存在自然的比较或唯一性，也明确承认构造只探测连通性而不探测完整范畴结构。因此把 scaffold 当作规范不变量使用需要谨慎，它更像一族等价的约化模型而非唯一对象。
- 数据库例子中"全局截面恰有三个"的结论来自作者手写表格的逐项检查，属于验证性示例而非一般算法；论文未分析计算 scaffold 与全局截面的复杂度，而这正是把该约化真正用于数据库实践的关键缺口。
