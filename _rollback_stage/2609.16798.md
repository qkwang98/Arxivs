# On Models of the Planar Lambda Calculus

keywords: [planar lambda calculus, semi-closed operad, multicategory, combinatory algebra, Scott representation theorem]
related_paper: "Hasegawa (2023) - Planar Lambda Algebras and Semi-Closed Operads"
one_liner_summary: "本文在任意 multicategory 中定义了平面 $\lambda$-模型，构造了它与半闭 operad 之间的伴随（其单位是同构），并证明半闭 multicategory 的幂等分裂完备化必为闭 multicategory，由此得到平面 $\lambda$-演算版本的 Scott 表示定理。"

## 1.  核心定位

- **解决的问题**：平面 $\lambda$-演算存在两条建模路线——Hyland 提出的半闭 operad 路线，以及源自组合逻辑的 $\lambda$-模型路线；本文要建立两者之间的严格范畴对应，并把经典的 Scott 表示定理搬到平面情形。
- **大图景位置**：这是 Hyland（半闭笛卡尔 operad 是 $\lambda$-演算的模型）与 Hasegawa（半闭 operad 对应平面 $\lambda$-演算）工作的继续，同时也是 Kuzmin 等人「子结构组合完全性」伴随（弱闭 operad 与子结构组合代数）在 $\lambda$-演算层面的专门化与深化；作者把本文视为把该框架系统推广到各种子结构 $\lambda$-模型的「第一步」。
- **主要贡献**：
  1. 在任意 ambient multicategory 中定义平面 $\lambda$-模型（平面 $\lambda$-代数 + 弱多外延性），并证明其可计算态射全体 $R(\mathcal{M},A,\bullet)$ 构成半闭 operad；反过来，半闭 multicategory 中的 reflexive object 给出平面 $\lambda$-模型（Lemma 的可计算-半闭与半闭-reflexive 两条引理互为逆方向）。
  2. 构造半闭 operad 范畴 $\mathsf{O}_s$ 与 $s$-triple 范畴 $\mathsf{T}_s$ 之间的伴随，且伴随单位是同构，从而 $\mathsf{O}_s$ 是 $\mathsf{T}_s$ 的全子范畴；这就说明平面 $\lambda$-模型与半闭 multicategory 的唯一实质差别在于「半闭 operad 与 ambient multicategory 处于同一元理论层级」。
  3. 证明半闭 multicategory $\mathcal{M}$ 的幂等分裂 $\mathsf{Split}(\mathcal{M})$ 总是闭 multicategory，并由此得到平面版 Scott 表示定理：任意半闭 operad $\mathcal{M}$ 都同构于 $R(\mathsf{Split}(\mathcal{M}),(*,1),\mathsf{ev})$，即都来自某个闭 multicategory 中的 reflexive object。
  4. 通过「有足够点（enough points）」条件调和了本文的弱多外延性与经典弱外延性：在点的可分离性成立时两者等价，故在集合与函数的 multicategory 中本文定义与经典 $\lambda$-模型一致。
- **关键先驱工作**：Hyland, *Classical lambda calculus in modern dress*（半闭笛卡尔 operad 与 $\lambda$-演算）；Hasegawa, *Planar lambda algebras and semi-closed operads*（平面 $\lambda$-代数公理 [P.1]–[P.7] 的来源）；Kuzmin 等人 *A structural account of combinatory completeness*（$w$-triple 伴随的一般框架，本文的 $s$-triple 伴随是其特化）；Scott, *Relating theories of the lambda calculus*（表示定理原型）；Selinger, *The lambda calculus is algebraic*（$\lambda$-代数公理的类比来源）；Leinster（multicategory 基础）、Manzyuk（闭 multicategory）、Tomita（平面可实现性中的 $\mathsf{BI}(-)^\bullet$-代数）、Cockett–Hofstra（Turing 范畴）、Shulman 与 Cockett–Seely（multicategory 与 sequent calculus 的对应）。
- **结果边界**：全部构造都在某个 ambient multicategory 中进行，集合论版本只是取「集合与函数」这一特例；结论只给出半闭（semi-closed）而非闭（closed）结构——半闭只要求 $\Lambda$ 与求值满足单向消去，缺少反向律与自然性以外的额外条件，因此所得 operad 一般不是闭 multicategory，必须经开分裂完备化才能得到闭结构。此外，唯一 $n$-flat 代表的存在性依赖于固定选择的 $\mathsf{B}$、$\mathsf{I}$（不同选择给出不同的平坦性概念，但都能推出同一核心引理）；弱多外延性严格强于经典弱外延性，需额外假设 ambient multicategory 有足够点才与经典定义吻合。
- **开放问题**：作者明确把系统建立「不同种类的半闭 multicategory ↔ 不同种类的子结构 $\lambda$-模型」之间的对应列为后续目标，即把 Kuzmin 等人对子结构组合代数的分类提升为对子结构 $\lambda$-演算模型的分类，最终与 Hyland 的 operadic 路线打通。
- **应用与推广**：为线性/平面等子结构 $\lambda$-演算的指称语义提供统一的范畴框架，可用以判定具体的组合代数（Turing 范畴、可实现性模型、带迹结构）何时构成合法模型；幂等分裂完备化作为构造 reflexive object 的通用手段，可迁移到其他「表示定理」型结果中。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Karoubi 包络（幂等完备化）在自动微分与范畴语义中的使用 — 见 [[2607.14453]]
- [[2607.14453]]：该文同样以幂等完备化（$\Kar$ 构造）为关键技术，把依赖的余切空间族嵌入非依赖范畴；本文则用 $\mathsf{Split}(\mathcal{M})$ 把半闭结构升级为闭结构，两者都把「幂等分裂」当作打破结构性障碍的杠杆，可对比其完备化对象的选取方式。
- [[2609.10501]]：该文研究自由非对称（即平面）operad 的表达式树范畴与 noetherian 形，本文处理的对象恰是平面 $\lambda$-演算的 operad 模型；两者都处在「去对称性」后的 operad 世界，可用于检验本文的半闭条件在具体自由 operad 上是否可满足。
- [[2607.12705]]：该文用 Eilenberg–Moore–Kleisli 完备化从 operad 造出 2-rig，本文则用可计算态射构造 operad、再从 operad 出发造 reflexive object；两文共享「从较低结构完备化出更高封闭结构」的方法论。
- 技术迁移：本文「弱多外延性 ⇒ 计算态射存在唯一 $n$-flat 代表」的论证模式（先用 $\mathsf{B}^{*n}\mathsf{I}$ 归一化，再用外延性去重）不依赖具体运算，可迁移到其他带外延性公理的组合模型，例如带偏迹或带对偶的组合代数，用以证明代表元的唯一性。

### 2.2.  可以尝试的方向

- [ ] 把半闭换回弱闭（去掉 $\Lambda$ 的自然性等式）时，$\mathsf{O}_w \hookrightarrow \mathsf{T}_w$ 与本文 $\mathsf{O}_s \hookrightarrow \mathsf{T}_s$ 是否构成相互伴随的三角关系，从而给出平面与一般 $\lambda$-演算模型之间的精确落差？
- [ ] 本文用「有足够点」调和两种外延性，能否以更范畴化的可表示性（如强生成性、或态射由全局元检测）条件替换，给出不依赖具体元的多外延性判据？
- [ ] 对非平面（对称/笛卡尔）$\lambda$-演算，$\mathsf{Split}$ 保持闭结构这一引理是否仍有对应版本，还是会因对称结构的收缩性而失效？

### 2.3.  批判性思考

- 本文定理的证明成本高度不对称：平面版 Scott 定理本身的证明只有两行，真正的全部工作量集中在「$\mathsf{Split}(\mathcal{M})$ 是闭 multicategory」这一引理（需要验证 $[a,b]$ 幂等、求值与 $\Lambda$ 良定义、以及两条消去律）；作者也明言这一引理「隔离出了此类表示定理成立的根本原因之一」，这意味着定理的深刻性应归功于分裂完备化而非表示定理陈述本身。
- 弱多外延性定义中对每个 $n$ 都要求 $\mathsf{B}^{*n}\mathsf{I}a = \mathsf{B}^{*n}\mathsf{I}b$，比经典弱外延性强得多；虽然作者在「有足够点」假设下证明了二者等价，但该假设在构造性/可实现性语境中并不自动成立（可实现性模型的点通常不足以分离态射），所以本文模型与经典的适配范围可能窄于其表述给人的印象。
- 平面 $\lambda$-代数的七条公理 [P.1]–[P.7] 被作者直接沿用而未作解释，只说明其类推自 Selinger 的 $\lambda$-代数公理；其中 [P.3] 可推出，真正承载信息的是 [P.4]–[P.7]。这使读者难以判断公理组是否「恰好」（既不强到排除期望模型、也不弱到丢失唯一代表元性质），作者也未给出公理独立性的讨论。
- 该框架把「模型」定义为 ambient multicategory 中的 applicative system，因此模型的身份依赖所选 ambient 范畴；虽然伴随的单位同构说明半闭 operad 侧没有这一自由度，但对平面 $\lambda$-模型侧的分类问题（何时两个不同 ambient 中的模型给出同一 operad）本文未作讨论。
