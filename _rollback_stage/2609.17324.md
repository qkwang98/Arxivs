# Universal Properties of Petri Net Unfoldings

keywords: [Petri 网展开, 事件结构, 相对伴随, 2-范畴, 对称性]
related_paper: "Kock, Whole-grain Petri nets and processes（whole-grain 路线）"
one_liner_summary: "本文用 2-范畴语言重新处理非安全 Petri 网的展开语义：whole-grain 一侧的展开给出 $\WGPetri$ 与事件结构范畴之间的伪伴随，普通网一侧的展开只能刻画为沿 $\ES \hookrightarrow \SES$ 的 $J$-相对伪伴随（即在带对称的事件结构上「模去对称」地唯一），并借助 $J$ 的 2-密度性与相对伴随之间的态射把两种展开构造形式地联系起来。"

## 核心定位

- **解决的问题**：Petri 网的展开把网的所有可能执行合并成一个指称对象，但当网不是安全（safe）网时，这一构造一般并不满足人们期望的万有性质——根源是展开忽略了网的内部对称性；本文要问的是：在完全放弃安全性假设后，能否为展开重建精确的万有刻画，并把已有的两种修补方案装进同一个 2-范畴框架。
- **大图景位置**：这是 Nielsen–Plotkin–Winskel（1981）开启的「事件结构作为 Petri 网指称语义」纲领在非安全情形下的续篇。作者把 Hayman–Winskel 的显式对称路线（把对称性加到网自身）与 Kock 的 whole-grain 路线（给 token 与边分配个体身份以打破对称）理解为同一问题的两种解法，并用相对伴随理论说明二者是同一现象的两面。此前两种构造都只做到 occurrence net 层级，而 occurrence net 因 place 可能冗余并不是合适的语义域；本文把二者都推进到事件结构层级。
- **主要贡献**：
  1. whole-grain 一侧：引入比 étale 映射更一般的 rational map（cabling 映射与 étale 映射的复合），证明嵌入 $\WGOcc \hookrightarrow \WGPetri$ 有右伴随 $\U$，从而把 Kock 关于 étale 映射的展开定理推广到 rational map，并把由此得到的 whole-grain 展开与 $\Occ \rightleftarrows \ES$ 的伴随复合，得到 $\WGPetri \rightleftarrows \ES$ 的伪伴随，即 whole-grain 网到事件结构的万有展开。
  2. 普通网一侧：以带对称的事件结构构成的 2-范畴 $\SES$（它的 hom-范畴全部退化为 setoid）为语义域，把展开语义 $\semAlone : \Petri \to \SES$ 刻画为沿嵌入 $\ES \hookrightarrow \SES$ 的 $J$-相对伪伴随；同时证明该嵌入 2-函子 $J$ 是 2-密的（2-dense），据此说明展开函数在相差对称的意义下本质唯一，并给出沿着 $J$ 的相对伪伴随的唯一性引理。
  3. 两套构造的连接：构造相对伪伴随之间的（伪）右态射，由恒等 2-函子 $\id_{\ES}$、多重度计数函子 $\Q : \WGPetri \to \Petri$、嵌入 $J : \ES \to \SES$ 以及伪自然变换 $\alpha_P : J\semWGA{P} \to \semSA{\Q(P)}$ 组成，从而把「忘记名字即产生新对称」这一直觉落实为形式陈述。
- **关键先驱工作**：Nielsen–Plotkin–Winskel 的事件结构与 occurrence net 理论（展开概念的源头）；Winskel 学派关于 occurrence net、因果与冲突关系的刻画；Hayman–Winskel 的显式对称展开（把对称性编码进网）；Kock 的 whole-grain Petri 网与进程理论（本文 whole-grain 一侧的直接基础）；相对伴随（relative adjunction）的一般理论；带对称事件结构的 2-范畴 $\SES$ 的既有工作。作者同时指出 2-范畴方法在既有的对称展开文献中已多次出现，是处理命名元素与对称性的自然工具。
- **结果边界**：普通网上的万有性质被本质地弱化，只能在「相差对称」意义下成立（即 $\SES$ 中 setoid 意义下的唯一性），严格万有展开只在安全性假设下才存在；whole-grain 一侧的伴随必须在 rational map 层面而非仅 étale 映射层面陈述；定理的伪自然性证明被作者称为高度技术性，正文只给思路、细节置于附录；附录中「$\WGPetri$ 局部是 setoid」的结论依赖网没有孤立 place 这一约定；$\Q : \WGOcc \to \Occ$ 给出的是等价而非同构；2-密度严格弱于 1-范畴意义下的密度，底层 1-函子 $J$ 并不稠密。
- **开放问题**：论文没有单列开放问题；结论部分提出两条展望——把对称性问题与其他类型的展开（其他文献中隐式或显式出现的对称处理）联系起来，以及在程序语义中借助带对称的事件结构获得新视角；另可追问各类展开中「对称性」是否都能由同一套相对伴随机制解释。
- **应用与推广**：本文给出一个可复用的模板——当对象被嵌入到一个更粗糙、弱化的范畴后，如何用 2-密度加相对伪伴随把万有性质恢复到「模去等价」的层面；这套模板适用于任何「忘记名字或结构会产生新对称」的语义场景。反向地，多重度计数函子 $\Q$ 与 $J$ 组成的相对伪伴随态射，示范了如何用 2-范畴的态射比较两套风格不同的语义构造，可用于形式地对应其他「细粒度与粗粒度」语义（如带标记与不带标记的结构、带命名与仅带重数的资源语义）。

## 主动思考区

### 与其他工作的联系

- 这让我想起：whole-grain 方案的本质是给每个 token 与每条边一个身份，使得「选了哪个 token」从无法区分的内部差别变成不同的态射；这与组合学中「标记结构与非标记结构」的对比、以及把点当作有名字对象来处理的一般手法同源，也与自由构造「先加结构再局部化」的范式相邻。
- [[2609.17282]]：该文用（余）笛卡尔纤维化在 $(\infty,2)$-范畴中处理「自由地添加伴随」，本文则用相对伪伴随处理展开这类伴随在对称性面前失效后的修补；两文共享的技术气质是「用 2-范畴的伴随，再配合密度或纤维化条件，把构造的典型性证出来」，区别在于该文在 $(\infty,2)$ 层做严格的融贯性控制，而本文停留在退化 2-范畴（hom 为 setoid）的层面。
- [[2607.28584]]：同属 math.CT 的 2-范畴基础性工作；本文不必处理尺寸问题与 2-范畴公理是否自洽的问题，但两文共同体现了「把 1-范畴层面的直觉提升到 2-范畴必须付出融贯性代价」这一现象。
- [[2609.16798]]：该文用半闭 operad 与 $s$-triple 之间的伴随刻画平面 $\lambda$-演算的模型，与本文一样把「语义模型」理解为某种伴随的单位所决定的结构；可对照的是它用单位是同构来给出强结论，而本文只能把唯一性弱化到对称等价。
- 技术迁移：本文用 2-密度（2-函子 $J$ 在局部是同构）来保证相对伴函子的唯一性，这一判据能否迁移到其他「忘记对称性」的嵌入？例如把多重范畴或 operad 嵌入到带对称的结构中，是否也能得到相对伴随层面的唯一性？

### 可以尝试的方向

- [ ] 能否把「2-密度 ⟹ 相对伪伴随在相差等价下唯一」抽成一条一般定理，并给出比本文更弱、更易验证的假设条件？
- [ ] 安全 Petri 网的严格万有展开是否可作为本文相对伴随在对称性自动平凡（对称群退化）时的特例自动导出，从而把经典结果纳入同一框架？
- [ ] rational map 层面的展开能否给出 $n$ 重的推广（例如对多层重数或高阶并发结构），此时相对伴随的层次是否需要从 2-范畴升到 3-范畴？

### 批判性思考

- 作者把安全性条件批评为数学上不够自然，但安全网恰是实际验证工具中展开方法的主要工作场景；相对伴随刻画虽然概念上更干净，却把唯一性弱化为「模去对称」，论文没有讨论这对工程中的展开式模型检验（尤其状态空间压缩算法）是否带来直接收益。
- 大量融贯性条件（伪自然性、相对伴随的态射、伪函子性）被推到附录或直接省略，理由是高技术性；这使得「展开在相差对称下唯一」这一结论的可靠性依赖读者对既有 2-范畴引理与技术的信任，而非自足的验证。
- 带对称的事件结构把对称性放在 bisimulation 式的同构族上，whole-grain 方案则把对称性放在对象层面的命名上；论文用相对伴随的态射连接两者，但该态射本身只是伪自然变换（非严格性来自伪逆仅定义到同构），因此「两种解法一致」这一陈述自身也只是模去等价层次的结论。
- 事件结构丢弃 place 被作者称为丢弃无关的实现细节，但 place 所承载的标记信息在 whole-grain 展开中仍以 in-boundary 对应 token 集的方式被保留；这是否意味着事件结构不足以完全替代 occurrence net 作为语义域，值得进一步追问。
