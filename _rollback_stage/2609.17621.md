# On motivic cohomology of commutative C*-algebras

keywords: [motivic 上同调, 交换 C*-代数, Betti 上同调, 代数 K-理论, Cortiñas-Thom 定理]
related_paper: "Cortiñas--Thom: K_*(C(X)) ≃ ku^{-*}(X)（本文结果是对它的 motivic 加细）"
one_liner_summary: "本文为紧 Hausdorff 空间 X 上复连续函数环的代数 K-理论结果给出 motivic 加细：对 i≥2j≥0，其第 i 个权重 j 的整系数 motivic 上同调群自然同构于 X 的第 i 个 Betti 上同调群。"

## 核心定位

- **解决的问题**：计算交换 C*-代数（即紧 Hausdorff 空间 X 上的复值连续函数环 C(X)）的 motivic 上同调，并把它与底空间 X 的 Betti 上同调精确比较。
- **大图景位置**：这是对 Cortiñas–Thom 定理（C(X) 的非正代数 K-理论同构于 connective 复拓扑 K-理论）的 motivic 加细，验证了 Rosenberg 的期待；同时把 Elmanto–Morrow 为等特征环建立的 motivic 滤过搬到了算子代数的交换情形，在特征零的工作框架下计算 K-理论滤过的分次片。
- **主要贡献**：（1）主定理：Betti 实现诱导自然映射 H^i_mot(C(X);Z(j)) → H^i_Bet(X;Z(j))，当 i ≥ 2j 时双射、i = 2j−1 时满射（右侧 Z(j) 指 (2πi)^j Z，指定生成元后与 H^i_Bet(X;Z) 等同）；（2）先证明两个中间定理：有理系数的比较映射在 i ≥ 2j 时双射、i = 2j−1 时满射；模 p 归约给出 D(F_p) 中的等价 F_p(j)^mot(C(X)) ≃ Γ_Bet(X;F_p(j))；（3）用纤维（fiber）论证把有限系数与有理系数两条输入合并，推出整系数结论。
- **关键先驱工作**：Cortiñas–Thom 对 C(X) 非正 K-理论的计算（并确认 Rosenberg 期待）、Rosenberg 的期待本身、Elmanto–Morrow 的 motivic 滤过（gr^j_mot K(A) ≃ Z(j)^mot(A)[2j]）、以及 k-ros-1 中的 going-down 论证（本文在证明章节复述）与 mot-oka 提供的满射性输入。
- **结果边界**：结果仅针对交换 C*-代数（等价地，紧 Hausdorff 空间上的连续函数环），工作特征为零；同构范围限于 i ≥ 2j，恰对应 K_* 的 * ≤ 0 部分，且在 i = 2j−1 处只有满射而非同构；非交换 C*-代数完全不在讨论范围内。
- **开放问题**：能否推广到非交换 C*-代数或更广的算子代数？i = 2j−1 处的满射是否可加强为同构（等价于某纤维群在该度消失）？更高权重、更一般的系数系统或与 étale、实实现等其他实现方式的比较是否成立？
- **应用与推广**：本文与 Banach 代数上的 étale（Lichtenbaum）Chow 群计算形成对照，两者都属"函数环的上同调由底空间 Betti 上同调刻画"这一母题；方法上，先分别建立有理与模 p 比较、再用纤维序列提升到整系数的套路，可移植到其他比较映射（例如 étale 到 Betti）的整系数提升问题，也可为把 motivic 权重结构引入 C*-代数稳定性与 K-理论计算提供工具。

## 主动思考区

### 与其他工作的联系

- [[2609.09871]]：该文证明可交换复 Banach 代数 A 的 étale（Lichtenbaum）Chow 群 CH^q_et(A) 典范同构于 Gelfand 谱的偶数度整系数 Betti 上同调 H^{2q}_Bet(Sp(A);Z)。本文的 i = 2j 情形正是同一母题在 motivic 一侧的对应陈述（C(X) 的 Gelfand 谱为 X），两文从 motivic 与 étale/Chow 两个入口得到一致的比较图像，互为印证。
- [[2609.15226]]：该文在 p-Banach 空间范畴中建立 Ext^n 构成通用 δ-函子并构造相对内射对象，属于"拟范数代数上的同调代数"。本文虽走 A^1-同伦/motivic 路线，但两者面对的都是拓扑向量空间类环的导出范畴技术，其相对内射工具可能对非交换推广中的同调代数步骤有用。
- [[2609.17851]]：Bochner 积分的范畴刻画同样研究"分析结构如何由纯代数/范畴数据确定"，与本文"上同调由函数环结构刻画"的问题意识相通，可在理解比较映射的自然性要求时参考。
- 技术迁移：把比较映射的整系数同构拆成"有理部分 + 模 p 部分 + 纤维序列"的三段式论证，能否用于其他算术–拓扑比较定理（如 étale 上同调到 Betti 上同调）的精确度改进？

### 可以尝试的方向

- [ ] 尝试把主定理推广到非交换 C*-代数，用 KK-理论或稳定同伦论取代交换情形的 Gelfand 对偶论证
- [ ] 判定 i = 2j−1 处满射是否能加强为同构，即相应纤维群在该度是否消失
- [ ] 与 [[2609.09871]] 的 étale Chow 群结果在共同定义域上做比较，寻求统一的 motivic/étale 比较陈述

### 批判性思考

- 证明的两大输入（Cortiñas–Thom 的 K-理论同构与 motivic 滤过框架）都是既有结果，本文的增益主要在于把已知同构提升到带权重、带系数的 motivic 层面，属于"精化型"贡献，新几何/新不变量有限。
- 交换性假设在论证中被用于把环与底空间的上同调对接，非交换情形需要为底对象寻找替代物；作者并未讨论这一障碍的难度，因此推广前景的表述偏乐观。
