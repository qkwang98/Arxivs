# Stable trace formula for Newton strata of Shimura varieties

keywords: [稳定迹公式, 内镜, Newton 层, Lefschetz 数, Langlands–Kottwitz 方法, Shimura 簇, 自守表示]
related_paper: "Kottwitz（Ann. of Math., 1990）Shimura 簇上同调与稳定迹公式 Theorem 7.2——本文给出其 Newton 层版本"
one_liner_summary: "本文用改造后的 Langlands–Kottwitz 方法，对 abelian type Shimura 簇的单个 Newton 层构造稳定迹公式：把 Frobenius–Hecke 对应在紧支 $\\ell$-进上同调上的 Lefschetz 数表达为内镜群上稳定迹公式几何侧的椭圆分布之和，并给出判定哪些椭圆内镜群能对该层有贡献的群论判据。"

## 核心定位

- **解决的问题**：在好约化素数的特殊纤维上，Shimura 簇按 $p$-进齐次空间（$p$-divisible group / $F$-isocrystal）的 Newton 多边形分层；本文要回答的问题是：单个 Newton 层 $\overline{S}_{K^p}(b)$ 上，Frobenius–Hecke 对应 $\mathrm{Frob}_q^n\times f^p$ 在紧支 $\ell$-进上同调（可带 $\ell$-进局部系数 $\mathcal{F}_\xi$）中的 Lefschetz 数 $c_b(n,f^p,\xi)$，能否用自守表示侧的数据（稳定迹公式的项）来描述。
- **大图景位置**：Langlands 纲领中 Shimura 簇的上同调同时携带折射域 Galois 群与 Hecke 代数的可交换作用，其分解同时反映 Galois 表示与自守表示；Langlands–Kottwitz 方法（Lefschetz–Verdier 迹公式与 Arthur–Selberg 迹公式的比较）历来用于描述整簇的 zeta 函数。此前 Kret 与 Liu 只在 Kottwitz 簇（基本层与某些中间层）完成自守描述，其稳定迹公式没有非平凡内镜项；本文把这一方法推进到一般 abelian type Shimura 簇，处理内镜项确实出现的困难情形，并把"整簇"精细化为"单个 Newton 层"。
- **主要贡献**：（1）主定理：设 $(G,X)$ 为 abelian type Shimura 数据，$G^{\mathrm{der}}$ 单连通、$Z(G)$ 的极大 $\mathbb{Q}$-split 环面等于其极大 $\mathbb{R}$-split 环面，$p$ 对 $G$ 好且在 $p$ 处取 hyperspecial 层 $K_p=\mathcal{G}(\mathbb{Z}_p)$、$K^p$ 充分小，固定 $b\in B(G_{\mathbb{Q}_p},\mu_h^{-1})$、$f^p\in\mathcal{H}(G(\mathbb{A}_f^p)/\!/K^p)$ 与局部系统 $\mathcal{F}_\xi$；则对充分大的 $n$，$\sum_i(-1)^i\mathrm{tr}\big(\mathrm{Frob}_q^n\times f^p\mid H^i_{c,\mathrm{et}}(\overline{S}_{K^p}(b)_{\overline{\mathbb{F}}_q},\mathcal{F}_\xi)\big)=\sum_{\mathcal{H}\in\mathcal{E}_{\mathrm{ell}}(G)_b}\iota(G,H)\,\mathrm{ST}_e^H(h^p h_p\chi^{\mathcal{H}}_{b,n}h_\infty)$，即 Lefschetz 数等于若干内镜群上稳定迹公式几何侧椭圆部分之和。（2）定义子集 $\mathcal{E}_{\mathrm{ell}}(G)_b\subset\mathcal{E}_{\mathrm{ell}}(G)$：借助 Newton 点映射 $\overline{\nu}$ 与基本群映射 $\kappa$（以及内镜三元组诱导的 $f^{\mathcal{H}}:\mathcal{N}(H)\to\mathcal{N}(G)$、$\psi^{\mathcal{H}}:\pi_1(H)\to\pi_1(G)$）给出纯群论判据，判定哪些椭圆内镜数据能贡献于给定层，并证明该条件可从根数据检验、且满足条件的 $b_H$ 只有有限多个。（3）构造把层贡献隔离出来的截断函数 $\chi^{\mathcal{H}}_{b,n}:H(\mathbb{Q}_p)\to\{0,1\}$，证明其光滑且在 $H(\mathbb{Q}_p)$ 的稳定共轭类上常值（故 $h_p\chi^{\mathcal{H}}_{b,n}$ 紧支）。（4）在 $\mathrm{GU}(r,s)$ 型酉 Shimura 簇上给出例子：存在中间 Newton 层只含平凡内镜贡献，而周围整簇的上同调却有非平凡内镜贡献——说明"层化"确实会杀掉部分内镜项。
- **关键先驱工作**：Kottwitz 关于 Langlands–Kottwitz 方法与内镜稳定化的一系列工作（尤其 Shimura 簇上同调与稳定迹公式的 Theorem 7.2、$B(G)$ 与 $\mathfrak{K}(I)$ 的定义）；Kisin–Shin–Zhu 更一般的稳定迹公式（本文第二条技术假设即在该框架下可去除）；Kret 与 Liu 关于 Kottwitz 簇基本层/中间层的自守描述；Rapoport–Richartz 的 Newton 分层（半连续性定理）；Kisin、Vasiu、Kim–Madapusi Pera 关于 abelian type 数据在 hyperspecial 层整模型的存在性；Kottwitz–Shelstad 的内镜理论；Arthur 关于迹公式稳定化与内镜的框架。
- **结果边界**：需要 $(G,X)$ 为 abelian type 并满足两条技术假设（单连通导群、中心 $\mathbb{Q}$-split 与 $\mathbb{R}$-split 极大环面相同，后者是 Kottwitz 形式的简化假设，Kisin–Shin–Zhu 已可去除）；要求 $p$ 好、层为 hyperspecial、$K^p$ 充分小；公式只对充分大的 $n$ 成立，且截断函数 $\chi^{\mathcal{H}}_{b,n}$ 通过 $j=n[\mathbb{F}_q:\mathbb{F}_p]$ 依赖 $n$（而集合 $\mathcal{E}_{\mathrm{ell}}(G)_b$ 与 $n$ 无关）；本文完成的是几何侧椭圆部分的稳定化，谱侧的稳定化在最一般情形仍条件依赖于 Arthur 猜想；$\chi^{\mathcal{H}}_{b,n}$ 本身不必紧支，紧支性由 $h_p$ 提供。
- **开放问题**：能否去掉两条技术假设（特别是中心环面假设）而保持结论？如何用这一自守描述真正算出某些 Newton 层的几何信息（维数、不可约分支数、zeta 函数）？非椭圆项与非稳定分布如何处理，谱侧是否有无条件的对应陈述？判据 $\mathcal{E}_{\mathrm{ell}}(G)_b$ 能否在更多族（正交群、Siegel 型、例外群）中显式算出，并解释"什么时候非平凡内镜贡献消失"？
- **应用与推广**：把 Newton 层 Lefschetz 数写成内镜群上稳定分布的线性组合，等于为该层铺好了与自守谱数据直接比较的道路——在有利情形下可反推层的几何性质（Kret、Liu 在 Kottwitz 簇已示范）。其中 $\mathfrak{K}(G_\gamma^0)$ 控制内镜贡献、以及用分层的截断函数从整簇迹公式中"切出"单一层这两项技术，具有独立价值，可望迁移到其它模 $p$ 上同调与局部-整体比较问题（如仿射 Deligne–Lusztig 簇、局部模型的分层、Shimura 簇的模 $p$ 上同调）。附带地，本文源于作者在阿姆斯特丹大学攻读博士期间的工作，由 Arno Kret 建议把其结果推广到内镜项非平凡的情形。

## 主动思考区

### 与其他工作的联系

- [[2609.11045]]：该文对局部域上导子为一的 temper 表示显式算出对偶 newform 的 Rankin–Selberg 积分，从而得到自守 $L$ 函数中心值的显式常数倍与局部相对特征的结论，属自守谱一侧的定量结果。本文右侧每一项都是内镜群上稳定迹公式的椭圆分布，其最终用途正是与自守谱数据比较；该文的显式局部计算提示了比较落地时所需的局部输入形态（局部因子、相对特征）。
- [[2609.12385]]：该文绕开表示论范式，用重整化轨道积分构造一般型 Iwahori–Hecke 代数余中心的"几乎对偶基"，核心工具是轨道积分与共轭类典范元。本文稳定化的关键在于把有理共轭类上的不变分布重组成稳定共轭类上的稳定分布（稳定轨道积分 $\mathrm{SO}_{\gamma_H}$、Tamagawa 数 $\tau(H)$、常数 $\iota(G,H)$），两文共享轨道积分/稳定共轭类这套技术母体，可互为参照。
- [[2609.10483]]：该文给出标准模被四元数一般线性群区分的组合判据与重数上界，是"重数信息判定表示论性质"的一类结果；本文的 Lefschetz 数最终也应可写成 $\sum_\pi m(\pi)\mathrm{tr}\,\pi(f)$ 的形式，因此"先从几何侧算出稳定分布、再解释为重数"是两文共同的算术-表示论逻辑。
- 技术迁移：本文用截断函数 $\chi^{\mathcal{H}}_{b,n}$ 把整簇迹公式"砍"到单一层上，这套做法与 Kisin–Shin–Zhu 处理整簇时的截断在结构上同源；若把 $\chi$ 的角色换成其它局部条件（如按 Hodge 多边形、按 $p$-rank 或按 Ekedahl–Oort 层分层），能否得到平行结论？

### 可以尝试的方向

- [ ] 在 $\mathrm{GU}(r,s)$ 例子之外，显式计算正交型与 Siegel 型 Shimura 簇的 $\mathcal{E}_{\mathrm{ell}}(G)_b$，寻找更多"整簇有内镜贡献、某个层却没有"的实例。
- [ ] 尝试用主定理计算某个最小非平凡层（如基本层或维数已知的中间层）的 zeta 函数，并与几何方法的结果对照。
- [ ] 考察能否用截断函数技术直接在模 $p$ 上同调（而非紧支 $\ell$-进上同调）上得到稳定表述，以对接 Arthur 猜想的谱侧。

### 批判性思考

- 主定理的形态是对 Kottwitz 的 Theorem 7.2 的逐项改造，其"新内容"集中在两处：集合 $\mathcal{E}_{\mathrm{ell}}(G)_b$ 的群论判据与截断函数 $\chi^{\mathcal{H}}_{b,n}$ 的光滑性。这种"只改 $p$-分量"的结构说明方法在概念上并不出人意料（局部系统只通过 $h_\infty$ 进入公式，与层化条件独立），但也因此把困难精确地集中在了 $p$-处的局部计算上。
- 第二条技术假设（中心极大 $\mathbb{Q}$-split 环面 = 极大 $\mathbb{R}$-split 环面）是为了保证 Lefschetz 公式中体积因子 $c_\infty$、$c_1(\gamma_0,\gamma,\delta)$ 的有限性而设的简化；作者明言 Kisin–Shin–Zhu 已能去掉它，这意味着本文的假设更像"为接入 Kottwitz 原始框架所付的成本"，在评审视角下会削弱结果的最终性，读者需要判断这种简化是否掩盖了层化本身的困难（作者的辩护是两者相互独立）。
- 谱侧稳定化仍条件依赖于 Arthur 猜想，而迹公式比较的意义恰恰在于两端都要稳定：因此本文严格来说是"把几何侧准备到位"的一步，其主定理的用途受限于与之比较的自守谱结论是否已（条件地）成立。文中 $\mathrm{GU}(r,s)$ 的例子给出方向性信息，但"层化会消灭内镜贡献"只是存在性示例，尚未形成一般判据。
