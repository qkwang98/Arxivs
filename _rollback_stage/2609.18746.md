# Support $\tau$-tilting modules over Morita context algebras: A bilateral approximation approach

keywords: [support τ-tilting 模, Morita 上下文代数, 双边逼近, 挠类, 角归纳, 最小逼近, 推出修正]
related_paper: "Zhang 关于三角矩阵代数的逼近构造（Theorem 5.1）——本文的 $N=0$ 特例恰好退回该构造"
one_liner_summary: "本文为有限维 Morita 上下文代数 $\\Lambda=\\bigl(\\begin{smallmatrix}A&N\\\\ M&B\\end{smallmatrix}\\bigr)_{\\phi,\\psi}$ 引入双边逼近构造：交替用最小逼近与推出修正两个角，把 $A$ 与 $B$ 上的 support $\\tau$-tilting 模粘成 $\\Lambda$ 上具有指定角挠类的 support $\\tau$-tilting 模，并给出单边情形与直接角归纳的判据及其终止性障碍。"

## 1.  核心定位

- **解决的问题**：support $\tau$-tilting 模与函子有限挠类一一对应，因此"构造具有指定挠类的 support $\tau$-tilting 模"等价于证明给定挠类的函子有限性并找出其 Ext-投射生成元。对三角矩阵代数，Zhang 已用角上的最小左逼近把直接交叉项替换掉从而显式写出粘合模，Gao–Huang 则刻画了直接角归纳所得的 support $\tau$-tilting 模。本文要回答的是：当代数换成一般 Morita 上下文代数（两个连接映射 $\phi,\psi$ 把两个角耦合起来）时，这套构造与判据能否成立、以何种形式成立。
- **大图景位置**：三角矩阵代数只带单侧交叉项，其对称情形方可退回到 recollement/ladder 框架；一般 Morita 上下文代数的两条结构映射相互耦合，角上独立选取的逼近一般不构成模，因此 Zhang 的 ladder 技术直接失效。本文的解法是引入两个推出修正并组织成链："双边修正 $\Longrightarrow$ 单边修正 $\Longrightarrow$ 直接角归纳"，从而把 Zhang 的逼近构造与 Gao–Huang 的直接归纳判据统一为同一套机制的不同退化层次。
- **主要贡献**：（1）双边定理：从 $F_A X$（$F_A=-\otimes_A e\Lambda$）与 $F_B Y$ 出发构造两条交替修正的梯子，每一步用最小逼近替换一个角、再用推出修改另一个角以保持 Morita 上下文恒等式；设两条梯子都终止，把两个极小目标的直和删去重复同构直和项得到 $K$，则 $K$ 是 $\tau$-rigid、$\mathrm{Fac}_\Lambda K=\mathcal{T}_{X,Y}$，且对任意左 $\mathrm{add}\,K$-逼近 $c:\Lambda\to K'$ 有 $K\oplus\mathrm{Coker}\,c\cong P(\mathcal{T}_{X,Y})$ 是 support $\tau$-tilting，其中 $\mathcal{T}_{X,Y}=\{W\in\mathsf{mod}\,\Lambda\mid We\in\mathcal{X},Wf\in\mathcal{Y}\}$、$\mathcal{X}=\mathrm{Fac}_A X$、$\mathcal{Y}=\mathrm{Fac}_B Y$。（2）单边定理：若 $X\otimes_A N\in\mathrm{Fac}_B Y$，取最小左 $\mathrm{Fac}_A X$-逼近 $p:Y\otimes_B M\to X_Y$，则 $G_{\mathcal{X}}(X,Y)=F_A X\oplus K_p\cong P(\mathcal{T}_{X,Y})$ 是 support $\tau$-tilting 且其 $\mathrm{Fac}_\Lambda$ 恰为 $\mathcal{T}_{X,Y}$；当 $N=0$ 时即 $F_A X=(X,0)$、$K_p=(X_Y,Y)_p$，退回 Zhang 的三角构造，对称版本给出对侧单边情形。（3）直接角归纳刻画：在根条件 $\mathrm{Im}\,\phi\subseteq J(A)$、$\mathrm{Im}\,\psi\subseteq J(B)$ 下，$F_A X\oplus F_B Y$ 是 support $\tau$-tilting 当且仅当 $X\in\mathsf{stau}\,A$、$Y\in\mathsf{stau}\,B$、$Y\otimes_B M\in\mathrm{Fac}_A X$、$X\otimes_A N\in\mathrm{Fac}_B Y$，此时投射补为 $F_A P_X\oplus F_B P_Y$ 且 $\mathrm{Fac}_\Lambda(F_A X\oplus F_B Y)=\mathcal{T}_{X,Y}$；充分方向（零修正特例）对任意连接映射成立，$N=0$ 时把 Gao–Huang 判据从代数闭域推广到任意域。（4）终止性与障碍：给出对无条件终止的广泛障碍（当 $N\otimes_B M$ 上存在满足特定条件的元素时梯子一般不会终止），并给出例子说明双边修正在两个单边相容条件都不满足时仍可终止、也存在永不终止的情形。
- **关键先驱工作**：Adachi–Iyama–Reiten 与 Jasso 关于 support $\tau$-tilting 模（对）与函子有限挠类的一一对应；Zhang 关于三角矩阵代数的粘合模显式构造（其证明依赖对称 ladder of recollements）；Gao–Huang 关于直接角归纳的判据、Peng–Ma–Huang 的相关构造与逆命题；Li–Zhang 关于平凡扩张的归纳构造；Di–Tang–Yang 关于零连接映射 Morita ring 上的弱 silting 模、Asefa–Xu 在零乘积条件下的 silting 刻画；Wang–Luo–Liu–He–Wu 通过好 recollement 的范畴化粘合。
- **结果边界**：双边定理以"两条修正梯子都终止"为假设，而终止性不是自动的——文中给出的是终止的障碍而非充要条件，因此该定理本质上是"条件性构造"；单边定理需要预处理条件 $X\otimes_A N\in\mathrm{Fac}_B Y$；直接归纳的"当且仅当"需要根条件才能数清直和项（充分方向与 $\tau$-rigid 判据对任意连接映射成立，逆命题依赖根条件）；角输入模 $X,Y$ 须取基本对象，而逼近映射、正合列与推出图中出现的对象保留真实重数；全文限于有限维 $k$-代数（不假设 basic），不涉及无限维或导出框架。
- **开放问题**：双边梯子终止的充要条件是什么？去掉根条件后直接角归纳的逆命题是否仍成立？这套"交替修正 + 推出"的粘合能否提升到导出/更高维的对应物（$n$-挠对、silting 对象、缺失范畴与三角范畴的粘合）？当代数带有 ladder/recollement 结构时，双边修正与 recollement 粘合的关系如何精确刻画？
- **应用与推广**：为"把两个角上的挠类粘成整体挠类"提供了可执行的算法化流程（交替最小逼近 + 推出修正 + 终止时删除重复直和项），可用于构造具体代数的 $\tau$-tilting 有限性例子与计数；把 silting/挠类粘合技术从三角矩阵代数推广到具有双侧关联双模结构的一般代数（Morita ring、平凡扩张、张量积代数等），有望在表示论与代数的导出等价问题中复用。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- [[2609.10217]]：该文研究有限维代数上的 brick 链滤过，用子模簇证明固定模的 torsion 部分只取有限多个值（回答 Pavón 问题），并给出砖链滤过个数的 $2^{d^2}$ 上界与 $\tau$-tilting 有限代数上的多项式系数上界。它与本文共享"挠类/$\tau$-tilting 有限性"的核心关切：该文在固定代数内部研究挠类的组合计数与有界性，本文则研究如何跨角把挠类粘起来，两者的结论放在一起可用于估计由角挠类粘出的模所生成的挠类规模。
- [[2609.13699]]：该文证明在带可延拓 $t$-结构的三角范畴中，对 heart 的挠类先作 HRS 倾斜再完备化，与先完备化再对像作 HRS 倾斜结果一致，并得到左 silting 变异与完备化的相容性。本文在模范畴层面用挠类刻画 support $\tau$-tilting 模，该文则在三角范畴层面处理挠类的倾斜与完备化，属于同一"用挠类组织倾斜理论"纲领下的范畴化版本；本文的角粘合若能与 HRS 倾斜组合，或可给出跨角粘合的三角范畴表述。
- [[2609.10396]]：该文刻画带 $(-d)$-simple-minded system 的三角范畴必可实现为局部有限严格正 dg 代数的余奇异商，具有明显的 Morita 型（范畴等价/实现）味道。本文的单边定理在 $N=0$ 时退回三角矩阵代数的已知构造，提示"上下文代数的角粘合"与"Morita 型实现"之间存在可以相互翻译的语言。
- 技术迁移：文中"用推出修正来修复被最小逼近破坏的结构恒等式"这一手法，是否可迁移到其它带两条耦合结构映射的对象（例如双模复形、带两个作用的结构代数、或偏序集路线上的 diagram 代数粘合）？

### 2.2.  可以尝试的方向

- [ ] 尝试给出梯子终止的充要条件（例如用 $N\otimes_B M\to Y\otimes_B M$ 与 $X\otimes_A N$ 上的特定元素/子模条件刻画），并检验文中障碍例子是否恰为该条件的边界情形。
- [ ] 对具体小代数（如 $A=B=k$、$N,M$ 为单模的极简 Morita 上下文代数）穷举计算双边修正的终止行为与所得 support $\tau$-tilting 模个数，与整体 $\tau$-tilting 有限性对照。
- [ ] 检验去掉根条件后逆命题的反例结构，判断是"需要更强假设"还是"式子的形态需要修正"。

### 2.3.  批判性思考

- 双边定理的叙述结构说明作者清楚终止性是真问题：定理以"两条梯子都终止"为前提，同时用一节给出终止的障碍与反例，这种"给条件、给障碍、给例子"的写法诚实地暴露了方法的适用边界，但读者应注意该定理并不能保证（甚至不总能）对给定 $(X,Y)$ 实际产出 support $\tau$-tilting 模。
- 三层次结构（双边 $\Rightarrow$ 单边 $\Rightarrow$ 直接归纳）在概念上很整齐，代价是条件逐层减弱、结论也逐层具体：最漂亮的"当且仅当"要付出根条件 $\mathrm{Im}\,\phi\subseteq J(A),\mathrm{Im}\,\psi\subseteq J(B)$ 与基本对象约定；这类"结构假设换判据"的权衡在文中并未给出最优性讨论（例如根条件是否必要）。
- 与已有工作的关系被表述为"推广"：单边情形退回 Zhang 的三角构造，$N=0$ 时把 Gao–Huang 判据从代数闭域放宽到任意域。这提示本文的实质创新集中在"两个交叉项耦合时的推出修正"与"终止性现象"上；但作者尚未把"何时双边修正比单边/直接归纳严格更强"整理成清晰的判据，例子的作用主要还是说明可能性而非刻画分界。
