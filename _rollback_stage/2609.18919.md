# Wehrl-type entropy problem for compact connected semisimple Lie groups

keywords: [Wehrl 型熵, 相干投影子, Husimi 函数, 紧连通半单 Lie 群, 二阶变分, 极值矩性质, Casimir 恒等式]
related_paper: "Lieb–Solovej 关于 SU(2) 与 SU(N) 对称表示的 Wehrl 型熵不等式（本文把该现象推广到任意紧连通半单 Lie 群并给出唯一性刻画）"
one_liner_summary: "本文沿用 Frank–Lieb 在 Heisenberg 群上处理 HLS 不等式稳定性的二阶变分策略：沿 Killing 场方向对极值子作扰动并把各方向二阶导数求和，再用最高权向量的极值矩性质闭合，从而证明对任意紧连通半单 Lie 群，相干投影子是全部密度矩阵上唯一的 Wehrl 型熵极小元，也是 $x^p$（任意实数 $p>1$）与 $x\log x$ 型 Husimi 矩的唯一极大元。"

## 1.  核心定位

- **解决的问题**：设 $G$ 紧连通半单，$\pi:G\to U(V_\lambda)$ 为最高权 $\lambda$ 的有限维不可约酉表示，$v_g=\pi(g)v_\lambda$ 生成相干投影子 $P_g$，Husimi 函数 $Q_\sigma(g)=\operatorname{tr}(\sigma P_g)$。本文证明对任意单位向量 $v$，
  $\int_G \Phi(|\langle v_g,v\rangle|^2)\,\mathrm{d}g \le \int_G \Phi(|\langle v_g,v_\lambda\rangle|^2)\,\mathrm{d}g$，
  其中 $\Phi(x)=x^p$（$p>1$）或 $\Phi(x)=x\log x$，且等号仅当 $v=e^{i\theta}v_h$；进而对任意密度矩阵 $\sigma$ 得到 $\int_G\Phi(Q_\sigma(g))\mathrm{d}g\le\int_G\Phi(Q_{v_\lambda}(g))\mathrm{d}g$，等号仅当 $\sigma=P_h$，由此得到熵不等式 $S^W(\sigma)\ge S^W(\operatorname{proj}v_\lambda)$。
- **大图景位置**：Wehrl 原始猜想（Heisenberg 群）经 Lieb、Carlen、Luo 解决；$SU(2)$ 的 Bloch 相干态由 Lieb–Solovej 解决并推广到 $SU(N)$ 对称表示；$SU(1,1)$ 全纯离散序列由 Lieb–Solovej 提出、Kulikov 用双曲等周不等式完成；任意紧连通半单群此前只有 Sugita 对整数幂 $p\ge2$ 的张量积方法。本文把这些片段收口为一条普适定理，并首次在一般凸函数族上给出纯态等号的刚性刻画。
- **主要贡献**：（1）对任意紧连通半单 Lie 群证明 $\Phi=x^p$（任意实数 $p>1$）与 $\Phi=x\log x$ 两类函数的主不等式及纯态等号条件；（2）由凸性归约得到密度矩阵版本与熵的唯一极小性；（3）提出并落地方法论机制：取 $-i\,\mathrm{d}\pi(X_j)$ 沿负 Killing 型正交基作扰动 $\gamma_j(t)$，同质性把问题化为标量函数 $\phi_j(t)$，由 Casimir 恒等式得 $\sum_j\phi_j''(0)=4p(p-1)M(\|\lambda\|^2-\sum_j\langle w_*,T_jw_*\rangle^2)$，再由极值矩引理保证右端非负，结合逐方向 $\phi_j''(0)\le0$ 逼出 $\|\lambda\|^2=\sum_j\langle w_*,T_jw_*\rangle^2$，而该等式只在相干向量处成立。
- **关键先驱工作**：Wehrl 的定义与猜想；Lieb 的 sharp Hausdorff–Young / Young 卷积证明与其对 $SU(2)$ 的猜想；Carlen 的对数 Sobolev 证明与首个等号条件；Luo 的超压缩性证明；Lieb–Solovej 关于 $SU(2)$、$SU(N)$ 与 $SU(1,1)$ 的结果；Kulikov 对一般凸函数的证明与等号刻画；Frank 与 Kulikov–Nicola–Ortega-Cerdà–Tilli 对纯态优化子的刻画；Frank–Nicola–Tilli、Nicola–Riccardi–Tilli 的定量稳定性；Sugita 的整数幂方法与 van Haastrecht–Zhang 的 Casimir 证明；Frank–Lieb 的二阶变分范式（作者明确致谢 Rupert Frank 指出这一相似）。
- **结果边界**：结论要求 $G$ 紧、连通、半单（Killing 型负定，才存在正交基 $T_j$ 与求和恒等式），且表示有限维不可约酉；密度矩阵版本经凸性由纯态情形归约，严格凸性用于等号的唯一性；核心输入的"极值矩性质"是关于最高权向量的表示论事实，在非紧群、无穷维表示中没有现成对应，故方法不能直接外推。
- **开放问题**：同一机制对非紧半单群、无穷维表示（离散序列、主序列）的适用范围；一般凸函数（不必形如 $x^p$ 或 $x\log x$）下等号刻画是否保持同样刚性；能否给出定量稳定性（偏离相干态时熵增益的显式下界）；Killing 场二阶变分是否可用于更一般的极值态分类；文中把正则性细节放入附录，其恒等式的最一般适用形式仍有整理空间。
- **应用与推广**：在量子信息语境中，该结论说明"以任意紧群相干态系综作为测量输入时，相干投影子是最大输出熵/幂矩的输入态"，即相干态是最"经典"的输入，可用于判别输出的经典性；技术层面，"沿群作用切方向作二阶变分 + 一条矩不等式闭合"这一组合可迁移到任何带紧群对称性与核函数的变分问题（不变算子谱的极值刻画、轨道积分极值、紧对称空间上热核型泛函的极值）。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Frank–Lieb 关于 Heisenberg 群上 Hardy–Littlewood–Sobolev 不等式稳定性与最优元的证明 — 本文的证明骨架与之同源（沿生成元方向作二阶变分、对方向求和、再用谱/矩比较锁定最优元），差别只是把 HLS 泛函换成了 Husimi 矩泛函。
- [[2609.13412]]：该文用可验证的精确证书处理 Lieb 提出的永久支配猜想（对称群特征标对广义行列式的支配），与本文同属"把 Lieb 型极值/不等式猜想严格化"的谱系；两者都把极值问题的核心归结为某个表示论量的正性，只是一个对象是矩阵函数的支配关系，另一个是紧群相干态的熵。
- [[2609.12134]]：该文为 $SU(2,2)$ 的酉 $(\mathfrak{g},K)$-模建立系数演算，核心工具是 $K$-型与 Casimir 作用；本文同样把 Casimir 恒等式当作"能量会计"（用 $\|\lambda\|^2$ 控制 $\sum_j\langle w_*,T_jw_*\rangle^2$），两者的技术语言高度互通：一个用系数描述酉模结构，另一个用 Casimir 把二阶变分求和封闭。
- [[2609.13365]]：该文构造简单 Lie 代数的显式"色张量"，强调具体表示层面的可计算性；本文的结论虽只依赖最高权与 Killing 型，但在给定具体表示时同样需要显式的权与不变量，两类工作可以互相供给"李代数上的可算数据"。
- 技术迁移：把该范式迁移到非紧情形（紧 Riemann 对称空间上热核/谱的极值问题）或算子代数上的信道容量极值问题，是最自然的下一个实验。

### 2.2.  可以尝试的方向

- [ ] 对不可微的一般凸函数，尝试用正则化极限得到统一的等号刻画，检验唯一性是否仍只落在相干投影子。
- [ ] 把二阶变分求和升级为定量稳定性：当 $\|\lambda\|^2-\sum_j\langle w_*,T_jw_*\rangle^2>0$ 时给出熵增益的线性或二次下界。
- [ ] 测试秩 $\ge2$ 的非紧半单群上是否存在类似的 Killing 场变分恒等式，即使只得到部分结果或只覆盖离散序列。

### 2.3.  批判性思考

- 证明骨架很短：二阶变分 + 极值矩引理即可闭合，工作量集中在技术引理与 Casimir 恒等式的显式计算上（正则性与表示论细节被放入两个附录）。因此结果的可信度高度依赖附录恒等式的正确性，阅读时应重点核查 $\sum_j\phi_j''(0)$ 的推导与极值矩性质的最一般形式。
- "极值矩性质"本身是独立的表示论事实，本文把它当黑箱使用；该性质对"非最高权"极值态的排除在所有紧群上是否同样强，值得单独立项考察。
- 作者把与 Frank–Lieb 的类比写入正文并致谢，说明方法借用是自觉的，本文的创新更多在于"把已有范式搬到正确的普遍位置并补上等号刻画"，而非发明新机制——评价其贡献时应按此定位理解。
