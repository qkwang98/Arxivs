# Bertini's theorem for $F$-rationality is false

keywords: [F-有理性, F-单射性, Bertini 定理, 素特征奇点, 一般超平面截口]
related_paper: "De Stefani–Polstra–Simpson–Zhang，F-纯度假设下 F-有理性对一般超平面截口的持久性（文献 DSPS25）"
one_liner_summary: "本文在 $k=\overline{\F_2}$ 上构造九维 F-有理仿射簇与射影簇，使其在稠密多个超平面上的截口既非 F-有理也非 F-单射，从而否证了 F-有理性版本的 Bertini 定理。"

## 核心定位

- **解决的问题**：F-有理性是否如复数域上的有理奇点那样，在一般超平面截口下得以保持？本文给出否定的答案，并指出失效甚至可以强到截口连 F-单射性都不满足。
- **大图景位置**：复数域上"具有有理奇点"满足两条持久性条件——沿平坦局部同态的提升，以及一般超平面截口下的保持；前者由 Elkik 关于有理奇点形变的结果给出，后者是经典 Bertini 光滑性定理的推论。在素特征一侧，已有研究表明 F-有理性不满足第一条，且在额外 F-纯度假设下才满足第二条。本文说明一旦去掉 F-纯度假设，Bertini 定理确实失效，并回答了关于正规簇或处处 F-单射的簇上是否也可能失效这一遗留问题。
- **主要贡献**：
  1. 仿射反例：当 $k=\overline{\F_2}$ 时，存在九维 F-有理整环 $R$（有限生成于 $k$）、局部闭嵌入 $X=\Spec R\hookrightarrow \PP^{19}_k$ 以及稠密开集 $U\subseteq (\PP^{19}_k)^\vee$，使得对一切 $H\in U(k)$，$X\cap H$ 都不是 F-有理的，事实上甚至不是 F-单射的；
  2. 射影反例：存在九维 F-有理射影簇 $\mathfrak{X}$、闭嵌入 $\mathfrak{X}\hookrightarrow \PP^{29}_k$ 与稠密开集 $U$，使所有 $H\in U(k)$ 对应的 $\mathfrak{X}\cap H$ 都不是 F-单射的；
  3. 同一批例子表明 Bertini 定理对 F-反幂零性（严格介于 F-有理性与 F-单射性之间的奇点条件）同样失效；
  4. 由于 F-有理性蕴含 F-单射性与正规性，上述反例同时解决了关于正规簇以及处处 F-单射的簇的遗留问题。
- **关键先驱工作**：Elkik 关于有理奇点形变的工作与经典 Bertini 光滑性定理；Har98、MS97、Smi97 通过约化到素特征建立有理奇点与 F-有理奇点联系的结果；Abe01、Ene00、Ene09、PSZ18、SZ13 等围绕 Frobenius 奇点持久性的研究计划；CGM86 给出的两条持久性现象之间的公理化联系（入射对应闭包的形变）；QGSS24 关于纯不可分基变换下 F-有理性丢失的反例；SZ13 的射影曲面例子（仅在有限多点之外 F-单射）。
- **结果边界**：结论在 $k=\overline{\F_2}$ 上给出，且属于存在性反例；射影反例不如仿射反例显式——$\mathfrak{X}$ 是 $X$ 的射影紧化，其嵌入先由显式闭浸入 $\mathfrak{X}\hookrightarrow\PP^{2547}_k$ 实现，再通过从一般中心 $\PP^{2517}_k\subseteq\PP^{2547}_k$ 出发的线性投影压缩到 $\PP^{29}_k$。
- **开放问题**：加入何种额外条件（如 F-纯度、处处 F-单射、正规性）才能让 Bertini 型持久性成立；在其它素特征或其它奇点条件下是否存在类似反例。
- **应用与推广**：为素特征奇点理论提供了一族可计算的检验实例；构造所依赖的"加权变体 + 展平族"手法（造出在 $\A^6$ 上的平坦族，其一般纤维 F-有理但非几何既约），可迁移到其它关于 Frobenius 奇点持久性的问题。

## 主动思考区

### 与其他工作的联系

- [[2609.15691]]：同处素特征交换代数语境，围绕用修改族与 Frobenius 平坦性（Kunz 定理）刻画正则性；本文的反例说明 F-有理性的持久性需要额外假设，与该文"何种修改族足以检测性质"的问题形成呼应。
- [[2609.12854]]：同属交换代数中带构造性操作的奇点研究（下降、半正规化与导子），可为理解本文的紧化与局部化操作提供邻近参照。
- 技术迁移：本文在仿射情形使用初等紧闭包计算、在射影情形改用典范模与 Frobenius 对偶来判定非 F-单射性，这套"对偶 + 局部化"判据可尝试用于检验其它 Frobenius 奇点条件在一般截口下的行为。

### 可以尝试的方向

- [ ] 能否把反例降到更低维数，或嵌入更小的环境射影空间 $\PP^N$？
- [ ] 在 $k=\overline{\F_p}$（任意素数 $p$）或更一般的基域上是否存在类似的九维反例？
- [ ] 能否刻画"一般超平面截口保持 F-有理性"的充要条件，而不止于 F-纯度这一充分条件？

### 批判性思考

- 射影反例的嵌入依赖从一般中心出发的线性投影，其中间维数（2547）与最终维数（29）差距极大，是否存在更简洁的显式紧化值得追问。
- 作者在文中披露这些例子是借助大语言模型辅助寻找的，并说明其中若干断言并不准确、证明被重新整理；因此读者宜直接核对初等紧闭包计算与对偶论证的细节。
- 结论是存在性反例，并不能说明 F-有理性在一般截口下"通常"失效；F-纯度假设在多大程度上是本质的仍待澄清。
