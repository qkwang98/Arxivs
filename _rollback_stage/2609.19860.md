# A Comparison Theorem for Parahoric Character Sheaves

keywords: [parahoric 特征层, 深水平 Deligne--Lusztig 特征, Jordan 分解, 广义 Green 函数, 正交性, 子域对称重数, Moy--Prasad 群]
related_paper: "A tensor square theorem for characters of $\\operatorname{GL}_{n}(q)$（arXiv:2609.17319）"
one_liner_summary: "本文为 parahoric 子群上特征层（Ivanov--Nie--Yu 构造）的特征函数建立 Jordan 分解公式，并在 $q$ 足够大时证明这些特征函数等于 $(-1)^{\dim G}$ 倍的对应深水平 Deligne--Lusztig 特征，从而把 Lusztig 1990 年的比较定理推广到正深度、把 Bezrukavnikov--Chan 与 INY 的结果从正则情形推广到任意情形；文章还证明了广义深水平 Green 函数与简单诱导特征层特征函数的正交性，并给出 $G^{F^2}$ 特征限制到 $G^{F}$ 的重数的层论表达式。"

## 核心定位

- **解决的问题**：把 Lusztig 关于经典特征层之特征函数与 Deligne--Lusztig 特征相等的比较定理，从有限约化群推广到 parahoric 子群上的特征层，并把已有的深水平结果（Bezrukavnikov--Chan、Ivanov--Nie--Yu）从正则特征扩展到任意深度的任意特征，同时给出深水平 Green 函数的正交性与其在子域对称重数上的应用。
- **大图景位置**：Lusztig 提出有限局部环上约化群的"特征层类比"以来，深水平/正深度情形一直是待补的缺口。本文补上比较定理这一步：在 $r=0$、$\mathbf{x}$ 为超特殊点时，$G_{r,\mathrm{vreg}}$ 恰是 $G_0$ 中的正则半单元轨迹，故定理退化为 Lusztig 1990 的比较定理，这说明本文结果确为该经典定理在深度方向上的推广；同时它也把 BC24 的定理 C 与 INY25 的定理 1.4 从正则字符推进到任意字符。
- **主要贡献**：
  1. Jordan 分解公式：设 $s\in G_r^F$ 半单、$H=Z_{G_r}^0(s)$、$u\in H^F$ 单幂，对满足 $x^{-1}sx\in T_r$ 的 $x$ 令 $T_x=xT_rx^{-1}$、$\mathcal{L}_{\phi,x}$ 为 $\mathcal{L}_\phi$ 沿 $T_x\to T_r$ 的拉回，则 $\chi_{\mathfrak{Ind}^{G_r}_{T_r}\mathcal{L}_\phi}(su)=\frac{1}{|H^F|}\sum_{x}Q_{T_x,H}^{\mathcal{L}_{\phi,x}+}(u)\,\chi_{\mathcal{L}_\phi}(x^{-1}sx)$，即把特征函数在半单部分与单幂部分之间作 Jordan 型分解，并给出显式的重数系数。
  2. 比较定理：当 $q$ 足够大时，$\chi_{\mathfrak{Ind}^{G_r}_{T_r}\mathcal{L}_\phi}=(-1)^{\dim G_r}\mathcal{R}^{G_r}_{T_r}(\phi)$，其中 $\mathcal{R}$ 是由 Nie 借助 Howe 分解与 Deligne--Lusztig 型簇 $Z_r$ 定义的虚模；在椭圆 torus 情形与 $R^{G_r}_{T_r}(\phi)$ 一致，故也可写为 $(-1)^{\dim G_r}R^{G_r}_{T_r}(\phi)$。
  3. 正交性：先给出诱导函数之间与广义深水平 Green 函数之间的标量积，再过渡到简单直和项；对 $\mathcal{K}=\mathfrak{Ind}_{T_r}^{G_r}\mathcal{L}_\phi$ 的每个 $F$-等变简单直和项 $A$，得到用 $W_{\mathcal{L}_\phi}$ 上的迹与 $\mathcal{R}_{T_{r,w}}^{G_r}(\phi_w)$ 表达其特征函数的公式。
  4. 子域对称重数的层论表达：对 $F^2$-等变的 $(T_r,\phi)$，把 $m_{T_r,\phi}=\langle\operatorname{Res}_{G_r^F}^{G_r^{F^2}}\mathcal{R}_{T_r}^{G_r,F^2}(\phi),1\rangle_{G_r^F}$ 化为 $\sum_{A}\operatorname{Tr}(\sigma_A,V_A)$，并给出 $|m_{T_r,\phi}|\leq|W_{\mathcal{L}_\phi}|$；特别地，对正则诱导对，该重数在 $F^*\mathcal{K}\cong\mathbb{D}\mathcal{K}$ 时为零、反之为一。
- **关键先驱工作**：Lusztig 1985 年的特征层系列工作与 1990 年的比较定理（本文直接推广对象）；Lusztig 2017 关于有限局部环上特征层类比的设想；Bezrukavnikov--Chan（一般特征层理论及正则情形的比较定理）；Ivanov--Nie--Yu（Yu 型框架下的替代构造与正则情形的对应）；Nie 关于虚模 $\mathcal{R}^{G_r}_{T_r}(\phi)$ 与 Howe 分解的工作；Moy--Prasad 关于 parahoric 子群的过滤理论与深水平簇；Lusztig--F2 与 Shoji 关于子域对称重数的工作。
- **结果边界**：比较定理需假设 $q$ 足够大（与 Lusztig 原始定理同类条件）且 $p$ 非坏素数；Jordan 分解与正交性的表达式均以 Ivanov--Nie--Yu 构造的深水平特征层为基础；子域对称重数部分的结果依赖比较定理作为输入，并限于 $F^2$ 等变的数据。
- **开放问题**：如何把 $q$ 足够大这一条件放松或量化（例如确定具体下界）；深水平特征层的特征函数与深水平 Deligne--Lusztig 特征之间的对应能否在更一般的 Moy--Prasad 点（非超特殊点、正深度）上给出统一的几何解释；正交性公式与简单诱导特征层的对应能否用于确定深水平 Green 函数的显式值。
- **应用与推广**：本文把"特征函数 = 上同调迹"这一几何化表示论范式搬到正深度，使有限局部域上约化群的深水平特征表的计算获得几何工具，类似于 Lucsztig 比较定理在深度零情形对有限约化群特征表的贡献；子域对称重数的层论表达把 $G^{F^2}$ 到 $G^F$ 的表示限制重数问题转化为特征层与其对偶之间的对应判定，可用于研究基变换与对称空间型的重数现象。

- [[2609.10152]]：该文为 Hecke 代数的混合 Kazhdan--Lusztig 基给出范畴化，用抛物诱导与分层结构匹配标准模。本文的正交性与分解（诱导特征层模去幂零部分、简单直和项与深度零直和项对应）同样以抛物诱导与分层为核心，但落点在特征层的特征函数一侧。

### 批判性思考

- 定理的适用范围受 $q$ 足够大约束：该假设为比较定理的技术前提，作者并未给出量化，因此对固定小 $q$ 的有限局部域（如 $q=2$、$3$）读者应谨慎，比较定理与由此推出的子域重数结论都继承这一限制。
- 全文以 Ivanov--Nie--Yu 的构造为出发点，Jordan 分解与正交性的形式依赖该构造所选取的深度零特征层及其诱导；若改用 Bezrukavnikov--Chan 的构造，公式中的具体重数系数（如 $|W_{\mathcal{L}_\phi}|$、迹项）是否需要相应调整是一个需要核对的隐含前提。
- 子域对称重数的上界 $|m_{T_r,\phi}|\leq|W_{\mathcal{L}_\phi}|$ 由正交性直接推出，但其取值的精细刻画仍然只有正则诱导对情形下的"零或一"结论，一般情形的重数结构（例如是否总落在由 Weyl 群数据决定的有限集合中）在文中更像是一个未展开的入口。
