# Categorical forms of the rigid direct-system representation for finite local-unit-aligned totally ordered monoids

keywords: [局部单位对齐幺半群, 刚性直接系统, 范畴等价, 严格块态射, τ-相容同态]
related_paper: "Derived equivalences between diagram categories of finite posets（arXiv:2609.10110，同以有限偏序集/链为指标构造图表范畴并讨论范畴等价）"
one_liner_summary: "本文研究有限局部单位对齐全序幺半群的规范刚性直接系统表示在范畴层面的性质：证明该表示在"严格块态射"下给出与定向序相容系统态射之间的范畴等价，并对与局部单位映射 τ 交换的 τ-相容同态给出第二条内蕴等价——后一情形中源侧的多个正幂等元（多个规范分量）可以塌缩到同一目标分量，在直接系统一侧表现为非单射的保序指标映射加上满足塌缩与吸收公理的分量映射。"

## 核心定位

- **解决的问题**：有限全序幺半群在局部单位对齐情形下，其元素的最大右局部单位与最大左局部单位一致，局部单位映射 τ 因此诱导出正幂等骨架的规范分层，而 τ-乘法相容的那部分分层支撑一个刚性直接系统表示：规范分量由内在的 τ-乘法相容划分给出，原幺半群可由定向字典序与相应的直接系统乘法恢复，且真过渡映射被迫在目标分量的单位处取值。对象层面的重建早已清楚，本文要回答的是范畴层面的问题：把一个幺半群换成它的规范刚性直接系统之后，哪些幺半群同态恰好被相应的系统态射精确表示？
- **大图景位置**：属于"从局部分量与连接映射重建整体代数对象"这一传统的范畴化版本（Clifford 的强半格表示、Płonka 和、Bowman 对拓扑半群的构造函子、Romanowska--Smith 对半格和与半格表示的范畴处理、Zawadowski 用单子的 lax/oplax 态射处理广义 Płonka 和与积），但与转向 groupoid、纤维化或半格商的方向不同：本文考察的是规范局部单位分解本身的函子性，且不假设逆元存在、不假设交换、单位元也不必在链的端点。有限性加全序性迫使真过渡映射单位常值，正是这种刚性使范畴比较可能。
- **主要贡献**：（1）严格块范畴的等价：以有限局部单位对齐全序幺半群为对象、以严格块态射（每个规范分量映入某个规范分量，且把所区分的块单位送到相应目标块单位）为态射的范畴，等价于以定向序相容的系统态射为态射的刚性直接系统范畴，这是重建定理最干净的范畴表达。（2）内蕴等价：以 τ-相容同态（保序、保单位的、且与局部单位映射交换的同态）为态射的幺半群范畴，等价于以 τ-相容塌缩态射为态射的刚性直接系统范畴；此处同态不必在正幂等元上单射，因此可以把源的若干规范分量塌缩到目标的同一个规范分量。（3）两条等价互为准逆，共同表明规范刚性直接系统表示不只是对象层面的重建工具，而是一个带两套互补态射理论的函子性不变量。
- **关键先驱工作**：Clifford 关于强半格表示与自然全序交换半群的工作；Płonka 的 Płonka 和（以及相关的和与积构造）；Bowman 对拓扑半群的构造函子；Romanowska--Smith 关于半格和与半格表示的范畴处理；Zawadowski 通过单子的 lax 与 oplax 态射对广义 Płonka 和、积的单子式处理；Bonzio 等与 Fusco--Paoli 关于对偶与富化形式 Płonka 和的新近工作；最大半格像作为从半群范畴到半格范畴的反射及其保极限性质；Ehresmann--Schein--Nambooripad 关于逆半群与归纳 groupoid 的对应及其后续扩展；Grothendieck 构造方法用于幺半群扩张分类的工作；以及把局部单位分层与残差格（residuation）动机联系起来的前作。
- **结果边界**：只处理有限、全序、局部单位对齐的幺半群；不假设逆元存在、不假设交换、单位元不必位于链的端点；"严格"指的是块单位保持而非块链上的单射——多个源块仍可送入同一目标块，但系统相容性随即迫使相应的下位分量映射单位常值。刚性（真过渡映射在目标分量单位处常值）是全部结论的关键前提：去掉有限性或全序性后，单位常值现象与互补的两条等价都不再成立。第二条等价本质上允许分量塌缩，因此它不是分量到分量的忠实表示，塌缩必须与目标的 τ-乘法相容划分相容。
- **开放问题**：引言未逐条列出开放问题，但从框架可以读出：无限或非全序的局部单位对齐幺半群是否存在对应的刚性表示与等价定理；把 τ-相容同态刻画为"非单射保序指标映射 + 塌缩/吸收公理"之后，是否存在更简洁的统一描述（例如用纤维化或 2-范畴语言的表述）；以及残差同态是否自动落入 τ-相容范畴——作者只在末条注记中作了说明性陈述，未展开证明。
- **应用与推广**：为"以局部单位为基础的代数分层"提供函子性判据，可用于把残差格与三角模族的局部单位分层计算翻译为有限链上的刚性直接系统，从而在有限情形下用块与过渡映射做结构化计算（例如单位区间的离散分层、序和式构造）。技术上"分量分解 + 单位常值过渡映射 ⇒ 范畴等价"的模式可以迁移到其它具有刚性分层结构的代数对象（序半群、quantale、MV-代数等）的有限局部单位分解，也可反过来用于判定某个同态是否被某类系统态射表示。

## 主动思考区

### 与其他工作的联系

- 这让我想起：Clifford 的强半格表示与 Płonka 和这条传统——它们同样把全局代数对象拆成局部块再装配回去；本文的新意在于坚持"规范"（分量由局部单位映射内在决定）并把函子性追问进行到底。
- [[2609.10110]]：该文研究以有限偏序集为指标的图表范畴之间的导出等价；本文的刚性直接系统同样是以有限链为指标的图表，两文共享"指标范畴 + 分量范畴 + 过渡映射"的骨架，可对照理解指标映射单射性/单调性的作用。
- [[2609.15515]]：该文为 stylic 幺半群构造有限的凝聚展示与同伦基，属 Squier 凝聚定理在具体幺半群族上的落地；本文关心的则是分解的态射理论，两文都涉及"幺半群的结构性描述何时足够精确地刻画态射"这一问题。
- [[2609.15874]]：该文为 R-整半群（右整除关系为偏序）给出整系数有界箭图表示；它与本文都处理带序结构的半群，且都以"序结构 + 整除/局部单位关系"作为构造的出发点，可互为参照的例子来源。
- 技术迁移："分量分解 + 刚性过渡 + 两套态射类"的三件套或许可以移植到残差格与其单位区间的有限分层上，用来判定哪一类代数同态可以被区间层面的系统态射表示。

### 可以尝试的方向

- [ ] 去掉有限性与全序性之一后，是否存在以更一般指标范畴（如有限格、树状偏序集）为指标的刚性表示与相应的等价定理？
- [ ] 塌缩与吸收公理能否用纤维化或 2-范畴语言重述，从而去掉"指标映射 + 分量映射"的双重数据描述？
- [ ] 残差同态是否自动是 τ-相容的？若成立，本文的第二条等价将自动覆盖残差格/三角模的同态类。

### 批判性思考

- 两条等价的"严格"与"内蕴"之分依赖于对块单位的处理方式：前者显式记录块单位的保持，后者把塌缩记在局部单位几何里；作者主张后者更细微，但读者需要核对在塌缩发生时后者的指标映射是否确实携带了足够信息来重建复合。
- 全文结论都在有限且全序的假设下取得，而单位常值这一刚性现象恰由这两个假设共同迫使；作者未讨论是否存在"部分刚性"的中间情形（例如有限但不全序）作为反例或推广空间。
- 第二个等价允许分量塌缩，于是"表示"不再是忠实函子意义上的分解；这意味着该不变量在塌缩态射下的行为需要更精细的不变量（例如分量重数）来补充，文章并未讨论这类补充不变量。
