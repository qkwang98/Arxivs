# String Diagrams for Process Mining

keywords: [弦图, 超图范畴, 过程挖掘, 装饰余张量, 对象中心过程]
related_paper: "Universal Properties of Petri Net Unfoldings（arXiv:2609.17324，同样把并发执行解释为偏序/事件结构并给出范畴式万有性质）"
one_liner_summary: "本文把过程挖掘中常用的四种记号（对象中心 Petri 网、对象中心因果网、对象中心过程树、类型化 BPMN）归约为同一种弦图表示：只记录模型的活动及其类型化接口（即签名），丢弃全部路由机制；四条构造定理分别确立这一表示，使不同记号（乃至不同发现工具）产生的模型能在同一形式上比较——签名相等蕴含轨迹等价且严格更细（能区分真并发与交错选择），签名包含蕴含轨迹包含，并在一个对象中心日志的恢复研究中得到验证。"

## 核心定位

- **解决的问题**：在同一事件日志上运行两个过程发现算法，会得到同一过程的两幅不同图。Petri 网、因果网、过程树与 BPMN 各有自己的路由机制（画成结点的缓冲区、折进边的缓冲区、算子结点、网关），它们唯一共同的地基是所生成的轨迹；而轨迹把活动依次列出，丢掉了这些记号本要表达的并发，于是轨迹语言相同的两个模型可能描述真正不同的过程。"两个被发现的模型是否意味同一件事"因此不存在与记号无关的答案。本文要给出一个保留并发的、各记号自身即可确定的规范形式，以及一个可判定的比较测试。
- **大图景位置**：把"用偏序/事件结构刻画并发"的传统（Pratt 以来的偏序语义、Petri 网展开、事件结构）从语义侧搬到语法侧：以往偏序是模型"意味着"的东西、需由展开计算得到，这里偏序是建模者"写下"的图，图与图是否相同由有限集合的相等判定，而不是靠状态空间上的配对博弈。同时把四种记号纳入统一的组合式范畴语境（超图范畴），使记号间翻译成为可检验的主张。
- **主要贡献**：（1）四种记号作为同一范畴的规范表示：每个记号中的模型都归约为签名，且四个情形由同一个构造完成——对象中心 Petri 网、对象中心因果网、对象中心过程树与类型化 BPMN 各获得一条构造定理；BPMN 无需结构前提，其 OR 网关通过有限展开为 AND 与 XOR 的组合处理；该表示与记号无关，同一行为无论用哪种记号表达都得到同一签名。（2）比轨迹更细的等价证书：比较签名即可检查两模型是否一致，无需先固定建模约定；签名相等证明结构相同（因而轨迹语言相同），并能把真并发 a⊗b 与排他选择（a;b 与 b;a）区分开——后者是轨迹比较与双相似都混同的；签名包含蕴含轨迹包含；由于映射保持顺序复合与并行复合，判断在片段被组合进更大模型后依然成立；该蕴含只在一个方向成立，作者明确不声称逆命题。（3）构造上即对象中心：对象类型写在线上，生成余张量的边界带对象类型标签，"类型匹配方可复合"在结构上强制多对象一致性，无需可达性记账，混合类型的模型从一开始就不可能被错误装配；经典无类型记号是单类型特化。副产品：证明过程树的顺序-并行片段在出现层面恰好生成有限序列-并行偏序集，且仅生成这些。
- **关键先驱工作**：超图范畴与组合式范畴论（Fong--Spivak 一脉）以及装饰余张量（decorated cospans）技术；对象中心 Petri 网、对象中心因果网、过程树与 BPMN 的既有定义及相应发现算法；Petri 网展开与事件结构理论（Nielsen--Plotkin--Winskel 传统）与并发分类中"保历史双相似"等能区分并发的等价；Sassone 关于并发模型分类、van Glabbeek 关于动作精化与等价的工作；基于重放的一致性检查；以及被明确排除在框架之外的声明式语言（Declare、DCR 图）。
- **结果边界**：只覆盖"过程式且局部"的记号——模型由与紧邻部件相连接的片段装配而成；约束横跨整条轨迹的全局声明式语言在框架之外。签名到行为的蕴含只有一个方向（结构相同 ⇒ 轨迹语言相同），不同结构可以有相同轨迹语言。过程树的序列-并行刻画只在出现层面上成立；对象中心 Petri 网要求类型一致（不存在连接不同类型库所的沉默迁移链），因果网是这套构造的参照实例，其路由机制以最"折叠"的形式出现。框架不承诺跨记号翻译的自动正确性，它提供的是可检查的判断依据。
- **开放问题**：引言未列成清单，但从边界可读出自然追问：如何把声明式/全局约束语言纳入同一签名框架（或证明原则上不能纳入）；签名相等是否也能与更强的行为等价（如保历史双相似）对齐，即上述单向蕴含的逆命题在何种附加条件下成立；无类型（经典）记号与多对象情形之间是否存在统一的提升定理，使经典结果成为特化而非平行理论；以及签名的代数（余张量代数）能否给出模型差异的最小解释（例如把"多出来的行为"定位到具体生成元）。
- **应用与推广**：为过程发现工具之间提供"可检查的翻译主张"：两工具输出可直接比较签名，从而定位某个模型多出的行为——恢复研究中被发现的因果网恰好具有真值签名，而被发现的 Petri 网签名严格包含真值签名，且其多出的行为全部落在该 Petri 网的沉默结构中，比较结果因此"指名"了新增行为。对对象中心数据收益最大（一个日志同时支撑多种记号）。方法上，把"路由机制全部归约掉、只留类型化接口"的思路可迁移到其它带中介结构的建模语言（工作流网、BPMN 扩展、组合式数据管道乃至数据库约化），把模型等价判定化为有限集合的比较；随论文发布的 proc-posets 包实现了从日志到签名再到判断的完整流程。

## 主动思考区

### 与其他工作的联系

- 这让我想起：偏序语义的"语法化"——Pratt 以来偏序是并发的语义，Petri 网展开把它算出来；本文直接让建模者把偏序画出来，于是并发比较退化为有限集合的相等判定。
- [[2609.17324]]：该文追问 Petri 网展开在放弃安全性假设后的精确万有刻画，并把两种修补方案装进同一个 2-范畴框架；本文则把展开所依赖的"并发作为偏序"直觉搬到语法层，两文分别从语义万有性质与语法规范形式两端处理同一类并发结构，可互为参照。
- [[2609.09056]]：该文用层论语言为"随时间变化的数据"给出统一描述，并让不同时序描述方式之间可以相互翻译；与本文"为多种记号提供同一共同形式并使其翻译成为可检验主张"的目标高度同构，可对照其如何组织跨表示翻译的忠实性条件。
- [[2609.16221]]：该文研究在保留极限（尤其函子式数据库的全局截面）的前提下把复杂无环范畴约化为更小模型的两种路径；本文的签名是把模型约化到不含路由机制的最小描述，两文共享"约化后仍保留关键信息"的问题意识，区别在于本文约化的是记号而该文约化的是指标范畴。
- 技术迁移："把中介结构全部丢弃、只保留类型化接口，再以生成元的有限集合比较模型"的方案，看起来可以用于比较带约束的组合式数据管道或事件日志的多视图描述。

### 可以尝试的方向

- [ ] 能否为声明式、全局约束的语言定义类似签名（例如把整条轨迹上的约束翻译为特定生成元的组合），或证明这类语言在原理上被排除？
- [ ] 在何种附加条件下，"签名相等"可以加强为保历史双相似，从而把当前的单向蕴含补成刻画？
- [ ] 能否用一个模型相对另一模型签名的差（多出的生成元）给出差异的最小解释，即自动生成"多出了什么行为"的人类可读报告？

### 批判性思考

- 签名的定义依赖"路由机制不贡献任何东西"这一判断的彻底性：作者论证了四种记号的中介结构都可被删除，但删除后信息是否绝对无损（例如沉默迁移所编码的隐式顺序约束）主要由恢复实验与构造定理共同支撑，读者应逐一核对四条构造定理的边界条件。
- 单向蕴含是全文的关键限制：签名不同并不证明过程不同，因此该证书在否定性判断上弱于双相似等传统等价；作者对此诚实说明，但使用者容易误读这一比较为"完全判定"。
- 论文把 Declare 与 DCR 图排除在框架之外，理由是它们的约束横跨整条轨迹；这种排除保证了构造的局部性，却也限制了框架对现代声明式过程挖掘的适用面，作者未讨论是否可以通过引入额外生成元把部分全局约束局部化。
