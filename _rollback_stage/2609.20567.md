# Rogers--Ramanujan identities from the geometry of $X^a=Y^b$

keywords: [Rogers--Ramanujan 恒等式, 环面结奇点, 圆柱分割, HJO 猜想, 有理 shuffle 定理]
related_paper: "Huang--Jiang--Oblomkov（HJO）关于环面结奇点 $X^a=Y^b$ 的 Quot scheme 计数与 $q$-级数 $Z_{a,b}$ 的猜想论文"
one_liner_summary: "本文证明有限恒等式 $N_{a,b;N}(q,1)=(q;q)_N C_{c,\le N}(q)$，把 HJO 有限和等同于有界圆柱分割的生成函数，再令 $N\to\infty$ 与既有的无界圆柱分割乘积公式衔接，从而对全部互素整数 $1<a<b$ 证明了 Huang--Jiang--Oblomkov 关于环面结奇点 $X^a=Y^b$ 的 Rogers--Ramanujan/Andrews--Gordon 型几何推广猜想。"

## 核心定位

- **解决的问题**：给出互素整数 $1<a<b$ 时计数级数 $Z_{a,b}(q)$ 的显式无穷乘积求值，即证明 Huang--Jiang--Oblomkov 猜想（HJO Conjecture 1.7）：$Z_{a,b}(q)=\prod_{m\ge1}(1-q^m)^{-\rho_{a,b}(m)}$，其中指数 $\rho_{a,b}(m)=\min\{a,b,\operatorname{dist}(am,d\mathbb{Z})\}-1+\mathbf 1_{d\mid m}$，$d=a+b$。
- **大图景位置**：经典 Rogers--Ramanujan 恒等式（模 $5$）与 Andrews--Gordon 恒等式（任意奇数模）被统一推广到全部环面结奇点 $X^a=Y^b$。此前除 $a=2$ 的经典族外，只对 $(a,b)=(3,4),(3,5),(3,7),(3,8)$ 及完整的 $a=3$ 层有结果，$a>3$ 一无所知；本文给出的首个新情形是 $(a,b)=(4,5)$。几何侧，$Z_{a,b}$ 是奇点 $R=\Bbbk[[T^a,T^b]]$ 的 punctual Quot scheme 的动机生成函数；算术侧，它是有限域 $\mathbb F_q$ 上满足 $A^a=B^b$ 的交换幂零矩阵对的群胚体积。
- **主要贡献**：
  1. 主定理（有限恒等式）：对互素 $1<a<b$、平衡剖面 $c_i=\lfloor (i+1)b/a\rfloor-\lfloor ib/a\rfloor$ 及任意 $N\ge0$，有 $N_{a,b;N}(q,1)=(q;q)_N C_{c,\le N}(q)$，即 HJO 的第 $N$ 阶有限和等于 $(q;q)_N$ 乘以元素不超过 $N$ 的圆柱分割体积生成函数。
  2. 令 $N\to\infty$，配合 Borodin 与 Foda--Welsh 已建立的无界圆柱分割乘积求值，得到 HJO 猜想成立（推论）；结合 HJO 对 $P_{a,b}(q)$ 与 $W_a(a,a+b)$ 平衡扇区特征标的识别，$P_{a,b}(q)=(q;q)_\infty C_c(q)$。
  3. 证明中把 $F_N(q)$ 同时等同于三个组合模型：有界平衡圆柱分割、经过每个 $(ka,kb)$ 的指定回归复合 Dyck 路径（权为整路径 arm-leg 统计量），以及加权 rank 图中 $N$ 个顶点不相交圈族；三者经两条独立分支归约到同一个 $q$-差分方程 $\mathscr G(qz;q)=A(-z;q)\mathscr G(z;q)$，再由解的唯一性合并。
  4. 由该表达式推出 Corteel--Warnaar 型的精细正性：对平衡互素剖面，$Q_{m,c}(q)=\sum_{n\in\mathcal C,\ n_f=m}q^{Q(n)}\mu_m(n)$（其中 $\mu_m$ 为广义 Gaussian 多项式系数）属于 $\mathbb N[q]$，从而验证了 Warnaar 猜想 8.4 对这类平衡剖面的正性断言。
  5. 有限恒等式与 HJO 猜想已在 Lean 中由 AxiomProver 形式化，条件是两条已陈述的文献输入。
- **关键先驱工作**：Rogers 与 Andrews 的经典恒等式、Gordon 的分拆定理与 Andrews 的解析恒等式；Huang 关于 $Q(n)\ge n_f^2/\delta$ 的有效正定性定理；HJO 关于 Quot scheme 仿射胞腔分解的结果；Bergeron--Garsia--Leven--Xin 与 Mellit 的组合有理 shuffle 定理；Gessel--Krattenthaler 引入的圆柱分割及 Borodin、Foda--Welsh 的乘积理论；Warnaar 的 $A_2$ Andrews--Gordon 恒等式与 Schilling--Warnaar 的 supernomial 理论（用于 $a=3$ 层）；Kurşungöz--Ömrüuzun Seyrek 关于一般多行剖面 $(q^r;q^r)_N C_{c,\le N}(q)$ 的正性结果。
- **结果边界**：只处理互素参数 $1<a<b$，且圆柱分割一侧限定为平衡剖面；无穷乘积侧的输入来自 Borodin 与 Foda--Welsh 的既有理论，本文的实质新内容集中在 $N$ 有限的恒等式；Lean 形式化是条件性的，不能视为独立校验。此外正定性结论只对平衡互素剖面成立，一般剖面的精细正性仍是 Warnaar 的猜想内容。
- **开放问题**：作者在关于 Warnaar 猜想 8.4 的注记中指出，$Q_{m,c}(1)$ 的封闭取值可由本文的 word-of-filters 模型推出，但明确"留作有兴趣读者的练习"，未在本文展开；此外文中也提到非平衡、非互素剖面的正性此前只对 $(q^r;q^r)_N$ 型归一化已知。
- **应用与推广**：把奇点计数、受限分割与图像模型三者统一起来，为后续用"公共 $q$-差分方程唯一性"证明计数恒等式提供了范式；技术上，斜率算子的乘性定理、圆柱分割的有限行列式模型（Cramer 余子式展开）与 word-of-filters 展开都可复用于其它 Quot scheme 型计数或受限分拆问题；结果还与 $W$-代数特征标、环面结奇点的 motivic 计数直接相连。

## 主动思考区

### 与其他工作的联系

- 这让我想起：环面结几何与 $q$-级数恒等式之间的转换机制 — 见 [[2609.13766]]
- [[2609.13766]]：该文处理两股环面结 $T(2,2p+1)$ 的着色 $SU(n)$ 不变量分圆展开，核心引擎是 Bailey 变换与形式 $q$-差分算子代数上的整性；本文同样处理环面结奇点相关的 $q$-级数，但走的是圆柱分割 + 组合有理 shuffle 定理 + 公共 $q$-差分方程唯一性的路线。两文可对比"整性由算子代数承载"与"恒等式由方程唯一性承载"这两种证明引擎，且都对"有限版本居中、极限情形由此推出"的结构感兴趣。
- [[2609.09209]]：该文把两个 Ramanujan 型 $1/\pi$ 级数嵌入含参数的无限族；本文把 Rogers--Ramanujan 与 Andrews--Gordon 恒等式嵌入以 $(a,b)$ 为参数的族，两文共享"母恒等式 + 参数特化"的组织方式，区别在于本文的参数化来自奇点几何而非超几何求和的自由参数。
- 技术迁移：本文"先用 $N$ 有限版本搭桥、再取 $N\to\infty$"的思路，原则上可用于其它已知无穷乘积求值的 $q$-级数猜想——只要能找到该级数的有限截断版本及其组合模型。

### 批判性思考

- 无穷乘积一侧并非本文独立得到：HJO 已把 $P_{a,b}(q)$ 识别为 $W_a(a,a+b)$ 平衡扇区特征标，Foda--Welsh 给出相应的乘积公式，本文只是在 $N\to\infty$ 后调用它们。因此"证明 HJO 猜想"这一结论的成立，依赖于这些外部识别的正确性，本文的真正增量是有限恒等式本身。
- 两条分支（路径侧 $\mathcal H=\mathcal P$ 与图论侧 $\mathcal B=\mathcal D$）都归约到同一 $q$-差分方程，理论上很漂亮，但桥接 $F_N(q)$ 与 Dyck 路径生成函数 $A_N(q)$ 需要组合有理 shuffle 定理与斜率算子的乘性定理，这两处外部输入是整篇证明最需要逐条核验的环节。
- 论文自述 Lean 形式化是条件的，依赖两条未形式化的文献输入，因此不能把"已形式化"读作端到端的机器验证。
