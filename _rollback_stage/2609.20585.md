# Conductor-Discriminant Inequality for Tamely Ramified Cyclic Covers II

keywords: [导体-判别式贡献, 导体指数-判别式贡献, 倍数 2 点, 局部 $n$-消解, 有理双点, 温和分歧循环覆盖]
related_paper: "Conductor-Discriminant Inequality for Tamely Ramified Cyclic Covers I（arXiv:2609.20553，本文是它赖以完成证明的技术续篇）"
one_liner_summary: "作为前作的配套论文，本文补齐了分支除子倍数 2 点处"导体-判别式贡献"所需的全部技术结果：证明该量除极受限情形外非负、给出它取负值时的完整充要局部刻画（三种构型，此时完备局部环的谱为型 $D_4$、$E_6$ 或 $E_8$ 的有理双点），并证明相关的"导体指数-判别式贡献"恒非负且可用于收缩特纤维分支，从而补全前作对导体-判别式不等式的证明，并给出 Kohls 关于导子指数上界结果的一条更简单的新证明。"

## 核心定位

- **解决的问题**：设 $K$ 为 Henselian 离散赋值域，$O_K$ 优良、剩余域 $k$ 代数闭，$n$ 与 $\mathrm{char}(k)$ 互素，$X\to \mathbb{P}^1_K$ 为光滑几何连通射影曲线上的 $\mathbb{Z}/n\mathbb{Z}$ 循环覆盖（亏格 $\ge1$）。前作把导体-判别式不等式 $-\operatorname{Art}(X/K)\le (n-1)\Delta_{X/K}$ 的证明归约为对分支除子 $D$ 的每个倍数 2 点 $y$ 验证"导体-判别式贡献" $\operatorname{cdc}(y)$ 非负；本文的任务正是补齐这一归约所依赖的全部局部技术结果。
- **大图景位置**：这是 Ogg、Saito、Liu、Srinivasan、Obus–Srinivasan 关于"判别式控制 Artin 导体/导子指数"这一纲领上的补全性工作：前作给出总体框架与归约命题，本文完成局部账目，两篇合读才构成完整证明。同时本文用一条更简单的路径重新证明了 Kohls 关于导子指数-判别式不等式的定理（这部分只用到 $\operatorname{cedc}$ 的非负性，不需要后续更重的局部消解分析）。
- **主要贡献**：（1）定理 $\operatorname{cedc}$：对任意倍数 2 点 $y$，相关的"导体指数-判别式贡献" $\operatorname{cedc}(y)\ge0$；（2）定理 contractions：若 $\operatorname{cdc}(y)<0$，则局部 $n$-消解后的极小消解到原归一化的极小消解之间的正则态射，至少在 $y$ 上方原像中收缩 $-\operatorname{cdc}(y)$ 个特纤维不可约分支；（3）定理 $\operatorname{cdc}$：$\operatorname{cdc}(y)<0$ 当且仅当三种显式局部构型之一发生（分支除子只含一个不可约分支 $\Gamma$、其相对于覆盖的歧化指数为 3、4 或 5，且 $\Gamma$ 在吹胀 $y$ 后的严格变换正则；或歧化指数为 3、需再吹胀一次才正则且 $n=3$；或 $y$ 落在两个交重数为 2 的分支上、两者歧化指数均为 3、吹胀的例外除子歧化指数为 3 且 $n=3$），并且在这些情形下完备局部环的谱都是有理双点，按情形分别取 $D_4$、$E_6$ 或 $E_8$ 型极小消解。
- **关键先驱工作**：前作中把全局不等式逐步归约为逐点贡献之和的命题（并给出 $\operatorname{cdc}$ 与 $\operatorname{cedc}$ 的定义）；Artin 导体的 $\ell$-进上同调定义以及 Liu 关于 $-\operatorname{Art}(\mathcal{X})=N-1+\phi(X/K)$ 的恒等式（$N$ 为几何特纤维的不可约分支数）；Ogg 与 Saito 关于 $n=2$、亏格 1 的等式型结果，Liu 关于 $n=2$、亏格 2 的结果，以及 Obus–Srinivasan 的 $n=2$ 完整情形；Kohls 关于导子指数上界的博士论文结果；Lipman 关于有理双点（Du Val 奇点）的分类与消解（用于分析 $\operatorname{cdc}(y)<0$ 时的局部奇点类型）。
- **结果边界**：所有结论都在温和分歧假设（$n$ 与 $\mathrm{char}(k)$ 互素）、剩余域代数闭、$O_K$ 优良的前提下成立；只讨论分支除子的倍数 2 点，高重数点没有对应理论；核心计算依赖前作的归约命题，因此本文不是自足的单篇，必须与前作合读；一般情形下 $\operatorname{cdc}(y)$ 确实可以取负值，故不能指望全局的非负性，负性只能通过三类列举构型来掌控。
- **开放问题**：引言没有显式罗列开放问题，但从假设的不可去除性与定理形状可读出若干自然追问——野生分歧（$p\mid n$）情形是否仍有对应的非负性与收缩定理（此时驯顺循环商奇点与 $D_4,E_6,E_8$ 的局部图景都会改变）；三类负性构型是否被"只考虑倍数 2 点"这一限制所穷尽，即是否需要对更高重数点发展同类账目；以及定理 contractions 的收缩数界 $-\operatorname{cdc}(y)$ 是否在一般情形下恰等于被收缩分支的实际数目（能否加强为等式）。
- **应用与推广**：本文把"极难计算的 Artin 导体与导子指数"替换为"可由定义方程与原像构型算出的局部贡献"，这类界可直接服务于曲线数据库（如 LMFDB）中固定亏格、有界导子的曲线枚举与模型构造算法；技术上，"局部 $n$-消解 + 逐点比较分歧收益与特纤维分支代价"的框架可移植到其它退化不变量（Swan 导子、特纤维不可约分支数）的局部估计；"负性蕴含商奇点为特定有理双点"这一结论也示范了如何把局部数值负性翻译为奇点类型信息。

## 主动思考区

### 与其他工作的联系

- 这让我想起：前作中"把全局不等式归约为逐点贡献之和"的总体策略 —— 本文正是该策略在局部层面的落实，单看本文会失去归约与全局结论的语境。
- [[2609.20553]]：这是本文的直接前作，定义 $\operatorname{cdc}(y)$ 与 $\operatorname{cedc}(y)$、证明把全局不等式归约为逐点验证的命题，并把本文的两个定理作为假设使用；本文补齐它所需的全部技术输入，二者构成一个整体。
- [[2609.15450]]：该文研究由关键多项式生成的单扩张，讨论赋值域上的亏、无分支扩张与 Mac Lane–Vaquié 链；它与本文共享"离散赋值域 + 分歧与亏的计算"这一技术底座，可用来对照本文局部消解中出现的歧化指数与分支链结构。
- [[2609.18921]]：该文在正特征奇点理论中否定了 F-有理性在一般超平面截口下的 Bertini 型定理；本文的温和分歧假设把正特征效应排除在外，若要把本文的局部理论推向 $p\mid n$，正特征奇点与相关几何工具很可能是必要输入。
- 技术迁移："局部吹胀 + 逐项账目比较"的框架看起来可以搬到其它覆盖（非循环覆盖、非温和 Galois 覆盖）或函数域上的同类退化不变量上下界估计问题。

### 可以尝试的方向

- [ ] 能否把 $\operatorname{cdc}(y)<0$ 的三类构型分类推广到分支除子的更高重数点，从而去掉"仅倍数 2 点"的限制？
- [ ] 在 $p\mid n$ 的野生分歧情形，是否存在以驯顺循环商奇点之外的对象（例如与野生分支群对应的局部模型）替代的新版非负性定理？
- [ ] 核查 $-\operatorname{cdc}(y)$ 与"被收缩特纤维分支数"在一般情况下是否相等，即定理 contractions 的界能否加强为等式。

### 批判性思考

- 三个主定理的证明都经由局部 $n$-消解的显式计算，而这些计算依赖前作固定的消解构造；读者需要核对"消解后分支除子在所有 $y$ 上方点处均为简单正规交叉"这一构造性要求在退化最严重的配置下是否仍可满足。
- 定理 $\operatorname{cdc}$ 的三类构型中有两类强制 $n=3$，这暗示负性现象严重受制于小次数；作者未说明这一限制是技术性的还是本质性的，值得追问。
- 全文的正性论证分成"$\operatorname{cedc}$ 恒非负"与"$\operatorname{cdc}$ 除三类构型外非负"两条线，前者明显更简单（作者亦指出这点）；这种不对称提示 $\operatorname{cedc}$ 可能是比 $\operatorname{cdc}$ 更自然的不变量，全局不等式是否可能只用前者陈述值得思考。
