# Character theory for 2-representations

keywords: [2-表示, 特征标理论, 双范畴迹, shadow 结构, 余诱导, 二阶特征标]
related_paper: "Ganter--Kapranov 用范畴化迹定义的 2-表示特征标理论（本文说明其为本框架的特例）"
one_liner_summary: "本文把经典群表示的特征标重新表述为函子（表示是函子 $BG\to\mathcal{B}$，特征标是 $\Lambda BG$ 上的函子），并借助双范畴中的迹理论为 2-表示建立直观的特征标理论：当双范畴具有 shadow 时，2-表示 $\rho$ 拥有特征标 $\mathcal{X}_\rho$ 且与限制、诱导、余诱导相容；在取值目标中迹有定义且像对象足够有限时，还可得到定义在交换元素对上的二阶特征标。"

## 核心定位

- **解决的问题**：群表示的特征标如何提升到 2-表示层面。已有的 2-表示特征标方案（Bartlett 的工作、Ganter--Kapranov 的范畴化迹）依赖特定类型的迹，适用范围较窄；本文要构造一套更直观、且允许更多迹类型的特征标理论，并说明经典特征标的各项形式性质在什么条件下能够保留。
- **大图景位置**：论文抓住经典表示论中一个常被忽略的观点——「表示与特征标是同一种东西，都是函子」，并把它推到 2-范畴层面。经典侧，$BG$ 到向量空间范畴的函子给出表示，而 $\Lambda BG\to\Vect_k(k,k)$ 的函子给出特征标；2-范畴侧，表示成为强 2-函子 $BG\to\mathcal{B}$，而 $\mathcal{B}$ 中 1-胞腔的迹允许把特征标的目标从只有恒等态射的单点范畴放大到含非恒等态射的范畴。论文因此处于经典特征标理论、等变 Morava $E$-理论（Hopkins--Kuhn--Ravenel 定义在交换元素元组上的特征标）、微分分次范畴与 Fourier--Mukai 变换下的 Riemann--Roch 型、Lefschetz 型定理（Ben-Zvi 与 Nadler 的二阶迹），以及 Bartlett、Ganter--Kapranov 的代数路线之间的交汇点。
- **主要贡献**：
  1. 主定理：若双范畴 $\mathcal{B}$ 具有 shadow，则任意 2-表示 $\rho\colon BG\to\mathcal{B}$ 都有一个特征标 $\mathcal{X}_\rho$；并且该构造与限制 $R$、诱导 $I$、余诱导 $C$ 相容，其中诱导与余诱导的相容性只能在相差唯一同构的意义下成立，形式上表现为 $\mathcal{X}$ 与 $R$、$I$、$C$ 的交换关系（诱导侧与余诱导侧各为「唯一映射」）。
  2. 二阶特征标定理：若 shadow 取值于对称幺半范畴且 $\rho(g)$ 的像足够有限，则存在二阶特征标 $\mathcal{X}_{\mathcal{X}_\rho}$，其定义域是群元素的交换对（模同时共轭），并且同样与限制、诱导、余诱导相容。
  3. 论文指出 Ganter--Kapranov 的范畴化迹是 Barhite 所谓余 shadow 的一个例子，因而他们的特征标是本框架的特例；反之本文允许用其它迹（例如由 Hochschild 同调与拓扑 Hochschild 同调给出的迹）定义特征标，也能给出他们无法触及的例子。此外，本文对诱导表示给出比 Ganter--Kapranov 更一般的定义，用唯一自然映射而非等式刻画诱导与特征标的相容性。
- **关键先驱工作**：Ben-Zvi 与 Nadler 的二阶迹及其与微分分次范畴、Fourier--Mukai 变换、Riemann--Roch 型定理的联系；Bartlett 关于 Grothendieck 对偶的特征标工作；Ganter 与 Kapranov 的范畴化迹与 2-表示特征标；Hopkins、Kuhn 与 Ravenel 关于等变 Morava $E$-理论的特征标；Ponto 关于双范畴中迹的专著（本文迹理论的主要来源）；Barhite 的双范畴余 shadow 与 cotrace；Dold 关于对称幺半范畴中迹的经典工作；以及 Elgueta、Ganter--Kapranov 关于 2-表示的早期定义。
- **结果边界**：整套构造要求双范畴具有 shadow（或相应的余 shadow），这是比范畴化迹更宽但仍属实质性的假设；二阶特征标额外要求取值目标为对称幺半范畴且相关 1-胞腔的像足够有限（即具备所需的钳制对象）；特征标不再具有经典意义下的共轭不变性，只保证共轭元素的像之间存在态射，因此不能直接当作共轭类上的函数使用；诱导侧的相容性只给出唯一自然映射，而不是 Ganter--Kapranov 式的等式，故不蕴含该映射为同构。
- **开放问题**：论文明确指出，作者与 Ganter--Kapranov 同样相信更高阶类比应当产生定义在更长交换元素元组上的特征标，这一信念来自 Hopkins--Kuhn--Ravenel 的元组特征标与二阶迹现象；此外，除 Hochschild 同调与拓扑 Hochschild 同调之外还有哪些迹结构能产生新的特征标、诱导与余诱导的相容性能否被加强为同构或提升为更高结构，文中均未给出答案。
- **应用与推广**：论文把双范畴迹这一源自拓扑不动点理论的工具移植到表示论，使得特征标可以用 Hochschild 同调、拓扑 Hochschild 同调等具体同调理论来计算，从而为等变同调、双范畴上的余诱导以及二阶迹在 Riemann--Roch 型定理中的应用提供统一语言；把群特征标视为 2-范畴构造的特例这一视角，也为高阶表示论（如 2-群表示、双范畴作用）中的不变量构造提供模板；同时它说明「特征标自身的特征标」这一递推在足够有限的条件下确实可以启动，为高阶特征标的逐层构造给出起点。

## 主动思考区

### 与其他工作的联系

- 这让我想起：Ben-Zvi 与 Nadler 用二阶迹把 Riemann--Roch 型定理写成函子的自然变换，本文则把同一机制用到群的特征标上 — 见 [[2609.09633]]
- [[2609.09633]]：Representation Varieties of Stacks and Trace Maps — 该文的迹映射同样经由 Fourier--Mukai 积分变换与 Hochschild 同调得到，与本文「用迹定义特征标、再由 Hochschild 同调具体计算」的路线在机制上高度一致，区别在于一个面向栈上的表示模空间，一个面向群的双范畴表示。
- [[2609.13788]]：Bicategorical Idempotent Completion — 两者都在双范畴框架内作严肃的构造性工作，都需处理弱富化下的相干性；本文对余 shadow（2-幂等元式的分裂行为）与特征标相容性的处理，与该文关于 2-幂等元分裂与绝对加权余极限的处理共享同一套图解演算语汇。
- [[2609.10440]]：Local Ocneanu rigidity for separable algebra objects — 同属用 Hochschild 上同调约束范畴化结构的刚性讨论，一个用上同调收缩证明代数结构有限性，一个用同调版本构造不变量，两者在「Hochschild 工具能告诉我们什么」这一问题上互补。
- 技术迁移：本文把「表示与特征标同为函子」的观察成功推广到 2-范畴，同样的要求（目标范畴中迹存在、对象足够有限）或许可用于定义双范畴作用的不变量，或把等变同调的元组化特征标推广到 2-群。

### 可以尝试的方向

- [ ] 二阶特征标定义在交换元素对上，能否给出可递推的更高阶特征标构造，并确定其中的终止条件与有限性假设？
- [ ] 诱导与余诱导的相容性目前只是唯一自然映射，是否存在自然的附加假设（例如余 shadow 的额外公理）使其成为同构？
- [ ] 能否把 shadow 假设进一步弱化为只要求局部（某些 1-胞腔上）存在迹，从而覆盖不具备整体 shadow 的双范畴？
- [ ] 对有限群与有限 2-群的具体例子，比较本文特征标与 Ganter--Kapranov 特征标的差异落在何处？

### 批判性思考

- 论文的构造依赖 shadow 假设，该假设虽比范畴化迹更一般，但仍排除大量自然出现的双范畴；二阶特征标更进一步要求像对象足够有限，论文没有给出一般性的判定方法，实际使用时要逐例核对，可用范围的门槛高于读者预期。
- 诱导侧与余诱导侧的相容性只得到唯一自然映射而非同构，与经典特征标理论中特征标完全决定表示的强度相比是实质性弱化；论文没有讨论该映射何时可逆，因此「特征标是否构成完全不变量」这一自然问题仍悬空。
- 论证的动机部分覆盖了至少四套语汇（双范畴迹、余 shadow 与 cotrace、二阶迹、元组特征标），这些来源被并列陈述以支撑「直观性」的主张，但并列本身并不构成统一的概念框架，读者需要自行判断哪一部分是核心构造、哪一部分只是类比。
- 二阶特征标定义在交换元素对模同时共轭上，形式上与 Hopkins--Kuhn--Ravenel 的元组特征标一致，「特征标的特征标」这一二阶步骤的终止性依赖有限性假设，论文未说明在无限群或表示不可约的情形下这一步骤会如何退化。
