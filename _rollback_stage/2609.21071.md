# Some freezing limits for Bessel functions and Bessel processes with drift of type $B_N$

keywords: [Bessel函数, Bessel过程, 漂移, 冻结极限, Jack多项式, 根系B_N, Dunkl]
related_paper: "Anker–Voit 等人关于 Bessel 过程冻结极限的系列工作（正文引用 [AKM1, AKM2, AnV2]）"
one_liner_summary: 利用 Jack 多项式级数表示证明 $B_N$ 型 Bessel 函数在多重度 $k_1\to\infty$ 时的冻结极限（含对数导数型），并据此推出带漂移 $B_N$ 型 Bessel 过程的弱大数定律，应用于矩阵空间上带漂移布朗运动径向部分的高维极限。

## 核心定位

- **解决的问题**：当多重度（逆温度）参数 $k_1\to\infty$ 时，带漂移向量 $w$ 的 $B_N$ 型 Bessel 函数与相应 Bessel 过程的冻结极限是否存在、极限是什么。
- **大图景位置**：把 $A_{N-1}$/$B_N$ 型 Bessel 过程冻结极限（Anker–Voit 系列、Dyson 布朗运动等）从无漂移情形推广到带漂移情形；同时是 Rösler、Demni 的 Laplace 型积分表示在极限参数下的新应用，并与 L、CLWW 的一致界估计互相印证。
- **主要贡献**：1) 用 Jack 多项式级数表示证明对所有 $k_2\ge 0$、$N\ge 1$ 成立的 $J_{(k_1,k_2)}^{B}(x,k_1y)^{1/k_1}$ 极限公式；2) 在 $N=1,2$ 或 $k_2=0,1/2,1,2$ 时证明对数导数型极限；3) 由转移密度表达式配合 Laplace 方法严格证明带漂移 $B_N$ 型 Bessel 过程的弱极限定理（随机变量依概率收敛到确定性 ODE 解）。
- **关键先驱工作**：Rösler 的 $B_N$ 型 Bessel 函数 Laplace 积分表示（基于球函数理论）；Demni 的 $B_2$ 型积分表示；Kaneko 等人的 Jack 多项式级数展开；Anker–Voit 系列的无漂移冻结极限；Pitman–Yor 的一维带漂移 Bessel 过程理论。
- **结果边界**：对数导数极限仅在 $N\le 2$ 或 $k_2\in\{0,1/2,1,2\}$ 时获证；对一般 $N\ge 3$、$k_2>0$ 只证明 $J^{1/k_1}$ 型极限，对数导数极限仅期望成立；$N=2$ 且一般 $k_2>0$ 时极限存在但通常无法显式计算（需解复杂代数方程）；过程弱极限定理的启发式论证部分依赖 Laplace 方法严格化，退化参数（如 $x_i=0$ 或 $w_i=0$）的边界行为需谨慎处理。
- **开放问题**：$N\ge 3$ 且一般 $k_2>0$ 时对数导数极限的证明；对 $N=2$ 或 $k_2=0,1/2,1,2$ 情形能否得到比依概率收敛更精细的收敛类型（如中心极限定理级）；$B_2$ 型一般 $k_2>0$ 时极限的显式计算。
- **应用与推广**：带漂移布朗运动在 $\mathbb R^M$、$M\times N$ 矩阵空间（$\mathbb R,\mathbb C$ 与四元数上）径向部分的 $M\to\infty$ 极限；$N=1$ 时 Dunkl 情形的讨论；所得极限公式可与一般根系 Bessel 函数与 Dunkl 核的一致界估计结合，用于更广的 Dunkl 过程渐近分析。

- 技术迁移：本文"转移密度 + Laplace 方法 + 唯一最大值点构造"的证明套路，可迁移到其它带漂移扩散族的冻结极限推导。

### 可以尝试的方向

- [ ] 能否把对数导数极限推广到一般 $N\ge 3$ 与任意 $k_2>0$，例如借助 Jack 多项式级数的高阶项分析？
- [ ] 能否对 $N=2$ 或 $k_2=0,1/2,1,2$ 情形证明比依概率收敛更精细的中心极限型定理？

### 批判性思考

- 对数导数极限与 $J^{1/k_1}$ 极限形式上互为对数导数关系，但作者明确无法用级数方法同时证明二者，说明 Jack 多项式级数对导数型极限不友好；是否存在更直接的解析论证（如积分表示下的直接展开）？
- 过程弱极限的启发式论证依赖极限生成元与 ODE 解的唯一性；Laplace 方法中唯一最大值点的构造在退化情形（如 $x_i=0$ 或 $w_i=0$）是否依然成立，作者定理在闭区域 $C_N^B$ 上的边界行为值得细究。
- 定理在 $x=w=0$ 时与 AKM2 的 Eq. (20) 相符，说明冻结极限对特殊参数退化为已有结果；但一般情形的紧性论证依赖转移密度估计，读者需确认 Laplace 方法的余项控制是否关于 $k_1$ 一致成立。
