# A Gelfand Model for the Okada Algebra

keywords: [Okada 代数, Gelfand 模型, Okada 弧图, Young–Fibonacci 格, Jones basic construction, cell modules]
related_paper: "Halverson–Reeks 的 partition 代数 Gelfand 模型（Jones basic construction 方法源头）"
one_liner_summary: "本文在对称 Okada 弧图空间上用共轭型作用归纳构造 Okada 代数 $O_n(X,Y)$ 的 Gelfand 模型（经 Jones basic construction 沿 $J_n=O_ne_nO_n$ 与 $C_n\cong O_{n-1}$ 递归），由此得到全部不可约表示并建立与 cell modules 的显式对应。"

## 1.  核心定位

- **解决的问题**：对带 generic 参数 $X,Y$ 的 Okada 代数 $O_n(X,Y)$（Bratteli 图为 Young–Fibonacci 格的半单代数塔，$\dim O_n=n!$），构造一个含每个不可约表示恰一次的 Gelfand 模型，并借此显式实现全部不可约表示。
- **大图景位置**：这是"图代数 + Jones basic construction"这一构造 Gelfand 模型纲领（Mazorchuk 对 Brauer/Temperley–Lieb，Halverson–Reeks 对 partition 代数）在 Okada 代数上的落地；Okada 代数与对称群的 Young 格地位相当（Bratteli 图即 Young–Fibonacci 格），故模型填补了"1-微分格"表示论中 Young 格一侧有模型、Young–Fibonacci 一侧此前缺失的空白。
- **主要贡献**：
  1. 在对称 Okada 弧图空间上定义共轭型作用 $d\cdot t=\lambda(d,t)[d\circ t\circ d^*]$（$t$ 对称、$\mathrm{PLab}([d\circ t\circ d^*])=S$ 时非零），构造 $O_n$-模 $M_n=\bigoplus_S M_n^S$（$S$ 取遍 rank-$n$ 的 Fibonacci 集）；该空间与 $S_n$ 中对合一一对应（Hivert–Scott Theorem 4.14）。
  2. 经 Jones basic construction：选取幂等元 $e_n$，使理想 $J_n=O_ne_nO_n$ 的不可约指标集与 $O_{n-2}$ 双射，补子代数 $C_n\cong O_{n-1}$，得到递归 $\Lambda_{O_n}=\Lambda_{O_{n-2}}\sqcup\Lambda_{O_{n-1}}$（即 Young–Fibonacci 格 rank 递推），在字符层面（split semisimple）证明 $M_n$ 为 Gelfand 模型。
  3. 用该模型显式给出 $O_n(X,Y)$ 的全部不可约表示（由 Young–Fibonacci 格 rank-$n$ 元素指标化），并证明与代数的 cell modules 一致；除建立 split semisimplicity 所需的维数信息外，不依赖 Okada 原始不可约实现。
- **关键先驱工作**：Stanley（differential posets）与 Fomin（differential posets 上的广义 Robinson 对应）；Okada（Okada 代数塔与 Young–Fibonacci Bratteli 图、不可约分类）；Hivert–Scott（Okada 代数弧图实现，heaps of dimers）；Kodiyalam–Verma、Adin–Postnikov–Roichman（对称群对合空间上的带符号共轭 Gelfand 模型）；Mazorchuk（Brauer/Temperley–Lieb 的 Gelfand 模型）；Halverson–Reeks（partition 代数 Gelfand 模型与 Jones basic construction 提升法）；Halverson–Ram（幂等元 $e_n$ 的选取）。
- **结果边界**：要求 $X,Y$ 为 generic 参数以保证塔 split semisimple（不可约维数信息用于证明 split semisimplicity，是构造的前提而非产物）；Gelfand 模型的判定在字符层面完成，依赖半单性，退化参数或非半单情形不适用；作用与 Okada 原始构造差异显著——本文共轭型作用把每个基元素映为单个基元素的标量倍（可为零），而 Okada 生成元一般给出非平凡线性组合。
- **开放问题**：文中未显式列出 open questions；自然延伸包括：退化参数（非 generic）下模型的行为、模型在 Hecke 型量子化或 $q$-变形下是否保持、与其他 1-微分格（如 Pascal 格）对应代数的 Gelfand 模型构造。
- **应用与推广**：模型直接给出全部不可约表示的无预取实现与 cell module 对应，可服务特征标计算、融合/诱导-限制系数（沿 $O_{n-1}\hookrightarrow O_n$、$O_{n-2}$ 理想递归）以及 Young–Fibonacci 格上路径代数的表示论；"弧图 + 共轭型作用 + Jones 提升"三件套可迁移到其他具 Fibonacci 型 Bratteli 图的图代数族。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Gelfand 模型构造的两大传统——图代数派（Jones basic construction）与群论派（拟抛物诱导），参见 [[2609.15235]]
- [[2609.15235]]：该文分类有限 Coxeter 群由抛物子群限制字符诱导的拟抛物 Gelfand 模型，并处理典范基与 $W$-图；本文则在图代数一侧用共轭型作用与 Jones basic construction 构造模型——两者同属"Gelfand 模型纲领"，一方以诱导/中心化子代数为主轴，一方以图表示与塔递归为主轴，可对照阅读以理解模型构造的两种机制。
- [[2609.07018]]：该文在 $\imath$-Kac–Moody 2-范畴框架下范畴化仿射/分圆 Brauer 代数；Brauer 代数与 Okada 代数同属"图代数 + 表示论"家族（Brauer 用配对图、Okada 用弧图），若把本文的共轭型作用与 cell module 对应提升到范畴化层面，可与该文的分次/范畴化技术衔接。
- 技术迁移："幂等元 $e_n$ 把不可约指标集拆成 $\Lambda_{O_{n-2}}\sqcup\Lambda_{O_{n-1}}$"的 Jones 递归能否用于其他具分形 Bratteli 图的代数（如 Motzkin/planar rook 代数），给出统一的 Gelfand 模型存在性判据？

### 2.2.  可以尝试的方向

- [ ] 能否对 $O_n(X,Y)$ 的 $q$-变形或 Hecke 型类比构造同类 Gelfand 模型，并保持 cell module 对应？
- [ ] 模型给出不可约表示与 cell modules 的对应后，能否据此计算 Okada 代数的分解数与诱导-限制分支规则？

### 2.3.  批判性思考

- 是否存在更范畴化的证明：Gelfand 模型的判定能否绕过字符层面，直接用范畴等价或基于 Fibonacci 集 $S$ 的几何/组合对合给出构造性证明？
- 作者的隐含假设：证明依赖 $X,Y$ generic 的 split semisimplicity，而对"generic"的精确开条件（参数域、谱例外）文中未展开；"两个子模无公共不可约 + 字符关系"的验证以引用的方式给出，其计算细节依赖对弧图乘积 $d\circ t\circ d^*$ 与标量 $\lambda(d,t)$ 的约定，独立复现时需对照 Hivert–Scott 的图代数记号。
