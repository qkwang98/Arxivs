# Coven--Meyerowitz T2 necessity through coprime stripe collapse

keywords: [整数铺砌, Coven--Meyerowitz 条件, 分圆多项式, 掩码多项式, 谱性]
related_paper: "Coven--Meyerowitz 的整数铺砌刻画（T1 必要性 + T1/T2 充分性，Theorems A, B1, B2）"
one_liner_summary: "通过对循环铺砌周期的强归纳、特征恒等式与 Frobenius 恒等式，证明每个平移铺砌整数的有限集合都满足 Coven--Meyerowitz 条件 T2，从而完成有限整数铺砌的完整刻画。"

## 1.  核心定位

- **解决的问题**：Coven--Meyerowitz 的 T2 必要性只在 $|A|$ 至多含两个不同素因子时成立，本文去除对基数、素因子个数、指数与铺砌周期的全部限制，证明任意平移铺砌 $\Z$ 的有限集合 $A\subseteq\Z$ 都满足 T2。
- **大图景位置**：验证了 Konyagin--Łaba 明确陈述的猜想（Conjecture 1.3），与 T1 必要性及 T1+T2 充分性合并，给出有限整数铺砌的完全刻画；该刻画还蕴含谱性与多项式时间可判定性。
- **主要贡献**：
  1. 证明无限制的 T2 必要性定理（Theorem thm:integer）：铺砌 $\Z$ 的有限集必满足 T2；
  2. 得到推论：非空有限集 $A\subseteq\Z$ 平移铺砌 $\Z$ 当且仅当归一化掩码多项式满足 T1 与 T2；
  3. 配套 Lean 形式化验证（companion Lean formalization）确认无限制 T2 必要性陈述。
- **关键先驱工作**：Newman 对素数幂基数整数铺砌的刻画；Coven--Meyerowitz 证明 T1 必要性、T1+T2 充分性及双素因子情形的 T2 必要性；Konyagin--Łaba 的猜想与箱积、多尺度长方体、饱和集方法；Łaba--Londner 对最多两个素除子的 T2 结果；Sands 的子群约化、Szabó 与 Lagarias--Szabó 的反例；Tijdeman 的膨胀定理；Tao 的 stripe 划分命题；Łaba--Londner 的 divisor isometry。
- **结果边界**：证明依赖循环铺砌周期上的强归纳，替换为直积会丢失重复素因子时的循环进位信息；结论针对集合铺砌，Kiss--Londner--Matolcsi--Somlai 的非负函数松弛反例不属于本陈述范围；Lorentz 号差等物理结构不适用。
- **开放问题**：文中以推论形式完成的刻画使整数铺砌可被 T1/T2 在 $\operatorname{diam}(A)$ 多项式时间内检验（Kolountzakis--Matolcsi），进一步的问题是稀疏输入下二进长度参数的算法复杂度；铺砌与谱性（Fuglede 型）在无限制条件下的完整对应细节。
- **应用与推广**：与 Łaba 的谱性定理结合，T1/T2 同时给出集合及其区间并 $A+[0,1)$ 的谱性；由 Kolountzakis--Matolcsi 检验，整数铺砌可在无素数计数限制下被判定；证明机制中"循环进位保留"与"素数-剩余纤维"思想可推广到更一般的有限循环群精确分解。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 与 [[2609.22089]] 同属"谱性 + 铺砌"主题：后者研究 $\mathbb{Q}_p^d$ 中乘积谱集与函数铺砌，本文是整数平移铺砌的经典刻画，两者在谱集与铺砌的等价性层面可互相参照。
- 与 Łaba--Londner 的工作衔接：他们的方法覆盖两个素除子与周期 $(pqr)^2$ 情形，本文通过 coprime stripe collapse 机制突破到无限制情形。
- 暂无匹配的已有笔记（除上述谱性/铺砌主题外）。

### 2.2.  可以尝试的方向

- [ ] 将"循环进位保留 + 素数-剩余纤维"归纳机制移植到有限 Abel 群直积之外的更一般精确分解，看是否给出新的子群约化定理。
- [ ] 能否把 T1/T2 刻画推广到更高维 $\mathbb{Z}^d$ 铺砌的对应条件，或至少刻画其障碍？

### 2.3.  批判性思考

- 证明中 Frobenius 恒等式在积分下降后强制所有 stripe 同向，这个"共取向"论证是否依赖特征 $p$ 的特定选择，值得细读。
- 强归纳依赖所有更小周期的铺砌结论，基础情形与归纳步的分界是否覆盖所有周期形态（含重复素因子幂）需要逐项核对。
