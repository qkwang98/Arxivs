# 1729 in the Mirror: Reversal and Affine Multiplication

keywords: [数字反转, 仿射乘法, 进位序列, 乘法阶, 回文数]
related_paper: "Pudwell 关于 reverse multiples 的综述（Sutcliffe、Kaczynski、Klosinski--Smolarski 的经典结果）"
one_liner_summary: "对任意底数 $B\ge3$ 完全分类仿射交换方程 $R_B(hx+1)=hR_B(x)+1$ 的解，并用其判定素数反转对 $2$ 的乘法阶互反的精确数字准则，证明 $\{1729,9271\}$ 是唯一的两位阶反转奇十进制反转对。"

## 核心定位

- **解决的问题**：受 $1729$ 与其反转 $9271$ 的 $2$ 的乘法阶（36 与 63）互为反转启发，完全分类仿射数字交换方程 $R_B(hx+1)=hR_B(x)+1$（$B\ge3$，$2\le h<B$，$x$ 与 $hx+1$ 均不以 0 结尾）的全部解。
- **大图景位置**：属于数字反转与乘法交换性的经典主题（reverse multiples、palintiples、permutiples）在仿射形式下的精确分类；把"1729 现象"归约为可完全枚举的进位结构，并给出唯一性定理。
- **主要贡献**：
  1. 等长情形（定理 thm:division）：输出与输入同长时，进位序列必须交替 $1,0,1,\ldots,0$，长度必为奇数，数字限制在两个交替区间；
  2. 增位情形：$\gcd(h,B+1)=1$ 时解恰为回文输出的 repdigit；$\gcd(h,B+1)>1$ 时长度为偶且构成有限族，slack 变量双射给出最大长度、各长度二项式计数与 Fibonacci 数/2 的幂形式的总数；
  3. 对已知共享阶指数 $h$ 的素数反转对给出阶反转的精确数字准则；穷举计算（带可独立验证的素性证书）证明 $\{1729,9271\}$ 是唯一一对 $2$ 的阶为不同两位反转的相异奇十进制反转对。
- **关键先驱工作**：经典 reverse multiples $R_B(N)=hN$ 的 Sutcliffe、Kaczynski、Klosinski--Smolarski 结果；Young 的成对进位方程与树方法；Sloane 的综述；Kendrick 的图分类；Holt 对 palintiples/permutiples 的进位关系、乘法系统比较与多图判据；Radcliffe 的定宽反转 $R_{10,L}(N)=2N-1$；Faber--Grantham 的反转和积对；Ezerman--Meyer--Solé 的反转分配律；Rivera 的 palinpoints（Joseph L. Pe 的交换方程）。
- **结果边界**：分类要求 $x$ 与 $hx+1$ 均不以 0 结尾（反转是单位对合）；素数准则假设反转对已共享阶指数 $h$ 且均为素数，素性与指数是前提而非结论；定宽反转（允许前导零）不在分类范围。
- **开放问题**：对一般 $f$ 的交换方程 $f(R_B(x))=R_B(f(x))$ 尚无一般分类理论；$(p-1)/o(p)$ 阶指数相同的素数反转对（如 769/967、72484572757/75727548427）的完整刻画；更宽阶长度（非两位）反转对的枚举。
- **应用与推广**：分类结果可直接判定已知共享阶指数 $h$ 的素数反转对是否具有互反阶，无需逐个计算乘法阶；进位序列比较与 slack 变量方法可迁移到其他仿射数字方程与回文结构计数问题。

## 主动思考区

### 与其他工作的联系

- 与 Holt 的多图判据相比，本文的仿射方程初值进位等于 1、额外输出数字使两进位序列错位，从而脱离 homogeneous 乘法与零边界进位的框架。
- 与 Ezerman--Meyer--Solé 的"反转分配于乘法"不同，本文的方程是仿射而非齐次的，结论由进位缺陷驱动而非无进位乘法。
- 暂无匹配的已有笔记。

### 可以尝试的方向

- [ ] 能否用相同的进位比较思想刻画 $2$ 的阶反转对的一般位数结构（超过两位阶的情形）？

### 批判性思考

- 唯一性证明依赖穷举计算加可验证素性证书，其计算边界（搜到多大范围）是否完全覆盖所有可能的两位阶反转对，需核对程序范围论证。
- "进位序列对齐强迫差消失"的核心论断在等长情形是否对任意底数都无隐藏例外，值得对照定理条件逐底验证。
