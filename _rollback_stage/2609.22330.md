# A Proof of the Common Root Conjecture for Legendre Polynomials

keywords: [Legendre 多项式, Stieltjes 猜想, 公共根, 2-adic Newton 多边形, 球面调和函数]
related_paper: "Stieltjes 1890 年致 Hermite 的信（公共根问题与不可约性问题）"
one_liner_summary: "本文证明 Stieltjes 公共根猜想：不同次数的 Legendre 多项式除两个奇数次多项式共享根 0 外无公共根，其关键是通过构造辅助多项式并估计其 2-adic Newton 多边形中斜率 $1/q$ 边的水平长度来导矛盾。"

## 核心定位

- **解决的问题**：证明 Stieltjes 公共根猜想——对 $0\\le m<n$，$P_m$ 与 $P_n$ 没有公共非零复根；等价地，$\\gcd(P_m,P_n)$ 在 $m,n$ 均为奇数时为 $x$，否则为 $1$。
- **大图景位置**：这是 Stieltjes 1890 年致 Hermite 信中提出的经典问题（连同不可约性问题）；不可约性断言（$P_{2j}$ 与 $P_{2j+1}/x$ 在 $\\mathbb{Q}$ 上不可约）蕴含公共根猜想；同时该问题与球面调和函数的节点集直接相关（Bourgain–Rudnick 关于非赤道纬度圆能否属于无穷多个不同特征值对应节点集的讨论）。
- **主要贡献**：1. 构造辅助多项式 $I_{m,n}(X)=\\frac1X\\int_0^X Q_m(t)Q_n(t)\\,dt$（$Q_j(X)=P_j(2X+1)$ 为平移 Legendre 多项式），并证明 $I_{m,n}\\in\\mathbb{Q}[X]$、$I_{m,n}(0)=1$；2. 证明若 $q=2^e\\ge2$ 且 $m,n$ 的第 $e$ 个二进制位均为 1，则 $I_{m,n}$ 的 2-adic Newton 多边形中斜率 $1/q$ 的边水平长度小于 $3q$（分四步：已知系数点给上界、导出下界、合并得端点横坐标条件、界定水平长度）；3. 结合 Legendre 微分方程与 Newton 多边形理论导出矛盾，完成主定理证明。
- **关键先驱工作**：Stieltjes（1890 年信件）与 Gichev；Wahab（平移 Legendre 多项式的 2-adic Newton 多边形与若干情形的不可约性）；Cullinan–Hajir（相应 Galois 群）；Mangoubi–Kadets–Weller Weiser（每个固定非零数至多是有限多个 Legendre 多项式的根）；Bourgain–Rudnick（球面调和节点集与纬度圆问题）。
- **结果边界**：定理的 gcd 表述精确区分了"两奇数次"（公共根仅 $x=0$）与"其它情形"（无公共根）；证明依赖 $\\mathbb{Q}_2[X]$ 中的因子分解与 Legendre 微分方程的结构，是针对 Legendre 多项式特殊性质量身定做的，未必能直接移植到其它正交多项式族。
- **开放问题**：不可约性问题（$P_{2j}$ 与 $P_{2j+1}/x$ 在 $\\mathbb{Q}$ 上不可约）在文中作为背景仍属未决；公共根问题虽已解决，但球面调和节点集的一般性问题（非轴对称情形）仍开放。
- **应用与推广**：在球面调和函数上，固定极轴后每条非赤道纬度圆至多对应一个使整条圆落入节点集的次数；证明中"系数点定上界 + 微分方程逼下界"的 Newton 多边形技术，可尝试推广到其它满足二阶微分方程的正交多项式族的公共根问题。

### 批判性思考

- 证明的关键杠杆是"水平长度 $<3q$ 与 $\\ge3q$"之间的缝隙，缝隙源于 Legendre 微分方程迫使公共不可约因子的立方整除 $I_{m,n}$；这说明证明对微分方程的依赖是本质的，而非仅靠组合信息。
- 与 Mangoubi–Kadets–Weller Weiser 的"每个固定非零数至多是有限多个 Legendre 多项式的根"相比，本文给出的是更强的整体结论（任意两个不同次数完全没有公共非零根），两种方法的适用范围不同。
