# Contour Computation of Linearized Painlevé II and IV Solutions with Monodromy-Based Error Control

keywords: [Painlevé方程, 线性化, 围道积分, monodromy, Lax对, Riemann–Hilbert, 数值误差控制, 等monodromy方法]
related_paper: "暂无"
one_liner_summary: 实现线性化 Painlevé II/IV 解的围道积分数值算法，以 monodromy 数据变化为诊断量建立阶段式误差分配判据，并与 Dormand–Prince 方法对比验证。

## 核心定位

- **解决的问题**：对线性化第二与第四 Painlevé 方程的围道积分表示进行可靠的数值求值，并控制跨转变层的长程漂移。
- **大图景位置**：这是等 monodromy 方法（Its–Novokshenov、Fokas–Its–Kapaev–Novokshenov）与数值 Riemann–Hilbert 方法（Olver–Trogdon）在"线性化方程数值解"上的具体实现，服务于非线性转变层与分岔现象的可积模型研究。
- **主要贡献**：
  1. 完整的围道算法：非线性背景解 + 规范 Lax 对列延拓 + 归一化匹配 + 不同扇区衰减分支环上的求积；
  2. 基于 monodromy 的误差控制：精确初始基误差恒等式、monodromy 误差分解恒等式，以及用 monodromy 变化增量做阶段式后验细化分配的判据；
  3. 与 Dormand–Prince 方法的系统对比：正则背景、快速增长区、硬失稳后近似正则振荡三种场景，分别测量 monodromy 变化累积偏移与后续漂移；
  4. 实验表明漂移依赖谱条件数、求积精度与初始/后续误差分配；正则 $\mathrm{P_{II}}$ 下匹配解误差时 Stokes 变化漂移小 $1.2$–$1.3$ 倍，选定复 $\mathrm{P_{IV}}$ 背景下两精度等级分别小 $1.9$ 与 $14$ 倍，但直接法更快且更保 Wronskian。
- **关键先驱工作**：Haberman 的 $\mathrm{P_{II}}$ 转变层连接问题；Suleimanov 的波灾变特殊函数非线性对应；Kiselev–Suleimanov 的六方程渐近层级；Kiselev 的 $\mathrm{P_{II}}$ 硬失稳分析；Its–Novokshenov 与 Fokas–Its–Kapaev–Novokshenov 的等 monodromy 理论；Olver–Trogdon 的数值 Riemann–Hilbert 方法；作者此前给出的积分公式（Kiselev24、Kiselev26）。
- **结果边界**：数值实验基于若干选定背景（正则 $\mathrm{P_{II}}$、复 $\mathrm{P_{IV}}$ 等），对比性能依赖非线性背景；围道法在保 Wronskian 与速度上不一定优于直接 RK 法，优势体现在长程漂移控制。
- **开放问题**：未列开放问题；自然的延伸包括将误差分配判据推广到更高阶渐近修正及六方程层级。
- **应用与推广**：线性化解是渐近修正的组成部分，可迁移到自动共振俘获、分界线穿越等动力学现象的量级控制；monodromy 诊断量可作为任意等 monodromy 数值格式的通用精度监测。
