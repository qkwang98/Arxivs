# Tree Bricks and Finite Tree Automata

keywords: [树模, 零关系代数, 树自动机, brick, 箭图]
related_paper: 暂无直接相关论文
one_liner_summary: 将 Crawley–Boevey 树模编码为有限根树并用确定性自底向上树自动机识别，在树上直接定义 automata-induced tree brick 并证明其与树模 brick 等价，最后通过局部染色实现字母表最优压缩。

## 核心定位

- **解决的问题**：能否把 Crawley–Boevey 树模类连同与自同态相关的组合学组织进有限状态框架，并直接在接受的树上表述 brick 性。
- **大图景位置**：树模在自动机理论下的"分支化"处理，是 string 模的正则语言与因子–像 brick 判据向树形组合对象的自然推广；延续自动机理论与有界箭图表示论之间的既有互动。
- **主要贡献**：第一，用有限根树（以 $Q$ 的箭号及其形式逆标记边）编码树数据，并构造确定性自底向上树自动机恰好识别这些编码，零关系的避免通过存储有界路径 profile 以有限记忆完成；第二，引入 automata-induced tree brick（无非平凡因子–像自重叠），借助 Crawley–Boevey 的 graph-map 基证明其等价于相应树模的自同态环为 $K$，即通常表示论意义的 brick；第三，通过局部染色压缩箭号字母表，证明最优颜色数等于 $Q$ 的最大入度与出度，且不改变树数据、graph maps 与 brick 性质。
- **关键先驱工作**：Crawley–Boevey 树模及其 graph-map 基；Gabriel 的万有覆盖方法；Rees 关于单项式代数 string 语言正则性；Srivastava 与 Kuber 用有限自动机描述特殊双列代数 hammock 线性序；Kuber 与 Sengupta 的 multi-entry 逆自动机与 string brick 因子–像判据；Thatcher–Wright 与 Doner 的树自动机基础。
- **结果边界**：框架限于有限维零关系代数（关系有有界长度）；唯一非局部障碍是零关系的避免；brick 对应的树语言是否正则仍属开放。
- **开放问题**：仅由 brick 组成的树语言是否为正则树语言（文中明确留作问题）。
- **应用与推广**：可为特殊双列代数、hammock 结构与稳定秩的算法研究提供树形类比；自动机式砖性判据可迁移到其他由组合数据定义的模类。

### 批判性思考

- 树模 brick 与自动机 brick 的等价依赖 graph-map 基的完整描述，证明较长，读者需熟悉 Crawley–Boevey 的原始框架。
- 正则性问题只对"仅由 brick 组成"的树语言提出，是否可以通过有限自动机构造直接回答尚未明朗。
- 零关系有界长度的假设对编码可行性至关重要，放松该假设时自动机构造可能需要无限状态。
