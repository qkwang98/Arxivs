# Special valuations and automorphisms of affine log Calabi--Yau varieties

keywords: [仿射对数卡拉比-丘簇, 特异赋值, 有限生成赋值, 对偶复形, 特异骨架, Vieta 对合, 三角反射群]

related_paper: "Special test configurations and K-stability of Fano varieties（Li–Xu 关于特殊 test configuration 判定 K-稳定性的工作，特异赋值概念的来源）"

one_liner_summary: "本文证明仿射对数卡拉比-丘簇上「有限生成赋值」与「特异赋值」在对偶复形中给出的骨架与对数卡拉比-丘-法诺紧化的选取无关，因而成为该簇的内在不变量并在自同构群作用下保持；同时把特异赋值刻画为该簇正则函数诱导的赋值偏序下的极大有限生成元。作为应用，作者完整描写了 Markov 三次曲面在 $\bA^3$ 中补集这一仿射对数卡拉比-丘三折上三个 Vieta 对合对特异骨架的作用，将其与双曲平面上 $(\infty,\infty,\infty)$ 三角反射群的作用对应起来，并由此给出逐单形局部闭性猜想的反例（经锥构造升到四维）。"

## 1.  核心定位

- **解决的问题**：特异赋值与有限生成赋值的定义都依赖所选的对数卡拉比-丘-法诺紧化 $(X,D;\Delta)$，本文要证明它们在对偶复形中对应的子集其实只依赖于底层的仿射对数卡拉比-丘簇 $U$，并给出「特异性」不依赖紧化的内蕴刻画，进而在具体三折上研究自同构群作用在该骨架上的动力学。
- **大图景位置**：在双有理几何与 K-稳定性中，退化可由赋值编码，而对数卡拉比-丘对的这类赋值自然落在对数典范位（log canonical place）锥中，其射影化就是对偶复形。Li–Xu 早已说明 K-稳定性可用特殊 test configuration 检验，而除子赋值意义下的特异性正对应于此。本文把关注点从「固定一个对数法诺对」转到「底层仿射对数卡拉比-丘簇上全体特异赋值」，是这一理论在紧化无关性方向上的整体化处理；它与 Peng 在 del Pezzo 曲面上得到的边界收缩下特异性保持的结果相衔接，并把它推广到一般维数。
- **主要贡献**：（1）定理 main：对任意仿射对数卡拉比-丘簇 $U$，$\cD^{\SV}(X,D;\Delta)$ 与 $\cD^{\rfg}(X,D;\Delta)$ 都与紧化选择无关，于是可定义内蕴的特异骨架 $\cD^{\SV}(U)$ 与有限生成骨架 $\cD^{\rfg}(U)$；由于自同构群自然作用于对偶复形，两副骨架都在 $\mathrm{Aut}(U)$ 作用下保持（推论 aut）。（2）定理 maximality：在 $U$ 的正则函数诱导的偏序 $v\preceq w$（即对一切 $f\in\cO_U(U)$ 有 $v(f)\le w(f)$）下，特异赋值必为极大元，反之有限生成的极大元必特异；特别地除子赋值特异当且仅当它在 $\preceq$ 下极大，该偏序还可用赋值独立基给出的热带 theta 函数等价描述。（3）对 Markov 三次曲面补：设 $S=(xyz+x^2+y^2+z^2=0)$、$U=\bA^3\setminus S$、$G$ 为三个 Vieta 对合生成的子群，则 $\cD^{\SV}(U)=\{\ord_S\}\sqcup G\cdot\Pi$，其中 $\Pi$ 是有理多面体基本域、$G\cdot\Pi$ 是连通分支，且存在 $G$-等变连续双射 $\Psi:G\cdot\Pi\to\bH^2\cup\bP^1(\bQ)$，目标取 Satake 拓扑、$G$ 的作用正是 $(\infty,\infty,\infty)$ 三角反射群的作用，而内部限制 $\Psi^\circ$ 是同胚——即特异骨架的非平凡部分几何上就是双曲平面加其有理边界点。（4）定理 counterex：对 $\cD(U)$ 的任意有限三角剖分，总存在开单形 $C^\circ$ 使 $\cD^{\SV}(U)\cap C^\circ$ 在其于 $C^\circ$ 中的闭包内不是开集，从而否定作者先前提出的逐单形局部闭性猜想的整体类比；再经锥构造得到 Kollár 型局部闭性猜想的四维反例。
- **关键先驱工作**：Li–Xu 用特殊 test configuration 判定 Fano 簇的 K-稳定性；作者与 Xu 关于特异骨架的猜想（本文给出反例）；de Fernex–Kollár–Xu 与 Kollár–Xu 关于对偶复形与对数典范位的基础工作；Jang 关于 Markov 三次曲面补上热带动力学的研究（本文借其把 Vieta 对合作用翻译为双曲反射）；赋值独立基与热带 theta 函数的前期工作；Peng 关于 del Pezzo 曲面上特异赋值的二维结果。
- **结果边界**：整体框架假设 $D$ 约化且完全支撑一个丰沛除子、$U:=X\setminus D$ 为 klt，紧化无关性的证明用到了任意两个此类紧化都 crepant 双有理这一事实。偏序极大性刻画中「极大蕴含特异」只对有限生成元成立，因此该刻画本质上是骨架内部而非整个赋值锥上的刻画。Markov 例的陈述针对该特定三折与其 Vieta 子群 $G$：双曲描述中的等变双射只在 $G\cdot\Pi$ 上给出，$\Psi$ 整体仅是连续双射、只有内部限制才是同胚；反例的表述涉及具体三角剖分，不能直接读成骨架自身的纯拓扑性质。
- **开放问题**：作者在讨论部分提出非阿基米德版本的锥猜想、特异骨架与簇复形及镜像对称的联系、以及有限生成性与极大性之间关系的进一步问题；四维反例能否推广到更高维、$\mathrm{Aut}(U)$ 中超出 Vieta 子群的部分在骨架上的作用如何描写，也都留有空间。
- **应用与推广**：骨架的内蕴性与自同构不变性为研究仿射对数卡拉比-丘簇的自同构动力学提供了新的载体；Markov 例把特异骨架与双曲三角反射群联系起来，并借 Markov 方程的簇代数/镜像对称背景给出可计算的模型；反例说明 Kollár 型局部闭性猜想需要新的假设或修正，而锥构造提供了从低维反例生成高维反例的一般通道。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：用 Newton–Okounkov 退化研究赋值与多面体体的工作 — 见 [[2608.11109]]；簇簇代数簇的 Chow 消没与动机研究 — 见 [[2609.19744]]
- [[2608.11109]]：该文以 Newton–Okounkov 退化刻画赋值几何与多面体体的关系，与本文用正则函数偏序（以及热带 theta 函数）刻画特异赋值处于同一技术语境；本文的偏序极大性可以视为对「哪些赋值有资格成为退化数据」这一问题的序论式回答。
- [[2609.19744]]：该文处于簇代数簇与镜像对称的语境，研究 Chow 消没与动机；本文 Markov 三次曲面补的构造天然带有簇结构与镜像对称背景，作者在讨论部分明确把与簇复形、镜像对称的联系列为后续方向，这篇笔记可作为进入该方向的入口。
- 技术迁移：本文证明紧化无关性的核心手法是「把有限生成与特异性翻译成多重退化中央纤维的性质，再在 crepant 双有理变换下比较」，这一策略同样适用于其它由紧化定义的赋值得合（如 Kollár 赋值、对数典范位的更多细分族），可能得到更多内蕴骨架。

### 2.2.  可以尝试的方向

- [ ] 若去掉 $D$ 约化或丰沛支撑的假设，或允许 $U$ 非 klt，骨架的紧化无关性是否仍然成立？
- [ ] 是否存在「极大但非特异」的赋值？若存在，其与特异赋值在几何上的差别（相应对数法诺退化是否 klt）能否量化？
- [ ] Markov 例的双曲描述能否推广到其它仿射对数卡拉比-丘曲面或三折，例如与 Markov 方程同类的其它簇代数模型？
- [ ] 锥构造能否把 Markov 例的反例升到任意维数，从而系统否定 Kollár 型局部闭性猜想的高维形式？
- [ ] $\mathrm{Aut}(U)$ 中 Vieta 子群之外的元素在 $\cD^{\SV}(U)$ 上的作用是否也有双曲几何解释？

### 2.3.  批判性思考

- 骨架内蕴性依赖于「任意两个此类紧化都 crepant 双有理」这一强事实，证明的落脚点是多重退化中央纤维的有限生成性与 klt 性在 crepant 双有理变换下的比较；当边界不约化或 $U$ 不 klt 时这一比较会遇到什么障碍，文中没有讨论，而这类放松恰恰是应用中最常见的需求。
- 偏序极大性刻画中「极大蕴含特异」一侧要求极大元有限生成，作者也把结论限制在有限生成骨架内，这使得该刻画无法直接用来判定一个一般赋值是否特异；要把它变成判定工具，需要额外的有限生成性判据。
- Markov 例中 Vieta 群 $G$ 只是 $\mathrm{Aut}(U)$ 的子群，而双曲描述是 $G$-等变的；相对地，推论中的自同构不变性是对整个 $\mathrm{Aut}(U)$ 陈述的。这一落差意味着除 $G\cdot\Pi$ 之外的骨架部分仍缺少显式描写，群作用的完整图像尚不闭合。
- 反例的表述依赖于对偶复形的有限三角剖分（「存在某个开单形使交集在其闭包中不开」），这与 $\cD^{\SV}(U)$ 的纯拓扑性质并不等价；作者经锥构造过渡到 Kollár 局部闭性猜想时引入了额外的维数与锥结构设定，这一过渡中隐含假设（如锥上骨架与底空间骨架的关系）值得单独核对。
- 「特异赋值恰为极大幅值元」这一优美结论与 $(\infty,\infty,\infty)$ 三角反射群的出现其实来自两条独立的论证路径（前者是代数序论、后者是热带动力学的计算），二者之间是否存在更本质的统一图景，文中未给出。
