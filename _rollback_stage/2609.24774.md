# ON THE INDUCTIVE BLOCKWISE ALPERIN WEIGHT CONDITION FOR TYPE $\mathsf B$ AND TYPE $\mathsf C$

keywords: [诱导 blockwise Alperin 权条件, Alperin 权猜想, 有限单群, $\ell$-块, Brauer 字符, Jordan 约化, 零星群]
related_paper: "Feng--Li--Zhang (2019)，B 型与 C 型单群诱导权条件的先前工作"
one_liner_summary: "本文证明所有 B 型与 C 型有限单群在整除其阶的每个素数处满足诱导 blockwise Alperin 权条件（iBAW），通过 Conlon 归纳定理去掉 unitriangularity 假设、修正 $\ell=2$ 时 radical 2-子群分类的遗漏并用 Jordan 约化推广到任意块，另以特征表计算完成四个零星群的证明。"

## 1.  核心定位

- **解决的问题**：证明每个 B 型或 C 型非交换有限单群 $S$ 在整除 $|S|$ 的每个素数 $\ell$ 处满足诱导 blockwise Alperin 权条件（iBAW），即 Alperin 权猜想的细化版本（要求相容的等变双射，由 Sp\"ath 引入）成立。
- **大图景位置**：这是有限群模表示论中 blockwise Alperin 权猜想验证计划的一部分；Sp\"ath 的约化定理将一般有限群的权猜想化归为对非交换单群验证 iBAW。本文补齐 B/C 型单群中此前依赖 unitriangularity 假设或分类遗漏而遗留的情形，并附带完成 $J_4$、$Fi'_{24}$、Baby Monster 与 Monster 四个零星群。
- **主要贡献**：① 对 $\Sp_{2n}(q)$（$q$ 奇、$n\geq3$）与 $\Omega_{2n+1}(q)$（$q$ 奇、$n\geq3$）在奇数非定义素数处，用 Conlon 归纳定理与置换格论证去掉 unitriangularity 假设；② 在 $\ell=2$ 奇定义特征时，基于修正后的 radical 2-子群分类验证主块权参数化，并用 Jordan 约化建立所有块的诱导条件；③ 对 $\mathrm{Spin}_{2n+1}(q)$ 证明 Feng--Yu--Zhang 所假设的 Brauer 字符稳定化与扩张性质（主块用广义 Gelfand--Graev 字符，非主块用等变 Jordan 对应与真 Levi 子群）；④ 对偶定义特征、奇数 $\ell$、秩至少 4 的情形，用 Geck 基本集定理与 Feng--Malle--Zhang 的 generic weight 对应给出不依赖 unitriangularity 的证明；⑤ 完成四个零星群的 iBAW 证明（不作优先权声明）。
- **关键先驱工作**：Alperin 权猜想（Alperin1987）；Sp\"ath 的 iBAW 条件与约化定理（Spath2013）；Feng--Li--Zhang（2019/2022）对单potent 块及任意块（在 unitriangularity 假设下）的诱导条件；Li（2021）对 $\mathsf C$ 型的结果；An（1993/1994）与 Fong--Srinivasan（1989）对奇特征块与 radical 子群的分类；Conlon 归纳定理（Conlon1968）；Geck 基本集定理（Geck1993）；Feng--Malle--Zhang（2026）的 generic weight 对应；Feng--Yu--Zhang（2024）对 B 型 $\ell=2$ 情形的处理。
- **结果边界**：$\ell=2$ 时 $\Omega_{2n+1}(q)$ 的结论要求 $(n,q)\neq(3,3)$，例外覆盖群 $3.\Omega_7(3)$ 需单独显式计算；$\PSp_{2n}(q)$ 在 $\ell=2$ 处的权参数化仅对主块做了直接验证，任意块依赖 Jordan 约化；零星群的证明依赖已发表权计数与特征表数据，且作者未获得 Breuer--Feng 相关手稿，无法与之比对范围。
- **开放问题**：作者对零星群部分明确不作优先权声明，Breuer--Feng 在准备中的工作与本文范围是否重合待公开后比较；是否存在不依赖 Jordan 约化的统一证明；unitriangularity 假设在更低秩情形的去除。
- **应用与推广**：与 Sp\"ath 约化定理结合，直接推出：凡被涉及的非交换单节均为 B 型、C 型或零星型的一般有限群 $H$，在 $\ell$ 处满足 blockwise Alperin 权猜想；为块论中权计数、Brauer 字符稳定化与等变双射技术提供新的实例与工具。
