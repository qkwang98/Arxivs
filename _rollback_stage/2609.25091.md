# Algebraic Proof of Completeness of a Positional Numeral System in the Normalized Mersenne Basis

keywords: [normalized Mersenne basis, positional numeral system, completeness, 有理数基数字系统, 贪心算法]
related_paper: "Rational Base Number Systems (Akiyama & Frougny, 2008)"
one_liner_summary: "通过分裂恒等式 $3M_k = M_{k+1} + 2M_{k-1}$ 与构造性贪心算法，代数地证明规范化 Mersenne 基 $M_k = (2^k-1)/3$ 构成封闭且无歧义的位置数字系统，任意自然数存在规范表示的绝对唯一性。"

## 1.  核心定位

- **解决的问题**：证明基于规范化 Mersenne 基 $M_k = (2^k-1)/3$ 的位置数字系统的完备性，即任意自然数存在规范表示且表示绝对唯一。
- **大图景位置**：将经典 Mersenne 序列（OEIS A000225）与交替二进制掩码整数序列（OEIS A002450）结构性联结，在有理数基数字系统（RBNS）与整数单调序列贪心打包理论之间建立代数桥梁。
- **主要贡献**：给出系统完备性（规范表示的存在性与绝对唯一性）的严格代数证明；揭示基的内部动力学由分裂恒等式 $3M_k = M_{k+1} + 2M_{k-1}$ 确定性支配，严格限制系数字母表为 $\{0, 1, 2\}$；基于低阶数字上确界引理与构造性贪心算法，证明该系统是封闭且无歧义的代数空间，完全排除位置质量的交叠。
- **关键先驱工作**：Fraenkel (1985) 与 Frougny (2002) 关于贪心打包算法与任意整数单调递增序列字母表性质的工作；Akiyama 等人对有理数基数字系统（RBNS）的系统研究；OEIS A000225 与 A002450 两条整数序列。
- **结果边界**：完备性针对自然数 $x \in \mathbb{N}$ 在规范（贪心打包）准则下成立；偶数指标 $k = 2m$ 的基元素为整数（对应 A002450），奇数指标落入有理数域，形成混合整-分数谱，其处理依赖规范化结构；系数字母表被严格限制为 $\{0, 1, 2\}$。
- **开放问题**：core 文本未明确列出开放问题；可进一步探索该系统在非自然数（整数、有理数）上的表示、与 RBNS 周期展开理论的关联、以及多基推广。
- **应用与推广**：为有理数基数字系统的完备性证明提供了新实例；其"分裂恒等式加字母表约束"的分析模式可迁移到其他由归一化整数序列构造的位置系统。

### 2.3.  批判性思考

- 唯一性是在 canonicity criterion（贪心打包）这一规范选择之下的绝对唯一性；若换用其他规范化准则（如非贪心），结论是否仍成立值得追问。
- 偶数指标对应 OEIS A002450、奇数指标落入有理数域，这种奇偶分裂是否暗示可以用更统一的方式（如线性递推拓扑）刻画整个基族？
- 分裂恒等式 $3M_k = M_{k+1} + 2M_{k-1}$ 中系数 3 的"级联"直觉需要在形式证明中严格化；若论文给出构造性证明，需检验其每一步是否依赖未被明示的良序或完备性假设。
