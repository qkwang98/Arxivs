# Categorical representations of algebraic groups in positive characteristic

keywords: [范畴表示论, 正特征, 代数群, Harish-Chandra 双模, ∞-范畴, Ind-凝聚层, 范畴迹]
related_paper: "2609.25539"
one_liner_summary: 对任意基域上的有限型仿射群概形建立弱与强范畴表示的形式体系，通过重正规化定义 $\Rep(H)$ 与 $\hc_H$，并计算恒等与 Frobenius 态射的范畴迹，与伴商 $G/G$ 及不动点 $G^{\Frob}$ 的 Ind-凝聚层范畴相联系。

## 1.  核心定位

- **解决的问题**：将特征 $0$ 几何朗兰兹纲领中成熟的范畴表示理论（Beraldo、Tao 等）推广到任意基域（尤其正特征）上的有限型仿射群概形，并处理正特征带来的无穷上同调维数困难。
- **大图景位置**：这是几何朗兰兹纲领中范畴表示论的基础性拓展——特征 $0$ 理论是弱/强范畴表示与 $\Rep(H)$/$\hc_H$ 模的等价；本文为正特征建立对应基础，并推进 Harish-Chandra 双模、范畴迹等核心对象的理论，为后续与半无限层/仿射格拉斯曼流形的等价做准备。
- **主要贡献**：
  - 修正 $\Rep(H)$ 的定义：采用 $\BB H$ 上的 Ind-凝聚层（重正规化），保证有限维表示紧致；类似地对 Harish-Chandra 双模 $\hc_H$ 重正规化。
  - 证明 $\Rep(H)$（交换、刚性）与 $\hc_H$（刚性、在模特征消失时 pivotal）为 $\DGCat$ 中的代数对象。
  - 定义弱（$\Rep(H)$-模）与强（$\hc_H$-模）范畴表示，构造从 $\QCoh(H)$-模、$\Dmod(H)$-模的完全忠实嵌入（非等价）。
  - 对子群、代数的等变模、Harish-Chandra 模给出具体例子；证明抛物情形下 $\Rep(K)$、$(\fh,K)\mod$ 的光滑性/真性（类比 Ben-Zvi-Gunningham-Oh 的主要结果）。
  - 计算范畴迹：恒等态射的迹 $\simeq$ 伴商 $H/H$ 的 Ind-凝聚层（代数闭域，利用 Fargues-Scholze）；Frobenius 态射的迹 $\simeq \Rep(H^{\Frob})$；并构造 $\Tr(\hc_H,\varphi)\to\Tr(\Rep(H),\varphi)$ 的保守函子，Frobenius 情形为等价。
- **关键先驱工作**：Gaitsgory-Lurie 的 $1$-affineness 定理、Beraldo 的弱/强范畴表示理论、Tao 的 Harish-Chandra 双模理论、Raskin 的无穷型群重正规化、Fargues-Scholze 的生成性结果、Ben-Zvi-Gunningham-Oh 的光滑性/真性定理。
- **结果边界**：重正规化后的定义与特征 $0$ 的朴素推广不等价（仅完全忠实嵌入）；强表示的几何例子受限于晶态 $D$-模 $\infty$-范畴理论在一般底上的不完善；范畴迹的 Frobenius 计算需假设 $H^{\Frob}$ 的每个简单表示可扩张为 $H$ 的代数表示（约化群且导子子群单连通时满足）。
- **开放问题**：将 $\Rep(H)$/$\hc_H$ 的范畴表示与半无限层、仿射旗簇/仿射格拉斯曼流形的等价（作者预告的后续工作）；晶态 $D$-模理论的一般底推广；pivotal 结构在一般模特征（非约化）情形的精确描述。
- **应用与推广**：为几何朗兰兹纲领正特征版本提供基础工具；Harish-Chandra 模的范畴化用于约化群表示论；范畴迹可用于局部朗兰兹对应与特征层的范畴化研究。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Frobenius 函子与 $n$-挠自由对象 — 见 [[arxiv_read/2609.25539]]
- [[arxiv_read/2609.25539]]：同为表示论中 Frobenius 相关结构的研究，该文处理 Frobenius 函子与挠自由对象；本文在正特征范畴表示框架下考察 Frobenius 态射的范畴迹，二者在 Frobenius 现象的范畴化层面互补。
- [[arxiv_read/2609.25045]]：Weil 表示与 theta 对应的表示论基础，本文的 Harish-Chandra 双模框架可作为更广泛 theta 对应范畴化的载体。
- 技术迁移：重正规化（Ind-凝聚层）构造 $\Rep(H)$ 的技巧，可迁移到其它病态 $\infty$-范畴（如格点、层范畴）的紧致性修复。

### 2.2.  可以尝试的方向

- [ ] 能否将 $\Tr(\hc_H,\varphi)\to\Tr(\Rep(H),\varphi)$ 的保守函子等价性推广到一般态射 $\varphi$ 或非代数闭基域？
- [ ] $\Rep(K)$（抛物子群）的光滑性/真性结论能否用于构造抛物诱导的范畴化（正特征 Soergel 理论式对应）？

### 2.3.  批判性思考

- 弱/强范畴表示定义采用"对偶"视角（$\Rep(H)$-模、$\hc_H$-模）而非特征 $0$ 的 $\QCoh(H)$-模/$\Dmod(H)$-模，二者仅完全忠实嵌入而非等价——这种分歧对几何例子（如轨道范畴）的适用性需要仔细评估。
- 范畴迹的计算依赖 Fargues-Scholze 的生成性结果与 Frobenius 表示的扩张假设，这些假设在一般约化群（如非单连通导子子群）失效时的行为未完全刻画。
