# The Missing Zigzag: Cycles of Semitone Trichords and a Conservation Law in Equal Temperament

keywords: [semitone trichords, equal temperament, conservation law, universal cycles, Lean 4]
related_paper: "Universal cycles for combinatorial structures (Chung, Diaconis, Graham, 1992)"
one_liner_summary: "通过 $\mathbb{Z}/3$ 值守恒律证明等程律中半音三和弦循环的之字形轮廓仅在 $3 \mid n$ 且 $n \notin \{6,12\}$ 时出现，并用 Lean 4 机器验证了该分类的两个方向。"

## 核心定位

- **解决的问题**：解释"缺失之字形之谜"（MZP）——在十二音等程律（$12$TET）的全部 $1764$ 个半音三和弦循环中，半音三和弦 $012$ 总是以音阶式（连续的 $x,x+1,x+2$）呈现，从不以之字形轮廓（如 $1,0,2$）出现，并给出该现象在一般 $n$TET 下的完整刻画。
- **大图景位置**：这是等程律组合学与普适循环（universal cycles）理论的交叉；它不是局部约束现象（Proposition 显示仅靠邻接数据无法检测），而必须从整条闭循环的全局结构理解，与 Chung–Diaconis–Graham 的 universal cycles 理论及欧拉回路计数传统一脉相承。
- **主要贡献**：
  1. 分类定理：$n$TET 中存在之字形循环当且仅当 $3\mid n$ 且 $n\notin\{6,12\}$；$9$TET 甚至只存在之字形循环；
  2. 分离定理：把循环拆成"每个三和弦类型的轮廓选择"与"轮廓的时间顺序"两层，障碍完全发生在第一层；
  3. 机制定理：半音类型的呈现是附属于循环的区间流网络的守恒荷——音阶式为中性（系统仅有的自环），之字形注入一单位荷且永不可中和，只能绕全循环传播并在算术上抵消，仅当 $3\mid n$ 时可能；正向障碍由 $\mathbb{Z}/3$ 值权重函数证明，两个例外 $n=6,12$ 由有限证书排除；
  4. 稀有性定量：转移动力学分裂为不相交的中性与带电扇区，增长常数分别为 $6.3723$ 与 $3$，至 $36$TET 时之字形配置约被反超 $1.8\times 10^6$ 倍；
  5. 精确普查：给出远超直接搜索范围的计数，如 $B(24)=952{,}560$、$B(27)=30{,}352{,}896$，并由 BEST 定理与精确矩阵树行列式独立复核。
- **关键先驱工作**：普适循环理论（Chung–Diaconis–Graham 1992、Jackson 1993、Hurlbert 1994）；欧拉回路计数（Aardenne-Ehrenfest–de Bruijn 的 BEST 定理，1951）；十二音作曲理论中转位（非转位）等价的三和弦类型约定。
- **结果边界**：分类适用于 $n$TET 且仅针对含半音的三和弦类型（按移调等价、不计转位）；例外 $n=6,12$ 的排除依赖有限计算证书；普查条目在 $n=21,24,27$ 处超出直接搜索、依赖 BEST 定理推导，证明中区分了定理、有限验证与猜想三种陈述。
- **开放问题**：在哪些其他调律或更高维音程结构中会出现类似"守恒荷"障碍？之字形稀有性随 $n$ 的增长常数 $3$ 与 $6.3723$ 是否有闭式刻画？对 $n=30,33,\dots$ 的精确普查可进一步验证增长规律。
- **应用与推广**：结果可直接用作作曲素材（文中含作曲应用节）；"守恒荷加有限证书"的证明框架结合 Lean 4 机器验证，可迁移到其他组合分类问题的形式化；其"转位不等价"视角对 Forte set class 理论的盲区给出了具体反例式洞见。

### 批判性思考

- 分类的"正向障碍"是纯论证，"例外排除"依赖有限计算证书，"存在性"依赖显式构造——三者性质不同，文中明确维持了定理、有限验证与猜想的区分，读者需留意哪部分依赖计算。
- 计数以转位不等价的类型为准，这是音乐学上合理的约定，但使结果无法直接与 Forte set class 文献对照；若改用转位等价，结论将完全不同甚至失去现象。
- Lean 4 验证中的有限 $12$ 音排除依赖编译后的有限计算，其可信性与纯逻辑证明不同，属于"核验证加外部计算"的混合可信模式。
