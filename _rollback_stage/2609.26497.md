# Chromatic Purity of Dualizable Categories

keywords: [色纯度, 连续K理论, 可对偶稳定范畴, 色断裂方块, redshift]
related_paper: "2609.26741"
one_liner_summary: 发展可对偶稳定范畴的色理论，将代数 $K$-理论的色纯度定理推广到连续 $K$-理论并用 $H$-幺环重新表述，借助范畴完备化构造色断裂方块，得到核纯度、色下降、redshift 上界与 Tate 消没/blueshift，并证明核固体与核气体模范畴满足色 redshift。

## 1.  核心定位

- **解决的问题**：色纯度定理原先只适用于紧生成稳定范畴的代数 $K$-理论；对非紧生成的可对偶稳定范畴（如 Clausen–Scholze 核模范畴、望远镜函子纤维范畴 $\fib(L_n \colon \Sp \to L_n\Sp)$），需要发展连续 $K$-理论的色理论，并构造范畴层面的色断裂方块给出纯度定理的典范实现。
- **大图景位置**：redshift 哲学（Ausoni–Rognes）在范畴层的实现；将 Land–Mathew–Meier–Tamme（LMMT24）与 Clausen–Mathew–Naumann–Noel（CMNN24）的纯度/下降定理从紧生成范畴推广到可对偶稳定范畴（$\mathrm{Pr}^{\dbl}_{\mathrm{st}}$），并提升到 $H$-幺环与核范畴的表述；核纯度进一步将纯度实现为 $\mathrm{Pr}^{\dbl}_{\mathrm{st}}$ 中的典范态射，拟合进范畴断裂方块。
- **主要贡献**：
  1. 对每个可对偶稳定范畴 $\mathcal{C}$，证明 $K^{\mathrm{cont}}_{T(n)}(\mathcal{C}) \xrightarrow{\simeq} K^{\mathrm{cont}}_{T(n)}(L_n^f\mathcal{C}) \xleftarrow{\simeq} K^{\mathrm{cont}}_{T(n)}(M_n^{2,f}\mathcal{C})$（纯度），并借助范畴完备化理论得到核纯度 $K^{\mathrm{cont}}_{T(n)}(\mathcal{C}) \simeq K^{\mathrm{cont}}_{T(n)}(\mathcal{N}\mathrm{uc}_{T(n)\oplus T(n-1)}(\mathcal{C}))$ 与范畴色断裂方块；用 $H$-幺环重新表述纯度。
  2. 建立可对偶同伦不动点/轨道范畴的色下降 $K^{\mathrm{cont}}_{T(n+1)}(\mathcal{C}^{hG,\dbl}) \simeq K^{\mathrm{cont}}_{T(n+1)}(\mathcal{C})^{hG}$ 及其核细化（norm map 在 $T(n)$-完备化后成为等价，对任意有限群成立）。
  3. 提升 redshift 上界、Tate 消没与 blueshift：$\mathrm{ht}(K^{\mathrm{cont}}(\mathcal{C})) \leq \mathrm{ht}(\mathcal{C})+1$（刚性时为等式区间 $[\mathrm{ht}(\mathcal{C}), \mathrm{ht}(\mathcal{C})+1]$），$C_p$-Tate 不动点至多降低高度 1；证明核固体与核气体模范畴满足色 redshift。
- **关键先驱工作**：Efimov 的连续 $K$-理论（Efi25localizing/Efi25limit/Efi25rigidity）；Zhou 的范畴完备化理论（Zhob）与 norm map/Tate 构造（Zhoa）；LMMT24/CMNN24 的纯度与下降定理；Tamme 对 Suslin–Wodzicki 消去的 $H$-幺环表述（Tam18）；Hahn 的 $\mathbb{E}_\infty$-环色高度刻画（Hah22Hinfty）；Ramzi 的 dimension map 与 noshift（Ram26noshift）；Kuhn 的 Tate 消没定理（Kuhn04Tate）。
- **结果边界**：对非刚性（non-rigid）可对偶范畴只有 redshift 上界，下界需要刚性（借助 Ramzi 的 dimension map）；$L_{T(n)\oplus T(n-1)}$ 不一定保持 $H$-幺性，故改用 $M_n^{2,f}$ 作张量；同伦不动点 $\mathcal{C}^{hG,\dbl}$ 一般不同于 $\mathrm{PrL}_{\mathrm{st}}$ 中的极限，仅在有限群时保持短正合列。
- **开放问题**：核下降对更高 $p$-群或更广群作用类的完整形态；除核固体/核气体外更多满足色 redshift 的范畴类；$\mathbb{E}_1$-与 $\mathbb{E}_2$-变体与 Ben-Moshe 工作（BM26quotient）的更精细比较（强 Mittag-Leffler 条件 vs 因子化条件）。
- **应用与推广**：为望远镜猜想反例的纤维范畴、Clausen–Scholze 解析几何中的核模范畴提供连续 $K$-理论的色行为；用于 $T(n)$-局部 Galois 下降与形式几何中 $\lim_n K(R/I^n)$ 的范畴实现（$\mathcal{N}\mathrm{uc}(R^{\wedge}_I)$ 与 $\mathcal{N}\mathrm{uc}(R^{\wedge,\solid}_I)$）。
