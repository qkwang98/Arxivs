# Brauer webs of finite and affine type

keywords: [B-web 范畴, 仿射 web 范畴, 图式范畴, 整基, BCD 型李代数, 冒泡]
related_paper: "SWweb：仿射 web 范畴（作者前作）"
one_liner_summary: 为 BCD 型李代数表示论引入有限与仿射 B-web 幺半范畴，建立带泡初等图的整基，并在特征零域上给出简化表示。

## 1.  核心定位

- **解决的问题**：为两类新的幺半范畴——有限与仿射 B-web 范畴——建立完整的图式框架与整基理论，并构造它们在 BCD 型李代数表示范畴上的自然作用。
- **大图景位置**：这是作者系列工作（仿射 web 范畴、仿射 Schur 范畴及其 q-形变）的 Brauer 型推广，把 A 型 web/Schur 范畴的图式方法扩展到 BCD 型李代数与量子群的表示论，预期与 iquantum 群上模范畴化紧密相关。
- **主要贡献**：
  1. 定义有限 B-web 范畴 $\Wb_{\mathbb J}$ 与仿射 B-web 范畴 $\AWb$，给出生成对象、生成态射（merge、split、粗 crossing、cup、cap、粗点）及定义关系。
  2. 建立基定理：$\Hom_{\AWb}(\mu,\lambda)$ 是以 $\PSMat_{\lambda,\mu}$ 为基的自由 $\Xi$-模，$\Xi$ 由偶 bubble 自由生成；有限型推论 $\Hom_{\Wb}(\mu,\lambda)$ 以 $\SMat_{\lambda,\mu}$ 为基。
  3. 构造表示函子 $\mathcal F_N:\Wb_{\C}(N)\to so_N\text{-mod}$ 与 $\cG_N:\AWb_{\C}(N)\to \emod(so_N\Mod)$；在特征零域给出 $\AWb$ 的简化表示（$\AWCb\cong \AWb$），并证明奇 bubble 由偶 bubble 与 Genocchi 数显式表达。
- **关键先驱工作**：BEEO 的有限 web（Schur）范畴、CKM 的 web 范畴、SWweb 与 DKM25 的仿射 web 范畴、SWSchur 的仿射 Schur 范畴、SSW25 的 q-形变、RS2019 的仿射 Brauer 范畴、ST19 的量子 web 范畴。
- **结果边界**：本文处理经典（非量子）情形，$q$-形变留待后续文章；基定理的线性无关性本质上依赖表示函子 $\cG_N$，因而只在 $\C$ 上工作；有限型整基 $\SMat_{\lambda,\mu}$ 与仿射型 $\PSMat_{\lambda,\mu}$ 均要求环 $\mathbb J$ 或 $\mathbb J'$ 上的积分设定。
- **开放问题**：cyclotomic B-web 范畴的表示论（bubble 与经典李代数万有包络代数中心的联系）、有限与仿射 B-web 范畴的 q-形变、仿射 B-Schur 范畴及其 cyclotomic 商、B-web/B-Schur 范畴的同调性质（三角基、拟遗传结构、Schur 型对偶）、与 iquantum 群模范畴化的联系。
- **应用与推广**：B-web 范畴自然作用于 BCD 型李代数（如 $\so_N$）的楔积模；Genocchi 数的出现给出表示允许性（admissibility）条件的必要充分判据；其上的冒泡与粗线技术为后续 B-Schur 范畴与 cyclotomic 商提供了图式计算基础。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：仿射 web 范畴与 q-web 范畴的分解矩阵理论 —— 见 [[2608.07394]]
- [[2608.07394]]：同作者（Song–Wang）对 cyclotomic $q$-web 范畴分解矩阵的研究，其仿射 $q$-web 范畴的典范基是本文 $q$-形变展望的天然延续。
- [[2609.07018]]：仿射与 cyclotomic Brauer 范畴的范畴化（$\imath$-Kac--Moody $2$-范畴），与本文 $\AWb$ 中细线子范畴等同于仿射 Brauer 范畴的结论互为印证。
- [[arxiv_read/2609.25159]]：仿射 Brauer 型范畴的幺半 Gröbner 系统与基定理，与本文的整基与归约过程可相互对照。
- 技术迁移：本文冒泡归约（lollipop 与 bubble 化简）与类型 A 情形 [[2608.07394]] 的归约技术同源，但 B 型新增的 cup/cap 关系使归约更复杂——这套技术可推广到其他带粗线生成元的图式范畴。

### 2.2.  可以尝试的方向

- [ ] 能否对 cyclotomic B-web 范畴建立类似 [[2608.07394]] 的分解矩阵理论，将奇 bubble 关系（Genocchi 数）翻译为表示论允许性条件？
- [ ] 能否把 $\Wb_{\C}(N)$ 的表示函子推广到量子群情形，与 $\imath$-量子群的典范基分类衔接？

### 2.3.  批判性思考

- 定理 F（$\AWCb\cong \AWb$）的证明依赖冗余的粗 crossing 生成元——这一策略是否在更一般的 Brauer 型范畴（如 $q$-形变）中仍然可行？
- 基定理的线性无关部分完全依赖表示函子 $\cG_N$ 的忠实性，作者是否隐含假设了该函子的某种完全忠实性？在 $\mathbb J'$ 系数下是否仍成立？
