# Degrees and Directional Defects of Embedded Algebraic Vector Bundles

keywords: [嵌入代数向量丛, 方向缺陷, 双次数, 几何度, 切丛, 割线簇, 延拓簇]
related_paper: "2609.09301"
one_liner_summary: 为嵌入代数向量丛建立统一的缺陷理论，以双次数消失给出方向缺陷的有效数值判据并恢复切、对偶、并、割线各类经典缺陷，证明光滑仿射簇切丛度的锐利二次上界 $\deg(TV)\leq\deg(V)^2$，并应用于微分代数延拓簇的度估计。

## 核心定位

- **解决的问题**：把切簇、对偶簇、并簇与割线簇等经典构造的缺陷性（defectivity）统一到嵌入代数向量丛的框架中，给出有效的数值判据与度公式。
- **大图景位置**：缺陷性研究长期分散于各个具体几何情境（如对偶簇的 Chern 类/极次消失判据）；本文提供了统一的数值框架，把缺陷性问题转化为消元/多项式方程求解问题，并推广了 Holme、van der Waerden 与 jeronimo 等人的结果。
- **主要贡献**：
  1. 定理 A：方向缺陷 $\Delta(E)>0$ 当且仅当某双次数 $\deg_{c,d+r-1-c}(\overline{E}')=0$，从而缺陷可由连续消失双次数个数恢复；余法丛情形回归 Holme 的极次判据。
  2. 定理 B：任意嵌入代数向量丛的度公式 $\deg(E)=\deg(V)+\xi_{d-s+1}(E)\deg(\mathscr{D}(E))+\sum_{a=1}^{s-1}\xi_{d-a+1}(E)\deg(\mathscr{D}(E_a))$，把几何度分解为一般线性限制的方向簇贡献；并证明嵌入平凡性等价于度最小。
  3. 定理 C：对光滑不可约仿射簇 $V\subseteq\mathbb A^n$ 证明锐利界 $\deg(TV)\leq\deg(V)^2$，且对满足 $d+1\le n$ 的任意 $(d,D)$ 存在达到等号的 $V_{D,d}$；当 $X$ 光滑且 $2\dim V\le n$ 时加强为 $\deg(TV)\le\deg(V)^2-2\mu(X)\deg(\mathrm{Sec}(X))$，彻底回答 jeronimo 的问题。
  4. 定理 D：在生成素理想且代数零点集光滑的假设下，微分代数系统延拓簇满足 $\deg(Z(\mathrm{Prol}(\Sigma)))\le\deg(Z(\Sigma))^2$，部分回答 Pogudin 提出的开放问题。
- **关键先驱工作**：Zak 关于 Hartshorne 线性正规猜想的工作、Terracini 与 Severi 的经典理论、Holme 的对偶簇度公式与极次判据、van der Waerden 双次数定理、Mezzetti–Tommasi、De Poi–Mezzetti 的缺陷性框架、jeronimo 的切丛几何度研究、Castillo 等人的双射影解释定理。
- **结果边界**：切丛二次界对光滑仿射簇成立，光滑射影闭包假设下的强形式需要 $2\dim V\le n$；延拓簇估计需要素理想与光滑性假设，仅部分回答 Pogudin 问题；缺陷数值判据依赖双射影解释与双次数计算。
- **开放问题**：Pogudin 关于延拓簇度的一般开放问题（本文给出正则假设下的部分回答）；缺陷理论对其他具体族（Segre 簇割线、Grassmann 簇割线）猜想的应用，如 Abo–Ottaviani–Peterson 与 Baur–Draisma–de Graaf 猜想。
- **应用与推广**：统一框架可把各类缺陷性问题转为多项式方程求解技术处理；度公式恢复切度 $\tau(X)$、割线度 $\mu(X)$ 与不变量 $\omega(V)$ 等枚举不变量；二次界可直接用于微分代数系统的复杂度分析。
