# Lifting $A_\infty$-structures through coverings with applications to fractional Brauer graph algebras

keywords: [$A_\\infty$-范畴, 覆盖, 群分次, 分数 Brauer 图代数, Nakayama 作用, 派生等价, 几何模型]
related_paper: "Opper–Zvonareva 的 Brauer graph $A_\\infty$-categories（OZ22）"
one_liner_summary: "证明相容群分次决定 $A_\\infty$-结构的典范提升（由覆盖投影的严格保单位唯一刻画），并以此把 Brauer 图 $A_\\infty$-范畴提升为 admissible 分数 Brauer 图代数的 $A_\\infty$-范畴，得到由几何数据（含 Nakayama 特征）控制的派生等价判定，以及四条件组合派生不变量在 reduced genus 0 与非二部 reduced genus $\\geq 2$ 情形的完备性。"

## 1.  核心定位

- **解决的问题**：$A_\\infty$-结构从轨道范畴下降的逆问题——给定基范畴上的 $A_\\infty$-结构及其态射空间的群分次，何时、以何种唯一方式把该结构提升到指定的覆盖（Galois 覆盖 / smash 积覆盖）之上；并将该框架用于构造 admissible 分数 Brauer 图代数的 $A_\\infty$-范畴与派生等价判据。
- **大图景位置**：这是覆盖理论（Riedtmann、Gabriel、Bongartz–Gabriel、Green、Martínez-Villa–de la Peña）在 $A_\\infty$-层面的自然延伸，与 Keller 的 dg 轨道范畴、BMRRT 簇范畴、OZ22 的 Brauer 图 $A_\\infty$-范畴一脉相承；同时把 Li–Liu 的分数 Brauer 配置代数（LL26、LLI26）与 Xin26 的 admissible 分数 Brauer 图代数纳入几何模型与 $A_\\infty$-方法，类比从对称 Brauer 图代数到自入射分数情形的推广。
- **主要贡献**：(1) 提升定理（thm:intro-lifting）：若每个结构映射保持群分次且严格单位具单位权，则相容群分次确定唯一典范提升 $\\widetilde{\\mathcal{A}}$，其唯一性由覆盖投影 $\\pi:\\widetilde{\\mathcal{A}}\\to\\mathcal{A}$ 的严格、保单位 $A_\\infty$-函子性刻画；(2) 构造 admissible 分数 Brauer 图代数的 $A_\\infty$-范畴 $\\mathcal{F}_{\\mathfrak D}(\\U)$，几何数据 $\\mathfrak D=(\\Sigma,\\mathcal P,\\eta,\\mathbf m,r,\\chi)$ 以 Nakayama 特征 $\\chi:H_1(\\Sigma\\setminus\\mathcal P;\\mathbb Z)\\to\\mathbb Z/r\\mathbb Z$ 编码覆盖的单值；(3) 几何数据等价（定向保持微分同胚保持线场、重数与 $\\chi$）蕴含 $A_\\infty$-范畴的 Morita 等价，进而在度零情形给出对应代数的派生等价（thm:intro-geometric）；(4) 四条件组合派生不变量（Nakayama 作用阶数与约化图顶点/边/面数、分数重数多重集、面对 $\\{\\!\\{(\\ell(F),\\operatorname{weight}(F))\\!\\}\\}$ 多重集、二部性）及其在 reduced genus 0 与非二部 reduced genus $\\geq 2$ 情形的完备性（prop:intro-four-derived-invariants、thm:intro-four-condition-completeness）。
- **关键先驱工作**：Riedtmann、Gabriel、Bongartz–Gabriel、Green、Martínez-Villa–de la Peña 的覆盖理论；Keller 的 dg 轨道范畴与三角化；OZ22 的 Brauer 图 $A_\\infty$-范畴；Sheridan 的 $A_\\infty$-pullback；Schröer（Brauer 图代数与对称 special biserial 代数）；Green–Schroll 的 Brauer 图覆盖理论；Li–Liu 的分数 Brauer 配置代数；Xin26 的 admissible 分数 Brauer 图代数；HKK17 的 gentle 代数与部分 wrapped Fukaya 范畴。
- **结果边界**：提升定理要求结构映射保持群分次、严格单位具单位权；几何等价要求定向保持微分同胚且同时保持线场同伦类、重数与 Nakayama 特征；四条件完备性仅在 reduced genus 0 与非二部 reduced genus $\\geq 2$ 情形证明，二部 reduced genus $\\geq 2$ 情形仍为猜想；域代数闭假设自曲面部分起生效。
- **开放问题**：四条件完备性猜想（conj:four-condition-all-genus）在二部 reduced genus $\\geq 2$ 情形的证明；Nakayama 作用与倾斜复形不变性（Aihara 定理 A.4）暗示提升的几何模型可能捕捉所有普通 admissible 分数 Brauer 图代数的派生等价，但尚未完全证实。
- **应用与推广**：为 admissible 分数 Brauer 图代数提供 Fukaya-型几何模型与 $A_\\infty$-结构，与 gentle/skew-gentle 代数的几何纲领（HKK17、OPS18、Lekili–Polishchuk、AB22、BSW24）平行；$r$-fold 平凡扩张（repetitive 构造）作为特例被覆盖；群分次提升框架可用于其他带群分次的代数或范畴结构的构造。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Brauer 图代数类的等价分类与几何模型纲领 — 见 [[2608.14253]]、[[2609.23527]]、[[2608.14360]]，它们与本文共同构成 Brauer/gentle 型代数的同调-几何研究谱系。
- [[2608.14253]]：该笔记证明 Brauer 图代数在 Morita 型稳定等价下封闭；本文处理其分数推广（admissible 分数 Brauer 图代数）的 $A_\\infty$-构造与派生等价判据，两者共享 Brauer 图代数类与等价分类主题，可互为对照。
- [[2609.23527]]：该笔记研究 skew-gentle 代数的 transferred $L_\\infty$-结构与形式性；本文的 $A_\\infty$-提升与之一同构成 gentle/Brauer 图型代数上高同伦结构的研究，$L_\\infty$ 与 $A_\\infty$ 属于同一同伦代数传统。
- [[2608.14360]]：该笔记研究 string 代数几何模型的唯一性与红尖刺判据；本文以（曲面、线场、重数、Nakayama 特征）几何数据推广 Brauer 图代数几何模型到分数情形，二者同属有限维代数表示论的几何化纲领。
- 技术迁移：群分次决定唯一 $A_\\infty$-提升的论证与 Sheridan 的 pullback 构造类似，可迁移到簇范畴或部分 wrapped Fukaya 范畴的覆盖构造中。

### 2.2.  可以尝试的方向

- [ ] 能否证明四条件完备性在二部 reduced genus $\\geq 2$ 情形成立（即证明 conj:four-condition-all-genus）？
- [ ] 提升定理能否推广到非严格单位或更一般分次数据（如加权 $A_\\infty$-结构）的范畴？

### 2.3.  批判性思考

- 提升的唯一性强烈依赖「覆盖投影严格且保单位」这一要求；若放松为同伦保持，典范性是否仍成立、是否会涌现同伦类层面的多个提升？
- 几何数据中的 Nakayama 特征 $\\chi$ 编码一维同调的单值；在高亏格情形，是否真的无需更高维同调信息即可完整刻画覆盖与派生等价？
