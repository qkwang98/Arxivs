# Generic $\\mu$-power ideals, fat points, and symbolic powers

keywords: [$\mu$-幂理想, fat point 线性系统, 符号幂, Hilbert 级数, Fröberg 猜想, apolarity]
related_paper: "FLOS18 中的 Problem F"
one_liner_summary: "本文否定地回答了 FLOS18 的 Problem F：由 $r$ 个一般 $\mu$-幂型生成的理想并不总与 $r$ 个一般 $d$ 次型生成的理想有相同 Hilbert 级数 $G_{n,d,r}$，并通过 apolarity 将反例转化为对偶射影空间中 fat point 线性系统的主障碍（master obstruction），同时给出 $r\le n+1$ 时的肯定结果并纠正 Problem L 的符号亏格公式。"

## 1.  核心定位

- **解决的问题**：对非纯分拆 $\mu\vdash d$，由 $r$ 个一般 $\mu$-幂型（$\mu$-power forms）生成的理想是否具有与 $r$ 个一般 $d$ 次型相同的 Hilbert 级数 $G_{n,d,r}$（FLOS18 的 Problem F）？本文证明答案是否定的，并精确刻画反例出现的条件；同时处理 Problem L 中 $s=n$ 情形的 Hilbert 级数差与符号亏格公式的修正。
- **大图景位置**：Fröberg 猜想预言一般形式的理想达到下界 $G_{n,d,r}$；经典幂理想（$\mu=(d)$）对应 Fröberg–Iarrobino 猜想。本文表明 Problem F 并非独立问题——它被 Fröberg–Iarrobino 猜想支配（Section FI），从而把"非退化 $\mu$ 会消灭反例"的直觉推翻，并给出几何（fat point）根源的完整描述。
- **主要贡献**：
  1. 主障碍定理（定理 master）：apolarity 包含关系把 $\mu$ 的"大块"转化为对偶射影空间 $\PP^{n-1}$ 中的 fat point 线性系统 $\mathcal L(q;m^r)$；若对某 $q$ 与 $m>a$，$\mathcal L(q;m^r)$ 非空而 $\mathcal L(q;(m-a)^r)$ 的虚拟维数非正，则 Problem F 对 $d=q-m+a+1$ 及每个含部分 $d-a$ 的 $\mu$ 有否定答案。
  2. 肯定结果（定理 small-r）：由 Stanley 定理，当 $r\le n+1$ 时 Problem F 对每个 $\mu\vdash d$（含纯分拆）都有肯定答案，因此三元情形在 $r<5$ 时不可能失败。
  3. 三元形式反例的完全刻画：$5\le r\le 8$ 恰为反例区间，极值曲线由五点确定的二次曲线与 del Pezzo 曲面上 $(-1)$-曲线的乘积给出；$r\le 4$ 与 $r=9$ 无条件无碍，假设 Nagata 猜想时 $r\ge 10$ 对每个非纯 $\mu$ 无碍。
  4. 四元情形：$n=4$、$r=9$ 时，$\PP^3$ 中过九个一般点的二次曲面给出对每个 $a\ge 0$ 的反例，$\mu=(d-1,1)$ 的首个反例出现在 $d=28$。
  5. 精确性证书：在 $\mathbb{F}_{32003}$ 上的精确计算表明，$n=3$、$r=5$ 时首个非纯反例为 $d=14$、$\mu=(13,1)$。
  6. Problem L：$s=n$ 的首个非平凡情形已由完全图边理想的符号幂语言解决（Janssen–Kamp–Vander Woude、Chakraborty–Mandal），本文以 Hilbert 级数形式记录 $\HS(I^{(m)})-\HS(I^m)$ 为支撑在次数 $m,\dots,2m-1$ 上的显式多项式；并纠正 CM19 定理 4.4 的符号亏格公式（$m=2$ 成立、$m\ge 3$ 失败），给出对所有 $m$ 有效的公式，该结果与 Rasheed–Yao 的 blow-up 框架特例一致。
- **关键先驱工作**：FLOS18（Problem F 与 Problem L 的提出）；Fröberg（1985）的 Hilbert 级数猜想；Iarrobino 关于经典幂理想的猜想；Stanley 定理（$r\le n+1$ 时的肯定来源）；Nagata 猜想（$r\ge 10$ 无碍的假设前提）；CM19（符号亏格公式，本文修正之）；Janssen–Kamp–Vander Woude 与 Chakraborty–Mandal（完全图边理想符号幂）；Rasheed–Yao（blow-up 框架）。
- **结果边界**：反例的构造依赖 fat point 线性系统的非空性与虚拟维数条件；$r\ge 10$ 时对每个非纯 $\mu$ 的无碍结论依赖于尚未证明的 Nagata 猜想；首个失败 $(d,\mu)=(14,(13,1))$ 的证书是在特征 $32003$ 的有限域上通过精确计算获得的。
- **开放问题**：由定理 small-r 与 master 的结构性后果，Problem F 受 Fröberg–Iarrobino 猜想支配，后者仍开放；若 Nagata 猜想成立则 $r\ge 10$ 无碍，反之则可能给出更多反例族；符号亏格修正公式的极小生成元计数与 blow-up 框架的完整统一仍有待系统化。
- **应用与推广**：为 Hilbert 级数与 fat point 线性系统的对应提供新的检验平台；Problem L 的显式公式可直接用于完全图边理想符号幂与符号亏格的计算；apolarity 障碍技术可推广到其他由线性因子幂构成的理想族。

### 2.1.  与其他工作的联系

- 这让我想起同属"理想幂稳定性"主线的 Eisenbud–Huneke–Ulrich 猜想证明 — 见 [[arxiv_read/2609.25385]]

- [[2609.26752]]：该文涉及的互补边理想符号幂正则度工作（[[2609.06903]]）与本文 Problem L 中完全图边理想的符号幂描述同属边理想符号幂的计算脉络。
- 技术迁移：本文"apolarity 把理想数据翻译为对偶空间中 fat point 线性系统"的编码方式，或可迁移到其他由乘积型生成元（如幂型、幂和型）定义的理想族，用线性系几何判定 Hilbert 级数是否达到 Fröberg 下界。

### 2.3.  批判性思考

- 主障碍定理给出充分条件而非充要条件：是否存在反例虽无主障碍、却因其他几何机制失败，从而需要比 fat point 线性系统更精细的不变量？
- Problem L 的符号亏格修正公式由边理想符号幂导出，其 blow-up 框架解释（Rasheed–Yao）是否对所有 $n,s$ 一致，还是仅在 $s=n$ 时吻合？
