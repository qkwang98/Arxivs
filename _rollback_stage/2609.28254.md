# $G$-categories, bootstrap classes and UCT

keywords: [等变 KK-理论, 等变 E-理论, genuine G-谱, 谱 Mackey 函子, bootstrap class, 万有系数定理, Künneth 公式, 轨道范畴]
related_paper: "Bunke–Wisbauer 关于谱 $G$-Mackey 函子的工作（cite: bw）"
one_liner_summary: 说明对有限群 $G$，等变 $KK$-与 $E$-理论天然丰富于 genuine $G$-谱（等价地，谱 $G$-Mackey 函子）中，由此描述相应 bootstrap classes 并推出万有系数与 Künneth 公式，且这些结果都是等变 $KK$/$E$-理论细化为轨道范畴 $G$ 上参数化范畴的形式推论。

## 1.  核心定位

- **解决的问题**：等变 $KK$-与 $E$-理论在何种意义上"丰富于 genuine $G$-谱"（即取值为谱 $G$-Mackey 函子），以及这一丰富化如何系统导出对应的 bootstrap classes 与万有系数定理（UCT）/Künneth 公式。
- **大图景位置**：把非等变 $KK$-理论（Kasparov 理论）的经典 bootstrap class 与 UCT 框架推广到有限群等变设定：等变 $KK$/$E$-理论不再只是取值于 Abel 群的双函子，而是取值于 genuine $G$-谱，从而携带完整的 $G$-等变同伦信息；这是等变算子 $K$-理论与稳定同伦论（Mackey 函子模型）的交叉。
- **主要贡献**：
  1. 丰富化定理：对有限群 $G$，等变 $KK$-与 $E$-理论自然丰富于 genuine $G$-谱（等价地，谱 $G$-Mackey 函子）；
  2. bootstrap classes：在丰富化框架下描述对应的 bootstrap class（可由基本对象生成、使 UCT 成立的子范畴）；
  3. 导出 UCT 与 Künneth 公式：作为丰富化的形式推论得到万有系数型与 Künneth 型分解；
  4. 统一解释：这些结果本质上源于等变 $KK$/$E$-理论可细化为轨道范畴 $G$ 上的参数化范畴。
- **关键先驱工作**：Bunke–Wisbauer 的谱 $G$-Mackey 函子理论（cite: bw）；等变 $KK$-理论（Kasparov）与等变 $E$-理论；genuine $G$-谱的 Mackey 函子模型；参数化范畴论与轨道范畴上的范畴化理论；经典 bootstrap class 与 UCT（Rosenberg–Schochet 型）框架。
- **结果边界**：群 $G$ 限于有限群；本文是注记（note）性质，主要结论是"形式推论"而非全新的构造性结果——其深度与适用范围取决于等变 $KK$/$E$-理论到参数化范畴的细化本身已被建立；UCT/Künneth 公式的有效性限于所定义的 bootstrap class。
- **开放问题**：bootstrap class 的具体刻画与极小生成对象族；UCT/Künneth 公式与等变指标理论、Baum–Connes 型装配映射的联系；无穷群或非紧群情形的推广。
- **应用与推广**：为等变算子 $K$-理论提供同伦论层面的结构工具，可用于等变指标问题、几何不变量与表示论中的 $K$-理论计算；genuine $G$-谱丰富化使等变 $KK$/$E$-理论能直接与等变稳定同伦论中的工具（如 Tate 图景、几何不动点）对接。

### 2.3.  批判性思考

- 论文自述结果为"形式推论"，其新颖性取决于"等变 $KK$/$E$-理论细化为参数化范畴"这一前提的证明深度；若细化本身仅在同伦范畴层面成立，UCT 的对象级结论可能需要额外条件。
- 有限群限制使 genuine $G$-谱的 Mackey 函子模型完全成熟，但对无穷群（如 $C^*$-代数指标理论常见设定）这一丰富化是否仍存在、UCT 是否仍成立，是未决的实质问题。
