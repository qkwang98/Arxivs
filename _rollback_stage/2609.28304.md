# Braidings, duoidal categories and pre-Cartier structures for bi(co)modules

keywords: [编织, 无穷小编织, duoidal 范畴, 双余模, 四模, pre-Cartier 范畴, Yetter-Drinfeld 模]
related_paper: "Agore–Caenepeel–Militaru 对双模范畴上编织的分类（arXiv 见 agore2014braidings）"
one_liner_summary: 对任意余代数分类了余张量积下双余模范畴上的编织（皆为对称且无穷小编织为零），构造了双(余)模与四模范畴上的 duoidal 结构，并引入 pre-Cartier duoidal 范畴研究编织与无穷小编织的相容性。

## 核心定位

- **解决的问题**：双模与双余模范畴上哪些幺半结构允许编织？编织及其无穷小版本如何与两个幺半乘积之间的交互（duoidal 结构）相容？
- **大图景位置**：双模情形由 Agore–Caenepeel–Militaru 用典范 $R$-矩阵完全分类；本文给出其对偶——余代数上余张量积 $\square^C$ 下双余模范畴 $(^{C}\mm^{C},\square^{C},C)$ 的编织分类，并把问题推进到双代数/双幺半群系数下的 duoidal 结构与 pre-Cartier（无穷小编织）相容性，是编织分类理论从模侧到余模侧、从单一乘积到双乘积的系统推广。
- **主要贡献**：
  1. 分类定理：对任意余代数 $C$，$(^{C}\mm^{C},\square^{C},C)$ 上的编织一一对应于满足对偶恒等式的典范 $R$-形式 $\Rr:C\ot C\ot C\to\Bbbk$；每个这样的编织都是对称，且（对偶于双模情形）只有平凡（零）无穷小编织。作为推论，若 $H$ 是双代数，则 $(^{H}\mm^{H},\square^{H},H)$ 与 $(_H\mm_H,\ot_H,H)$ 除非 $H=\Bbbk$ 否则均无编织；
  2. duoidal 构造：编织幺半范畴中，若余等子存在且被 $\ot$ 保持，则 $(_H\Mm_H,\ot_H,H,\ot,I)$ 是 duoidal；对偶地，若等子存在且被 $\ot$ 保持，则 $(^H\Mm^H,\ot,I,\square^H,H)$ 是 duoidal；四模情形 $({}^{H}_{H}\Mm^H_H,\ot_H,H,\square^H,H)$ 亦为 duoidal（推广 Shoikhet 的向量空间结果）；Hopf 情形下相对张量积与余张量积有公共实现，且与 Yetter-Drinfeld 模的等价把四模 duoidal 结构识别为由典范 Yetter-Drinfeld 编织诱导的结构；
  3. pre-Cartier 理论：引入 $\circ$-pre-Cartier、$\bullet$-pre-Cartier 与双边 pre-Cartier duoidal 范畴；证明四模上的典范 duoidal 结构仅在 $H\cong\Bbbk$ 时允许 $\circ$-或 $\bullet$-编织（障碍定理）；由 pre-Cartier 双代数构造双(余)模上的单侧 pre-Cartier 结构，并给出非零无穷小编织的例子（含截断 Cauchy 与 Hadamard 积构造的完整 pre-Cartier duoidal 例子）。
- **关键先驱工作**：Agore–Caenepeel–Militaru 对 $(_{A}\mm_{A},\ot_{A},A)$ 编织的典范 $R$-矩阵分类；Aguiar 的 duoidal 范畴理论；Shoikhet 关于四模 duoidal 结构的向量空间情形；Drabant、Bespalov–Drabant、Schauenburg 的 Hopf 双模与 Yetter-Drinfeld 模结构理论；ABSW 的 pre-Cartier（无穷小编织）范畴。
- **结果边界**：分类依赖域 $\Bbbk$ 上向量空间设定与 Sweedler 记号；duoidal 构造要求 $\ot$ 保持等子/余等子；pre-Cartier 相容性要求分别检验两个乘积；四模 duoidal 的 Yetter-Drinfeld 等价要求 Hopf 对象反演（antipode）双射。
- **开放问题**：论文未显式列出开放问题，但结合正文可提炼：对更一般（非向量空间）基底的 braided monoidal 环境，双余模编织的 $R$-形式分类是否仍然成立；单侧 pre-Cartier 结构何时能加强为双边 pre-Cartier；除零无穷小编织外，更一般系数下是否出现非平凡无穷小编织。
- **应用与推广**：为 Hopf 双模、Yetter-Drinfeld 模与辫 Hopf 代数的结构理论提供编织分类工具；duoidal 框架可继续用于研究双乘积交互下的表示论与形变理论；pre-Cartier 结构为量子群与辫范畴中的无穷小辫化构造提供系统路径。

### 批判性思考

- 编织皆为对称、无穷小编织皆为零的结论相当刚性，其本质是余张量积的"相对"性质；是否在弱化余模结构（如余模态射不保持余作用）后会出现非对称编织？
- 障碍定理（四模 duoidal 仅当 $H\cong\Bbbk$ 允许编织）与 Yetter-Drinfeld 等价之间的张力值得深究：既然四模等价于 YD 模且 YD 模有非平凡编织，为何 duoidal 结构本身仍被障碍排除——说明相容性条件比单乘积的编织性强得多。
