# Inequalities for ratios of Gamma functions

keywords: [Gamma 函数, Beta 函数, 广义 Stieltjes 函数, 完全单调函数, 对数完全单调, 积分表示]
related_paper: "DSS（Beta 函数比值不等式 $\frac{B(\beta,y)}{B(\alpha,y)}\le(\alpha/\beta)^y$，本文的出发点）"
one_liner_summary: 证明 Gamma 函数比值的对数与初等逼近项之差 $\phi_{a,b}$ 是 3 阶广义 Stieltjes 函数（$0<b<1$ 时为正、$b>1$ 时为负），从而把 Beta 函数比值不等式加强为高阶完全单调性结论。

## 核心定位

- **解决的问题**：加强关于 Gamma 函数比值的经典不等式，即把 DSS 中 Beta 函数比值不等式 $\frac{B(\beta,y)}{B(\alpha,y)}\le(\alpha/\beta)^y$（$0<\alpha<\beta$，$0\le y\le1$）加强为对差值 $\phi_{a,b}(x)=\log\frac{\Gamma(x+a+b)\Gamma(x)}{\Gamma(x+a)\Gamma(x+b)}-b\log(1+\frac{a}{x})$ 的正性与更强结构性质的刻画。
- **大图景位置**：完全单调函数与广义 Stieltjes 函数是分析中刻画积分表示的标准层级；BI 已证明该 Gamma 比值是对数完全单调的，BKP 将其对数加强为 2 阶广义 Stieltjes 函数，本文把阶数推进到 3，并证明这一阶数在一般参数下不可被 $\mathcal S_2$ 容纳（差函数 $g_{a,b}-bh_a$ 一般要变号）。
- **主要贡献**：1) 证明对 $a>0$、$0<b<1$，$\phi_{a,b}$ 是 3 阶广义 Stieltjes 函数，对 $a>0$、$b>1$，$-\phi_{a,b}$ 是 3 阶广义 Stieltjes 函数（定理）；2) 推论出 $R_{a,b}$ 在 $0<b<1$ 时对数完全单调、$1/R_{a,b}$ 在 $b>1$ 时对数完全单调；3) 给出 $\phi_{a,b}$ 的显式积分表示 $\phi_{a,b}(x)=\int_0^\infty\frac{g_{a,b}(t)-bh_a(t)}{(t+x)^2}dt$，并分析其渐近行为 $x^2\phi_{a,b}(x)\to ab(1-b)/2$ 与原点处的对数奇性。
- **关键先驱工作**：DSS 的 Beta 函数比值不等式；BI 关于 Gamma 比值对数完全单调的开创性工作；BKP 的 2 阶广义 Stieltjes 表示及其权重函数 $\varphi_{a,b}(t)=\frac{(1-e^{-at})(1-e^{-bt})}{t(1-e^{-t})}$ 与 $g_{a,b}$ 的显式公式；Bernstein 定理与 Laplace 变换表示；广义 Stieltjes 函数的经典理论（Widder、Sokal 等）。
- **结果边界**：阶数为 3 且参数区间为 $0<b<1$ 与 $b>1$ 两个分离情形，$b=1$ 时 $\phi_{a,1}\equiv0$ 平凡；$\phi_{a,b}\notin\mathcal S_2$ 的一般结论由图例说明而非全程证明；广义 Stieltjes 表示中的测度不一定是显式的。
- **开放问题**：作者未在简介中明确列出开放问题；自然延伸包括：$\mathcal S_3$ 表示的测度是否可取为显式形式、阶数 3 是否最优（能否构造反例说明不属于 $\mathcal S_{3+\varepsilon}$）、以及更一般的多参数 Gamma 比值是否落入更高阶类。
- **应用与推广**：这类高阶完全单调性可直接用于特殊函数不等式的机器证明、概率论中 Gamma/Beta 分布尾概率的界，以及统计物理中相关函数衰减率的严格估计。

## 主动思考区

### 与其他工作的联系

- 暂无匹配的已有笔记。
- 技术迁移：把"差函数逐阶提升广义 Stieltjes 阶数"的证明策略，可迁移到其他由 Laplace 变换表示的正函数类（如 $\Psi$ 函数、polygamma 比）的不等式分析。

### 可以尝试的方向

- [ ] 能否把定理推广到 $n$ 个 Gamma 因子的比值（多参数情形），并给出对应的广义 Stieltjes 阶数？
- [ ] 能否构造 $\phi_{a,b}\notin\mathcal S_{3+\varepsilon}$ 的反例，以确认阶数 3 的最优性？

### 批判性思考

- 定理的证明依赖 $g_{a,b}-bh_a$ 的符号控制，文中以图示说明一般会变号，那么"控制相消"的机制是否本质依赖于 $b$ 与 $1$ 的大小比较，值得细究。
- 广义 Stieltjes 函数的表示中常数 $c\ge0$ 与测度 $\nu$ 的显式性未给出，对想直接利用表示做数值计算的人而言不够直接。
