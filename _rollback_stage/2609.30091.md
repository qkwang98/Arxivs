# Reduced and coreduced modules with respect to inverse families of ideals

keywords: [$\Phi$-reduced 模, $\Phi$-coreduced 模, 理想的逆向族, 广义挠函子, 广义完备化函子, Greenlees–May 伴随, 挠理论]
related_paper: "Ssevviiri 关于 $I$-reduced 与 $I$-coreduced 模的工作（2024）"
one_liner_summary: "将单理想情形的 reduced 与 coreduced 模概念推广到理想的逆向族，证明在这类模上广义挠函子与广义完备化函子被族中最大真理想完全控制，并建立 Greenlees–May 型伴随、Matlis–Greenlees–May 型刻画以及 Serre 子范畴上的挠理论。"

## 1.  核心定位

- **解决的问题**：能否直接针对理想的逆向族 $\Phi$ 定义 reduced 与 coreduced 模，并刻画它们与广义挠、广义完备化及挠理论的相互作用。
- **大图景位置**：将 $I$-reduced 与 $I$-coreduced 模（针对单个理想的幂）推广到任意逆向理想族，与局部上同调中早已使用的逆向族与理想系统框架相统一，是模块论概念向族级情形的自然推进。
- **主要贡献**：①引入 $\Phi$-reduced 与 $\Phi$-coreduced 模并给出刻画；②证明在此类模上广义挠函子 $\Gamma_\Phi$ 与广义完备化函子 $\Lambda_\Phi$ 由最大真成员 $\mathcal{L}$ 决定；③建立 Greenlees–May 型伴随与 Matlis–Greenlees–May 型等价刻画；④对理想系统研究 $\Gamma_\Phi$ 的根性，并得到 Serre 子范畴上的挠理论。
- **关键先驱工作**：Lee 与 Zhou 引入的 reduced 模；Ssevviiri 的 $I$-reduced 与 $I$-coreduced 模；广义局部上同调中逆向族与理想系统的理论（Brodmann、Divaani-Aazar、Bijan-Zadeh 等）；Greenlees–May 对偶与 Matlis–Greenlees–May 等价；Jans 的 torsion–torsionfree 框架。
- **结果边界**：主要结论要求 $\Phi$ 关于包含关系存在最大真成员 $\mathcal{L}$；理想系统的额外乘法条件仅在第 5 节根性与挠理论部分需要；对无最大真成员的逆向族，本文的简化机制不直接适用。
- **开放问题**：作者未单独列出开放问题，但隐含地，无 Noether 与有限生成假设下更一般族的行为、以及理想系统之外 $\Gamma_\Phi$ 的根性问题留有探索空间。
- **应用与推广**：可用于在非 Noether 环与非有限生成模上替代经典理论中的有限性假设；结合 Hom–张量对偶与挠理论框架，可推广到表示论与范畴论中的 torsion pairs 与余挠对。
