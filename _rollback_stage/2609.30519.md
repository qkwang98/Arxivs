# Asymptotic multiplicity sequences of graded families

keywords: [渐近重数序列, 分次族, 整依赖, Rees 准则, 混合重数, 解析展形]
related_paper: "Achilles–Manaresi 重数序列（1997）"
one_liner_summary: "该文系统研究 Noetherian 局部环上任意理想分次族的渐近重数序列：刻画零分量收敛与首个非零分量的收敛性，证明 Noether 分次滤的全部分量存在且为有理数，并发展对角混合理论与公共解析模型收敛机制。"

## 1.  核心定位

- **解决的问题**：对任意理想（非 $\mathfrak m$-primary）的分次族 $\mathcal I=\{I_n\}_{n\ge 0}$，规范化极限 $c_i(\mathcal I;R)=\lim_{n\to\infty} c_i(I_n;R)/n^i$ 何时存在且有限？
- **大图景位置**：把 Cutkosky 关于 $\mathfrak m$-primary 分次族重数的极限定理与 Achilles–Manaresi 重数序列推广到任意理想，建立"渐近重数序列"这一精细不变量的一般理论。
- **主要贡献**：用加法半群条件刻画零分量收敛，并在等维链式假设下证明首个不被强制为零的分量 $c_h$ 必收敛；在 $k[[x,y]]$ 上构造固定根、高度与解析展形的整闭滤，使其规范化顶分量可实现任意给定的上下极限，表明高分量无一般收敛性；对 Noether 分次滤证明全部分量存在、有限且为有理数，给出标准 Veronese 指标与总量公式；建立族版本的 Rees 整依赖准则与赋值判据；在约化纯维复解析芽上，用单一公共主化改换给出不依赖有限生成的第二类收敛机制；发展对角混合理论：$\mathfrak m$-primary 族的对角渐近分量是相邻 Rees–Teissier 混合重数之和，公共解析模型上所有对角混合分量收敛。
- **关键先驱工作**：Achilles 与 Manaresi 的重数序列；Cutkosky 关于分次族重数与混合重数的极限定理；Polini、Trung、Ulrich 与 Validashti 用重数序列刻画整依赖；Callejas–Bedregal 与 Jorge Pérez 的混合重数序列系数。
- **结果边界**：一般（非 Noether）族的较高分量可任意发散；Noether 收敛性依赖滤的递减条件；混合固定因子估计在一般情形仍为公开问题。
- **开放问题**：混合固定因子估计的一般有效性；公共模型收敛机制的代数对应——excellent 局部域上尚缺的局部相交理论输入。
- **应用与推广**：重数序列与整依赖判定的结合可用于分次环与多次数理论；在奇点理论中与 Segre 数的渐近分析衔接，也可为 j-重数等其它渐近不变量提供统一视角。
