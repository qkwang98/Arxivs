# Quasi-equivalence of relabeled positroid cluster structures

keywords: [positroid 簇, cluster 结构, plabic 图, 可容许重标号, Frobenius 范畴化, tilting 模, 稳定范畴, Plücker 坐标]
related_paper: "Fraser–Sherman-Bennett 关于重标号 positroid cluster 结构的准等价猜想（本文证明）"
one_liner_summary: "本文对可容许重标号的 plabic 图产生的 positroid cluster 结构证明 Fraser–Sherman-Bennett 准等价猜想：从新边界项链构造 tilting 模得到 Frobenius 范畴化，把秩一模的局部化特征与 Plücker 坐标等同，借稳定范畴中可达 cluster-tilting 对象的唯一性证明坐标环上的恒等映射是 quasi-cluster 同构。"

## 1.  核心定位

- **解决的问题**：开 positroid 簇的坐标环 $R_\pi$ 上，由可容许重标号 plabic 图 $G^\rho$（即对边界标签施加置换 $\rho$）产生的 cluster 结构，与标准（source 或 target 标记）cluster 结构之间是否 quasi-equivalent，即经过 mutation 后对应可变变量只差冻结 Laurent 单项式、交换比一致。
- **大图景位置**：正 Grassmannian 簇的 cluster 结构由约化 plabic 图给出；Fraser–Sherman-Bennett 构造了可容许重标号产生的更多 cluster 结构（冻结生成元可以不同），并猜想它们全部 quasi-equivalent。Pressland 用 Frobenius 范畴化与 Fraser–Keller 的范畴比较证明了 source–target 情形，但一般重标号需要引入新的边界项链，不在其论证覆盖内；本文补上这一缺口。
- **主要贡献**：① 证明主定理（Theorem thm:introduction-fsb）：对 $\pi$ 可容许的 $\rho$，$R_\pi$ 上的恒等映射是从重标号图 $G^\rho$ 的 target 标记 cluster 结构到 Postnikov 图 $D$ 的 source 或 target 标记 cluster 结构的 quasi-cluster 同构，从而证明 FSB 猜想；② 从新的边界项链构造 $1$-tilting 模 $P_{\mathcal I}$，得到重标号 cluster 结构的 Frobenius 范畴化 $\mathcal E_{\mathcal I}=\mathrm{GP}\,B_{\mathcal I}$，其 cluster-tilting 对象 $T_{\mathcal I}$ 的射影-内射和项由边界项链指标化；③ 建立"局部化特征 = Plücker 坐标"（$\Phi_s(M_J)=\Delta_J$，推广到有界导出范畴），把可变面模 $qM_J$ 的稳定像与标准 source 模型中可达 cluster-tilting 对象的和项匹配，再经相对指标格与扩展交换矩阵的识别证明准等价；④ 对非连通 positroid，证明可容许性诱导各连通分支的可容许重标号，并经公共 Plücker 度的齐次粘合（homogeneous amalgamation）完成整体证明。
- **关键先驱工作**：Scott 等的 Grassmannian/positroid 簇 cluster 结构（约化 plabic 图种子）；Fraser–Sherman-Bennett 的可容许重标号构造与猜想；Pressland 定理（source–target 情形，Frobenius 范畴化 + Fraser–Keller 附录 A 的范畴比较）；MMMSV 定理（每个非零 Plücker 坐标是 cluster monomial）；Fu–Gyoda 的变量相容性判据；Klimyk 式秩一格理论中边界项链与 aligned-toggle 路径的机制。
- **结果边界**：工作于 $\mathbb C$ 上并反转所有冻结变量（localized 设置）；$\rho$ 必须对 $\pi$ 可容许（圆周弱序条件 $\pi\rho\leq_\circ\pi$ 与维数条件）；弱分离只在最终项链处需要，中间项链无需弱分离；source 比较之后 target 比较依赖 Pressland 定理，故结论仍是"准等价"（差冻结单项式）而非逐变量相等。
- **开放问题**：正文未单列开放问题。由方法自然延伸：不反转冻结变量的整（非局部化）版本的准等价；带环或非约化 plabic 图；重标号结构在更大对称群作用下的轨道分类；与 2-Calabi–Yau 范畴中其他 Frobenius 模型（非来自秩一格）的比较。
- **应用与推广**：为 Richardson 簇、unipotent cell、augmentation 簇等正典范簇的 cluster 结构比较提供可移植的 Frobenius 范畴化模板；"边界项链 tilting 模 + 特征识别 + 稳定范畴唯一性"三步法可推广到其他由组合数据（如格、项链）定义的 cluster 结构族。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：簇特征沿合冲搬运与 positroid 几何扭转 — 见 [[2609.10090]]
- [[2609.10090]]：该文研究簇特征函数在 2-Calabi–Yau 范畴中沿合冲/上合冲/悬挂的搬运并辨认 Grassmannian、positroid 几何扭转，其背景正是 Fraser–Keller 的 quasi-cluster automorphism 与 Pressland 关于可达刚性对象的结论；本文把 Pressland 论证推广到一般重标号，两文共享"可达性 + 稳定范畴唯一性"的核心机制。
- [[2609.19744]]：该文研究三次分次 Khovanov–Rozansky 同调与 augmentation/Richardson 簇的 Chow 群消没，其 strata（Richardson、positroid、辫）基本类生成 Chow 群；positroid strata 的 cluster 结构比较可为这类消没结果提供坐标层面的验证。
- 技术迁移："构造 tilting 模 + 相对指标格单模变换识别交换矩阵"能否用于比较两个来自不同组合数据（如双 plabic 图）的 cluster 结构，或推广到量子 cluster 结构？

### 2.2.  可以尝试的方向

- [ ] 能否去掉"反转冻结变量"的限制，在整坐标环上证明准等价（需处理冻结变量非单位时的 Laurent 单项式差异）？
- [ ] 结果能否推广到带环 plabic 图或非约化图，从而覆盖更一般的 positroid 与 Grassmannian 子簇？

### 2.3.  批判性思考

- 可容许性条件（圆周弱序 + 维数相等）是否也是准等价的必要条件，还是仅为本证明的技术要求？
- 证明依赖 MMMSV 的"Plücker 坐标为 cluster monomial"定理，若该定理在更一般的（非环面）设置失效，准等价是否仍成立？
- 反转冻结变量把准等价简化为普通同构的比较；未反转时"冻结 Laurent 单项式"的差异是否可能破坏目标标记情形的结论？
