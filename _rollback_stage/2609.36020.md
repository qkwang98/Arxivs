# Diagrammatic bases from stratified normalization

keywords: [图式重写, 分层表示, hom 基, q-Schur 范畴, 幺半范畴]
related_paper: "2609.25159"
one_liner_summary: 引入基于分层表示的分层重写方法，建立分层终止与汇合的模块化原理及归一化完成程序，证明分层 hom 基定理，并为 $q$-Schur 范畴构造新的 normal form 基。

## 1.  核心定位

- **解决的问题**：为图式范畴（diagrammatic categories）的态射空间构造显式线性基，同时克服重写理论中的两大困难——关键分支分析的组合复杂性与终止性所需良基度量的构造。
- **大图景位置**：属于表示论与高维代数中「由生成元与关系给出范畴表示 → 定向为重写规则 → 终止与汇合给出规范形与同态基」这一纲领的工具化推进；将 Gröbner-Shirshov 基方法的思想推广到线性幺半范畴与 2-范畴的图式重写设定，并首次系统处理带系数环（不取域扩张）的重写。
- **主要贡献**：① 引入分层终止函数（stratified termination functions），使终止性可按层逐步证明并可组合不同终止方法（基于推导的与基于单项式序的），得到分层终止定理；② 引入归一化完成程序，将新层与既有层之间的混合交互吸收进归一化重写规则，使汇合成为关于分层的模块化性质；③ 建立分层 hom 基定理：在左单项性与逐层汇合条件下，规范形集合构成同态基；④ 应用于 Brundan 的 $q$-Schur 范畴表示，构造出新的 normal form 基，并与 standard、canonical、codeterminant 基通过画图演算进行显式比较。
- **关键先驱工作**：Buchberger 与 Shirshov 的 Gröbner-Shirshov 基方法；Bergman 菱形引理及其在幺半范畴上的 Elias 版本；Dupont、Schelstraete 关于线性 2-范畴模掉同痕关系的重写与基定理；Guiraud-Hoffbeck-Malbos 的线性 polygraph 方法；Brundan 对 $q$-Schur 范畴的表示及其与 $q$-Schur 代数、$U_q(\mathfrak{gl}_n)$ web 范畴基的联系。
- **结果边界**：方法要求表示具有分层结构且每个归一化层为左单项且汇合；终止性依赖分层终止函数与兼容单项式序的存在；对系数环的整除性要求使可归约步骤的判断更精细，非域系数下局部与关键分支的结构发生变化。
- **开放问题**：完成程序何时终止缺乏一般判据（文中仅给出程序终止条件下的构造）；分层方法能否推广到非左单项的层或带更高维胞腔（如 3-范畴）的重写仍需探索。
- **应用与推广**：方法可直接用于构造 Soergel 双模、仿射与轮回 web 范畴、KLR 范畴等图式范畴的 hom 基；对 $q$-Schur 范畴的新基为量子群表示论提供显式计算工具；带环系数重写对定义在 $\Z$ 或其他交换环上的图式代数的计算具有实际价值。
