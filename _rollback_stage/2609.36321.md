# The $F$-signature function on the big cone

keywords: [F-特征标, 大锥, 整体F-正则性, Frobenius-alpha不变量, 双有理变换规则]
related_paper: "Lee-Pande, The F-signature function on the ample cone"
one_liner_summary: 本文将F-特征标函数从ample锥连续延拓到normal projective簇的大锥，并证明其正性等价于整体F-正则性。

## 核心定位

- **解决的问题**：如何把F-特征标函数从ample锥延拓到normal projective簇的大锥，并研究其正性、连续性以及与volume函数的比较。
- **大图景位置**：这是作者前作（ample锥上的F-特征标函数）的直接推广；F-特征标是正特征奇点的数值度量，本文将其定义域扩展到big divisor，填补了big divisor情形下F-特征标理论的研究空白。
- **主要贡献**：①定义big Cartier divisor的F-特征标，证明极限存在且满足标度性质 $s_X(L^n)=\frac{1}{n}s_X(L)$；②证明F-特征标函数在大锥上良定义且局部Lipschitz连续；③证明big divisor的F-特征标正性等价于整体F-正则性；④建立双有理变换规则；⑤在mod $p$约化中证明特征无关下界的spreading-out原理。
- **关键先驱工作**：Smith-van den Bergh与Huneke-Leuschke对F-特征标的正式化、Tucker证明极限存在、Aberbach-Leuschke以F-特征标正性刻画强F-正则环、Schwede-Smith关于整体F-正则性与log Fano的关系、Pande的Frobenius版本Tian alpha不变量。
- **结果边界**：限于正特征代数闭域上的normal projective簇；big divisor的section ring可能非有限生成，故不能直接沿用ample情形的局部化论证；当section ring非有限生成时，定义依赖逐层Frobenius splitting的度量而非整体section ring。
- **开放问题**：big divisor的section ring $S(X,L)$在整体F-正则簇上是否有限生成（文中引用Datta-Schwede-Tucker的预期结果）；F-特征标在reduction mod $p$下的一般计算仍困难。
- **应用与推广**：可用于正特征奇点理论中估计局部基本群大小、divisor class群阶数与局部体积；变换规则可推广到pairs $(X,\Delta)$与triples $(X,\Delta,\fad)$。

### 批判性思考

- 定义中逐层和 $\sum_{m=0}^\infty$ 的收敛性与换序需细致验证，文中极限存在性证明是关键技术点，值得检查是否依赖有限生成之外的隐藏假设。
- 作者以Frobenius-alpha不变量作桥梁，其单调性在大锥上是否完全平行于ample锥情形，需对比两者边界行为。
