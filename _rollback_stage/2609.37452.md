# A Note on Universal Positivity of Rank-Two Quantum Greedy Elements

keywords: [量子簇代数, 量子贪婪基, 普遍正性, Laurent 展开, Schur 正性, theta 基]
related_paper: "Canonical bases for cluster algebras (Gross--Hacking--Keel--Kontsevich)"
one_liner_summary: 本文在整除情形 b|c 或 c|b 下证明二阶量子簇代数中量子贪婪基元素的普遍正性，从而验证了 Lee--Li--Rupel--Zelevinsky 猜想 1.10。

## 核心定位

- **解决的问题**：证明二阶（秩二）量子簇代数中量子贪婪元素在每一个簇的 Laurent 展开中均具有非负系数，即普遍正性。
- **大图景位置**：这是 LLRZ 提出的猜想 1.10 在整除性条件 b∣c 或 c∣b 下的肯定解答；普遍正性是量子簇代数与 theta 基理论的核心问题之一，直接关系到量子化正性理论是否由贪婪基承载。
- **主要贡献**：①在 b∣c 或 c∣b 时证明所有量子贪婪元素 $G_{bc}(A,N)$ 在归一化单项式 $v^{rs}X_m^rX_{m+1}^s$ 下的系数均属于 $\pos$；②结合 LLRZ 定理 1.9(d) 的不可分解性，证明此类元素不可分解为两个非零普遍正元素的之和；③给出基于 Schur 正性、积分星-箭图模型与形式散射构造的证明框架。
- **关键先驱工作**：Lee--Li--Rupel--Zelevinsky 对量子贪婪基的存在性、有限支撑与唯一性（定理 1.7）及不可分解性（定理 1.9(d)）；经典 theta 基与经典贪婪基的一致性（CGMMRSW）；Gross--Hacking--Keel--Kontsevich 的 theta 基理论；DM 的形式散射构造。
- **结果边界**：证明依赖整除性假设 c=kb（或对称情形 b=kc）；对一般非整除的 $(b,c)$ 对，普遍正性仍为开放问题。正性的定义是系数逐项非负（允许零），$v=1$ 的特殊化可能掩盖负系数，故不能由经典正性直接推出量子正性。
- **开放问题**：LLRZ 猜想 1.10 的一般情形，即对任意正整数 $b,c$ 是否普遍正性仍成立；以及在非整除情形下是否仍存在类似的 Schur 正性分解。
- **应用与推广**：为量子簇代数提供了一类显式的正基元素，可用于 theta 基的量子化构造；源色 Schur 正性技巧可迁移到其他具有量子 dilogarithm 交换结构的模型，例如带分数箭图的簇代数与量子化丛上。
