# Six functor formalisms via internal higher algebra

keywords: [六函子形式, 内部高阶代数, ∞-topos, 惰性对称幺半函子, span 范畴]
related_paper: "Cnossen–Lenz–Linskens 关于六函子形式万有性质的论文（CLLuniv）"
one_liner_summary: 该文将六函子形式 $D\colon\Span(C,E)\to\Cat$ 提升为惰性对称幺半的 $(\infty,2)$-函子 $\Span^2(C,E)^P_I\to\Cat_2$（$P$、$I$ 分别为 $D$-proper 与 $D$-étale 态射类），由此证明 Mann 猜想并推广 Cnossen–Lenz–Linskens 定理；为此发展了 topos 中由局部态射类 $\mathcal{U}$ 定义的内部 $\mathcal{U}$-幺半范畴与 $\mathcal{U}$-operad 理论。

## 1.  核心定位

- **解决的问题**：在缺乏"合适分解" $E=P\circ I$ 的情况下，六函子形式能否仍延拓为携带 2-态射（编码伴随的 counit/unit）的 $(\infty,2)$-范畴值惰性对称幺半函子；即证明 Mann 提出的猜想。
- **大图景位置**：它是 Mann 猜想的完整证明，同时将 Cnossen–Lenz–Linskens 在"合适分解"假设下建立的万有性质推广到一般情形；也是将六函子形式理论完全纳入内部（$\infty$-topos 内）高阶代数框架的关键一步。
- **主要贡献**：① 证明 $\Span(C,E)\to\Span^2(C,E)^P_I$ 是自由 $I$-左伴随、$P$-右伴随函子（及惰性对称幺半版本），进而推出 Mann 猜想；② 发展内部 $\mathcal{U}$-幺半范畴与 $\mathcal{U}$-operad 理论，推广 Martini–Wolf 的内部对称幺半范畴与 operad；③ 建立 2-函子形式范畴与 $\mathcal{U}$-幺半 $\vartopos[C]$-范畴之间的对称幺半等价，并给出 3-函子形式的完全内部定义。
- **关键先驱工作**：Grothendieck 的 étale 上同调六函子；Liu–Zheng 与 Gaitsgory–Rozenblyum 的 span/对应方法；Mann 关于六函子形式与 3-函子形式的构造；Cnossen–Lenz–Linskens（CLLuniv）的万有性质定理；Martini–Wolf 的内部范畴理论；Lurie 的高阶代数；Harpaz 的 ∞-半可加性及 CLLambi 的内部推广。
- **结果边界**：定理要求 $P$、$I$ 为在 $C$ 中基变换下稳定的宽子范畴、左可消且态射截断（truncated）；自由性在固定截断度的假设下先证明，再经适当余极限取一般情形；若 $D$ 本身并非由合适分解构造（如凝聚 anima 上的 sheafification 形式），则只能走本文的路线而非 CLLuniv 的直接特例。
- **开放问题**：作者正在推进将惰性对称幺半自由伴随定理应用于导出模 $p$ Hecke 代数 $\mathcal{H}$，构造提升长度滤过的相容滤过；第三作者正在用内部高阶代数把 Bachmann–Hoyois 的范数结构提升到 motivic 谱范畴 $\mathrm{MS}$ 上。
- **应用与推广**：为任意 3-函子形式自动提供 2-函子结构与伴随数据的一致性；内部 $\mathcal{U}$-幺半范畴框架可承载范数结构（normed structures）；借助与 Day convolution 的对称幺半等价，可用范畴代数（CAlg、幂等代数、模）重新理解 3-函子形式，其中 $\Span^2$ 对应幂等代数且其模恰为相应笛卡尔/余笛卡尔型幺半范畴。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：Mann 的六函子形式机制与 Cnossen–Lenz–Linskens 的万有性质定理 — 见 [[arxiv_read/2609.26497]]
- [[arxiv_read/2609.26497]]：该文讨论可对偶范畴的色纯性，与六函子形式中 $g^!$、$f_*$ 等对偶性操作共享对偶化结构的关注。
- [[2609.28304]]：辫子 duoidal 范畴与 bi(co)module 的 pre-Cartier 结构，涉及内部幺半结构与分配律，与本文的 $\mathcal{U}$-幺半/$\mathcal{U}$-笛卡尔组合结构同属高阶代数谱系。
- [[2609.28435]]：形式弱充实范畴理论为内部范畴与充实结构提供形式化基础，与本文 $\infty$-topos 内部范畴论的技术环境相关。
- [[2609.30435]]：Fourier–Mukai 配与向量丛模空间的自动等价，是六函子形式（导出范畴、$f_*$、$f^!$）在代数几何中的典型应用背景。
- 技术迁移：本文"自由 $I$-左伴随与 $P$-右伴随"的万有性质证明策略（识别原则 + 内部高阶代数编码）或可迁移到其它携带受限极限/余极限且要求交换性的结构，如半可加范畴与 ambidexterity 型框架。

### 2.2.  可以尝试的方向

- [ ] 将自由伴随万有性质推广到 $P$、$I$ 非截断或非左可消的情形，考察需要何种额外条件。
- [ ] 用内部 $\mathcal{U}$-operad 与 $\mathcal{U}$-幺半范畴的伴随（enveloping adjunction）系统化构造六函子形式中的乘性结构（投影公式、基变换）。
- [ ] 将幂等代数刻画应用到具体六函子形式（凝聚 anima 上的 sheafification 形式），检验是否导出模 $p$ Hecke 代数滤过的新性质。

### 2.3.  批判性思考

- 是否有比"先固定截断度、再取余极限"更直接的统一证明？截断条件是否本质上不可避免？
- 作者的论证将 2-函子形式等价于 $\mathcal{U}$-幺半 $\vartopos[C]$-范畴，该等价对 $E$ 的基变换稳定性与局部性假设的依赖是否被充分检验？
- 幂等代数 $\Span^2$ 的模刻画给出了"$\mathcal{U}[P]$-笛卡尔且 $\mathcal{U}[I]$-余笛卡尔 $\mathcal{U}$-幺半范畴"的描述，但这类模结构在具体六函子形式中的几何意义是否仍有待阐明。
