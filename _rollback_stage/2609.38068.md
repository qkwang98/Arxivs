# Deep Points of Cluster Algebras II: Punctured Marked Surfaces

keywords: [cluster 代数, 深点, 刺穿曲面, 标记曲面, 簇簇簇变体]
related_paper: "2609.30637"
one_liner_summary: 分类了带边界刺穿标记曲面对应的 cluster 代数的 cluster 簇的深点（deep locus），给出奇偶边界标记点下深点的精确结构。

## 核心定位

- **解决的问题**：对带边界的刺穿标记曲面（punctured marked surfaces with boundary）所对应的 cluster 代数，完整分类其 cluster 簇 $V(\CA,\Bbbk)$ 中的深点（deep locus）。
- **大图景位置**：延续与 Greg Muller 合作的《BM25》工作（此前已分类 $A_n$ 型、秩 2、Markov 簇以及无刺穿可三角剖分带边界曲面），本工作是深点分类向刺穿曲面情形的推进；同时呼应 Castronovo-Gorsky-Simental-Speyer 对多种 cluster 代数深点丛的平行研究。
- **主要贡献**：① 对单刺圆盘（$n \geq 4$ 个边界标记点）给出完整分类：$n$ 为奇数时深点丛为单一 $2n-3$ 维分支，$n$ 为偶数时为一个 $2n-3$ 维分支加上四个同构于 $(\Bbbk^\times)^n$ 的不相交子集，五个集合的闭包交为 $(n-1)$ 维子簇；② 推广到一般连通曲面（亏格 $g$、$b$ 个边界分量、$m \geq 2$ 个边界标记点、$q \geq 1$ 个刺穿）：$m$ 为奇数时深点丛是 $q$ 个非不相交集合（各同构 $V(\CA(\SS_{q-1}),\Bbbk)$）的并；$m$ 为偶数时额外加上 $2^{2g+b+2q+1}$ 个不相交的 $(\Bbbk^\times)^{2g+b+q+m-2}$ 集合。
- **关键先驱工作**：BM25 中提出的「任何 cluster 代数的坏性质都可归咎于其深点」准则及其奇异点必为深点等命题；Muller、Matherne-Muller、Neville-Simental、Tyler 关于深点丛性质的工作；Muller 关于曲面 cluster 代数的相关结果。
- **结果边界**：分类限定在带边界且至少含一个边界标记点的刺穿曲面（$b \geq 1$、$m \geq 1$ 或 $m \geq 2$）；无边界标记点、闭曲面或更多刺穿结构的情形需另行处理；结果依赖于 cluster 代数的曲面型实现与 $\Bbbk$ 为域（或适当环）的假设。
- **开放问题**：将深点分类推广到更一般的曲面配置（如边界无标记点或刺穿与边界相互作用更复杂的情形），以及进一步厘清深点丛与其他「坏性质」（奇异性、非有限性等）之间的确切对应关系。
- **应用与推广**：深点丛的定位可用于预先识别 cluster 代数中可能出现奇异或病态行为的点，对 cluster 代数在表示论、数学物理（如 Teichmüller 理论、量子群范畴化）中的应用中的计算与分析具有参考价值。
