# Vector balancing in convex order

keywords: [向量平衡, 凸序, Komlós 猜想, Schatten 范数, Talagrand 凸性, 鞅传输]
related_paper: "Banaszczyk 的高斯测度定理（Komlós 型向量平衡经典工具）"
one_liner_summary: 构造带精确均值与独立高斯参考的向量平衡符号律，以凸序同时控制硬不一致性、Schatten 范数与高斯几何，解决 Reis--Rothvoss、Reis、Nutz--Wang--Zhang 与高维 Bass-flow 等一批猜想。

## 核心定位

- **解决的问题**：如何构造 $\{-1,1\}^n$ 上的符号分布，使每个输出同时满足硬不一致性界、精确条件均值，并在凸序意义下被一个独立高斯参考控制。
- **大图景位置**：将 Komlós 猜想、Beck--Fiala 界等经典向量平衡结果从"单个符号向量"提升为"整个符号律"，并统一推广到矩阵 Schatten 范数、迹类体积比、鞅传输与统计隐私等看似无关的领域。
- **主要贡献**：①构造 Komlós 型符号律，硬不一致性低于 $6.84$，熵下界 $n\log(1.22946)$，且联合凸序被 $N(0,6.5I_m)$ 与 $N(0,3.23I_n)$ 的独立高斯参考控制；②解决 Reis--Rothvoss 的两个 Schatten 猜想与 Reis 的迹类体积比猜想；③解决 Nutz--Wang--Zhang 方向/supermartingale 猜想与高维 Bass-flow 猜想；④给出 Talagrand 凸性问题的最优三项与五项分解结论。
- **关键先驱工作**：Banaszczyk 的高斯测度定理、Guo--Fang--Lu 的 Komlós 常数构造、Akbas--Sra 的 reciprocal/Fisher 与小球估计、Strassen 的凸序鞅表示、Hua--Song--Tudose 的高斯表示与 Talagrand 存在性定理。
- **结果边界**：凸序允许右侧无穷期望；Gaussian endpoint 处 $\varepsilon\downarrow0$ 的权衡与熵亏损以 $\Theta(\varepsilon^{-1/2})$、$\sqrt{\pi/3}\sqrt\varepsilon$ 刻画，且端点律退化为独立均匀符号律；隐私分类仅在条件原子性缺失时等价于独立性。
- **开放问题**：Talagrand 关于两求和项阻挠的最优性已由作者证明，但 Johnston 的 dilation-free Question 1.2 仍保持独立范围；任意正输入质量 $\alpha>1/2$ 的显式求和项计数由 Corollary 给出，更一般的紧输入端点有待细化。
- **应用与推广**：联合参考律可服务于采样（一个律控制所有被积函数）、整数舍入（最优协方差因子 $\pi/8$）、谱稀疏化（无偏稀疏律）、精确隐私释放（Blackwell-greatest 机制分类），并可迁移到随机矩阵与统计决策问题。
