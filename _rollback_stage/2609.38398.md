# Grassmannian tree webs and cluster variables

keywords: [cluster 代数, Grassmannian, web 不变量, tensor diagram, arborizable, cluster quasihomomorphism]
related_paper: "Cluster algebras, quiver representations and triangulated categories (Fomin--Zelevinsky)"
one_liner_summary: 对 Gr(3,n) 平面树 web 的 Fomin--Pylyavskyy 定理给出新证明，并推广到 Gr(4,n)：若 SL4 张量图是平面树 web，则其 web 不变量是 cluster 或 frozen 变量，证明依赖 cluster 拟同态（upper promotion、spurion promotion）与新引入的 6-leg pattern 映射。

## 核心定位

- **解决的问题**：Grassmannian 齐次坐标环作为 cluster 代数的基本实例，其 cluster 变量在有限型情形之外缺少显式刻画；本文要为 Gr(3,n) 与 Gr(4,n) 的平面树 web 不变量给出"属于 cluster/frozen 变量"的构造性证明。
- **大图景位置**：这是 Fomin--Pylyavskyy 猜想（Gr(3,n) 的 cluster/frozen 变量恰为 indecomposable、non-elliptic 且 arborizable 的 web 不变量）在树形情形下的直接推进：对 Gr(3,n) 给出新证明（对应原推论 8.10），并首次推广到 Gr(4,n)。
- **主要贡献**：①对 Gr(3,n) 平面树 web 的已知结论给出新证明；②将结果推广到 Gr(4,n)：SL4 张量图若是平面树 web，其不变量是 cluster 或 frozen 变量；③引入新的 6-leg pattern 映射作为证明工具，与既有 cluster 拟同态（upper promotion、spurion promotion）配合使用。
- **关键先驱工作**：Fomin--Zelevinsky 的 cluster 代数；Scott 对 Grassmannian 有限型 cluster 结构的工作；Kuperberg 的 SL3 张量不变量与 web 理论；Fomin--Pylyavskyy 的猜想与树 web 定理；Fraser 对有限突变类型（Gr(3,9)、Gr(4,8)）的验证；Even-Zohar--Lakrec--Parisi--Sherman-Bennett--Tessler--Williams 的 amplituhedron 工作中引入的 promotion 拟同态与 plabic tangle 框架。
- **结果边界**：结果限于平面树 web（planar tree webs）；带环或非平面的一般 tensor diagram 不在覆盖范围内；方法虽自述可推广到更一般情形，但具体表述以 Gr(3,n) 与 Gr(4,n) 为准，推广细节留给后续工作。
- **开放问题**：作者指出方法可应用于 Gr(3,n)、Gr(4,n) 树 web 之外更广的场景，具体推广将在后续工作中探索。
- **应用与推广**：为 Grassmannian cluster 代数的 cluster 变量分类提供组合判据，可服务于 Plücker 坐标与 web 不变量计数、正 Grassmannian 与 amplituhedron 的边界结构分析，以及 cluster 代数与表示论范畴化的交叉研究。
