# Relative Derived Delooping Levels and $\tau$-Tilting Modules

keywords: [derived delooping level, τ-tilting 模, finitistic dimension, exact 范畴, 1-tilting 模, 相对同调]
related_paper: "2609.36444"
one_liner_summary: "本文在本质小幂等完备且有足够投射对象的 exact 范畴上发展 derived delooping level，并构造支撑 τ-tilting 模的相对版本，用它给出端代数对偶大有限维数的上界及 τ-tilting 模成为经典 1-tilting 模的判据。"

## 核心定位

- **解决的问题**：把 Guo–Igusa 的 derived delooping level 理论相对化到支撑 $\tau$-tilting 模 $T$ 生成的范畴 $\mathcal C=\operatorname{Fac}T$，用其控制端代数 $B=\operatorname{End}_A(T)$ 的对偶大有限维数，并回答"相对普通 delooping 能否被相对 derived delooping 取代"的问题。
- **大图景位置**：finitistic dimension 猜想是 Artin 代数表示论的核心开放问题，delooping level 族（Gélinas 的普通版本、Guo–Igusa 的 derived 版本）是其重要上界工具；本文将其推广到由 tilting 型模生成的恰当范畴，并与 Brenner–Butler 等价、支撑 $\tau$-tilting 理论及经典 tilting 理论衔接。
- **主要贡献**：① 在 exact 范畴上发展 derived delooping level，证明同伦不等式 $k\text{-}\operatorname{ddell}_{\mathcal E}Y \leq k\text{-}\operatorname{ddell}_{\mathcal E}X + k\text{-}\operatorname{ddell}_{\mathcal E}Z +1$、inflation 不等式及有限投射幅度的 exact 函子转移定理；② 定义相对 derived delooping level $k\text{-}\operatorname{ddell}_{T}\mathcal C$（由 $\mathcal C$ 的典范 semibrick 与 Brenner–Butler 等价下的边界对象构造），证明定理 A 的不等式链 $\operatorname{depth}_{T}\mathcal C \leq \operatorname{findim}B^{\mathrm{op}} \leq \operatorname{Findim}B^{\mathrm{op}} \leq \operatorname{ddell}B \leq \operatorname{ddell}_{T}\mathcal C \leq \operatorname{dell}_{T}\mathcal C$；③ 用 $\overline A=A/\operatorname{ann}_{A}T$ 的单对象控制：$\operatorname{ddell}_{\mathcal C}(D\overline A) \leq \operatorname{gddell}(\mathcal C) \leq \operatorname{ddell}_{\mathcal C}(D\overline A)+1$；④ 定理 B：若 $d=2\text{-}\operatorname{ddell}_{B}(DT)<\infty$ 且 $\operatorname{Ext}_{A}^{j}(T,T)=0$（$2\leq j\leq d+3$），则 $T$ 是 $1$-tilting 模，特别地自正交 $\tau$-tilting 模在 $2\text{-}\operatorname{ddell}_B(DT)$ 有限时即为 $1$-tilting。
- **关键先驱工作**：finitistic dimension 猜想；Gélinas 的 delooping level（Adv. Math. 2022）；Guo–Igusa 的 derived/effective delooping levels；Xu–Zhang 关于 $\operatorname{Fac}T$ 相对同调不变量与 $\operatorname{findim}B^{\mathrm{op}}$ 上界的工作；AIR 的支撑 $\tau$-tilting 理论；Brenner–Butler 等价；半砖（semibrick）理论。
- **结果边界**：框架要求 exact 范畴本质小、幂等完备且有足够投射对象；相对 derived delooping level 可为 $\infty$；定理 B 的指标范围依赖 $2\text{-}\operatorname{ddell}_B(DT)$ 有限这一关键假设。
- **开放问题**：引言未明确列出开放问题；相对 derived 与普通相对 delooping 之间的指标平移现象及一般代数上的紧性值得进一步探索。
- **应用与推广**：为相对 finitistic dimension 提供新的上界工具；与精确范畴上的相对同调结合可用于研究 Artin 代数的整体同调行为，并为判定 $\tau$-tilting 模何时为经典 tilting 模给出可检验判据。
