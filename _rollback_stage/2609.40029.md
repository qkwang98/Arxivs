# K-theoretic invariants of four three-dimensional operator systems

keywords: [算子系统, K-理论, C*-包络, 三维算子系统, 不变量]
related_paper: "2609.40028"
one_liner_summary: "本文以四个三维算子系统为例，展示新提出的算子系统 K-理论的计算：某些情形下算子系统的不变量多于其 C*-包络，某些情形相反，某些情形二者重合，并探讨一般理论的细化与扩展。"

## 1.  核心定位

- **解决的问题**：为刚建立的算子系统 K-理论提供具体低维算例，说明该理论在哪些情况下能区分算子系统与其 C*-包络。
- **大图景位置**：这是算子系统 K-理论（从 $C^*$-代数扩展而来）的"样例集"论文；完整详细的大规模计算（Toeplitz、Fejér--Riesz 与图算子系统）见姊妹篇 2609.40028。
- **主要贡献**：1) 对四个三维算子系统显式计算 K-理论不变量；2) 展示三种关系类型：算子系统的不变量多于其 C*-包络、少于其 C*-包络、以及二者重合；3) 探讨一般理论的细化（refinements）与扩展方向。
- **关键先驱工作**：作者此前建立的算子系统 K-理论（基于 hermitian 形式、受 Witt 群启发）；对 Toeplitz / Fejér--Riesz / 图算子系统的完整详细计算（2609.40028）。
- **结果边界**：仅限于四个三维例子，目的是简洁说明现象的广度与多样性而非穷举；不变量计算仍依赖有限维算子系统下路径连通分量分析。
- **开放问题**：core 文本未明确列出；四例中"不变量与 C*-包络不同"的机制如何一般化、以及理论细化在更高维算例上的表现是自然的后续问题。
- **应用与推广**：为算子系统 K-理论提供教学式的最小算例集；"不变量何时区分算子系统与其 C*-包络"的分类可指导非交换几何中具体截断系统的选择与研究。

- [[2609.40028]]：姊妹篇对 Toeplitz、Fejér--Riesz 与所有图算子系统给出完整详细计算，本文是其低维样例的浓缩版。

- 技术迁移：三维算例中"不变量与 C*-包络谁多谁少"的比较方法，可作为检测一般算子系统是否被其 C*-包络"捕获"的快速判据。

### 2.3.  批判性思考

- 论文定位为说明一般理论，例证的价值取决于四例是否覆盖了现象的全部典型类型；应核对是否还存在第五种关系类型未被提及。
- 作者披露推导过程使用了 LLM 辅助，对四个例子的不变量结论应逐例核验论证的严格性。
