# A characterization of triangulated structures induced by premutation triples

keywords: [extriangulated category, premutation triple, pretriangulated category, triangulated quotient, mutation, cotorsion pair]
related_paper: "Iitsuka 的 premutation triples 系列（含规范 pretriangulated 结构与 (MT4) 条件）"
one_liner_summary: "证明 Iitsuka 兼容条件 (MT4) 是 extriangulated 范畴中 premutation triple 的规范 pretriangulated 商结构成为三角范畴的充要条件，并给出 concentric twin cotorsion pairs 情形下与 Nakaoka 三角商条件的等价性，以及 reducible triple 非 mutation triple 的显式反例。"

## 核心定位

- **解决的问题**：给定 extriangulated 范畴中的 premutation triple $(\mathcal{S},\mathcal{Z},\mathcal{V})$，Iitsuka 构造的商范畴 $\mathcal{Z}/[\mathcal{I}]$（$\mathcal{I}=\mathcal{S}\cap\mathcal{Z}=\mathcal{Z}\cap\mathcal{V}$）带有规范 pretriangulated 结构。何时该结构真正成为三角范畴？本文证明兼容条件 $(\mathrm{MT4})$（等价于 $(\mathrm{MT4})'$）不仅是充分条件，也是必要条件，从而精确刻画三角化的判据。
- **大图景位置**：mutation 是表示论中构造新对象与商范畴的基本方法——Iyama–Yoshino 对 rigid 子范畴的 mutation（含 cluster tilting mutation）、Coelho Simões–Pauksztello 对正交集的 mutation、Zhou–Zhu 与 Zheng–Cao–Wei 由函子有限子范畴得到的商构造；Nakaoka–Palu 的 extriangulated 范畴统一 exact 与 triangulated 两大框架；Iitsuka 的 premutation triple 进一步统一 Frobenius extriangulated 范畴、rigid mutation pairs、orthogonal mutation pairs 与 concentric twin cotorsion pairs 的构造。本文补上 Iitsuka 商构造三角化的逆向方向，属这一统一纲领的收敛性结果。
- **主要贡献**：
  1. 主定理：对 extriangulated 范畴 $(\mathcal{C},\mathbb{E},\mathfrak{s})$ 中的 premutation triple，规范 pretriangulated 范畴 $(\mathcal{Z}/[\mathcal{I}],\Sigma,\Omega,\nabla,\Delta)$ 是三角范畴，当且仅当该 triple 满足 $(\mathrm{MT4})'$，当且仅当满足 $(\mathrm{MT4})$；等价形式为 $\underline{\mathcal{Z}}\langle1\rangle^{-}=\underline{\mathcal{Z}}\langle-1\rangle^{+}$。
  2. 对 concentric twin cotorsion pairs $((\mathcal{S},\mathcal{T}),(\mathcal{U},\mathcal{V}))$，Nakaoka 构造三角商所用的兼容条件等价于 $(\mathrm{MT4})$，故两组商包含关系、$(\mathrm{MT4}^{-})$ 与 $(\mathrm{MT4})$ 全部等价。
  3. 构造显式 reducible triple 而非 mutation triple 的例子（$A_4$ 型路代数的模范畴及一个有限维 bound quiver 代数），否定 Iitsuka 关于"每个 reducible triple 是否都是 mutation triple"的提问。
- **关键先驱工作**：Iitsuka 引入 premutation triple、mutation 函子 $\Sigma,\Omega$ 与规范 pretriangulated 结构（Theorem 3.37），以及兼容条件 $(\mathrm{MT4})'$（Condition 4.6）与 $(\mathrm{MT4})$（Remark 4.9(1)）的充分性（Theorem 4.8）；Nakaoka–Palu 的 extriangulated 范畴；Nakaoka 的 cotorsion pair 三角商构造；Iyama–Yoshino、Zhou–Zhu、Zheng–Cao–Wei 的 mutation 与商构造。
- **结果边界**：主定理的等价条件由环境 extriangulated 范畴中的相对扩张定义，商范畴的三角性必须在这种相对结构下理解；前提是 $\Sigma$ 为 $\Omega$ 的左伴随（Iitsuka 引理 3.16 与记号 3.17），且 $\Sigma$ 的等价性由三角性推出。非 premutation 的一般 triple 情形不在结论范围内。
- **开放问题**：reducible triple 与 mutation triple 的精确关系已由反例否定"充分性"，但 reducible triple 结构的整体分类与规范商的更精细性质仍开放；$(\mathrm{MT4})$ 之外是否存在更弱的三角化判据值得追问。
- **应用与推广**：为判定各种 mutation 构造（rigid mutation、orthogonal mutation、cotorsion pair 商）得到的商范畴何时三角化提供统一判据；concentric twin cotorsion pairs 的等价性说明三角商构造在多种框架下是同一机制。
