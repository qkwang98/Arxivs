# Riemannian Structures on Quotients in Elastic Diffeology via Q-Charts

keywords: [弹性 diffeology, Q-charts, Riemannian 度量, Levi-Civita 联络, 测地流, 无理环面, 切线范畴]
related_paper: "Riemannian geometry on elastic spaces（Y. Shiobara 前期工作，基于 Blohmann 切线函子）"
one_liner_summary: "证明弹性 diffeology 中的 Riemannian 装置（垂直/水平/全联络、Riemannian 度量、Levi-Civita 联络与测地线）沿 Miyamoto 的 Q-charts 双射下降，并据此完整确定无理环面的 Riemannian 几何。"

## 核心定位

- **解决的问题**：给定弹性 diffeological 空间之间的 Q-chart 商映射 $\phi\colon X\to Y$，$X$ 上的哪些 Riemannian 结构可以（唯一地）下降到 $Y$，以及该下降是否保持无挠、有效、平坦、全联络、Levi-Civita 性质与测地线方程。
- **大图景位置**：diffeology 中商空间是基本例子类，但商对 Blohmann 切线函子十分敏感（orbifold $\R/\{\pm1\}$ 甚至不弹性，见 Miyamoto [Ex. 3.11]）。本文把作者前期在弹性空间上建立的 Riemannian 几何（[Shio]）沿 Miyamoto 隔离出的 Q-chart 类整体下降到商，是无理环面这类拓扑高度退化（D-拓扑不可分、仅有常值光滑函数）却仍携带完备 Riemannian 几何的极端例子的正面回答。
- **主要贡献**：
  1. 主定理 A（Theorem 1.1）：沿 Q-chart $\phi$，$\Psi(\phi)$-不变的结构与 $Y$ 上结构一一对应；无挠/有效/平坦、全联络、Levi-Civita 性质与测地线方程双向保持，且每个 $T_x\phi$ 为线性等距。
  2. 主定理 B（Theorem 1.2）：对 diffeologically 离散群的主作用商，测地线全局提升、$\Elastc$（$\R$ 为曲线对象）闭性、完备测地流下降均成立。
  3. 主定理 C（Theorem 1.3）：无理环面 $\Tor_\alpha$ 的度量恰为 $\rho\vartheta^2$（$\rho>0$ 常数）；垂直联络构成一族平坦有效联络，其中唯一成员是所有度量的 Levi-Civita 联络 $K_0$；其测地流完备，但诱导伪距离恒为零。
- **关键先驱工作**：Souriau 的 diffeology 与 Iglesias-Zemmour 的系统发展；Blohmann 的弹性 diffeological 空间与其切线函子（左 Kan 扩张）；Cockett–Cruttwell 的切线范畴公理；Miyamoto 对 Q-charts 的隔离与 elasticity 下降定理；Iglesias-Zemmour 与 Blohmann 意义下的 Riemannian 度量。
- **结果边界**：下降要求 $\phi$ 是 Q-chart（沿之 elasticity 下降的特殊 subduction 类）；非 Q-chart 商（如 $\R/\{\pm1\}$）不在范围内。主定理 A 不提供曲线全局提升，需主作用（division map 光滑）的额外条件。伪距离退化与 [KSS] 距离定理的分离假设在此失效，故不矛盾。
- **开放问题**：作者未显式列出 open problems；从文中可推断：更一般（非主作用）商的测地线全局提升、伪距离退化的更精细刻画、以及 $\Tor_\alpha$ 之外其他退化商空间上的显式几何是自然方向。
- **应用与推广**：为弹性 diffeology 中一类广泛的商空间（可数群自由作用商、diffeological 群对离散子群商）提供整套 Riemannian 装置；无理环面的显式计算说明拓扑平凡性不阻碍 Riemannian 结构存在；迭代切丛 $T^nX$ 与纤维积 $T_kX$ 沿 $\phi$ 的拉回方（Proposition 4.1）是可在其它公理化几何中复用的形式工具。

### 可以尝试的方向

- [ ] 对非主作用的 Q-chart（如带固定点的群作用）能否获得测地线的局部提升或伪距离的局部非退化性？
- [ ] 主定理 C 的完整结论能否推广到一般的 $G/N$ 型商（$N$ 为 diffeologically 离散正规子群）并给出显式联络族？

### 批判性思考

- 主定理 A 的证明把下降归结为切线范畴结构映射的自然性，本质上是形式论证；其"检测相等只需在 $X$ 上应用 $F\phi$"的策略依赖拉回方块为同胚（Proposition 4.1），该命题在非 Q-chart 上失败——是否有更弱条件（如局部拉回）仍足以承载下降？
- 无理环面的伪距离恒为零却仍存在实现不了下确界的正长度路径，这一现象说明 [KSS] 距离定理的分离假设是不可省的本质条件；作者未讨论伪距离退化与测地完备性并存的更一般刻画，值得追问。
