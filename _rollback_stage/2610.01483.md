# Relative quasi-Gorenstein homological dimensions in extriangulated categories

keywords: [extriangulated 范畴, proper class, 拟 $\xi$-Gorenstein 投射对象, 拟 $\xi$-Gorenstein 内射对象, 相对同调维数, 迹理想, 测试模]
related_paper: "Relative homological algebra in extriangulated categories（Hu–Zhang–Zhou）"
one_liner_summary: "在带 proper class 的 extriangulated 范畴中证明拟-$\xi$-Gorenstein 投射/内射子范畴对迭代稳定、扩展相对 Ext 消没判据的系数子范畴范围，并构造判定有界投射维数的有限拟投射测试模族。"

## 核心定位

- **解决的问题**：给定 extriangulated 范畴 $(\mathcal C,\mathbb{E},\mathfrak{s})$ 与一个 proper class $\xi$ 的 $\mathbb{E}$-三角，拟-$\xi$-Gorenstein 投射与内射对象及其有限同调维数在何种条件下对迭代封闭，以及有限维数的 Ext 消没判据能把系数子范畴收缩到 $\mathcal P(\xi)$ 或扩张到 $\widehat{\mathcal{QP}}(\xi)$；对模范畴则要构造独立于模本身的有限测试模族来检测有界投射维数。
- **大图景位置**：这是 Gorenstein 同调代数（Enochs–Jenda）在 extriangulated 范畴相对同调框架（Hu–Zhang–Zhou 统一 Beligiannis 三角相对同调与 Quillen 正合同调）中的"准"变体推进：把 Mohammadi Aghjeh Mashhad 的拟 Gorenstein 模理论相对化，并填补有限维数判据系数范围的空白。
- **主要贡献**：
  1. 拟-$\xi$-Gorenstein 投射与内射子范畴对迭代稳定（系数子范畴 $\mathcal{QP}(\xi)$、$\mathcal{QI}(\xi)$ 在迭代中保持不变）。
  2. 有限拟-$\xi$-Gorenstein 投射维数的 Ext 消没判据中系数子范畴可收缩至 $\mathcal P(\xi)$ 或扩张至 $\widehat{\mathcal{QP}}(\xi)$；内射侧对偶成立。
  3. 在二次数环上有限生成模范畴的有界同伦范畴中给出实例：$\mathcal{P}(\xi)\subsetneq\mathcal{QGP}(\xi)\subsetneq\mathcal{GP}(\xi)$ 均严格、$\mathcal{QP}(\xi)$ 与 $\mathcal{QGP}(\xi)$ 不可比较，且诱导的 extriangulated 结构既非 exact 也非三角。
  4. 对模范畴：左完全环或有限 Krull 维数交换 Noetherian 环上 $\mathcal{QGP}(R)=\mathrm{Proj}R$；对满足有限迹理想/幂零商链的交换环，构造有限拟投射测试模族 $\mathscr Q_\lambda$，使 $\mathrm{pd}_RX\leq n$ 等价于 $\mathrm{Ext}_R^{n+i}(X,Q)=0$ 对 $1\leq i\leq c+1$ 全部成立。
- **关键先驱工作**：Nakaoka–Palu 的 extriangulated 范畴；Hu–Zhang–Zhou 的相对同调代数与 $\xi$-Gorenstein 维数；Beligiannis 的 $\mathcal{X}$-Gorenstein 对象；Auslander–Bridger 的 G-dimension 零模；Enochs–Jenda 的 Gorenstein 投射/内射模；Wu–Jans 与 Rangaswamy–Vanaja 的拟投射模与拟投射覆盖；Mohammadi Aghjeh Mashhad 的拟 Gorenstein 模。
- **结果边界**：迭代稳定与判据扩展均在固定 proper class $\xi$ 下陈述，系数子范畴在迭代中固定；测试模构造要求交换环存在有限迹理想与幂零理想商链、迹步骤的端射环有有限右整体维数且迹模非零有限生成；$\mathscr Q_\lambda$ 与 $c$ 依赖基数 $\lambda\geq|R|$，但独立于待测模 $X$ 与维数 $n$。
- **开放问题**：作者未显式列 open problems；从文中可推断：一般 proper class 下 $\mathcal{QP}(\xi)$ 与 $\mathcal{QGP}(\xi)$ 可比性的刻画、测试模族对非交换环的推广、以及 $c$ 的最优下界是自然方向。
- **应用与推广**：为 extriangulated 相对同调提供可操作的有限维数判据；迹理想约化技巧（mod trace ideal 的 reduction）可用于构造其它相对投射/内射类的判别模；测试模族把有界投射维数的检测化为有限个连续 Ext 度消没，适合计算性验证。

### 批判性思考

- 主定理中"系数子范畴可收缩到 $\mathcal P(\xi)$ 或扩张到 $\widehat{\mathcal{QP}}(\xi)$"依赖对象具有有限拟-$\xi$-Gorenstein 投射维数这一前提；当维数无限时判据退化，作者未讨论截断版本的渐进行为。
- 有界同伦范畴实例中 $\mathcal{P}(\xi)\subsetneq\mathcal{QGP}(\xi)\subsetneq\mathcal{GP}(\xi)$ 严格性依赖二次数环的特殊性质（短正合列诱导的 cohomology 相对结构）；该实例的普适性（能否在一般代数上复现）值得检验。
- 测试模族的基数依赖 $\lambda\geq|R|$ 使构造对大基数的分类意义明确，但对有限生成模的实际应用可能只需更小的族——是否存在不依赖 $|R|$ 的统一构造，文中未回答。
