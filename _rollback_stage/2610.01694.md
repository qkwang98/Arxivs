# Harmonic Norms on Quiver Representations over Non-Archimedean Fields

keywords: [调和范数, 箭图表示, 非阿基米德域, 多稳定, HKKP 势, CAT(0) 空间, Bruhat-Tits 建筑, Berkovich 解析族]
related_paper: "2607.17605"
one_liner_summary: 在任意完备非阿基米德域（不要求球形完备）上证明有限箭图的多稳定表示存在 split 调和范数，回答 HKKP 的公开问题：通过闭像定理获得强制性、在一阶变分与支撑铰链下降中建立 split 极小元与半稳定约化的对应。

## 核心定位

- **解决的问题**：Haiden-Katzarkov-Kontsevich-Pandit（HKKP）定理 6.23 要求域球形完备，其问题 6.24 询问能否去掉该假设；本文在任意完备非阿基米德域上给出肯定回答。
- **大图景位置**：非阿基米德版本的 Kempf-Ness 变分理论——Donaldson-Uhlenbeck-Yau / Kobayashi-Hitchin 对应与 King 的箭图矩映射方程在 p-adic 侧的类比；Maculan 的 Berkovich GIT 中范数极小化问题的箭图版本。
- **主要贡献**：(1) 证明 $\theta$-多稳定 $\Rightarrow$ 存在 $(\theta,f)$ 的 split HKKP 调和范数 $\Rightarrow$ $\theta$-半稳定；(2) 证明扩展 HKKP 势 $S_E$ 在完备范数空间 $\Nall(E)$ 上有全局极小值；(3) 证明任何全局极小元 $h$ 都存在具相同箭图奇异型（arrow singular profiles）与相同势值的 split 全局极小元；(4) 以 $D_4$ 表示在 Novikov 域上的两参数 Berkovich 解析族显式分离多稳定、半稳定与调和性三个子簇。
- **关键先驱工作**：HKKP 调和范数与凸势框架；Moret-Bailly 闭像定理；Goldman-Iwahori 度量与 Bruhat-Tits 建筑（对角化范数为扩展欧氏建筑）；Maculan 的 Berkovich GIT；King 的箭图矩映射方程；Bacak 的 CAT(0) 直接方法。
- **结果边界**：结论对平凡赋值自动成立（球形完备退化情形）；强制下界依赖 Moret-Bailly 定理提供的均匀分离常数；Novikov 域上的例子显示调和范数存在域严格大于给定 split 范数的调和域。
- **开放问题**：HKKP 已观察到非多稳定、不可分解表示上调和范数仍可全局极小化势；split 极小元与半稳定约化的更精细唯一性/模空间描述待进一步刻画。
- **应用与推广**：为非阿基米德表示论提供存在性工具：在 $p$-adic 表示、Berkovich 空间与建筑几何中可类比 Hermitian-Yang-Mills 理论做"度量存在等价于稳定性"的判定；split 极小元的奇异型保持性质可服务于箭图模空间的度量几何。

## 主动思考区

### 与其他工作的联系

- 这让我想起：非阿基米德范数空间与 Bruhat-Tits 建筑的几何 — 见 [[2607.17605]]
- [[2607.17605]]：该文刻画局部代数表示上非阿基米德范数空间为有界投射极限，并讨论 Goldman-Iwahori 度量与 Bruhat-Tits 建筑（且指出其度量一般非 CAT(0)）；本文的 $\Ndiag(E)$ 即逐顶点扩展 Bruhat-Tits 建筑的乘积，两文共享建筑-范数语言。
- [[2608.13375]]：该文处理箭图表示的超 GIT 商与超簇几何；本文的稳定性-范数对应可视为 GIT 商几何在非阿基米德度量侧的补充。
- [[2607.10253]]：该文研究 $\mathbb{F}_1$ 上箭图表示的同调刚性；本文关注任意完备非阿基米德域上的度量存在性，二者构成箭图表示在退化基域上的互补视角。
- 技术迁移：Moret-Bailly 闭像定理 + 强制下界的论证模式可迁移到其他稳定性-度量对应（如 $G$-主丛、扭转箭图丛）的非阿基米德版本。
