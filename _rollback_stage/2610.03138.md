# Equivariant Poincaré polynomial of type B Wonderful Models

keywords: [wonderful models, 超八面体群, 等变 Poincaré 多项式, 等变 incidence 代数, 特征级数, plethysm, Getzler 恒等式]
related_paper: "De Concini--Procesi；Yuzvinsky；Getzler（A 型组合恒等式）；Douglass（B_n 作用）；Ferroni--Pagaria--Vecchi；EFMPV25（等变 incidence 代数反演）"
one_liner_summary: 研究超八面体群 $B_n=\mathbb Z_2\wr S_n$ 在 B 型反射排列的最小 De Concini--Procesi wonderful models 上同调上的作用，用等变 incidence 代数中的反演公式把等变 Poincaré 多项式生成级数表达为 A 型级数与 B 型等变约化特征级数的组合，并建立 Getzler 组合恒等式的 B 型类比及显式 plethystic/无穷积公式。

## 核心定位

- **解决的问题**：B 型 minimal wonderful models 的 $B_n$-等变 Poincaré 多项式的显式生成级数；此前自 Yuzvinsky 起仅有非等变的 Poincaré 级数（经微分方程），等变情形（超八面体群作用）无实质进展。
- **大图景位置**：De Concini--Procesi 的 wonderful compactification 是 Deligne--Mumford 模空间 $\overline{\mathcal M}_{0,n+1}$ 在超平面排列情形的推广（A 型 minimal building set 恰恢复模空间）；Manin--Getzler 用指数生成级数研究 Poincaré 多项式，Getzler 用 operadic 方法给出 $S_{n+1}$-等变恒等式 $H^A(-\overline\chi_A(t))=p_1[X]$；本文完成 B 型（Coxeter/超八面体）类比。
- **主要贡献**：①引入并应用等变 incidence 代数框架，证明连接等变 Chow 函数与 super-reduced 特征函数的一般反演公式；②主定理：$H^B=\frac{-1}{\overline\chi^B[H^A[X+Y]]}$，其中 $\overline\chi^B=(\chi^B-x)/(x-1)$ 为 B 型等变约化特征级数；③显式计算 $\chi^B=\omega\bigl(\Exp((1-x)(\Lie_\epsilon[X+Y])^\even)\bigr)=\prod_{n\ge1}\Bigl(\frac{(1+p_n[X+Y])(1+p_n[X-Y])}{1+p_{2n}[X+Y]}\Bigr)^{T_n^B(x)}$，$T_n^B(x)=\frac1{2n}\sum_{d\mid n,\ d\text{ odd}}\mu(d)(x^{n/d}-1)$；④把反演公式用于 partition 与 signed partition lattices：恢复 A 型 Getzler 恒等式并建立 B 型类比；⑤基于 Douglass 的排列补上同调描述计算 B 型等变特征级数，并给出有限域点计数替代证明；⑥讨论 $H^B$ 系数潜在的组合描述。
- **关键先驱工作**：Keel、Manin、Getzler（$\overline{\mathcal M}_{0,n+1}$ 与 A 型恒等式）；De Concini--Procesi（wonderful models）；Yuzvinsky（加性基与 B 型 Poincaré 级数）；Douglass（$B_n$ 在排列补上同调的作用）；GPY17（等变约化特征多项式）；EquivariantIncidenceAlgebras（等变 incidence 代数）；Aluffi--Marcolli--Nascimento、EFMPV25。
- **结果边界**：限于 minimal building set 与 B 型反射排列；一般 building set/其他 Coxeter 型的等变理论未覆盖。
- **开放问题**：$H^B$ 系数的直接组合解释；其他根系统（D 型等）的类似等变级数。
- **应用与推广**：为 B 型 moduli/排列模型提供等变上同调计算工具；等变 incidence 代数反演公式可推广到更一般的原子格与 polymatroid。

## 理解辅助

- Wonderful models：超平面排列的紧化，依赖 building set；A 型 minimal 情形恢复 $\overline{\mathcal M}_{0,n+1}$。
- 超八面体群：$B_n=\mathbb Z_2\wr S_n$，作用在 B 型反射排列（signed arrangement）上。
- 等变 Poincaré 多项式生成级数：$H^B$ 编码 $B_n$ 表示（经 Frobenius 特征映射到双对称函数）。
- 等变 incidence 代数反演：等变 Chow 函数与 super-reduced 特征函数之间的 Möbius 型反演，是主定理的关键工具。
- Plethysm：对称函数复合，出现在 $\overline\chi^B[H^A[X+Y]]$ 中。

## 主要定理原文

> Our main result is the identity of \Cref{thm:inverted-equation-B}:
> \[ H^B= \frac{-1}{\overline{\chi}^B[H^A[X+Y]]}.\]
> Here the series of reduced characteristic polynomial $\overline{\chi}^B= \frac{\chi^B-x}{x-1}$ is explicit computed (see \Cref{formula-chiB})
> \[\chi^B = \omega \left( \Exp \left( (1- x) \bigl( \Lie_{\epsilon} [X+Y])^\even \right) \right)
>     =  \prod_{n \geq 1} \left( \frac{(1+ p_n[X+Y])(1+ p_n[X- Y])}{1+ p_{2n}[X+Y]} \right)^{T_n^B(x)},
>    \]
> where $T_n^B(x)= \frac{1}{2n}\sum_{\substack{d \mid n \\ d \textnormal{ odd}}} \mu (d) (x^{\frac{n}{d}}-1)$.

## 主动思考区

### 与其他工作的联系

- 这让我想起：生成级数与表示论 — [[2610.02787]]（Takiff 抛物诱导的特征公式含 Möbius 系数）与本文的 $T_n^B$（Möbius 求和）共享算术-表示论编码；[[2609.38293]] 的普适环思路与等变 incidence 代数反演同为"把不变量编码为环上运算"。
- 技术迁移：等变 incidence 代数反演公式可复用于其他超平面排列/格（如别根系统、polymatroid 的等变上同调）。

### 批判性思考

- 主定理把 B 型级数约化为 A 型级数 + B 型特征级数，但 $\overline\chi^B[H^A[X+Y]]$ 的 plethysm 在实际计算中仍高度非平凡；"潜在组合描述"尚未落地，工程价值取决于后续系数的显式提取。
- Douglass 的补上同调描述是 B 型特征级数计算的基础，若其对偶（同调 vs 上同调）表述不一致会传播到 $H^B$，文中点计数替代证明是重要的独立校验。
