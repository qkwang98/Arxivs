# Ample stability implies rigidity for quiver moduli

keywords: [quiver moduli, ample stability, rigidity inequality, Teleman 量子化, Harder--Narasimhan 分解, 万有表示, 无穷小刚性]
related_paper: "Belmans--Brecan--Franzen--Reineke（sheaf cohomology of universal bundles, MR4954467）；Belmans--Reineke（向量场与 Hochschild, MR4883104）"
one_liner_summary: 证明 ample θ-stability 足以使 Teleman 量子化应用于 quiver 模空间上万有表示的自同态丛并推出其无穷小刚性，即 rigidity inequality 对每个非平凡 Harder--Narasimhan 型成立，从而移除若干近期结果中比 ample stability 更强的技术条件。

## 核心定位

- **解决的问题**：回答 Belmans--Brecan--Franzen--Reineke 关于万有丛层上同调工作中留下的开放问题（MR4954467 Remark 1.3）：ample stability 是否足以推出 rigidity inequality（对每个非平凡 Harder--Narasimhan 型成立），从而可用 Teleman 量子化推导模空间的无穷小刚性。
- **大图景位置**：quiver moduli 的几何可用组合工具研究；ample/strong ample stability 介于经典 GIT 稳定与强 ample 稳定之间。rigidity inequality 位于 ample 与 strong ample stability 之间：strongly amply stable ⇒ 对每个非平凡 HN 型满足不等式 ⇒ amply stable。第一蕴含严格（已知反例），本文证第二蕴含的逆（无需共素假设）。
- **主要贡献**：①主定理：$\tuple{d}$ amply θ-stable 蕴含 rigidity inequality 对每个非平凡 HN 型成立（此前仅已知 strong ample 推出）；②由此 ample stability 足以对万有表示的自同态丛应用 Teleman 量子化并得无穷小刚性；③清除以下结果中的技术条件：MR4954467 的更高上同调消没（Theorem A）、Schofield 猜想（万有表示部分倾斜，Corollary C）、无圈 quiver 的刚性（Corollary D）、MR4883104 的向量场与一阶 Hochschild 上同调同构（Theorem B）；④修正 MR4954467 式(34)的两处笔误（左边应为 $\mu(\tuple{d}^1)-\mu(\tuple{d}^\ell)$，Euler 形式参数应为 $\langle\tuple{d}^m,\tuple{d}^n\rangle$）。
- **关键先驱工作**：MR4954467（rigidity inequality、higher cohomology vanishing、Schofield 猜想、刚性）；MR4883104；Teleman 量子化理论。
- **结果边界**：coprime 性只用于"半稳定=稳定"以保证涉及 semistable 与 stable locus 的论断，主定理的反向蕴含不需要共素假设。
- **开放问题**：rigidity inequality 与 ample stability 之间是否还有更细的层级；非无圈 quiver 的刚性。
- **应用与推广**：使上述一系列 quiver moduli 结果在最大的适用范围内成立（仅需 ample stability）；共素维数向量下保证 Picard 秩最大，Teleman 量子化可直接应用。

## 理解辅助

- Ample stability：较 GIT 稳定更强、较 strong ample 稳定更弱的稳定性概念，涉及 complement of stable locus 的余维数。
- Rigidity inequality：$\mu(\tuple{d}^1)-\mu(\tuple{d}^\ell) < \sum_{1\leq m<n\leq\ell}(\mu(\tuple{d}^m)-\mu(\tuple{d}^n))(-\langle\tuple{d}^m,\tuple{d}^n\rangle)$，其中 $\tuple{d}^1,\dots,\tuple{d}^\ell$ 为 HN 型的 μ-半稳定部分按斜率严格递减排列。
- Teleman 量子化：通过万有表示的自同态丛构造模空间上同调不变量并推出刚性的一类工具；本文显示 ample stability 恰好是其可用性边界。
- HN 分层余维数：不等式左端度量非平凡 HN 层的余维数下界，从而控制 semistable locus 补集的结构。

## 主要定理原文

> \begin{alphatheorem}
> Let~$Q$ be a quiver. If $\tuple{d}$ is amply~$\theta$\nobreakdash-stable, then the rigidity inequality \eqref{equation:rigidity-inequality} holds for every non-trivial Harder--Narasimhan type~$\tuple{d}^*$.
> \end{alphatheorem}
>
> \begin{equation}
>   \mu(\tuple{d}^1)-\mu(\tuple{d}^\ell)
>   <
>   \sum_{1\leq m<n\leq\ell}\left( \mu(\tuple{d}^m)-\mu(\tuple{d}^n) \right)\left( -\langle\tuple{d}^m,\tuple{d}^n\rangle \right).
> \end{equation}
