# Robustness of quantum spectrum estimation: weak Schur sampling under noisy inputs

keywords: [弱 Schur 采样, 量子谱估计, 噪声稳健性, 量子 Wasserstein 距离, Keyl--Werner, 集体测量, 样本最优算法]
related_paper: "Keyl--Werner（谱估计算法）；Bakshi 等（样本最优谱估计）；O'Donnell--Wright、Haah 等（量子层析）；De Palma 等（量子 Wasserstein 距离）；França 等（快速单副本协议）"
one_liner_summary: 首次在噪声输入下研究弱 Schur 采样（WSS）：对产品噪声（每副本在迹距离 ε 内接近目标态）证明其输出期望误差至多为 ε+η(n,d)（η(n,d)=O(d/√n) 为无噪声误差），加性噪声项 ε 最优；对任意输入证明 WSS 结果可观测量关于量子 Wasserstein 距离是 1/n-Lipschitz，从而首次建立 Keyl--Werner 量子谱估计算法（二十余年后）的噪声稳健性。

## 核心定位

- **解决的问题**：样本最优的量子学习算法（谱估计 QSE、态层析 QST）都在完美输入 $\rho^{\otimes n}$ 假设下分析；实际设备每 shot 产生的副本只是近似相同（漂移、标定误差、纠错后的残差），破坏 WSS 依赖的置换对称性。朴素数据处理论证给出随系统大小增长的 $n\epsilon$ 误差上界，威胁集体协议的优越性。
- **大图景位置**：量子学习理论中"最优算法的噪声稳健性"的空白；WSS 是 QSE 与 QST 最优算法的核心测量，建立其稳健性是使最优算法走向实用的必要步骤。
- **主要贡献**：①产品噪声模型（独立但非同分布，每副本与目标态迹距离 ≤ε）下：$\mathbb E[\frac12\|\hat\pp-\pp\|_1]\le\epsilon+\eta(n,d)$，η(n,d)=O(d/√n) 为无噪声误差——噪声只带来加性 ε（噪声地板），样本复杂度 $O(d^2/\delta^2)$ 保持；②地板最优性：n 个同一 ε-扰动态的副本上任何估计器误差至少 Ω(ε)；③任意输入 ω 下：WSS 的结果可观测量关于 De Palma 等量子 Wasserstein 距离 $W_1$ 是 $1/n$-Lipschitz，误差 ≤ η(n,d)+$\frac1n\|\omega-\rho^{\otimes n}\|_{W_1}$；④推论：首次证明 Keyl--Werner QSE 算法（提出 20 余年后）的噪声稳健性，并确立其核心子程序在样本最优算法中的稳健性；⑤否定结果：承诺不能弱化为"单副本边缘接近"或"全局迹距离预算"——这两类弱承诺下存在击败一切测量与估计器的噪声输入。
- **关键先驱工作**：Keyl--Werner（WSS 与谱估计）；Bakshi 等（样本最优谱估计）；O'Donnell--Wright、Haah 等（最优层析）；De Palma 等（量子 Wasserstein 距离）；Keyl（层析的第二测量）。
- **结果边界**：稳健性只对 WSS 这一核心步骤建立；最优算法的其余步骤（层析的基估计第二测量）是否稳健是两个主要开放问题之一。
- **开放问题**：①最优谱估计算法其余步骤（含可去偏/混合态步骤）的稳健性；②最优全态层析第二测量（特征基估计）的稳健性；③一般噪声模型（相关噪声、非马尔可夫）下的扩展。
- **应用与推广**：量子设备验证（用谱估计学习设备的残差误差）；噪声中等规模（NISQ）与容错硬件输出的表征；向认证、假设检验等其他量子学习任务的稳健性推广。

## 理解辅助

- WSS：在 $(\mathbb C^d)^{\otimes n}$ 上输出 n 的至多 d 部分拆分的测量；完美输入下 $\lambda/n$ 集中于 $\spec(\rho)$，得到经验谱估计 $\hat\pp$。
- 噪声地板：由噪声引起的、无法靠增加副本数降低的输出误差部分（此处为 ε）；误差以无噪声速率下降到地板后不再下降。
- 置换对称性：集体最优测量利用 $\rho^{\otimes n}$ 的置换对称；噪声非对称输入 $\rho_1\otimes\cdots\otimes\rho_n$ 无任何置换对称。
- 量子 Wasserstein 距离 $W_1$：De Palma 等引入的度量，用于度量输入态与理想 $\rho^{\otimes n}$ 的距离。

## 主要定理原文

> \begin{result}[Weak Schur sampling under product noise, \cref{thm:robust,prop:floor}]
>   Consider the product noise model on $n$ input copies, in which each noisy copy is within trace distance $\eps$ of the target state $\rho$ on $\C^d$. On such input weak Schur sampling with the estimator $\hat\pp=\lambda/n$ learns the spectrum $\pp$ of $\rho$ with expected error
>   \begin{equation*}
>     \mathbb{E}\bigl[\tfrac12\|\hat\pp-\pp\|_1\bigr] \;\le\;\eps+\eta(n,d), \qquad \eta(n,d)=O\!\bigl(d/\sqrt n\bigr),
>   \end{equation*}
>   where $\eta(n,d)$ is the error of the same estimator on noiseless input $\rho^{\otimes n}$. That is, $n=O(d^2/\delta^2)$ noisy copies give output precision $\delta+\eps$, and the noise-induced output error $\eps$ cannot be avoided by any measurement and estimator.
> \end{result}
