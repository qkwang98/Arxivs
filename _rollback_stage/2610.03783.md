# Neural Network Solvers for Nonlinear ODEs: Benchmarking MLPs and B-Spline/Chebyshev KANs

keywords: [神经网络求解器, 非线性常微分方程, Kolmogorov-Arnold网络, B样条, Chebyshev]
related_paper: "Liu 等的 KAN（Kolmogorov-Arnold Networks, 2024）原始论文"
one_liner_summary: 本文在统一训练预算下系统对比 MLP、B 样条 KAN 与 Chebyshev KAN 求解一至四阶非线性常微分方程的表现，发现最优 KAN 至少与最优 MLP 同样精确且参数更少，同时揭示高阶问题中 KAN 基分辨率与导数正则性的关键作用。

## 1.  核心定位

- **解决的问题**：KAN 声称的"参数高效、可解释、可后训练细化"等优势在直接以微分方程残差训练时是否仍然成立，且现有文献结论相互矛盾，缺乏跨微分阶数的系统评估。
- **大图景位置**：在物理信息机器学习（PINNs）这一广阔领域中，本文是对"MLP 主导的神经 ODE 求解器 vs 新兴 KAN 架构"的一次受控基准测试，填补了"按微分阶数系统对比"这一空白。
- **主要贡献**：在相同训练预算与相同五种激活函数选择下，对比 MLP、B 样条 KAN 与 Chebyshev KAN 在五个一至四阶非线性 ODE（含两个奇异问题与一个具有闭式解的四阶新问题）上的表现；所有训练运行无一数值失败，并逐例记录未能捕获精确解的运行；证明高阶（三、四阶）时 KAN 基必须从粗分辨率起步，并将标准网格延拓替换为保导数的结点插入；提取并绘制全部学习到的边缘函数，与简单解析式直接匹配。
- **关键先驱工作**：Lee–Meade–Lagaris–Raissi 等的残差训练框架；Cybenko–Hornik 的通用逼近定理；Kolmogorov–Arnold 表示定理与 Liu 等的 KAN、Chebyshev KAN 变体；Wang 等的梯度失衡分析与神经正切核解释；Shukla 等与 Wang 等在 KAN 求解器上的对立结论。
- **结果边界**：结论基于五个特定测试问题与固定统一训练协议，不覆盖自适应损失加权、自适应激活等改进技巧；KAN 在高阶问题时更易失败且需要粗基，B 样条 KAN 的导数被网格延拓扭曲，结点插入对四阶问题无改善；奇异问题与截断半无限域场景的泛化仍需更多验证。
- **开放问题**：高阶问题中 KAN 为何更频繁失败、粗基要求的理论解释；结点插入能否系统化以替代网格延拓；KAN 边缘函数可解释性在更复杂耦合系统中的实用性。
- **应用与推广**：为物理信息机器学习中架构选择提供实证依据；B 样条 KAN 在 Falkner–Skan 类边界层问题中 34 至 220 倍的精度提升提示其在流体力学中的应用价值；边缘函数到解析式的匹配可服务于符号回归与模型简化。
