# Repunit Coordinates for the Erdős Ternary-Digit Problem

keywords: [Erdős猜想, 三进制数字, 广义repunit, 3-adic动力系统, 提升律]
related_paper: "Saye（2022）的递归尾随数字构造"
one_liner_summary: "把 Erdős 三元数字猜想转化为广义基 4 repunit 的数字省略条件，证明有限深度映射 $\Phi_m$ 是模 $3^m$ 的置换并给出种子纤维、提升律与 3-adic 等距同胚共轭结构，将问题严格分解为精确的有限深度局部结构与未解决的全局整数问题。"

## 核心定位

- **解决的问题**：为 Erdős 三元数字猜想（2 的幂中三进制展开不含数字 2 的仅有 1、4、256）提供自足的坐标框架，精确刻画有限深度后缀可允许性。
- **大图景位置**：该猜想自 1979 年提出后经大量计算与结构研究仍未解决；本文将问题置于广义基 4 repunit 与 3-adic 动力系统的交叉点，整合并深化了 Saye、Lagarias、Abram 与 Lagarias 等人的工作，但不声称证明猜想。
- **主要贡献**：将 Erdős 条件精确约化为 repunit $\mathrm{Rep}_s(4)$ 的数字省略条件；证明 $\Phi_m: s\pmod{3^m}\mapsto \mathrm{Rep}_s(4)\pmod{3^m}$ 是模 $3^m$ 剩余类的置换；建立中心提升恒等式并证明每个剩余类恰好有三个提升、其中恰好两个保持可允许性；给出规范种子纤维与逆极限描述；证明 repunit 映射在 3-adic 整数上延拓为共轭平移 $x\mapsto x+1$ 与仿射递推 $y\mapsto 4y+1$ 的等距同胚。
- **关键先驱工作**：Erdős 1979 年原文与已知例外 $2^8=256$；Gupta 的计算验证；Saye 的递归尾随数字构造与 $n\leq 2\cdot3^{45}$ 验证；Dimitrov 与 Howe 关于至多 25 个不同 3 的幂之和的结果；Lagarias 的实与 3-adic 动力系统表述；Abram 与 Lagarias 的 3-adic Cantor 集有限交集研究。
- **结果边界**：论文明确不证明 Erdős 猜想本身；有限深度剩余树无论多深都无法推出普通整数解的有限性，因为逆极限树含无穷多条 3-adic 路径；示例 $s=12$ 通过深度 3 局部检验但完整三进制展开仍含数字 2，全局排除需要真正超越有限深度的机制。
- **开放问题**：确定哪些普通非负整数指数在每一位上都满足数字限制仍是未解决的全局问题；如何引入超越有限深度后缀可允许性的全局机制是该框架留下的核心问题。
- **应用与推广**：repunit 坐标与种子纤维可作为数字性质问题的标准工具，可迁移到其他底数与数字集合的类似问题；3-adic 等距同胚的共轭结构可用于研究相关的动力系统与 Cantor 集交集；有限深度数据集与搜索协议可复现验证。
