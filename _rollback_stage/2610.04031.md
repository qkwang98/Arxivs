# On injective dimension of the conormal module

keywords: [conormal module, injective dimension, complete intersection, licci ideal, Koszul homology]
related_paper: "Briggs 关于 Vasconcelos 猜想的证明（有限投射维数版本）"
one_liner_summary: 证明在 licci 理想、若干数值条件、正规域无挠类群与单项式理想等情形下，共模 $I/I^2$ 的内射维数有限迫使理想 $I$ 由正则序列生成。

## 1.  核心定位

- **解决的问题**：将 Vasconcelos 关于共模的有限投射维数判别推广为内射维数版本——何时 $\id_R(I/I^2)<\infty$ 迫使理想 $I$ 由 $Q$-正则序列生成。
- **大图景位置**：Ferrand–Vasconcelos 经典结果（$I/I^2$ 自由当且仅当 $I$ 由正则序列生成）与 Briggs 的投射维数猜想是完整交检测的同调判据；本文给出内射维数的对偶版本，并揭示 Gorenstein 性是两类判据之间的关键桥梁。
- **主要贡献**：Theorem A 对任意 licci 理想（完全交的 linkage 类）给出肯定回答；Theorem B 在无 licci 假设下给出三组数值条件（$\mu(I)\le\height(I)+2$；$R$ 为 generically Gorenstein 且 $\mu(I)\le\height(I)+\type(R)$；$\mu(I)$ 为素数且 $Q$ 非分歧或 $R$ generically Gorenstein）；Theorem C 对正规域商得到类群中的挠关系 $(g+1)[\omega_R]=0\in\operatorname{Cl}(R)$；Theorem D 对多项式环中所有单项式理想给出肯定回答；此外证明 Kunz 关于 almost complete intersection 的第一 Koszul 同调描述的逆命题。
- **关键先驱工作**：Ferrand 与 Vasconcelos（1967）、Vasconcelos（1978）有限投射维数猜想、Avramov–Herzog（分次特征零情形）、Briggs（一般情形，利用同伦李代数）、Kunz 关于 Cohen–Macaulay almost complete intersection 的 $\H_1(I)\cong\omega_R$。
- **结果边界**：内射维数有限仅推出 $R$ 为 Cohen–Macaulay；须再证 $R$ 为 Gorenstein 方可调用 Briggs 定理，故 Gorenstein 性是联结内射维数问题与 Vasconcelos 猜想的枢纽；Theorem B 的数值条件局限于生成元个数与高度、type 的差距；Theorem C 需要类群无挠或 $g+1$ 阶挠条件。
- **开放问题**：能否去掉各定理的附加限制（licci、数值上界、类群无挠、单项式）而给出统一回答；正文未给出反例表明各附加条件不可去。
- **应用与推广**：对正规分次环族（generic 与 ladder determinantal 环、Grassmannian 中 Schubert 簇的齐次坐标环、若干 Pfaffian 环与 toric 环）在无挠类群情形给出肯定回答；为判别理想是否由正则序列生成提供同调不变量 $\id_R(I/I^2)$。
