# Restrictions of the dot action representation

keywords: [dot action 表示, Hessenberg 簇, 色拟对称函数, Weyl 群, 限制表示]
related_paper: "Chromatic quasisymmetric functions and Hessenberg varieties"
one_liner_summary: 证明将任意 Weyl 群的 dot action 表示限制到 type A 抛物子群后同构于若干 type A dot action 表示的直和（带平移分次），并在经典 $B_n/C_n/D_n$ 型中利用色对称函数给出限制到极大 type A 抛物子群 $W_J\cong S_n$ 的简洁组合公式，作为应用证明了 Lesnevich 关于 $B$ 型与 $C$ 型理想对应的 dot action 表示同构的猜想（同构当且仅当两个理想给出相同反射集，且此类理想总数由 Catalan 数刻画）。

## 1.  核心定位

- **解决的问题**：确定 Tymoczko 定义的 Weyl 群 dot action 表示（作用于正则半单 Hessenberg 簇 $H^\ast(\Hess(s,H))$）限制到抛物子群的结构，特别是限制到 type A 极大抛物子群 $W_J$ 时的分解。
- **大图景位置**：type A（对称群）情形已由 Athanasiadis、Brosnan–Chow、Shareshian–Wachs 的工作完全理解（色拟对称函数编码）；本文把理解推进到一般既约根系（$F_4$ 除外，其余不可约根系均有 type A 极大抛物子群），并给出经典型 $B_n,C_n,D_n$ 的具体组合公式；同时验证了关于所有抛物子群均满足类似性质的猜想在 type A 分量的特殊情形。
- **主要贡献**：1. 主定理：当 $\Phi_J$ 的每个不可约分量均为 type A 时，限制 $\sum_j H^{2j}(\Hess(s,H))\downarrow^W_{W_J}\,t^j$ 同构于 $\sum_{v\in {^J}W} t^{\ell_H(v)}\sum_k H^{2k}(\Hess(s,H_v))t^k$（$H_v=\Ad(\dot{v})H\cap\fl_J$ 为 Levi 子代数中的 Hessenberg 空间，$\ell_H(v)$ 为 Hessenberg 长度）；2. 经典型 $B_n/C_n/D_n$：对删除 $\alpha_n$ 得到的 $W_J\cong S_n$，证明每个图 $\Gamma_{H,v}$ 是自然标号单位区间图，且限制的 Frobenius 特征为 $\omega(\sum_{v\in {^J}W}t^{\ell_H(v)}X_{\Gamma_{H,v}}(\vx;t))$；3. 应用：证明 Lesnevich 猜想——$B_n$ 与 $C_n$ 根理想在标准偏序同构下对应的 dot action 表示同构当且仅当它们确定相同反射集，并证明此类理想总数由 $W$-Catalan 数给出；4. 推论：限制到同构于对称群的抛物子群时，全上同调的 dot action 是 $W_J$ 抛物子群陪集空间置换表示诱导的直和。
- **关键先驱工作**：Tymoczko 的 dot action 定义；Shareshian–Wachs 的色拟对称函数与 Hessenberg 簇、Athanasiadis 的幂和分解；Brosnan–Chow 定理（$f_{j,I}$ 与 $H^{2j}\otimes\sgn$ 的 Frobenius 特征）；Precup 关于 $H_v$ 为 Levi 中 Hessenberg 空间的引理；de Mari–Shayman、de Mari–Procesi–Shayman 的正则半单 Hessenberg 簇研究；Goresky–Kottwitz–MacPherson 的 GKM 理论。
- **结果边界**：主定理要求 $\Phi_J$ 的每个不可约分量均为 type A；一般抛物子群情形的 Conjecture（maincon）仍开放；非 type A 根系中抛物子群共轭类数少于 $W$ 的共轭类数，因此不能仅凭各 $W_J$ 不变维数确定表示，这限制了可证明的结论范围；$F_4$ 因无 type A 极大抛物子群而未被经典公式覆盖。
- **开放问题**：一般抛物子群 $J$ 下限制的直和分解是否成立（Conjecture maincon）；$W_J\cong S_n$ 时逐次 $H^{2j}$ 的限制是否仍为抛物子群陪集空间置换表示诱导的直和（Conjecture hposq，依赖 Shareshian–Wachs 的 Stanley–Stembridge 精细化版本）。
- **应用与推广**：经逆 Frobenius 特征，经典型限制的不可约分解与特征值可显式计算；Lesnevich 猜想的证明为 $B/C$ 型理想分类提供了反射集判据；Stanley–Stembridge 猜想（Hikita 已证）保证 dot action 为抛物诱导置换表示的直和，本文将其推广到对称群抛物子群上的限制。
