# Classification of reductive monoids

keywords: [reductive monoids, reductive group schemes, based root data, Weyl cones, Vinberg monoid, 下降, spherical embeddings]
related_paper: "Renner, Classification of semisimple algebraic monoids"
one_liner_summary: 通过对分裂情形的分类作下降，给出任意基概形上以给定约化群概形为单位群的 reductive monoids 的完全分类：构造基于根数据、抽象 Cartan 环面、抽象 Weyl 群与 Weyl 锥的层，并以 Weyl 锥概形的整体截面刻画刚性化 reductive monoids 的同构类。

## 核心定位

- **解决的问题**：将 reductive monoids 的分类从分裂、连通基概形（前作 CJ）推广到任意基概形上的完全一般性，回答"以给定约化群概形 $G$ 为单位群的 reductive monoids 如何分类"。
- **大图景位置**：这是 Vinberg（特征 0 代数闭域）、Rittatore（任意代数闭域，用余权空间中的锥与 Luna–Vust/Knop 球嵌入理论）、Renner（代数闭域，Theorem 5.4）经典分类的基概形化推广；前作 CJ 处理分裂连通基的特例并推广 Vinberg 方法，本文完成下降步骤。
- **主要贡献**：1) 对任意 reductive group scheme $G$，以规范方式（无需选择 global pinning）构造基于根数据、抽象 Cartan 环面、抽象 Weyl 群与 Weyl 锥的层，并证明其由 étale 局部常值概形表示；2) 主定理：刚性化 reductive $G$-monoids 的同构类与 Weyl 锥概形的整体截面一一对应，遗忘刚性化即取 $\Aut_G(S)$ 整体截面的轨道；3) 应用：给出非平凡 reductive monoid 存在性判据、normal integral 基上的唯一延拓定理，并对任意（含非拟分裂）reductive group scheme 构造 Vinberg monoid。
- **关键先驱工作**：Renner 的代数闭域分类；Vinberg 的特征 0 分类；Rittatore 基于 coweight 锥与球嵌入的分类；Luna–Vust 与 Knop 的球嵌入理论（后由 Huruguen、Wedhorn 推广到任意域）；前作 CJ 的分裂分类。
- **结果边界**：分类以"刚性化"对象陈述，遗忘刚性化需取自同构群轨道；Weyl 锥方法不依赖 pinning 因而适用于非拟分裂群，但对应关系建立在下降与 étale 局部常值概形表示的基础上；spherical embeddings 在一般基概形上的类似分类仍属开放。
- **开放问题**：作者在 Related work 中提出：能否对一般基概形上的球嵌入建立分类定理。
- **应用与推广**：为 reductive monoids 的算术与模问题提供基概形层面的统一框架；Vinberg monoid 的普遍构造可直接用于约化群概形的表示论与球簇理论；Weyl 锥层的规范构造可作为研究非分裂群上其他组合数据（如权重幺半群）的模型。
