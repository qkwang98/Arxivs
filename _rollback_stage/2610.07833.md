# Higher localised $\widehat{A}$-genera: a note on disconnected fixed-point sets

keywords: [higher localised A-hat genus, 断连不动点集, 正标量曲率, 高阶指标, 对角嵌入]
related_paper: "Regular boundary conditions and analytic K-homology (2610.02899)"
one_liner_summary: 将高阶局部化 $\widehat{A}$-亏格（localised $\widehat{A}$-genus）的指标型不动点公式从连通的非正则不动点集推广到一般断连情形，为带群作用流形上的正标量曲率障碍提供更广的几何工具。

## 核心定位

- **解决的问题**：Rosenberg 提出的局部化 $\widehat{A}$-亏格用于检测带 $\mathbb{T}$-作用流形上是否存在不变的正标量曲率度量；此前的高阶推广对不动点集的连通分支与"$\alpha$-正则"条件有所限制，本文去掉这些限制，处理一般（断连且非正则）的不动点集。
- **大图景位置**：处于正标量曲率几何与 K-理论指标理论的交汇处：局部化 $\widehat{A}$-亏格是正标量曲率障碍的精细化不变量，其高阶形式（higher localised genera）把障碍从 $\mathbb{Z}$ 值提升到高阶 K-理论/循环同调层面，本文补全了不动点集几何形态上的空白。
- **主要贡献**：
  1. 将局部化 $\widehat{A}$-亏格的高阶推广从连通的 $\alpha$-正则不动点集扩展到任意断连不动点集；
  2. 用对角嵌入（diagonal embedding）技巧把多分支不动点集的贡献统一编码，绕过逐分支的正则性要求；
  3. 给出该设定下指标型不动点公式（equivariant index / higher index 版本）的完整表述，为后续正标量曲率障碍的实例计算铺路。
- **关键先驱工作**：Rosenberg 的局部化 $\widehat{A}$-亏格与正标量曲率障碍理论；Gromov–Lawson 的稳定正标量曲率与 $\widehat{A}$-亏格消没条件；Atiyah–Bott 等指标定理与不动点公式传统；高阶指标（higher index）与粗几何/等变 K-同调框架。
- **结果边界**：结果对不动点集的断连性放宽，但仍要求作用具有良好指标理论设置（闭流形、可定向、紧群作用等）；不动点分支之间若出现退化相交或非孤立奇点，公式是否仍适用需另行检验。
- **开放问题**：如何用该高阶局部化亏格构造新的正标量曲率障碍实例；能否进一步去掉紧性/正则性假设，或推广到非紧与带边情形。
- **应用与推广**：为正标量曲率问题的等变 K-理论方法提供更通用的不变量；其对角嵌入编码思想可迁移到其它不动点集不连通情形下的指标公式（如 Dolbeault、spin$^c$ 算子）中。
