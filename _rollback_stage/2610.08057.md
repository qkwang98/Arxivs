# Webs and finite dimensional Representation theory for quantum symmetric pairs

keywords: [量子对称对, coideal 子代数, Verma 模, web 范畴, skew Howe 对偶, 量子外幂, 无重数分解]
related_paper: "Bao–Wang, A new approach to Kazhdan–Lusztig theory of type B via quantum symmetric pairs"
one_liner_summary: 本文对拟分裂 AIII 型量子对称对子代数建立统一的 Letzter 映射三角分解与 Verma 模理论，并构造控制其多项式表示的 web 范畴 $\mathcal B$，通过点态态射的显式特征空间分解证明量子外幂 $\bigwedge^k V$ 的无重数分解，从而确定其不可约直和项的型与最高权向量。

## 核心定位

- **解决的问题**：为拟分裂 AIII 型量子对称对子代数 $\mathcal B$ 建立完整的高权表示理论（三角分解、Verma 模、有限维单模实现），并给出量子外幂 $\bigwedge^k V$ 作为 $\mathcal B$-模的无重数分解及其不可约直和项的显式刻画。
- **大图景位置**：量子对称对是 Drinfeld–Jimbo 量子群中的 coideal 子代数，其有限维表示论因 Letzter Cartan 子代数不由 group-like 元生成而长期缺乏经典高权理论的平行版本。本文在拟分裂 AIII 情形用新的 Letzter 映射方法给出统一处理，并引入 web 范畴把分解问题转化为图范畴中幂等元的计算。
- **主要贡献**：① 在 AIII 拟分裂两个子族上，结合新的 Cartan 子代数与 Letzter Cartan 子代数，通过 Letzter 映射构造三角分解，并定义 Verma 模；证明有限维单 $\mathcal B$-模均为 Verma 模的商，且处理对两子族统一；② 构造图范畴 $\mathcal B$（控制 $\mathcal B$ 的多项式表示），证明量子外幂 $\bigwedge^k V$ 作为 $\mathcal B$-模的无重数分解，谱由点态态射的特征值 $[k-2i]_Q$（$Q=-q$）给出且重数显式为二项式系数；③ 应用：推出相关反球面 Hecke 模的无重数性，显式确定 $\bigwedge^k V$ 的最高权向量（由特定 box 图给出）及其权，进而确定不可约直和项的同构类；④ 确定 $\mathcal B$-作用在多项式表示范畴 $\mathrm{Fund}_{\mathcal B}$ 上的核，给出商范畴等价 $\bar\Phi$ 与交换图。
- **关键先驱工作**：Letzter 对量子对称对与 coideal 子代数的开创性工作；Kolb 对量子对称对的系统处理与分类；Kolb–Yakimov 的 Letzter 映射与定义关系；Stroppel–Webster 在 $\mathfrak{gl}_2\times\mathfrak{gl}_2$ 情形的 PBW 基、三角分解与 Verma 模；Cautis–Kamnitzer–Morrison 的 skew Howe 对偶 web 范畴；Bao–Wang 的 $\iota$-canonical 基；Elliott–Stroppel 的 NW 代数与 Howe 对偶。
- **结果边界**：三角分解与 Verma 模构造限定于拟分裂 AIII 型（$\mathcal B\subset U_q(\mathfrak{gl}_n)$，$n$ 奇或偶的两个子族）；无重数分解针对量子外幂 $\bigwedge^k V$ 这一具体表示族；作者指出其方法比 Watanabe 的构造更特定于此类型，但期望可推广到其他类型。
- **开放问题**：作者期望类似构造在其他类型中可行；未明确列出开放问题，但自然方向包括将 Letzter 映射与 web 方法推广到更多量子对称对类型，以及把核刻画推广到更大的表示范畴。
- **应用与推广**：为拟分裂 AIII 型量子对称对的最高权理论提供统一框架，便于计算有限维不可约模的中心特征标与分类；web 范畴 $\mathcal B$ 为多项式表示的张量积分解提供图算法（类比 Jones–Wenzl 投影子的归纳机制）；反球面 Hecke 模的无重数性可直接用于 Hecke 代数的表示论与范畴化。
