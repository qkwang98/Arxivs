# Log-concavity and unimodality of cluster monomials in fan coordinates of type $A_n$

keywords: [cluster 代数, 对数凹性, 单峰性, Laurent 展开, laminar 区间族, 扇形三角剖分]
related_paper: "Chen–Huang–Sun (CHS26) 关于 $A_n$ 型 cluster 单项式对数凹性的猜想与 Chen (Che26) 的单峰性猜想"
one_liner_summary: 本文证明 $A_n$ 型 cluster 代数的每个 cluster 单项式在扇形初始簇坐标下的 Laurent 展开沿每个坐标方向是对数凹且单峰的，且非零坐标切片无内部零点，从而在扇形初始三角剖分情形部分肯定地回答了 Chen–Huang–Sun 的对数凹性猜想与 Chen 的单峰性猜想。

## 核心定位

- **解决的问题**：$A_n$ 型 cluster 代数中，任意 cluster 单项式在固定初始簇（扇形初始三角剖分对应的 fan initial cluster）坐标下的 Laurent 展开系数，沿每个坐标方向是否对数凹（log-concave）且单峰（unimodal）。
- **大图景位置**：这是 cluster 代数正性与 Laurent 现象研究的自然延续：Fomin–Zelevinsky 引入 cluster 代数并证明 Laurent 现象，Chen–Huang–Sun 证明 $A_n$ 型 cluster 变量与 $A_2$ 型 cluster 单项式的对数凹性，Chen 证明 $A_3$ 型的对数凹性与单峰性；本文将其推广到 $A_n$ 全秩的 cluster 单项式，是对相关猜想在扇形初始种子情形下的一般性验证。
- **主要贡献**：1) 给出由相容对角线（compatible diagonals）产生的 laminar 区间乘积的系数公式；2) 偶秩情形把扇形坐标下的对数凹性约化为沿整数线的对数凹性；3) 奇秩情形用卷积处理扇形替换产生的系数和，证明对数凹性对卷积与逐点乘法的封闭性成立。
- **关键先驱工作**：Fomin–Zelevinsky 的 cluster 代数与 Laurent 现象；Gross–Hacking–Keel–Kontsevich 的散射图与正性；Chen–Huang–Sun (CHS26) 与 Chen (Che26) 的低秩对数凹性/单峰性结果；Fock–Goncharov 的 cluster ensemble 与正坐标系统；Shen (She14) 对 $A_n$ 型 cluster $\mathcal{X}$-簇典范基元素乘积支撑（Stasheff 多面体）的研究。
- **结果边界**：仅对扇形初始三角剖分（线性定向 $A_n$ 箭图）成立；未证明对任意初始种子的种子无关性（猜想第二部分）；证明依赖系数自由、斜对称 cluster 代数与多边形模型组合学，推广到其他 Dynkin 型或带系数情形需要新方法。
- **开放问题**：cluster 单项式的对数凹性与单峰性是否对任意初始种子成立（种子无关性）；能否推广到 $A_n$ 以外的有限型甚至无限型 cluster 代数；奇秩情形卷积论证能否得到显式的单峰性界。
- **应用与推广**：为 cluster 代数的系数结构研究提供一般性工具；laminar 区间族与扇形替换的组合技术可迁移到其他由曲面构造的 cluster 代数；对 cluster $\mathcal{A}$-簇与 $\mathcal{X}$-簇的对偶、典范基与热带几何的联系提供新的系数层面证据。
