# A secondary index map on relative $K$-homology

## 核心定位

- **解决的问题**：为带边流形上正标量曲率（psc）度量的相对问题——边界上的 psc 度量能否延拓为整体 collared psc 度量——建立精细的次级不变量：从相对 $K$-同调到相对结构代数 $K$-理论的次级指标映射，并使其与代数 Mayer-Vietoris 序列及相对指标映射形成协调的代数框架。
- **大图景位置**：这是粗指标理论（coarse index theory）在"带边流形 + 均匀正标量曲率"情境下的自然深化。经典粗指标 $\mathrm{Ind}(\Dirac)$ 消失时，高阶 $\rho$-不变量用于区分不同的 psc 度量；本文的次级指标把这一机制搬到相对 $K$-同调上，与 Chang--Weinberger--Yu 的相对 Baum-Connes 映射互补，并补全 Zeidler 对 delocalized APS 指标定理的加强（去掉有限宽度假设、给出构造性描述）。
- **主要贡献**：(1) 定义从等变相对 $K$-同调 $K_*^\Gamma(X,Z)$ 到相对结构代数 $K$-理论 $K_*(D^*(X,Z)^\Gamma)$ 的次级指标映射 $\secInd$；(2) 证明相对结构代数的代数 Mayer-Vietoris 序列，其边界映射与 $K$-同调上的边界映射相容；(3) 定义到相对 Roe 代数 $K$-理论的相对指标映射 $\Ind_{\mathrm{rel}}$，并给出联系两套长正合列的交换图；(4) 在偶数维 collared spin 流形（边界具均匀正标量曲率）上证明 $\secInd(\Dirac_\Omega) = \Ind_{\mathrm{APS}}(\Dirac_\Omega) + \rho^\Gamma(\Dirac_{\dO})$，从而推出带符号修正且无需有限宽度假设的 delocalized APS 指标定理。
- **关键先驱工作**：Roe 的粗指标理论；Piazza--Schick 与 Xie--Yu 的 delocalized APS 指标定理（分别处理偶数维与奇数维）；Chang--Weinberger--Yu 引入的相对 Baum-Connes 映射；Zeidler 借助局部化代数的 bordism $\rho$-不变量；Baum--Douglas--Taylor 及其推广（Forsyth--Goffeng--Mesland--Rennie、Fries、Engel--Lyko）关于正则边界条件给出相对 $K$-同调类的工作。
- **结果边界**：公式 $\secInd(\Dirac_\Omega) = \Ind_{\mathrm{APS}}(\Dirac_\Omega) + \rho^\Gamma(\Dirac_{\dO})$ 仅在偶数维证明——奇数维时边界映射不易直接计算，作者明确表示这更可能是方法限制而非定理本身的缺陷；文中假设 $\Gamma$ 的作用自由、真、等距且保持边界，度量须为 collared，边界须有均匀正标量曲率；此外相对结构代数与次级指标映射不落入"长正合列之间干净交换图"的框架。
- **开放问题**：相对结构代数与次级指标映射能否推广以纳入边界的（基本群）信息，使得 Chang--Weinberger--Yu 的相对 Baum-Connes 映射分解经过升级后的次级指标映射？这是作者明确留下的未竟方向；奇数维情形的对应公式仍待证明（Xie--Yu 曾用局部化代数处理同类问题）。
- **应用与推广**：次级指标为区分带边流形上不同的 collared psc 度量提供新的障碍工具；相对指标映射 $\Ind_{\mathrm{rel}}$ 与相对 Roe 代数的联系可把问题转化为相对粗 Baum-Connes 型陈述；该框架可与等变 $KK$-理论、粗几何中的 Mayer-Vietoris 技术以及 psc-bordism 不变量结合，为"映射标量曲率到分析"的一般纲领（Piazza--Schick）补充带边版本。
