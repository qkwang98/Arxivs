## 核心定位

- **解决的问题**：对特征零域上具有孤立临界点的幂级数 f（即 Jacobian 理想 J_f 为极大理想 m-准素），证明 Euler 导子 J_f:f = {g : gf ∈ J_f} 不被 Tjurina 理想 (J_f,f) 包含——这是 Hassanzadeh、Nasrollah Nejad 与 Simis 提出的猜想，此前仅在平面曲线情形被证明。
- **大图景位置**：Milnor 数 μ_f 与 Tjurina 数 τ_f 的数值比较有大量文献（μ_f = τ_f 当且仅当 f ∈ J_f，Saito 判据联系拟齐次性）；本文处理互补的位置问题——把 J_f:f 与 (J_f,f) 的关系翻译成 Jacobian 商环 A = R/J_f 上幂零元 a = [f] 的约当块结构，并最终归结为 Kähler 微分 d_{A/k}a = 0 的余法向障碍。
- **主要贡献**：① 一般 Noether 商环定理：若 k 特征零、A = R/I 为 Noether 且 a = [f] 幂零、d_{A/k}a = 0，则 I:f ⊄ (I,f)；② 局部强化：当 (R,n) 局部时 I:f ⊄ (I,f) + n(I:f)，且给出一个可加入极小生成集的元素，其类模 n(I:f) 非零；③ 在任意维数证明 HNS 猜想，并得到强化式 J_f:f ⊄ (J_f,f) + m(J_f:f)；④ 构造五变量孤立奇点 f = (1/4)Σ_{i=1}^5 x_i^4 + (x_1+⋯+x_5)^5 满足 J_f:f ⊆ conj(J_f) = m^3，否证 Ma–Zuo 的积分闭包加强猜想。
- **关键先驱工作**：HNS 的平面曲线情形与猜想 3.6；Saito 判据（拟齐次性与 μ_f = τ_f）；Milnor 对 μ_f 的拓扑解释；Kähler 微分与余法向模的标准理论；Stanley 与 Watanabe 的强 Lefschetz 定理（用于反例中单项式完全交的 injectivity 验证）。
