# On a new class of $q$-fractional integral operators involving multivariate $q$-Mittag-Leffler functions

## 1.  核心定位

- **解决的问题**：在 $q$-分数阶微积分中，可供使用的良态 $q$-分数阶算子仍然很少；本文要基于 Luo-Zhou 框架定义一类新的、以多元 $q$-Mittag-Leffler 函数为积分核的 $q$-分数阶积分算子，并给出与之配套的 $q$-分数阶导数（含 $q$-Caputo 型）与显式可解性。
- **大图景位置**：这是经典分数阶微积分（特别是 Prabhakar 分数阶微积分）在 $q$-离散化框架下的对应物推广；同时是 Luo 与 Zhou 所提出"基于离散卷积可和性构造良态算子"方法论的具体实现与验证实例。
- **主要贡献**：1) 定义多元 $q$-Mittag-Leffler 函数 $E_{\bm{\rho},\lambda}^{\bm{\gamma}}(q;\bm{\omega};\mathbf{z},\mathbf{c})$，并给出其特殊化（$E_{\bm{\rho},\lambda}^{\bm{\gamma}}(q;\mathbf{z})$ 与核函数形式 $E_{\bm{\rho},\lambda}^{\bm{\gamma}}(q;\bm{\omega};z,c)$）；2) 定义以其为核的 $q$-分数阶积分算子 $E_{q;\bm{\rho},\lambda;(\bm{\omega})}^{\bm{\gamma}}$，构造左右逆并引入相应的 $q$-分数阶导数与 $q$-Caputo 导数；3) 借助 $q$-Laplace 变换对相关 $q$-分数阶微分方程的特征值问题给出显式解。
- **关键先驱工作**：Agarwal、Al-Salam 等开创的 $q$-分数阶微积分理论；Annaby-Mansour 专著；Kac-Cheung 与 Gasper-Rahman 的 $q$-级数工具；Riemann-Liouville 型 $q$-分数阶积分算子（Annaby-Mansour）；Prabhakar 分数阶微积分（Giusti 等）；Saxena-Kalla-Saxena 的多元 Mittag-Leffler 型分数阶积分算子；Shaimardan 等的 Prabhakar 型 $q$-分数阶积分算子。
- **结果边界**：定义均在 $0<q<1$、$\Re(\lambda)>0$、$\Re(\rho_j)>0$ 等正则性条件下成立；右连续于 $0$ 的条件扮演"在零处 $q$-正则"的角色，以保证 $I_qD_qf=f-f(0)$ 等互逆关系；核函数要求 $0\leq c_j<z_j$，超出该范围的算子行为不在本文讨论。
- **开放问题**：作者在结语中指出了若干进一步研究的方向，包括在本文 $q$-算子理论基础上构造更多良态算子、扩展 $q$-Caputo 型算子的应用场景，以及把相关结果推广到更一般的 $q$-级数设定。
- **应用与推广**：所定义的算子可用于求解一类 $q$-分数阶微分方程（作者已用 $q$-Laplace 变换给出特征值问题的显式解）；$q$-Caputo 导数已被用于推广 Tsallis 熵泛函（Gonzalez-Bayron），本文算子可作为类似非广延统计与记忆效应建模的新工具；多元 Mittag-Leffler 函数的经典对应物在广义 Mittag-Leffler 随机变量和的分布、分数阶 Cauchy 问题、分数阶 Poisson 过程中有应用，$q$-版本有望承载对应的离散化模型。
