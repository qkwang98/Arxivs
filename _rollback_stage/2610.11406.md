# A Counterexample to Left-Right Symmetry for Diagonal Auslander-Regularity

## 1.  核心定位

- **解决的问题**：Iyama 提出对角 Auslander-正则性是否左右对称的问题（artin 代数情形，Question 3.6.2），本文给出否定答案。
- **大图景位置**：Bass 定理刻画交换 Noether 环的 Gorenstein 性，Auslander 将相应条件推广为非交换情形并证明其左右对称（Auslander 条件）；Iyama 进一步引入右对角/左对角 Auslander-正则代数，并证明整体维数不超过 2 时左右对称。本文表明整体维数 3 时对称性破裂。
- **主要贡献**：
  - 构造有限维 Auslander-正则代数 $R$，满足 $\mathrm{gldim}\, R = 3$，右对角但非左对角；
  - 任意满足 $\mathrm{grade}\, S = i$ 的右单模 $S$ 均有 $\mathrm{pd}_R S = i$；
  - 存在一个左单模 $S'$，满足 $\mathrm{grade}\, S' = 1$ 而 $\mathrm{pd}_{R^{\mathrm{op}}} S' = 2$，直接破坏条件 $(*)$ 的左右对称性。
- **关键先驱工作**：Bass 的 Gorenstein 环判定定理；Auslander 的 Auslander 条件（左右对称）；Iyama 对对角 Auslander-正则 artin 代数在整体维数至多 2 时的左右对称定理（Theorem 3.4）及其关于 grade 为 0 的单模投射性的对称结果。
- **结果边界**：反例的整体维数为 3；对于整体维数不超过 2 的 artin 代数，Iyama 的正向结果依然成立。反例依赖具体的有限维代数构造，未表明更大类中对称性必然失败。
- **开放问题**：Iyama 所问更一般的条件 $(*)$（对 Auslander $n$-Gorenstein 环，$\mathrm{grade}\, S=i$ 的单模满足 $\mathrm{pd} S=i$）在 $n$ 充分大时是否左右对称，本文仅给出 $n=3$（整体维数 3）层面的反例，更大 $n$ 或更广环类的行为仍开放。
- **应用与推广**：该反例提示在 Auslander-正则代数的分类与不变量研究中不能想当然地左右对等；也为双模导出范畴、Cohen–Macaulay 模理论中的左右不对称现象提供实例支撑。
