# Categorified Cluster Structures on Coulomb Branches of Certain Star-Shaped Quivers

keywords: [量子簇代数, Coulomb 分支, Koszul-perverse heart, 幺半范畴化, K-理论, 变异]

## 1.  核心定位

- **解决的问题**：为星形箭图规范数据 $GL_2\times(\C^*)^r$ 在 $GL((\C^2)^r)$ 中的像 $\G_r$ 所对应的量子化 $K$-理论 Coulomb 分支构造量子簇结构，并证明其 graded Koszul-perverse heart $\mathcal{C}_r^q$ 是相应量子簇代数的幺半范畴化。
- **大图景位置**：这是量子簇代数与几何表示论交叉处的重要推广：把 Cautis--Williams 关于 $K$-理论 Coulomb 分支的 Koszul-perverse $t$-结构与 Fock--Goncharov 型量子簇结构系统地联系起来，同时推广了作者博士论文中的结果。
- **主要贡献**：① 构造显式的相容对 $(\Lambda_r,\widetilde B_r)$（$r+2$ 个可变异方向、$r$ 个可逆 frozen 方向），使量子簇代数同构于 Grothendieck 环 $K_0(\mathcal{C}_r^q)$；② 证明每个量子簇变量由实单 Koszul-perverse 对象表示，每个量子簇单项式由单的规范化卷积积表示；③ 证明每个有限变异序列由量子幺半种子与短正合列实现，从而 $\mathcal{C}_r^q$ 成为局部化量子簇代数的幺半范畴化；④ 证明整量子等式 $\mathcal{A}=\mathcal{U}$（frozen 变量取逆），覆盖 $r=4$ 的四穿孔球面 mutation 型 $D_4^{(1,1)}$ 与 $r\geq5$ 的 mutation-infinite 情形。
- **关键先驱工作**：Cautis--Williams 的 Koszul-perverse heart 与 renormalized $r$-matrices（CW23）、Braverman--Finkelberg--Nakajima 的 Coulomb 分支理论（BFN18）、Schrader--Shapiro 的 Whittaker 变换与量子环面（SS19）、Berenstein--Zelevinsky 的量子簇代数与 upper bound 定理（BZ05）。
- **结果边界**：结果对每个 $r\geq1$ 成立，但变异定向限制于该星形箭图族；Schrader--Shapiro 量子环面到本文相容对的识别依赖于强制为奇的二次 refinement，偶数符号赋值被排除；未推广到更一般的规范群或非星形箭图。
- **开放问题**：将类似构造推广到其他规范群与箭图族；澄清在 $r=4$ 之外各 frozen 变量的几何解释；将幺半范畴化提升为更精细的范畴等价（如导出等价意义下的范畴化）。
- **应用与推广**：为 $K$-理论 Coulomb 分支提供 cluster 坐标系，可用于研究其上的量子乘法、BPS 态与 stable envelope 结构；幺半范畴化的变异短正合列可用于构造正基与典范基；$r=2$ 的环面（仿射型 $A_3^{(1)}$）情形给出弧与单对象、交换序列的显式字典。
