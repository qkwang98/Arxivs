## 1.  核心定位

- **解决的问题**：对小有限群 $G$ 作用在 Cohen--Macaulay 正规整环 $S$ 上的情形，$G$-等变 NCCR 与 $G$-MM 模在商环 $S^G$ 上如何诱导 NCCR、MM 模与 MMA；并为非 Gorenstein 三维奇点建立 MMA 存在性（非交换 minimal model 理论）与 MMA 派生等价（非交换 Bondal--Orlov 猜想）的新实例。
- **大图景位置**：NCCR 是 crepant resolution 的非交换环模拟（van den Bergh），MMA 是 minimal model 的非交换模拟（Iyama--Wemyss）。DITW 仅处理 canonical cover 诱导的循环群作用（Gabriel cover 方法），本文将其推广到任意小有限群作用，并推进三维非交换 Bondal--Orlov 猜想向非 Gorenstein 情形（指数二终端奇点）的扩展。

- **关键先驱工作**：van den Bergh 的 NCCR；Iyama--Wemyss 的 MMA 及其与三维 minimal model 的派生等价对应；Dao--Iyama--Takahashi--Wemyss 的 $\Q$-Gorenstein 条件与 canonical cover 等价刻画；Mori 对终端三维簇局部模型的六类分类（$cA/r$、$cAx/2$、$cAx/4$、$cD/2$、$cD/3$、$cE/2$）；Iyama--Wemyss 在 Gorenstein 情形对非交换 Bondal--Orlov 猜想的证明。
- **结果边界**：一般小群作用下 $\varphi_*\colon G\text{-}\NCCR S\to\NCCR R$ 仅为单射、一般不双射（双射性依赖 canonical cover 结构）；定理 intro main 3 要求修改模范畴的稠密性假设；MMA 派生等价限于 Gorenstein MMA；三维终端奇点应用限于指数二（含 canonical cover 奇异的情形），指数更高的类型（如 $cA/r$、$cAx/4$、$cD/3$）仍未解决。
