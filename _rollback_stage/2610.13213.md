# Haar measure for totally positive split real semisimple quantum groups of classical type

## 1.  核心定位

- **解决的问题**：对经典型（$\mathfrak{sl}_N,\mathfrak{so}_N,\mathfrak{sp}_N$）分裂实单 Lie 群的全正半群 $G^+$，构造积分 Drinfeld–Jimbo 量子包络代数的 Borel 部分 $U_q(\mathfrak{b}_{\mathbb{C}})$（$|q|=1$、分裂实结构）的局部紧量子群，并计算其 Haar 权与模数据。
- **大图景位置**：将 De Commer 等人（DCSSV25）关于 $SL_N^+(\mathbb{R})$ 的量子化从 A 型推广到全部经典型（$SO_{n,n}^+(\mathbb{R}),SO_{n,n+1}^+(\mathbb{R}),Sp_n^+(\mathbb{R})$）；同时把 Ip 正表示论中的代数计算置于严格的算子代数（解析）基础之上。
- **主要贡献**：(1) 对任意 $\hbar\in\mathbb{R}^{\times}$（包括 $q=e^{-\pi i\hbar}$ 为单位根的情形）构造局部紧量子群 $(L_\hbar(B),\Delta)$，其 von Neumann 代数由仿射正无界算子 $\widehat{E}_i,\widehat{K}_i$ 生成，满足 $\Delta(\widehat{K}_i)=\widehat{K}_i\otimes\widehat{K}_i$、$\Delta(\widehat{E}_i)=\widehat{E}_i\otimes 1\boxplus\widehat{K}_i\otimes\widehat{E}_i$（$\boxplus$ 为正算子 form sum）；(2) 基于 Feigin 表示建立 von Neumann 代数量子环面框架，提炼 integrability 与 full exchangeability 两个充分条件；(3) 证明经典 Cartan 数据的最长字满足这两个性质，从而完成构造，并计算相应的 Haar 权与模数据。
- **关键先驱工作**：Kustermans–Vaes 的局部紧量子群公理化；Drinfeld–Jimbo 量子包络代数；Lusztig 的全正理论；De Commer 等人对 $SL_N^+(\mathbb{R})$ 的量子化（DCSSV25）；Ip 的正表示论系列；量子指数函数（Wor00）；modular double 量子群（Fad00,KLS02,BT03）。
- **结果边界**：经典极限（$q\to 1$）的严格意义验证超出本文范围；仅量化 $G^+$ 的负 Borel 部分 $B_-$，整体量子群需经 Drinfeld double 构造；例外型中 $F_4,E_8$ 的 integrability 尚不清晰、$G_2$ 的 full exchangeability 需要更多技术工作。
- **开放问题**：经典极限下量子化的严格刻画；$F_4,E_8$ 的 integrability 与 $G_2$ 的 full exchangeability；与 modular double / Langlands 型对偶 $\hbar\leftrightarrow\hbar^{-1}$ 的更深入联系。
- **应用与推广**：为全正分裂实量子群提供局部紧量子群框架，可统一群作用、Fell 丛、交叉积算子代数与 Takesaki–Takai 对偶等构造；为量子簇代数的解析理论提供 von Neumann 代数模型；附录中 type B 的 Kashaev 五边形方程证明可迁移到其他算子代数设定。
