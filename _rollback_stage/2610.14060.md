# Linear maps preserving the matrix discriminant. An enhanced approach

keywords: [矩阵判别式, 线性保持子, 特征多项式, 线性映射, 矩阵不变量]
related_paper: "Pierce (1979) 关于保持矩阵判别式的线性映射的经典刻画；作者前作 Yurkov2025"
one_liner_summary: 本文在基域足够大（$|F|>n(n-1)$）且 $n\ge3$ 的条件下完整刻画保持矩阵判别式（特征多项式判别式）的线性映射，将其分为相似共轭加线性泛函项与转置变体两类，把此前仅适用于无限域的结果推广到有限域以及特征整除矩阵阶数的情形，并引入对线性保持子理论具有独立价值的新不变量。

## 1.  核心定位

- **解决的问题**：刻画保持矩阵判别式（即特征多项式判别式）的所有线性映射 $T:\M_n(F)\to\M_n(F)$。
- **大图景位置**：属于线性保持子问题（linear preserver problem）谱系——自 Frobenius (1897) 刻画行列式保持线性映射以来，本文将 Pierce (1978) 对矩阵判别式的经典结果从无限域推广到有限域，并首次覆盖 $\Char(F)$ 整除 $n$ 以及 $n<6$ 的情形，从而对足够大基域和所有可能的 $n$ 完整解决该问题。
- **主要贡献**：1) 在 $n\ge3$、$|F|>n(n-1)$ 时证明保持矩阵判别式的线性映射必为 $T(X)=cM^{-1}XM+\alpha(X)I_n$ 或 $T(X)=cM^{-1}X^tM+\alpha(X)I_n$（其中 $c^{n(n-1)}=1$，$M$ 可逆，$\alpha$ 为线性泛函）；2) 引入在保持给定多项式的所有双射线性映射作用下不变的新不变量，具有独立理论价值；3) 处理 $\Char(F)$ 整除 $n$ 的困难情形，并指出 $n=2$、$\Char(F)=2$ 时存在不符合上述描述的例外映射。
- **关键先驱工作**：Frobenius (1897) 的行列式保持定理；Pierce (1978/1979) 的矩阵判别式保持刻画；作者前作 Yurkov2025 对矩阵判别式工作的改进与修正；YurkovPolyPres2026 中多项式保持映射的不变量方法。
- **结果边界**：要求 $n\ge3$ 且 $|F|>n(n-1)$；$n=2$ 且 $\Char(F)=2$ 时存在反例；$n=1$ 时判别式恒为 1，问题平凡；小域（$|F|\le n(n-1)$）的情形尚未完全处理。
- **开放问题**：对于 $|F|\le n(n-1)$ 的小基域，保持矩阵判别式的线性映射能否给出类似的完整分类？$n=2$ 且特征为 2 的例外是否唯一、能否纳入统一框架？
- **应用与推广**：矩阵判别式指示特征值是否互异，相关保持结果可用于量子信息论、算子理论与泛函分析中的不变量问题；新引入的不变量有望推广到其他多项式保持问题的研究。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 暂无匹配的已有笔记。
- 技术迁移：作者引入的「保持给定多项式的双射线性映射作用下的不变量」能否用于行列式、积和式（permanent）、谱半径等其他矩阵不变量的保持问题？

### 2.2.  可以尝试的方向

- [ ] 将完整刻画推广到 $|F|\le n(n-1)$ 的小基域，或证明存在更多例外类？
- [ ] 新不变量能否直接给出其他多项式（如非交换多项式、对称多项式）保持线性映射的分类工具？

### 2.3.  批判性思考

- 证明依赖「$\deg_\lambda\D(A+\lambda X)\le 2n-2$ 对所有 $A$ 成立」与「$X$ 是数量矩阵与秩一矩阵的线性组合」这一特征刻画，其例外情形（$n\le5$）的处理是否已完全穷尽？
- 主定理要求 $c^{n(n-1)}=1$ 而非 Pierce 定理中的 $c^n=1$，这一放宽来自判别式的齐次性质；是否存在更一般的原则可以统一这些系数条件？
