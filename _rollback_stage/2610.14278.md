# Representation homology of involutive algebras and hyperoctaherdral homology

keywords: [表示同调, 超八面体同调, 对合代数, 交叉单纯群, Dold-Thom 空间]
related_paper: "2610.13488"
one_liner_summary: "将表示同调理论推广到对合代数，证明特征 0 域上超八面体同调同构于一维对合表示同调，并由此显式计算包络代数、对称代数与群代数的超八面体同调。"

## 1.  核心定位

- **解决的问题**：为对合代数（带对合反自同构的结合代数）建立对合表示同调理论，并利用它计算此前难以处理的超八面体同调。
- **大图景位置**：这是作者此前把对称同调与表示同调建立同构（BR22c）的对合版本推广；超八面体同调是交叉单纯群框架下最普适的同调理论，本文为其在特征 0 下提供了可计算的代数刻画。
- **主要贡献**：
  1. 定义对合代数的 $n$ 维对合表示同调，并构造导出特征映射将二面体同调映射到对合表示同调；
  2. 主定理：特征 0 域上，任意单纯对合代数的超八面体同调与其一维对合表示同调同构（作为分级交换代数）；
  3. 应用：显式计算对合 DG Lie 代数包络代数、$\mathrm{Sym}(V)$、$U\mathfrak{gl}_n(k)$、$U\mathfrak{sl}_n(k)$ 的超八面体同调；对群代数证明 ${\rm HO}_\bullet(k[\Gamma]) \cong k[H_1(B\Gamma; \mathbb{Z}/2)]$，从而正度全部消失。
- **关键先驱工作**：Berest–Khachatryan–Ramadoss 的表示同调理论；BR22c 与 BR22（对称同调与表示同调同构、Dold-Thom 同调刻画）；Fiedorowicz–Loday 的交叉单纯群框架；Graves 对超八面体同调的系统研究；Ault 对对称同调的早期计算。
- **结果边界**：主定理要求基域特征 0；群代数正度消失的结论亦仅对特征 0 成立；Theorem Tgroups 对任意交换环成立，但用于对合代数时需特征 0；论文标题中 hyperoctahedral 拼写为 hyperoctaherdral（原文如此）。
- **开放问题**：非特征 0 或一般交换环基域上的系统计算；超八面体同调在拓扑与谱细化（Angelini-Knoll 等的工作）下的对应版本；进一步推广到其他交叉单纯群对应的同调理论。
- **应用与推广**：提供了计算超八面体同调的实用工具，可迁移到纽结理论中的 skein 代数（历史动机）、李代数包络代数的同调，以及群同调与 Dold-Thom/McCord 空间的联系。
