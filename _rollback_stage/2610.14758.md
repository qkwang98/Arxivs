# Clifford Invariants and Three-Copy Quantum Tests

keywords: [Clifford group, qutrit, three-copy twirl, stabilizer states, discrete Wigner function, unitary 3-design, quantum Boolean functions, character table]
related_paper: "Gross--Nezami--Walter, Schur--Weyl duality for Clifford groups"
one_liner_summary: 对 $n\ge2$ 个 qutrit 上 Clifford 表示的第三张量幂给出自包含分解（五个不等价不可约分量，重数 $1,1,1,1,2$），将 Clifford twirl 降至四个实参数，并据此分类不变量子布尔函数、给出稳定子测试与未知可观测量测试的拷贝与查询复杂度界。

## 核心定位

- **解决的问题**：$n\ge2$ 个 qutrit 上 Clifford 群第三张量幂的结构与由其控制的三拷贝测量统计：分解、不变量、twirl 参数化、稳定子保真度界与测试复杂度。
- **大图景位置**：本文自包含地推导 Gross--Nezami--Walter（gnw21）Example 4.26 的五分量分解并显式构造投影子与等价拷贝间的缠结子；同时恢复并精确比较 Zhu--Mao--Yi（zmy24）关于纯态 Clifford 轨道第三矩的 $q\in[0,3^{-n}]$ 结果与复射影 3-design 判据。
- **主要贡献**：
  1. 显式分解与交换子计算：第三张量幂含五个不等价不可约分量，重数 $1,1,1,1,2$；交换子计算将 zhu17 与 gnw21 的辛轨道方法特化到 Weyl 标号有序对，并给出二拷贝等价分量的投影子与缠结子。
  2. 不变量理论：trace-one Hermitian 矩阵上次数不超过 $3$ 的 Clifford 不变多项式以 $1,t_2,t_3,u,v$ 为基，四个非常值函数代数独立（附录 Jacobian 计算）但不可分离 Clifford 轨道；纯态情形单个参数 $q$ 即足够，恢复其值域、达到极值的族（稳定子态）与复射影 3-design 判据。
  3. 测量与测试：分类 Clifford 与三拷贝置换双不变的量子布尔函数，可用五输出扇区测量实现；给出稳定子测试与未知可观测量测试的显式拷贝与查询复杂度界，及重复三拷贝批次的保真度下界；证明非平凡完全三拷贝稳定子测试不可能。
  4. 有限射影 Clifford 群：$G_n=V_n\rtimes\operatorname{Sp}(2n,3)$ 的 little-group 参数化、不可约特征标度数的递推公式，并给出两 qutrit 的完整特征标表。
- **关键先驱工作**：Gottesman--Knill 定理与 tableau 算法；Gross 的有限维 Hudson 定理（非负离散 Wigner 函数刻画纯稳定子态）；Clifford 群为酉 2-design 而 qutrit 非 3-design 的结果（Zhu）；Gross--Nezami--Walter 的 Clifford 群张量幂 Schur--Weyl 对偶与有限几何方法；Zhu--Mao--Yi 的 qutrit 第三矩；Bolt--Room--Wall 的奇特征 Clifford 群结构、GAP 特征标表库。
- **结果边界**：$d=3$、$n\ge2$（qutrit）；张量幂次数为三；对 $d>3$ 或更高张量幂结论不直接成立。Clifford 群因含全部标量酉而无限，须经有限射影商 $G_n$ 处理；代数独立性依赖附录中显式 Jacobian 计算。
- **开放问题**：文中未显式列出开放问题；自然延伸包括更高局部维数或更高张量幂的类似不变量分类、完全三拷贝稳定子测试不可能性的边界强度、以及四拷贝测试（gnw21）与本文方法的互补。
- **应用与推广**：为稳定子框架中的资源理论（Wigner 负性、magic）与随机基准测试提供三拷贝统计的完整不变量描述；五输出扇区测量与量子布尔函数分类可直接用于稳定子测试协议设计与未知通道、可观测量查询的复杂度下界。

### 批判性思考

- 交换子计算特化自 zhu17 与 gnw21 的辛轨道方法，自包含性依赖显式投影子构造；该方法对 $d=3$ 之外素数的可移植性未被本文讨论。
- 标量相位处理（用有限升 $\widetilde G_n$ 定义张量立方再下降）是本文技术关键；其对无限 Clifford 群上更高次张量幂是否同样可行值得检验。
