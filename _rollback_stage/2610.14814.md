# A counterexample to the TF-cone conjecture

keywords: [TF 等价, 典范分解, τ-tilting 理论, 双 term silting 复形, Kronecker 代数, 通有不可分解]
related_paper: "Asai–Iyama 的 TF-cone 猜想（Conjecture 1.2，本文所反驳的原猜想）"
one_liner_summary: "在三箭头 Kronecker 代数与单箭头路代数的张量积上，构造权重 $w$ 使其 TF 等价类为二维开锥 $\mathbb{R}_{>0}p+\mathbb{R}_{>0}q$，而所有正整数倍 $mw$ 通有不可分解、典范分解仅含单个和项，从而锥退化为一射线，同时推翻 Asai–Iyama 猜想与 Haerizadeh–Yassemi 相对内部版本。"

## 核心定位

- **解决的问题**：验证 Asai 与 Iyama 提出的 TF-cone 猜想是否成立——对任意有限维基本代数，整数权重 $g$ 的 TF 等价类是否等于其所有正倍数典范和项所生成的开锥 $\Cone^\circ(\ind(\mathbb{N}g))$。
- **大图景位置**：TF 等价类是 $\tau$-tilting 理论中把实数权重按其半稳定 torsion pairs 分组的工具，刻画了两-term silting 复形 chamber 之外的区域。本文给出该猜想在无限型（$\tau$-tilting 无限）代数上的反例，划定其成立边界。
- **主要贡献**：1) 构造反例代数 $A=B\otimes_k k(s\to t)$（$B$ 为三箭头 Kronecker 代数）与权重 $w=p+q$；2) 证明 $[w]_{\mathrm{TF}}= [w]_{\mathrm{TF}}^\circ=\mathbb{R}_{>0}p+\mathbb{R}_{>0}q$ 为二维开锥，而 $\ind(mw)=\{mw\}$、$\Cone^\circ(\ind(\mathbb{N}w))=\mathbb{R}_{>0}w$ 仅为单射线；3) 同一例子同时推翻 Haerizadeh–Yassemi 的相对内部版本猜想。
- **关键先驱工作**：Kac 与 Schofield 的维度向量典范分解及其算法；Derksen–Fei 将典范分解推广到固定投射模间表示的投射 Grothendieck 群类；King 数值半稳定与 GIT moduli；Asai 的 TF 等价及其与 $\tau$-tilting 的腔室定理（Brüstle–Smith–Treffinger）；Asai–Iyama 的包含关系 $\Cone^\circ(\ind(g))\subseteq [g]_{\mathrm{TF}}$。
- **结果边界**：反例依赖射线条件（ray condition）的失效；对遗传代数与 $E$-tame 代数等式仍成立，因此该猜想仅对满足射线条件的代数类保持。
- **开放问题**：TF 等价类由典范分解决定的充要条件是什么？哪些代数满足射线条件，能否给出系统刻画？Haerizadeh–Yassemi 版本在何种额外假设下成立？
- **应用与推广**：对 $\tau$-tilting 无限型代数的 $g$-向量锥几何、chamber 之外区域的描述策略提出警示；构造 brick 并借最小投射分解与自同态维数上半连续证明通有不可分解的技术，可用于一般权重的不可分解性判定。

## 主动思考区

### 与其他工作的联系

- 这让我想起：表示有限代数与 $\tau$-tilting 有限代数的整体同调性质 — 见 [[2610.14638]]
- [[2610.14638]]：Cartan 行列式猜想针对 representation-finite（即 $\tau$-tilting 有限）代数；本文反例正落在 $\tau$-tilting 无限情形，二者共同勾勒出有限与无限型代数的分水岭。
- [[2610.14420]]：该文在 tensor triangulated category 中借助 compact tilting generator 研究同调维数；本文的权重 $w$ 与典范分解则完全脱离 tilting/silting 对象的锥覆盖情形，说明 chamber 之外的结构需独立工具。
- 技术迁移：以「构造 brick + 最小投射分解 + 自同态维数上半连续」证明通有不可分解的策略，可迁移到其它带关系箭图的 $g$-向量不可分解性判定问题。

### 可以尝试的方向

- [ ] 能否将反例推广到 $n$ 箭头 Kronecker 代数与更一般张量积代数，考察锥退化与射线条件失效的系统规律？
- [ ] 是否可加强结论：在 $A$ 上给出更多权重使 $\Cone^\circ(\ind(\mathbb{N}g))$ 与 $[g]_{\mathrm{TF}}$ 维数差任意大？

### 批判性思考

- 证明对「通有」表示（非空 Zariski 开集上的性质）的依赖是否掩盖了非一般表示处的异常行为？作者通过逐 $m$ 构造 brick $M_m$ 并利用上半连续补足了这一缺口，但该论证是否对 $m$ 的算术性质敏感值得细察。
- 是否有更范畴化的路线直接计算 TF 等价类（不借助逐正倍数砖的构造），例如通过 torsion pairs 的格论结构？
