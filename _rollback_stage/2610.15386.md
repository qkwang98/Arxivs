# Cohen-Macaulay truncated path and Nakayama algebras

keywords: [Cohen-Macaulay 代数, truncated path 代数, Nakayama 代数, 对偶模, Iwanaga-Gorenstein 代数, Auslander-Reiten 理论]
related_paper: "The Cartan determinant conjecture for representation-finite algebras over perfect fields（2610.14638）"
one_liner_summary: 本文在 Auslander-Reiten 意义下完整刻画了 truncated path 代数与 Nakayama 代数中的 Cohen-Macaulay 代数，证明前者 Cohen-Macaulay 当且仅当其箭图是 balanced（此时 $\Lambda$ 或 $D(\Lambda)$ 给出对偶模），后者 Cohen-Macaulay 当且仅当 Iwanaga-Gorenstein，从而这两类代数中不存在非平凡的 Cohen-Macaulay 代数。

## 核心定位

- **解决的问题**：刻画有限维代数两大自然类——truncated path 代数 $\Lambda=KQ/\langle \text{所有长度 }L+1\text{ 的路径}\rangle$（$L\geq 1$，$Q$ 连通箭图）与 Nakayama 代数——中哪些是 Auslander-Reiten 意义下的 Cohen-Macaulay 代数。
- **大图景位置**：交换 Cohen-Macaulay 环的非交换类比研究：Sharp 建立的对偶模等价被 Auslander-Reiten 推广为 artin 代数上的 Cohen-Macaulay 性；本文为两类具体代数类给出完整分类，直接回答"是否存在非平凡 Cohen-Macaulay 代数"这一自然问题。
- **主要贡献**：1) 引入 balanced quiver 概念，证明连通 truncated path 代数 $\Lambda$ 是 Cohen-Macaulay 当且仅当 $Q$ 是 balanced，且此时 $\Lambda$ 或 $D(\Lambda)$ 给出对偶模（$D$ 为 Matlis 对偶）；2) 证明 Nakayama 代数 Cohen-Macaulay 当且仅当 Iwanaga-Gorenstein，此时总可取 $\Lambda$ 自身为对偶模；3) 推论 truncated path 与 Nakayama 代数中无平凡对偶模之外的非平凡 Cohen-Macaulay 代数，并证明 truncated path 代数中的 minimal Auslander-Cohen-Macaulay 代数恰为 minimal Auslander-Gorenstein Nakayama 代数。
- **关键先驱工作**：Sharp 的交换局部环对偶模等价定理；Auslander-Reiten 引入 Cohen-Macaulay 代数与对偶模；Chan-Iyama-Marczinzik 关于 radical square zero truncated path 代数（无源无汇箭图）为 Cohen-Macaulay 的例子；Iyama-Solberg 的 minimal Auslander-Gorenstein 代数理论。
- **结果边界**：连通性假设仅用于简化陈述（非连通箭图情形另有处理）；对偶模作为单边模唯一、作为双模不唯一，分类结论只针对 truncated path 与 Nakayama 两类代数，不覆盖一般 artin 代数；radical square zero 情形对应 $L=1$。
- **开放问题**：寻找对偶模（视为单边模）含非投射非内射直和项的非平凡 Cohen-Macaulay 代数仍是开放方向（已知仅有 Nishida 例子及部分 contracted preprojective 代数）；最小 Auslander-Cohen-Macaulay 类在其他代数类中的刻画未展开。
- **应用与推广**：为有限维代数的同调维数与 Gorenstein 性质提供可组合验证的判据；balanced 箭图的组合条件可用于快速排除非 Cohen-Macaulay 情形；最小 Auslander-Cohen-Macaulay 与 Nakayama 结构的对应可用于表示型分类与稳定范畴研究。

- 技术迁移：balanced 箭图这一组合判据可迁移到其他由箭图/位形定义的代数类（如 string algebras、special biserial algebras）的 Cohen-Macaulay 性判定。
