# A trace Paley-Wiener theorem for $\mathrm{GL}_{n}(F)\backslash \mathrm{GL}_{n}(E)$, with $E/F$ a quadratic extension of non-Archimedean local fields

keywords: [相对 Langlands 纲领, trace Paley-Wiener 定理, 对称空间, 相对 Bessel 分布, Bernstein 中心, base change, 相对迹公式]
related_paper: "Multiplicity One and van Dijk's Conjecture for Connected Complex Symmetric Spaces（2610.14540）"
one_liner_summary: 本文将 Bernstein-Deligne-Kazhdan 的约化 $p$-adic 群上 trace Paley-Wiener 定理推广到对称空间 $\mathrm{GL}_n(F)\backslash \mathrm{GL}_n(E)$（$E/F$ 为二次非 Archimedean 局部域扩张），证明 $\mathrm{GL}_n(F)$-distinguished tempered 表示上相对 Bessel 分布 $I_\pi(f)$ 的函数空间经 base change 同构于拟分裂酉群 $U(n)$ 的 generic Bernstein 中心 $\mathfrak{Z}_{\mathrm{gen}}(U(n))$。

## 核心定位

- **解决的问题**：对对称空间 $\mathrm{GL}_n(F)\backslash \mathrm{GL}_n(E)$ 建立标量型 trace Paley-Wiener 定理：确定相对特征标（相对 Bessel 分布）$\pi\mapsto I_\pi(f)$（$f\in C_c^\infty(G)$）的取值空间，并将其描述为 $U(n)$ 的 generic Bernstein 中心。
- **大图景位置**：相对 Langlands 纲领中 Sakellaridis-Venkatesh 猜想断言相对特征标的极点与球性簇局部 $L$-因子的极点相关；本文为特定对称空间提供谱侧的精确调和分析输入，是相对迹公式谱展开与几何展开比较的关键构件。
- **主要贡献**：1) 主定理：$\{\pi\in \mathrm{Temp}_H(G)\mapsto I_\pi(f)\}\cong \mathfrak{Z}_{\mathrm{gen}}(U(n))$，等价地经 base change 用 $\mathrm{Temp}_{\mathrm{gen}}(U(n))$ 参数化；2) 构造并利用 base change 映射 $BC_n:\mathrm{Temp}(U(n))\to\mathrm{Temp}(G)$（$n$ 奇时稳定、偶时不稳定），在 generic 表示与 $H$-distinguished tempered 谱间建立双射；3) 为相对 Kuznetsov 迹公式提供谱局部转移，可能用于 Lapid-Mao 关于 Fourier-Whittaker 系数的猜想（Ichino-Ikeda 精神下的显式公式）。
- **关键先驱工作**：Bernstein-Deligne-Kazhdan 的群上 trace Paley-Wiener 定理；Delorme-Harinck-Sakellaridis 的球性簇 Schwartz 空间矩阵型 Paley-Wiener 定理；Bernstein 中心理论；$\mathrm{GL}_n(F)\backslash \mathrm{GL}_n(E)$ 的 Plancherel 分解；局部 Langlands 对应及由 $U(n)$ 诱导的 base change 映射。
- **结果边界**：定理仅对 $H=\mathrm{GL}_n(F)$、$G=\mathrm{GL}_n(E)$ 这一特定对称空间成立；$BC_n$ 的稳定/不稳定性质依赖 $n$ 的奇偶；谱范围限定为 tempered、$H$-distinguished、generic 表示；证明依赖 Bernstein 中心、Plancherel 分解与局部 Langlands 对应等重工具。
- **开放问题**：将标量型 trace Paley-Wiener 推广到其他对称空间或一般球性簇；Lapid-Mao 猜想的全局应用（全局 Whittaker 周期与 $L$-函数特殊值的显式公式）尚未展开。
- **应用与推广**：标准化相对迹公式的谱侧输入，支撑谱展开与轨道积分的比较；为局部相对特征标极点与 $L$-因子极点的对应提供可检验实例；可用于相对 Langlands 纲领中 periods 与 $L$-函数联系的数值与结构研究。
