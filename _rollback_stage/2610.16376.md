# Track objects in cubical presheaf automata

keywords: [presheaf 自动机, 高维自动机, 并发理论, track objects, c-集合, d-余完备化]
related_paper: "Presheaf automata（文中引用 `SZ_Presheaf-Automata`，本文所采用的形式化框架）"
one_liner_summary: "在 presheaf 自动机框架下引入新的并发自动机类（含混合 HDA），并证明其语言可由区间 poset 的 cospan 刻划，从而将经典 HDA 中 track objects 与区间 ipomsets 的对应推广到对称 HDA 等更广模型。"

## 核心定位

- **解决的问题**：为高维自动机（HDA）及其变体（对称 HDA、混合 HDA）建立统一的语言理论，特别是给出 track objects 的组合描述，弥补 presheaf 自动机框架下 track objects 缺乏 poset 描述的问题。
- **大图景位置**：是 FJSZ 等人近期发展的 HDA 形式语言理论（含 Kleene 定理、Myhill–Nerode 类比等经典定理类比）的推广与范畴化：用 presheaf 自动机统一 HDA 类模型，并将语言刻画为区间 c-poset 上的 cospan。
- **主要贡献**：1) 引入 c-集合与 c-poset 两个新的有向范畴作为变体 precube 范畴的基范畴，证明二者中存在有向推出（但包含 $\cSet\subset\cPos$ 不保持它们）；2) 发展 d-余完备化理论，证明 Yoneda 嵌入可全忠实延拓到 d-余完备化且保持有向推出，从而 track objects 可构造为其中的有向 cospan；3) 主定理：对任何 sieve $\cV\hookrightarrow\lecSet$，track objects 与区间 $\cV$-poset 的有向 cospan 之间是双范畴的 biequivalence，并由此给出对称 HDA 等模型语言的显式描述。
- **关键先驱工作**：Pratt 的高维自动机模型；FJSZ 的 HDA 语言理论、Kleene 定理与正则语言类比；Gaucher、Kahl、Zouari 等人的对称 HDA 工作；presheaf 自动机框架（文中引用 `SZ_Presheaf-Automata`）。
- **结果边界**：语言描述要求基范畴为 precube 型且 sieve 对子对象封闭；track objects 对应的是脚为可表示 presheaf 的区间 cospan；包含 $\cSet\subset\cPos$ 不保持有向推出，说明结果对范畴选择敏感。
- **开放问题**：作者未在导言中显式列出开放问题，但框架的自然后续包括：将 Kleene 定理与 Myhill–Nerode 类比推广到混合 HDA、对更广的 sieve 给出语言刻画、研究 d-余完备化在其他有向范畴构造下的保持性。
- **应用与推广**：为并发系统的建模与验证提供新的自动机类；语言刻画可辅助比较 HDA、对称 HDA 与其他并发模型（Petri 网、事件结构）的表达力；d-余完备化技术可用于其他基于有向范畴的自动机理论。

## 主动思考区

### 与其他工作的联系

- 这让我想起：范畴化的自动机理论——用有向范畴上的 presheaf 与 cospan 语言统一经典自动机与并发模型，与笔记库中若干范畴论主题相邻但不直接对应。
- 暂无匹配的已有笔记：笔记库中未找到与 presheaf 自动机、高维自动机直接相关的主题笔记。

### 可以尝试的方向

- [ ] 能否在混合 HDA 上建立 Kleene 定理与 Myhill–Nerode 类比的完整版本？
- [ ] 区间 $\cV$-poset cospan 的刻画能否导出更简单的语言成员判定算法？
- [ ] 能否将 d-余完备化理论应用到其他代数结构（如高阶范畴、operad）的自动机模型中？

### 批判性思考

- track objects 与区间 cospan 的 biequivalence 依赖 sieve 封闭条件，该条件能否放宽值得考察。
- "混合 HDA"是否覆盖 HDA 与对称 HDA 的全部重要实例，需逐一核对各 precube 型变体。
- 有向推出存在性的要求较强，某些实际并发模型（如带优先级的事件结构）可能不满足，语言理论的应用边界有待澄清。
