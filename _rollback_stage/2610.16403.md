# Ideal quotients of $n$-exact categories

keywords: [n-exact category, 理想商, 可移除子范畴, Frobenius 范畴, cluster tilting]
related_paper: "Demonet--Iyama 关于理想商继承精确结构的定理"
one_liner_summary: "本文将可移除子范畴的概念推广到 n-exact 范畴，证明沿投射-内射子范畴做理想商后继承 n-exact 结构当且仅当该子范畴可移除，并给出 Frobenius 情形、cluster tilting 相容性及 Geigle--Lenzing 射影平面上的应用。"

## 核心定位

- **解决的问题**：刻画 n-exact 范畴沿投射-内射子范畴 $\mathscr{F}$ 做理想商 $\mathscr{C}/[\mathscr{F}]$ 后何时继承 n-exact 结构，并处理 Frobenius 情形下的 $(n+2)$-角化等价。
- **大图景位置**：n-exact 范畴是 Jasso 提出的高阶同调代数框架（$n=1$ 时恢复 Quillen 精确范畴），其 Frobenius 稳定范畴带自然的 $(n+2)$-角化结构。本文填补了 Herschend--Liu--Nakaoka 的 n-exangulated 商准则不保持 n-exact 结构的空白，给出 n-exact 范畴理想商的直接处理。
- **主要贡献**：(1) 定理 A：$\mathscr{F}$ 可移除当且仅当 $(\mathscr{C}/[\mathscr{F}],\mathscr{X}_{\mathscr{F}})$ 是 n-exact 范畴，此时 $\pi_{\mathscr{F}}$ 诱导 $\nExt^1$ 群同构；Frobenius 情形商仍 Frobenius，投射-内射子范畴恰为 $\mathscr{P}/[\mathscr{F}]$，并诱导 $(n+2)$-角化等价。(2) 定理 B：理想商构造与 n-cluster tilting 相容，构造图可交换。(3) 定理 C：对 Geigle--Lenzing 射影平面上的 ACM 丛范畴的 2-cluster tilting 子范畴，自然与相对 2-exact 结构均给出理想商构造。
- **关键先驱工作**：Quillen 精确范畴；Jasso 的 n-exact 范畴与 n-cluster tilting 构造（含 Kvamme 修正）；Herschend--Liu--Nakaoka 的 n-exangulated 范畴；Demonet--Iyama 的精确范畴理想商准则；Chen 的 Frobenius 商充分条件；Geiss--Keller--Oppermann 的 $(n+2)$-角化范畴。
- **结果边界**：HZZ 的反例表明一般 n-exangulated 商不必是 n-exact；本文限定 $\mathscr{F}\subset\mathscr{P}\cap\mathscr{I}$ 并直接验证商公理；用 $(\mathrm{EC}')$ 与 $(\mathrm{EI})$ 取代弱同构封闭性，后者直接验证困难。
- **开放问题**：相对 2-exact 结构 $\mathscr{X}^{\mathrm{rel}}$ 与自然结构相等当且仅当 $\min\{p_1,p_2,p_3\}=2$ 的判据提示，一般权型的自然商与相对商结构差异需要进一步刻画。
- **应用与推广**：可应用于 cluster tilting 理论中商范畴的高阶同调结构保持问题；对 Geigle--Lenzing 射影平面的 ACM 丛范畴给出 Frobenius 2-exact 商范畴的显式例子；$n=1$ 时恢复并补充了 Demonet--Iyama 与 Chen 的经典结果。

## 主动思考区

### 与其他工作的联系

- 这让我想起：n-Abelian 范畴中宽子范畴的谱与支撑理论（2610.16541），同样研究高阶同调代数（n-Abelian 范畴）中子范畴的结构性质，与本文对 n-exact 范畴子范畴商构造的处理互补。
- [[2610.14420]]：张量三角范畴中的维数理论同样关心商与子范畴保持同调性质的问题，其证明思路可对照本文的理想商公理验证。
- 技术迁移：用 $(\mathrm{EC}')$ 与 $(\mathrm{EI})$ 公理替换弱同构封闭性来验证商结构的方法，可用于其他高阶结构（如 extriangulated 或 n-exangulated 范畴）的商构造。
