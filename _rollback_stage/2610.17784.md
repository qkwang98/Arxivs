# Asymptotic Lech Bounds and Bertini Flags

keywords: [渐近 Lech 常数, Bertini 旗, Hilbert-Samuel 重数, 孤立奇点, Lech-Mumford 常数, klt 锥]
related_paper: "Huneke-Ma-Quy-Smirnov, Asymptotic Lech's inequality（HMQS）"
one_liner_summary: 通过引入容许 Bertini 旗并用超积与猫幂（catapower）论证建立沿超平面截面的递推不等式，完全证明了 Huneke-Ma-Quy-Smirnov 的渐近 Lech 猜想及 Ma-Smirnov 的 Lech-Mumford 常数可达性猜想，并构造了非孤立 klt 锥的例子族。

## 核心定位

- **解决的问题**：证明任意特征下，当完备化 $\widehat R$ 具有孤立奇点时渐近 Lech 常数 $\cinf(R)=1$（即对充分大余长度的 $\m$-准素理想，Lech 不等式中的系数 $e(R)$ 可用 $1+\eps$ 替代），并证明 Ma-Smirnov 猜想：在孤立奇点且 $\cLM(R)>1$ 时 Lech-Mumford 常数被某个理想取到且为有理数。
- **大图景位置**：Lech 不等式 $e_R(I)\le d!\,e(R)\length_R(R/I)$ 是 Hilbert-Samuel 重数与余长度关系的经典估计，也与 Mumford 的渐近 GIT 半稳定性局部数值条件相关。Huneke-Ma-Quy-Smirnov 仅在正特征完美剩余域（用 Hilbert-Kunz 重数）和一维任意特征下证明了猜想，本文用完全不同的方法在一般情形（任意特征、任意维数）彻底解决。
- **主要贡献**：① 主定理：$\widehat R$ 孤立奇点时 $\cinf(R)=1$，等价于对每个 $\eps>0$ 存在 $N$ 使 $e_R(I)\le d!(1+\eps)\length_R(R/I)$ 对余长度大于 $N$ 的 $\m$-准素理想成立；② 核心技术定理（递推不等式）：$\cinf(R)\le\max\{\cinf(R/xR),\muo(R)\}$，其中 $\muo(R)=\sup\{e(R_P):P\ne\m\}$ 为去心谱上的重数上确界；③ 引入容许 Bertini 旗概念，利用 Flenner-Trivedi 局部 Bertini 定理构造截面并给出 $\cinf(R)\le\Lambda_{\mathrm{Bert}}(R)\le e(R)$；④ Veronese 子环顶点局部环上 $\cLM$ 的可达性与有理性；⑤ 特征零下构造每个维数 $d\ge3$ 的非孤立 klt 仿射锥，其奇异轨迹维数为 $d-2$、$\cinf=1$ 而 $\cLM$ 任意大。
- **关键先驱工作**：Lech 的经典重数-余长度不等式；Huneke-Ma-Quy-Smirnov 的渐近 Lech 猜想与单步不等式（HMQS Lemma 5.1）；Ma-Smirnov 的 Lech-Mumford 常数与一致改进（均匀 Lech 不等式）；Flenner 与 Trivedi 的局部 Bertini 定理；Nagata 关于去心谱上重数有界性；Mumford 的渐近 GIT 半稳定性条件。
- **结果边界**：递推不等式中 $\muo(R)$ 项不可省略（论文给出反例：$\cinf(R/zR)=1$ 而 $\cinf(R)$ 可以无界，见 ordinary multiple point 族）；$\cinf(R)=1$ 的结论需要 $\widehat R$ 孤立奇点这一较强假设；$\cLM$ 可达性要求 $\cLM(R)>1$，条件 $\cLM(R)>1$ 是本质的；Veronese 结论要求 $n>d!$（正规且 $d\ge3$ 时放宽为 $n^2>d!$）；超积构造中的环不一定是 Noether 的。
- **开放问题**：均匀改进中 Ma-Smirnov 的非显式常数 $\delta(R)$ 与本文旗系数 $\Lambda(\mathcal F)$ 之间的精确关系（文中指出 $\Lambda(\mathcal F)<e(R)$ 本身不蕴含 $\Lambda(\mathcal F)<e(R)-\delta(R)$）；更一般地，何时 $\cinf(R)<e(R)$ 能推出优于经典系数的统一常数；非孤立奇点情形下 $\cinf$ 与奇异轨迹维数、klt 性质之间的关系。
- **应用与推广**：$\cLM(R\fps{T})=\cinf(R\fps{T})$ 的观察回答了 Ma-Smirnov 关于 Mumford 半稳定性的问题（$R$ 半稳定当且仅当 $\cinf(R\fps{T})=1$）；给出 Veronese 子环与 del Pezzo 乘积锥上 $\cLM$ 的显式可达性；为渐近 GIT 半稳定性提供局部数值判据；递推技术（超积/猫幂与非相消论证）可迁移到其他重数型渐近量的估计。

## 主动思考区

### 与其他工作的联系

- 这让我想起：用 Hilbert-Kunz 重数证明正特征情形的 HMQS 定理 — 见 [[2610.00362]]
- [[2610.13888]]：同样研究重数与模的 Rees 型不等式（混合 Buchsbaum-Rim 重数与 Minkowski/Teissier 不等式），与本文的去心谱重数 $\muo(R)$ 同属交换代数中的重数估计传统，可对照重数型量的渐近行为。
- [[2610.00362]]：Frobenius 重数与 $F$-签名研究正特征重数不变量，而本文用超积/猫幂统一处理任意特征，二者在正特征重数理论处交汇。
- [[2610.15261]]：正则序列与 Cohen-Macaulay 环的基本性质，正是本文 Bertini 旗每一步保持 Cohen-Macaulay 性的背景工具。
- 技术迁移：本文的"超积 + 猫幂 + 非相消"论证框架是否可用于证明其他重数型渐近量（如 $F$-签名极限、体积函数）的一致估计？

### 可以尝试的方向

### 批判性思考

- 递推不等式 $\cinf(R)\le\max\{\cinf(R/xR),\muo(R)\}$ 的证明依赖超积与猫幂，非 Noether 环的出现使论证的技术门槛很高；是否存在更初等的截面估计直接得到同一上界？
- 定理中"admissible Bertini flag 存在"依赖无限剩余域假设；有限域情形是否可用有限域版本的局部 Bertini 定理或通过扩张剩余域绕过？
- 超积论证中"非相消"步骤（catapower 上重数下降不可直接读出）是否隐含了紧致性原理之外的选择公理依赖？
