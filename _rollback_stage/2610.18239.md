# River ribbon tableaux and symmetric group characters

keywords: [河流丝带杨表, 对称群特征标, 特征标界, 标准杨表, Moore-Russell 猜想]
related_paper: "Rattan and Śniady, 2008 (Moore-Russell 猜想的出处)"
one_liner_summary: 引入河流丝带杨表这一组合工具，证明对称群正则化特征标的普适上界，特化到平衡图时证实了 Moore-Russell 猜想，并推出 Dousse-Féray 关于斜形状标准杨表个数的猜想。

## 核心定位

- **解决的问题**：为对称群 $\mathfrak{S}_n$ 的正则化特征标 $\chi^\lambda(\sigma)$ 建立随置换支撑大小衰减的普适上界，并证明 Moore-Russell 猜想与 Dousse-Féray 猜想。
- **大图景位置**：属于对称群特征标界的长期研究脉络。该脉络中"厚图"一派的已有界在平衡图下分别适用于不同支撑规模（有界支撑、$O(\sqrt{n})$ 支撑、$\omega(\sqrt{n})$ 支撑），本文给出一个在所有支撑规模下统一的界，填补了 Moore-Russell 猜想这一空缺；同时为斜杨表计数问题提供新工具。
- **主要贡献**：
  1. 引入河流丝带杨表（river ribbon tableaux）——由两条单格框"河岸"夹住一条非平凡丝带"河流"的组合对象，相比既有丝带剥皮方法大幅减少不同形状图之间的几何差异与丝带配置的最大数目；
  2. 证明统一特征标界 $|\chi^\lambda(\sigma)| \leq (5\delta s^2/n^2)^{|\sigma|}$，在温和形状假设 $\delta s = O(n)$ 下指数项化为 $O(s/n)^{|\sigma|}$，不含置换部分 $|\sigma|/n$；
  3. 特化到 $C$-平衡图证明 $|\chi^\lambda(\sigma)| \leq (5C^2/\sqrt{n})^{|\sigma|}$，即 Moore 与 Russell 的猜想；
  4. 作为应用证明 Dousse 与 Féray 关于斜形状标准杨表个数的猜想。
- **关键先驱工作**：Biane（基于 Kerov 的交错测度方法）对平衡图、有界支撑的情形；Rattan 与 Śniady（支撑 $O(\sqrt{n})$ 及较弱的大支撑界）；Féray 与 Śniady 的一般界；作者本人的 Teyssier 2025 关于斜杨表维数与特征标的界；另一条线为 Diaconis-Shahshahani 随机换位工作推广出的指数特征标界（Roichman、Müller-Schlage-Puchta、Larsen-Shalev 等），通常依赖 Murnaghan-Nakayama 规则。
- **结果边界**：定理中的常数 5 虽小，但推导依赖河流丝带杨表的组合构造；对非平衡图（$s(\lambda)$ 相对 $\sqrt{n}$ 很大）情形，本文界退化为一般形式，未必是最优。文中指出与 $|\sigma|$ 相关的指数项不再显式出现，但这是在 $\delta s = O(n)$ 假设下获得的。
- **开放问题**：正文未显式列出开放问题；隐含的可研究方向包括：进一步优化常数、将河流丝带杨表方法推广到其他群（如一般线性群、超对称群），以及将其用于随机游走混合时间的更精细分析。
- **应用与推广**：正则化特征标界可直接用于对称群上的随机游走混合时间估计；斜形状标准杨表计数与表示论的维度问题密切相关；丝带型组合对象的方法有望迁移到 Hecke 代数、$q$-杨表以及正特征表示论中的类似计数与界。

## 主动思考区

### 与其他工作的联系

- 这让我想起对称群表示论与自由概率的交汇处——Kerov 交错测度与特征标渐近 — 见 [[Cotorsion pairs, model categories, and representation theory2601130219]]（该笔记属表示论大方向，但主题为模型范畴与 cotorsion 对，与本文关联较弱）。
- 技术迁移：本文"减少丝带配置多样性"的思路类似于在组合证明中用更规整的剥皮序列控制计数；该想法或可用于斜 Schur 函数展开、Jack 多项式以及 Macdonald 多项式正性问题的类似上界推导。

### 可以尝试的方向

- [ ] 能否将河流丝带杨表构造推广到 $\mathrm{GL}_n$ 或一般线性群（超群）的特征标，得到类似支撑衰减界？
- [ ] 常数 5 能否进一步优化？较小的普适常数对实际混合时间估计更有利。

### 批判性思考

- 本文方法不依赖 Murnaghan-Nakayama 规则，这与指数特征标界一线的工作形成对比；能否用河流丝带构造给出指数型界的替代证明？
- 统一界的获得依赖于 $\delta s = O(n)$ 这一温和假设；若放宽该假设，指数项中是否会重新出现置换部分 $|\sigma|/n$，与 Féray-Śniady 界如何衔接？
