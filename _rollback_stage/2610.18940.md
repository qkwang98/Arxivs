## 核心定位

- **解决的问题**：为 cluster 代数中 mutation loop 建立类似于 3-流形 Reidemeister 挠率的指标不变量，并证明其整数性与 genus-$0$ 消失条件。
- **大图景位置**：把 Gang–Kim–Yoon 基于 3d-3d 对应提出的 3-流形指标整数性猜想推广到 mutation loop 的更广框架，衔接 3-流形几何、量子场论指标与 cluster 理论三者的字典。
- **主要贡献**：其一，定义非退化 mutation loop 的 genus-$g$ 指标 $\Ind_g^\phi = \sum_{x \in \Fix_\phi(\overline{\mathbb{Q}})} \det(1-(d\phi)_x)^{g-1}$ 及细化 $\Ind_{g,t}^\phi$；其二，主定理在有限阶或形状参数整数性假设下证明 $\Ind_{g,t}^\phi \in \mathbb{Z}[t]$（$g \geq 1$），证明基于不动点代数 $R_\phi$ 上的迹与 Mizuno 的 Jacobian 公式；其三，$R_\phi$ 上的 Frobenius 结构使 $\Ind_g^\phi$ 成为 $(1+1)$-维 TQFT 的 genus-$g$ 配分函数，并借全局留数定理与 Siebert–Tian 的度论证得到 genus-$0$ 消失的充分条件；其四，对 Fordy–Marsh 分类的 period one mutation loop 给出显式整数性与消失判据，并对广义 Kronecker quiver 给出所有 genus 的生成函数为多项式之比。
- **关键先驱工作**：Gang–Kim–Yoon 的 3-流形指标与整数性猜想；Terashima–Yamazaki 的 3d-3d 对应向 quiver mutation loop 的推广；Connes–Marcolli 的 Reidemeister 挠率簇论类比；Mizuno 的 mutation network 与 Jacobian 公式；Fordy–Marsh 对 period one mutation 的分类；Siebert–Tian 的量子上同调 Vafa–Intriligator 公式。
- **结果边界**：细化指标的整数性在一般情况下不成立（文中给出反例），需要有限阶或形状参数假设；genus-$0$ 消失条件在非零情形可能与初始簇环面外"缺失"的不动点相关，文中未深究；primitive 情形下的整数性仍为猜想。
- **开放问题**：能否构造 cluster 版本的模张量范畴对应 3-流形；指标与扭结–quiver 对应、扭结–规范对应之间是否存在系统联系；"缺失不动点"如何刻画 genus-$0$ 非零指标。
- **应用与推广**：为 cluster 代数提供从 3-流形拓扑借来的不变量工具；生成函数的多项式比值形式可直接用于广义 Kronecker quiver 指标的大规模计算；$(1+1)$-维 TQFT 解释架起与量子上同调公式的桥梁。
