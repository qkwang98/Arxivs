# Duality Theory for Sequent Algebras

keywords: [sequent algebra, contact algebra, closure operator, 对偶性, sequent space, positive filter, topological category]
related_paper: "Vakarelov 关于 sequent algebras 的原始论文"
one_liner_summary: 该文将 Vakarelov 的 sequent algebras 呈现为带四条件有限闭包算子的 Boolean 代数，以不可约闭集（即 Vakarelov 氏族）为点建立 sequent algebras 与 sequent spaces 的范畴对偶等价，刻画同余并证明 sequent 同态范畴在 Boolean 代数范畴上是拓扑的。

## 1.  核心定位

- **解决的问题**：作为 contact algebras 推广的 sequent algebras 缺乏系统的对偶理论——需要建立点式表示、范畴对偶与同余刻画，并理解其范畴结构。
- **大图景位置**：这是基于区域的空间理论（mereotopology）与抽象代数逻辑的交叉：把 sequent algebras 归约为带闭包算子的 Boolean 代数，从而将 Stone 对偶传统推广到满足 Tarski 后承关系的 $n$ 元接触结构。
- **主要贡献**：
  1. 给出 sequent algebras 的闭包算子刻画：Boolean 代数上满足 Fi、One、Up、Jo 四条件的有限闭包算子。
  2. 证明不可约闭集构成闭包系的基、与 join 素闭集及 Vakarelov 氏族一致，并以之为点构造 sequent spaces，建立 sequent algebras 与 sequent spaces 的对偶等价（含保完整 Boolean 结构的限制版本）。
  3. 引入 sequent 同余，证明其对应正滤子（等于自然从属关系确定的正则滤子），且同余格与正则滤子格同构、与极小递减闭子集格反序同构。
  4. 证明 sequent 同态范畴在 Boolean 代数范畴上是拓扑的（完备性、余完备性与完备格结构）；同时证明半同态版本不是拓扑的。
- **关键先驱工作**：Vakarelov 的 sequent algebras 与拓扑表示；Boolean 代数与 Stone 对偶；Tarski 后承关系；contact algebras 理论；Lipparini 的 hypercontact semilattices；Goldblatt--Grice 的 mereocompactness 对偶；抽象代数逻辑中的闭包算子视角。
- **结果边界**：对偶等价建立在 sequent 半同态层面，完整 Boolean 结构的保持需要限制态射类别；拓扑性结论仅对 sequent 同态成立，半同态版本明确失败；空间层面的分离性要求（如正则闭集框架）与 mereocompactness 型推广仍有距离。
- **开放问题**：半同态范畴拓扑性失败的更精细刻画；与 mereocompactness、hypercontact 结构的统一对偶框架；拓扑性导出的完备格结构在具体 Boolean 代数上的显式描述。
- **应用与推广**：为区域式空间理论提供严格的对偶工具，可用于点式/点无模型间的翻译；同余刻画为 sequent algebras 上的商结构研究提供代数途径；拓扑范畴性与完备格结构可指导进一步的一般性构造（离散/非离散函子）。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：范畴完备性与闭性结构的研究 — 见 [[2610.20428]]
- [[2610.20428]]：经典同伦范畴的笛卡尔闭性属于范畴结构性质研究，与本文证明 sequent 同态范畴的拓扑性（完备性与余完备性）同属范畴层面结构的建立。
- [[2610.20386]]：加法范畴中 Kaplansky--Walker 引理处理直和分解与生成结构，与本文 Boolean 代数范畴上的完备性研究同属范畴论结构分析。
- 技术迁移：用闭包算子的不可约闭集作为点构造对偶空间的方案，或可迁移到其他以有限生成闭集为点的非点式结构（如超接触半格、抽象后果算子结构）的表示论。
