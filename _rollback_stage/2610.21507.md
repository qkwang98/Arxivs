# A Krause-type recollement for $\Q$-shaped derived categories

keywords: [Q-shaped derived category, recollement, cotorsion pair, compact generator, Frobenius category]
related_paper: "Gluing weak approximability along recollements (2610.22161)"
one_liner_summary: 对满足强退缩性质的 $\Q$-形状范畴，构造对象式内射 $\Q$-形状模同伦范畴关于正合对象子范畴与 $\Q$-形状导出范畴的 Krause 型 recollement，并给出紧生成元与紧对象的商描述。

## 核心定位

- **解决的问题**：在 $\Q$-形状导出的范畴框架下，将 Krause（链复形）与 Liu（周期复形）的经典 recollement 推广到一般 $\Q$-形状模，并研究其中三个三角范畴的紧生成性质与紧对象之间的关系。
- **大图景位置**：$\Q$-形状导出范畴是环的导出范畴的自然推广（Holm–Jørgensen 引入）；本文把 Krause 关于内射复形同伦范畴的 recollement 结果提升到 $\Q$-形状，是已有结果的统一推广。
- **主要贡献**：1）在 $\I$ 上建立 Frobenius 结构，构造 $Q_I:\KI\to\DQ$ 的完全忠实左伴随 $L_I$ 与右伴随 $R_I$，得到三角范畴的 recollement $\KAI\to\KI\to\DQ$；2）当 $A$ 左诺特时，用特殊预包络显式给出 $\KI$ 与 $\KAI$ 的紧生成元集合；3）将 $(\KAI)^c$ 识别为 $(\KI)^c/L_I((\DQ)^c)$ 的幂等完备化。
- **关键先驱工作**：Krause 的链复形 recollement（2005）；Liu 的周期复形版本；Holm–Jørgensen 的 $\Q$-形状导出范畴与模型结构；Slaftsos–Vitória 的 $\Q$-形状同伦范畴；Neeman 的局部化定理。
- **结果边界**：主 recollement 本身不要求 $A$ 左诺特，但紧生成元与紧对象的描述需要 $A$ 左诺特；要求 $\Q$ 满足强退缩性质且具有幂零伪根（nilpotent pseudo-radical）。
- **开放问题**：对一般 $\Q$，商 $(\KI)^c/L_I((\DQ)^c)$ 并不总等价于经典奇点范畴，其几何/代数解释仍有待进一步刻画。
- **应用与推广**：适用于链复形、周期复形与 $N$-复形；可进一步用于奇点理论、Gorenstein 同调代数与非诺特环上的导出范畴研究。

## 主动思考区

### 与其他工作的联系

- 这让我想起：recollement 与 Bousfield 局部化三元组之间的关系 — 见 [[2610.22161]]
- [[2610.22161]]：同样围绕 recollement 展开，但关注 weak approximability 的胶合，本文则关注 $\Q$-形状下的紧对象结构，两者互补。
- [[2608.03212]]：n-cotorsion pair 在三角范畴上的 heart 构造，与本文用完全遗传 cotorsion pair 诱导 Bousfield 局部化对的思想相通。
- [[2610.20428]]：经典同伦范畴的闭笛卡尔性，本文的同伦范畴 $\KQ$ 与其同属范畴层面的同伦构造语境。
- 技术迁移：完全遗传 cotorsion pair 限制到 Frobenius 子范畴得到 Bousfield 局部化对的手法，或可迁移到更多带有模型结构的函子范畴。

### 可以尝试的方向

- [ ] 能否将本文的紧对象商描述推广到非诺特环上的更广函子范畴？

### 批判性思考

- 左伴随 $L_I$ 的构造依赖 $\I$ 上 Frobenius 结构与 cotorsion pair 的继承，是否可去掉强退缩条件而用更弱的假设实现？
- 特殊预包络的选取是否影响紧生成元的显式表达，作者未讨论其非典范性。
