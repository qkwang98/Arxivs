# Generalized Cluster Algebra Homomorphisms Induced by Cluster Tube Embeddings

keywords: [广义 cluster 代数, cluster tube, 仿射 cluster 代数, cluster 特征标, theta 函数, 虚交换关系]
related_paper: "Reading–Stella 关于仿射型虚墙 theta 函数与虚交换关系的工作"
one_liner_summary: 在 cluster tube 上引入带参数 $z$ 的加权 cluster 特征标，证明其满足 $C_{n-1}$ 型广义交换关系，并建立广义 cluster 代数到仿射 cluster 代数的单射同态，从而将广义交换参数 $z$ 与虚根对应的 theta 函数统一起来。

## 1.  核心定位

- **解决的问题**：将仿射 cluster 代数中正则模的乘法公式与 Reading–Stella 的虚交换关系对应起来，解释广义 cluster 代数中二次交换多项式 $1+zu+u^2$ 的中项与参数 $z$ 的表示论来源。
- **大图景位置**：连接两条独立路线——(a) Ding–Xiao–Xu 正则模乘法公式与差性质；(b) Gross–Hacking–Keel–Kontsevich 散射图 theta 函数与 Reading–Stella 虚交换关系——为仿射型 cluster 代数提供表示论诠释。
- **主要贡献**：1) 推广 Zhou–Zhu 构造，在 cluster tube $\mathcal C_n$ 上定义带参数 $z$ 的加权 cluster 特征标 $X_M^{(z)}$，并证明满足广义交换关系（一维扩张空间给出二项式关系，二维扩张空间给出 $X_{\mathcal I(U)}^2+X_\delta X_{\mathcal I(U)}X_{\mathcal I(V)}+X_{\mathcal I(V)}^2$ 型三项关系）；2) 证明不可分解刚性对象与 $C_{n-1}$ 型广义 cluster 代数的 cluster 变量一一对应，且极大刚性对象的 mutation 与种子 mutation 相容；3) 证明非齐性 tube 嵌入 $\mathcal I:\mathcal C_n\to\mathcal C_Q$ 在赋值 $z\mapsto X_\delta$、$X_M^{(z)}\mapsto X_{\mathcal I(M)}$ 下诱导单射 $\mathbb Z$-代数同态 $\mathcal A^{(z)}(\mathcal C_n)\hookrightarrow\mathcal A(\mathcal C_Q)$，并将 $X_\delta$ 识别为 theta 函数 $\vartheta_{\mathrm{ind}_\Gamma H}$。
- **关键先驱工作**：Fomin–Zelevinsky cluster 代数；Buan–Marsh–Vatne 关于 cluster tube 极大刚性对象的工作；Zhou–Zhu、Fu–Geng–Liu 的 Caldero–Chapoton 型映射；Caldero–Keller 与 Palu 的 cluster 特征标；Ding–Xiao–Xu 的正则模乘法公式与积分基；Chekhov–Shapiro 广义 cluster 代数；Labardini–Fragoso–Mou 的 gentle Jacobian 代数方法；Gross–Hacking–Keel–Kontsevich 与 Reading–Stella。
- **结果边界**：限于系数自由的 skew-symmetric 交换矩阵、连通无圈仿射型（非 Kronecker 箭图）的齐性 tube 嵌入；齐性 tube 中 quasi-simple 模的维数向量为最小正虚根 $\delta$；取 $z=0$ 时恢复 Zhou–Zhu 公式；广义交换多项式 $1+zu+u^2$ 在 $z=1$ 时特化为 Labardini–Fragoso–Mou 的 $1+u+u^2$。
- **开放问题**：文中未明确列出开放问题；对 Kronecker 箭图与带系数情形的推广是自然的后续方向。
- **应用与推广**：为仿射型 cluster 代数虚根的 theta 函数提供表示论诠释；加权特征标的分层赋值方法可推广至其他 2-Calabi–Yau 范畴；为广义 cluster 代数与稳定散射图、$\tau$-倾斜理论之间的对应提供新例。
