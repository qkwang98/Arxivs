# Double covers of tori for p=2 and genuine functions

keywords: [二重复盖, 真函数, 非阿基米德局部域, 剩余特征 2, 超cuspidal 表示, 局部 Langlands 对应, 模-a-数据, 指数映射]
related_paper: "Kaletha, arXiv:1907.05173"
one_liner_summary: 在非阿基米德局部域上（含剩余特征 2）给出环面二重复盖 $S(F)_{\pm}$ 上真符号函数 $a_S$ 的两种构造——基于根提升与基于指数映射——并在显式分歧条件下与 Kaletha 在奇剩余特征下的构造一致。

## 核心定位

- **解决的问题**：构造真函数 $a_S$（正则超cuspidal 表示特征标公式与局部 Langlands 对应中的关键成分），且不要求剩余特征 $p$ 为奇数。
- **大图景位置**：Kaletha（arXiv:1907.05173）理论的补充与推广：其简单构造的关键步骤（除以 2、主单位上二次特征的平凡性）本质上依赖 $p\neq 2$；本文给出处理 $p=2$（包括野分歧）的完整构造，并包含此前仅公告于 Appendix D 的第一种构造的完整细节。
- **主要贡献**：
  1. 第一种构造（根提升法）：构造提升 $N_{F_\alpha/F}\circ\alpha^\vee$ 的同态 $F_\alpha^{\times}\to S(F)_{\pm}$，将 $\theta_{\pm}$ 拉回为 $F_\alpha^{\times}$ 的特征，从而定义模-a-数据 $\overline{a}_{\alpha}$；
  2. 第二种构造（指数映射法，特征零）：利用 $S(F)_{\pm}$ 的指数映射与 $N_{F_\alpha/F}$、$\alpha^\vee$ 的微分映射，在指数映射收敛的适当开子群上拉回 $\theta_{\pm}$ 并经加性对偶定义 $\overline{a}_{\alpha}$；
  3. 引入"细化"模-a-数据机制（保证两个提升之比落在 $\kappa_\alpha$ 的核中）及假设 (Ram) 与 (Exp)，在 $G=\mathrm{PGL}_2$ 的椭圆环面情形显式刻画，说明二者一般不互相蕴含（野分歧时）。
- **关键先驱工作**：Kaletha 1907.05173（二重复盖、L-嵌入、特征标公式与猜想 4.4.1）；Langlands–Shelstad 的 a-数据与对称根理论；mod-a-数据的变体（MR4013740）；Deligne 扭公式（局部 ε 因子表达 $\alpha$-因子）。
- **结果边界**：两种构造分别在逐根条件 (Ram) 与 (Exp) 下成立；与 Kaletha 构造一致性仅在显式分歧条件、奇剩余特征下证明；第二种构造要求 $F$ 特征零（指数映射收敛性）；$p=2$ 时平方-加倍程序失效是核心障碍，需直接提取 $\theta_{\pm}$ 的"$\alpha$-分量"。
- **开放问题**：稳定特征标公式对超cuspidal $L$-参数谱刻画（Kaletha 猜想 4.4.1）的完整验证；野分歧时 (Ram) 与 (Exp) 不互蕴含对 $a_S$ 具体形式的影响；$p=2$ 情形下局部 Langlands 对应的显式实现。
- **应用与推广**：正则（更一般非奇异）超cuspidal 表示的特征标公式、显式局部 Langlands 对应、避免 $\chi$-数据选择的典型 L-嵌入构造、局部调和分析中 genuine 特征的理论。

### 可以尝试的方向

- [ ] 将第二种构造（指数映射）推广到剩余特征 2 但特征非零的域，寻找 Artin–Schreier 风格的对偶替代。
- [ ] 检验 (Ram) 与 (Exp) 在更一般对称根（而非仅 $\mathrm{PGL}_2$ 椭圆环面）下的相容性与最优性。

### 批判性思考

- "细化"模-a-数据保证 $\kappa_\alpha$ 在提升之比上平凡：当 $\kappa_\alpha$ 非平凡作用更复杂时该修正是普遍可行还是仅对特定深度特征成立？
- 两种构造在特征零时通过局部 ε 因子（Deligne 扭公式）统一，这一统一在 $p=2$ 时是否仍然成立，还是会出现本质分歧？
