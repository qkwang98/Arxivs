# Vector bundles on singular surfaces and threefolds

keywords: [向量丛分类, motivic上同调, 代数K-理论, motivic滤过, Chern类]
related_paper: "2607.21567"
one_liner_summary: 本文利用代数 $K$-理论上的 motivic 滤过及其与 motivic 上同调的第三 Chern 类比较，在代数闭域上完全分类正规仿射曲面与三维流形上的临界秩向量丛，并证明三维流形上给定前两个 motivic Chern 类的秩 $2$ 丛的存在性。

## 1.  核心定位

- **解决的问题**：将向量丛按特征类分类这一经典问题从光滑仿射曲面/三维流形推广到**奇异**（正规）仿射曲面与三维流形，给出临界秩的完全分类与存在性结果。
- **大图景位置**：位于代数几何中"向量丛分类 ↔ 特征类/代数 $K$-理论"的经典脉络：Murthy–Swan（光滑曲面秩 $2$）、Mohan Kumar–Murthy（光滑三维流形秩 $3$）、Asok–Fasel（motivic 同伦方法）之后的奇异化推广；其工具核心是 Elmanto–Morrow 的奇异簇 motivic 上同调框架。
- **主要贡献**：
  1. 秩 $2$ 丛在正规仿射曲面上的完全分类：$(c_1,c_2)$ 诱导的双射；
  2. 秩 $3$ 丛在正规仿射三维流形上的完全分类：$(c_1,c_2,c_3)$ 诱导的双射；
  3. 关键技术定理：三维情形中 motivic 滤过的第三段 $F^3_{\mathrm{mot}}\mathrm{K}_0(X)$ 恰由光滑闭点生成，并由此证明秩 $2$ 丛存在性。
- **关键先驱工作**：Murthy–Swan（1976）光滑曲面秩 $2$ 分类；Mohan Kumar–Murthy（1982）光滑三维流形秩 $3$ 分类；Asok–Fasel 的 motivic 同伦方法；Serre 分裂定理与 Suslin 消去定理；Murthy（1994）秩等于维数时的顶 Chern 类分裂判据；Elmanto–Morrow 的 motivic 上同调与 motivic 滤过；Krishna（2019）与 Schlichting（2015）的 Euler class 群框架。
- **结果边界**：要求基域代数闭、仿射有限型、正规性假设（作者预期正规性是证明产物而非结果本质）；秩等于维数的分类依赖顶 Chern 类分裂判据；四维及以上有 Mohan Kumar 反例（非平凡 stably trivial 丛），说明低维特殊性不可直接推广。
- **开放问题**：奇异仿射三维流形上秩 $2$ 丛是否由 $(c_1,c_2)$ **唯一**决定（当前只证满射）；$F^3_{\mathrm{mot}}\mathrm{K}_0(X)$ 与适当 Euler class 群的进一步等同。
- **应用与推广**：为奇异簇上的消去/分裂问题提供 K-理论滤过工具；第三段比较定理可将抽象 motivic 滤过片段落实到由光滑闭点生成的 concrete 群（Levine–Weibel Chow 群），可用于构造秩 $3$ 丛的 Euler class 框架分裂判据。
