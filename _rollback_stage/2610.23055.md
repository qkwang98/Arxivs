# Typical representations of admissible type I algebraic supergroups

keywords: [代数超群, 典型表示, Kac 模, Frobenius 核, 超代数]
related_paper: "Marko 关于 $\mathrm{GL}(m|n)$ 典型权诱导超模简单性的工作"
one_liner_summary: "本文引入 admissible type I 代数超群的概念，证明其诱导超模 $H^0_{\G}(\lambda)$ 简单当且仅当权典型且偶数子群的诱导模简单，并建立典型分块与偶数子群分块之间的范畴等价及 Frobenius 核上 Kac 模的投射性判据。"

## 1.  核心定位

- **解决的问题**：代数超群的表示与其偶数子群表示之间的关系；具体地，对一类覆盖多个超群族（$\mathrm{GL}(m|n)$、连通正交-辛超群 $\mathrm{SpO}(2\ell|2)$ 及其中心商）的"可容许 type I"代数超群，研究典型表示（简单性、分块、Kac 模与投射性）。
- **大图景位置**：Kac 在复基本典型李超代数上确立了典型简单表示可由偶数部分描述；Zhao 在正特征下对 type I 基本典型李超代数建立了约化包络代数范畴的归约；Marko 将 Kac 的简单性判据推广到正特征 $\mathrm{GL}(m|n)$。本文把这些结果统一并推广到一个更广泛的代数超群类，同时补足 Frobenius 核上的投射性判据，是该方向的系统性现代处理。
- **主要贡献**：1) 定义 admissible type I 代数超群（偶数子群分裂连通约化、李超代数具有 $\Gev$-稳定的 $\mathbb Z$-分次、奇数正根可逐次变号保持正根集）；2) Main Theorem A：对每个支配权 $\lambda$，$H^0_{\G}(\lambda)$ 简单当且仅当 $\lambda$ 典型且 $H^0_{\Gev}(\lambda)$ 简单；特征零时后者自动成立，从而恢复 Kac 的判据；3) 证明 $\KacG(L_{\Gev}(\lambda))$ 简单当且仅当 $\lambda$ 典型，此时 $L_{\G}(\lambda)\cong\KacG(L_{\Gev}(\lambda))$；4) Main Theorem B：Kac 函子 $\KacG:\mathscr E\to\mathscr C^{\mathrm{typ}}$ 与 $(-)^{\gpone}:\mathscr C^{\mathrm{typ}}\to\mathscr E$ 互为阿贝尔范畴逆等价，且每个有限维超模有自然分解 $W=W^{\mathrm{typ}}\oplus W^{\mathrm{atyp}}$；5) 典型分块与 $\Gev$ 分块等价，并给出 $\Ext^n_{\G}(L_{\G}(\lambda),L_{\G}(\mu))\cong\Ext^n_{\Gev}(L_{\Gev}(\lambda),L_{\Gev}(\mu))$；6) Main Theorem C：对 Frobenius 核，$\KacGr(M)$ 投射当且仅当 $M$ 投射且 $\Theta_M$ 可逆，并给出简单投射 $\G_r$-超模与带可逆 $\Theta$-作用的简单投射 $\G_{\mathrm{ev},r}$-超模之间的双射；7) 对代数闭域奇特征上的连通 $\mathrm{SpO}(2\ell|2)$ 及其 2 阶标量商，分类全部 Frobenius 核上的简单投射超模。
- **关键先驱工作**：Kac 的典型简单表示理论（特征标公式、type I 归纳构造）；Gorelik 对固定强典型中心荷的范畴等价；Zhao 的正特征约化包络代数归约；Marko 对 $\mathrm{GL}(m|n)$ 的简单性判据；Marko--Zubkov 关于典型分块最高权的刻画；Li--Shu 的 $p$-典型权与 Jantzen 滤过；Masuoka 的超代数乘法同构；Zubkov 的 Steinberg 超模投射性。
- **结果边界**：要求基域特征 $\neq 2$，投射性部分要求特征为奇数的完美域/代数闭域；admissible type I 结构条件（奇数正根的可逐次变号性质）对某些超群族可能过强；分类结论针对连通 $\mathrm{SpO}(2\ell|2)$ 及其 2 阶标量中心商，未覆盖所有超群类型。
- **开放问题**：类型 A 与 C 之外（例如类型 D 或更一般超群）的典型分块显式描述；admissible 条件能否放宽；$\mathrm{SpO}(2\ell|2)$ 之外的简单投射超模分类。
- **应用与推广**：典型分块与偶数子群分块的等价可用于计算典型表示间的扩张群；简单投射超模的分类可用于模表示论中的支撑映射与不可约模的投射维数研究；Kac 函子与 $(-)^{\gpone}$ 的逆等价提供"先研究偶数子群、再通过 Kac 函子迁移"的系统方法，可推广到更多超群族。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起：已有笔记库中暂无与代数超群典型表示直接语义相关的笔记，暂不建立双链。
- 技术迁移：本文"可容许奇数根排序"技巧与超代数乘法同构 $\bigwedge(\gmone)\otimes\hy(\Gev)\otimes\bigwedge(\gpone)\cong\hy(\G)$ 的结合，可用于其他超代数/量子群的投射性判定。

### 2.2.  可以尝试的方向

- [ ] 能否把 Main Theorem A 的典型性判据推广到更多 admissible 超群族（如 type D 的正交-辛情形）或中心商的更一般情形？
- [ ] 能否显式计算更多超群的典型性标量 $\Dtyp(\lambda)$，从而得到典型分块的显式列表？
- [ ] 简单投射超模分类能否与支撑映射/拟遗传代数理论结合，给出不可约超模的投射维数下界？

### 2.3.  批判性思考

- admissible type I 定义中的奇数根逐次变号条件是否对所有自然候选超群族成立，还是排除了某些重要情形，值得检验。
- Main Theorem A 的证明依赖 $EF$ 作用在最高权向量上的标量计算与两个 Kac 函子间的自然映射，这些构造在正特征下是否有隐含的分离性/有限性假设。
- 特征零与正特征结论的衔接（$H^0_{\Gev}(\lambda)$ 简单性自动成立）掩盖了偶数部分表示论的复杂度，应用时需注意基域假设。
