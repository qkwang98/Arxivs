# Locally Gorenstein algebras, a generalization of Gorenstein algebras

keywords: [局部 Gorenstein 模, 局部 Gorenstein 代数, 半 Gorenstein 投射模, Igusa-Todorov 函数, finitistic 维数]
related_paper: "2609.14453（Igusa--Todorov Algebras and the Auslander--Reiten Conjecture）"
one_liner_summary: "在 Artin 代数上引入局部 Gorenstein 模（半 Gorenstein 投射模的推广），证明 Igusa-Todorov 函数 $\phi$、$\psi$ 在其上取零，并据此定义局部 Gorenstein 代数（Gorenstein 代数的推广），其 finitistic、$\phi$ 与 $\psi$ 维数均为有限。"

## 核心定位

- **解决的问题**：如何把 Gorenstein 代数与 Gorenstein 投射模的优良同调性质（有限的 finitistic 维数、Igusa-Todorov 函数消失）推广到更大的模类与代数类上。
- **大图景位置**：沿 Gorenstein 投射模 → 半 Gorenstein 投射模 → 局部 Gorenstein 投射模的推广链前进；代数侧则与 virtually Gorenstein 代数（Beligiannis-Reiten）和 weakly Gorenstein 代数（Ringel-Zhang）并列，构成 Gorenstein 代数的三个互不重合的推广族。
- **主要贡献**：
  1. 定义局部 Gorenstein 模类，并对 $X\in\bmod\Lambda$ 构造稳定范畴 $\underline{\mathrm{mod}}\,\Lambda$ 的全子范畴 $\underline{\chi}_X$，证明 syzygy 函子 $\Omega$ 限制在 $\underline{\chi}_X$ 上忠实且全（Theorem 1），方法仿照 Auslander-Bridger。
  2. 证明 Igusa-Todorov 函数 $\phi$ 与 $\psi$ 在整个局部 Gorenstein 模族上取零（Theorem 2），这是半 Gorenstein 投射模所不具备的结构性结论。
  3. 定义局部 Gorenstein 代数并证明其 finitistic 维数、$\phi$-维数与 $\psi$-维数均有限（Proposition 5.4、Theorem 3），从而满足 finitistic 猜想。
  4. 给出 Morita context 代数成为局部 Gorenstein 的充分条件，构造一族具体的局部 Gorenstein 代数实例。
- **关键先驱工作**：Auslander-Bridger（$G$-维数）、Enochs-Jenda（Gorenstein 投射模）、Auslander-Reiten（Gorenstein 代数定义与良好同调行为）、Igusa-Todorov（同调函数 $\phi,\psi$）与 Lanzilotta-Mendoza（Gorenstein 投射模对 Igusa-Todorov 函数消失）、Beligiannis-Reiten（virtually Gorenstein 代数）、Ringel-Zhang（weakly Gorenstein 代数）。
- **结果边界**：局部 Gorenstein 代数与 virtually / weakly Gorenstein 代数互不包含；例如由箭图 $1\rightleftarrows 2$（含环 $\alpha$ 与 $\beta$）及关系 $\{\alpha^2,\beta\alpha\}$ 定义的 bound quiver 代数是 virtually Gorenstein 且 weakly Gorenstein，但不是局部 Gorenstein。定理要求 $\Lambda$ 为 Artin 代数，模为有限生成左模。
- **开放问题**：正文明确留下的开放问题较少，主要开放空间在于局部 Gorenstein 代数判定的完整刻画，以及 Morita context 情形充分条件之外的充要条件。
- **应用与推广**：为 finitistic 维数猜想提供了一族新的（超越 Gorenstein 代数）验证实例；Morita context 构造可作为批量生成局部 Gorenstein 代数的工具，有望与斜群代数、平凡扩张等常见构造结合产生更多例子。
