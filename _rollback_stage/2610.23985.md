# Ramanujan Conjecture and Riemann Hypothesis for the unitary groups over function fields

keywords: [Langlands 函子性, 稳定基变换, 酉群, 函数域, Ramanujan 猜想, Riemann 假设, Langlands-Shahidi L-函数]
related_paper: "L. Lafforgue 关于 $\mathrm{GL}_n$ 函数域 Langlands 对应的工作（La2002）"
one_liner_summary: 在特征 $p$ 下建立拟分裂酉群 $\mathrm{U}_N$ 上整体 generic 表示的稳定基变换，并据此证明酉群 Ramanujan 猜想与扩展 Langlands-Shahidi L-函数的 Riemann 假设。

## 核心定位

- **解决的问题**：在函数域上为酉群建立（generic 表示的）局部与整体 Langlands 函子性——稳定基变换，并解决两个经典算术问题：Ramanujan 猜想与自守 L-函数的 Riemann 假设。
- **大图景位置**：这是数域情形（Kim-Krishnamurthy 对酉群、CKPSS 对经典群、Arthur 与 Mok 的内窥分类）在正特征的对应物；在缺乏特征 $p$ 稳定迹公式的条件下，作者用 Langlands-Shahidi 方法与 converse theorem 的组合绕开迹公式，为酉群建立类 Weil 猜想的自守 L-函数理论。
- **主要贡献**：
  1. 整体层：为 $\mathrm{U}_N(\mathbb{A}_F)$ 的整体 generic cuspidal 自守表示建立"弱"基变换（所有非分歧位与局部基变换一致，Proposition weakBC），再利用 L-函数的解析性质升级为"强"基变换（每处一致，Theorem strongBC），目标为 $\mathrm{GL}_N(\mathbb{A}_E)$ 上互异酉 cuspidal 表示的 isobaric 和。
  2. 局部层：通过"整体到局部"论证证明 generic 局部基变换的存在性（Theorem localLC），由保持局部 L-函数、$\gamma$-因子与根数唯一刻画；tempered 性由纯局部论证获得，整体证明经 Langlands 分类递归化为超尖点情形。
  3. 算术应用：Theorem mainthm 证明扩展 Langlands-Shahidi L-函数有理、满足函数方程且零点位于直线 $\Re(s)=1/2$；Theorem ramanujan 证明 generic cuspidal 自守表示的每个局部分量 $\pi_v$ 皆 tempered，非分歧处 Satake 参数绝对值均为 $1$。
- **关键先驱工作**：Langlands-Shahidi 方法在正特征的发展（LomLS）与 $\gamma$-因子稳定性引理；Cogdell-Piatetski-Shapiro converse theorem；Lafforgue 的 $\mathrm{GL}_n$ 函数域 Langlands 对应（La2002）；Kim-Krishnamurthy 数域酉群基变换（KiKr2004, KiKr2005）；Mœglin-Tadić 离散序列构造与 Tadić 酉表示分类；Asai L-函数理论（HeLo2013, Lo2016）。
- **结果边界**：整体结论限定在 globally generic cuspidal 自守表示；非 generic 情形的局部因子研究依赖 Shahidi 的 tempered L-packet 猜想（特征 0 已知，特征 $p$ 仅由 Ganapathy-Varma 对分裂经典群验证）；全程假设基域为函数域，且未依赖稳定迹公式。
- **开放问题**：Shahidi tempered L-packet 猜想在函数域酉群一般（非分裂或非 generic）情形的完整验证；非 generic 表示的强基变换推广。
- **应用与推广**：稳定基变换把酉群上的算术问题（Ramanujan、零点分布）转运到 $\mathrm{GL}_N$，可进一步用于 Asai/扭 Asai L-函数与 Rankin-Selberg 乘积 L-函数的零点与特殊值研究；其"整体到局部"模板或可迁移到其他经典群（辛群、正交群）的正特征基变换问题。
