# Cospan contexts and higher categories

keywords: [cospan, 高阶范畴, 配边假设, 扭曲箭头范畴, 伴随]
related_paper: "Haugseng 的 $n$ 重 span 构造（Haugseng2018）"
one_liner_summary: "本文引入 $n$-cospan context（配备可容许迭代余跨及其推出复合的 $1$-范畴），证明一切 $n$-范畴均可由其忠实建模，并构造 $\flat_n \dashv \Cospan_n$ 伴随，把高阶范畴论约化到 $1$-范畴语言，为将配边假设改写为 $1$-范畴陈述铺路。"

## 核心定位

- **解决的问题**：高维范畴（$n \geq 3$）极难操作，扩展 TQFT 的目标范畴与 dualizability data 难以处理；能否用 $1$-范畴与推出（pushout）复合来忠实建模 $n$-范畴？
- **大图景位置**：这是把配边假设（cobordism hypothesis）——某 $n$-范畴万有性质的陈述——转译为 $1$-范畴陈述的第一步；同时统一并推广 Haugseng 的 $n$ 重 span 构造与扭曲箭头范畴（twisted arrow category）构造。
- **主要贡献**：
  1. 定义 $n$-cospan context：范畴 $\sC$ 配备可容许 $m$-余跨子空间 $\bAC_m(\sC)$（$0 \leq m \leq n$），满足边界保持与经迭代推出复合封闭两条性质；全体构成范畴 $\bAC_n\Cat$，$\Cat^{\mrm{po}}$ 全忠实嵌入；
  2. 构造函子 $\Cospan_n : \bAC_n\Cat \to \Cat_n$，推广 Haugseng 的 $\Cospan_n : \Cat^{\mrm{po}} \to \Cat_n$；
  3. 构造 flattening 函子 $\flat_n : \Cat_n \to \bAC_n\Cat$：其对象为 $\sC$ 的 $n$-态射，态射为态射的因子分解，$n=1$ 时 $\flat_1(\sC) \simeq \Tw(\sC)$；可容许 $m$-余跨与 $\sC$ 的 $m$-态射一一对应；
  4. 证明伴随 $\flat_n \dashv \Cospan_n$，推广到 $\bbE_k$-幺半结构后仍成立，且左伴随全忠实。
- **关键先驱工作**：Haugseng 的 span $n$-范畴构造；Baez-Dolan 与 Lurie 的配边假设；扭曲箭头范畴及其左纤维化刻画；Tanaka 关于未定向加厚流形与嵌入的万有性质；Grothendieck-Lurie straightening-unstraightening 对应。
- **结果边界**：$n$-范畴按完备 $n$ 重 Segal 空间建模（模型无关框架），严格 $n$-范畴只是全子范畴；配边假设的完整证明仍需在 $n$-cospan context 中表达 dualizability data，本文未完成这一步。
- **开放问题**：$\flat_n(\sC)$ 在 $n \geq 2$ 时是否也构成左纤维化、分类何种映射空间函子；$\bAC_n\Cat$ 中除笛卡尔闭性外还能发展多少 $n$-范畴理论；$\flat_n(\Bord_{n,n}^X)$ 与 Tanaka 加厚流形范畴取余极限后的关系。
- **应用与推广**：为扩展 TQFT 提供 $1$-范畴化框架；把高维态射复合编码为推出，与流形的切拼及 handle 分解的范畴化直接衔接，指向无向配边假设的新证明路径。

### 批判性思考

- 可容许余跨的选取对"边界保持"与"推出复合保持"要求较高，实际构造中验证这些封闭性可能需要额外技术条件。
- 模型无关框架下"唯一即收缩（contractible）"的处理是否掩盖了严格性与同伦性之间的微妙差别，值得在具体模型中检验。
