# Rank and Border Rank Additivity of Complex Tensors with a Hankel Summand

keywords: [张量 CP 秩, 对称秩, border rank, Hankel 张量, Strassen 直和猜想]
related_paper: "Nie--Ye, Hankel tensor rank (2019)"
one_liner_summary: 证明阶数至少 3 的复 Hankel 张量的 CP 秩对任意同阶复张量相加具有可加性，并证明普通与对称 border rank 在复 Hankel 张量直和上相等且可加，其公共值等于中间二元 catalecticant 秩之和。

## 核心定位

- **解决的问题**：研究 Strassen 直和猜想在"一个直和项为复 Hankel 张量"时的正例：CP 秩、对称秩与两类 border rank 的直和可加性问题。Strassen 1973 年猜想三阶张量 CP 秩直和可加，2019 年被 Shitov 反例否定；本文给出一类广泛的正例。
- **大图景位置**：位于张量分解复杂度理论（CP 秩、对称秩/Waring 秩、border rank 与近似算法）与 Hankel 张量结构理论的交叉点。Hankel 张量具有生成序列、Vandermonde 分解等结构，且复 Hankel 张量的 CP 秩与对称秩相等（Holden 精确公式），成为直和可加性的理想研究对象。
- **主要贡献**：① 对任意阶 $m\ge3$，复 Hankel 张量与任意同阶复张量的 CP 秩可加；结合已知的 CP/对称秩相等，当另一项 CP 秩等于对称秩时对称秩也可加（特别地两个 Hankel 张量相加成立）；② 任意公共阶 $\ge3$ 的复 Hankel 张量直和上，普通与对称 border rank 相等且可加，公共值为各项中间二元 catalecticant 秩之和；③ 三阶情形进一步证明：另一项 border rank $\le3$ 时 border rank 可加；另一项为对称张量且本质变量至多 5 时，普通与对称 border rank 相等（从而两类 border rank 可加）。
- **关键先驱工作**：Hitchcock/Kruskal 的 CP 秩与 Kolda--Bader、Landsberg 的标准叙述；Comon 对称秩猜想；Strassen 1973 直和猜想与 Shitov 2019 反例；Schönhage 1981 与 Christandl--Gesmundo--Michałek--Zuiddam 2021 的 border rank 反例；Nie--Ye 的 Vandermonde 秩算法与 Hankel 张量秩等式；Holden 的精确公式与 $\Delta_c(H)=0$。
- **结果边界**：CP 秩可加性要求 $m\ge3$ 且 Hankel 项为复张量；border rank 可加性限于 Hankel 直和，三阶扩展限于 border rank $\le3$ 或对称且本质变量 $\le5$；一般对称 border rank 可加性（$\underline{\Delta}_s=0$）在 $\mathbb C$ 上仍未解决。
- **开放问题**：一般对称 border rank 直和可加性是否在 $\mathbb C$ 成立仍未解决；Hankel 张量之外还有哪些结构族可作为直和可加性的正例有待探寻。
- **应用与推广**：border rank 可加性与中间 catalecticant 秩公式可直接用于近似复杂度下界估计与快速矩阵乘法分析；Hankel 张量分解与矩方法（Artinian Gorenstein 代数、多项式-指数表示）的联系使结果可迁移至多项式根与张量分解的乘法算子方法。
