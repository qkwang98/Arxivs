# The center conjecture for cyclotomic Hecke algebras and cohomology of quiver varieties

keywords: [中心猜想, cyclotomic Hecke 代数, Ariki--Koike 代数, Nakajima quiver variety, Jucys--Murphy 中心]
related_paper: "arXiv:2610.22669"
one_liner_summary: 对无环 quiver 证明 Nakajima quiver variety 的任意域上同调环与对应 cyclotomic KLR 代数的 Jucys--Murphy 中心同构，从而推出 type $G(r,1,n)$ cyclotomic Hecke 代数在任意特征、$q\ne1$ 下中心由 Jucys--Murphy 元素对称多项式生成，并整环化推广 Krylov--Paegelow--Shlykov 关于 Gieseker 簇 $K$-理论与其余中心的猜想。

## 核心定位

- **解决的问题**：证明 McGerty 提出的中心猜想——Ariki--Koike 型 cyclotomic Hecke 代数 $\mathcal{H}_n$（type $G(r,1,n)$，$q\ne1$）的中心等于其 Jucys--Murphy 元素 $L_1,\dots,L_n$ 的对称多项式代数，且要在任意特征、任意域乃至 $q-1$ 可逆的交换整环上成立。
- **大图景位置**：这是几何表示论与 Hecke 代数理论的交汇点：weight space 的几何侧（quiver variety 上同调）与代数侧（KLR 代数中心）之间的同构被推广到任意域；在仿射 $A_{e-1}^{(1)}$ 型与任意特征下补上了 Shan--Varagnolo--Vasserot 与 Webster 的有限型方法（依赖 current 代数表示论）无法覆盖的缺口。
- **主要贡献**：① 主定理：构造代数同态 $\phi_{\kk}:H^*(\mathcal{M}_{\Lambda,\alpha};\kk)\to Z(R_n^\Lambda[\alpha](\kk))$，$\phi_{\kk}(c_{i;j})=e_{i;j}$，其像是 Jucys--Murphy 中心且总是同构（故 $\phi_{\kk}$ 单）；$\phi_{\kk}$ 为同构当且仅当 JM 中心等于全中心，等价于维度不等式 $\dim H^*\ge\dim Z$；当每连通分量是同一 $e$-环且 $p=0$、$p\nmid e$ 或 $p=e$ 时为同构；② 定理 B：任意域上 $q\ne1$ 时中心猜想成立；③ 定理 C：Krylov--Paegelow--Shlykov 猜想的整环化推广，包括正特征版本：$K$-理论 $K(\mathcal{N}_{\Lambda};\kk)$ 与对应 Hecke 代数分块中心同构，并给出 Gieseker 簇与 generic cyclotomic Hecke 代数余中心的兼容同构。
- **关键先驱工作**：Brundan--Kleshchev 的 KLR 代数与 Hecke 代数分块同构；有限型 A 的 Brundan 与一般有限型的 Shan--Varagnolo--Vasserot、Webster 的中心同构；McGerty--Nevins 的 Kirwan 满射性；Nakajima 的 quiver variety 上同调余生成；Jucys--Murphy 的对称群中心定理与 Brundan 的退化 Ariki--Koike 版本。
- **结果边界**：仿射 $A_{e-1}^{(1)}$ 型条件（每连通分量为同一 $e$-环）对 $p$ 的限制正是中心维数已知的特征；$q=1$ 情形由 Ariki 的例子表明假设必要；整环结论要求 $q,Q_1,\dots,Q_r,q-1$ 均为单位（如 $\mathcal{S}_{\mathrm{Ac}}$）；$e=2$ 亦被覆盖，但 $e=1$（即非分圆情形）不在讨论范围。
- **开放问题**：Kirwan 像核的闭式表述仍然未知（目前只能逐点用环面不动点定位确定核）；JM 中心在任意特征下是否总等于全中心（对一般图、一般 $p$）仍取决于中心的维度计数；余中心与 $K$-理论的整性对应是否可推广到非 Jordan quiver。
- **应用与推广**：为 Ariki--Koike 代数中心的显式基与表示论应用（如模块结构、分块判别）提供统一证明；把 quiver variety 上同调作为 JM 中心的正则化模型，可用于 KLR 代数与 Hecke 代数模的范畴化研究；divided-power 对应与 loop 代数整形式的技术可迁移到其他几何--代数对偶。

## 主动思考区

### 与其他工作的联系

- 这让我想起：cyclotomic Hecke 代数表示论与仿射李代数特征标的经典对应 — 见 [[2610.22669]]
- [[2610.22669]]：研究参数为 $1$ 与 $-1$ 的 cyclotomic Hecke 代数分块与 string functions 的联系，与本文同属 Ariki--Koike 型代数的结构问题，可对照分块与中心的结构层级。
- [[2610.21576]]：Jung--Kim 猜想的证明同样处理"中心等于某类对称元素代数"型问题（walled Brauer 代数），并使用了兼容 Hecke/KLR 作用的强等变等价技术，与本文的 JM 中心论证互为姊妹技术。
- [[2610.22156]]：双仿射 Frobenius Hecke 代数也讨论 generic 参数下的中心，说明"中心由显式对称多项式生成"这一模式在更广 Hecke 型代数族中的普适性。
- 技术迁移："构造代数同态 + 上界维度计数 + 循环性/余生成保证单性"的三步证明框架，或可迁移到 Hecke 范畴化中的其他同构问题（如中心与 Hochschild 上同调、余中心与 $K$-理论）。

### 可以尝试的方向

- [ ] 能否把维度不等式 $\dim H^*\ge\dim Z$ 对任意特征的一般图也建立起来，从而去掉 $e$-环与特征条件的限制？
- [ ] 将定理 C 的整性同构推广到其他 quiver（如星形或带边权的 Jordan 型）的核 $K$-理论。

### 批判性思考

- 注入性最终依赖 $\phi$ 作为更大代数（loop 代数整形式）表示之间的映射这一结构，而不仅是环同态；当特征整除某些组合系数导致 divided-power 结构退化时，该论证是否仍对任意 $\kk$ 封闭值得推敲。
- Kirwan 满射性大幅简化了构造，但核的缺失使维度计数仍依赖两端的独立估计；若未来给出核的闭式表述，或可得到更直接的满性证明。
