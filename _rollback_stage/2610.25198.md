# Finitely enhanced nontopological triangulated categories

keywords: [三角范畴, 拓扑三角范畴, 有限增强, 厚子范畴, A-infinity 结构, Toda bracket, Mac Lane 上同调]
related_paper: "2608.03212"
one_liner_summary: 对每个非零交换环 $R$ 构造一个 $R$-线性三角范畴，其有限生成厚子范畴均为代数三角范畴（即"有限增强"），但整个范畴不存在拓扑实现，从而否定"有限增强蕴涵拓扑实现"的猜想。

## 核心定位

- **解决的问题**：一个三角范畴若所有有限生成厚子范畴都是代数的（称为"有限增强"），是否必然存在拓扑实现（即全忠实三角函子嵌入某个稳定模型范畴的同伦范畴）？本文给出否定回答。
- **大图景位置**：延续 Muro–Schwede–Strickland 构造首个非拓扑三角范畴、Rizzardo–Van den Bergh 构造不可增强三角范畴的研究路线，把"局部代数、整体非拓扑"现象推广到任意非零交换环上，并首次在一般环系数下验证忠实标量作用。
- **主要贡献**：①主定理：对任意非零交换环 $R$，存在小 $R$-线性三角范畴序列 $(\mathcal D_n)_{n\ge 0}$，满足每项代数、$\mathcal D_n$ 是 $\mathcal D_{n+1}$ 的厚子范畴、直极限 $\varinjlim \mathcal D_n$ 非拓扑、标量作用 $R\to Z(\mathcal D_n)$ 单射；②构造技术：给分次代数 $B[v,v^{-1}]$（$|v|=2$）配备两个极小 $A_\infty$-结构 $\Lambda_\pm$，其完美范畴三角等价但更大的子范畴 $\mathcal V_\pm$ 通过四重 Toda bracket 区分 $M_4$；③建立四重 Toda bracket、Yoneda 4-扩张与 Mac Lane 上同调群 $\mathrm{HML}^4$ 之间的桥梁作为拓扑障碍。
- **关键先驱工作**：Muro–Schwede–Strickland 的 Hopf 映射障碍；Rizzardo–Van den Bergh 通过不提升为 $A_\infty$-函子的三角函子粘合代数范畴构造不可增强范畴；Díaz Cabrera–Muro 在 preprojective 代数 $P(\mathbb L_2)$ 上构造非拓扑预三角结构；He–Le 证明其满足八面体公理。
- **结果边界**：构造依赖基数论证证明 $\eta\ne 0\in \mathrm{Ext}_B^4(M,M)$，并依赖 $R$ 为非零交换环；直极限的非拓扑性通过序列 $(\chi_M(z_i))$ 的"最终常值"与"交替取值 $0$ 与 $\eta$"之间的矛盾确立，框架未必直接推广到非交换或退化环。
- **开放问题**：作者未明示的开放问题包括：有限增强是否蕴涵某种更弱的增强性质（如可增强为 $A_\infty$-范畴但非拓扑）；以及在更高阶 Toda bracket 或更高维 Mac Lane 上同调中能否构造类似的区分不变量。
- **应用与推广**：结合三角范畴与表示论已有知识，该构造为"代数性局部性质"与"拓扑实现全局性质"的分离提供新例证，可用于测试稳定模型范畴的嵌入理论，也可将 Toda bracket 与 Mac Lane 上同调的联系推广到导出范畴与 $A_\infty$-范畴的研究。

- [[2610.14420]]：在张量三角范畴中借助紧 tilting generator 研究平坦与幽灵维数，与本文用完美范畴与厚子范畴区分 $A_\infty$-结构的技术路径互补。
