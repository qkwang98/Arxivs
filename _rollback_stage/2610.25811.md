# Principal bundles in supersymmetry

keywords: [超主丛, 超流形, 超 Lie 群, Batchelor 定理, 商超流形]
related_paper: "[[2610.25564]]"
one_liner_summary: "本文系统研究 $C^{\infty}$-超流形与任意特征完备域上解析超流形的超主丛基本问题，证明超主丛与普通主丛之间的一一对应（含广义等变 Batchelor 定理），并建立齐性超流形 $G/H$ 的商与重构定理。"

## 1.  核心定位

- **解决的问题**：超主丛的三个基本问题——(P1) 在适当假设下证明 $X/G$ 是超流形且 $X\to X/G$ 构成 $G$-超主丛；(P2) 建立条件 (A)（$\alpha=(\mathrm{pr},\mathrm{act})$ 为嵌入）与商是超主丛之间的等价性；(P3) 从底超流形 $B$（split）与 $G_{\mathrm{rd}}$-主丛重构 $G$-超主丛。
- **大图景位置**：超主丛是超对称规范场论的几何基础（BBH、E 等），本文把普通流形主丛理论的基本定理系统"超化"，并以广义等变 Batchelor 定理填补 $C^{\infty}$ 情形下的关键缺口；在解析情形处理任意特征完备域，对齐性超流形给出与 Vishnyakova 分裂性研究互补的判据。
- **主要贡献**：① 构造 $X/G$（子层结构）并证明其共等化子性质；② $C^{\infty}$ 情形证明 (P2) 等价定理（Hausdorff 且第二可数时条件 (A) 与超主丛结构等价）；③ 对应定理：$G$-超主丛与 $G_{\mathrm{rd}}$-主丛一一对应，依赖广义等变 Batchelor 定理（每个 $G_0$-超主丛是 $G_0$-split 的）；④ 齐性超流形定理（$\mathrm{Thom}1$–$3$）：$G/H$ 是超流形、$G$ 是 $H$-超主丛，给出结构层的局部/全局描述，并在解析情形给出 (a) 特征 0 且 $\mathfrak{h}_{\bar0}$ 半单、$\pi_0(H_{\mathrm{rd}})$ 有限，或 (b) $\mathfrak{h}_{\bar1}$ 在 $\mathfrak{g}_{\bar1}$ 中 $G_{\mathrm{rd}}$-稳定 两类充分条件。
- **关键先驱工作**：Batchelor 定理（$C^{\infty}$-超流形 split）及其 Bartocci 等人的优美证明（BBH）；超流形与超 Lie 群的标准参考（Kostant、Manin、DM、CCF、L）；Vishnyakova 对复解析齐性超流形分裂性的研究（V1、V2）；作者与 Oe、Takahashi 的代数类比（MOT、MT），后者处理仿射代数超群概形的齐性超概形。
- **结果边界**：要求局部奇维数恒定（奇维数非常数情形排除）；底空间一般不假设 Hausdorff 或第二可数，但 $C^{\infty}$ 的强结果（等价定理、对应定理、等变 Batchelor）要求底空间与群 Hausdorff/第二可数；解析情形的齐性定理仅在特征 0 半单或奇部稳定两类假设下成立（齐性超流形一般不 split）。
- **开放问题**：解析情形 $G/H$ 分裂性的完整刻画（Vishnyakova 部分结果如何统一到本文框架）；一般超 Lie 群自由作用的商存在性（作者指出方法可推广）；$C^{\infty}$ 与解析两条路线的代数类比在正特征超概形上的进一步展开。
- **应用与推广**：为超规范场论提供严格的几何基础；Hopf-超代数作用（$G_{\mathrm{rd}}\ltimes\mathrm{hy}(G)$）刻画等变态射，可迁移到量子超群或超模表示；商构造与等变下降定理可用于计算超流形上的超主丛分类（如奇部 Čech 上同调与 torsor 分类）。
