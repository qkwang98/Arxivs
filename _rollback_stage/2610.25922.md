# Brauer and iquantum categorification

keywords: [Brauer 范畴化, iquantum 范畴化, 2-iquantum 群, 仿射 Brauer 范畴, Kac–Moody 范畴化, cyclotomic 商, 量子对称对]
related_paper: "Gao, Rui and Song 关于 AIII$_{2\infty}$ 型 Brauer/iquantum 范畴化的 arXiv 工作（2026）"
one_liner_summary: "在特征不等于 2 的代数闭域上、对任意谱，证明仿射 Brauer 范畴的局部有限 Abel 模范畴（Brauer 范畴化）与 2-iquantum 群的偶幂零 2-表示（iquantum 范畴化）互为典范转化，并由此推出两侧变形 cyclotomic 商的范畴等价。"

## 核心定位

- **解决的问题**：仿射 Brauer 范畴 $\AB$ 与 2-iquantum 群 $\UU^\imath(\mathfrak{g})$ 之间是否可建立类似 Heisenberg/Kac–Moody 范畴化的"桥"，即 Brauer 范畴化与偶幂零 iquantum 范畴化能否互相转化。
- **大图景位置**：这是 Kac–Moody 范畴化纲领（Rouquier、Khovanov–Lauda）向 Bao–Wang iquantum 群方向的关键延伸，属于量子对称对表示论的高阶范畴化；将 Gao–Rui–Song 在特征 0、半整数谱（quasi-split 型 AIII$_{2\infty}$）的结果推广到任意谱与任意特征（$\mathrm{char}\ \kk \neq 2$）。
- **主要贡献**：
  1. 定理 A：任何偶幂零 iquantum 范畴化可典范地做成 Brauer 范畴化（正文 $passportcor$）。
  2. 定理 B：任何 Brauer 范畴化可典范地做成偶幂零 iquantum 范畴化，且两构造互逆（正文 $btoq$），从而两概念等价。
  3. 应用：当 $f(u)=\prod_{i\in I} f_i(u-i)$ 时，Brauer 侧 cyclotomic 商 $\cB(f)$ 与 iquantum 侧 cyclotomic 商 $\cC(f_i\,|\,i\in I)$ 等价；特别地，Deligne 范畴 $\underline{\operatorname{Re}}\!\operatorname{p} O_\delta$ 等价于某 iquantum cyclotomic 商。
- **关键先驱工作**：Rouquier 的 Kac–Moody 范畴化与"control by $K_0$"；Khovanov–Lauda–Rouquier 的 2-量子群 $\UU(\mathfrak{g})$ 与 quiver Hecke 代数；Bao–Wang 的 iquantum 群与 icanonical 基；Brundan–Savage–Webster 对 quasi-split iquantum 群的 2-范畴化 $\UU^\imath(\mathfrak{g})$；Rui–Song 的仿射 Brauer 范畴 $\AB$；Gao–Rui–Song 的 AIII$_{2\infty}$ 情形；Heisenberg 范畴化的 HKM 框架。
- **结果边界**：要求 $\kk$ 为特征 $p\neq 2$ 的代数闭域；相关 Satake 图限于 quasi-split AIII 型与 diagonal A 型（含正特征仿射型）；范畴需满足局部有限、偶性与幂零性条件；2-iquantum 群参数需按文中精细约定选取。
- **开放问题**：BWW 中关于非对称 Cartan 矩阵（多数非对称型）的 iquantum 范畴化仍为猜想；内部 bubble 与 0 节点相关的公式被文中证明最为复杂，目前仅完成所列 Satake 类型的检查。
- **应用与推广**：为 type B/C/D 表示论中的经典范畴（正交/辛李代数的 BGG 范畴 $\mathcal O$ 的块、orthosymplectic 超群 $OSp_{m|2n}(\mathbb{C})$ 的有限维表示、经典 Brauer 范畴）提供统一范畴化解释；为 Gao–Rui–Song 关于 $\AB$ cyclotomic 商的一般理论给出概念化重构；揭示 Brauer 范畴的 $\mathbb{Z}$-分次结构。
