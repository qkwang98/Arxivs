# Herzog Class of Codimension $3$ Licci Monomial Ideals

keywords: [licci 理想, Herzog 类, 刚性形变, Schur 函子, 单式理想]
related_paper: "2610.24438"
one_liner_summary: 对三元多项式环 $S=\mathbb{C}[x,y,z]$ 中 $\mathfrak m$-primary 的 licci 单式理想，给出由最小生成元决定的闭式公式以确定其 Herzog 类。

## 核心定位

- **解决的问题**：给定 codimension $3$ 的 licci 理想，能否不依赖具体 linkage 链而直接由理想本身（其最小生成元）确定其 Herzog 类？
- **大图景位置**：Herzog 类把 licci 理想按公共刚性形变分类。codimension $2$ 情形由 Hilbert--Burch 定理完全解决（Herzog 类与最小生成元个数一一对应）；codimension $3$ 情形因生成元个数与 CM type 不再决定 Herzog 类而显著困难。本文对 $\mathfrak m$-primary 单式 licci 理想这一特殊族给出首个闭式公式，填补了"已知 linkage 过程才能计算 Herzog 类"的空白。
- **主要贡献**：其一，利用 Huneke--Ulrich 对 $\mathfrak m$-primary licci 单式理想的显式组合结构构造一条连接 $I$ 到完全交的 linkage 链；其二，借助 Guerrieri--Ni--Weyman 的装饰（decoration）理论得到 Herzog 类的递归公式，该递归是动态的（系数随 linkage 数据逐步行变）；其三，求解该递推关系，得到以 $I$ 的组合数据表达的闭式公式。
- **关键先驱工作**：Peskine--Szpiro 的 linkage 理论；Buchweitz 的 licci 理想强无阻塞性；Herzog 关于强无阻塞代数刚性形变的存在唯一性；Weyman 的 generic ring 与 Kac--Moody 李代数联系（T 形 Dynkin 图）；Guerrieri--Ni--Weyman 对 Herzog 类的 Schur 函子参数化。
- **结果边界**：公式仅适用于 $\mathfrak m$-primary licci 单式理想（$S=\mathbb{C}[x,y,z]$）；一般 codimension $3$ licci 理想尚无直接公式，其 Herzog 类仍需借助显式 linkage 链计算。
- **开放问题**：作者希望本文技术可用于其他 licci 理想族 Herzog 类的直接公式；如何把单式情形推广到非单式 licci 理想是自然后续方向。
- **应用与推广**：闭式公式使 Herzog 类的判定变成对最小生成元集的纯组合检查，可用于批量验证 licci 理想的形变等价；结合表示论（Schur 函子、Kac--Moody 表示）可进一步探索 resolution format 与 Herzog 类的关联。
