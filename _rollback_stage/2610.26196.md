# Simple-shifted monoidal derived equivalences for tensor categories

keywords: [幺半派生等价, 张量范畴, 单对象, 张量等价, 重构定理, 单移位]
related_paper: "2610.14420"
one_liner_summary: 引入 simple-shifted 幺半派生等价概念，证明它必然蕴含张量等价；对具有无穷多个单对象同构类的张量范畴给出若干充分条件，保证任意幺半派生等价都是 simple-shifted，并推出 pointed tensor categories 之间的幺半派生等价蕴含张量等价。

## 核心定位

- **解决的问题**：对具有无穷多个单对象同构类的张量范畴，研究幺半派生等价（monoidal derived equivalence）何时蕴含张量等价。先前结果仅覆盖有限多单对象情形（Xu–Zheng）与半单情形（Tan），一般非半单、无穷多单对象的张量范畴重构问题尚未解决。
- **大图景位置**：在幺半三角范畴的框架下，将 Balmer 张量三角几何与 Nakano–Vashaw–Yakimov 非交换谱理论的研究推进到派生等价层面：派生等价若保持幺半结构，是否足以重构底层的张量范畴。
- **主要贡献**：①引入 simple-shifted 函子的概念，即由三元组 $(F,\psi,r)$ 指定、满足 $F(S)\cong \psi(S)[r(S)]$（对每个单对象 $S$）的三角函子；②证明 simple-shifted 等价保证底层 Abel 范畴等价（命题 prop:equ），且 simple-shifted 幺半等价保证底层多重环范畴张量等价（命题 prop:tensorequ）；③主定理（定理 thm:Cgamma）给出每块满足条件 (i)（单对象存在有限单对象的张量子范畴包含 $S\otimes S^*$ 或 $S^*\otimes S$）或条件 (ii)（存在特殊单对象 $S^\gamma$，其余单对象可写成 $L_S\otimes S^\gamma\otimes R_S$ 且 $L_S\otimes R_S$ 的派生同调集中于零度）时，任意幺半派生等价都是 simple-shifted 的，从而张量范畴等价；④推论：pointed tensor categories 之间的幺半派生等价蕴含张量等价。
- **关键先驱工作**：Balmer 张量三角几何与支撑理论；Nakano–Vashaw–Yakimov 非交换谱与支撑（有限维 Hopf 代数、小量子 Borel 代数应用）；Rickard 派生 Morita 理论（tilting 复形）；Aihara–Mizuno 关于 Dynkin 型 preprojective 代数的结果；Zhang–Zhou 关于有限维遗传弱双代数的结果；Xu–Zheng 有限单对象情形的等价性定理；作者本人（Yu）先前用三角模范畴等价研究无穷多单对象情形的工作；Tan 对半单张量范畴的重构定理。
- **结果边界**：设定在代数闭域上，范畴本质小、对象有限长、子范畴全子范畴；主定理要求张量范畴的每个块满足条件 (i) 或 (ii) 之一；覆盖有限单对象情形（Xu–Zheng）与无穷多单对象的半单情形（Tan）作为特例。
- **开放问题**：一般非半单且具有无穷多单对象同构类的张量范畴，其重构问题尚未完全解决；作者也期望刚性（rigidity）假设在幺半派生等价中发挥本质作用，即此类等价应强制张量等价。
- **应用与推广**：作为直接推论，pointed 张量范畴的幺半派生等价判定退化为张量等价判定；技术路线（t-结构 heart 的允许偏离 + 单对象像的移位追踪）可推广到带刚性的其他幺半三角范畴，如稳定同伦理论中的谱范畴或表示论中的稳定模块范畴。
