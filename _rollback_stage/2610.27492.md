# Lie algebras in symmetric tensor categories

keywords: [对称张量范畴, 李代数, Verlinde 范畴, PBW 性质, Verma 模, Cartan 判据, contragredient 李代数]
related_paper: "Small Lie algebras in the Verlinde category（arXiv:2608.10585）"
one_liner_summary: "在任意特征代数闭域上的对称张量范畴中系统发展李代数的一般理论，建立 Engel 定理、Cartan 判据与强半单李代数导子皆内等经典结果的范畴化版本，构造分级范畴 O 与 Verma 模并证明其分级单对象分类，最后发展 contragredient 李代数的根系理论。"

## 核心定位

- **解决的问题**：经典李理论在任意特征的对称张量范畴中有多少能够存续。许多经典论证依赖向量空间的特殊性质，例如正特征下满足 Jacobi 恒等式的斜对称括号未必具有 PBW 性质，因此从向量空间到对称张量范畴的推广绝非形式平移。
- **大图景位置**：特征零时 Deligne 定理表明中速增长的 pre-Tannakian 范畴都承认到超向量空间的纤维函子，从而可由普通或超群论重建；该直接类比在特征 $p$ 失效，核心反例是 Verlinde 范畴 $\mathrm{Ver}_p$（$p\geq 5$ 时不存在到 $\mathrm{Vec}$ 或 $\mathrm{sVec}$ 的对称张量函子）。Ostrik 进一步证明特征 $p$ 的每个对称融合范畴都承认到 $\mathrm{Ver}_p$ 的对称张量函子，本文为该纲领提供一般性结构工具。
- **主要贡献**：1) 范畴化 Engel 定理：底对象半单且每个单子对象幂零作用时，表示承认被 $\g$ 严格降低的有限滤过；2) 二次与强半单李代数理论：无非零 Abel 理想的有限维二次李代数半单，对 Killing 形式应用即得范畴 Cartan 判据，并证明强半单李代数的每个导子都是内导子；3) 对不变量零（invariantless）对象的刚性结果：相应一阶上同调消没时仿射同态概形有限且既约；4) 构造分级范畴 $\Ocat$ 与 Verma 模 $\Delta(X,d)$，证明每个 Verma 模有唯一分级单商且每个分级单对象如此实现，在 $\mathrm{Ver}_p$ 中证明 $U(\g)$ Noether 且 $\Ocat$ 为 Abel 范畴；5) 定义范畴 Shapovalov 映射：特征零时非退化分级给出 Verma 模的 generic 分级单性，特征 $p$ 在 $\mathrm{Ver}_p$ 的 $p$-幂零假设下证明 baby Verma 模在非空 Zariski 开集上分级单；6) 在 quasi-semisimple 对称张量范畴中建立 contragredient 李代数的单性判据、根串有限时的反射同构与根系理论。
- **关键先驱工作**：Deligne 的 pre-Tannakian 重建定理；Ostrik 关于对称融合范畴到 $\mathrm{Ver}_p$ 的函子与 Coulembier–Etingof–Ostrik 对半单 pre-Tannakian 的推广；Etingof 关于正特征 PBW 性质反例的工作；Verlinde 范畴中仿射群方案、Harish–Chandra 对与一般线性群表示论；APS 在任意对称张量范畴中对 contragredient 李代数的定义。
- **结果边界**：PBW 性质仅在 quasi-semisimple（对称代数保持单态射）范畴中对核的中心商成立；特征 $p$ 中中心 $p$ 次幂阻碍普通 Verma 模的 generic 分级单性，相应结果需要 $\mathrm{Ver}_p$ 中的 $p$-幂零假设；Engel 定理要求每个单子对象幂零作用。
- **开放问题**：一般（非 $p$-幂零）情形下 baby Verma 模分级单性的完整刻画；Shapovalov 映射在更广泛范畴中的判别式理论；一般对称张量范畴中 contragredient 李代数的根系分类与量子群类比的构造。
- **应用与推广**：为 $\mathrm{Ver}_p$ 中仿射群方案、表示论、范畴 Chevalley–Eilenberg 上同调与李代数对象的构造分类提供基础工具；contragredient 构造的范畴化版本可推广到正特征模范畴并用于构造新一类最高权理论。

## 主动思考区

### 与其他工作的联系

- 这让我想起：Verlinde 范畴中李代数对象的构造与分类 — 见 [[2608.10585]]
- [[2608.10585]]：Verlinde 范畴中"小"基于李代数的完全分类，与本文的 Engel/Cartan 理论与结构工具同属 $\mathrm{Ver}_p$ 中李代数结构理论。
- [[2610.28534]]：Taft 代数的张量范畴 2-表示论通过半单化与 adjoint $\mathfrak{sl}_2$ Verlinde 范畴联系，示范了"非半单 → 半单化 → Verlinde 范畴"的分析路线，与本文以 $\mathrm{Ver}_p$ 为基本测试范畴的思路互补。
- 技术迁移：分级范畴 $\Ocat$ 与 Shapovalov 映射的范畴化滤过方法，能否迁移到其他特征 $p$ 的有限张量范畴（如小量子群的整体）以建立类似的最高权理论？

### 可以尝试的方向

- [ ] 对一般有限张量范畴（不限于 $\mathrm{Ver}_p$）检验 $U(\g)$ Noether 性与 $\Ocat$ 为 Abel 范畴的条件
- [ ] 在 quasi-semisimple 假设之外寻找 PBW 性质成立的更弱充分条件
- [ ] 将 contragredient 李代数的根系理论与正特征 Kac–Moody 型分类进行系统对照

### 批判性思考

- quasi-semisimple 条件（对称代数保持单态射）是否本质？能否用更弱的同调条件替代？
- 特征 $p$ 中心 $p$ 次幂对 Verma 模理论的阻碍是否仅出现于 $\mathrm{Ver}_p$，还是所有正特征对称张量范畴的普遍现象？
