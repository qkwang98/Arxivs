# Harder-Narasimhan Filtrations of Hyperquiver Representations

keywords: [超箭图表示, Harder-Narasimhan 滤, 仿射 GIT, Kempf 泛函, 稳定性参数, 斜率]
related_paper: "2608.13375"
one_liner_summary: 用仿射 GIT 与 Kempf 泛函研究超箭图表示的（不）稳定性，证明每个不稳定超箭图表示存在唯一的 Harder-Narasimhan 滤，并给出其权重公式；该公式在箭图情形退化为经典的 Harder-Narasimhan 斜率。

## 核心定位

- **解决的问题**：为超箭图表示（有向超图 + 顶点向量空间 + 超边上张量积之间的线性映射）建立与箭图表示平行的稳定性理论与 Harder-Narasimhan 滤：不稳定对象如何唯一地分解为逐级半稳定的相关分次表示，其权重如何计算。
- **大图景位置**：这是 Reineke 关于箭图表示 Harder-Narasimhan 滤经典定理向超箭图的推广；由于 $\mathrm{Rep}(\mathcal{H})$ 不是 Abel 范畴、子对象难以描述且半稳定性不能仅靠子表示判定，作者放弃直接定义 slope 与子表示，转而经由仿射 GIT（Kempf 泛函、极大去稳定化 1-PS、KKT 条件）给出内禀描述，延续 Zamora、Hoskins（箭图）与 Jones（有限维代数）的路线。
- **主要贡献**：其一，引入 $\mathbb{Q}$-滤与容许 $\mathbb{Q}$-滤的概念，把（容许）1-参数子群翻译为滤 + 有理权重对；其二，证明主定理：对 $\boldsymbol{\theta}$-不稳定的超箭图表示，存在唯一的 Harder-Narasimhan 滤 $(F^\bullet W,\boldsymbol{\ell})$，其相关分次 $\mathrm{gr}(\boldsymbol{\phi})$ 作为细化超箭图 $\mathcal{H}_F$ 的表示对某个平移后的稳定性参数 $\widetilde{\boldsymbol{\theta}}$ 是半稳定的；其三，给出权重公式 $\boldsymbol{\ell}=\boldsymbol{p}/\|\boldsymbol{p}\|_D^2$，其中 $\boldsymbol{p}=-D^{-1}(I-A^\top L^\dagger A D^{-1})\boldsymbol{\Theta}$；对箭图而言误差项 $A^\top L^\dagger A D^{-1}$ 消失，公式化为经典斜率 $\mu_{\boldsymbol{\theta}}(\mathbf{d})$。
- **关键先驱工作**：Gabriel 定理与箭图表示分类；Mumford 的 GIT 与 King 判据（slope 半稳定与 $\theta$-半稳定等价）；Reineke 的箭图表示 Harder-Narasimhan 滤定理；Kempf 的不稳定 1-PS 唯一性定理；Zamora、Hoskins 用仿射 GIT 研究箭图表示稳定性；Jones 对有限维结合代数与李代数的典范滤；超箭图表示的开创性工作 Muller–Nanda–Seigal。
- **结果边界**：主定理要求表示是 $\boldsymbol{\theta}$-不稳定的（$\boldsymbol{\theta}$-半稳定对象只有长度 1 的平凡滤）；权重公式中的 $\boldsymbol{\Theta},D,A,L^\dagger$ 依赖于相关分次 $\mathrm{gr}(\boldsymbol{\phi})$ 的细化超箭图组合数据；与箭图情形不同，超箭图表示的半稳定性不能仅通过长度 1 滤（即子表示）检验；本文允许超边有多个目标顶点（推广了 Muller–Nanda–Seigal 仅允许单目标顶点的设定）。
- **开放问题**：误差项 $A^\top L^\dagger A D^{-1}$ 的精细组合解释与一般超箭图上的显式计算；半稳定性检验在更高步滤上的完全刻画；超箭图表示模空间上由该滤诱导的层化结构（类比箭图情形的 HN 层化）的几何性质。
- **应用与推广**：为超箭图表示的模空间（一般线性群乘积作用下仿射 GIT 商）提供不变量来源——每表示带唯一的 HN 滤及权重；权重公式在箭图退化给出经典 slope，可与箭图表示论中的既有工具衔接；超箭图表示可编码代数、张量结构等众多代数对象，其 HN 理论有望为这些结构的模空间研究提供统一语言。

## 主动思考区

### 与其他工作的联系

- 这让我想起：超表示的模空间与 King 判据的推广 — 见 [[2608.13375]]
- [[2608.13375]]：该文把箭图表示模空间理论推广到超表示（超向量空间上的表示），同样以 $\theta$-稳定性与 GIT 线性化为核心；本文则针对超箭图（张量积型超边）建立 HN 滤理论，两者都处于「超越经典箭图」的模空间研究谱系中，稳定性判据都经由 GIT 而非直接定义子对象给出。
- [[2608.02514]]：该文在平方零扩张的自守函数研究中系统使用 Harder-Narasimhan 层化与最优界；本文的超箭图 HN 滤可视为在表示论侧为类似的层化与最优界计算提供新的对象来源。
- 技术迁移：Kempf 泛函 + KKT 条件的「最优去稳定化」框架不依赖 Abel 范畴结构，可直接迁移到其他非 Abel 的表示类（如张量范畴对象、超代数模）的稳定性研究。
