# Dold--Kan Correspondences via Morita Normalization

keywords: [Dold–Kan correspondence, Morita equivalence, normalized category, crossed simplicial group, duplicial module, paracyclic module, cyclic module]
related_paper: "2610.24720"
one_liner_summary: 本文用 Morita 理论为每个携带保最大单纯算子作用的线性范畴构造规范化（normalization）函子，证明其与原始范畴 Morita 等价，从而对一切 crossed simplicial groups 建立 Dold–Kan 型对应，并证明自对偶等价于自同构群单纯集维数为一，同时恢复 duplicial、paracyclic 与 $N$-cyclic 模的 Dwyer–Kan 对应。

## 1.  核心定位

- **解决的问题**：经典 Dold–Kan 对应将单纯 $k$-模与连通链复形等同；本文问：对哪些（更一般的）线性范畴/指标结构能系统构造 Dold–Kan 型对应，并给出统一的函子性框架。
- **大图景位置**：Dold–Kan 定理自 1958 年来有众多推广（Pirashvili 的 $\Gamma$-群、Słomińska 的函子范畴 Morita 等价视角、Lack–Street 的因子化条件、Lurie 的稳定 $\infty$-范畴版本、Heine 的 2-duplicial 稳定 $\infty$-范畴 Dwyer–Kan 版本）；本文回到经典线性设置，融合 Lyubashenko 的幂等元族与 Getzler 的 Dold–Puppe 投影子思路，建立统一构造，填补了函子性 Dold–Kan 型对应的一般理论空白。
- **主要贡献**：
  1. 抽象 Dold–Kan 对应定理：对每个 $k[\Delta_{\max}]$-ring $\mathcal{C}$ 构造线性范畴 $\Nor(\mathcal{C})$，且 $\mathcal{C}$ 与 $\Nor(\mathcal{C})$ Morita 等价；函子 $\Nor:\mathrm{Ring}_{k[\Delta_{\max}]}\to\mathrm{Ring}_{\Nor(k[\Delta_{\max}])}$ 是范畴等价。
  2. 对一切 crossed simplicial group $\Delta G$ 建立 Dold–Kan 型对应；给出 $\Nor(\Delta G)$ 的 hom-模的秩公式（基于 $G$ 的非退化单纯形）。
  3. 自对偶分类：$(\Delta G)^{\mathrm{op}}\simeq\Delta G$ 等价于 $\Nor(\Delta G)^{\mathrm{op}}\simeq\Nor(\Delta G)$ 等价于 $G$ 的单纯维数为一；且任何此类等价必为同构。
  4. 构造 normalization-compatible 自对偶（paracyclic、paradihedral 范畴用整数上的 order adjoints），并恢复 duplicial、paracyclic、$N$-cyclic 模的 Dwyer–Kan 对应。
- **关键先驱工作**：Dold–Kan 对应（1958）；Pirashvili 的 $\Gamma$-群 Dold–Kan 型定理；Słomińska 的函子范畴 Morita 等价视角；Lack–Street 的因子化条件框架与 Walde 的同伦相干扩展；Lyubashenko 的线性化单纯范畴幂等元族；Dold–Puppe 投影子与 Getzler 对 paracyclic 模的 Dwyer–Kan 定理直接证明；Lurie、Dyckerhoff、Heine 的高范畴化推广。
- **结果边界**：构造要求线性范畴（$k\Mod$-enriched）且对象集上带 $k[\Delta_{\max}]$-ring 结构；Morita 等价给出的是函子范畴 $\Fun_k(\mathcal{C}^{\mathrm{op}},\mathcal{A})$ 与 $\Fun_k(\Nor(\mathcal{C})^{\mathrm{op}},\mathcal{A})$ 的等价（对线性、加法、幂等完备的 $\mathcal{A}$），而非范畴本身同构；自对偶分类的等价性结论限定在单纯维数为一的 crossed simplicial groups。
- **开放问题**：将 Morita normalization 框架推广到更一般的指标范畴（如非单纯型算子族）或高维单纯结构；自对偶分类在单纯维数大于一情形的行为；normalization 与高阶 Dwyer–Kan 对应（Heine）之间的函子性比较。
- **应用与推广**：为 duplicial/paracyclic/cyclic 模理论提供统一构造与自对偶工具；秩公式可用于计算具体 crossed simplicial group 的规范化 hom-模；与循环同调、范数映射及张量三角几何中的结构保持问题衔接。

- Morita 等价的证明是否依赖 $k$ 的交换性，能否推广到非交换系数环或广义系数范畴？
- 自对偶等价必为同构的结论看似强，其证明是否用到了 crossed simplicial group 的特殊结构而非一般线性范畴？
- normalization 构造中保最大单纯算子与保最小单纯算子（$\Delta_{\max}$ 与 $\Delta_{\min}$）的对称性是否被充分挖掘？
