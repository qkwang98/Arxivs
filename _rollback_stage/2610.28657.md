# Ideal balanced pairs in n-exangulated categories

keywords: [n-exangulated 范畴, ideal balanced pair, 理想逼近论, precover, preenvelope, 完备理想余挠三元组, 加法子函子]
related_paper: "arXiv:2608.09777"
one_liner_summary: "本文把理想逼近论引入 $n$-exangulated 范畴：定义 ideal balanced pair，证明满足适当条件的完备理想余挠三元组诱导 ideal balanced pair（并给出逆命题与两个等价刻画），最终证明 ideal balanced pair 等价于一个具有足够投射态射与足够内射态射的加法子函子。"

## 1.  核心定位

- **解决的问题**：在 $n$-exangulated 范畴（Herschend-Liu-Nakaoka 引入的高维推广，统一 $n$-exact 范畴与 $(n+2)$-angulated 范畴）中建立理想逼近论的平衡对理论：定义并刻画 ideal balanced pair，并厘清它与完备理想余挠三元组、加法子函子之间的等价关系。
- **大图景位置**：这是"理想逼近论"（exact 范畴中相对理想的逼近现象研究，FGHT 系列）与"高维同调代数"（$n$-exangulated 范畴、$n$-cluster tilting、$n$-abelian、$n$-exact、$n$-angulated）的交汇；也是 abelian 范畴中 Chen 的 balanced pair 概念、Wang-Li-Huang 的"balanced pairs / Ext 子函子 / Quillen 正合结构"三集合一一对应定理在高维与理想情形的类比。
- **主要贡献**：
  1. 引入 $\mathcal{I}$-resolution 与 ideal balanced pair 的定义：对 strongly precovering ideal $\mathcal{I}$ 与对象 $C$ 构造 $\mathcal{I}$-resolution，并据此定义理想意义下的平衡对。
  2. 证明满足适当条件的完备理想余挠三元组 $(\mathcal{I},\mathcal{K},\mathcal{J})$ 诱导 ideal balanced pair $(\mathcal{I},\mathcal{J})$（定理 Th0），并在合适假设下建立逆命题（定理 Th2）；同时给出 ideal balanced pair 的两个等价刻画（定理 Th1）。
  3. 引入 object ideal balanced pair，建立 $(\mathcal{I},\mathcal{J})$ 与 $(\mathrm{Ob}\mathcal{I},\mathrm{Ob}\mathcal{J})$ 的关系，证明 $(\mathcal{I},\mathcal{J})$ 是 ideal balanced pair 当且仅当存在加法子函子 $\mathbb{F}=\mathbb{E}_{\mathcal{I}}=\mathbb{E}^{\mathcal{J}}$ 具有足够 projective morphisms 与足够 injective morphisms，且 $\mathcal{I}=\mathbb{F}\text{-}\mathbf{proj}$、$\mathcal{J}=\mathbb{F}\text{-}\mathbf{inj}$。
- **关键先驱工作**：Iyama 的 $n$-cluster tilting 子范畴与高维 Auslander 对应；Jasso 的 $n$-abelian / $n$-exact 范畴；Geiss-Keller-Oppermann 的 $n$-angulated 范畴；Herschend-Liu-Nakaoka 的 $n$-exangulated 范畴（统一上述结构并推广 Nakaoka-Palu 的 extriangulated 范畴）；exact 范畴与 extriangulated 范畴中的理想逼近论（FGHT、XFGS）；abelian 范畴中 Chen 的 balanced pair 与 Wang-Li-Huang 的三集合对应。
- **结果边界**：完备理想余挠三元组诱导 ideal balanced pair 需要满足"适当假设"（具体条件见正文 Th0），逆命题（Th2）在额外假设下成立而非无条件；加法子函子刻画依赖 $n$-exangulated 范畴的结构（$\mathbb{E}$ 与理想态射类兼容）；目前结论在 $n$-exangulated 框架下陈述，$n=1$ 时退化到已知的 extriangulated / exact 情形。
- **开放问题**：能否去掉 Th2 的额外假设得到逆命题的无条件版本；能否建立类似 Wang-Li-Huang 的"ideal balanced pairs / 理想子函子 / 理想正合结构"三方完全一一对应；以及 ideal balanced pair 理论在 $n$-cluster tilting 子范畴（Salce 引理等）中的应用推广。
- **应用与推广**：为高维范畴中的逼近理论提供工具：special precovering / preenveloping 理想的研究可借助 ideal balanced pair 统一处理；与完备理想余挠三元组的等价性可迁移自 cotorsion 理论（模型范畴、凝聚层范畴等）的既有结果；加法子函子刻画给出构造性判定方法，便于在具体 $n$-exangulated 范畴（如 $n$-cluster tilting 子范畴、$n$-exact 范畴）中检验平衡性。
