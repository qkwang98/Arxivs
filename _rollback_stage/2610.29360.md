# Curvature, second variation and Jacobi fields in elastic diffeology

keywords: [弹性微分空间, 曲率, Levi-Civita联络, 第二变分, Jacobi场, 指标形式, 截面曲率]
related_paper: "Riemannian geometry on elastic diffeological spaces (Shiobara)"
one_liner_summary: 在 Blohmann 弹性微分空间上引入曲率张量联络，证明曲率满足经典 Riemann 对称性，建立第二变分公式与指标形式、Jacobi 场的存在唯一性，并指出一般无法通过求迹定义 Ricci 张量。

## 1.  核心定位

- **解决的问题**：把 Riemann 几何的二阶变分理论（曲率、第二变分公式、Jacobi 场、指标形式）推广到 Blohmann 弹性微分空间上，弥补前作留下的"曲率态射与 Riemann 度量相互作用"空白。
- **大图景位置**：微分空间（diffeology）推广光滑流形，涵盖奇异商与无穷维空间；本文在切线范畴（tangent category）框架下补全 Riemann 几何核心内容，使 Morse 理论的局部工具在弹性微分学中可用。
- **主要贡献**：1) 引入曲率张量联络（curvature-tensorial connections），曲率经投影 Π: T^3M→T_3M 唯一分解为三线性态射；2) 用沿 plot 的换位子恒等式与弹性公理证明 Riemann 张量四类经典对称性；3) 证明第二变分公式（能量 Hessian = 指标形式），刻画其零空间；4) 在 (SH1)–(SH3) 假设下证明 Jacobi 场的存在唯一性；5) 证明非正截面曲率排除共轭点、负指标方向阻碍长度极小化。
- **关键先驱工作**：Souriau 与 Iglesias-Zemmour 的微分空间理论、Blohmann 的切函子与弹性空间、Rosický 与 Cockett–Cruttwell 的切线范畴、Goldammer–Welker 的联络与度量研究、作者前作的一阶变分理论。
- **结果边界**：点态验证依赖弹性公理 (E1) 保证有限族切向量可嵌入单个 plot；Ricci 张量在 C^∞(S^1,S^2) 上不可由求迹得到（算子非迹类）；Jacobi 场唯一性需要 (SH1)–(SH3) 与曲线对象条件；文中明确不证明 Morse 引理、指标定理与一般局部极小性定理。
- **开放问题**：Ricci 张量的一般定义与替代构造；完整的 Morse 理论（指标定理）在弹性微分空间上的建立；无穷维映射空间上更精细的谱理论。
- **应用与推广**：可为带 L^2 度量的映射空间 C^∞(Σ,N) 提供变分几何工具，用于调和映射与测地线理论；弹性微分学框架有望统一奇异商空间上的几何分析。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 暂无匹配的已有笔记（当前知识库中无微分空间/弹性微分几何相关条目）。
- 技术迁移：用"plot 坐标系 + 沿 plot 的场"代替全局向量场的局部化技巧，可迁移到其他缺乏足够光滑函数的无穷维或奇异几何设置中。

### 2.2.  可以尝试的方向

- [ ] 能否在弹性微分空间上构造一个合理的"正则化 Ricci 张量"，绕过迹类障碍？
- [ ] 截面曲率非正与共轭点排除的结论能否推广到带边界的测地线段？

### 2.3.  批判性思考

- 曲率张量联络的"唯一分解"依赖 Π: T^3M→T_3M 是 subduction；该 subduction 性质在一般微分空间（非弹性）是否仍成立是潜在的隐含假设。
- 第二变分公式要求能量泛函光滑且指标形式对称，这强依赖曲率张量联络条件；若只取一般垂直联络，二阶变分是否仍良定义值得考察。
