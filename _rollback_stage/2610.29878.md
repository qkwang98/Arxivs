# On unitary vertex operator algebras

keywords: [酉性, 顶点算子代数, 共形顶点代数, W-代数, 自由场实现, 正能模, 中心荷]
related_paper: "Kac--Möseneder Frajria--Papi, 前作中的 Conjecture 3 (KMP1)"
one_liner_summary: 证明带非零不变 Hermitian 形式的共形顶点代数只要承认非零正定正能模即酉，并借此给出主简单 W-代数及若干 $sl_2$-子代数情形 W-代数酉性层次的精确刻画。

## 核心定位

- **解决的问题**：确定哪些（简单）W-代数 $W_k(\g,\mathfrak s)$ 是酉的：既要从一般原则推出"酉模存在 ⇒ 代数酉"的判定，又要对主 $sl_2$-子代数给出中心荷的显式下界，并对一般（偶）$sl_2$-子代数证明酉性只可能发生在有限多个水平 $k$。
- **大图景位置**：这是作者前作（KMP1）中 Conjecture 3 的正面解决，将共形顶点代数的酉性判定归结为正能模的存在性；它把酉表示论（正定 Hermitian 形式、正能性）与 W-代数的自由场实现、Feigin--Frenkel 对偶统一起来，是顶点代数物理（幺正共形场论）与李理论之间的桥梁。
- **主要贡献**：1. 一般定理（Theorem 11）：带非零不变 Hermitian 形式的共形顶点代数若承认非零酉正能模，则其本身酉；2. 主 W-代数：简单李代数 $\g$ 的主简单 W-代数 $W_k(\g)$ 在 $c_{\g,k}\ge \rank(\g)+24\big((\rho|\rho^\vee)+\|\rho\|\|\rho^\vee\|\big)$ 时酉；若 $\g$ 单连通型（simply laced）则 $c\ge\rank(\g)$ 即酉；3. 超情形：自由场论证适用于 $osp(1|2n)$（$c\ge n+\tfrac12$）与 $osp(2|2n)$（显式下界），并说明对其它非李代数的 basic Lie superalgebra 存在双重障碍（Cartan 子代数实形式上 Hermitian 形式的正定性、$\rho$ 与 $\rho^\vee$ 的比例性）；4. 有限性定理：若 $\g$ 为简单李代数、$\mathfrak s$ 为偶 $sl_2$-子代数且其中心化子非交换，则 $W_k(\g,\mathfrak s)$ 至多对有限多个 $k$ 酉，并以 $sl_{qm}$ 的 Jordan 型 $q^m$ 幂零元为例（酉性只可能出现在两个水平，$q=2$ 时两处都出现；如 $sl_4$ 的 $2+2$ 型仅在 $k=-2$ 与 $k=-\tfrac32$ 酉）；5. 非 distinguished 情形：$\g$ 简单且 $\mathfrak s$ 非 distinguished 时同样只有有限多个酉水平，进而提出"酉水平无限多当且仅当 $\mathfrak s$ 为主 $sl_2$-子代数"的猜想。
- **关键先驱工作**：KMP1 的 Conjecture 3；Carpi--Tanimoto--Weiner 对 $W_3$ 代数（$sl_3$、$c\ge2$）的酉性证明；Feigin--Frenkel 对偶及对 $osp(1|2n)$ 的变体；Miura 映射的单射性（用于在非实水平建立对偶）；Arakawa 学派对 W-代数坍缩（collapsing）的检测。
- **结果边界**：一般定理要求存在"非零酉正能模"，且不变 Hermitian 形式非零；超情形的自由场论证仅适用于 $osp(1|2n)$ 与 $osp(2|2n)$（对 diagram 型对合而言仅此二者）；对 basic Lie superalgebra 存在两类结构性障碍；对一般 $sl_2$-子代数只证有限性，不给出酉水平的完整分类；$sl_4$ 的结论基于收集已知结果形成的表。
- **开放问题**：非 distinguished 非主 $sl_2$-子代数情形的完整酉水平分类（猜想：酉水平无限当且仅当 $\mathfrak s$ 为主）；$B_n\ (n\ge4)$、$C_n\ (n\ge3)$、$D_n\ (n\ge4)$、$E_6,E_7,E_8,F_4,G_2$ 等存在 distinguished 非主子代数的类型。
- **应用与推广**：为幺正共形场论中 W-代数的物理可实现性提供代数判据；主 W-代数酉下界可与仿射 WZW 模型、可积表示的正能性条件对照；有限性定理可用于排查候选酉 W-代数，指导表示论与顶点代数中"酉模型"的搜索。

## 主动思考区

### 与其他工作的联系

- 暂无匹配的已有笔记：当前笔记库中未收录顶点代数/W-代数方向的直接相关笔记；若后续收录 Kac 学派 W-代数或共形场论相关文献，可与此建立双向链接。
- 从技术层面看，该文的"正能模 ⇒ 酉"判据与李代数表示论中"K-型正定 ⇒ 整体酉"的经典思路同源，可迁移到其他带 Hermitian 形式的代数对象（如量子群、Drinfel'd 双重）的酉性判定。
- 技术迁移：Feigin--Frenkel 对偶在非实水平上的成立（借 Miura 映射单射性）这一技巧，或可迁移到其它需要在对偶参数域外使用对偶定理的场景。

### 可以尝试的方向

- [ ] 能否将 Theorem 31 的有限性推广到 basic Lie superalgebra 的完整分类，给出各 distinguished 子代数情形酉水平的穷举？
- [ ] 主 W-代数的酉下界 $m_0$ 是否最优？能否通过构造临界水平附近的显式表示收紧？

### 批判性思考

- 一般定理的条件"存在非零正定不变 Hermitian 形式的正能模"在实际验证时是否容易满足，还是往往与要证明的酉性同难度？
- 超情形的"仅适用于 $osp(1|2n)$、$osp(2|2n)$"依赖 diagram 型对合的分类，是否遗漏了非 diagram 型对合的潜在酉性？
- 有限性定理的证明依赖中心化子非交换；当中心化子交换（如 distinguished 情形）时猜想开放，其中间地带（如 $E_7,D_4(a_1),k=-12$ 的例外水平）值得进一步辨析。
