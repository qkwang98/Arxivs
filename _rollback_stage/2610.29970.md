# Mackey formulas for smooth stacks

keywords: [Mackey 公式, 抛物诱导与限制, component lattice, 构造性层, 几何 Langlands]
related_paper: "Hennecart (2024)，线性商栈上的上同调 Mackey 公式"
one_liner_summary: 在具有良好或充足模空间的光滑代数栈上，用 component lattice 参数化相对位置，证明抛物诱导与限制函子之间的 Mackey 滤过公式，覆盖构造性层、D-模、混合 Hodge 模与 $\ell$-adic 层等六函子理论，并应用于半稳定主丛模栈。

## 核心定位

- **解决的问题**：光滑代数栈上抛物诱导 $\mathrm{Ind}_\lambda$ 与抛物限制 $\mathrm{Res}_\mu$ 复合的结构。经典表示论中二者的交互由 Mackey 公式描述；本文把这一交互推广到一般光滑代数栈的层论设置，给出以相对位置为指标、带 Tate 扭转的有限滤过。
- **大图景位置**：推广广义 Springer 理论与 character sheaves 中的 Mackey 公式（余伴随商栈情形），也推广 Lusztig 量子群范畴化中箭图表示栈的诱导/限制相容性；是 Bu 提出的 intrinsic parabolic induction / component lattice 纲领的后续工作。
- **主要贡献**：1) 定义任意光滑栈上由 component lattice $\mathrm{CL}(\mathcal{X})$ 参数化的抛物诱导/限制函子，并证明 Mackey 滤过公式 $\mathrm{Res}_\mu\circ\mathrm{Ind}_\lambda$ 的 associated graded 为 $\bigoplus_i \mathrm{Ind}_{\lambda_i}\circ T^i_{\lambda,\mu}\circ\mathrm{Res}_{\mu_i}$；2) 通过构造 Steinberg 栈的分层（推广 Bruhat 分解）给出证明；3) 应用于半稳定主丛模栈 $\mathcal{B}un_G^{\mathrm{ss}}(C)$，作为几何 Langlands 中 Mackey 公式的第一步。
- **关键先驱工作**：Halpern-Leistner 的 instability 分层、Alper 的好/充足模空间理论、Bu (2025) 的 component lattice 与内在抛物诱导、Hennecart 的线性商栈 Mackey 公式、Lusztig 的 character sheaves 与箭图表示范畴化。
- **结果边界**：要求栈拟紧且具有好或充足模空间；因此不适用于全部 $G$-丛模栈 $\mathcal{B}un_G(C)$，自动侧完整 Eisenstein 与 constant term 函子不在覆盖范围；相干层与光滑/拟光滑栈的情形（谱侧）亦未覆盖。
- **开放问题**：全 $\mathcal{B}un_G(C)$ 上更复杂版本（修正诱导/限制与更精细扭转函子）的 Mackey 公式；相干层与 $K$-理论 Hall 代数侧（量子 loop 代数范畴化的双代数相容性）；基于 Mackey 公式构造 perverse schobers 并研究其中的高阶同伦相容性。
- **应用与推广**：为尖点 character sheaves 理论提供栈化框架；给箭图表示栈上 Lusztig 复形的 Ext-代数（quiver Hecke 代数几何实现）的计算提供统一工具；为几何 Langlands 的 Eisenstein/constant term 交互奠定基础。

### 可以尝试的方向

- [ ] 对 $\mathcal{B}un_G(C)$ 全模栈寻找修正的诱导/限制函子与更精细扭转函子，使 Mackey 公式在非拟紧情形成立

### 批判性思考

- 证明依赖 Steinberg 栈的分层，其层状结构与 Bruhat 分解类比到一般（非代数群）栈时，是否隐含了模空间存在性之外的更强假设？
- 相对位置的序结构由 component lattice 决定，Tate 扭转 $T^i_{\lambda,\mu}$ 的阶次在特征 $p$ 或混合 Hodge 模设置下是否与 $\ell$-adic 设置一致，作者未完全展开。
