# A Künneth theorem for the cyclic homology of $A_\infty$ algebras

keywords: [$A_\\infty$ 代数, 负循环同调, Künneth 定理, EP-结构, 弱 Calabi-Yau 结构, 非交换 Hodge 结构]
related_paper: "Shklyarov 关于 dg 代数情形的循环 Künneth 定理（shklyarov2016hodge）"
one_liner_summary: "将 dg 代数情形的循环同调 Künneth 定理推广到特征零域上 $\\mathbb{Z}/2\\mathbb{Z}$ 分次、光滑、proper 的 $A_\\infty$ 代数，构造保持 EP-结构（higher residue pairing 与 $u$-connection）与弱 Calabi-Yau 结构的 Künneth 拟同构，并给出 Hodge 滤子 good splitting 在张量积上的相容性。"

## 核心定位

- **解决的问题**：两个 $A_\infty$ 代数的负循环同调的张量积与它们 $A_\infty$ 张量积的负循环同调之间，是否存在保持 EP-结构的 Künneth 拟同构；以及弱 Calabi-Yau 结构与 Hodge 滤子分裂如何沿 $A_\infty$ 张量积继承。
- **大图景位置**：非交换 Hodge 理论 / VSHS 纲领的一部分——Kontsevich 同调镜像对称与 Hodge 理论镜像对称之间的桥梁；将 Shklyarov 在 dg 代数情形建立的 Künneth 定理推广到 $A_\infty$ 世界，并进一步证明其与 Mukai 配对、higher residue pairing 相容。
- **主要贡献**：
  1. 构造 Künneth 链映射 $k+uK: CC_*^-(A)\otimes_{k[[u]]}CC_*^-(B)\to CC_*^-(A\otimes_\infty B)$，证明其为链复形拟同构（定理 (a)），推广 Loday 的 shuffle / cyclic shuffle 映射。
  2. 证明 $k+uK$ 与 higher residue pairings 及 $u$-connections 相容，即 EP-结构的态射（定理 (b)）。
  3. 应用：若 $A,B$ 带弱 Calabi-Yau 结构，则 $\phi_{A\otimes_\infty B}:=\langle k(\omega_A\otimes\omega_B),-\rangle_{\mathrm{Muk}}$ 是 $A\otimes_\infty B$ 上的弱 Calabi-Yau 结构，且 $\omega^\otimes$ 生成 $HH_*(A\otimes_\infty B)$ 为 $HH^*(A\otimes_\infty B)$-模；$\omega$-相容 good splittings 沿张量积保持。
- **关键先驱工作**：Barannikov 的 VSHS 与量子形变；Katzarkov-Kontsevich-Pantev 与 Gantara-Perutz-Sheridan 关于负循环同调承载 VSHS 的工作；Shklyarov（dg 情形循环 Künneth 与 $u$-connection 相容性）；Amorim 用树形组合描述 $A_\infty$ 张量积（amorim2016tensor）；Amorim-Tu 的弱 Calabi-Yau 结构与 categorical good splittings（amorim2022categorical、amorim2022morita）。
- **结果边界**：要求 $\mathbb{Z}/2\mathbb{Z}$ 分度、有限维、光滑、proper、特征零域；$A_\infty$ 张量积本身非规范（采用 Amorim 无 filter 的树形版本），且该张量积框架不保持循环结构，故以弱 Calabi-Yau 结构替代循环结构；good splitting 的存在性已知仅在 $HH^*(A)$ 半单时成立（Amorim-Tu）。
- **开放问题**：一般 $A_\infty$ 代数上 $\omega$-相容 good splitting 的存在性仍非平凡；与 versal 形变上的 primitive forms 对应（Amorim-Tu, Theorem 4.2）在张量积语境下的系统研究。
- **应用与推广**：为 Fukaya 范畴与导出范畴在张量/乘积操作下 VSHS 的分解提供工具；结合 primitive forms 可构造 formal Frobenius 流形（Saito-Takahashi 的 $A_\infty$ 范畴类比）；为研究 $A_\infty$ 张量积上的非交换 Hodge 结构提供标准工具。
