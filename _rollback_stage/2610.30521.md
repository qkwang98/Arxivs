# Drinfeld presentation of affine $\mathrm i$quantum groups via $\mathrm i$Hopf algebras

keywords: [iquantum group, Drinfeld presentation, iHopf algebra, coideal subalgebra, quantum affinization, imaginary root vector, quantum symmetric pair]
related_paper: "Li–Przeździecki 对 split 型 BCD 与拟分裂型 AIII 的仿射 iquantum 群 Drinfeld 表示工作"
one_liner_summary: 利用 iHopf 代数框架，从仿射量子群的 Drinfeld 表示概念化地推导仿射 iquantum 群的 Drinfeld 表示，并定义任意 Kac-Moody 型 iquantum affinization 且证明其为量子 affinization 的 coideal 子代数。

## 核心定位

- **解决的问题**：仿射 iquantum 群 $\tUi$ 的 Drinfeld（current）表示此前需要逐类型（split A、BCD、拟分裂 AIII 等）依赖大量约化表达式计算；本文给出统一的概念性推导，并建立 Drinfeld 生成元与 $\tU$ 生成元的显式对应。
- **大图景位置**：属于量子对称对（quantum symmetric pairs）与量子仿射化理论的交叉。将 Letzter 的 iquantum 群框架与 Drinfeld-Beck 新实现统一在 iHopf 代数语言下，并把 iquantum 群推广为任意 Kac-Moody 型的 iquantum affinization。
- **主要贡献**：
  1. 定理 A：通过 Borel 子代数的 iHopf 代数构造，给出同构 $\widetilde{\Phi}^\imath:\tB^\imath_\tau \to \tUi$，使 $\H_i\mapsto\K_{\tau i}$、$\psi_{i,m}\mapsto\Theta_{i,m}$、$\theta_{i,r}\mapsto B_{i,r}$，从而统一推导 $\tUi$ 的 Drinfeld 关系。
  2. 定理 B：用生成函数将 $\tUi$ 的虚根向量 $\Theta_i(z)$ 显式表为 $\tU$ 的 $\psi_{\tau i}^+$、$\psi_i^-$，推广 Li-Przeździecki 的结果并覆盖全部（非扭）仿射类型。
  3. 定理 C 与定理 D：定义任意 Kac-Moody 型的 iquantum affinization $\tUiD$，证明存在单射 $\mathcal{L}^{\mathrm{Dr}}:{}^{Dr}\tUi\to{}^{Dr}\tU^{T}$，且像为 Drinfeld coproduct 下的 coideal 子代数；对 $c_{ij}c_{ji}\le 3$ 给出完整的一般定义关系。
- **关键先驱工作**：Drinfeld-Jimbo 与 Drinfeld current 表示及 Beck、Damiani 用 Lusztig braid 群作用证明的同构；Letzter 的 iquantum 群；Wang 及其合作者的相对 braid 群作用与 $\tUi$ Drinfeld 表示系列工作；iHopf 代数理论（CLPRW）。
- **结果边界**：仿射 Drinfeld 表示部分针对固定仿射节点的 Satake 对合 $\tau$（$\tau(0)=0$）；完整定义关系在 $c_{ij}c_{ji}\le 3$ 情形给出，更深的 Cartan 矩阵仍需逐类处理；定理 B 的公式采用带中心荷的 $\tU_v(\widehat{\fg})$ 设定，与无中心荷的 $L\fg$ 设定存在表述差异。
- **开放问题**：扭型仿射类型中 iquantum 群的 Drinfeld 表示；iSerre 关系在 $c_{ij}c_{ji}>3$ 情形的完整形式；iquantum toroidal 代数的 Schur-Weyl 对偶（与椭圆 DAHA）与几何实现（类比量子仿射群）。
- **应用与推广**：为边界 $q$-characters 提供统一理论基础（Li-Przeździecki 的边界 $q$-characters 可由定理 B 推广到所有非扭仿射 iquantum 群）；twisted Yangians 的 Drinfeld 表示可由仿射 iquantum 群退化得到；对带边界量子可积模型（XXZ 开链、反射方程、边界仿射 Toda）提供代数基础。
