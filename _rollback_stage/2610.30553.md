# Localizing Restriction Categories

keywords: [restriction category, 局部化, 密度, 分离函子, join restriction category, 逆半群, 分解系统, Zariski 谱]
related_paper: "Lawvere–Tierney 拓扑与层函子（本文密度-局部化的 topos 类比），以及 Garner–Cockett 对 restriction 范畴 localic/hyperconnected 分解的工作"
one_liner_summary: "为 restriction 范畴发展局部化/分离分解系统：以密度（restriction 序的稳定且泛子序）生成局部化，并在 join restriction 范畴层面构造 join 局部化，给出 Zariski 谱与 Pierce 谱等例子。"

## 核心定位

- **解决的问题**：restriction 范畴是否具有与 topos 的 surjective/embedding 分解相类比的分解？答案是肯定的，即 localizing/separating 分解，并在 mere 与 join 两个层面给出构造。
- **大图景位置**：把 Lawvere–Tierney/Grothendieck 拓扑及其层函子在 topos 中所起的作用移植到 restriction 范畴：密度对应拓扑、局部化对应层化；同时把逆半群理论中的 unitary 概念与密度综合为 ${\sf j}$-unitary。
- **主要贡献**：1) 引入局部化/分离分解系统：密度诱导限制同余，商出局部化，分离函子恰为在限制幂等元上诱导单射的函子；2) 阐明 ${\sf j}$-unitary 与 topos 意义下 separated 的联系，并比较局部化与 ${\sf j}$-层化；3) 主结果：把分解提升到 join restriction 范畴，用 ${\sf j}$-full 集合填补局部化中缺失的 join，构造局部化 join 函子 ${\cal I}_{\sf j}:\X\to\X_{\sf j}$；4) 给出 complement density（双否定拓扑的类比）、join 完备化提升、交换 rig 上的 Zariski 谱与 Pierce 谱等例子，展示如何由此搭建 scheme 范畴。
- **关键先驱工作**：Lawvere–Tierney 拓扑与 topos 分解理论；Funk–Hofstra 关于 restriction 范畴与（逆）半群理论联系的观察；逆半群中的 unitary 概念（Lawson）；Garner–Cockett 的 localic/hyperconnected 分解。
- **结果边界**：restriction 函子沿代数方向而非几何方向，几何方向的右伴随可能不存在，故与 topos 的类比是方向的颠倒；mere 局部化即使从带 join 的范畴出发也不保留 join，必须额外填补；join 层面与 topos 情形之间仍有显著结构差距。
- **开放问题**：${\sf j}$-unitary 与分离性在更广泛结构中的等价关系开辟了独立研究方向（作者明言超出本文范围）；密度/局部化与 topos 情形的结构差距留待后续工作弥合。
- **应用与推广**：为 restriction 范畴提供一套可操作的局部化工具；在交换 rig 上构造 Zariski 谱与 Pierce 谱，给出用本文构造搭建 scheme 范畴的路线；逆半群与 restriction 范畴的同构层面使结果可双向迁移。
