# What the submission does not show: Complexifying cognitive offloading in students' mathematical work with LLMs

keywords: [认知卸载, 大语言模型, 数学教育, 自我调节学习, 提示结构, 任务设计]
related_paper: "Wang, Xia & Ye (2025), Synthetic fluency and epistemic offloading in undergraduate mathematics in the age of AI"
one_liner_summary: "通过分析 23 名线性代数学生与 LLM 的 59 段聊天记录及其提交作业，论证认知卸载不能笼统地回答是或否，而必须分监管空间、分工作部分地考察；最终提交物并不能显示产生它的调节过程。"

## 核心定位

- **解决的问题**：借助 LLM 完成的数学作业能否作为学生先前数学工作的可信标记？学生在与 LLM 合作时是否把数学思维卸载给了 LLM？
- **大图景位置**：回应生成式 AI 给数学教育带来的"存在性危机"论述（Horrocks & Shearman, 2025）；对认知卸载概念做经验性复杂化，将"与 LLM 的交换"与"向提交物的过渡"视为两个可分离的监管空间，主张卸载须对照学生自设目标评价。
- **主要贡献**：
  1. 经验地复杂化认知卸载：卸载可以在交换中发生、也可以在过渡到提交物时发生，二者不必重合；卸载是达成自设目标的手段而非目的，不能脱离目标判断其好坏。
  2. 提出 5 种提示结构（Solve this problem / Explain this term / Is my idea correct? / Continue my idea / Your math is incorrect）与 4 类提交使用方式（copy-paste / minor revisions / major revisions / abandonment），并刻画提示结构与提交方式间的关联。
  3. 方法论贡献：聊天记录作为自我调节学习的痕迹数据——每个 prompt 都刻录了任务定义与角色分工，即使它不记录工具包与标准的显式设定。
- **关键先驱工作**：认知卸载理论（Risko & Gilbert, 2016）；自我调节学习的事件观（Winne & Hadwin, 1998; Panadero, 2017）；choice-affluent environments（Koichu, 2018）；求助的行政性/工具性区分（Nelson-Le Gall, 1981）；关于学生很少验证 LLM 输出的报告（Noster et al., 2024; Bulut & Borromeo Ferri, 2026）。
- **结果边界**：数据来自单所师范院校、约 23 名未来中学数学教师；聊天记录是提交的必需部分，学生知道教师会阅读，可能修饰了提示行为；三项任务固定顺序且数学内容不同，无法分离任务设计效应；希伯来语从右到左排版造成的数学渲染错误使部分 minor revisions 是修正渲染而非修正数学；提示与提交间的关系是相关而非因果。
- **开放问题**：结合 think-aloud 或 stimulated-recall 访谈研究 prompt 之间发生的调节与学生目标；学生对 LLM 时代作业"作者身份"的态度，以及自己撰写解答是否影响学习；控制内容与顺序、跨课程长周期的任务设计实验。
- **应用与推广**：为数学教育中的 LLM 任务设计提供可检验假设——提供除"交给求解"之外的分工示范（如 Task 2 的示范 prompt 池）可拓宽学生实际采用的选择；当任务赋予 LLM 的角色与要求的作业产品重合时，LLM 产品几乎可直接提交，二者错位则促使学生转化产物；提示研究者将问题从"学生是否卸载"转向"学生交出哪部分工作、在哪个监管空间、朝向什么目标"。

## 主动思考区

### 与其他工作的联系

- 这让我想起：关于学生极少显式拒绝 LLM 输出的既有报告——本文发现显式拒绝仅 4 个 prompt，但质疑常以澄清请求的形式出现，仅计数显式拒绝会低估学生评判 LLM 产物的频率
- [[2609.06127]]：PAGR 把 LLM 检索形式化为带证明的代数几何检索框架，与本文从教育实证角度刻画学生与 LLM 的交互形成互补视角，提示"验证 LLM 输出"可作为可形式化、可教学的目标
- 暂无匹配的已有笔记：笔记库以纯数学方向为主，本文属数学教育实证研究，其余已有笔记不直接相关
- 技术迁移：提示结构编码方案（定性编码 + 逐阶段独立编码 + κ 一致性 + Spearman 相关）可迁移至其它 LLM 课堂交互研究

### 可以尝试的方向

- [ ] 在数学内容固定、任务顺序平衡的设计中，验证任务赋予的 LLM 角色与要求的产品类型对提示结构的影响
- [ ] 用 think-aloud / 刺激回忆数据补充 prompt 之间的调节行为与目标设定，检验聊天记录遗漏的部分

### 批判性思考

- 学生明知聊天记录会被教师审阅，这一可见性可能系统性地改变了提示行为，削弱"记录即调节痕迹"这一核心假设的生态效度
- 作者把"学生最一致地交出写解环节"推断为可能"为分数而非学习"，但数据无法检验动机，这一解释是否过于保守
