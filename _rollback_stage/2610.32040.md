# Imaginary elements and crystals for quantum groups

keywords: [量子群, 虚元素, 晶体基, 量子幺幂坐标环, 量子扭自同构, 量子 Schur–Weyl 对偶, 虚模]
related_paper: "Leclerc 关于量子幺幂坐标环虚元素的论文"
one_liner_summary: 引入稳定虚元素概念，用晶体基理论对所有有限型量子群构造单参数虚元素族，并通过广义量子 Schur–Weyl 对偶得到量子仿射代数上的虚模。

## 核心定位

- **解决的问题**：如何系统构造量子幺幂坐标环 $A_q(\mathfrak n(w))$ 对偶典范基 $\Gup(w)$ 中的虚元素（即不可达 cluster 单项式的元素），并推广 Leclerc 的零散例子。
- **大图景位置**：直接服务 reachability 猜想（cluster 单项式恰为 $\Gup(w)$ 中 real 元素）；为 cluster 代数的 monoidal categorification 与量子仿射代数表示论提供新的虚模族。
- **主要贡献**：(1) 引入 $\cdual_w$-稳定虚元素概念（被量子扭自同构的晶体描述 $\cdual_w$ 固定、至多差冻结变量的非冻结元素），并证明稳定虚元素必为虚元素；(2) 证明有限型下稳定虚元素的倍数仍稳定，从而由单例得到单参数族 $\{\Gup(b^{[k]})\}$；(3) 用晶体理论与整值不变量给出寻找稳定虚元素的判定条件（定理与推论），条件仅涉及权重与 Weyl 群元素并兼容折叠与嵌入；(4) 借助 SageMath 对所有有限型构造显式稳定虚元素 $b_{\triX}$，证明 Leclerc 全部例子均在其中；(5) 经广义量子 Schur–Weyl 对偶构造未扭仿射型 $A_6^{(1)}$、$B_3^{(1)}$、$C_4^{(1)}$、$D_5^{(1)}$、$E_k^{(1)}$（$k=6,7,8$）、$F_4^{(1)}$、$G_2^{(1)}$ 的虚模族显式例子。
- **关键先驱工作**：Kashiwara 的晶体基理论；Kimura–Oya 的量子扭自同构；Jung–Park 对其的晶体描述；Leclerc 对 Berenstein–Zelevinsky 猜想的反例（虚元素）；quiver Hecke 代数 monoidal categorification（Kang–Kashiwara–Kim–Oh）；Lapid–Mínguez、Brito–Chari、Brito–Moura、Early–Li、Sakamoto 的虚模工作。
- **结果边界**：稳定虚元素是虚元素的真子集（逆命题不成立）；存在满足不了文中判定条件的稳定虚元素例子；reachability 猜想完全一般情形仍开放。
- **开放问题**：完全一般情形下的 reachability 猜想；对稳定虚元素族的完备分类。
- **应用与推广**：提供 cluster 代数中虚元素与量子仿射代数虚模的系统构造；晶体理论与整值不变量方法可迁移到其他量子群/仿射型表示论问题。
