# Schur--Weyl duality for coideal subalgebras of quantum affine superalgebras of type $A$

keywords: [Schur–Weyl 对偶, i量子群, 量子仿射超代数, coideal 子代数, 仿射 Hecke 代数, Koszul 符号, 超 Satake 图]
related_paper: "Fan–Li–Luo–Li–Wang–Wang, Three-parameter affine type C iSchur duality（\cite{FLLLWW20}）"
one_liner_summary: 本文把三参数仿射 C 型 iSchur 对偶推广到超设置：定义量子仿射超代数（type A）的两族 coideal 子超代数（$\jmath$-与 $\imath$-量子仿射超代数），构造三参数仿射 C 型 Hecke 代数在张量超空间上的作用并证明交换性，进而建立与仿射 $\jmath/\imath$-Schur 超代数的 Schur–Weyl 对偶与双重中心化性质。

## 核心定位

- **解决的问题**：如何把 \cite{FLLLWW20} 中三参数仿射 C 型 $\imath$Schur 对偶（coideal 子代数 vs 仿射 Hecke 代数）推广到李超代数/量子仿射超代数的超设置？
- **大图景位置**：处于 Schur–Weyl 对偶谱系的超化与量子对称对交叉点——经典 GL–S 对偶、量子群–Hecke 对偶、正交/辛–Brauer 对偶、i量子群的 $\imath$Schur 对偶（\cite{BW18,BWW18,FLLLW20,FLLLW23,FLLLWW20}），以及近年超化版本（\cite{S25,SW25,CL23}）之后，本文把仿射三参数情形整体超化。
- **主要贡献**：
  1. 定义 $\jmath$-与 $\imath$-量子仿射超代数（type A 量子仿射超代数的 coideal 子超代数），并给出显式生成元-关系表述（Theorems~\ref{def:ipreseab}、\ref{def:ipreseabslmadada}）。
  2. 构造三参数仿射 C 型 Hecke 代数在无穷维张量超空间上的作用，证明与一类 $\jmath/\imath$-量子仿射超代数在适当参数特化下的交换性（Theorems~\ref{hatcuth}、\ref{icommu}）。
  3. 引入三参数仿射 $\jmath$-与 $\imath$-Schur 超代数（仿射 C 型 Hecke 代数的带符号置换模直和的自同态代数），证明同态满射并建立双重中心化性质（Theorems~\ref{schruimo}、\ref{suchuri}）。
- **关键先驱工作**：经典与量子 Schur–Weyl 对偶（Schur、Jimbo \cite{J86}、Ser \cite{Ser84}、BR87、Mo03、Mi06、ES16）；量子对称对与 $\imath$Schur 对偶（\cite{W23,BW18,BWW18,FLLLW20,FLLLW23,FLLLWW20,CS24}）；超设置 $\imath$Schur 对偶（\cite{S25,SW25,CL23}）；量子仿射超代数的生成元-关系定义（Yamane \cite{Yam94,Yam99}）。
- **结果边界**：仅覆盖 type A 量子仿射超代数及其 coideal 子超代数；正交-辛型（\cite{MS26}）等类型留作未来工作。超化并非简单替换底空间：$\mathbb Z_2$-分级影响定义关系（各向同性奇简单根带来额外四次 Serre 关系）、张量作用（Koszul 符号规则）与 Hecke 代数作用。
- **开放问题**：这些超代数的 Drinfeld 型表述与表示论；其他类型（尤其 ortho-symplectic）coideal 子超代数及 \cite{SW25} 的仿射化；两类仿射 $\jmath/\imath$-Schur 超代数的结构研究。
- **应用与推广**：为量子超代数与仿射 Hecke 代数的交互提供新的中心化框架；带符号置换模的表述可用于超对称背景下的组合与表示论计算；为量子对称对理论的超化提供模板。
