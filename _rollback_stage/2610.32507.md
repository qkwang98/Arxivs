# Higher \v Cech derived functors via Galois theory

keywords: [Čech 导出函子, 范畴 Galois 理论, 半 Abel 范畴, 余单同调, Hopf 公式]
related_paper: "2610.32399"
one_liner_summary: 对半 Abel 范畴上的 Birkhoff 反射子，高阶 Čech 导出函子与通常的余单同调在全体次数上一致，从而把两类 Hopf 公式在结构层面统一起来。

## 核心定位

- **解决的问题**：回答"Čech 导出函子方法与 Galois 理论方法究竟如何关联"——证明对半 Abel 范畴到子范畴的反射子，高阶 Čech 导出函子与 Barr–Beck 余单同调完全一致：对每个 \(n\geq 1\)，第 \(n\) 个 Čech 导出函子同构于第 \(n+1\) 个同调对象（次数平移源于导出函子的单纯编号与群同调编号之差）。
- **大图景位置**：Donadze–Inassaridze–Porter 用 Čech 导出函子给出高阶 Hopf 公式的代数证明，Everaert–Gran–Van der Linden（EGVdL）用范畴 Galois 理论给出半 Abel 范畴中的 Galois 塔与高阶中心扩张。本文证明两条路径计算的是同一个导出函子，从而在结构层面解释了两族 Hopf 公式的一致性。
- **主要贡献**：
  1. 一般比较定理：只要半 Abel 范畴上带有满足 Quillen 条件的余单，任意 Birkhoff 反射子的高阶 Čech 导出函子即与其余单同调一致（无需变体假设）。
  2. 范畴版 Loday 定理：用双单纯对象的 Quillen 谱序列证明，适用于任意半 Abel 范畴，取代了原群论框架中对 n 重群胚的依赖。
  3. 沿 Galois 塔的归纳比较：将一度同构（Culot–Everaert 已有）沿 EGVdL 的塔结构抬升到所有次数，得到 \(\mathrm{HH}_n F(Y) \cong H_{n+1}(Y,F)\) 对一切 \(n\geq 1\)。
  4. 基本群的中心化自由计算：弱泛中心扩张定义的基本群可直接由射影表示 \(f\colon X\to Y\) 的核偶计算，无需先中心化，为归纳提供显式形态。
- **关键先驱工作**：Janelidze 的范畴 Galois 理论与高中心扩张纲领；Barr–Beck 余单同调；Donadze–Inassaridze–Porter 的 n 重 Čech 导出函子与群 Hopf 公式；Loday 的 n 重群胚对角线同调定理；EGVdL 的 Galois 塔与高阶 Hopf 公式；Culot–Everaert 的一度比较。
- **结果边界**：\(\mathbb{C}\) 是变体时余单同调对象自然可用，此时比较对所有 \(n\) 成立；变体假设可放宽为带 Quillen 条件余单的半 Abel 范畴（一般比较定理），但一度比较还需要 enough projectives；更广的 exact Mal'tsev 范畴背景下的高阶中心扩张理论已有推广，本文的比较定理本身并未覆盖该背景。
- **开放问题**：比较在 exact Mal'tsev 范畴等半 Abel 之外是否仍成立；是否存在比谱序列归纳更直接的证明；与 Culot–Everaert 一度证明的差异（文中 Remark）是否暗示更低阶的独立构造。
- **应用与推广**：为群、交叉 n-立方、Leibniz n-代数、预交叉模、紧群及 skew braces 等各类 Hopf 公式提供统一的导出函子解释；中心化自由的 Galois groupoid 算法可用于其他同调不变量的有效计算。
