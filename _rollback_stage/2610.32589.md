# Affine and cyclotomic Brauer categorification via $\imath$-Kac--Moody $2$-categories: the integral type $\operatorname{AIII}$ case

keywords: [Brauer 范畴化, ı-Kac–Moody 2-范畴, 分圆 Brauer 代数, 幂零 2-表示, 拟分裂型 AIII, Z-分次]
related_paper: "Affine and cyclotomic Brauer categorification via $\imath$-Kac--Moody $2$-categories: the half-integral type $\operatorname{AIII}$ case（2609.07018）"
one_liner_summary: "本文构造积分拟分裂型 $\operatorname{AIII}$ $\imath$-Kac--Moody $2$-范畴的广义幂零 $2$-表示与仿射 Brauer 作用之间的双向对应，并证明分圆 Brauer 范畴的局部单位代数同构于主 $2$-表示的 cyclotomic 商，从而给出其自然的 $\mathbb Z$-分次。"

## 核心定位

- **解决的问题**：为分圆 Brauer 代数（cyclotomic Nazarov--Wenzl 代数）建立"分圆 Hecke 代数分次实现"的 Brauer 类比：从点谱恰为 $\mathbb Z$ 的仿射 Brauer 作用构造积分拟分裂型 $\operatorname{AIII}$ $\imath$-Kac--Moody $2$-范畴的（广义）幂零 $2$-表示，反之亦然，并借此把 $2$-范畴的分次传送到分圆 Brauer 代数上。
- **大图景位置**：是作者半整数工作（[[2609.07018]]）的积分对应。半整数情形用偶数分量 $\mathfrak U^\imath_+$、$i\mapsto -i$ 无不动点；积分情形顶点 $0$ 固定，满足 nil-Brauer 关系，需要独立的修正生成元验证。整体属于"量子对称对 $\Rightarrow$ 范畴化"纲领（Bao--Wang 典范基、Bao--Shan--Wang--Webster 的 $\operatorname{AIII}$ 范畴化）。
- **主要贡献**：
  1. 正向构造（定理 A(1)，即定理 5.16）：局部 Schurian $\mathbb C$-线性范畴上的仿射 Brauer 范畴化，若生成自函子点谱恰为 $\mathbb Z$，则给出 $\mathfrak U^\imath$ 的广义幂零 $2$-表示；有限生成对象的全子范畴是幂零 $2$-子表示，局部有限 Abelian 时整个表示幂零。
  2. 反向构造（定理 A(2)，即推论 8.32 与定理 8.31）：颜色支撑有限且点幂零的 $2$-子表示给出谱含于 $\mathbb Z$ 的仿射 Brauer 作用。
  3. 固定顶点 $0$ 处的修正生成元（含 $\Gamma$-因子）与 nil-Brauer、混合关系的验证；$\mathbf u$-可容许积分参数下局部单位代数同构 $Q_m\cong B_{\mathbf u}$（定理 B，即定理 9.8 与推论 9.9），从而每个可容许分圆 Brauer 代数获得自然的 $\mathbb Z$-分次。
  4. 奇特征 $p$ 的混合仿射数据（mixed affine datum）：谱含于 $\mathbb F_p$ 的双向构造（推论 10.3、10.5），特征 $3$ 单独处理（10.5 节修正零色归一化）。
- **关键先驱工作**：Ariki 定理（分解数 = 典范基系数）；Brundan--Kleshchev 同构（分圆 Hecke 代数与分圆 quiver Hecke 代数）；Rui--Song 的仿射 Brauer 范畴与可容许分圆商（抛物范畴 $\mathcal O$ 类型 $B,C,D$）；Bao--Wang 量子对称对典范基；Bao--Shan--Wang--Webster 拟分裂 $\operatorname{AIII}$ 范畴化；Brundan--Wang--Webster 的 nil-Brauer 范畴与 $\imath$-Kac--Moody $2$-范畴；作者的半整数篇（[[2609.07018]]）与弱三角表示论。
- **结果边界**：正向方向要求完整谱 $\mathbb Z$，而反向重建的点不一定实现每个整数；两种构造对任意 $2$-表示并不互逆；半整数情形在类型 $C$、$D$ 作用的是半整数 $2$-范畴的偶数分量，积分 $2$-范畴只在类型 $B$ 作用；同构沿无分次同构传送分次，而不是直接构造 $2$-范畴分次。
- **开放问题**：构造 categorical bar involution；把不可分解投影对应到 $\imath$-典范基元素；将分解数解释为 Ariki 定理的 Brauer 类比；弱三角表示论的分次精化。
- **应用与推广**：任意水平 $\mathbf u$-可容许积分分圆 Brauer 代数的 $\mathbb Z$-分次（此前仅知某些特例，如 Ehrig--Stroppel 用 level-two 分圆代数给整参数普通 Brauer 代数分次）；抛物范畴 $\mathcal O$ 中最高权 $\varepsilon$-坐标为整数的子范畴上的作用；奇特征下的有限域谱构造。

## 主动思考区

### 与其他工作的联系

- 这是半整数姊妹篇 [[2609.07018]] 的积分版：两文共享"广义特征空间 + 点有理函数"的构造框架，积分情形的新增点全在固定顶点 $0$（nil-Brauer 关系、$\Gamma$-修正、混合关系）。
- [[2609.09042]]：仿射/分圆 Brauer 范畴化与传播分拆代数同属"图代数 + Schur--Weyl 型对偶"家族，本文为其提供量子对称对侧（$\imath$-Kac--Moody $2$-范畴）的范畴化描述。
- [[2610.32400]]：shifted affine $\mathrm{i}$Quantum groups via Coulomb Branches 亦属量子群 $2$-范畴化纲领，本文的 $\mathfrak U^\imath$ 与其共享"用 $2$-范畴实现量子对称对"的方法论。
- [[2610.32480]]：量子仿射超代数的 coideal 子代数的 Schur--Weyl 对偶与本文的仿射 Brauer 作用同处"量子对称对表示论"版图。
- 技术迁移：固定顶点处的"逐点构造 + 系数比较（含气泡贡献）"技巧，可迁移到其他带不动点的箭图/图代数范畴化。

### 可以尝试的方向

### 批判性思考

- 正向与反向构造不互逆：谱假设（恰好 $\mathbb Z$ vs 含于 $\mathbb Z$）与幂零条件的不对称性是否本质上不可避免？
- 分次通过无分次同构传送而非 $2$-范畴天然携带：是否存在更直接的、使 $\mathcal{CB}_{\mathbf u}$ 在范畴层面就分次的构造？
