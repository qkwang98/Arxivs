# Deformations of cohomology classes and spectral sequences

keywords: [谱序列, Rees 构造, 形变理论, 平坦性, 退化判据, 双复形, ∂∂-引理, 形式性]
related_paper: "Melani--Rubió 的 formality 判据（谱序列 $E_2$ 退化 $\Leftrightarrow$ 形式性）"
one_liner_summary: "本文把滤过复形的谱序列解释为通过 Rees 构造形变上同调类的障碍理论：高阶微分正是沿特殊纤维无穷小邻域提升上同调类的障碍，并由此给出 $E_1$ 退化与 Rees 上同调平坦性的等价、Hard Lefschetz 型无挠判据、Kaledin 类与形式性的联系，以及双复形双参数 Rees 构造下的 $\partial\bar\partial$-引理内蕴刻画。"

## 核心定位

- **解决的问题**：让"滤过复形的谱序列度量上同调与伴随分次（associated graded）不交换的程度"这一失败变得几何化：把谱序列的（高阶）微分解读为延拓上同调类离开特殊纤维时的障碍类。
- **大图景位置**：Rees 构造把滤过复形视为仿射线上的 $\mathbf G_m$-等变退化族（$\hbar=0$ 处为 $\operatorname{Gr}_F(C)$，$\hbar=1$ 处还原为 $C$），从而把退化问题翻译为 Rees 上同调的平坦性——这是 Deligne 判据（$E_1$ 退化 $\Leftrightarrow$ 微分严格）的 Rees 侧类比。同一框架统摄 Wavrik 障碍理论、Hard Lefschetz、形变量子化、双复形分解（Khovanov--Qi、Stelzig）与 $\partial\bar\partial$-引理。
- **主要贡献**：
  1. 谱序列的 Rees 描述（命题 pages / diffs）：$E_r^{p,q}$ 同构于 $\cdot\hbar^{r-1}$ 在 $H^{p,q}(R_F(C)/\hbar^r)$ 上的像，微分对应短正合列诱导的连接态射；无穷小提升定理：$E_1$ 类 $x_0$ 可提升到第 $N$ 阶无穷小邻域当且仅当 $d_1([x_0])=\cdots=d_N([x_0])=0$。
  2. 退化 $\Leftrightarrow$ 平坦：双正则滤过下 $E_1$ 退化等价于 $H(R_F(C))$ 为 $k[\hbar]$-平坦（且等价于每个 $E_1$ 类可提升）；一般滤过下平坦仍推退化，反向需要 $\hbar$-进分离性排除无穷 $\hbar$-可除挠；形式邻域版本用 $\widehat R_F(C)$ 陈述。
  3. 乘法结构应用：对紧 Kähler Lagrangian 的 $\operatorname{Ext}$ 谱序列，$E_2$ 塌缩等价于所有 $d_2^{p,1}=0$（Abelian Lagrangian 时仅需 $d_2^{0,1}=0$）。
  4. Hard Lefschetz 无挠判据：主理想整环上带 Serre 对偶与 Lefschetz 算子的完美复形，其各次上同调无挠（从而有限自由）。
  5. 形式性：Kaledin 类 $K_A$ 是提升 Euler 类 $e_A$ 到形式 Rees 上循环的障碍类；对约化 dg Koszul operad，$K_A=0$ 等价于 Rees 上同调 $H(\mathfrak g\brak,D_{Q,\hbar})$ 平坦，从而（配合 Melani--Rubió）等价于形式性。
  6. 双参数 Rees 构造：$R_{s,t}(C)$ 定义在 $k[s,t]$ 上，其高阶微分对应支撑在加厚坐标轴上的挠模；给出 $\partial\bar\partial$-引理的等价刻画（分解仅含单形与方块；$H(R_{s,t}(C))$ 在 $\mathbf A^2\setminus\{0\}$ 局部自由；原点处 Hartogs 性质；挠子层概形支撑于约化原点；Postnikov 类 / 自由与摩天层上同调层间的 $\operatorname{Ext}^2$ 类消失）。
- **关键先驱工作**：Rees 构造；Deligne 的 $E_1$-退化判据；Wavrik 的形变上同调类障碍理论；Khovanov--Qi 的三复形分解；Stelzig 的双复形分解与 $\partial\bar\partial$-引理；Manetti 的 DGLA 形式性判据；Melani--Rubió 的谱序列退化 $\Leftrightarrow$ 形式性；Kaledin 的形式性族。
- **结果边界**：退化推平坦需要分离性（separatedness）（排除无穷 $\hbar$-可除挠）；提升到每个有限加厚与构造相容逆系统 / 完备化是不同问题（后者需完备性 / 分离性 / 完美性假设）；Ext 谱序列判据要求 Hodge 代数由全纯度 $q\le 1$ 的类生成；Hard Lefschetz 判据要求复形有界且对偶移位匹配。
- **开放问题**：把几何 / 模论退化判据推广到更一般的（非 Kähler、非 Lagrangian）情形；双参数构造下 Postnikov 类的更精细刻画。
- **应用与推广**：复辛流形中紧 Kähler Lagrangian 的 $\operatorname{Ext}$ 谱序列退化；同伦代数的形式性判据（dg Koszul operad）；双复形分解与 $\partial\bar\partial$-引理的内蕴（不依赖分解选择）刻画；Hodge 滤过严格性与 $\lambda$-connection / Higgs 族的联系。
