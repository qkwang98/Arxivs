# Cross numbers and the characterization of finite abelian groups by length sets

keywords: [Characterization Problem, 长度集, Davenport 常数, cross number, 零和序列, 同循环群, 非唯一分解]
related_paper: "暂无匹配的已有笔记（笔记库中未检索到零和序列、长度集或 cross number 语义相关的既有笔记）"
one_liner_summary: "本文解决同循环有限阿贝尔群 $C_n^r$ 的 Characterization Problem（Davenport 常数至少为 4 时，长度集系统完全决定群结构），并给出最小零和序列最大 cross number 在最小距离可被秩减一整除的子集上的精确公式。"

## 核心定位

- **解决的问题**：非唯一分解理论中的核心逆问题——设 $G,G'$ 为有限阿贝尔群且 Davenport 常数 $\mathsf D(G)\ge4$，是否由 $\mathcal L(G)=\mathcal L(G')$ 可推出 $G\cong G'$（Characterization Problem）？本文对一切同循环群 $C_n^r$ 给出肯定回答，并证明 cross number 不变量 $\mathsf K(G,r-1)$ 的精确公式。
- **大图景位置**：该问题属于 Narkiewicz 自 1970 年代发起的"由算术性质恢复类群"纲领：代数数域整环的分解长度集合仅记录不可约因子个数的可能值，其全系统被猜想足以决定理想类群（经 transfer Krull 幺半群 $\mathcal L(H)=\mathcal L(G)$ 归约到零和序列幺半群 $\mathcal B(G)$）。Carlitz 定理（类数至多二等价于半因子化）是该方向的奠基结果。
- **主要贡献**：
  1. Theorem 2：设 $n\ge2$、$r\ge1$，$G$ 为有限阿贝尔群且 $\mathsf D(G)\ge4$。若 $\mathcal L(G)=\mathcal L(C_n^r)$，则 $G\cong C_n^r$。这补全了 Zhong 此前结果（$r\le n-3$；$r\ge n-1$ 且 $n$ 为素幂）留下的 $r=n-2$ 与 $r\ge n-1$（$n$ 非素幂）两处空白。
  2. Theorem 1：对 $G\cong C_{n_1}\oplus\cdots\oplus C_{n_r}$（$1<n_1\mid\cdots\mid n_r$，$r\ge\max\{2,n_r-2\}$），$\mathsf K(G,r-1)=1+(r-1)\sum_{p\mid n_1}(1-p^{-\mathsf v_p(n_1)})$；该公式同时证明 Zhong 的猜想 C1 与 C2（$s=n\sum_{p\mid n}(1-p^{-\mathsf v_p(n)})$ 满足 $\gcd(s,n)=1$）。
  3. 将 cross number 极值问题限定到"最小距离被 $d$ 整除"的子集族上并精确求解，作为通过 refined elasticity 恢复群循环因子结构的工具。
- **关键先驱工作**：Carlitz 的半因子化定理（1960）；Krause 引入 cross number（1984）与 Krause–Zahlten 对 Krull 幺半群的发展；Schmid 对 $C_n^2$ 的刻画与 Geroldinger–Schmid 对秩二群的刻画；Geroldinger–Zhong 与 Zhong 基于最小距离与 refined elasticity 的同循环群方法（含 $\rho^*(G,d)$、$\bcro(G,d)$ 不变量）；经典 cross number 猜想（$\mathsf K(G)=\frac1{\exp(G)}+\sum_i(1-\frac1{q_i})$）在 $p$-群上已证。
- **结果边界**：Theorem 2 限于同循环群目标；Davenport 常数 $\ge4$ 的小群限制必要（$\mathcal L(C_3)=\mathcal L(C_2^2)$）；Theorem 1 要求 $r\ge\max\{2,n_r-2\}$，未覆盖低秩情形；cross number 公式只针对"最小距离被秩减一整除"的子集族，一般子集族上的经典猜想仍开放（多素因子时向 primary components 投影不保极小性）。
- **开放问题**：一般有限阿贝尔群（非同循环）的 Characterization Problem；一般子集族上的经典 cross number 猜想上界；达到最大 cross number 的极小零和序列的结构刻画（逆问题）。
- **应用与推广**：为"由分解长度恢复理想类群"提供同循环群的完全判据，强化代数数域算术对类群的约束；cross number 作为加权长度度量可用于比较分解长度、判定半因子化（子集 $G_0$ 半因子化当且仅当其原子 cross number 恒为一）；精确公式可用于设计更细的群不变量族（最小距离 + elasticity + cross number 组合）。

- 技术迁移：Theorem 1 的"把极值问题限制在满足最小距离条件的子集族上求解"策略，可用于其它算术不变量（如 elasticities、catenary degree）在受限子集族上的精确计算。

### 可以尝试的方向

- [ ] 非同循环群（如 $C_2\oplus C_4$ 型混合指数群）的 Characterization Problem 是否可由类似的不变量组合（$\rho^*$ 与 $\mathsf K$）区分？

### 批判性思考

- Theorem 2 的证明在 $r=n-2$ 时依赖 $\rho^*(G,n-3)$ 与 $C_n^{n-2}$ 对应值的比较，而 $n\in\{4,5\}$ 需单独处理——这说明不变量在极端小参数处会失效，任何"有限族统一公式"都应警惕边界现象。
- cross number 猜想的多素因子困难源于投影不保极小性；本文通过加"最小距离条件"绕过该障碍，这一条件在组合上对应何种图/超图结构，值得进一步阐明。
