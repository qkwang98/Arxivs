# Stability functions inducing stability data

keywords: [stability data, stability functions, maximal green sequences, red paths, wide subcategories, torsion classes]
related_paper: "Relative Delooping Levels on Intervals of Torsion Classes (2610.33762)"
one_liner_summary: 本文给出了阿贝尔长度范畴上稳定性数据可由稳定性函数诱导的固有刻画：相位数不超过六时等价于每个半稳定子范畴宽，并构造了 $D_4$ 箭图上一个长度为 11 的、任何稳定性函数都无法诱导的最大绿色序列，从而否证了 Brüstle–Smith–Treffinger 的红路猜想。

## 核心定位

- **解决的问题**：给定阿贝尔长度范畴上的稳定性数据 $(\Phi,\{\Pi_\varphi\}_{\varphi\in\Phi})$（只指定有序半稳定子范畴与 HN 滤），何时存在一个稳定性函数，使其半稳定对象恰好是 $\Pi_\varphi$ 中的非零对象且取值随相位严格递增。
- **大图景位置**：Gorodentsev–Kuleshov–Rudakov 2004 年提出"加性斜率给出 see-saw 序、see-saw 序给出稳定性数据"并追问更弱结构能恢复多少更强结构；本文系统回答"从稳定性数据回到稳定性函数"这一步，是 Mumford 斜率稳定性、Narasimhan–Seshadri 定理与 Bridgeland 稳定性理论在范畴层面的组合刻画。
- **主要贡献**：
  1. 给出任意相位集的固有判别准则：存在诱导稳定性函数 $\Leftrightarrow$ 对每个有限链 $\varphi_1<\cdots<\varphi_n$，非负锥内满足 $\mathbf x_0=\mathbf x_n=0$、$\mathbf x_i-\mathbf x_{i-1}\in H_{\varphi_i}$ 的元组必为零元组 $\Leftrightarrow$ 存在全序域 $\mathbb{F}$ 上在 $H_\varphi$ 上消失、且在简单类上随相位严格递减的同态族；
  2. 证明相位数 $\leq 6$ 时诱导函数存在当且仅当每个 $\Pi_\varphi$ 宽，且此时可取有理值函数；七相位反例说明六是最佳上界（$D_4$ 箭图，七个半单宽半稳定子范畴不可诱导）；
  3. 在有限相位集与有限秩情形证明存在诱导稳定性函数当且仅当存在诱导红路；构造 $D_4$ 箭图上一个长度 11 的最大绿色序列不被任何稳定性函数诱导，从而否证 Brüstle–Smith–Treffinger 红路猜想（Conjecture 4.14）。
- **关键先驱工作**：Gorodentsev–Kuleshov–Rudakov 的稳定性数据定义（GKR2004）；Brüstle–Smith–Treffinger 证明半稳定子范畴宽是必要条件、红路诱导稳定性函数并提出红路猜想（BST）；Liu–Li 用穿越不等式刻画由 central charge 诱导的最大绿色序列（LiLiu2020）；Chen–Lin–Ruan 对稳定性数据细化与 torsion pair 的研究；Li–Qu 关于无限最大绿色序列的工作（LQInfiniteMGS）。
- **结果边界**：六相位充分性在七相位即告失效；有限秩/有限相位下稳定性函数与红路等价，但一般（无限相位或无限秩）情形仅给出一般准则；反例针对 $D_4$ 箭图上的特定最大绿色序列，未涉及所有长度范畴。
- **开放问题**：寻找比"宽度"更精细的、刻画任意相位数可诱导性的组合条件；红路猜想被否证后，刻画"可由稳定性函数诱导的最大绿色序列"仍开放。
- **应用与推广**：为阿贝尔长度范畴上稳定性结构的存在性判定提供可操作判据；红路与稳定性函数等价性可用于最大绿色序列的构造与 torsion class 链的分类；结果与倾理论、cluster 范畴的稳定性相关研究可相互印证。
