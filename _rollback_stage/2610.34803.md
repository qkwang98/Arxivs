# An event is a set, not a number: building the algebra of events before the probability measure in a school progression

keywords: [概率教学, 事件代数, 样本空间, 概率测度, 数学课程设计, 先验分析]
related_paper: "Kolmogorov (1933) 的基础概念"
one_liner_summary: 主张学校概率教学应把"事件代数"与"概率测度"分离并排序——先让学生学会构造、识别与操作作为结果集合的事件，再学习把数附给事件的概率——并以五个设计原则审计法国课程与 IB 课程的概率章节。

## 核心定位

- **解决的问题**：学生被问"什么是事件"时常常回答一个分数，因为事件（结果的集合）与概率（附在该集合上的数）在学校教学中从未被分离。论文要确立两个学习对象的明确区分并给出跨整个学段的排序。
- **大图景位置**：把 Kolmogorov 的公理化结构（事件构成集合代数、概率是其上可加函数）转译为学校课程设计的指导原则；延续法国数学教育研究（Douady 的面积/测度区分传统、didactic engineering 的先验分析）并审计具体课程材料。
- **主要贡献**：
  1. 陈述并论证五个设计原则：两个对象两个名字、事件先于概率、模态判断（不可能/必然/可能）先于数值、事件代数本身作为教学内容且概率规则由其导出、样本空间作为建模选择且频率最后作为统计量；
  2. 以 CommeUnJeu 平台法国课程（CM1 至 terminale）与 IB 课程（PYP 0 至 DP）为语料做逐章审计，量化事件类练习占比（18%–44%）并指出证明在高中被隐藏、自动批改只记录数字等问题；
  3. 提出 6–8 岁无数字的事件任务设计，并给出对 IB 课程的具体修改建议；以假设形式陈述可供实证检验的命题。
- **关键先驱工作**：Kolmogorov 的测度论公理体系；Bryant 等人关于样本空间教学的研究综述与 Nunes 等人的干预研究；Jones 等人的概率推理框架；法国 inter-IREM 委员会与 Girard 对事件定义与集合语言的讨论；Douady 关于面积与其测度区分的教学研究。
- **结果边界**：论文是设计论证与课程分析，不含课堂实验，关于学习者的陈述均来自文献或明确标注为假设；统计针对的是练习内容的分类编码，而非学生实际投入的时间。
- **开放问题**：事件/概率分离的排序是否真的改善学习结果（作者提出 Hypothesis 但未实证）；频率作为统计估计放在章节末尾的安排在不同文化课程中是否成立。
- **应用与推广**：可作为概率教学、课程设计与教材审计的方法论模板；其"先建对象后附数值"的排序思想可迁移到面积、度量、随机变量等其他"对象-测度"成对概念的教学。
