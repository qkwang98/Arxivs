# Exponentially large mu-coefficients
keywords: [Kazhdan–Lusztig μ-系数, 对称群, sl₃ webs, 左胞腔, 指数增长]
related_paper: "Scott–Xi 仿射型无界 μ 系数构造"
one_liner_summary: 本文用 sl₃ web 方法构造显式置换对，证明对称群的 Kazhdan–Lusztig μ-系数随秩至少指数增长，且已在三行矩形左胞腔内实现。
## 核心定位
- **解决的问题**：对称群的 Kazhdan–Lusztig μ-系数是否无界、能增长多快。此前有限型情形连无界性都悬而未决，本文给出远比无界更强的结论——至少指数增长。
- **大图景位置**：这是对 McLarnan–Warrington 2002 年反例（μ 取值不限于 0/1）以来长期开放问题的强力解答；将 Scott–Xi、Chen 在仿射型中线性增长的无界族推进为有限对称群中的指数增长。
- **主要贡献**：
  1. 构造一族显式置换对，使 μ(x₂ᵣ,y₂ᵣ)=2^r（位于形状 (4+6r,4+6r,4+6r) 的共同左胞腔内，r≥0），从而 μ 关于长度差本身指数增长（δ_r=34r+11，次数 17r+5）；
  2. 引入基于 sl₃ webs 的新方法论：构造在 web 图形中“显然”，尽管其置换描述十分复杂；
  3. 提供 Lean 形式化验证，覆盖局部张量/图计算、格归纳与二态读出。
- **关键先驱工作**：Kazhdan–Lusztig（KL 多项式与 μ-系数）、Frenkel–Khovanov–Kirillov（FKK 张量坐标与正规化抛物 KL 多项式）、Khovanov–Kuperberg（basis web 不必为对偶典范基的反例）、Lanini–McNamara（对称群与单左胞腔内 μ 的关系）、Nguyen（左胞腔 W-图的算法）。
- **结果边界**：奇数个九字母块（m 奇数）对应 μ 系数为零；指数族限于三行矩形形状，二行分区内所有 μ 系数仍在 {0,1} 内。证明依赖 FKK/KK 等外部表示论结果（Lean 只验证本文自身贡献，不验证依赖）。
- **开放问题**：作者在文末略述主结果的若干推论，但未系统列出开放问题；由指数增长自然引出：其他形状/类型中增长率的精确阶、以及是否存在更快增长。
- **应用与推广**：μ-系数决定 KL 基上单反射的作用与 KL 胞腔 W-图边权，因而本文族可直接用于构造胞腔表示的复杂实例；方法论上，web 方法有望推广到更高秩 sl_n 或仿射类型的 μ 系数研究。

### 批判性思考
- 构造的“显然性”依赖 web 图而非置换，但证明仍高度复杂——是否存在更系统的范畴化证明（如通过 Soergel 双模或 Hecke 范畴）能简化？
- 证明中 Lean 只验证本文自身贡献，FKK/KK 等关键输入作为显式前提接受；若这些依赖被修正，结论的适用范围是否收缩？
- 单位三角修正依赖 Leclerc–Toffin 晶体基构造与 FKK 归一化，其中归一化把“最高 KL 次数”变成 t 的幂次，这一对应在一般形状下是否总能保持？
