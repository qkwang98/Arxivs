# The modular characters of $\text{Sp}_{10}(2)$
keywords: [Brauer 特征标, 模表示, 辛群, 块理论, 分解矩阵]
related_paper: "模块化特征标计算的 basic sets 方法（moc 包）"
one_liner_summary: 本文用 GAP 与 moc 包等计算方法确定了辛群 Sp10(2) 在特征 3 与 5 下非循环亏群块的不可约 Brauer 特征标，仅主 3-块存在一处歧义。
## 核心定位
- **解决的问题**：确定辛群 G=Sp10(2) 的不可约 3-模与 5-模特征标（限制在非循环亏群块上）。
- **大图景位置**：这是有限群模表示论中计算性项目（moc 包系列）的具体推进：以普通特征标表和极大子群 O10⁺(2)、O10⁻(2) 的 3-与 5-模特征标表为起点，用 basic sets 方法重构 G 的分解矩阵。
- **主要贡献**：
  1. 给出特征 3 下五个非循环亏群块（亏数 6, 4, 4, 2, 2；编号 B1, B2, B3, B5, B6）与特征 5 下三个非循环亏群块（均亏数 2；编号 B1, B3, B4）的分解矩阵，从而可直接算出不可约 Brauer 特征标；
  2. 特征 3 的证明独立可复现（仅需普通特征标表与上述子群模特征标表，可用 GAP/MAGMA 重验）；结果在主 3-块 B1 中保留一处歧义，其余完全确定。
- **关键先驱工作**：GAP 特征标表库（CTblLib）、moc 包（basic sets 方法，见同名专著）、Brauer 块理论的标准工具。
- **结果边界**：仅处理非循环亏群块（循环亏群块由 Brauer 树论覆盖，不在本文范围）；特征 5 的证明被略去（作者认为明显更容易），只留少量提示；主 3-块存在一处歧义未消除。
- **开放问题**：主 3-块 B1 中歧义的最终消除；向更大辛群 Sp_{2n}(2)（如 Sp_{12}(2)）推广的计算。
- **应用与推广**：所得分解矩阵与 Brauer 特征标表可作为后续研究（如块结构、代换论、有限群分类中局部结构计算）的可靠数据基础；basic sets 方法可推广到其他有相似极大子群结构的有限群。
