# Geometry of holonomic modules over the first Weyl algebra
keywords: [Weyl 代数, 完整 D-模, 形式亚纯联络, 截断喷流, 对数族, Stokes data, 局部 Fourier 变换]
related_paper: "Kontsevich 对数族与奇异类的对应构想；Sabatier 形式联络初等块理论"
one_liner_summary: 本文给出一阶 Weyl 代数上完整模形式局部数据的几何描述：指数部分由仿射平面曲线在无穷远的截断喷流编码，正则部分由正则形式亚纯联络编码，并证明装饰对数族与奇异类的双射对应在 Weyl 代数自同构（含 Fourier 变换）下等变。
## 核心定位
- **解决的问题**：对一阶 Weyl 代数 W_{1,C} 上的完整模（即单变量多项式系数线性微分方程组），给出其形式局部数据的几何编码，向 Stokes data 的几何描述迈出一步。
- **大图景位置**：Stokes data 范畴等价于解析亚纯联络范畴；固定奇异类（irregular class）后，Stokes data 范畴可描述为带关系箭图的表示范畴。本文把 Kontsevich 的对数族构想落实为可操作的对应工具。
- **主要贡献**：
  1. 构造装饰对数族空间 J~∞（截断喷流 j 与正则 C((t))-联络 M 的对）与奇异类之间的对应，限制在“初等”对象上为双射（Theorem T1）；
  2. 给出 J^∞ 的初等定义，证明其定义关系是等价关系，并证明 Aut(A²) 保持截断喷流空间（Kontsevich 仅陈述未证明的断言，Lemma J 传递性）；
  3. 构造 germ 函子与 Φ 函子的复合，建立形式局部数据的整体对应：辛自同构群 G 在 J~∞ 上的作用与 Aut(W_{1,C}) 在 Φ_glob(M) 上的作用一致（Theorem T2）；
  4. 采用 Arinkin 方法克服局部 Fourier 变换在存在水平截面时的退化，用局部驻相公式描述 Aut(W_{1,C}) 在形式亚纯联络上的作用（Theorem T0）。
- **关键先驱工作**：Kontsevich（对数族、J^∞ 空间）、Turrittin–Levelt 定理（形式解的一般形态）、Sabatier（初等块 El(ρ,φ,R)，形式亚纯联络的“Jordan 标准形”）、Malgrange 与 Kashiwara（Stokes data）、Arinkin（Fourier 变换的无退化定义）。
- **结果边界**：仅处理一阶 Weyl 代数（单变量情形）；对应限于形式局部数据与“初等”对象；正则部分的 quiver 表示描述（附录 B）保留比形式化更多的芽结构，但一般无法从 J~∞ 元素恢复。
- **开放问题**：完整 Stokes data（含解析正规解与 Stokes 因子）的几何描述仍待建立；高维 Weyl 代数的平行理论未讨论。
- **应用与推广**：为微分方程奇异摄动、Stokes 现象、形式联络分类提供几何化工具；对数族与喷流编码可望迁移到 q-差分与差微分方程的形式分类。
