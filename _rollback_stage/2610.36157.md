# Delooping levels on Morita context algebras

keywords: [delooping level, Morita context algebra, syzygy, derived delooping level, finitistic dimension]
related_paper: "2610.33762"
one_liner_summary: "在零双模同态的 Morita context 代数上，给出各分量代数 delooping level 有限时整体代数 delooping level、全局 delooping level 与导出 delooping level 有限性的充分条件，并展示整体指标可严格小于分量指标的实例。"

## 核心定位

- **解决的问题**：当 Morita context 代数的两个分量代数具有有限 delooping level 时，如何保证整体 Morita context 代数的 delooping level（及其派生不变量的推广）仍然有限。
- **大图景位置**：这是对 Bass 有限维数猜想相关不变量（delooping level、derived delooping level）在 Morita context 代数这一经典代数族上的系统研究；此前对 Artin 代数已证明 delooping level 可以取无穷而 $\Fin$ 有限，本文给出有限性的充分条件。
- **主要贡献**：1) 描述并计算零双模同态 Morita context 代数上模的 syzygy 结构；2) 建立主定理：若分量代数 $A$、$B$ 有有限 delooping level，$_{A}M$ 与 $_{B}N$ 半单，且存在 $n\in\mathbb{N}$ 使 $\Omega_{\Lambda}^{n}$ 作用于若干特定简单模的直和是可无限 deloopable 的，则 $\Dell(\Lambda)<\infty$；3) 将结果推广到全局 delooping level 与 derived delooping level，并给出满足假设的若干代数族与反例。
- **关键先驱工作**：Gélinas 引入 delooping level 并证明 $\Fin(R^{op})\le\Dell(R)$；Guo–Igusa 引入 derived delooping level 并证明 $\Fin(\Gamma^{op})\le\DDell(\Gamma)\le\Dell(\Gamma)$；Bass 的有限维数猜想；Morita context 代数的经典同调研究（如 BM2、BM3、CRS、GP、GX、LV 等系列工作）。
- **结果边界**：结果仅在双模同态为零（$\alpha=\beta=0$）的设置下成立；要求分量代数本身 delooping level 有限，并对双模的半单性与特定 syzygy 的可无限 deloopable 性有假设；非零双模同态的一般情形不在本文处理范围内。
- **开放问题**：对于不满足主定理假设的 Morita context 代数，如何刻画其 delooping level 的有限性；整体 delooping level 严格小于分量代数时的一般判定准则。
- **应用与推广**：零双模同态的 Morita context 代数将 $\mathrm{Mod}\,A$、$\mathrm{Mod}\,B$ 及两类三角矩阵代数模范畴全嵌入其模范畴，因而本文的 syzygy 计算与有限性准则可服务于三角矩阵代数及其他由 Morita context 拼合构造的代数族。

## 主动思考区

### 与其他工作的联系

- 这让我想起：相对 delooping level 在 torsion classes 区间上的行为 — 见 [[2610.33762]]
- [[2610.33762]]：同样研究 delooping level 的有限性传播，在 torsion classes 区间上建立相对版本；本文则在 Morita context 拼合代数上研究绝对与导出版本的保持，两者可互为补充。
- 技术迁移：对 Morita context 代数的 syzygy 显式描述技巧，可用于研究此类代数的有限维数猜想、$\Fin$ 与 $\Dell$ 的差距，以及推广到更一般的双模拼合（如三角矩阵环）上的同调不变量。

### 可以尝试的方向

- [ ] 对 $\Omega_{\Lambda}^{n}$ 可无限 deloopable 的假设寻找更易检验的代数或表示论等价刻画。

### 批判性思考

- 是否存在满足分量 delooping level 有限、但整体 delooping level 无穷的 Morita context 代数？文中例子表明整体 delooping level 可以比分量更小，这一方向的间隙尚需更系统的刻画。
- 主定理对双模半单性的要求是否本质？能否替换为更弱的同调条件。
