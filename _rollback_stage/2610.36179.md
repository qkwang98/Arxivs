# Mutation-acyclicity in rank four is decidable but not semialgebraic

keywords: [quiver mutation, mutation-acyclicity, cluster algebras, Markov invariant, semialgebraic criterion]
related_paper: "Beineke, Brüstle, Hille 的三顶点 mutation-cyclicity 判据"
one_liner_summary: "证明四顶点箭图的 mutation-acyclicity 可判定（利用高度界 $\max\{\mathrm{htq}(Q),m(Q)\}$ 的有限搜索，状态数 $O(h^{24})$），同时构造仿射族说明对 $n\ge 4$ 不存在固定的半代数判据。"

## 核心定位

- **解决的问题**：给出四顶点箭图 mutation-acyclicity 的判定算法，并回答更高秩情形是否存在类似秩三那样的半代数判据。
- **大图景位置**：mutation-acyclicity 是 acyclic cluster algebras 的基本组合性质，此前仅三顶点情形有完整判据，四顶点及以上无已知算法；本文把四顶点情形变为可判定，同时证明秩四及以上不存在固定半代数判据，填补了「可判定性」与「判据复杂度」两个空白。
- **主要贡献**：1) 主定理：若四顶点箭图 $Q$ 是 mutation-acyclic，则存在一条 mutation 序列到达无圈箭图，序列中每步的高度不超过 $\max\{\mathrm{htq}(Q),m(Q)\}$，其中 $m(Q)$ 是 Fomin–Neville 的 Markov 不变量在 totally proper wiggle class 上的取值；由此 mutation-acyclicity 在四顶点上可判定，搜索 $O(h^{24})$ 个状态；2) 对 $n\ge4$ 构造仿射族 $Q(t)$（箭图权重 $( -2,t+2,t,-t,2-t,0)$），其 mutation-acyclicity 当且仅当 $t<0$ 或 $t$ 为偶数，从而证明不存在固定的有限 Boolean 组合（多项式等式与严格多项式不等式）能判定 $n$ 顶点箭图的 mutation-acyclicity，即使允许非 mutation-不变量多项式；3) 修正前作对高度至多二的四顶点箭图的判据，并用短证书恢复分类计数。
- **关键先驱工作**：Fomin–Zelevinsky 引入 quiver mutation；Neville 证明 mutation-acyclic 箭图都是 totally proper 的，且其 mutation 类中有圈箭图的箭头重数被 Markov 不变量 $m(Q)$ 控制；Caldero–Keller 对 acyclic seeds 的描述；Beineke–Brüstle–Hille 的秩三 Markov 常数判据；Felikson–Shapiro–Tumarkin 的有限 mutation type 分类。
- **结果边界**：高度界只保证存在一条不超界的 mutation 序列，其他路线可能任意高；算法运行时间是箭头重数的伪多项式（非二进制编码长度的多项式）；$m(Q)$ 是否真正需要未知（猜想仅 $\mathrm{htq}(Q)$ 足够，已在高度至多三时验证）；结果不排除算术测试、一般 mutation 不变量或步数依赖输入的算法。
- **开放问题**：$\mathrm{htq}(Q)$ 单独是否足以作为界（若成立可将搜索降到 $O(h^{6})$）；mutation equivalence 的判定算法；是否存在类似 Coward–Lackenby 那样的界。
- **应用与推广**：高度界同时给出最短 mutation 序列长度的上界，可服务于 cluster algebra 的计算与分类；结合 Caldero–Keller 定理可判定（在其中一个箭图 mutation-acyclic 时）两个四顶点箭图在重标号意义下的 mutation equivalence；Lean 4 形式化提供了可机器核验的判据实现。

### 批判性思考

- 主定理证明依赖大量计算机验证的 case analysis（附录由程序对所有参数值逐一核对），独立的人工理解仍缺；形式化（Lean 4）采用了比文中更粗糙的高度界，两个界的差距来源值得审视。
- 半代数不可判定性的论证依赖系数为实数的一般多项式族，若限定整数系数或 mutation 不变量，结论是否依然成立是值得追问的边界。
