# Highest weight vectors in queer Howe duality
keywords: [queer 李超代数, Howe 对偶, 最高权向量, Gauss 分解, 奇异向量, Clifford 代数, Schur Q-函数, 大胞腔]
related_paper: "Cheng 与 Wang 关于一般线性与 queer 李超代数 Howe 对偶及其显式最高权向量的工作"
one_liner_summary: 用 Gauss 分解研究 queer 超群大胞腔坐标超代数正则表示中的奇异向量，给出 queer Howe 对偶中最高权空间 $H_\lambda$ 的显式基 $\{\prod_{k=1}^{\ell}a_k^{\lambda_k-\delta_k}b_k^{\delta_k}\mid\delta_k\in\{0,1\}\}$（维数 $2^\ell$），并恢复 Cheng 与 Wang 在一般线性超代数情形得到的显式最高权向量公式。
## 核心定位
- **解决的问题**：确定 $(\fq(m),\fq(n))$-Howe 对偶中与严格分拆 $\lambda$ 对应的最高权向量空间的显式基，即 queer 李超代数情形的显式最高权向量生成元。
- **大图景位置**：Howe 对偶的多重性自由分解 $S(\bc^{mn|mn})\cong\bigoplus_\lambda 2^{-\delta(\lambda)}L_m(\lambda)\otimes L_n(\lambda)$ 是 Schur $Q$-函数的 Cauchy 恒等式的表示论形式；本文为其提供构造性输入，同时把大胞腔 Peter--Weyl 观点（Styrkas）引入超群情形，并统一恢复一般线性情形的已知公式。
- **主要贡献**：
  - 定理 A：$\fn^-\oplus\fn^+$-奇异子空间 $\Sing(\co(\Omega_n))=\Gamma_n^{-1}(1\otimes\co(H_n)\otimes1)$，显式由 $\prod_{i=1}^{n}a_i^{r_i}b_i^{\epsilon_i}$（$r_i\in\bz$，$\epsilon_i\in\{0,1\}$）张成，其中 $a_k,b_k$ 由块矩阵 Schur 补公式给出。
  - 定理 B：对严格分拆 $\lambda=(\lambda_1,\ldots,\lambda_\ell)$，集合 $\{\prod_{k=1}^{\ell}a_k^{\lambda_k-\delta_k}b_k^{\delta_k}\mid\delta_k\in\{0,1\}\}$ 构成 $H_\lambda$ 的基，维数为 $2^\ell$。
  - 利用两个 queer 李超代数 Cartan 子代数的作用，在 $H_\lambda$ 上构造自然不可约 $\Cl_{2\ell}$-模结构，给出比一维情形更精细的描述。
  - 定理 C：同一 Gauss 分解方法应用到 $(\fgl(m|q),\fgl(m|n))$-Howe 对偶（$p=m$），恢复 Cheng 与 Wang 的显式最高权向量公式。
- **关键先驱工作**：Howe 的经典不变量论方法；$(\fgl(p|q),\fgl(m|n))$-Howe 对偶及 Cheng--Wang 的显式公式；Cheng--Wang 与 Sergeev 独立建立的 $(\fq(m),\fq(n))$-Howe 对偶；Schur $Q$-函数的 Cauchy 恒等式与 Schur--Sergeev 对偶；Styrkas 对简单代数群大胞腔正则表示的 Peter--Weyl 型描述；量子情形 Zhang 与 Chang--Wang 的工作。
- **结果边界**：工作于复数域 $\bc$；最高权向量空间仅在对应的 summand 存在时非平凡；$\dim H_\lambda=2^\ell$ 源于 queer 李超代数 Cartan 子代数 $\fh$ 非交换带来的 Clifford 模结构；严格分拆的长度受 $\min(m,n)$ 限制。
- **开放问题**：量子 queer 情形（Chang--Wang 的量子坐标 queer 超代数）的显式最高权向量尚待构造；$H_\lambda$ 的 $\Cl_{2\ell}$-模结构与更广泛表示论对象（如晶体基、FFT）的联系有待展开。
- **应用与推广**：为 queer Howe 对偶提供构造性基础，可用于联系 Schur--Sergeev 对偶与第一基本定理；Gauss 分解与大胞腔方法可迁移到其他李超代数族的奇异向量与最高权向量问题。
