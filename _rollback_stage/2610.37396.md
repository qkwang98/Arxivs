# Finite group actions on the non-minimal nilpotent orbit closures in type A

keywords: [幂零轨道, 轨道闭包, 有限群作用, 辛分解, Q-因子终端化, Mori 扇, 型A]
related_paper: "2610.37207"
one_liner_summary: "本文证明型 A 非极小幂零轨道闭包被内自同构有限群作用后的商的 Q-因子终端化恰为轨道闭包辛分解的商，并将两者的 Mori 扇等同。"

## 核心定位

- **解决的问题**：刻画型 A 幂零轨道闭包在有限内自同构群作用下的商簇的终端化几何，确定其 $\mathbb{Q}$-因子终端化与 Mori 扇的结构。
- **大图景位置**：将幂零轨道闭包的辛分解理论推广到带有限群作用的商簇；补足非极小轨道情形下商奇点的终端化刻画，是 GIT 商理论与奇异簇双有理几何的交叉。
- **主要贡献**：
  1. 对非极小幂零轨道闭包的有限群商，证明其 $\mathbb{Q}$-因子终端化恰好等于轨道闭包辛分解的商。
  2. 将每个 $\mathbb{Q}$-因子终端化的 Mori 扇等同于轨道闭包辛分解的 Mori 扇，从而给出商的 Mori program 描述。
- **关键先驱工作**：型 A 幂零轨道闭包的 symplectic resolution 理论；GIT 商理论；crepant resolution 的商与 $\mathbb{Q}$-因子终端化的已有结果（含 Bellamy 等在奇点商方面的系列工作）；Mori fan 与终端化分类的现代双有理几何工具。
- **结果边界**：仅在型 A、且幂零轨道非极小的条件下成立；极小幂零轨道闭包情形被明确排除，其商行为可能不同。
- **开放问题**：极小幂零轨道情形的对应终端化与 Mori 扇刻画；将结论推广到其他型（B/C/D）或更一般具有辛分解的奇异簇的有限群商。
- **应用与推广**：为商奇异簇的奇点理论、辛奇点分类与 Mori program 提供具体新例子；可用于 Springer 理论相关奇点及哈密顿约化几何的进一步研究。
