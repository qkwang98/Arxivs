# Iwahori Whittaker functions for unramified quasi-split groups

keywords: [Iwahori Whittaker 函数, 非分歧拟分裂群, Demazure–Whittaker 算子, 不等参数 Hecke 代数, Casselman–Shalika 公式]
related_paper: "Brubaker, Bump and Licata, Demazure operators and Whittaker functions (BBL)"
one_liner_summary: 对非分歧拟分裂约化群引入 Demazure–Whittaker 算子，证明其生成由群决定的不等参数 Hecke 代数，并由此给出 Iwahori Whittaker 函数全部取值的递归公式及 Casselman–Shalika 公式的新证明。

## 核心定位

- **解决的问题**：将分裂群情形下 Demazure 算子与 Whittaker 函数联系的整套方法（Brubaker–Bump–Licata）推广到非分歧拟分裂群，计算 Iwahori Whittaker 函数在一个基上的所有取值，并在非分裂情形给出 Casselman–Shalika 公式的新证明。
- **大图景位置**：球 Whittaker 函数的取值由 Casselman–Shalika 公式给出；利用 Iwahori 分解可将其分解为更细的 Iwahori Whittaker 函数。本文把这些细对象的全部取值用递归公式算出，属于 Lusztig 不等参数 Hecke 代数框架与 Whittaker 函数理论的交汇。
- **主要贡献**：
  1. 定义 Demazure–Whittaker 算子 $T_i$（由单根对应的 intertwining 算子导出），并直接证明拟分裂而非分裂时它们生成不等参数 Hecke 代数（参数由 $\mathbf{G}$ 决定）；
  2. 建立这些算子与 Iwahori Whittaker 函数取值间的递归公式（在 Weyl 群代表元对应的陪集 $Aw$ 上）；
  3. 以经典 Demazure 算子 $D_i=(T_i+1)/\text{归一化因子}$ 给出 Casselman–Shalika 公式的独立新证明。
- **关键先驱工作**：Lusztig 关于拟分裂情形单极表示的研究（Demazure 算子与不等参数 Hecke 代数）；Brubaker–Bump–Licata 分裂群方法；Chinta–Gunnells–Puskás 对覆盖群的工作；Casselman–Shalika 原始证明与 Reeder 基于 Kazhdan–Lusztig 多项式的过渡矩阵。
- **结果边界**：仅覆盖非分歧拟分裂群及其非分歧主级数；过渡到 Casselman 基的矩阵复杂且涉及 Kazhdan–Lusztig 多项式；与可解格点模型及量子群表示的联系仅在本笔记中预告，完整描述在后续论文给出。
- **开放问题**：$p$-adic 群的唯一泛函与 Hecke 代数模之间的联系很可能可以平行移植到拟分裂情形（作者明确表示有把握但尚未展开）。
- **应用与推广**：为拟分裂群上 Whittaker 函数提供统一计算方法；与 solvable lattice models、量子群表示论的关联可在后续工作中发展，也可用于研究唯一泛函理论与 Hecke 代数模结构。
