# Symmetric List Objects

keywords: [list object, 自由幺半群, 自由交换幺半群, symmetric monoidal category, 参数化递归, string diagram, 多重集]
related_paper: "2607.12944"
one_liner_summary: "本文在对称幺半范畴中研究参数化对称列表对象（允许置换最前两个元素的列表对象），证明其正是自由交换幺半群的构造，并推出所有对称列表对象存在时 CMon(C)→C 的忘却函子具有单态性，为有限多重集提供了无需闭包的纯幺半范畴公理化。"

## 核心定位

- **解决的问题**：如何在一般的对称幺半范畴内部（而非仅在有函数类型的类型论中）公理化地刻画有限多重集/自由交换幺半群？具体地，把 Joyal 算术宇宙与 Fiore 参数化列表对象中"列表 = 自由幺半群"的思想，推广到允许前两个元素置换的"对称列表对象"。
- **大图景位置**：这是列表对象理论（自然数对象的推广，源自 Lawvere 的函数式语义与 Joyal 算术宇宙）向交换方向的自然延伸；在类型论中有限多重集已被实现为 bag equivalence setoid 或带 swap 构造子的高阶归纳类型，本文表明这些构造只需要对称幺半结构而不需要闭包/函数类型，从而把多重集纳入纯范畴代数框架。
- **主要贡献**：
  1. 定义参数化对称列表对象（在对称幺半范畴中允许两个最前元素经 symmetry 置换），证明它给出自由交换幺半群的构造；
  2. 用 string diagram 给出 Fiore 定理（参数化列表对象给出自由幺半群）的图式化证明，并推出 $\mathsf{Mon}(\mathcal{C})\to\mathcal{C}$ 的忘却函子单态（monadic）；
  3. 对称版本下推出 $\mathsf{CMon}(\mathcal{C})\to\mathcal{C}$ 的类似单态伴随，从而把有限多重集（bag）纳入范畴论公理化。
- **关键先驱工作**：Hagino 与 Adámek 等对列表作为初始代数 $\mu X.1+A\times X$ 的研究；Lawvere 的自然数对象、Joyal 的算术宇宙与 Maietti 的内部语言；Cockett、Jay 对列表变体的探索；Fiore 的参数化列表对象与自由幺半群定理（Kelly 的 transfinite 构造）；类型论中的 bag equivalence（Danielsson、Altenkirch）与带 swap 构造子的 HIT（Choudhury）。
- **结果边界**：需要在对称幺半范畴中工作（对称性用于置换前两元）；参数化递归（而非普通递归）是获得自由幺半群性质的关键，最小幺半范畴设置下普通列表对象不足以重构列表运算（如 append）；文章未给出闭包或余完备性条件，说明结果在不含函数类型的范畴中仍成立，但也意味着不直接给出类型论中的计算实现。
- **开放问题**：对称列表对象与其它自由代数构造（自由交换半群、自由半环）能否用同样的"加一个置换规则"模式公理化？对称列表对象之间的态射范畴/消去子的唯一性是否如自由对象一般完全刻画？是否存在不需要参数化递归的较弱对称列表概念仍给出交换幺半群结构？
- **应用与推广**：为有限多重集（bag）提供纯范畴论模型，可用于算术宇宙、递归论与程序语义中交换数据结构的公理化；string diagram 证明技术可迁移到其它自由构造的范畴化证明；单态性结果把交换幺半群范畴与其底层范畴的联系纳入 monad 理论框架，便于泛代数与拓扑斯中交换结构的研究。

## 主动思考区

### 与其他工作的联系

- 这让我想起：monoidal 范畴中的自由结构与 Grothendieck 构造的对应——见 [[2607.12944]]。
- [[2607.12944]]：该笔记研究 Clifford 半群与 monoidal Grothendieck 构造、monoidal fibrations 中的幺半对象，与本文同属"在幺半范畴内刻画自由/结构对象"的问题域；本文的对称列表对象可视作 monoidal fibrations 框架之外的一种交换自由构造。
- 技术迁移：本文的 string diagram 证明风格（把参数化递归编码为图的收缩）可迁移到自由交换半群、自由交换环等泛代数构造的范畴化证明，作为 Fiore 定理的图式化补充。

### 可以尝试的方向

- [ ] 把对称列表对象推广到对称半群/半环对象，检验是否给出自由交换半群/自由交换半环的范畴论构造。
- [ ] 研究对称列表对象的消去子与态射范畴，验证其是否满足自由交换幺半群的泛性质（唯一性部分），并考察与 bag equivalence setoid 的等价关系。

### 批判性思考

- 允许置换"最前两个元素"是否足以生成任意置换（多重集的完全对称性）？对列表而言相邻对换生成全对称群，但对称列表对象只允许前两元交换，作者应依赖对称范畴的 coherence 来说明可由此得到任意重排，该论证是结果成立的关键假设。
- 参数化递归在对称版本中的唯一性构造没有在摘要中展开，自由交换幺半群的泛性质（商掉所有置换）是否确实由"只置换前两元"的规则捕捉，值得在证明中严格核对。
