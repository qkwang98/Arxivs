# Torsion Theories in a non-pointed Context II: iterated torsion theories

keywords: [torsion theory, 非点态, protomodular 范畴, 零对象类, 箭头范畴, Galois 结构, 可迭代]
related_paper: "2605141610"
one_liner_summary: "本文证明在带零对象类的正则 protomodular 范畴中，每个满足合适条件（含 Condition (N) 与挠自由反射子 protoadditive）的非点态挠理论都会诱导箭头范畴 Arr(C) 上的挠理论并保持同样性质，从而可迭代得到 Arr^n(C) 中的挠理论序列，推广了同调范畴中点态情形的已知结果。"

## 核心定位

- **解决的问题**：把同调范畴（pointed, regular, protomodular）中"挠理论经箭头范畴提升并可迭代"的机制（Gran 及其合作者处理，源自 EGVdL 的 Birkhoff 反射子与高阶 Galois 结构）推广到非点态设置：当基础范畴只有零对象类（而非真正的零对象）时，如何仍能由好的挠理论在箭头范畴中诱导新的挠理论并保持全部好性质？
- **大图景位置**：这是作者前作（non-pointed Context I，在 regular protomodular 范畴配备 posetal monocoreflective 子范畴、coreflector 反转单态的"零对象类"框架中研究挠理论）的续篇，目标是把 Gran 关于挠理论 ↔ 稳定分解系统 ↔ Galois 结构的对应推广到非点态；其迭代机制最终服务于从 n-extensions 范畴的导出 Galois 结构中提取同调群。
- **主要贡献**：
  1. 在带零对象类 $\mathcal{Z}$ 的范畴 $\mathcal{C}$ 中，每个"好的"非点态挠理论 $\mathbb{T}$ 诱导箭头范畴 $\mathrm{Arr}(\mathcal{C})$ 上的挠理论 $(\mathcal{T}_1,\mathcal{F}_1)$，其中 $\mathrm{Arr}(\mathcal{Z})$（零对象之间的箭头）构成新的零对象类；
  2. 证明诱导的挠理论保持原挠理论的全部好性质，尤其是 Condition (N)（挠子对象为特征子对象）与挠自由反射子的 protoadditivity——这两点的证明在点态情形平凡、在非点态情形则完全不同且远为复杂；
  3. 因性质保持，过程可迭代：得到 $\mathrm{Arr}^n(\mathcal{C})$ 中的挠理论序列 $(\mathcal{T}_n,\mathcal{F}_n)$。
- **关键先驱工作**：Dickson 的 Abel 范畴挠理论、Johnstone–Tierney 对一般点态范畴的推广；Borceux–Grandis 与 Bourn 的同调/半 Abel 范畴框架；Grandis–Janelidze 用理想 $\mathcal{N}$ 的核/余核定义的非点态挠理论、Facchini 的 pretorsion theory；作者前作（CM torsion theories 1）的零对象类框架；Gran 关于挠理论与分解系统、Galois 结构对应及 protoadditivity 的研究；Everaert–Goedecke–van der Linden 的 Birkhoff 反射子与广义 Hopf 公式。
- **结果边界**：基础范畴须为带 posetal、monocoreflective 零对象类子范畴（coreflector 反转单态）的正则 protomodular 范畴；挠理论须满足 Condition (N) 且挠自由反射子 protoadditive 等"合适条件"（点态情形自动满足、非点态需额外假设）；迭代得到的挠理论在 $\Arr^n(\mathcal{C})$ 上成立，但限制到 $n$-extensions 范畴以提取同调群的工作明确留作未来。
- **开放问题**：将迭代挠理论限制到 $n$-extensions（有效下降态射）范畴、由伴随的 Galois 结构提取同调群；非点态设置下 protoadditive 反射子与 Galois 结构中正规/中心扩张描述之间的精确对应是否与点态情形一致；更多满足全部条件的非点态例子（除多常数 protomodular varieties 与 elementary toposes 对偶外）。
- **应用与推广**：为含多常数的泛代数（unitary rings、Boolean/Heyting/MV-algebras 及其拓扑模型）与 elementary toposes 对偶中的同调代数提供统一框架；非点态挠理论经箭头范畴迭代的机制可用于构造高阶 Galois 结构并计算同调群，与半 Abel 情形中的 Hopf 公式类比。

## 主动思考区

### 与其他工作的联系

- 这让我想起：挠理论在范畴论中的不同实现——tt 挠模型结构、孪生挠对，以及 Abel 范畴挠理论的发展谱系——见 [[2609.39317]] 与 [[2605141610]]。
- [[2609.39317]]：该笔记研究正交模型结构与 TTF 挠模型结构、孪生挠对与挠模型结构的对应，是挠理论在模型范畴层的另一种范畴化；本文的迭代挠理论与其在"挠类/挠自由类如何承载高阶结构"上互补。
- [[2605141610]]：该笔记梳理 Dickson 挠理论、cotorsion theory 与 t-结构的发展历史，为本文非点态挠理论提供经典同调代数背景与范畴化脉络。
- 技术迁移：把 Condition (N) 与 protoadditivity 从 $\mathcal{C}$ 传递到 $\mathrm{Arr}(\mathcal{C})$ 的非点态证明技术，可迁移到其它由态射范畴诱导的结构（如群胚化、切片范畴）中的性质保持问题。

### 可以尝试的方向

- [ ] 实现文中预告的未来工作：把迭代挠理论限制到 $n$-extensions 范畴，并由此建立非点态版本的广义 Hopf 公式/同调群提取。
- [ ] 检验更多非点态例子（如拓扑模型、MV-代数范畴的对偶侧）是否满足全部所需条件，扩充可迭代挠理论的样本库。

### 批判性思考

- 非点态情形下"平凡性质变得远为复杂"说明零对象类 $\mathcal{Z}$ 的选择承载了实质内容；coreflector 反转单态这一假设本质上是把零对象的拟态射性质替换为结构性条件，其必要性（能否弱化）值得追问。
- 迭代得到的是 $\Arr^n(\mathcal{C})$ 中的挠理论序列，但最终目标（同调群提取）仍依赖未来工作，本文的"好性质保持"是充分条件还是必要条件尚不清楚。
