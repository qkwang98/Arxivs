# Hilbert functions of filtered graphical zonotopal algebras

keywords: [zonotopal algebra, Hilbert function, 滤过代数, 图重构, Tutte 多项式, boundary-state]
related_paper: "Nenashev–Shapiro 关于滤过 zonotopal 代数重构的前作（[NSh]）"
one_liner_summary: 本文研究图的滤过 zonotopal 代数 $\CC_G^f$ 的 Hilbert 函数如何依赖生成函数 $f$ 与图的结构，证明其对一切多项式 $f$ 仍不能重构十顶点树（否定 Nenashev–Shapiro 的公开问题），并给出森林退化情形的单项式表示、固定最大度树的统一参数划分以及黏合路径的四阶递推等显式公式。

## 核心定位

- **解决的问题**：一个图的滤过 zonotopal 代数 $\CC_G^f$ 的 Hilbert 函数 $\hs_G^f(t)$ 究竟能恢复多少图的信息？它如何随生成函数 $f$ 变化？在图的黏合（attachment）操作下如何计算？
- **大图景位置**：这是 Nenashev 与第一作者 [NSh] 问题的延续：滤过代数本身（取 $f=\exp$ 或一般的非退化 $f$）可以重构图，但 Hilbert 函数作为更粗略的不变量能保留多少信息则是不清楚的。本文同时给出正向公式与反例，是"代数–图"双向编码研究中的关键一步。
- **主要贡献**：①把滤过图重构从简单图推广到无孤立顶点的无环多重图（$f$ 的线性与二次系数非零）；②构造两个非同构的十顶点树，使 $\hs^f$ 对一切 $f\in\K[u]$ 相同，否定"所有多项式 Hilbert profile 可重构图"，并枚举十顶点内全部三对树与八顶点内一对单圈图的全多项式碰撞；③对森林与阶 $k\ge2$ 的退化级数给出以"被 $k$ 整除的偏得分向量"为索引的单项式表示与公式 $\hs_G^f=s_k(G;t)$；④对固定最大度 $D$ 的全体树给出有限统一参数划分，并在 $D=3,4$ 时用逆级数 $g=f^{-1}$ 的系数消失模式显式实现；⑤给出黏合路径的四阶递推 $L(a_n)=a_n-a_{n-1}-3t\,a_{n-2}+2t\,a_{n-3}$，星形与平行边的对称性约化，以及圈的稳定范围系数与最高次项公式。
- **关键先驱工作**：外部 zonotopal 代数 $\CC_G$（生成元 $X_v$ 幂零）与 graphical matroid 的等价性；Nenashev–Shapiro [NSh] 的滤过代数重构定理（$f=\exp$ 与一般非退化 $f$ 的简单图情形）；Tutte 多项式特化给出 $\CC_G$ 的分次 Hilbert 级数；external bizonotopal algebra 与 matching algebra 等邻近构造。
- **结果边界**：全多项式 Hilbert profile 对树的重构失败（十顶点反例）；统一参数划分只对固定最大度 $D$ 的树成立，且 $D=5$ 时不再由单个逆系数的消失刻画（五叶星即给出反例）；退化级数 $f=cu^k+\cdots$ 只能生成 $\CC_G$ 的真子代数，且单项式表示仅对森林成立（圈需一维修正项，偶圈长度相关）；计算依赖特征零假设。
- **开放问题**：圈的剩余系数猜想（以加权独立集公式描述 trace sequence）；Rees 模与滤过比较复形的解释；环状黏合所需的额外相容性；$D\ge5$ 时统一参数划分的显式描述。
- **应用与推广**：Hilbert 函数只依赖乘积空间的秩，比代数同构更易计算，可用于图的组合不变量研究；星形与平行边约化可嵌入任意更大图的边组；盒样条与格点计数（box splines、lattice-point enumeration）的既有联系提供了潜在应用；递推公式可用于枚举与符号计算验证。

## 主动思考区

### 与其他工作的联系

- 暂无匹配的已有笔记：当前笔记库中未找到关于 zonotopal algebra、filtered algebra 或 Hilbert function 重构主题的已有笔记。
- 技术迁移：边界态（boundary-state）局域计算把整体 Hilbert 级数化归为有限多种局域类型，这种"局域类型 + 传递矩阵"的思路可类比于一维统计力学转移矩阵方法，或可迁移到其他图不变量（如独立集多项式）的黏合计算。

### 可以尝试的方向

- [ ] 对 $D\ge5$ 的树，寻找统一参数划分的非系数消失刻画（已知单系数消失不够，可能需要代数簇条件的组合）。
- [ ] 将退化级数的单项式表示推广到更广图类（如 cactus 图），检验偶圈修正项的机制。

### 批判性思考

- 边界态多重性与基的选择无关，但 $p,q$ 的整体平移约定是否掩盖了某些不变量？作者将 Rees 模解释留作后续，可能暗示 $q-p$ 与最大度的界并非最优。
- 全多项式 profile 碰撞仅对十个顶点内的树做了穷举，更大图类中是否会出现更小规模的碰撞模式尚不清楚；"universal Hilbert equivalence" 的传递性结构值得更系统的刻画。
