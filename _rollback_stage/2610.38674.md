# Projected Brion's Theorem

keywords: [Brion 定理, 整数点变换, 格投影, 收缩类, 多面体, toric 簇, 权重重数, Gelfand-Zetlin 多面体, string 多面体]
related_paper: "2610.14275"
one_liner_summary: "给出 Brion 定理在投影整数点变换（沿格投影的 pushforward）下的类比：把多面体的顶点按被投影杀死的边方向分组为收缩类，类内顶点锥有理函数之和可整体 pushforward，从而得到投影整数点变换的有理函数分解。"

## 核心定位

- **解决的问题**：Brion 定理把有理多面体 $P$ 的整数点变换写为顶点锥 $K_v$ 对应有理函数之和，但沿格投影 $\pi\colon\R^n\to\R^m$ 做 pushforward $\pi_*$ 时，单个顶点锥项可能无定义——分母因子 $1-\vec x^{\vec u}$ 恰在 $\pi(\vec u)=0$ 时落入 $\ker\pi_*$。本文给出 $\pi_*\varsigma(P;\vec x)$ 由顶点局部数据组装成的公式。
- **大图景位置**：这是 Brion 型公式（整数点变换、Ehrhart 理论、toric 几何与表示论中权重重数计算的核心工具）在"投影"方向上的系统推广；其 toric 解释表明它正是子环面 $T'$ 的 Thomason 局部化定理在 $T$-等变 $K$-理论中的体现。
- **主要贡献**：
  1. 定义收缩边与收缩类：边被 $\pi$ 杀死方向（有界边即两端点像相同）时称 contracted，收缩边生成顶点集上的等价关系，其等价类为收缩类。
  2. 主定理（thm:projected-brion）：若无界边均不被收缩，则每个收缩类中顶点锥有理函数之和有良定义的 pushforward，且 $\pi_*\varsigma(P;\vec x)=\sum_S\pi_*\left(\sum_{v\in S}\varsigma(K_v;\vec x)\right)$；对格多面体，收缩类给出使该分解成立的最细分组（prop:minimality）。
  3. 定理 thm:phi-localizes：可求和 Laurent 级数 $f$ 的支撑对 $\pi$ 有有限纤维时，$\pi_*(f)$ 仍可求和且 $\Phi(\pi_*(f))=\pi_*(\Phi(f))$，从而把投影整数点变换与有理函数分解严格衔接。
  4. 线性族公式：$\pi_*\varsigma(\Delta(\vec c);\vec x)=\sum_S\vec y^{\vec a_S(\vec c)}\frac{g_S(\vec c)}{\prod_{\vec u}(1-\vec y^{\pi(\vec u)})}$，其中 $g_S$ 是 $\vec c$ 的多项式，次数以 $S$ 中顶点仿射张为界。
  5. 推广到扭曲 pushforward（$\theta\colon\Z^n\to K^\times$）与取值于有限生成阿贝尔群群环的变换。
- **关键先驱工作**：Brion 的顶点锥分解定理（格多面体与有理多面体）；Thomason 的 $T$-等变 $K$-理论局部化定理；Berline-Vergne 对简单多面体按 $\xi$ 常数面的顶点分组给出全纯函数的处理；Peterson 的退化 Brion 公式；Makhlin 关于 Gelfand-Zetlin 多面体投影恢复 Weyl 特征公式的结果。
- **结果边界**：主定理要求无被收缩的无界边；$g_S$ 的次数界依赖收缩类顶点仿射张；线性族公式中 $\vec a_S$ 的线性性与 $g_S$ 的多项式性依赖具体族的几何。
- **开放问题**：收缩类在非简单多面体情形的一般结构（不必是面的顶点集）；扭曲 pushforward 下更一般同态 $\theta$ 的显式公式；对 string 多面体给出 Littelmann 特征公式扩展到所有权重的完整形状。
- **应用与推广**：为投影格点计数提供可计算的分解工具；权重重数与 toric 不动点计数的统一框架；线性族公式可直接用于参数化计数问题与表示论特征公式的延伸。
