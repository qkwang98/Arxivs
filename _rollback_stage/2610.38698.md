# Models of n-dimensional categories as n→∞

keywords: [complicial set, (∞,n)-范畴, ∞-范畴, 左极限, 右极限, 严格ω-范畴]
related_paper: "2609.39317"
one_liner_summary: "本文建立 ∞-范畴序列沿左右伴随定义左/右极限的一般框架，验证饱和 complicial sets 的 ∞-范畴等价于 (∞,n)-范畴序列的右极限（提供 (∞,∞)-范畴模型），而左极限不等价；严格 ω-范畴则同时等价于严格 n-范畴序列的左右极限。"

## 核心定位

- **解决的问题**：给定 ∞-范畴的包含链 $\mathscr C_0\hookrightarrow\mathscr C_1\hookrightarrow\cdots$，如何组合成单个 ∞-范畴以反映 n→∞ 的极限行为？普通余极限通常不捕捉有趣的极限对象，本文系统处理沿左伴随或右伴随定义的左/右极限框架，并回答两类经典序列的极限模型问题。
- **大图景位置**：验证饱和 complicial sets 模型了 (∞,n)-范畴之 ∞-范畴序列的右极限，即提供 (∞,∞)-范畴的 complicial 模型，与 Loubaton 对 Θ-空间的右极限等价结果经模型等价互相推导；同时揭示严格与弱情形的重要分歧：严格 ω-范畴等价于左右两个极限，而 complicial 情形左极限与右极限不等价。
- **主要贡献**：
  1. 建立一般框架：何时一个 ∞-范畴等价于序列的左/右极限（模仿 HTT §5.5.6 的形式主义；presentable 情形下分别对应在 $\Pr^R$ 或 $\Pr^L$ 中计算余极限）；
  2. 严格情形：$\omega\cat\simeq\lim^R n\cat\simeq\lim^L n\cat$，两个极限等价；
  3. 弱情形（主定理）：$\lim_{n\ge0}^{R}\mathscr Comp_n\simeq\mathscr Comp$（饱和 complicial sets 的 ∞-范畴），而左极限给出不同对象，其伴随与 ORW1 的 proper reflective localization 等同；$N^{\mathrm{RS}}\cE$ 是该定位核中一个非平凡 (∞,∞)-范畴的显式呈现，其所有有限截断平凡。
- **关键先驱工作**：Verity 的 complicial set 理论（VeritySlides、EmilyNotes、OR、RiehlVerityBook）；Street 的有向复形与严格 ω-范畴；HTT §5.5.6 的极限形式主义；Loubaton 对 Θ-空间的右极限等价；ORW1 的 reflective localization 与 ORW2 的 $N^{\mathrm{RS}}$ 构造；Gepner-Heine、Stefanich、Goldthorpe、Campion 对右极限的既有考虑。
- **结果边界**：框架要求包含链存在左右伴随且满足 presentable 性以识别为 $\Pr^R$/$\Pr^L$ 余极限；证明依赖 routine 的 $\mathbb{N}$-序列严格化引理与 complicial 模型的基本事实；左极限不等价于 complicial 模型，故左极限需另行刻画。
- **开放问题**：构造更多非平凡 (∞,∞)-范畴（所有有限截断平凡）及其显式 complicial 呈现；左极限 $\lim^L\mathscr Comp_n$ 的完整模型与结构刻画。
- **应用与推广**：为 (∞,∞)-范畴提供可计算的 complicial 模型；与 Θ-空间、半严格（henry-loubaton）等模型的极限描述互相印证；为高阶同伦论中分层序列的极限计算提供形式化工具。
