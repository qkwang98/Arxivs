# PBW theorem for affine super Yangian

keywords: [PBW 定理, 仿射超 Yangian, 通用中心扩张, 二变量 current Lie 超代数, 求值同态, 迭代余积, 张量幂分离, Steinberg 超李代数, 完成包络代数]
related_paper: "2607.24334"
one_liner_summary: "证明 Ueda 的仿射超 Yangian（m,n≥2、m≠n、ε1=ε2=1/2、ħ=1）满足 PBW 定理：其分次代数典范同构于 sl(m|n)⊗C[z±1,u] 的通用中心扩张的包络代数，从而经典基上的任何（当前次数齐次的）全序都给出 Yangian 的有序单项式基。"

## 核心定位

- **解决的问题**：为 Ueda 构造的仿射超 Yangian（$m,n\ge2$，$m\ne n$，$\varepsilon_1=\varepsilon_2=\frac12$，$\hbar=1$）建立 PBW 定理，即识别其经典极限并给出表示论的基础基。
- **大图景位置**：这是 Yangian 理论（Drinfeld 引入，作为多项式 current Lie 双代数的 Hopf 代数量子化）的 PBW 定理谱系的一环：有限型超 Yangian（Gow 的 $Y(\mathfrak{gl}_{m|n})$）与 ordinary 仿射 Yangian（Guay-Regelskis-Wendlandt 的 simply laced 情形）之后，仿射超情形由于微分形式中心方向与 degreewise 完备化而需要新的处理。
- **主要贡献**：
  1. 主结果（thm:pbw）：分次同构 $\operatorname{gr}_F Y_\hbar\cong U(\operatorname{uce}(\mathfrak{sl}(m|n)\otimes\mathbb C[z^{\pm1},u]))$，其中 $\operatorname{uce}$ 为通用中心扩张（含微分形式中心方向）。
  2. 推论：经典基上任意（在当前次数上齐次的）全序，其 filtered lifts 的有序单项式构成 Yangian 基；偶基元素允许任意非负幂，奇基元素指数为 0 或 1。
  3. 证明路径：先经通用中心扩张与 Steinberg 超李代数识别经典呈现（Prop:classical-presentation-isomorphism），再研究 Ueda 求值公式在完成包络代数中的首项符号（Prop:evaluation-leading-symbols），配合迭代余积与张量幂分离（Lem:iterated-evaluation-symbols、Lem:tensor-power-separation）证明典范分次同态 $\Phi$ 的满射与内射；附录对 $\widehat{\mathfrak{sl}}(3|2)$ 显式选序并演示重排、中心修正、filtered lifts 与张量分离。
  4. 方法要点：正常 PBW 序给出求值目标中的局部有限系数与连续性；系数逐项分离论证全程保留微分形式中心方向与 degreewise 完备化。
- **关键先驱工作**：Drinfeld 的 Yangian 构造；Levendorskii 的 filtered PBW 基方法；Nazarov 与 Stukopin 的超代数理论；Boyarchenko-Levendorskii 的仿射 Yangian 构造；Guay-Nakajima-Wendlandt 的完成余积；Ueda 的仿射超 Yangian 构造与求值同态；Gow 的有限型超 Yangian PBW（RTT 与 Drinfeld 描述经 Gauss 分解联系）；Guay-Regelskis-Wendlandt 的 ordinary 仿射 PBW；Iohara-Koga、Chen-Sun 的 Steinberg 超李代数。
- **结果边界**：仅覆盖 $m,n\ge2$、$m\ne n$、$\varepsilon_1=\varepsilon_2=\frac12$（$\hbar=1$）的 Ueda 仿射超 Yangian；一般参数或 $m=n$ 情形不在本文范围。
- **开放问题**：一般参数 $\hbar$ 与任意 $m,n$ 的 PBW 定理；RTT 型与 Drinfeld 型描述的等价（仿射超情形）；与表示论（evaluation 模、张量范畴）的进一步联系。
- **应用与推广**：为仿射超 Yangian 的表示理论提供基与经典极限；方法（首项符号 + 迭代余积 + 张量分离）可用于其它带中心扩张的量子化代数。
