# The Categorical Fargues-Scholze Correspondence at Generic Parameters

keywords: [Fargues-Scholze 对应, 局部 Langlands 对应, generic 参数, Springer 理论, 反常层]
related_paper: "Local Langlands functoriality for Yu's supercuspidals II: Fargues--Scholze's parametrization (2609.16387)"
one_liner_summary: 将幂零锥上的 Springer 理论与 quasi-exceptional 集理论推广到不连通 reductive 群，从而在 generic 参数处构造谱侧层并刻画 Fargues-Scholze 函子的像。

## 核心定位

- **解决的问题**：在 generic 参数 $\phi$（其半简化不与任何带非平凡 monodromy 的参数重合）处，确定 Fargues-Scholze 范畴 Langlands 对应中谱侧对象 $c_\psi(i_{b!}\pi)$、$c_\psi(i_{b\sharp}\pi)$ 及相关层的确切形态。
- **大图景位置**：generous 参数处的对应行为已有较完整（一般是猜想性的）理解，本文为 generic 参数处的研究奠定基础，并给出对 generous 猜想的精确类比；同时将 Bezrukavnikov 的幂零锥 quasi-exceptional 集理论与 Springer 理论扩展到作为 semisimple generic 参数稳定子出现的（可能）不连通 reductive 群。
- **主要贡献**：1. 对 semisimple generic 参数 $\phi$ 的稳定子 $S_\phi$ 的每个不可约表示 $\rho$，在 $\mathcal{U}_{S_\phi}/S_\phi$ 上构造层 $\overline{\nabla}_\rho$、$\overline{\Delta}_\rho$、$IC_\rho$、$\delta_\rho$；2. 主定理（Theorem IntroMainThm）：在若干条件（经典 semisimple 局部 Langlands 一致性、generous 猜想对全体 Levi 已知、$c_\psi$ 与几何 Eisenstein 级数相容、$c_\psi$ 在 $D(\text{Bun}_G)^{\omega,\phi}$ 上 fully faithful）下，$c_\psi(i_{b!}\pi)\cong\nu_{\phi*}\overline{\nabla}_\rho$、$c_\psi(i_{b\sharp}\pi)\cong\nu_{\phi*}\overline{\Delta}_\rho$、$c_\psi(i_{b\sharp!}\pi)\cong\nu_{\phi*}IC_\rho$、$c_\psi(i_{b!*}\pi)\cong\nu_{\phi*}\delta_\rho$；3. 应用包括：generic 参数处 $c_\psi$ 的 t-exactness、Hecke 算子 $T_V$ 在 generic locus 上的 perverse t-exactness、generic 参数处 Hecke eigensheaves 的构造与基本性质、generic locus 上非半单化 Fargues-Scholze 参数的计算、以及 BM-O 双射的 Fargues-Scholze 理论版本；附录另证经典参数 generic 时 $i_P^G(\sigma)$ 完全可约。
- **关键先驱工作**：Fargues-Scholze 的范畴对应基础；Bezrukavnikov 的 quasi-exceptional 集；Hansen 北京讲义中 generous/generic 参数的定义；Hamann-Lee 的 Langlands-Shahidi 型条件；Hansen-Mann 关于 $\text{GL}(n)$ 的等价；AHR 的不连通 reductive 群表示论；perverse-coherent sheaf 理论；BM-O 双射。
- **结果边界**：主定理在一般群上仍为条件性结果，依赖 generous 猜想（对所有 Levi 成立）、Hamann-Hansen-Mann 进行中的几何 Eisenstein 相容性工作，以及 $c_\psi$ 的 fully faithful 假设；对 $\text{GL}(n)$ 仅依赖几何 Eisenstein 相容性，对许多经典群则主要瓶颈是 generous 猜想。
- **开放问题**：作者明确指出 generous 猜想（Conjecture generousstalks）是使主定理在更多群上无条件的首要瓶颈；几何 Eisenstein 相容性（Hamann-Hansen-Mann 进行中）一旦完成可大幅扩大定理适用范围。
- **应用与推广**：t-exactness 结果可用于研究 generic locus 上表示范畴与 Hecke 模块的精细结构；Hecke eigensheaves 的构造为局部与几何 Langlands 的进一步比较提供谱侧对象；非半单化 Fargues-Scholze 参数的概念具有独立价值，可用于追踪表示沿参数闭包边界的退化。
