# Bases for the Top-Degree Garsia--Haiman Module

keywords: [Garsia--Haiman 模, modified Macdonald 多项式, orbit harmonics, Haglund 统计量, q-Whittaker 多项式, column-strict 填充]
related_paper: "Hilbert schemes and the n! theorem (Haiman, 2001)"
one_liner_summary: 本文为每个分拆 $\mu$ 的 Garsia--Haiman 模 $V_\mu$ 的最高 $t$-度分量 $V_\mu^{\mathrm{top}}$ 构造两个新的单项式基——Haglund 基（指数由 Haglund 统计量的顶端特化控制）与 Flag 基（由插入算法给出 $q$-Whittaker 多项式 $m_{1^n}$ 系数的费米子公式的基实现）。

## 核心定位

- **解决的问题**：为 Garsia--Haiman 模 $V_\mu$ 构造显式基（开放问题 Problem 1 的部分解），本文聚焦于最高 $t$-度分量 $V_\mu^{\mathrm{top}}$。
- **大图景位置**：Haiman 的 $n!$ 定理确定了 $\dim V_\mu=n!$ 并建立了 modified Macdonald 多项式的 Schur 正性，但未给出显式基；本文以 Haglund--Haiman--Loehr 组合公式为验证基准，首次对最高 $t$-度给出完整的组合基。
- **主要贡献**：①Haglund 基：由 column-strict standard fillings $\CST_\mu$ 索引，单项式 $\mathfrak m_\sigma=x^{\invvec(\sigma)}y^{\rowvec(\sigma)}$ 的指数由 Haglund 反转三元组统计量控制；②Flag 基：由 $\mu$-格词 $\mathrm{Lat}_\mu$ 与 $g_a(\beta)$ 控制指数范围，实现 $q$-Whittaker 多项式 $m_{1^n}$ 系数的费米子公式 $\Hilb_q(V_\mu^{\mathrm{top}})=\sum_{\beta\in\mathrm{Lat}_\mu}\prod_{a=1}^n[g_a(\beta)]_q$；③row-word 枚举推论：固定行词 $\beta$ 时 $\sum q^{|\invvec(\sigma)|}=\prod [g_a(\beta)]_q$。
- **关键先驱工作**：Garsia--Haiman 对 $V_\mu$ 与 modified Macdonald 多项式的构造、Haiman 的 $n!$ 定理与 Hilbert scheme 几何、Haglund--Haiman--Loehr 组合公式、Adin--Remmel--Roichman 的 hook 形状基、Assaf--Garsia 的两列 kicking basis。
- **结果边界**：结果仅覆盖最高 $t$-度分量 $V_\mu^{\mathrm{top}}$，完整 $V_\mu$ 的显式基仍未解决；基的证明依赖线性泛函三角性与计数，未给出两基之间的显式变换矩阵。
- **开放问题**：对一般分级分量 $V_\mu^{(i,j)}$ 构造显式基；将插入算法推广到其他 Macdonald 型多项式（如非对称 Macdonald 多项式）；费米子公式的 $q,t$ 推广。
- **应用与推广**：为 coinvariant 与超空间 coinvariant 理论的单项式基研究提供模板；q-Whittaker 与晶格词的因式分解结构可迁移到 $S_n$ 模的 Hilbert 级数计算。
