# Additive factorizations in finitely generated semidomains

keywords: [additive factorization, semidomains, atomicity, half-factoriality, finite factorization, complete integral closure]
related_paper: "Baeth, Chapman 与 Gotti 关于正半环乘法与加法分解性质的论文"
one_liner_summary: "系统研究由有限多个复数生成的半环加法幺半群 $\mathbb{N}_0[S]$ 的分解性质：给出正整数生成元下 ACCP/BF/FF 与 HF/UF 的精确判别、加法因子分解有限性定理、原子性与半阶乘性的若干反例，以及完全整闭包的显式刻画。"

## 核心定位

- **解决的问题**：有限生成半环的加法幺半群 $M_S=(\mathbb{N}_0[S],+)$ 的因子分解性质（原子性、ACCP、BF、FF、HF、UF）如何依赖生成元集合 $S$，以及添附新生成元如何破坏或保持这些性质。
- **大图景位置**：这是因子分解理论（factorization theory）中非数值半群方向的推进——把单生成元情形（Correa-Morris–Gotti）的系统结论推广到多生成元，展示"单生成元结论不再成立"的丰富现象，并与 Anderson–Anderson–Zafrullah 的标准分解性质层级图衔接。
- **主要贡献**：
  - 有限长度分解有限性：对每个有限 $S\subseteq\mathbb{R}_{>0}$，$M_S$ 中每元素在给定长度下只有有限多个分解（用 Evertse–Schlickewei–Schmidt 定理）；由此 BF 与 FF 等价、HF 蕴含 FF。
  - 有理生成元精确判别：$S\subseteq\mathbb{Q}_{>0}$ 时 ACCP、BF、FF 恰在全部生成元 $\ge1$ 时成立，HF 与 UF 恰在全部生成元为正整数时成立。
  - 原子性反例：互素整数 $a,b\ge2$ 时 $M_{\{a/b,\ a/(a+b)\}}$ 的原子恰为 $a/(a+b)$ 的幂，故 $a/b$ 无分解、幺半群不原子；二次反例说明即使每个生成元的纯幂都是原子，幺半群仍可不原子。
  - 保持与提升：代数无关添附生成元保持六种性质；正代数生成元在联合线性无交性下 UF 提升；给出所有单项式为原子时半阶乘性的增强判别准则。
  - 完全整闭包：$S\subseteq\mathbb{Q}_{>0}$ 时完全整闭包为 $\mathbb{Z}[1/D]_{\ge0}$（$D$ 为既约分母的 LCM），且 $M_S$ 完全整闭恰当 $1/D\in M_S$。
- **关键先驱工作**：Anderson–Anderson–Zafrullah 的分解性质框架、Baeth–Chapman–Gotti 的正半环分解研究、Correa-Morris–Gotti 的单生成元理论、Chapman–Gotti–Gotti 的正有理单生成元不变量、Evertse–Schlickewei–Schmidt 子空间型定理、CGG21 的 $\mathbb{Q}_{\ge0}$ 加法子幺半群闭包公式。
- **结果边界**：结果依赖加法幺半群（而非乘法）视角，分解到相伴类；多生成元情形中"存在原子蕴含原子性"失效；正实生成元的结果依赖 ESS 定理，无法直接给出分解集合的结构；部分结论限于正有理数或正实数生成元。
- **开放问题**：文中末节总结分解性质蕴含链条并留下若干问题，如更一般复数生成元情形下原子性、ACCP 与 BF/FF 之间的精确关系。
- **应用与推广**：对半环与半域的加法结构分解性质提供了系统方法，可推广到 Laurent 求值、多生成元代数闭包与更广的加法子幺半群类别。

### 与其他工作的联系

- 这让我想起：因子分解理论中数值半群与广义数值半群的经典结果，以及多项式环中分解性质研究的方法论。
- 暂无匹配的已有笔记：笔记库中未检索到直接讨论半环加法分解、原子性或半阶乘性的既有笔记。
- 技术迁移：ESS 定理用于控制固定长度分解个数的技巧，或可迁移到其他加法/乘法幺半群的分解有限性估计。
