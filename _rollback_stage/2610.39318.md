# Pre-modular fusion categories of global dimension $2p$

keywords: [fusion category, pre-modular, global dimension, congruence representation, modular data, de-equivariantization]
related_paper: "Schopieray (2021) 关于 global dimension 为素数的 pre-modular fusion category 的分类工作"
one_liner_summary: 本文用代数与算术方法（尤其是 $\mathrm{SL}_2(\mathbb{Z})$ 的 congruence representation）证明：global dimension 为 $2p$（$p>5$ 素数）的 pre-modular fusion category 要么是 pointed，要么张量等价于 $\mathrm{Rep}(D_{2p})$。

## 核心定位

- **解决的问题**：对给定 global dimension $2p$（$p>5$ 素数）的 pre-modular fusion category 完成结构分类，回答「非简单情形下融合范畴由什么决定」的问题。
- **大图景位置**：这是（超）模融合范畴分类纲领的组成部分：已有工作覆盖 global dimension $p$（$p\neq 5$ 时 pointed）与 $p^2$（非简单模范畴完全分类），本文把分类推进到 $2p$ 这一新的量级，并承接 de-equivariantization 将 braided fusion category 归约为非退化与轻微退化两类的总体策略。
- **主要贡献**：
  1. 主要定理：若 $\mathcal{C}$ 是 global dimension $2p$（$p>5$ 素数）的 pre-modular fusion category 且 $\mathcal{C}'\subseteq\sVec$，则 $\mathcal{C}$ 是 pointed。
  2. 结合已知结果得到完整分类：global dimension $2p$ 的 pre-modular fusion category 要么 pointed，要么张量等价于 $\mathrm{Rep}(D_{2p})$。
  3. 技术层面把 $\mathrm{SL}_2(\mathbb{Z})$ 的 congruence representation（模与超模情形的射影版本）作为分类工具系统用于该量级。
- **关键先驱工作**：Drinfeld-Gelaki-Nikshych-Ostrik 关于 braided fusion category 与 de-equivariantization 的纲领（Müger 中心、Tannakian 子范畴）；Schopieray 对 global dimension $p$ 的 pre-modular 分类；Yu 本人对 $p^2$ 非简单模范畴的分类及 $p\le 5$ 情形的结构；modular data 的算术约束（BNRW、DLN、NRW、BRWZ）。
- **结果边界**：仅覆盖 $p>5$ 的素数情形（$p\le 5$ 已有结果）；定理要求 Müger 中心 $\mathcal{C}'\subseteq\sVec$（即由 $\Vec$ 或 $\sVec$ 主导的情形）；结论是张量等价意义下的分类，不涉及预模结构（编织/spherical）的精细差异。
- **开放问题**：非退化与轻微退化之外的中间情形（Müger 中心更大）的 $2p$ 量级分类；张量等价到 $\mathrm{Rep}(D_{2p})$ 的范畴是否携带非平凡编织结构有待澄清；将 congruence representation 方法推广到更大 global dimension 的前景。
- **应用与推广**：为模数据与 congruence representation 在融合范畴分类中的应用提供新样本；结果约束了 $2p$ 维量子对称结构，可用于顶点算子代数、共形场论与量子群单位根表示的分类问题。
