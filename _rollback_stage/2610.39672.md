# Syzygy-Quiver Formulas and Finitistic Dimensions of Special Biserial Algebras

keywords: [可达 syzygy 箭图, 特殊双序列代数, finitistic 维数, string 代数, relation-chain 箭图]
related_paper: "2610.37050 Relative derived delooping levels and torsion intervals"
one_liner_summary: 通过引入以迭代 syzygy 直和项为顶点的可达 syzygy 箭图，建立了所有有限维代数上投射维数与顶点有向路径高度的通用公式，并借助 Liu–Morin 闭包定理将其压缩为 string 代数与特殊双序列代数上可由 bound quiver 直接计算的组合不变量。

## 核心定位

- **解决的问题**：如何仅从 bound quiver 数据精确计算有限维代数的全局维数与 finitistic 维数，并回答 Xin–Zhang 关系链哲学能推广多远。
- **大图景位置**：Xin–Zhang 定理把 string 代数的全局维数表达为箭头起始的最小关系链最大长度；本文将这一思想推广到所有特殊双序列代数，把关系链箭图升级为顶点为 string 模的同调状态图，同时说明对一般双序列代数不可能做统一的路径/串压缩。
- **主要贡献**：第一，对任意有限维代数引入可达 syzygy 箭图 $\Gamma_\Omega(\Lambda)$ 并证明通用高度公式 $\pd_\Lambda X = 1 + \operatorname{ht}([X])$，从而全局维数与 finitistic 维数均可由高度函数读出；第二，对特殊双序列代数用 Liu–Morin 闭包定理把状态空间约化为 string-syzygy 箭图，使这些维数成为由 bound quiver 精确可计算的组合不变量；第三，对 string 代数恢复 Xin–Zhang 关系链公式并给出 finitistic 维数的平行公式；第四，证明一般双序列代数上不存在统一的路径/串压缩（Skowroński–Waschbüsch 代数为见证），且两个 string 代数可有相同 Gabriel quiver 却不同全局维数，说明关系理想对这些不变量不可或缺。
- **关键先驱工作**：Xin–Zhang 的关系链箭图与全局维数公式；Liu–Morin 闭包定理（特殊双序列代数上 string 模第一 syzygy 分解为投射部分与有限个 string 模直和）；特殊双序列、string、gentle 代数及双序列代数的经典表示论。
- **结果边界**：通用公式对所有有限维代数形式精确，但其状态是任意模，只有具备闭包性质的代数类才能变成组合定理；特殊双序列情形的等式 $\findim\Lambda \ge \sup\{1+\operatorname{ht}([X])\}$ 仅在全局维数有限时取等；对一般双序列代数，syzygy 转移只能通过双剖分表示用线性代数计算，无法统一压缩。
- **开放问题**：论文末节列出若干供未来研究的问题，包括寻找一般双序列代数上更强的组合压缩、以及非 monomial 关系（如 binomial 关系）情形下状态空间结构的进一步理解。
- **应用与推广**：高度函数框架给出 finitistic 维数猜想在特殊双序列类中的有效计算途径；string-syzygy 箭图的构造可直接用于其他具有类似闭包性质的有界箭图代数类，relation-chain 压缩思想也可迁移到 gentler 型代数的同调不变量研究。
