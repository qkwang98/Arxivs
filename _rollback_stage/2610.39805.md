# Standardly stratified structures from tilting modules

keywords: [特征倾斜模, 三角倾斜模, standardly stratified 结构, quasi-hereditary 代数, GLS path 代数]
related_paper: "2610.34716 Resolution quivers and the QF-1 property of higher Auslander Nakayama algebras"
one_liner_summary: 证明了基本倾斜模 $T$ 是某 standardly stratified 结构的特征倾斜模当且仅当 $T$ 是三角的（其不可分解直和项的支持在适当偏序下呈三角矩阵形），并由此从倾斜模出发唯一恢复标准模与全部偏序，进而把 GLS path 代数与关联遗传代数之间的倾斜对应限制为特征倾斜模的双射。

## 核心定位

- **解决的问题**：不预先指定偏序，仅从倾斜模本身的模论性质判定它是否为某 standardly stratified 结构的特征倾斜模，并在肯定情形下恢复标准模与全部偏序（逆问题）。
- **大图景位置**：quasi-hereditary 代数的特征倾斜模是 Ringel 对偶的核心对象，standardly stratified 结构是 quasi-hereditary 结构的自然推广；本文把 \cite{ACKT} 对代数闭域上 quasi-hereditary 情形的回答推广到任意域上的 standardly stratified 结构，并建立了三角倾斜模偏序集与标准分层结构偏序集的同构。
- **主要贡献**：第一，主定理（thmA）：基本倾斜模 $T$ 是特征倾斜模当且仅当 $T$ 是三角的，此时结构由 $T$ 唯一确定且满足三角条件的标号唯一；第二，给出结构内偏序的完全描述——关系 $j\preceq_T i$（$j\in\supp T(i)$）生成最小偏序 $\preceq_T$，结构中的偏序恰为包含 $\preceq_T$ 者，且标准模 $\Delta(i)$ 同构于 $S(i)$ 的投射覆盖在 $T(i)$ 中的 trace；第三，证明三角倾斜模偏序集与 standardly stratified 结构偏序集同构，三角性在 Ringel 对偶下保持，并给出递归判定算法；第四，应用：GLS path 代数与关联遗传代数的倾斜对应限制为三角（特征）倾斜模之间的双射，由此得到 $m\ge2$ 时 $k[x]/(x^m)\otimes_k k\vec{\mathbb{A}}_n$ 没有 quasi-hereditary 结构但每个倾斜模都是特征倾斜模的例子。
- **关键先驱工作**：Ringel 的特征倾斜模与 Ringel 对偶；Cline–Parshall–Scott、Dlab、Ágoston–Dlab–Lukács 对 standardly stratified 代数与 stratifying systems 的研究；Geiss–Leclerc–Schröer 的 GLS path 代数与倾斜对应；\cite{ACKT} 的 quasi-hereditary 特征倾斜模刻画；\cite{MPW} 的 essential order 与 \cite{FKR} 的 adapted order。
- **结果边界**：主定理针对基本有限维代数与基本倾斜模；三角条件要求直和项可标号为 $T(1),\dots,T(n)$ 使得 $\supp T(i)\subseteq\{j\mid j\unlhd i\}$，标号唯一性依赖该条件；应用部分仅覆盖 GLS path 代数这类张量代数，一般代数的倾斜模未必三角。
- **开放问题**：对任意倾斜模判断三角性的高效算法细节；特征倾斜模与三角倾斜模之间的对应在更一般张量代数上的推广。
- **应用与推广**：三角性判据把标准分层结构的研究转化为倾斜模组合（支持集）的研究，可直接用于构造非 quasi-hereditary 但具有良好倾斜理论（全倾斜模均为特征倾斜模）的代数例子；$\preceq_T$ 与 essential/adapted order 的一致性为偏序比较提供了统一框架。
