# Parahoric Spherical Whittaker Functions

keywords: [parahoric 子群, Whittaker 函数, Casselman–Shalika 公式, Demazure–Whittaker 算子, Rankin–Selberg 积分]
related_paper: "2610.37614 Iwahori Whittaker functions for unramified quasi-split groups"
one_liner_summary: 对 $\GL_n(F)$ 的标准 parahoric 子群 $K_\mu$ 建立归一化 parahoric Whittaker 特征函数对角值的块状 Casselman–Shalika 公式，证明每个不可约 generic Iwahori-spherical 表示在合适 parahoric 上恰有一维不动线、由完整 Hecke 特征唯一决定，并在每个 Bruhat cell 上给出显式有限公式，进而得到局部 Rankin–Selberg 积分与 $L$-因子测试向量。

## 核心定位

- **解决的问题**：Shintani 与 Casselman–Shalika 的球性公式描述极大紧致不动向量，Baruch–Karameris 计算 Steinberg 表示的 Iwahori 不动 Whittaker 函数；本文研究介于两者之间的标准 parahoric 子群情形，给出其 Whittaker 特征函数的显式公式并用于局部 Rankin–Selberg 积分。
- **大图景位置**：显式 Whittaker 函数是自守 $L$-函数的局部测试向量；本文把经典的球性（Shintani、Casselman–Shalika）与 Iwahori 情形（Bar–Kar、Brubaker–Buciumas–Bump–Gustafsson）推广到任意标准 parahoric，实现标准 segment 分类在一维 parahoric Hecke 模内的实现。
- **主要贡献**：第一，对角公式：归一化 parahoric Hecke 特征函数的对角值等于每个 Levi 块对应的 Schur Laurent 多项式之积，带适当模因子（块状 Casselman–Shalika 公式）；第二，对分拆 $\mu$ 构造由长度为 $(\mu^+)^t$ 的 Steinberg 因子诱导的 generic 表示，其 $K_\mu$-不动空间恰为一线，且关于 parahoric 包含是新的（严格更大的 parahoric 无非零不动向量），完整 parahoric Hecke 特征连同规范分拆 $\mu$ 唯一决定表示；第三，在额外不可约假设下用 opposite induced model、保持 Whittaker 的 intertwiner 与 Demazure–Whittaker 算子，在每个 Bruhat cell 上得到显式有限公式（结合 BBBG 的 Iwahori 公式与块对称化）；第四，应用：$\GL_n\times\GL_1$ 与兼容 parahoric 的 $\GL_n\times\GL_m$ 局部 Rankin–Selberg 积分，后者由最低 Laurent 系数与等秩函数方程决定，显式平移与缩放给出局部 $L$-因子的测试向量。
- **关键先驱工作**：Shintani 与 Casselman–Shalika 的球性 Whittaker 公式；Baruch–Karameris 的 Iwahori 不动 Steinberg Whittaker 函数；Brubaker–Buciumas–Bump–Gustafsson 的 Iwahori Whittaker 公式；Jacquet–Piatetski-Shapiro–Shalika 的 Rankin–Selberg 理想定理与函数方程。
- **结果边界**：完整显式公式依赖额外的不可约性假设（Section opposite-induced model）；$\GL_n\times\GL_m$ 情形限于 $n>m$ 且较大 parahoric 由附加单例块得到；平凡中心特征为前置条件。
- **开放问题**：去掉额外不可约假设后能否在全部 Bruhat cell 上获得同样显式的公式；非平凡中心特征与更一般 parahoric 组合情形的积分公式。
- **应用与推广**：为局部 $L$-因子提供不依赖完整 Bruhat cell 求和的显式测试向量；parahoric Hecke 特征分类把 segment 分类嵌入 Iwahori 不动模内的一维 Hecke 模，可用于研究层范畴与模表示论的对应。
