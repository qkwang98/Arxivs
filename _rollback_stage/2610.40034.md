# Quasimodularity of $q$-series associated to root lattices

keywords: [拟模形式, 根格, 极 quasi-Jacobi 形式, 顶点代数, Witten zeta 函数, 多重 q-zeta]
related_paper: "2610.34953 Faithful Localization of Vertex Algebra Modules"
one_liner_summary: 对有限维单李代数关联的多重 $q$-zeta 函数 $F_{\mathfrak g,\ell,k}$ 及其 Weyl 对称化版本，引入 level-one 集与 level-two 对两类新组合对象并证明相应格点和为极 quasi-Jacobi 形式的 Fourier 展开，从而证明其在所有经典李代数（$A/B/C/D$ 型）上的拟模性猜想。

## 核心定位

- **解决的问题**：证明由 class-$\mathcal{S}$ 顶点代数与四维超对称场论研究引出的猜想：在合适奇偶条件下，有限维单李代数 $\mathfrak g$ 关联的多重 $q$-zeta 函数 $F_{\mathfrak g,\ell,k}$ 是 $\SL_2(\mathbb Z)$ 某同余子群上的拟模形式。
- **大图景位置**：多重 zeta 值与根系统、李代数相交于数论、表示论与数学物理；其 $q$-模拟近期出现在顶点算子代数与四维量子场论超对称指标中，模性被期望反映底层表示论结构；本文是 Zagier 关于 Witten zeta 函数偶数参数整格求和的 $q$-模拟，把拟模性归结为格点和的组合结构。
- **主要贡献**：第一，引入 level-one sets 与 level-two pairs 两类新组合对象，推广经典根系统配置；对容许多项式 $p$ 证明相应的多元格点和 $\Psi_{S,p}$（与 $\Psi^{(\bm s)}_{S,p}$）是 level one（level two）极 quasi-Jacobi 形式（指标 0、混合权由 $p$ 的度界住）的 Fourier 展开（Theorem main1 / main2），$\bm s=\bm0$ 时落在 $\Gamma_0(2)$ 上；第二，由椭圆变量特化证明 $F_{\mathfrak g,\ell,k}$ 对全部经典李代数 $A/B/C/D$ 的拟模性（$A$ 型由 level-one 理论、$B/C/D$ 型由 level-two 理论处理），并对指数 $k_\alpha$ 随根变化、满足 $k_\alpha\equiv\ell\equiv0\pmod2$ 的 Weyl 对称化版本 $F^W_{\mathfrak g,\ell,\mathbf k}$ 证明拟模性；第三，建立秩归纳所需的约化程序与稳定性理论，并给出对整系数超平面排列格点和更广拟模性猜想的框架（Zagier 提出的一般原则）。
- **关键先驱工作**：Witten 与 Zagier 的根系统多重 zeta 值；Arakawa、Arakawa–Kawasetsu、Beem–Rastelli、Milas 的 class-$\mathcal{S}$ 顶点代数特征标与拟模性猜想；Bachmann 的 $q$-MZV 代数与 Okounkov 的 $q$-MZV；Oberdieck–Pixton、Goujard–Möller 对椭圆变量取常项/围道积分得到拟模形式的方法。
- **结果边界**：主定理覆盖经典李代数（$A/B/C/D$），例外型（$G_2$、$F_4$、$E_{6,7,8}$）未处理；level-one/level-two 结构只刻画两宽类配置，更一般的超平面排列格点和拟模性仍是猜想；奇偶条件是本质的（去掉对称化的 $q$-MZV 型级数一般不拟模）。
- **开放问题**：把拟模性框架推广到例外型与更一般积分向量配置；研究相关 $q$-级数生成的代数结构（生成元、导子、关系）及其与 $q$-MZV 关系的对应。
- **应用与推广**：证明 genus zero class-$\mathcal{S}$ 顶点代数（Arakawa）特征标的拟模性；为整系数超平面排列的格点和提供统一的准 Jacobi 视角，可直接用于更多组合与几何问题中的格点和估计。
