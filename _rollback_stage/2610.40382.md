# Beyond Selected Breakthroughs: Evaluating Language Models on Randomly Sampled Mathematical Conjectures

keywords: [LLM数学能力, OpenConjecture数据集, 数学猜想, 反例与证明, 三轮评估协议, 解新颖性]
related_paper: "First Proof（AI 数学证明基准，Abouzaid 等）"
one_liner_summary: 引入 OpenConjecture 数据集，对从 arXiv 随机抽样的 200 个数学猜想用前沿 GPT 模型做三轮无领域指导求解，系统分析候选解的类型、新颖性、文献引用与作者意图保真度，指出评估应超越正确性。

## 1.  核心定位

- **解决的问题**：只盯着重大突破（如 Erdős 单位距离猜想的否证、Jacobian 猜想、Navier–Stokes 爆破）会给 LLM 数学能力与计算资源需求以偏概全；本文用随机抽样回答"LLM 在普通数学猜想上到底能解多少、解得好不好、解在数学上贡献了什么"。
- **大图景位置**：在 AI 辅助数学的评估研究中，多数基准（First Proof、Leipzig 等）选已知答案的问题；本文反其道而行——直接从 2026 年 2 月以来 arXiv 预印本中"野外"采集猜想，首次系统度量模型对全新开放问题的行为分布，属于 LLM 数学能力评估从"正确性中心"转向"贡献性质中心"的代表性工作。
- **主要贡献**：
  1. 发布 OpenConjecture 数据集：收集 arXiv 数学论文（2026-02 起）中的猜想，公开在 HuggingFace 供分析使用；
  2. 可复现的三轮求解协议：从 200 篇随机抽样论文各取 1 个猜想，对 GPT-5.6 Sol、GPT-5.6 Sol Pro、GPT-6 Astra Pro 做三轮提示，每轮以上轮未解决尝试为上下文，且不提供问题特定的数学指导；得到约 60% 的猜想产生候选解（70 个反例、55 个证明，反例约为证明的 1.3 倍），84% 的候选解通过 LLM 复核；
  3. 对候选解做多维内容分析：长度（词数与定义/引理/定理数量）、反例构造的新颖性及其与作者意图的符合度、证明与既有文献的关联程度、是否依赖猜想的错误或欠规范表述（如提出平凡群作反例）。
- **关键先驱工作**：OpenAI 等单位对单位距离猜想、Jacobian 猜想、Navier–Stokes 等的突破式结果；First Proof 与 Leipzig 基准；AI 辅助数学中的可复现提示协议与成本记录传统。
- **结果边界**：不做专家验证与形式化，也不将数据集用作模型间比较基准；"通过 LLM 复核"不等于数学正确性；结论基于 2026 年上半年的 GPT 模型族，不代表其他模型或后续版本；仅从 arXiv 论文抽取猜想，覆盖存在选择偏差。
- **开放问题**：如何自动区分"利用欠规范/错误的猜想"与"数学上有实质的构造"；解的新颖性如何独立于文献检索能力被度量；为"保真于作者意图"建立可操作的自动化判据仍是开放方向。
- **应用与推广**：OpenConjecture 可作为开放数学问题的持续来源，供自动化猜想求解、形式化验证、问题筛选等流水线使用；三轮累积上下文协议可推广为通用的"无指导多轮求解"评估基线；其"反例与证明比例""off-the-shelf vs standard constructions"等分类框架可迁移到其他领域模型评测。

## 2.  主动思考区

### 2.1.  与其他工作的联系

- 这让我想起用数学结构承载 LLM 检索与证明流程的工作 — 见 [[2609.06127]]
- [[2609.06127]]：该文构建 Proof-Carrying Algebraic-Geometric Retrieval 框架（quiver/sheaf 理论支撑的 LLM 数学检索），与本文对 LLM 解与文献关系的分析互补——前者强调检索结构，后者度量解对既有文献的依赖程度。
- [[2610.37260]]：该文讨论数学发现的"现实捕捉"与地形学式绘图，与本文把"野外猜想"作为数学地形样本进行系统勘察的立意相通。
- 技术迁移：OpenConjecture 的随机抽样协议能否用于评估其他生成式系统（定理证明器、自动形式化器）在开放问题上的表现？

### 2.2.  可以尝试的方向

- [ ] 对 200 个候选解中的相当比例做专家验证，校准"LLM 复核通过率 84%"的真实误差。
- [ ] 将三轮协议扩展到更多模型族与更多 pass，观察反例/证明比例与新颖性的收敛行为。
- [ ] 为"作者意图保真度"开发可自动化的形式化判据（如把猜想转成类型/逻辑陈述后做一致性检查）。

### 2.3.  批判性思考

- "随机抽样 200 篇论文各取 1 个猜想"中"取哪个猜想"的选择若由人工完成，会引入何种偏差？
- 以 LLM 复核代替专家验证，可能系统性高估简单反例（如平凡群反例）的通过率，本文如何缓解？
- 解的长度与结构统计能否真正反映"数学贡献"，还是更接近生成模型的表面统计量？

## 3.  补充信息

论文以 ICLR 2027 会议格式撰写（math.HO 分类提交，2026-10-30）；OpenConjecture 数据集位于 https://huggingface.co/datasets/OpenConjecture/openconjecture ，200 个抽样的模型响应将另行公开。作者单位为 Pacific Northwest National Laboratory、UC San Diego、University of Pennsylvania 与 University of Washington。
