# Process matrices on generalised theories

keywords: [过程矩阵, 广义物理理论, 非确定因果序, 范畴超映射, 过程泛函, 经典探针自然性]
related_paper: "Quantum correlations with no causal order（Oreshkov-Costa-Brukner）"
one_liner_summary: 将过程矩阵框架推广到广义物理理论，用经典探针上的强自然性重新公理化过程泛函，并精确刻画过程矩阵表示与超映射-过程矩阵一致性的成立条件。

## 1.  核心定位

- **解决的问题**：把刻画非确定因果序（indefinite causal order）的过程矩阵框架从量子与经典理论推广到更广的广义物理理论（generalised theories），回答三个问题：什么是广义理论上的过程泛函？何时过程泛函允许过程矩阵表示类比？超映射（supermap）与过程矩阵两种视角在什么条件下一致？
- **大图景位置**：这是对 Oreshkov-Costa-Brukner 过程矩阵纲领与 Chiribella 量子超映射纲领的范畴化统一尝试；它将量子基础中"因果结构"研究嵌入广义概率理论（GPT）谱系，同时衔接 categorical supermaps 与过程矩阵两条路线，填补了广义理论中二者关系的空白。
- **主要贡献**：
  1. 以"经典探针上的自然性"给出时空上下文的简洁重公理化，精确刻画非语境赋值（non-contextual assignment）与局部实验室内凸性、粗粒化兼容性；
  2. 证明核心定理：任何广义理论 $\mathcal{C}$ 上，过程泛函全体与经典变量上的强自然变换全体同构，构成 categorical supermaps 纲领的直接类比；
  3. 在具备 channel-state duality（Choi-Jamiolkowski 类同构）的理论中证明：Busch-Gleason 公理成立当且仅当每个多部分抽象过程泛函都有过程矩阵表示；
  4. 特征化产品输入过程泛函：经典理论对应经典随机过程、量子理论对应 POPT 张量、Boxworld 对应 Boxworld 过程张量，并指出量子与 Boxworld 情形的刻画"非物理"根源于 completeness 缺失而非单纯的积极性或信号性失败。
- **关键先驱工作**：Oreshkov-Costa-Brukner 过程矩阵、Chiribella 量子超映射（completeness 原理）、categorical supermaps 与 Yoneda 引理（Hefford-Wilson 系列）、广义概率理论（Barrett 等）、Choi-Jamiolkowski 同构、Busch-Gleason 定理、wNSWSE 条件（Bavaresco 等）。
- **结果边界**：过程矩阵表示定理仅在带 channel-state duality 的理论上成立；产品输入过程泛函的刻画在量子与 Boxworld 情形因缺失 completeness 而非物理（量子是表示算子非正性、Boxworld 是 wNSWSE 弱化）；Tomographic Closure 不满足时并非每个过程矩阵都是超映射。
- **开放问题**：共享过去（common past）资源/环境介导纠缠实验的兼容性目前只有示意性刻画，作者明确说明该 schema 尚未形式化；更广理论类上不依赖内在线性表示的过程泛函公理化仍待完善。
- **应用与推广**：为 Boxworld 等超量子理论上的因果结构提供统一框架；可推广到多部分、多参与方因果不等式（OCB、Lugano、Grenoble 过程）的广义理论分析；为强 profunctor 范畴中张量积结构驱动的过程泛函扩展提供入口。
