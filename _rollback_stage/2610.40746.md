# Homotopy in Enriched Functor Categories: Frobenius Exact Structures and Weak Serre Functors

keywords: [Frobenius 精确范畴, 富化函子范畴, 弱 Serre 函子, 同伦关系, 三角稳定范畴, N-复形]
related_paper: "Gillespie 的 N-复形同伦范畴工作（本文 \cite{Gil15}）"
one_liner_summary: "在闭对称幺半范畴 $\mathcal{V}$ 上，对小型 $\mathcal{V}$-范畴 $\mathcal{A}$ 的富化函子范畴 $[\mathcal{A},\mathcal{V}]_0$ 赋予逐点平凡正合结构 $\mathcal{E}_{\mathrm{lowt}}$，给出其成为 Frobenius 精确范畴的充分条件，并用新引入的左右弱 Serre $\mathcal{V}$-函子刻画抽象的左右同伦关系。"

## 核心定位

- **解决的问题**：何时富化函子范畴 $[\mathcal{A},\mathcal{V}]_0$（配备逐点平凡正合结构 $\mathcal{E}_{\mathrm{lowt}}$）成为 Frobenius 精确范畴从而诱导三角稳定范畴，以及其中的抽象同伦关系能否用逐对象定义的态射族显式刻画。
- **大图景位置**：这是经典同伦范畴构造的系统统一：$N$-复形同伦范畴 $\mathbf{K}_N(R)$ 与 $m$-周期复形相对同伦范畴 $\mathbf{K}_{\equiv_m}(\mathcal{C})$ 均被实现为某类 $R$-模值函子范畴上的 Frobenius 稳定范畴；本文将框架提升到富化范畴论，从而涵盖非模范畴（如概形上的拟凝聚层、Banach 空间范畴）。
- **主要贡献**：
  1. 在闭对称幺半范畴 $\mathcal{V}$（弱幂等完备且加法）中，对每个对象 $A\in\mathcal{A}$ 引入局部诱导幺半对象 $R_A:=\mathcal{A}(A,A)$，建立伴随三元组 $(\mathrm{q}_A,\mathrm{ev}_A,\mathrm{p}_A)$ 与 $\mathcal{E}_{\mathrm{lowt}}$ 投射/内射对象的显式描述，并证明存在足够投射与内射。
  2. 给出两组条件 Condition (frob) 与 Condition (frob2)，证明满足其一则 $\mathcal{E}_{\mathrm{lowt}}$ 投射类包含于内射类（反之亦然），同时满足则 $([\mathcal{A},\mathcal{V}]_0;\mathcal{E}_{\mathrm{lowt}})$ 为 Frobenius 精确范畴，两个稳定范畴重合且为三角范畴，并显式描述环空间 $\Omega$ 与悬垂函子 $\Sigma$。
  3. 引入右/左弱 Serre $\mathcal{V}$-函子，证明右（左）同伦为零当且仅当可由一族满足特定等式的 $R_{\mathrm{G}(A)}$-态射（或 $R_{\mathrm{F}(A)}$-态射）确定，从而统一链同伦与相对同伦关系。
  4. 附录构造富化稳定范畴 $\underline{[\mathcal{A},\mathcal{V}]}$ 与 $\overline{[\mathcal{A},\mathcal{V}]}$，其底层普通范畴恰为投射/内射稳定范畴。
- **关键先驱工作**：Keller 的 Frobenius 精确范畴框架（稳定范畴三角化）；Gillespie 对 $N$-复形同伦范畴的 Frobenius 精确结构；Pirashvili--Xiu 的 $m$-周期复形相对同伦；Pareigis 的幺半对象与左对象理论；Bak20 的双可对 $R$-左对象；DSS17 的经典 Serre 函子。
- **结果边界**：$\mathcal{V}_0$ 需为弱幂等完备的加法范畴且具有限（余）极限；$N$-复形情形要求 $N\geq 2$、$m$-周期情形要求 $m$ 为偶数；Frobenius 结论依赖 $\mathcal{A}$ 同时满足两组条件；弱 Serre 函子刻画中的态射族须满足的等式在一般设置下仍较抽象，需借助特定情形简化。
- **开放问题**：文末提出的问题涉及富化商构造的适用范围——Setup 3 条件下可构造投射稳定范畴的富化版本，而注入稳定范畴需要更强的 $\mathcal{V}_0$ 乘积假设；经典 Serre 函子与弱 Serre 函子之间更精确的桥接条件仍待厘清。
- **应用与推广**：为 $N$-复形、$m$-周期复形、Morita 环上的模范畴、拟凝聚层与 Banach 空间范畴提供统一的三角稳定范畴构造；右/左弱 Serre 函子在环扩张下的稳定性说明其适合表示论中非对称代数与 Morita 语境。
