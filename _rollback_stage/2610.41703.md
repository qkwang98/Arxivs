# Exchange graphs and $g$-vectors of surface rigid algebras

keywords: [support τ-tilting 理论, 曲面刚性代数, 交换图, g-向量, Cartan 矩阵, 部分带标记三角剖分]
related_paper: "He–Zhou–Zhu (HZZ)：曲面 cluster 范畴中刚性对象自同态代数的几何模型"
one_liner_summary: "分类曲面刚性代数的支撑 τ-tilting 交换图与固定 τ-rigid 对的完成图的连通分支：连通代数的不连通当且仅当弱对称、至少两个单模且 Cartan 秩为一（此时恰有两个分支），并用带符号端点数据给出 τ-tilting 有限性、Cartan 矩阵正定性与有限型 g-向量射线生成元的完整刻画。"

## 1.  核心定位

- **解决的问题**：对任意曲面刚性代数（由带孔标记曲面的部分带标记三角剖分给出）分类支撑 τ-tilting 交换图以及固定基本 τ-rigid 对的完成图的连通分支，并在端点全在尖点的情形用端点数据刻画 Cartan 矩阵、$g$-向量与有限型根集。
- **大图景位置**：将 Adachi–Iyama–Reiten 的 τ-tilting 理论与 Fomin–Shapiro–Thurston 的曲面 cluster 组合结合，扩展 He–Zhou–Zhu 的曲面刚性代数几何方法；同时修正 HZZ 推论 5.18 在无边界条件下的不成立断言（sparse digon 给出反例），给出该无限制断言的正确分类。
- **主要贡献**：
  1. 连通代数 $A$ 的交换图不连通当且仅当 $A$ 弱对称、至少两个单模且 Cartan 秩为一，此时恰有两个连通分支，分别含 $(A,0)$ 与 $(0,A)$；任意曲面刚性代数的分支数为 $2^{\delta_C(A)}$，其中 $\delta_C(A)$ 为满足上述三条的块数。
  2. 对任意非零基本 τ-rigid 对 $u$，完成图 $\mathcal F_A(u)$ 连通；一般地 $\#\pi_0\mathcal F_A(u)=2^{\#\{B\in\mathcal B_C(A):u_B=(0,0)\}}$，并由此得到 keep-summand 意义下的 reachable-in-face 性质。
  3. 当所有弧端点都在尖点时，$C_A=B^tB$ 且 $Bg_{\mathbf R}(\gamma)=\eta(\gamma)$（有符号端点矩阵 $B$）；τ-tilting 有限等价于 Cartan 矩阵正定，等价于有符号端点图 $\Gamma_{\mathbf R}$ 每个分量是树或恰有一个非平衡环；有限情形的 primitive $g$-向量射线生成元在端点坐标下呈 $A_n$（树）或 $D_n/C_n$（单环，视共轭对或围无尖点圆盘而定）根集。
- **关键先驱工作**：AIR 的 τ-tilting 理论；FST 的曲面 cluster 组合；HZZ 的曲面刚性代数几何模型（$\tau$-tilting 对由相对部分带标记三角剖分的剖分表示）；Jasso 将完成图等同为约化代数交换图及 AHIKM 的商扇定理；AAC 对 Brauer graph 代数的树与奇环有限性判据；FGLZ 的 gentle 代数连通性与 reachable-in-face 性质。
- **结果边界**：不连通判据按块给出且要求弱对称、至少两个单模与 Cartan 秩一；HZZ 原推论在无边界条件下不成立（sparse digon 反例），本文的修正在允许共轭弧与非 sparse 构型下成立；射线集识别针对 primitive 射线生成元，锥面及规范 $g$-多面体的凸性还依赖 tagged 相容性；曲面嵌入可改变射线集而保持有符号端点矩阵与 Cartan 型不变。
- **开放问题**：文中未显式列出；自然引申包括：非有限情形下规范 $g$-多面体的锥面结构与凸性的完整描述，以及端点坐标判别向端点不全在尖点的部分带标记三角剖分的推广。
- **应用与推广**：为 τ-tilting 突变的连通性提供纯代数判据，可用于 gentle/skew-gentle 与 Brauer graph 代数的倾斜理论；切割曲面实现约化的几何手法可迁移到其他带曲面模型的代数类（如分数 Brauer graph 代数）；有限型射线根集（$A_n/D_n/C_n$）可服务 cluster 理论中扇形与极限结构的研究。

- 块级判据 $\#\pi_0=2^{\delta_C(A)}$ 依赖各块独立的乘积结构，但证明通过切割几何完成；是否存在不依赖曲面模型的纯代数证明？
