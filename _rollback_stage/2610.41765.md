# On the generic case of Jiang's conjecture

keywords: [Jiang's conjecture, wavefront set, Aubert-Zelevinsky involution, generic representation, local Langlands correspondence, supercuspidal representation]
related_paper: "2609.27261"
one_liner_summary: "对拟分裂 p-adic 群证明 Jiang 猜想的一般情形：只要假定局部 Langlands 对应满足与 Langlands 分类及 tempered 抛物诱导相容两条公理，任意 generic 不可约容许表示的 Aubert–Zelevinsky 对合之 L-参数在 Arthur 的 $\SL_2(\BC)$ 上必然平凡。"

## 核心定位

- **解决的问题**：证明 Jiang 猜想的 generic 情形（本文 Conjecture 4 的等价形式）：设 $G$ 为拟分裂群并配有局部 Langlands 对应 $\LLC$，若 $\pi$ 是 generic 表示，则 $\LLC(\widehat{\pi})$ 在 $\SL_2(\BC)$ 上平凡，其中 $\widehat{\pi}$ 为 $\pi$ 的 Aubert–Zelevinsky 对合。
- **大图景位置**：这是上界猜想（HLLS24、CK25）在 $\pi$ generic 时的直接推论，而该上界猜想等价于 Jiang 对任意局部 Arthur 包波前集的原猜想（Jia14）。此前仅在经典群族（$\RU_n,\Sp_{2n},\SO_{2n+1},\SO_{2n}^{\alpha}$ 及其纯内形式，LLS24）以及分裂辛群与正交群（Atobe–Ciubotaru，$p\gg 0$）等特殊情形成立；本文首次对一般拟分裂群给出证明，代价是假定推测性 LLC 满足两条自然公理。
- **主要贡献**：1. 约化定理：若 Conjecture 4 对所有 Levi 子群的 generic 超尖表示成立，则对 $G$ 的所有 generic 表示成立（以 Jacquet 函子与 Aubert–Zelevinsky 对合的相容性及 Casselman–Shahidi 广义单射猜想为关键输入）；2. 超尖情形给出两条独立论证——条件 (a) 下利用 Kaletha 构造（$p\gg 0$ 时 generic 超尖表示非奇异，其参数离散且平凡于 $\SL_2(\BC)$）；条件 (b) 下用 Gross–Prasad–Rallis、Haines 猜想构造非超尖 generic 成员，与唯一性公理矛盾的反证法（无 $p$ 限制）。
- **关键先驱工作**：Jiang (Jia14) 原猜想与 LS23 的推广；HLLS24 与 CK25 的等价重述；Mœglin–Waldspurger 与 Varma 的几何波前集/广义 Whittaker 模型理论（generic 当且仅当波前集为正则轨道）；Kaletha (Kal21) 的非奇异超尖表示与 LLC 构造；Casselman–Shahidi、Hanzer、Dijols 直至 Solleveld 完全证明的广义单射猜想；LLS24 对经典群族的显式 LLC 证明。
- **结果边界**：定理是假设性的——需要存在满足 (LC)（与 Langlands 分类相容）与 (IT)（与温性抛物诱导相容）的 LLC；条件 (a) 要求 $p\gg 0$ 且 $\LLC$ 与 Kaletha 构造一致；条件 (b) 要求 Gross–Prasad–Rallis 猜想、温性 L-包中 generic 成员唯一性以及 Haines 猜想成立。LLC 的存在性本身未被证明，故结果仍是"公理假定下的条件证明"。
- **开放问题**：不依赖 $p$ 限制或 Kaletha 条件的一般证明；证明或反驳条件 (b) 中三条猜想；对非 generic 表示将上界猜想推进到更广群类。
- **应用与推广**：为上界猜想（HLLS24）在一般拟分裂群上补齐 generic 支柱；结合局部 ABV 包理论检验 Arthur 型表示波前集的上界；为 LLC 构造的合理性提供一条新判据——任何满足 (LC) 与 (IT) 的合理 LLC 必须使 generic 表示的 Aubert 对合参数平凡化于 $\SL_2(\BC)$。

## 主动思考区

### 与其他工作的联系

- 这让我想起：经典群 Arthur 分类中 $\Psi(\pi)$ 的组合结构与 wavefront 上界（HLLS24）— 见 [[2609.27261]]
- [[2609.27261]]：其 $\Psi(\pi)$ 组合结构与 $\psi^{max}(\pi)$ 正是 upper bound conjecture 的输入；本文补上该猜想在 generic 情形、一般拟分裂群上的正面结果。
- [[2610.27924]]：supercuspidal blocks 与 LLC 的研究（含 Kaletha 基于 rigid inner forms 的非奇异超尖参数化），为本文条件 (a) 提供背景支撑。

- 技术迁移：本文"先约化到超尖、再用 Kaletha 离散参数或矛盾法"的两步论证，可用于将其它关于 generic 表示的猜想（如 Shahidi 猜想、局部 packet 性质）从经典群族推广到一般拟分裂群。

### 批判性思考

- 约化步骤依赖 Jacquet 函子与 Aubert–Zelevinsky 对合的相容性以及 Solleveld 完全证明的广义单射猜想，两处环环相扣，值得逐项核对假设的适用范围。
- 条件 (a) 与 (b) 是两条互斥的技术路线而非统一框架；是否存在更本质的机制（如 ABV 包理论）同时蕴含二者，是一个悬而未决的结构问题。
