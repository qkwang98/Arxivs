# Decomposing super unitary representations using Berezin integration

keywords: [超酉表示, Berezin 积分, 超 Heisenberg 群, 共轭轨道, 超几何量子化, 超流形]
related_paper: "2610.41742"
one_liner_summary: 引入依赖奇参数的超酉表示族及其直接 Berezin 积分，用以分解超 Heisenberg 群与类超 Heisenberg 群的左正则表示，并与超几何量子化在共轭轨道上得到的表示相比较。

## 核心定位

- **解决的问题**：如何将超群的左正则表示分解为不可约子表示，以及如何将该分解与超几何量子化在共轭轨道上构造的表示对应起来。
- **大图景位置**：将经典 Heisenberg 群的 Fourier 分解（直接积分表示）推广到超设置，同时把 Kirillov 型共轭轨道量子化方案推广到超流形，属于超表示论与超几何量子化的交叉尝试。
- **主要贡献**：提出"依赖奇参数的超酉表示族"与"超表示的直接 Berezin 积分"两个新概念；用它们分解超 Heisenberg 群 $\SuperH$ 与类超 Heisenberg 超群 $G$ 的左正则表示；通过与共轭轨道量子化结果的比较，指出超情形必须使用带奇辛形式的轨道（对 $\SuperH$）乃至带非齐次辛形式的轨道（对 $G$）。
- **关键先驱工作**：经典 Heisenberg 群的正则表示分解；Kirillov 共轭轨道几何量子化；DeWitt 的 $H^\infty$ 超流形理论（等价于 Leites 与 Kostant 的分次流形理论）。
- **结果边界**：针对共轭轨道量子化的理论框架目前只有部分成立——有超预量子化、超极化和相应的函数空间，但缺少半密度/半形式概念的推广，无法在这些函数空间上自然定义超 Hilbert 空间结构；奇 Berezin-Fourier 变换引入的奇参数 $\kappa$ 要求分解中全部奇参数均为其实倍数，限制了一般 $p\vert q$ 参数族的比较。
- **开放问题**：如何推广半密度/半形式以在量子化函数空间上构造自然的超 Hilbert 结构；如何让任意 $p\vert q$ 族中的奇参数不必受制于单一 $\kappa$。
- **应用与推广**：为超李群表示论提供新的分解工具；所建立的"极化分次维度不恒定且导致不等价表示"现象为超几何量子化的极化理论提供检验标准，可推广到更一般的超李群。
