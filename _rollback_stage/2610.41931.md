# A Tropical Viewpoint on the Nagata--Biran--Szemberg Conjecture

keywords: [Nagata conjecture, Nagata-Biran-Szemberg conjecture, Seshadri constant, tropical geometry, semistable degeneration, interpolation]
related_paper: "2609.27965"
one_liner_summary: "本文用热带几何重新解释 OpenAI 对 Nagata 猜想与 Nagata--Biran--Szemberg 猜想的证明思路：通过退化到正规锥与对偶图为圈的半稳定模型，把曲面上的截面替换为二元 Laurent 多项式，用热带方法界定其指数并用环面插值证明猜想及其精确阈值。"

## 1.  核心定位

- **解决的问题**：在 $|\nu H|$ 含有一条唯一奇点为非基点的普通结点的整曲线时，证明 Nagata--Biran--Szemberg 猜想（多重 Seshadri 常数达到上界 $\sqrt{h/r}$ 的阈值版本），并由此推出非严格形式的 Nagata 猜想。
- **大图景位置**：Nagata 猜想（$r\geq10$ 个一般点情形 $\sum_i\mult_{p_i}(C)<d\sqrt{r}$）是 Nagata--Biran--Szemberg 猜想的特例，后者预测极化曲面 $(X,H)$ 上足够多一般点的多重 Seshadri 常数达到理论上界 $\sqrt{h/r}$。本文给出该猜想的显式阈值 $r_0$，是 OpenAI 定性版本（无显式阈值）的定量强化，并把其 theta 函数论证替换为热带几何论证。
- **主要贡献**：
  1. 主定理（定理 main-thm:technical-nagata）：若 $|\nu H|$ 含唯一奇点为非基点的普通结点的整曲线 $B_0$，则对一切 $r\geq\nu^2 h$，极一般的 $\mathfrak{p}\in\operatorname{Conf}_r(X)$ 满足 $\varepsilon(X,H;\mathfrak{p})=\sqrt{h/r}$。
  2. 定理 main-thm:general-nagata：若 $kH$ 极丰沛且 $(X,kH)\neq(\mathbb{P}^2,\mathcal{O}_{\mathbb{P}^2}(1))$，则对一切 $r\geq4k^2 h$ 结论成立——对全部极化曲面给出（更差的）阈值。
  3. 推论给出三个具体例子：$(\mathbb{P}^2,\mathcal{O}(1))$ 取 $r_0=9$（即非严格 Nagata 猜想）、$(\mathbb{P}^1\times\mathbb{P}^1,\mathcal{O}(1,1))$ 取 $r_0=8$、$\mathbb{P}^3$ 中 $d\geq3$ 度光滑曲面取 $r_0=d$；并由此推出严格 Nagata 猜想（定理 main-thm:nagata-I）。
  4. 方法论贡献：把 theta 函数替换为"支持界 + 环面插值"的热带机制——用热带 Abel–Jacobi 类的提升（tropical moment）控制 Laurent 多项式的指数图，证明可推广到高亏格曲线。
- **关键先驱工作**：Nagata 原证明（$r$ 为完全平方）；Demailly 的 Seshadri 常数；Küchle 的多点 Seshadri 常数；Biran、Szemberg–Tutaj-Gasińska 的猜想提出；OpenAI 的两篇工作（Nagata 猜想与 NBS 猜想的定性证明）；Tevelev 的 theta 函数解释；Baker–Norine、Mikhalkin–Zharkov 的热带 Abel–Jacobi 理论；Baker–Jensen 的多重次数映射。
- **结果边界**：主定理依赖线性系含"单结点整曲线"这一几何条件（如主极化阿贝尔曲面上的 theta 除子线性系满足光滑正亏格但不满足该条件）；一般定理给出的是更差阈值 $4k^2h$ 而非 $\nu^2h$；$(\mathbb{P}^2,\mathcal{O}(1))$ 的 $k=1$ 情形被排除（$r=5,\dots,8$ 为反例）；特征与域假设为特征零的不可数代数闭域。
- **开放问题**：对不含单结点整曲线的线性系（如 theta 除子）能否去掉额外假设；更一般的半稳定模型双图（非圈）是否可强化阈值；"调和热带 moment"的构造。
- **应用与推广**：Seshadri 常数的精确计算与插值问题的热带化；与 Newton–Okounkov 体的联系（本文三角形 $\mathcal{P}_{\kappa,\alpha}$ 是 $(d/m)H$ 的 Newton–Okounkov 体的剪切）；符号幂与 fat point 线性系统的无碍性问题（参见 [[2609.27965]]）。
