# Type classifiers

keywords: [类型分类子, 依值类型论, 语境范畴与族, 宇宙, 单值公理, 格罗滕迪克 topos]
related_paper: "2610.41068"
one_liner_summary: "用类型分类子（type classifier）扩展依值类型论，通过在语境中引入自由类型变量实现无需宇宙的全类型量化，并在语境范畴与族（contextual cwfs）范畴中构造其模型，证明同构类型的替换在即使外延类型论中亦诱导结果类型的同构，从而给出单值公理不变性的类比。"

## 核心定位

- **解决的问题**：依值类型论中，对"所有类型"进行的量化（如关于所有群的定理）通常依赖宇宙，但 Girard 悖论禁止自含的宇宙，而宇宙层次与多态性只是把量化问题向更高层转移，且宇宙闭包公理会不必要地提高证明论强度。
- **大图景位置**：以类型分类子取代"分类所有类型的类型"，本质是类比 topos 理论中的相对对象分类子（relative object classifier）——每个格罗滕迪克 topos 上存在这样的分类子，其上的几何态射对应定义域 topos 的对象，从而无需内部宇宙对象即可对任意对象进行推理。
- **主要贡献**：（1）引入类型分类子扩展类型论语境，其泛性质允许被任意闭类型替换，得到"分类所有类型的语境"而非"分类所有类型的类型"；（2）在语境范畴与族（contextual cwfs）范畴中构造完整模型——采用局部笛卡尔闭范畴大模型（big model）构造的简化版本，contexts 自身是类型论的小模型，类型与项为其中的闭类型与闭项，协变替换为保持结构及类型构造子的函子；（3）证明替换同构类型诱导自然同构的替换，进而诱导结果类型之间的同构——即使在外延类型论中也成立，给出同伦类型论中单值公理不变性的类比；省略函数类型使所有类型构造子协变时，自然性可推广到任意（可能不可逆）映射。
- **关键先驱工作**：Girard 悖论（自含宇宙的不可能性）；Palmgren 关于宇宙闭包公理提高证明论强度的讨论；Bidlingmaier 的局部笛卡尔闭范畴大模型构造；BKS（Lemma 25）关于自由邻接给定闭类型项给出语境余切片（contextual coslice）的结论。
- **结果边界**：模型建立在语境范畴与族之上，依赖大模型构造及其简化版本；类型分类子作为与一个闭类型上的自由语境范畴与族的余积获得；当理论含函数类型时自然性仅限于同构（单值类比），推广到任意映射需放弃函数类型以保证所有类型构造子协变。
- **开放问题**：类型分类子理论在含函数类型情形下是否能获得更强的自然性；与同伦类型论中单值公理的关系还有哪些深层类比值得展开。
- **应用与推广**：允许不引入宇宙直接表述关于任意类型参数的数学断言，避免不必要的证明论强度假设，使形式化结果可在不含这些宇宙的小模型中解释；为类型论语义研究与 topos 理论之间的类比提供新桥梁。

### 批判性思考

- 类型分类子给出的"语境分类所有类型"与宇宙的"类型分类所有类型"在表达力上是否真正等价？作者的处理绕开了 Girard 悖论，但其代价是量化形式从依赖积变为语境扩展，实际使用时的语法成本值得考察。
- 外延类型论中获得单值不变性的类比，其"同构诱导同构"是否严格弱于单值公理的完全等价替换原则？作者未在本文给出完整比较。
