# Relative homological algebra of filter modules

keywords: [filter 模块, 相对同调代数, 整体维数, 分配格, 投射化, 持久性理论, 相对导出函子]
related_paper: "2610.41614"
one_liner_summary: 在任意有序集上的 kQ-模范畴中，以 filter 模块为相对投射对象引入 filter 精确结构，通过 filter 分配格给出显式投射化并确定其整体维数上下界，同时刻画 filter-tiny 有序集相对内射预壳的存在性。

## 核心定位

- **解决的问题**：为 Miller 的 fringe 表示理论补齐同调基础——建立以 filter 模块（升集指示模块）为相对投射对象的相对同调代数，并测量其整体维数。
- **大图景位置**：将持久性理论/TDA 中区间模块的 interval 相对同调框架推广到 filter/ideal 模块，把相对同调性质约化到分配格上的 incidence 代数 $k\operatorname{Fil}(Q)$ 的标准同调，属于表示论与拓扑数据分析的交叉。
- **主要贡献**：刻画 filter 模块的普遍性质并构造 filter 精确结构 $\mathcal F_{\mathcal U}$ 的显式投射化（通过 $\eta\colon Q\to\operatorname{Fil}(Q)$ 的拉回与余诱导函子 $\eta_\sharp$）；在有限 join-半格情形利用反链给出 $k\operatorname{Fil}(Q)$ 的全局维数等于 $Q$ 的宽度 $W$（$|Q|>1$），并借此得到相对整体维数不等式 $W\le 2+\operatorname{gldim}_{\filt}kQ\le 2+W$；引入 filter-tiny 概念，证明若相对整体维数大于 1 则不存在相对内射预壳。
- **关键先驱工作**：经典 $kQ$-模表示论（Gabriel、Nazarova-Roiter）；Auslander-Reiten-Smalø 关于 Artin 环整体维数的经典引理；Miller 的 fringe/flange 表示理论；Chachólski-Guidolin-Ren-Scolamiero-Tombari 的 filter 模块相对同调；interval 相对同调与 interval-全局维数的工作。
- **结果边界**：整体维数计算限于 $|Q|>1$ 的有限 join-半格；投射化方法依赖 $\operatorname{Fil}(Q)$ 的分配格结构，不易直接迁移到其他精确结构；filter-tiny 类适用于哪些有序集尚属开放，非 filter-tiny 情形的相对内射模未分类。
- **开放问题**：filter-tiny 条件对哪些有序集成立；非 filter-tiny 有序集的相对内射模是什么；filter 分解与 fringe 表示的关系。
- **应用与推广**：为 fringe 表示提供最小性（投射覆盖/内射壳）同调工具；可用于持久性理论中非线序参数化的 $kQ$-模分解与障碍测量；$\operatorname{gldim}_{\filt}$ 的不等式给出 filter 相对维数的可计算界。
