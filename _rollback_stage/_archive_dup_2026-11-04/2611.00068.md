# Univalent Non-Associative Categorical Structures

keywords: [Univalent Foundations, Duploids, Adjunction Models, Polarization, unital magmoid]
related_paper: "Munch–Maccagnoni, Models of a Non-Associative Composition (2014)"
one_liner_summary: 本文在单值化基础（UniMath/Rocq 形式化）中研究 unital magmoid 与 duploid 两类非结合范畴结构，定义了其单值性概念，指出由伴随构造的 duploid 作为单类（single-sorted）duploid 不满足单值性，并给出满足单值性的新构造。

## 核心定位

- **解决的问题**：在单值化基础中为 unital magmoid 与 duploid 建立正确的单值性概念，并修复"从伴随构造 duploid"这一经典构造中引入的、在好的同构下不保持的额外结构。
- **大图景位置**：它是 Ahrens 等人开创的单值化范畴论向非结合组合结构的推广，同时把 Munch–Maccagnoni 的 duploid/极化理论与 Levy 的 call-by-push-value 联系起来，为编程语言极化的范畴模型提供单值化表述。
- **主要贡献**：
  1. 定义了 univalent unital magmoid 与 univalent duploid，并区分 single-sorted 与 two-sorted 两种变体及其各自的单值性定义；
  2. 指出 unital magmoid 中"好的同构"除 linear（Munch–Maccagnoni）与 thunkable（Führmann）外还需满足第三个性质 intermediate；在 duploid 中该性质对既 linear 又 thunkable 的同构自动成立；
  3. 证明旧构造（由伴随诱导的 duploid）作为 unital magmoid 或 single-sorted duploid 不满足单值性，并给出一个满足 single-sorted 单值性条件的替代构造；
  4. 在 UniMath 库（Rocq 证明助手）中完整形式化：共 7958 行代码、跨 22 个文件，位于 UniMath/CategoryTheory/Nonassociative/ 目录。
- **关键先驱工作**：Munch–Maccagnoni 的 duploid 理论与其博士论文；Levy 的 call-by-push-value 与 Contextual Isomorphisms；Führmann 的 thunkable isomorphism；Ahrens 等的 univalent category 与 The Univalence Principle；UniMath 形式化库。
- **结果边界**：单值性定义依赖特定的同构概念（linear + thunkable + intermediate），不同变体（single-sorted / two-sorted）的单值性定义不同；本文未包含 duploid 的内部语言与联系 duploid 范畴和伴随范畴的完整"结构定理"。
- **开放问题**：文中未显式列出开放问题；可推断 two-sorted duploid 是否也能获得满足其单值性定义的伴随构造，以及 duploid 内部语言在单值化设定下的表述。
- **应用与推广**：为 call-by-push-value、经典逻辑与线性逻辑的极化模型提供单值化基础下的严格表述；形式化代码直接嵌入 UniMath 生态，可复用于其它非结合结构（如非结合环、loop）的单值化研究。
