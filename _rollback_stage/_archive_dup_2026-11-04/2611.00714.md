# Cube-freeness and a square formula for canonical trace ideals of Stanley--Reisner rings

keywords: [canonical trace ideal, Stanley–Reisner 环, cube-free 单项式理想, 局部 Gorenstein, normal pseudomanifold]
related_paper: "关于 locally Gorenstein 的 Cohen--Macaulay Stanley--Reisner 环的 canonical trace ideal 分类的工作（引文 MV、KM26）"
one_liner_summary: "证明了所有 Stanley--Reisner 环的 canonical trace ideal 都是 cube-free 的，并在 $(S_2)$ 条件下给出了其等于根号平方的充要条件。"

## 1.  核心定位

- **解决的问题**：回答两个问题：其一，每个 Stanley–Reisner 环的 canonical trace ideal 是否 cube-free（最小单项式生成元的指数至多为 2）？其二，在什么假设下等式 $\tr_R(\omega_R)=\bigl(\sqrt{\tr_R(\omega_R)}\bigr)^2$ 成立？
- **大图景位置**：这是 trace ideal 理论在组合交换代数中的系统推进，将 locally Gorenstein 性质的可计算描述从 Cohen–Macaulay 情形推广到 $(S_2)$ 情形，并首次以指数约束（bounded 单项式理想）回答 cube-free 问题。
- **主要贡献**：1) 定理 A：若 $I$ 是 $\mathbf{a}$-bounded 的单项式理想，$M$ 是正 $\mathbf{b}$-determined 的 $R=S/I$-模，则 $\tr_R(M)$ 是 $(\mathbf{a}+\mathbf{b})$-bounded，特别地 canonical trace ideal $\tr_R(\omega_R)$ 是 $2\mathbf{a}$-bounded；取 $\mathbf{a}=\mathbf{1}$ 即得所有 Stanley–Reisner 环的 canonical trace ideal 均 cube-free。2) 定理 B：对满足 $(S_2)$ 的 Stanley–Reisner 环，$(G_2)$ 成立当且仅当 $\tr_R(\omega_R)=\bigl(\sqrt{\tr_R(\omega_R)}\bigr)^2$；当 $\Delta=\core(\Delta)$ 且 $\dim\Delta\ge 1$ 时，该等式恰在 $\Delta$ 为 normal pseudomanifold 时成立。3) 证明利用 Gröbe 对 canonical module 的描述，为 normal pseudomanifold 构造了一个配对（引理）。
- **关键先驱工作**：HHS 表明 Cohen–Macaulay 情形下 canonical trace ideal 定义非 Gorenstein 轨迹；MV 给出 locally Gorenstein 的 Cohen–Macaulay Stanley–Reisner 环的 canonical trace ideal 三分分类（$R$、$\mathfrak m$、$\mathfrak m^2$）；KM26 在连通假设下去掉 Cohen–Macaulay 条件；Miller 与 Yanagawa 的 $\mathbf{c}$-bounded 与 squarefree 模理论；Stanley 的 core 与 pseudomanifold 理论。
- **结果边界**：定理 B 依赖 $(S_2)$（示例表明该条件不能省略），且 $(G_2)$ 不能被 $(G_1)$ 替换；根不一定是极大理想（存在非孤立奇点的示例）；指数上界 $2\mathbf{a}$ 是在 $\mathbf{a}\ge\mathbf{1}$ 的设定下导出的。
- **开放问题**：对不满足 $(S_2)$ 的环，平方公式的充要刻画是否仍有简洁描述？更一般地，对非 Stanley–Reisner 的单项式商环，canonical trace ideal 的平方公式在什么条件下成立。
- **应用与推广**：为判定 locally Gorenstein 与 Gorenstein 性质提供纯组合判据（normal pseudomanifold）；bounded 指数技术可迁移到边理想、facet 理想等其他由单项式理想定义的环境，研究 trace ideal 的指数约束。
